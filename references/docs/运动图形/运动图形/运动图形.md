# 运动图形

运动图形是可视化设计的一个分支，其中通常涉及重新排列抽象形状并将其变换为有趣的动画。下面列出了有助于呈现这类效果的功能。

| [多边形文本](../创建多边形文字/创建多边形文字.md) | 允许使用安装的任何字体创建 3D 文本。然后，可以按线条、单词或字符对文本进行修改、上色、重新定形和设置动画。 对于以下场景特别有用：与[曲线扭曲(Curve Warp)变形器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C3C6DF01-C240-4668-ADFD-27762257C5A8)结合使用以创建移动或扭曲标题；或者与 MASH 结合使用以形成或分离文本。 |
|---|---|
| [多边形 SVG 对象](../从%20SVG%20对象创建多边形网格/从%20SVG%20对象创建多边形网格.md) | 允许将 2D SVG 对象作为 3D 多边形对象导入。然后，可以按层对对象进行修改、上色、重新定形和设置动画。 有助于快速将向量图像转换为 3D 对象，以便使其翻滚和变形。 |
| [MASH 程序效果](../MASH%20程序效果/MASH%20程序效果.md) | 允许创建多边形对象的实例或完整网格重现，然后对其应用不同的程序效果。可以组合使用效果，以便形成复合结果。 有助于创建并调整形状和颜色的 2D 或 3D 抽象效果。 |
| [Adobe 实时链接](../Maya%20到%20Adobe%20After%20Effects/Maya%20到%20Adobe%20After%20Effects/与%20Adobe%20After%20Effects%20的实时链接.md) | 允许您同时在 Maya 和 Adobe® After Effects® 中查看场景。 |
