# 从 SVG 对象创建多边形网格

使用“SVG 工具”(SVG Tool)（“创建 > SVG”(Create > SVG)），可以创建具有可扩展向量图形形状和样式的多边形网格。

## 导入和修改 SVG 网格

有关相关“类型工具”(Type Tool)的信息，请参见[创建多边形文本](../创建多边形文字/创建多边形文字.md)。
