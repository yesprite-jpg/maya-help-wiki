# 智能预设

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../assets/Maya-MotionGraphics/GUID-4AB6AA8F-094A-422B-981B-D2867DCC6E66.png) <!-- baize:img-hook downloaded=true reason="正文 206 字 <300 且带图" -->

智能预设是一系列预制的脚本，用于执行常见的运动图形任务。您可以在[内容浏览器(Content Browser)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9221B2E8-7E68-4ECB-94DC-ABEB21E956BF)中找到智能预设。

使用智能预设

1. 打开[内容浏览器(Content Browser)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9221B2E8-7E68-4ECB-94DC-ABEB21E956BF)。

2. 转到“智能预设”(Smart Presets)文件夹。

3. 使用鼠标中键将预设拖动到您的场景中。

根据选定的预设，Maya 可能会显示其他说明以指示您执行相应操作。很多情况是打开另一个对话框窗口，可以使用鼠标中键在其中拖动想要应用预设的节点。
