# MASH 节点概述

MASH 的主干是其节点网络。每个节点执行特定的功能，且可与其他节点组合以合成自身的行为。您可以通过 [Waiter](MASH%20节点概述/Waiter.md) 节点的“属性编辑器”(Attribute Editor)将大多数（但并非全部）节点添加到网络。

| [音频(Audio)](MASH%20节点概述/音频.md) | 使用音频输入文件驱动动画。 |
|---|---|
| [颜色(Color)](MASH%20节点概述/颜色.md) | 在 MASH 网络中自定义网格的 CPV 数据。 |
| [曲线(Curve)](MASH%20节点概述/曲线.md) | 沿曲线设置对象的动画。 |
| [延迟(Delay)](MASH%20节点概述/延迟.md) | 在时间上偏移对象的现有动画。 |
| [分布(Distribute)](MASH%20节点概述/分布.md) | 在形式上排列对象的多个副本。 |
| [动力学(Dynamics)](MASH%20节点概述/动力学.md) | 将动力学作用力应用于 MASH 点。 |
| [飞行(Flight)](MASH%20节点概述/飞行.md) | 近似于聚集/集群行为。 |
| [ID](MASH%20节点概述/ID.md) | 自定义为 MASH 点指定实例化对象的方式。 |
| [影响(Influence)](MASH%20节点概述/影响.md) | 使用导向对象影响 MASH 网络的变换。 |
| [合并(Merge)](MASH%20节点概述/Merge.md) | 将两个 MASH 网络合并到一起。 |
| [偏移(Offset)](MASH%20节点概述/偏移.md) | 偏移对象变换。 |
| [方向(Orient)](MASH%20节点概述/方向.md) | 将对象指向移动方向或另一个对象。 |
| [放置器(Placer)](MASH%20节点概述/放置器.md) | 允许通过绘制来放置 MASH 点。 |
| [Python](MASH%20节点概述/Python.md) | 允许编写自定义 Python 脚本。 |
| [随机(Random)](MASH%20节点概述/随机.md) | 随机数生成器。 |
| [复制器(Replicator)](MASH%20节点概述/复制器.md) | 复制 MASH 网络。 |
| [信号(Signal)](MASH%20节点概述/信号.md) | 将 4D 噪波或三角动画添加到网络。 |
| [强度(Strength)](MASH%20节点概述/强度.md) | 控制连接节点在网络上的效果程度。 |
| [弹簧(Spring)](MASH%20节点概述/弹簧.md) | 将弹簧添加到对象的动画。 |
| [对称(Symmetry)](MASH%20节点概述/对称.md) | 沿指定的轴反射整个 MASH 网络。 |
| [时间(Time)](MASH%20节点概述/时间.md) | 偏移组件动画。 |
| [变换(Transform)](MASH%20节点概述/变换.md) | 移动/旋转/缩放整个网络。 |
| [可见性(Visibility)](MASH%20节点概述/可见性.md) | 控制对象的可见性。 |
| [Waiter](MASH%20节点概述/Waiter.md) | 充当 MASH 网络的中心，可用于添加其他节点。 |
| [世界(World)](MASH%20节点概述/世界.md) | 在自然的非碰撞簇中围绕点排列对象。 |

禁用“仅 DAG 对象”(DAG Objects Only)时，可以通过使用 MASH 过滤器的“显示 > 对象 > MASH”(Show > Objects > MASH)在 [MASH 编辑器](MASH%20窗口和编辑器/MASH%20编辑器.md)或常规大纲视图中查看 MASH 节点。
