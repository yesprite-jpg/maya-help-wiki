# 运动图形工作区

“运动图形”(Motion Graphics)工作区可排列界面，使您能够快速访问相关程度最高的工具，用于创建和编辑运动图形。有关详细信息，请参见[工作区](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0384C282-3CA1-4587-9775-F7164D3F6980)。

若要切换到“运动图形”(Motion Graphics)工作区，请转到“窗口 > 工作区 > 运动图形”(Windows > Workspaces > Motion Graphics)，或者从界面右上角的“工作区”(Workspace)下拉菜单中选择“运动图形”(Motion Graphics)。
