# Mac OS X 版 Maya 中的热键

本部分说明在 Mac OS X 版 Maya 中使用热键时可能会遇到的不同之处。

## 热键和 Exposé

Exposé 热键（F9、F10、F11、F12）可能会与 Maya 预设热键冲突。如果遇到该问题，可以更改 Maya 热键，或者可以在运行 Mac OS X 的计算机上更改“系统首选项”(System Preferences)面板中的 Exposé 热键。

## 使用设置焦点热键 (Alt‘) 更改焦点

如果将“Alt `”用作将焦点设置为数值输入字段的热键，则必须按该热键两次才能将焦点设置为数值输入字段。但是，如果使用其他热键（不是“Alt `”）完成相同功能，则按一次该热键组合即已足够。

## 移动枢轴

默认情况下，键盘上的“D”键可以用于移动枢轴点。按住“D”键并拖动操纵器可移动枢轴点。对于没有“Insert”或“Home”键的 Mac 键盘而言，这非常有用。
