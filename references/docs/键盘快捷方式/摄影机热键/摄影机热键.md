# 摄影机热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| 翻滚、平移或推拉 |  |  |
|---|---|---|
| Alt | 鼠标左键 | 翻滚工具（按下并释放） |
| Alt | 鼠标中键 | 平移工具（按下并释放） |
| Alt | 鼠标右键 | 推拉工具（按下并释放） |

| 二维平移/缩放 |  |  |
|---|---|---|
| \+ | 鼠标中键 | 二维平移工具 |
| \+ | 鼠标右键 | 二维缩放工具 |
| \ |  | 启用/禁用二维平移/缩放。 |
