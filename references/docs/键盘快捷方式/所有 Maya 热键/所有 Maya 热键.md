# 所有 Maya 热键

本主题提供了所有 Maya 热键的可搜索列表。您也可以使用此页面底部的链接来查找相关热键组。

**注**

提示：

将热键表复制到电子表格程序中，或者打印网页以将其用作快速参考。

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command
