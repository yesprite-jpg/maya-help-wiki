# 工具和操作热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| 工具操作 |  |  |
|---|---|---|
|  | 回车 | 完成当前工具 |
|  | 插入 | 进入工具编辑模式 |
|  | q | 选择工具或对选择遮罩标记菜单使用鼠标左键 |
|  | w | 移动工具或对移动工具标记菜单使用鼠标左键 |
|  | e | 旋转工具或对旋转工具标记菜单使用鼠标左键 |
|  | r | 缩放工具或对缩放工具标记菜单使用鼠标左键 |
| Ctrl | t | 显示通用操纵器工具 |
|  | t | 显示操纵器工具 |
|  | y | 选择不属于选择、移动、旋转或缩放的最后使用的工具 |
|  | j | （按住 + 拖动）移动、旋转、缩放工具捕捉 |
|  | =, + | 增加操纵器大小 |
|  | - | 降低操纵器大小 |
|  | d | 使用鼠标左键移动枢轴（移动工具） |
|  | 插入 | 在移动枢轴与移动对象之间切换（移动工具） |
|  | Tab 键 | 循环切换视图中编辑器值 |
| Shift | Tab 键 | 反向循环切换视图中编辑器值。 |
| Ctrl | 使用鼠标中键拖动（使用[移动工具(Move Tool)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)） | 沿其法线移动组件（仅限“组件”(Component)模式） |
| Ctrl | 使用鼠标中键拖动（使用[旋转工具(Rotate Tool)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C2D0F80C-812B-465D-A634-DB6ECFABFCB3)） | 沿其局部 X 轴旋转组件（仅限“组件”(Component)模式） |
| Ctrl | 使用鼠标中键拖动（使用[缩放工具(Scale Tool)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-487B6A23-E135-45E2-94F1-B0D59D6B6F33)） | 沿其局部 YZ 轴缩放组件（仅限“组件”(Component)模式） |

| 动作操作 |  |  |
|---|---|---|
| Ctrl | z | 撤消(Undo) |
| Ctrl | y | 重做(Redo) |
|  | g | 重复上次操作 |
|  | F8 | 在对象/组件选择模式之间切换 |
|  | p | 结成父子关系 |
| Shift | P | 断开父子关系 |
|  | s | 设置关键帧 |
| Shift | w | 对选定对象位置设定关键帧 |
| Shift | e | 对选定对象旋转设定关键帧 |
| Shift | r | 对选定对象缩放设定关键帧 |

| 属性编辑器 |  |  |
|---|---|---|
| Ctrl | a | 属性编辑器 |

| 捕捉到操作 |  |  |
|---|---|---|
|  | x | 捕捉到栅格(Snap to grids) |
|  | c | 捕捉到曲线(Snap to curves) |
|  | v | 捕捉到点(Snap to points) |
