# 动画热键

| 动画操作 |  |  |
|---|---|---|
|  | s | 设置关键帧 |
| Shift | e | 设置旋转关键帧 |
| Shift | r | 设置缩放关键帧 |
| Shift | w | 设置平移关键帧 |
| Alt | I | 插入关键帧（在“曲线图编辑器”(Graph Editor)内部或外部的任何曲线上，与当前时间指示器的位置相对应）。 注： 如果窗口焦点位于“曲线图编辑器”(Graph Editor)外部，则此热键会在所有曲线上插入一个关键帧。如果在“曲线图编辑器”(Graph Editor)内部，则此热键会在选定曲线上设置一个关键帧。 |
| Ctrl+Shift | e r w | 在特定通道上当前时间指示器的位置处插入关键帧：**E** 表示旋转，**R** 表示缩放，**W** 表示平移。 |
|  | I | 使用鼠标中键可以在选定曲线上的任意位置插入关键帧，而不管当前时间指示器的位置如何。 |
| Shift | s | 对关键帧标记菜单使用鼠标左键（或向左轻扫） |
| Shift | s | 对切线标记菜单使用鼠标中键（或向右轻扫） |
| Alt | V | 播放动画（再次按 V 可关闭动画） |
| Alt | j | 切换多色反馈 |
| Alt | 1 | 切换 NURBS 曲线可见性 |
| Alt | 2 | 切换多边形网格可见性 |
| Alt | 4 | 切换图像平面可见性 |
| Alt | 5 | 在线框视图和着色视图之间切换 |
| Ctrl | 1 | 在关节、控制和角色可见性之间切换 |
| Alt | t | 打开[“创建书签”(Create Bookmark)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-CBEFBC4B-925F-4A27-A3EE-C966FBFBB2CA)。 |
| Alt + Shift | t | 为选定的时间范围创建书签。（通过这种方式创建的书签没有名称，但会关联一种随机颜色。可在[书签管理器(Bookmark Manager)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7E26C8C9-6F27-4A56-8119-DC4A75DAC265)中修改相关设置。） |
|  | \|（竖线） | 框显书签(Frame Bookmark)：将播放范围设置为当前书签的开始和结束。（如果多个书签重叠，将选择顶部最新创建的书签。） |
|  | :（冒号） | 框显上一个书签(Frame Previous Bookmark)：在当前时间书签之前的书签上设置“范围滑块”(Range Slider)。 |
|  | "（引号） | 框显下一个书签(Frame Next Bookmark)：在当前时间书签之后的书签上设置“范围滑块”(Range Slider)。 |
| Alt | \（反斜线） | 取消框显书签(Unframe Bookmark)：将播放范围设置为动画范围。 |
|  | '（撇号） | 书签选择前进 |
|  | ;（分号） | 书签选择后退 |
| Ctrl | 拖动 (drag) | 在时间滑块上重新定位书签。 |
| Ctrl | 拖动左边缘或右边缘 | 在时间滑块上调整书签大小。 |
| Ctrl | 双击 | 选择书签和与之关联的帧，以便可以一起移动它们 |

| 播放控件 |  |  |
|---|---|---|
| Alt | . （句点） | 在时间方向上向前移动一帧 |
| Alt | ,（逗号） | 在时间方向上向后移动一帧 |
|  | . （句点） | 转到下一个关键帧 |
|  | ,（逗号） | 转到上一个关键帧 |
| Ctrl+Alt | . （句点） | 在“曲线图编辑器”(Graph Editor)中选择“下一个”(Next)关键帧，而不将其打开。 |
| Ctrl+Alt | ,（逗号） | 在“曲线图编辑器”(Graph Editor)中选择“上一个”(Previous)关键帧，而不将其打开。 |
| Alt | V | 启用或禁用播放 |
| Alt+Shift | V | 转到最小帧（通常为 0） |
|  | k | 为虚拟时间滑块模式使用鼠标中键（按住和拖动时间轴） |

| 时间编辑器 |  |  |
|---|---|---|
|  | q | 打开或关闭时间编辑器禁用 |
|  | m | 打开或关闭时间编辑器轨迹禁用 |
|  | n | 打开或关闭“单放轨迹”(Solo Track) |
| Ctrl | e | 导出选定对象 |
|  | I | 导入动画片段 |
| Shift | I | 导入音频片段 |
|  | l | 创建相加层 |
| Shift | L | 创建覆盖层 |
|  | o | 从场景选择中添加动画 |
|  | p | 从场景选择中添加姿势 |
|  | a | 框显全部(Frame all) |
|  | F | 框显当前选择(Frame selection) |
|  | W | 在当前帧分割片段 |
|  | g | 修剪之前的片段 |
|  | h | 修剪之后的片段 |
| Shift | G | 将片段的开头缩放至当前帧 |
| Shift | H | 将片段的结尾缩放至当前帧 |
|  | e | 修剪片段 |
|  | r | 缩放片段 |
|  | t | 循环片段 |
|  | Y | 保持片段 |
| Ctrl | g | 组片段 |
| Ctrl+Shift | G | 解组片段 |

| 曲线图编辑器(Graph Editor) |  |  |
|---|---|---|
| Alt | z | 撤消视图更改 |
| Alt | Y | 重做视图更改 |
|  | t | 居中当前时间 |
| Alt | /（正斜线） | 将时间标记捕捉到选定关键帧 |
|  | 1 | 切换到绝对视图 |
|  | 2 | 切换到堆叠视图 |
|  | 3 | 切换到归一化视图 |
|  | h | 锁定曲线通道 |
|  | j | 解除锁定曲线通道 |
|  | d | 自动切线 |
| Shift | 9 | 向左移动选定的关键帧 |
| Shift | 0 | 向右移动选定的关键帧 |
| Ctrl+Alt | ,（逗号） | 选择上一个关键帧 |
| Ctrl+Alt | . （句点） | 选择下一个关键帧 |
