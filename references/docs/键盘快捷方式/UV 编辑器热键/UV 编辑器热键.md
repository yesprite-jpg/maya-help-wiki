# UV 编辑器热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| UV 操作 |  |  |
|---|---|---|
|  | 4 | 线框模式 |
|  | 5 | 着色模式。请参见[“UV 编辑器”(UV Editor)的“视图”(View)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9FE00F2-5B8B-4224-9E96-878E9FBAA466)。 |
|  | 6 | 显示纹理图像 |
|  | 7 | 切换 UV 扭曲显示。请参见[识别 UV 扭曲](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-637CCCB0-3513-4DFD-A8D5-EB1AB5CCEB9D)。 |
| Ctrl+Shift | A | 选择所有活动组件 |
| Ctrl+Shift | I | 反转当前选择 |
| Ctrl | < 或 > | 缩小或扩大选择 |
| Ctrl | C | 复制最后一个选定面 |
| Ctrl | V | 粘贴添加到剪贴板的最后一个面 |
| Ctrl | L | 排布当前选择。请参见[排布 UV 壳](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-21CFF911-9C21-4019-B676-766ACA3BC889)。 |
| Ctrl | U | 展开当前选择。请参见[展开 UV 网格](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6C2B784F-DE8A-4702-8FD5-6FBB8340C9C5)。 |
| Ctrl+Shift | X | 从当前选择创建 UV 壳 |
| Ctrl+Shift | 拖动 | 当变换工具处于活动状态时，这会将移动约束到边。 |
| Shift | X | 切割当前选定的边。请参见[分离和附加 UV 壳](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-578193DB-7EE7-4C60-A26F-9187DF8614A3)。 |
| Shift | S | 缝合当前选定的边。请参见[分离和附加 UV 壳](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-578193DB-7EE7-4C60-A26F-9187DF8614A3)。 |
|  | Q、W、E、R | 分别激活“选择”(Select)、“平移”(Translate)、“旋转”(Rotate)和“缩放”(Scale)工具 |
|  | A | 框显选定对象的所有 UV 壳。 |
|  | F | 框显所有选定组件/壳。 |
| Ctrl | 向上箭头、向下箭头 | 提高/降低棋盘格贴图的分辨率（当启用“棋盘格贴图”(Checker Map)时）。 |
