# 选择热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| 选择对象和组件 |  |  |
|---|---|---|
|  | F8 | 选择 > 对象/组件（在对象与组件编辑之间切换） |
|  | F9 | 选择 > 顶点 |
|  | F10 | 选择 > 边 |
|  | F11 | 选择 > 面 |
|  | F12 | 选择 > UV |
| Ctrl | i | 选择下一个中间对象 |
| Alt | F9 | 选择 > 顶点面 |
|  | < | 收缩多边形选择区域 |
|  | > | 增长多边形选择区域 |

| 行进式拾取* |  |  |
|---|---|---|
|  | 上箭头键 | 从当前项向上移动 |
|  | 下箭头键 | 从当前项向下移动 |
|  | 左箭头键 | 从当前项向左移动 |
|  | 右箭头键 | 从当前项向右移动 |
| *基于当前选择，可以使用箭头键向上移动当前层次（选定对象）或漫游对象的组件（选定组件，包括顶点、循环边、环形边）。 |  |  |
