# 渲染热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| 渲染 |  |  |
|---|---|---|
| Ctrl | 左箭头键 | 渲染视图下一个图像 |
| Ctrl | 右箭头键 | 渲染视图上一个图像 |
| Ctrl | P | 在模态窗口中打开“颜色选择器”(Color Chooser)。使用该热键（而非从样例）打开时，您可以将颜色保存到“颜色历史”(Color History)或使用“滴管”(Eyedropper)选择或检查屏幕上的颜色。此外，还可以加载、保存和编辑选项板。但是，您无法在场景对象上设置颜色属性。 |
