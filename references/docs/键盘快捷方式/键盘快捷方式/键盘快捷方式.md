# 键盘快捷方式

键盘快捷方式是指可用于运行命令、打开窗口和激活工具的特定按键的组合。在 Maya 帮助中，键盘快捷方式通常称为热键。

您可以创建自己的 Maya 热键。请参见[自定义 Maya 热键](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4713459B-7DEC-4744-904C-38F84E062CD5)。
