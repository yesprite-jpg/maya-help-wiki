# 绘制操作的热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| 绘制操作 |  |  |
|---|---|---|
| Alt | f | 整体应用当前值 |
| Alt | a | 开启或关闭显示线框 |
| Alt | c | 开启或关闭颜色反馈 |
| Alt | r | 开启或关闭反射 |
|  | u | 对 Artisan Paint 操作标记菜单使用鼠标左键 |
|  | b | 修改高端笔刷半径（按下并释放） |
| Shift | B | 修改低端笔刷半径（按下并释放） |
| Ctrl | b | 编辑 Paint Effects 模板笔刷设置 |
|  | m | 修改最大置换（雕刻曲面和雕刻多边形工具） |
|  | n | 修改绘制值 |
|  | / | 切换到拾取颜色模式（按下并释放） |
|  | o | 对多边形笔刷工具标记菜单使用鼠标左键 |
|  | o | 对多边形 UV 工具标记菜单使用鼠标中键 |
