# 选择源片段

执行下列操作之一：

- 在“Visor”中，选择源片段的图标。

- 在“大纲视图”(Outliner)中，关闭“显示 > 仅 DAG 对象”(Display > DAG Objects Only)，然后打开“显示 > 对象 > 片段”(Show > Objects > Clips)。

  - 选择源片段的名称。

- 在“Trax 编辑器”(Trax Editor)中，在要选择的源片段的一个实例上单击鼠标右键，然后从显示的菜单中选择“选择源片段”(Select Source Clip)。

- 在 Maya 依存关系图 (DG) 中，为要选择的源片段选择 clipnameSource 节点。请参见手册的“基础知识”部分中的[依存关系图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-51096BC4-32B7-4391-BE39-21641B374745)。
