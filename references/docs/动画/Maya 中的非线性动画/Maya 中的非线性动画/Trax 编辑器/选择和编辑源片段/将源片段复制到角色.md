# 将源片段复制到角色

在“Trax 编辑器”(Trax Editor)中创建源片段的实例

1. 执行下列操作之一：

- 在“大纲视图”(Outliner)中，选择一个源片段，然后按鼠标中键将该片段拖动到 Trax 中的角色。请参见[将大纲视图与 Trax 结合使用](../将“大纲视图”%28Outliner%29和“Visor”与%20Trax%20结合使用/将“大纲视图”%28Outliner%29与%20Trax%20结合使用.md)。

- 在“Visor”中，选择一个源片段，然后按鼠标中键将该片段拖动到 Trax 中的角色。请参见[将 Visor 与 Trax 结合使用](../将“大纲视图”%28Outliner%29和“Visor”与%20Trax%20结合使用/将“Visor”与%20Trax%20结合使用.md)。

- 在“Trax 编辑器”(Trax Editor)中，亮显某个角色，然后从 Trax 菜单栏中选择“库 > 插入片段”(Library > Insert Clip) > <源片段>。

此时，所选的源片段的实例会显示在轨迹视图区域中该源片段的角色下。

**注**

必须先映射角色，然后才能在角色之间复制和粘贴片段。请参见手册的“角色设置”
