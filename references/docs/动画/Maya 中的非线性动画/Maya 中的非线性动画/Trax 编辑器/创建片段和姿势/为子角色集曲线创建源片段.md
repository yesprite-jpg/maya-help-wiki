# 为子角色集曲线创建源片段

为单一子角色集创建仅包含动画曲线的源片段

1. 从“当前角色集”(Current Character Set)下拉列表中，选择要创建片段的子角色集。

2. 在 Trax 菜单栏中，选择“创建 > 动画片段”(Create > Animation Clip)。

  Trax 中的子角色下方将出现一个片段，其中包含选定的子角色的所有动画曲线。

源片段可以仅由一个子角色集使用。不能创建从源片段到多个子角色集的实例。

同时为多个子角色集设置动画

1. 将片段从一个子角色集复制并粘贴到另一个子角色集。

  **注**

  必须先映射角色，然后才能在角色之间复制并粘贴片段。请参见手册的“角色设置”部分的[在角色之间映射动画](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-AAF92442-CDC0-46C2-B55C-276D75D292DE)。
