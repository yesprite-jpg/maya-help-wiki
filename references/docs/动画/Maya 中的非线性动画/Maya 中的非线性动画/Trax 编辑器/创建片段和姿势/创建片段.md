# 创建片段

为已设置动画对象创建片段

1. 选择要将其动画曲线放在片段中的已设置动画（关键帧或运动捕捉）对象。

2. 在“Trax 编辑器”(Trax Editor)中，选择“创建 > 动画片段”(Create > Animation Clip) > ![图：在“Trax 编辑器”(Trax Editor)中，选择“创建 动画片段”(Create Animation Clip)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 825 字 ≥300，非承重" -->。

  此时将显示[“创建片段选项”(Create Clip Options)](../“Trax%20编辑器”%28Trax%20Editor%29菜单/Trax%20编辑器%28Trax%20Editor%29%20创建%28Create%29菜单/“创建片段”%28Create%20Clip%29选项.md)窗口。

3. 设定这些选项，然后单击“创建片段”(Create Clip)。

  将为选定的对象动画通道创建一个片段，Maya 会自动新建一个角色集将该片段纳入 Trax。

**注**

提示：

- 若要快速为动画对象创建片段，请在场景视图中选择该对象，然后单击 Trax 编辑器中的创建片段(Create Clip)按钮 ![图：若要快速为动画对象创建片段，请在场景视图中选择该对象，然后单击 Trax 编辑器中的创建片段(Create Clip)按…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C8761A18-9F90-4479-AD81-33A037FDAD1E.png) <!-- baize:img-hook downloaded=false reason="正文 825 字 ≥300，非承重" -->。

  ![图：若要快速为动画对象创建片段，请在场景视图中选择该对象，然后单击 Trax 编辑器中的创建片段(Create Clip)按…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D31D9A31-8C8A-4A7F-B00F-93106BBF1769.png) <!-- baize:img-hook downloaded=false reason="正文 825 字 ≥300，非承重" -->

- 按钮。

- 您可以为动画创建包含表达式或约束的片段。请参见[创建表达式片段或约束片段](创建表达式片段或约束片段.md)。

为角色创建片段

1. 从场景视图或从“当前角色集”(Current Character Set)下拉列表中选择要为其创建片段的角色集（请参见[设置当前角色集(Set the current character set)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-22D2DD39-D298-4007-97F1-8C67F42CF424)）。

2. 在“Trax 编辑器”(Trax Editor)中，选择“创建 > 动画片段”(Create > Animation Clip) > ![图：在“Trax 编辑器”(Trax Editor)中，选择“创建 动画片段”(Create Animation Clip)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 825 字 ≥300，非承重" -->。

  此时将显示[“创建片段选项”(Create Clip Options)](../“Trax%20编辑器”%28Trax%20Editor%29菜单/Trax%20编辑器%28Trax%20Editor%29%20创建%28Create%29菜单/“创建片段”%28Create%20Clip%29选项.md)窗口。

3. 设定选项。

4. 执行下列操作之一：

  - 在“创建片段选项”(Create Clip Options)窗口中，单击“创建片段”(Create Clip)。

    Maya 将为选定角色的动画通道创建一个片段，并将片段放在轨迹视图区域中相应角色下。

  - 将片段从“Visor”或“大纲视图”(Outliner)拖动到轨迹视图区域中的该角色。请参见[将 Visor 与 Trax 结合使用](../将“大纲视图”%28Outliner%29和“Visor”与%20Trax%20结合使用/将“Visor”与%20Trax%20结合使用.md)和[将大纲视图与 Trax 结合使用](../将“大纲视图”%28Outliner%29和“Visor”与%20Trax%20结合使用/将“大纲视图”%28Outliner%29与%20Trax%20结合使用.md)。

    此时将在轨迹视图区域中相应角色下显示选定片段的一个实例。

  - 在 Trax 菜单中，选择“库 > 插入片段”(Library > Insert Clip) > <源片段>。

    此时将在轨迹视图区域中相应角色下显示选定的源片段的一个实例。
