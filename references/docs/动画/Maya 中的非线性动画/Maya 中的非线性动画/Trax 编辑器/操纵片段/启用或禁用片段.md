# 启用或禁用片段

可以禁用片段以在 Trax 中回放其角色动画期间使该片段停止播放。如果以后决定要重新播放该片段，则可以启用该片段。

**注**

有用的动画技术是创建多个片段来对运动进行组合，然后通过禁用或启用片段来控制在某种情况下应用哪些片段，以帮助分析运动。

禁用或启用片段

1. 在“Trax 编辑器”(Trax Editor)中，选择要禁用或启用的片段。

2. 执行下列操作之一：

  - 在该片段上单击鼠标右键，然后从显示的菜单中选择“启用片段”(Enable Clip)。请参见[启用/禁用](../“Trax%20编辑器”%28Trax%20Editor%29菜单/Trax%20编辑器%28Trax%20Editor%29%20修改%28Modify%29菜单.md#GUID-148B51BC-8792-4950-93F7-2E9404614FE7__GUID-4A959B25-925F-49A1-A428-935AC9DB337D)。

  - 在 Trax 菜单栏上，选择“修改 > 启用/禁用”(Modify > Enable/Disable)。
