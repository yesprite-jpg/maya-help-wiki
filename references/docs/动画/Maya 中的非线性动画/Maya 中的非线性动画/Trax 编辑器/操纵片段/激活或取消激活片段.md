# 激活或取消激活片段

可以激活片段以从时间滑块编辑其中包含的关键帧。另外，当片段处于活动状态时，为活动片段中的通道设定的所有关键帧将被自动放置在该片段中。请参见[活动/非活动片段](../Trax%20中的非线性动画组件/Trax%20中的片段/片段状态.md#GUID-968254A9-1044-4887-8197-63A41D0DE05A__WS17956D7ADBC6E736475032DC117AE308AAE-7F6F)和[在片段中设置关键帧](在片段中设置关键帧.md)。

如果片段处于活动状态（启用“激活关键帧”(Activate Keys)），Maya 会忽略片段设置，如“权重”(Weight)、“偏移”(Offset)等。

如果在片段上设定的新关键帧超出活动片段持续时间的结束位置，会在片段处于激活状态时播放关键帧，但不会包含在取消激活的片段中，除非在“通道盒”(Channel Box)中调整其“源输入/源输出”(Source In/Source Out)通道值或修改源片段的持续时间。有关在“时间滑块”(Time Slider)中编辑片段关键帧的信息，请参见[编辑片段的动画曲线](编辑片段的动画曲线.md)。

激活或取消激活片段

1. 在“Trax 编辑器”(Trax Editor)中，选择要激活或取消激活的片段。

2. 执行下列操作之一：

  - 在片段上单击鼠标右键，然后从显示的菜单中选择“激活关键帧”(Activate Keys)。

  - 在 Trax 菜单栏中，选择“修改 > 激活/取消激活关键帧”(Modify > Activate/Deactivate Keys)。
