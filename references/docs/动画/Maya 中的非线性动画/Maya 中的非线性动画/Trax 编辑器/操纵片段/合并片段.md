# 合并片段

可以将两个或更多片段合并为一个片段。可以按顺序将要合并的片段置于一个轨迹中，也可以置于不同的轨迹中。

合并片段的优点如下：

- 需要管理的片段较少

- 如果合并一对融合片段，则生成的源片段包含融合动画的关键帧。可以激活合并的片段并在“曲线图编辑器”(Graph Editor)中编辑其动画。

- 可以将单个片段合并为一个新的片段。这有助于根据相对片段创建绝对片段，或分割循环片段。请参见[分割片段](分割片段.md)。

  **注**

  如果不希望合并片段，您仍可通过分组来同时管理多个片段。请参见[将片段分组和解组](将片段分组和解组.md)。

合并片段

1. 在“Trax 编辑器”(Trax Editor)中，选择要合并的片段。

  可以从相同或不同的轨迹中选择多个片段。

2. 选择“编辑 > 合并”(Edit > Merge) > ![图：选择“编辑 合并”(Edit Merge) 。 将出现“合并片段选项”(Merge Clip Options)窗口。请参…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 456 字 ≥300，非承重" -->。

  将出现“合并片段选项”(Merge Clip Options)窗口。请参见 Trax 编辑器“编辑”(Edit)菜单中的[合并(Merge)](../“Trax%20编辑器”%28Trax%20Editor%29菜单/“Trax%20编辑器”%28Trax%20Editor%29%20“编辑”%28Edit%29菜单.md#GUID-C6D15F23-7D7A-4E00-AB3D-6B12110651A5__GUID-C3819DD0-3229-4C98-ACCB-8C847FBFB13F)。

3. 设置选项并单击“合并片段”(Merge Clip)按钮。

  此时选定片段将合并为一个片段。

  **注**

  片段合并之后，会对动画片段之间的任何间距进行插值或融合动画片段之间的任何重叠。
