# 偏移片段通道

可以在动画片段中偏移通道来更改 Maya 解释该片段中的通道值的方式。片段通道可以具有绝对偏移或 相对偏移。可以在片段上单击鼠标右键后使用“通道偏移”(Channel Offsets)控件或在[“创建片段选项”(Create Clip Options)](../“Trax%20编辑器”%28Trax%20Editor%29菜单/Trax%20编辑器%28Trax%20Editor%29%20创建%28Create%29菜单/“创建片段”%28Create%20Clip%29选项.md)中设置片段的通道偏移。

**注**

如果两个片段在同一角色集的一对轨迹中重叠，则无论使用“绝对”(Absolute)还是“相对”(Relative)偏移，Maya 都将添加任何冗余属性的值。除非您融合片段，否则该复合效果通常是不需要的。有关融合动画片段的信息，请参见[创建和编辑融合](创建和编辑融合.md)。

**注**

“绝对”(Absolute)

是新片段和导入片段的默认

“偏移”(Offset)

设置。

若要查看或更改动画片段的通道偏移行为，请执行下列操作之一：

- 在“Trax 编辑器”(Trax Editor)中的片段上单击鼠标右键，以查看显示的弹出菜单中的偏移选项。

  如果片段中的所有通道当前都已设置为相对偏移，则“相对片段”(Relative Clip)选项在弹出菜单中处于启用状态。如果“相对片段”(Relative Clip)处于禁用状态，则所有片段通道均设置为绝对偏移。

  如果片段通道当前已设置为混合使用绝对和相对偏移，则将显示“将片段设置为相对”(Make Clip Relative)和“将片段设置为绝对”(Make Clip Absolute)选项。选择这两个选项中的任一选项均可立即设置所有通道的偏移行为。

- 在“Trax 编辑器”(Trax Editor)中的片段上单击鼠标右键，然后选择“编辑每通道偏移”(Edit Per-Channel Offsets)。在“属性编辑器”(Attribute Editor)显示 [animClip](../../../../动画引用/动画引用/动画节点/animClip.md) 选项卡时展开[“通道偏移”(Channel Offsets)](../../../../动画引用/动画引用/动画节点/animClip.md#WS17956D7ADBC6E736-2696A29F117AE307F06-7FF6)标题，然后将每个通道设置为“绝对”(Absolute)或“相对”(Relative)。

  （也可以单击“全部绝对”(All Absolute)/“全部相对”(All Relative)以同时设置所有通道。若要仅自动将顶级通道（旋转通道除外）设置为“相对”(Relative)，并且将所有其他通道设置为“绝对”(Absolute)，请单击“还原默认值”(Restore Defaults)。）

将通道偏移设置从一个片段复制到另一个片段

1. 选择具有您要复制的通道偏移设置的片段。该片段为源片段。

2. 按住 Shift 键的同时单击要对其应用源片段的通道偏移设置的片段。该片段为目标片段。

  **注**

  - 源和目标片段必须属于同一角色。

  - 源和目标片段必须具有公用通道。

  - 不能将片段通道偏移设置从一个源片段复制到多个目标片段。

3. 在“Trax”菜单栏中，选择“编辑 > 复制通道偏移”(Edit > Copy Channel Offsets)。

  现在目标片段和源片段具有相同的通道偏移设置。
