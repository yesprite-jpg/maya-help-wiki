# 保持片段

从“Trax 编辑器”(Trax Editor)中创建片段的保持

1. 按住 Shift 键的同时拖动片段聚光区的上角，以在片段之后创建保持。

为片段创建保持时，将出现“保持”鼠标指针 ![图：为片段创建保持时，将出现“保持”鼠标指针 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-416066D5-1AA8-447C-8F07-559BFCBC3640.png) <!-- baize:img-hook downloaded=false reason="正文 359 字 ≥300，非承重" -->。

保持是片段的一部分或延伸，它将为指定的时间周期保持最后一个姿势。“保持”由字母 H 表示，并以蓝色显示，颜色略浅于片段的其他部分。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-992D366E-E045-4B42-89FA-5D8116F531ED.png) <!-- baize:img-hook downloaded=false reason="正文 359 字 ≥300，非承重" -->

从“通道盒”(Channel Box)中创建片段的保持

1. 在“Trax 编辑器”(Trax Editor)中，选择要缩放的片段。

2. 在 Maya 主菜单中，选择“显示 > UI 元素 > 通道盒/层编辑器”(Display > UI Elements > Channel Box/Layer Editor)。

  将出现“通道盒”(Channel Box)，其中显示选定片段的通道。

3. 在“通道盒”(Channel Box)中，设定“保持”值，以便在片段之后创建保持。

  请参见[保持](../../../../动画引用/动画引用/动画节点/animClip.md#WS1A9193826455F5FF-6D855556117E9F816D22745)。
