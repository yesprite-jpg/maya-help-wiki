# 轨迹控制区域

通过“Trax 编辑器”(Trax Editor)中的轨迹控制区域，可以锁定、单放或禁用轨迹中的所有动画片段。

#### 锁定 ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-412D8C3A-40CB-40C8-A84E-6FA83EC179ED.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

冻结当前动画轨迹。锁定轨迹后，将无法编辑其片段，但播放期间会显示该轨迹的动画。

#### 单放 ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-FB03DC57-3AC8-44D5-A778-4546FCAD3B85.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

隔离当前轨迹上的片段，使其成为播放期间针对角色播放的唯一动画序列。要隔离并查看角色的特定动画序列时，可使用单放功能。一次可以单放一个或多个轨迹。

#### 禁用 ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-064275A6-62FA-4C98-9DCB-33438ADA85B4.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

禁用当前轨迹上的所有片段。禁用可抑制或隐藏轨迹上的动画，而无需将其从“Trax 编辑器”(Trax Editor)中移除。要在播放期间抑制角色的特定动画序列时，可使用禁用功能。请参见[禁用动画](../../../动画基础知识/动画基础知识/禁用动画.md)。

#### 向上移动![图：向上移动](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-8802D925-4942-48B3-8606-18CFF5F7BC9E.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

单击此图标可在视图区域中上移选定轨迹。

#### 向下移动![图：向下移动](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-93562518-68EF-441B-BC10-E32DAF14E868.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

单击此图标可在视图区域中下移选定轨迹。
