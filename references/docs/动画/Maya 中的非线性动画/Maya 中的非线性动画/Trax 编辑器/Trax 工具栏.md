# Trax 工具栏

通过 Trax 工具栏可快速访问 Trax 中最常用的菜单栏选项。

## 创建片段(Create Clip)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C8761A18-9F90-4479-AD81-33A037FDAD1E.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

使用当前角色的关键帧动画创建动画片段。

## 创建融合(Create Blend)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-1F775E34-9CB7-4771-94EA-23AAD3DA084E.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

在两个选定的动画片段之间创建融合。请参见[融合](Trax%20中的非线性动画组件/Trax%20中的片段/片段状态.md#GUID-968254A9-1044-4887-8197-63A41D0DE05A__WS17956D7ADBC6E736475032DC117AE308AAE-7F6E)。

## 获取片段(Get Clips)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-DB059130-6C3C-4B62-9D2A-B5B846C4BB07.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

启动“Visor”。有关详细信息，请参见手册的“基础知识”部分中的 [Visor](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0065E2FA-EC3E-4BBD-A896-043621AD35D2)。

## 框显全部(Frame All)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-AC8F3337-DCAE-42E6-89BD-B5CC5E392A61.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

使 Trax 中的所有片段在轨迹视图区域中可见。也可以在“曲线图编辑器”(Graph Editor)和“摄影表”(Dope Sheet)工具栏中找到该按钮。

## 框显播放范围(Frame Playback Range)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-CA6CD768-52B3-4278-8DD3-3F07760D450D.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

框显选定时间轴范围内的所有轨迹视图区域内容。

## 使视图围绕当前时间居中(Center the view about the current time)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-08D37895-563C-4696-A7CD-8EE29CA70A12.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

## 成组(Group)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-FCA518FB-B57D-46D0-9F3B-90D813D0BE85.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

*仅用于动画片段。*

在当前角色下创建一个组，并在该组下的轨迹中放置选定动画片段。

## 解组(Ungroup)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-4398F7A9-59E1-458E-B907-11C4359B0235.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

*仅用于动画片段。*

从角色中移除选定组，并直接将该组的轨迹放置到其角色或父对象组下。

## 修剪当前时间之前的片段(Trim clip before current time)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C17D95BC-2F7B-4F3B-9D07-FCCF199BDB0D.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

移除在 Trax 当前时间指示器位置后的选定动画或几何缓存片段的分段。

## 在片段中设置关键帧(Key into clip)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-3CFFAFF3-C758-4E15-B008-B51AE56AE76A.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

## 打开曲线图编辑器(Open the Graph Editor)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-F7A48249-70F8-4296-956E-637BBB16AC50.png) <!-- baize:img-hook downloaded=false reason="正文 967 字 ≥300，非承重" -->

在“曲线图编辑器”(Graph Editor)中打开当前对象的动画片段和角色或者几何缓存片段和对象。

在“摄影表”(Dope Sheet)中打开当前对象的动画片段和角色或者几何缓存片段和对象。
