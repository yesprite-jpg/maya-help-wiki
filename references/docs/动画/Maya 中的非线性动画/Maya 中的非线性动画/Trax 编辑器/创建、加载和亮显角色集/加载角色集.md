# 加载角色集

将角色加载到“Trax 编辑器”(Trax Editor)中

1. 在场景视图中或从“当前角色集”(Current Character Set)下拉列表中选择角色。

2. 执行下列操作之一：

  - 在 Trax 工具栏上，单击“加载选定角色”(Load Selected Characters) ![图：在 Trax 工具栏上，单击“加载选定角色”(Load Selected Characters) 按钮。](../../../../../../assets/Maya-Animation/GUID-1914FB5B-A12C-44E4-AC90-D1C489767927.png) <!-- baize:img-hook downloaded=true reason="正文 277 字 <300 且带图" -->按钮。

  - 在 Trax 主菜单栏上，选择“列表 > 加载选定角色”(List > Load Selected Characters)。

  此时您的角色将显示在轨迹视图区域中。

  **注**

  当

  “列表”(List)

  >

  “自动加载选定对象”(Auto Load Selected Objects)

  处于启用状态时，所有选定角色将自动加载到 Trax 中。
