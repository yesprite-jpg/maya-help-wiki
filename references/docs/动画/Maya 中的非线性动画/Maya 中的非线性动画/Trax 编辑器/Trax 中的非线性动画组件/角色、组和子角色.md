# 角色、组和子角色

**注**

“Trax 编辑器”(Trax Editor)中角色、组和子角色的名称可以通过双击其名称并输入新名称进行更改。

## Trax 中的角色

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-2DF44F4F-ABEA-4FA0-904F-D31C5CDDEC06.png) <!-- baize:img-hook downloaded=false reason="正文 786 字 ≥300，非承重" -->

角色集或角色是已设置动画对象、对象部分或属性的集合。如果为尚不是角色集一部分的已设置动画对象创建片段，“Trax 编辑器”(Trax Editor)将自动为该片段创建角色。在“Trax 编辑器”(Trax Editor)中，角色显示为轨迹层次的第一级别。这意味着角色是角色所有轨迹、组和子角色的父对象或最高级别。请参见[轨迹层次](../轨迹视图区域.md#GUID-42EF9259-F328-421D-823C-2571717EB564__WS17956D7ADBC6E736475032DC117AE308AAE-7F80)。

请参见：

- [角色集(Character Sets)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-39A5A681-1BB8-41BA-8139-95E16111B297)

- [为角色集设定动画](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-52E4F44F-C6A9-468A-9B6A-76B128B7081F)

- [角色(character)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-996AE123-BFF4-42B7-B5C8-E3F2DDFC3D12)

**注**

删除角色时，也将删除角色的所有常规片段。但是，已删除角色的所有源片段都将保留在其场景中。

## Trax 中的组

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-209235B1-285D-4E9F-B41E-AF194E9ACBBA.png) <!-- baize:img-hook downloaded=false reason="正文 786 字 ≥300，非承重" -->

组是单个角色的任何片段集合。可以使用组对角色动画的特定序列进行分隔和隔离。请参见[将片段分组和解组](../操纵片段/将片段分组和解组.md)。角色或子角色可以有多个组，但组之中不能有组。

## Trax 中的子角色

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-8A6A2387-8E98-4B4F-8612-9037D36DFCAC.png) <!-- baize:img-hook downloaded=false reason="正文 786 字 ≥300，非承重" -->

子角色集或子角色是相关角色集属性的束。可以使用子角色同时对属性组设置关键帧和操纵。请参见[“关键帧”(Key)菜单](../../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单.md)中的“关键帧 > 创建子角色集”(Key > Create Subcharacter Set)。

子角色与角色组在相同的轨迹层次级别上。请参见[子角色](../轨迹视图区域.md#GUID-42EF9259-F328-421D-823C-2571717EB564__WS17956D7ADBC6E736475032DC117AE308AAE-7F7E)。在“Trax 编辑器”(Trax Editor)中，子角色始终显示在角色组下方。角色可以有多个子角色。

在“Trax 编辑器”(Trax Editor)中处理子角色时，请注意以下事项：

- 如果将包含子角色的角色加载到 Trax 中，该角色的所有子角色都将自动显示在轨迹视图区域中。

- 如果为拥有现有片段的角色创建子角色，子角色将继承现有片段，这样就不会丢失动画。

- 如果在创建片段时启用“在片段中包括子角色”(Include Subcharacters in Clip)，Maya 将创建包含该角色所有动画曲线及其所有子角色的源片段。请参见[在片段中包括子角色](../“Trax%20编辑器”%28Trax%20Editor%29菜单/Trax%20编辑器%28Trax%20Editor%29%20创建%28Create%29菜单/“创建片段”%28Create%20Clip%29选项.md#GUID-E4D22E09-7F0A-4A58-BCC6-63B99E6D6FE0__WS73099CC142F48755-3D114B7511841AEFA9F1A8B)。
