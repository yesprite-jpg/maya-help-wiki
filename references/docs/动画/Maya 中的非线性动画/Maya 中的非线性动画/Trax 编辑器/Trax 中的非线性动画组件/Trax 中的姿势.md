# Trax 中的姿势

您可以存储动画过程中任何时候角色当前位置的快照。该快照称为姿势。请参见[创建姿势](../创建片段和姿势/创建姿势.md)。姿势本质上是仅捕捉角色动画一个帧的片段。

姿势可以从 Trax 中的“Visor”、“大纲视图”(Outliner)或“库”(Library)菜单访问。请参见[什么是 Visor、大纲视图和片段库？](../../../Maya%20中的非线性动画.md#GUID-B90726CA-6C86-4E9B-80F3-1F65745C3B3F__WS17956D7ADBC6E736B6BA507117AE308213-7FFB). 在“Trax 编辑器”(Trax Editor)中，您可以如常规动画片段一般缩放、循环和保持姿势。请参见[您可以对动画片段执行什么操作？](Trax%20中的片段.md#GUID-D462A79C-A766-43DD-BB43-5BCDAEC5D8BD__WS17956D7ADBC6E736B6BA507117AE308213-7FF2). 但是，片段属性（“帧输入”(Frame In)、“帧输出”(Frame Out)等)不在 Trax 中的姿势上显示，因为默认情况下姿势只是长度中的一个帧。若要编辑姿势属性，必须使用“属性编辑器”(Attribute Editor)。

## 您可以对姿势执行什么操作？

姿势非常适用于以下情况：

- 姿势可以用于在设置动画时比较角色的不同位置。例如，要对角色设置在圆内行走的动画，可以显示第一步时角色的姿势，这样就能够了解角色必须在何处返回才能完成圆形路线。

- 可以为“融合变形”(Blend Shape)变形器创建姿势来创建组合融合变形滑块组合。例如，为角色的面部肌肉定义融合变形滑块，然后可以创建发出多种音素的面部姿势。

- 首席动画师可以为冗长的角色动画序列创建各种关键帧姿势，然后让团队中的其他动画师创造性地自由设置姿势之间角色的运动。
