# 将音频与序列或快照相关联

在“摄影机序列器”(Camera Sequencer)中，可以导入整个序列的音频文件，或导入各个音频文件以与特定的摄影机快照相关联。

导入序列的音频文件

1. 在“摄影机序列器”(Camera Sequencer)中将时间轴光标移动到希望音频片段开始的位置。

2. 选择“文件 > 导入序列器音频”(File > Import Sequencer Audio)。

3. 在显示的“导入”(Import)窗口中，通过导航来选择要导入的音频文件，然后单击“打开”(Open)。

  会在“摄影机序列器”(Camera Sequencer)的“声音轨迹”(Soundtrack)区域中加载该音频。

  **注**

  如果没有立即看到音频片段，请确保

  “声音轨迹”(Soundtrack)

  已展开（未收拢）。

  可以向左或向右拖动音频片段，以更改它相对于序列开始播放的时间。若要更改音频片段相对于序列的持续时间，请参见[调整序列中音频的计时](调整序列中音频的计时.md)。

将音频文件与快照相关联

1. 选择快照。

2. 从“摄影机序列器”(Camera Sequencer)菜单栏中，选择“文件 > 导入镜头音频”(File > Import Shot Audio)。

3. 通过导航来选择某个音频文件，然后单击“打开”(Open)。

  会在“摄影机序列器”(Camera Sequencer)的“声音轨迹”(Soundtrack)区域中加载该音频，并将该音频与选定快照相关联。

  音频片段的持续时间和位置是由关联的快照控制的，因此无法通过向左或向右拖动来调整音频片段的位置。例如，如果快照在第 1 帧处开始并在第 350 帧处结束，那么音频片段也会在第 1 帧处开始，并在第 350 帧处结束。

  若要调整音频相对于快照的计时，请参见[调整序列中音频的计时](调整序列中音频的计时.md)。

**注**

提示：

如果在

“摄影机序列器”(Camera Sequencer)

中播放音频时遇到困难，请确保已设定下列选项：

- 在“摄影机序列器”(Camera Sequencer)中，在“视图”(View)菜单中启用“启用声音”(Enable Sound)。

- 在“时间滑块”(Time Slider)中，设置“声音 > 使用 Trax 声音”(Sounds > Use Trax Sounds)和“播放速度 > 实时”(Playback Speed > Real-time)。（在“时间滑块”(Time Slider)上单击鼠标右键，然后在显示的菜单中设置这些选项。）
