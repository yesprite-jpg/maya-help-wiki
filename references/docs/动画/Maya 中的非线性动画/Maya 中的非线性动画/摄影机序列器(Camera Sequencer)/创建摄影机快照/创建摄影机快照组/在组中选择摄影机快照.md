# 在组中选择摄影机快照

如果组已收拢，使用“选择快照”(Select Shot)菜单项可以将快照添加到选择列表。该菜单项还可以帮助确定已选定了收拢组的哪些快照。在已收拢的组中选择快照非常有用，例如要从组中移除快照时即可使用。

在组中选择快照

1. 执行下列操作之一：

  - 选择一个组，然后选择“组 > 选择镜头”(Group > Select Shot)。

  - 在组节点上单击鼠标右键，然后从显示的菜单中选择“选择镜头”(Select Shot)。

  此时将显示包含组中所有快照名称的下拉菜单。每个条目都有一个切换，如果条目相应的快照当前处于选择列表中，则切换处于选中状态。通过选择快照，可从选择列表中添加和移除该快照。

  **注**

  组内的多个快照可以同时处于选中状态。

  **注**

  如果已选定某组，则该组的活动快照也将处于选中状态。
