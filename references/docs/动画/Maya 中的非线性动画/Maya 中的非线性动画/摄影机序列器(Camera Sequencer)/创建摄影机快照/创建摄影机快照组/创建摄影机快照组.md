# 创建摄影机快照组

对快照分组

1. 选择一个或多个快照节点。

2. 在“摄影机序列器”(Camera Sequencer)中，选择“分组 > 创建”(Group > Create)。

  将创建一个包含选定快照的新组。选定快照中按字母顺序排列的第一个快照成为该组的活动快照。

  将在活动快照的位置以紫色绘制一个新组。“摄影机序列器”(Camera Sequencer)显示中不会显示已成为该组一部分的任何其他快照。

在组中设定活动快照

1. 执行下列操作之一：

  - 选择一个组，然后从菜单栏中选择“分组 > 设置活动镜头”(Group > Set Active Shot)。

  - 在组节点上单击鼠标右键，然后从显示的菜单中选择“设置活动镜头”(Set Active Shot)。

    将显示一个菜单，其中列出了该组中所有可用的快照。

2. 选择要使其成为活动快照的快照。

  **注**

  该组的大小会调整为新的活动快照的长度。
