# 通过时间编辑器重影预览动画

“时间编辑器”(Time Editor)重影是动画对象的简化表示形式，可用于在 crossfading、过渡和线性插值之前预览每个片段的影响。使用重影指导融合运动捕捉动画文件或通过匹配姿势预先可视化姿势匹配（请参见[通过重新定位重新确定角色的方向](通过重新定位重新确定角色的方向.md)）。

重影表示片段的内容，且根据您所选的动画源而定。例如，如果动画源是控制装备，则重影是对骨架的描述。如果动画源是立方体等对象，则重影将显示为立方体。可以使用[时间编辑器片段(Clip)上下文菜单](../使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中的“设置/编辑用户定义的重影”(Set/Edit User Defined Ghosts)选项，指定将动画的哪个元素描述为片段重影。

您可以在时间编辑器中使用两种类型的重影：

- 轨迹重影，其中显示轨迹上的所有重影（请参见[在时间编辑器中查看轨迹重影](通过时间编辑器重影预览动画/在时间编辑器中查看轨迹重影.md)）

- 片段重影，其中显示选定片段的重影（请参见[在时间编辑器中查看片段重影](通过时间编辑器重影预览动画/在时间编辑器中查看片段重影.md)）

区分片段重影与轨迹重影非常重要，尤其是在拥挤的场景中。可能会需要通过在几个对象上设置重影来整理视图。

**注**

如果只有一个片段或组片段定义对象的位置，则重影和对象将显示在同一位置。重影有可能不可见。

可以使用重影可视化 crossfade、过渡、权重更改和以及不同轨迹上的片段之间的线性插值。

**注**

时间编辑器的默认重影是动画的骨架或根对象。如果要使用除此之外的重影预先可视化动画，请参见
