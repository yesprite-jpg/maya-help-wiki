# 创建自定义片段重影

时间编辑器对片段使用默认重影对象（例如，装备的骨架线条图），但有时您可能需要重影描述其他内容。例如，除了骨架外，复杂装备还可以具有多个层次的控制器、辅助对象和变形器。如果默认设置不满足您的需求，请定义自己的片段重影。

**注**

应避免将

“重影编辑器”(Ghosting Editor)

与

时间编辑器(Time Editor)

和

动画层重影

组合使用，因为目前这会出现不可预测的结果。

定义自定义片段重影

1. 在要定义重影的片段上单击鼠标右键，然后从[时间编辑器片段(Clip)上下文菜单](../../使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“重影 > 设置/编辑用户定义的重影”(Ghost > Set/Edit User defined Ghosts)。此时将显示“用户定义的重影”(User Defined Ghost)窗口。

2. 在“大纲视图”(Outliner)或视口中，选择要用于替代时间编辑器的默认重影的对象（例如，动画控制器）。

3. 在“用户定义的重影”(User Defined Ghost)窗口中，单击“添加”(Add)，可将这些对象添加到“要用于重影的对象”(Objects to be used for Ghosting)列表中。如果希望这些对象是选定对象的子对象，请单击“带子对象添加”(Add with children)。例如，如果选择腕部控制器，是否也要包括附加的手指？

4. 单击“应用”(Apply)。

## 更改时间编辑器片段重影的颜色

重影的颜色与对应的片段相同。若要自定义片段重影颜色，请在[属性编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中片段信息的“层”(Layer)区域中选择新颜色。
