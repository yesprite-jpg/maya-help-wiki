# 通过重新定位重新确定角色的方向

有时，无论是为了适应场景中的其他对象还是与姿势更好地拟合，您都需要在场景中重新定位角色动画。“重新定位”(Relocate)可用于在 XYZ 空间中移动动画角色。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-698C3306-8F91-493C-AA2C-B7336FE8CAB5.gif) <!-- baize:img-hook downloaded=false reason="正文 635 字 ≥300，非承重" -->

1. 在时间编辑器中选择动画片段。

2. 从[时间编辑器菜单栏](../时间编辑器界面概述/时间编辑器菜单栏.md)中选择“重新定位 > 创建重定位器”(Relocate > Create Relocator)。或者，在[时间编辑器工具栏](../时间编辑器界面概述/时间编辑器工具栏.md)中单击“重新定位”(Relocate)按钮 ![图：从时间编辑器菜单栏中选择“重新定位 创建重定位器”(Relocate Create Relocator)。或者，在时间编…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-BB8127EC-068F-47C8-9004-47D80128C8B8.png) <!-- baize:img-hook downloaded=false reason="正文 635 字 ≥300，非承重" -->。将在角色的基础关节附近创建一个重定位器。“重新定位”(Relocate)图标 ![图：从时间编辑器菜单栏中选择“重新定位 创建重定位器”(Relocate Create Relocator)。或者，在时间编…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-8C13639F-0BBD-45DD-9B28-8CDEA39703B8.png) <!-- baize:img-hook downloaded=false reason="正文 635 字 ≥300，非承重" --> 将显示在轨迹上。

  **注**

  如果动画片段由多个根驱动，请改为选择

  “重新定位 > 创建重定位器”(Relocate > Create Relocator) > ![图：从时间编辑器菜单栏中选择“重新定位 创建重定位器”(Relocate Create Relocator)。或者，在时间编…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 635 字 ≥300，非承重" -->

  以打开

  Relocator Options(重定位器选项)

  。在其中，您可以从列表中（包括场景中的所有根对象）创建一个重定位器。

  除非选中（这是下一步），否则“重新定位”(Relocate)不可见。

3. 在动画片段仍处于选定状态时，从[时间编辑器菜单栏](../时间编辑器界面概述/时间编辑器菜单栏.md)中选择“重新定位 > 选择重定位器”(Relocate > Select Relocator)。

4. 使用平移和旋转工具，或者在通道盒中修改 X 或 Y 值，将角色移动到不同的位置。

  ![图：使用平移和旋转工具，或者在通道盒中修改 X 或 Y 值，将角色移动到不同的位置。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C5B7E7BF-D504-41D9-957C-0AF7C3ADDF47.gif) <!-- baize:img-hook downloaded=false reason="正文 635 字 ≥300，非承重" -->

**注**

如果多个根驱动动画片段（例如，如果装备没有明确层次，但具有用于整个角色的控制器），则可以选择片段，然后随时单击

“编辑重定位器”(Edit Relocator)

以在

重定位器选项

中将其他根设为重定位器。

使用重定位器可简化匹配姿势过程，因为您可对齐姿势元素以便更好地匹配。请参见[使用时间编辑器重定位器匹配姿势](../使用时间编辑器重定位器匹配姿势.md)。
