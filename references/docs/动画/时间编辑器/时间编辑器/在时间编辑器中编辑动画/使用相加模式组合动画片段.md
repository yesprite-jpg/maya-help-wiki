# 使用相加模式组合动画片段

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 301 字 ≥300，非承重" -->

使用相加融合模式，可以将[时间编辑器(Time Editor)](../../时间编辑器.md)动画片段组合在一起以创建新的动画片段。

例如，可以融合循环行走的动画片段和挥动手臂的人的片段，以便可以创建在挥动手臂的同时行走的角色的新片段。

另请参见[在时间编辑器中编辑动画](../在时间编辑器中编辑动画.md)。

使用相加 融合模式合并动画片段

1. 将动画片段导入到动画轨迹中，例如，循环行走。请参见[将内容添加和导入到时间编辑器](../将内容添加和导入到时间编辑器.md)。

2. 将第二个片段导入到第二个动画轨迹中。例如，手臂挥动动画源。

3. 在第二个片段（手臂挥动片段）上单击鼠标右键，然后从[时间编辑器“片段”(Clip)上下文菜单](../使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“融合模式 > **相加”(Blending Mode > Additive)**。片段名称旁边将出现一个加号 (+)。

4. 播放动画。
