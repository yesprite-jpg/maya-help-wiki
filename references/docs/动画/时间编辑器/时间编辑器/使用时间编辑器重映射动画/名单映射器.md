# 名单映射器

打开名单映射器

- 在[时间编辑器动画片段](../使用时间编辑器片段.md#GUID-63B2245A-5D4E-4844-A2F0-A2DFCA39F10C__SECTION_1C440FF4EAAF4918888C7792E1417FCA)上单击鼠标右键，选择“从名称空间重映射和创建片段”(Remap and Create Clip from namespace)，然后选择一个列出的动画。

**注**

如果未列出用于重新映射的动画或者

“从名称空间重映射和创建片段”(Remap and Create Clip from namespace)

选项处于禁用状态，这是因为场景中不存在用于重新映射的动画。

使用“名单映射器”(Roster Mapper)，可以将动画从一个角色（源）映射到另一个（目标）角色。使用“名单映射器”(Roster Mapper)，可在[动画源](../使用时间编辑器片段/时间编辑器动画源.md)和片段中目标角色的节点或属性之间创建关系，使您能够在“时间编辑器”(Time Editor)中已映射的角色之间导入和导出或复制和粘贴动画片段。您可以在下图中的“名单映射器”(Roster Mapper)顶部看到“从”(From)和“至”(To)字段：

当您需要映射动画类似的角色时，“名单映射器”(Roster Mapper)效果最佳，因为它可识别类似的层次。层次之间的任何差异均会显示在“未映射”(Unmapped)列表中。

#### 已映射(Mapped)列表

显示在动画源和目标角色之间定义的所有属性关系。通过在源（左侧）和目标（右侧）“未映射”(Unmapped)列表中单击节点或属性、以此将它们链接在一起之后，链接对将出现在“已映射”(Mapped)列表中。

#### 未映射(Unmapped)列表

左侧“未映射”(Unmapped)列将列出源角色骨架中的所有节点或属性，右侧“未映射”(Unmapped)列则将列出目标角色骨架中的所有节点或属性。若要链接节点或属性对，请参见[将一个角色映射到另一个角色](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-47CB74C4-4031-4A99-BB06-65D0D148FFC4)。

#### 重映射后调整容器长度(Adjust Container length after remapping)

将重映射后的片段修剪到动画的长度。
