# 通过动画源重映射动画

通过将[动画源](../使用时间编辑器片段/时间编辑器动画源.md)从大纲视图拖动到片段上，可以重映射动画。

通过动画源重映射动画

1. 若要使新的[动画源](../使用时间编辑器片段/时间编辑器动画源.md)起作用，请确保场景中存在骨架或装备。

2. 在[时间编辑器菜单栏](../时间编辑器界面概述/时间编辑器菜单栏.md)中，选择“源 > 创建片段”(Source > Create Clip)。此时将显示场景中的动画源列表。

  **注**

  如果场景不包含任何动画源，则您必须添加一些动画源。请参见

  时间编辑器动画源

  主题中的

  创建动画源

  。

3. 选择动画源。也可以在大纲视图中展开 **timeEditor** 来查看场景中的所有动画源。

4. 使用鼠标中键将要共享的动画源拖动到已在驱动角色的片段上。

  将出现“名单映射器”(Roster Mapper)，显示要映射的内容。请参见[名单映射器](名单映射器.md)。

  ![图：使用鼠标中键将要共享的动画源拖动到已在驱动角色的片段上。 将出现“名单映射器”(Roster Mapper)，显示要映射…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-99334286-1CD9-4886-8043-1F8A2033A0A3.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" -->

5. 激活“重映射后调整片段长度”(Adjust Clip Length After Remapping)，将新的动画片段修剪成动画的长度。单击“继续”(Continue)
