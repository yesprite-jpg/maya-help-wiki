# 在时间编辑器中设置动画关键帧

利用时间编辑器，您可以像使用非线性编辑器处理音频或视频一样排列和编辑片段。还可以通过在片段动画层上设置关键帧来修改片段内部的动画。

在时间编辑器中设置片段关键帧时，您应修改动画片段而不是动画源，且不遵循常规的 Maya 动画规则。对于片段层，该层必须在[时间编辑器工具栏](时间编辑器界面概述/时间编辑器工具栏.md)的时间编辑器“活动片段”(Active Clip)字段中处于活动状态，以便将其指定为要设置关键帧的片段层。设置轨迹权重的关键帧时，必须先选择该轨迹并查看其中的关键帧。

**注**

- 您不能直接在时间编辑器中的片段上设置关键帧。同时，也不能在时间编辑器中为受片段驱动的场景对象或属性设置关键帧。若要在动画源上设置关键帧，必须创建片段层或禁用时间编辑器。有关创建片段层的信息，请参见[在片段层上设置关键帧](在时间编辑器中设置动画关键帧/在片段层上设置关键帧.md)；有关如何在时间编辑器外部编辑动画源的信息，请参见[禁用时间编辑器](禁用时间编辑器.md)。

- 如果某个对象受时间编辑器片段驱动，而另一个对象不受时间编辑器片段驱动，则无法在其中任意一个对象上设置关键帧。 在片段上设置关键帧时，将修改[动画源](使用时间编辑器片段/时间编辑器动画源.md)。

- 时间编辑器不支持动画层。相反，可以使用时间编辑器片段层改变现有片段上的动画。（有关创建片段层的信息，请参见[在层片段上设置关键帧](在时间编辑器中设置动画关键帧/在片段层上设置关键帧.md)。）

- 如果您要编辑的动画源已在时间编辑器中的其他位置使用，请在片段上单击鼠标右键，然后从[时间编辑器“片段”(Clip)上下文菜单](使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“使动画源唯一”(Make Animation Source Unique)，使选定的动画源与其原始片段无关。请参见[动画源](使用时间编辑器片段/时间编辑器动画源.md)主题中的“重用动画源”部分。

有两种方法可以在时间编辑器中设置动画片段的关键帧

- 设置片段权重的关键帧（请参见[设置时间编辑器片段权重的关键帧](在时间编辑器中设置动画关键帧/设置时间编辑器片段权重的关键帧.md)）

- 在片段层上设置关键帧（请参见[在片段层上设置关键帧](在时间编辑器中设置动画关键帧/在片段层上设置关键帧.md)）
