# 时间编辑器权重(Weight)上下文菜单

查看“权重”(Weight)上下文菜单

- 在时间编辑器名单中的轨迹“权重”(Weight)字段上单击鼠标右键

#### 创建新表达式

打开[表达式编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-251640EA-AACC-4F1B-A341-297F0F4CEFE4)，从中可以控制权重属性。

#### 设置关键帧

在“时间编辑器”(Time Editor)中由“当前时间指示器”(Current Time Indicator)显示的动画点处，设置关键帧。这些关键帧仅影响“时间编辑器”(Time Editor)轨迹视图中的动画片段，而不影响原始[动画源](../../使用时间编辑器片段/时间编辑器动画源.md)。

#### 设置受驱动关键帧

打开[“设置受驱动关键帧”(Set Driven Key)窗口](../../../../关键帧动画/关键帧动画/受驱动关键帧/“设置受驱动关键帧”%28Set%20Driven%20Key%29窗口.md)。

#### 创建新纹理

打开[创建渲染节点(Create Render Node)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4918C294-FAAD-45B5-A896-92161177EEED)。

#### 锁定属性

冻结轨迹的“权重”(Weight)值，使您无法对其进行编辑。

#### 在曲线图编辑器中编辑权重曲线

打开[“曲线图编辑器”(Graph Editor)](../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)，使您能够提高曲线编辑的精确度。
