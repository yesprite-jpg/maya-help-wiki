# 在片段层上设置关键帧

您可以使用时间编辑器中的片段层以非破坏性方式修改现有动画。

在此示例中，您可以使角色跳跃的现有动画并更改跳起的高度，而不改变原始动画文件。

**注**

您无法驱动同时包含动画层和片段层的动画，因为这会产生冲突。

若要在时间编辑器的片段层上设置关键帧，请执行以下操作：

1. 选择要更改的对象/属性。在本示例中，角色的“髋部”(Hips)效应器有助于增加跳起的高度。

  ![图：选择要更改的对象/属性。在本示例中，角色的“髋部”(Hips)效应器有助于增加跳起的高度。 根据在视口或通道盒中所做的选…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-0DCFB624-948B-4824-90E4-ADECA53D2BC5.png) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" -->

  根据在视口或通道盒中所做的选择，系统将选择用于设置关键帧的属性：

  - 如果未选择任何选项，则为层中的所有属性设置关键帧

  - 如果仅选择对象，则为活动层中的这些对象的所有属性设置关键帧

  - 如果在通道盒中选择属性，则仅为活动层中与通道盒选择匹配的属性设置关键帧

2. 在通道盒中，选择“髋部效应器”(Hips Effector)的“平移 Y”(Translate Y)值，然后在第一个片段上单击鼠标右键。

3. 从[时间编辑器工具栏](../时间编辑器界面概述/时间编辑器工具栏.md)中选择“创建(相加)”(Create (Additive)) ![图：从时间编辑器工具栏中选择“创建(相加)”(Create (Additive)) 。选定属性的动画层将添加到片段。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-7CD629EF-BEC8-49DF-BEC9-AC904F4116C3.png) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" -->。选定属性的动画层将添加到片段。

4. 单击“片段层”(Clip Layer)图标 ![图：单击“片段层”(Clip Layer)图标 以展开片段层，可看到一个名为 Character1_Ctrl_Hips_Ef…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B057651A-0B8C-423E-A17F-86DD0BABA664.png) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" --> 以展开片段层，可看到一个名为 **Character1_Ctrl_Hips_Effector.Translate.Y** 的层。

  ![图：单击“片段层”(Clip Layer)图标 以展开片段层，可看到一个名为 Character1_Ctrl_Hips_Ef…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-88A41D02-21D5-4552-AE6D-FABEEA1882FD.gif) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" -->

5. 单击片段层以使其变为活动层（确保已在[时间编辑器工具栏](../时间编辑器界面概述/时间编辑器工具栏.md)的“活动层”(Active Layer)字段中将其选定）（也可以在片段层上单击鼠标右键，然后从[“片段层”(Clip Layer)上下文菜单](../将内容添加和导入到时间编辑器/将片段层添加到时间编辑器/“时间编辑器”%28Time%20Editor%29的“片段层”%28Clip%20Layer%29上下文菜单.md)中选择“设置为可设置关键帧的层”(Set as Keyable Layer)。）

7. 接下来，将“当前时间标记”(Current Time Marker)移动到角色落地的位置，并使用“设置层关键帧”(Set Layer Key)按钮来设置关键帧。

  ![图：接下来，将“当前时间标记”(Current Time Marker)移动到角色落地的位置，并使用“设置层关键帧”(Set…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9002FCDE-160C-4CB5-96E5-6D538E13BAFA.gif) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" -->

8. 最后，将“当前时间标记”(Current Time Marker)移动到角色跳起的最高点，并在“通道盒”(Channel Box)将 Y 轴再向上平移一些以创建逼真的飞跃，然后在层上为此设置关键帧。

**注**

- 使用[片段(Clip)上下文菜单](../使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中的“展平层”(Flatten Layers)选项，可将多个动画层合并为单个层。

- 打开曲线图编辑器即可直接编辑片段层的动画曲线。若要执行该操作，请选择片段层，然后单击 ![图：打开曲线图编辑器即可直接编辑片段层的动画曲线。若要执行该操作，请选择片段层，然后单击 打开曲线图编辑器中的层曲线。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-04FA3782-0382-4560-9B52-5F9126FEBEDF.png) <!-- baize:img-hook downloaded=false reason="正文 1456 字 ≥300，非承重" --> 打开[曲线图编辑器](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)中的层曲线。

- 如果要将其他对象添加到片段层以细化动画，请在片段层仍处于活动状态时选择通道盒中的属性，在片段层中单击鼠标右键，然后从[层片段(Layer Clip)上下文菜单](../将内容添加和导入到时间编辑器/将片段层添加到时间编辑器/“时间编辑器”%28Time%20Editor%29的“片段层”%28Clip%20Layer%29上下文菜单.md)中选择“选择 > 添加当前选择”(Selection > Add Selection)。将为每个选定属性创建层

- 可以通过调整层的权重来调整其影响。请参见[设置时间编辑器片段权重的关键帧](设置时间编辑器片段权重的关键帧.md)。

- 活动片段层是按照合成定义的，其信息存储在 Maya 场景文件中。

- 可以通过拖动操作移动片段层上的关键帧。
