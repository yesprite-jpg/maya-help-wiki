# 时间编辑器界面概述

时间编辑器窗口包括名单和时间视图。

- 左侧的名单表示对象的计时层次。

- 右侧的时间视图包含片段。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A7E20136-43CE-47AC-9672-149C2709236A.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->

“时间编辑器”(Time Editor)供您用于设置动画流，然后在“曲线图编辑器”(Graph Editor)中微调关键帧。单击菜单栏上的“打开曲线图编辑器”(Open the Graph Editor)图标 (![图：“时间编辑器”(Time Editor)供您用于设置动画流，然后在“曲线图编辑器”(Graph Editor)中微调关键…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-46A4EBDA-07C7-4ACC-AA46-869818DF37A4.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->)，以显示“曲线图编辑器”(Graph Editor)窗口。若要切换回“时间编辑器”(Time Editor)，请从“曲线图编辑器”菜单栏中单击“打开时间编辑器”(Open the Time Editor)图标 (![图：“时间编辑器”(Time Editor)供您用于设置动画流，然后在“曲线图编辑器”(Graph Editor)中微调关键…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-1A1665A3-5CB3-4B17-AC72-DD537D403319.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->)。

“时间编辑器”(Time Editor)的许多基本操作只能通过在不同区域和对象上单击鼠标右键时显示的上下文菜单执行。请参见[时间编辑器上下文菜单](使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)。

## 快速启动提示

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-015A744B-9F1C-4ED6-A5B6-99EAE70932F3.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->

每次在新的 Maya 会话中打开时间编辑器时，都会显示时间编辑器的快速启动提示。将这些提示包含在内，使您可以在时间编辑器中快速启动和运行动画。前两个图形是交互式的，您可以单击它们将内容导入 Maya 以用于时间编辑器，或者添加 Maya 场景中的已有内容。第三个图形提醒您可以从内容或文件浏览器拖动文件。

#### 视图中消息(In-view Messages)

![图：在时间编辑器中执行操作时，将显示视图中消息，提醒您时间编辑器状态发生的变化。您可以在“动画”(Animation)首选项…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9F40AE3E-6F43-49AB-9918-0DFA67C2A5E3.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->

在时间编辑器中执行操作时，将显示视图中消息，提醒您时间编辑器状态发生的变化。您可以在[“动画”(Animation)首选项（在“设置”(Settings)下）](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0817C74B-C95C-4E5F-BCFA-26DEE1D7747F)的“时间编辑器”(Time Editor)区域中禁用这些消息。

## 时间编辑器名单

该名单位于“时间编辑器”(Time Editor)左侧，在其中可以找到多个“时间编辑器”(Time Editor)控件，例如禁用、单放、重影和轨迹权重。有关这些功能的描述，请参见[时间编辑器名单](时间编辑器界面概述/时间编辑器名单.md)和[设置时间编辑器片段权重的关键帧](在时间编辑器中设置动画关键帧/设置时间编辑器片段权重的关键帧.md)。

## 时间视图

时间视图位于名单旁边并包含轨迹上的动画片段。每个片段都与组、对象或对象的属性关联。使用滚动条可以查看时间视图中的所有动画片段。有关详细信息，请参见[时间编辑器时间视图](时间编辑器界面概述/时间编辑器时间视图.md)。

每当选择某个片段时，在该片段上方就会显示开始帧和结束帧。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B376AE31-C03E-4DE8-9094-EF7A893AF825.gif) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->

如果片段存在于时间编辑器窗口外部，则结束帧处将显示一个点以指示片段超出边界。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-6BC2FAB5-F029-4E0C-B728-A9F5AFD2A6D7.png) <!-- baize:img-hook downloaded=false reason="正文 1277 字 ≥300，非承重" -->

有关片段如何显示在时间视图中的详细信息，请参见[时间编辑器片段符号](使用时间编辑器片段/时间编辑器片段符号.md)。

使用[当前时间标记](时间编辑器界面概述/时间编辑器的当前时间标记.md)从时间范围内的任意位置播放动画。在所需的帧上放置当前时间标记以执行编辑任务，如修剪、分割、删除等。

请参见[时间编辑器的当前时间标记](时间编辑器界面概述/时间编辑器的当前时间标记.md)以及[使用时间编辑器轨迹](使用时间编辑器轨迹.md)。
