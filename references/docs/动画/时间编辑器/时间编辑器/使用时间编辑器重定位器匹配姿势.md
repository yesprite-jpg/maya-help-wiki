# 使用时间编辑器重定位器匹配姿势

时间编辑器 “匹配重定位器”(Match Relocator)选项允许根据指定的对象对齐片段，因此您可以将它们合并在一起以创建新动画。

**注**

如果角色的位置已紧密对齐，则有助于匹配。若要使匹配角色彼此相互靠近，请参见

通过重新定位重新确定角色的方向

。

**注**

如果多个根驱动动画片段（例如，如果装备没有明确层次，但具有用于整个角色的控制器），则可以选择片段，然后随时单击

“编辑重定位器”(Edit Relocator)

以在

重定位器选项

中将其他根设为重定位器。

1. 为相同轨迹上的相同角色添加两个动画片段。

  ![图：为相同轨迹上的相同角色添加两个动画片段。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-AD5E658A-6362-4A94-813C-44BF1FB45756.gif) <!-- baize:img-hook downloaded=false reason="正文 886 字 ≥300，非承重" -->

2. 修剪片段以加快匹配过程。例如，在两个片段中找到一个帧，其中角色的左脚平放在地面上。如果第一个片段的结尾与第二个片段的开始类似，则匹配更平滑且所需的调整更少。

  ![图：修剪片段以加快匹配过程。例如，在两个片段中找到一个帧，其中角色的左脚平放在地面上。如果第一个片段的结尾与第二个片段的开始…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-2294C1B8-9EA5-4BBA-98C0-28CCE3F48C43.gif) <!-- baize:img-hook downloaded=false reason="正文 886 字 ≥300，非承重" -->

  **注**

  提示：

  在匹配点将两个片段融合在一起，以大致了解最终结果的外观。

3. 在第一个片段上单击鼠标右键，然后选择“重新定位 > 匹配重定位器...”(Relocate > Match Relocators...)。此时将显示[“匹配选项”(Matching options)](使用时间编辑器重定位器匹配姿势/匹配选项%28Matching%20options%29.md)。

4. 接下来，在“大纲视图”(Outliner)中，从要成为匹配对象的第一个动画片段中选择角色身体部位（如左踝），然后单击“选择”(Select)![图：接下来，在“大纲视图”(Outliner)中，从要成为匹配对象的第一个动画片段中选择角色身体部位（如左踝），然后单击“选…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D9CDF876-4E30-4101-BC0D-587C77692769.png) <!-- baize:img-hook downloaded=false reason="正文 886 字 ≥300，非承重" -->。

  “时间编辑器”(Time Editor)使用此对象作为匹配参考点。

  **注**

  如果选择身体部位，请在“匹配对象”(Matching Objects)区域中禁用

  “根对象”(Root Objects)

  。

5. 从“匹配片段”(Matching Clip)选项中选择“下一个”(Next)或“上一个”(Previous)，使选定对象与下一/上一片段匹配。

6. 从“匹配时间”(Matching Time)选项中选择要匹配片段的过渡时间。

7. 选择“匹配姿势”(Matching Pose)。有关“匹配姿势”(Matching Pose)选项的描述，请参见[匹配选项](使用时间编辑器重定位器匹配姿势/匹配选项%28Matching%20options%29.md)。

8. 单击“匹配”(Match)。

  ![图：单击“匹配”(Match)。 两个片段接合在一起。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-22DF2043-AADC-485B-AF88-0B2204128D19.gif) <!-- baize:img-hook downloaded=false reason="正文 886 字 ≥300，非承重" -->

  两个片段接合在一起。

  ![图：单击“匹配”(Match)。 两个片段接合在一起。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-0FB00D14-C84E-4F51-B6AF-141E85C2AC70.gif) <!-- baize:img-hook downloaded=false reason="正文 886 字 ≥300，非承重" -->

**注**

如果匹配生成不需要的结果，请尝试指定一个除自动指定以外的根对象。请参见

“匹配选项”(Matching Options)

中的

“根对象”(Root Objects)

以及

姿势匹配最佳实践

。
