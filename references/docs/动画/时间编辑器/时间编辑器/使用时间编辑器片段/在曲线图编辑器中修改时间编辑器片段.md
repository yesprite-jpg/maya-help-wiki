# 在曲线图编辑器中修改时间编辑器片段

尽管时间编辑器允许您大致组织和排列动画，但有时您需要更详细地调整动画精度。在这些情况下，请使用曲线图编辑器查看动画曲线和关键帧。

若要从片段编辑动画曲线，请执行以下操作：

- 在时间编辑器中选择片段并单击[时间编辑器工具栏](../时间编辑器界面概述/时间编辑器工具栏.md)中的“曲线图编辑器”(Graph Editor)图标 ![图：在时间编辑器中选择片段并单击时间编辑器工具栏中的“曲线图编辑器”(Graph Editor)图标 ，即可在曲线图编辑器中…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-04FA3782-0382-4560-9B52-5F9126FEBEDF.png) <!-- baize:img-hook downloaded=false reason="正文 705 字 ≥300，非承重" -->，即可在[曲线图编辑器](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)中打开片段的动画曲线以执行详细的曲线编辑。

- 在片段的层上单击鼠标右键，并从[“时间编辑器“片段”(Clip)上下文菜单](时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“在曲线图编辑器显示所有曲线”(Show All Curves in the Graph Editor)。有关编辑曲线的信息，请参见[将动画层添加到时间编辑器](../将内容添加和导入到时间编辑器/将片段层添加到时间编辑器.md)。

- 选择片段并单击[时间编辑器工具栏](../时间编辑器界面概述/时间编辑器工具栏.md)中的“在曲线图编辑器中编辑权重曲线”(Edit Weight Curve in Graph Editor)图标 ![图：选择片段并单击时间编辑器工具栏中的“在曲线图编辑器中编辑权重曲线”(Edit Weight Curve in Graph…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-4E318283-9BF2-4432-803D-B4EFDDCDC541.png) <!-- baize:img-hook downloaded=false reason="正文 705 字 ≥300，非承重" -->，即可在“曲线图编辑器”(Graph Editor)中打开片段的动画和权重曲线以编辑动画片段的权重曲线。请参见[设置时间编辑器片段权重的关键帧](../在时间编辑器中设置动画关键帧/设置时间编辑器片段权重的关键帧.md)。

  **注**

  动画片段和权重曲线均会显示，但权重曲线将自动在大纲视图中处于选中状态，因此单独显示。

- 若要在片段之间创建自定义 crossfade，请在动画片段的 crossfade 区域上单击鼠标右键，并从[时间编辑器片段(Clip)上下文菜单](时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“Crossfade > 自定义”(Crossfade > Custom)，然后单击“编辑自定义曲线”(Edit Custom Curve)。请参见[在时间编辑器中创建自定义 crossfade](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-40010838-3CD7-40EF-8D3D-46BB9DAB6D8B.htm)。

此外，您还可以在“曲线图编辑器”(Graph Editor)中为时间编辑器动画片段创建时间扭曲和速度曲线。请参见[在时间编辑器中重定时动画](../在时间编辑器中编辑动画/在时间编辑器中重定时动画.md)。
