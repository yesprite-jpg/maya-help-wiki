# 时间编辑器中的循环类型

您可以使用两类不同的方式循环时间编辑器动画片段：“周期”(Cyclical)和“渐进”(Progressive)。通常，时间编辑器根据在所导入片段中找到的动画决定要应用哪类循环模式。这通常是循环行走，其中仅穿过空间向前移动的属性采用“渐进”(Progressive)模式，其他动画（如摆动手臂）采用“周期”(Cyclical)模式。

可以为片段的开始和结束设置不同的模式。

更改片段的循环模式：

1. 在时间编辑器中选择动画片段。

2. 在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)的“片段”(Clip)选项卡中，从**“之前的片段循环”(Clip Loop Before)**和**“之后的片段循环”(Clip Loop After)**菜单中选择一个新模式。

在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中，更改“之前的片段循环”(Clip Loop Before)和“之后的片段循环”(Clip Loop After)模式相关设置。请参见[使用“渐进”(Progressive)循环创建循环行走](../在时间编辑器中编辑动画/使用“渐进”%28Progressive%29循环创建循环行走.md)。

## “周期”(Cyclical)循环

如果在循环中第一帧与最后一个帧匹配则为“周期”(Cyclical)循环，此循环模式可用于重复性动作（如角色摆动）。这是时间编辑器中的默认循环模式。

## “渐进”(Progressive)循环

“渐进”(Progressive)循环仍会重复动画，但会对每个循环周期应用偏移，从而沿相应路径逐渐向前推移动画。借助此类循环，您可以通过一个简短动画创建循环行走。

根据原始片段第一帧与最后一帧之间的动画位置差异确定偏移。然后，将此偏移应用于片段内的每个根变换（如同默认重定位器），从而使片段中的多个角色沿其各自的路径进行渐进循环。（有关自定义和默认片段重定位器的信息，请参见[重定位器选项](../在时间编辑器中编辑动画/通过重新定位重新确定角色的方向/“重定位器”%28Relocator%29选项.md)。）
