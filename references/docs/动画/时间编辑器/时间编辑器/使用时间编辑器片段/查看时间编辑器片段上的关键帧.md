# 查看时间编辑器片段上的关键帧

您可以在片段上显示关键帧。

要显示片段的关键帧，请在轨迹的[名单控件](../时间编辑器界面概述/时间编辑器名单.md)中单击“显示关键帧”(Show Keys)图标 ![图：要显示片段的关键帧，请在轨迹的名单控件中单击“显示关键帧”(Show Keys)图标 。](../../../../../assets/Maya-Animation/GUID-EA150053-2F37-4D91-B407-A75EAAA19B7D.png) <!-- baize:img-hook downloaded=true reason="正文 165 字 <300 且带图" -->。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Animation/GUID-8E6BC62C-D8D3-4F9B-97B8-05EE858AB91B.gif) <!-- baize:img-hook downloaded=true reason="正文 165 字 <300 且带图" -->

您也可以展开片段层次，显示每个对象上设置的关键帧。

展开片段的层次以查看每个对象上的关键帧

请单击片段名称旁边的箭头；要显示动画层次，请展开“名单”(Roster)中的每个箭头以显示层次。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Animation/GUID-EAB36B59-0C50-4D83-B1CE-10926A158552.gif) <!-- baize:img-hook downloaded=true reason="正文 165 字 <300 且带图" -->

请参见[在时间编辑器中设置动画关键帧](../在时间编辑器中设置动画关键帧.md)。
