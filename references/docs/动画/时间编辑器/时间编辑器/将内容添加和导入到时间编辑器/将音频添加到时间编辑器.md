# 将音频添加到时间编辑器

时间编辑器支持以下音频文件格式：

- *.wav*

- *.aiff*

**注**

- Maya 不支持 *.mp3* 音频格式。

- 播放速度必须设置为“实时”(Real-time)，否则您只能在拖动时听到声音，但在播放过程中听不到。为此，请右键单击 Maya 的[时间滑块](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-827ED8CD-C6AA-4495-8B5E-2FC98C8D49EE.htm)，并从“播放速度”(Playback Speed)选项中选择**“实时”(Real-time)**。

- 您可以同时播放多个音频片段，但无法调节片段音量、权重、循环或保留片段。

将音频文件添加到时间编辑器

从[“时间编辑器”(Time Editor)菜单栏](../时间编辑器界面概述/时间编辑器菜单栏.md)中选择“文件 > 导入音频片段”(File > Import Audio Clip)来打开文件浏览器，您可从中找到要加载到时间编辑器的音频文件。此时将创建音频轨迹。

此外，您还可以将音频文件拖动到[轨迹编辑器时间视图](../时间编辑器界面概述/时间编辑器时间视图.md)的空白区域中。

## 时间编辑器中的音频偏移

您可以使用音频偏移在您的音频文件中构建延迟。例如，假定创建了一个小鸟在绷紧的绳上走动的动画，然后想要在小鸟走到绳子尽头的时候播放声音文件。如果已知小鸟走到绳子尽头时处于时间 108 处，就可以在[“文件”(File)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9D1021A8-60A4-4B72-9A90-7C5070A9E037) **的“声音文件偏移”(Sound file offset)**字段中将声音文件偏移指定为 108。有关详细信息，请参见[导入选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-37B31221-7BBC-40DA-AB33-47C333EF4E14.htm)中的“音频”部分。

在时间编辑器中偏移一个音频片段

1. 通过在“时间滑块”(Time Slider)的“播放选项”(Playback options)的**“音量”(Volume)**图标 (![图：通过在“时间滑块”(Time Slider)的“播放选项”(Playback options)的“音量”(Volume)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A2FE50FE-BF80-4EFA-94CA-2D7DB09B34B6.png) <!-- baize:img-hook downloaded=false reason="正文 775 字 ≥300，非承重" -->) 上单击鼠标右键，然后选择**“将音频片段导入到时间编辑器”(Import Audio clip to Time Editor)**，导入音频。每个音频文件会在“时间编辑器”(Time Editor)中成为一个音频片段。

2. 使用所需偏移放置每个文件，或双击片段以访问其“属性编辑器”(Attribute Editor)选项卡并更改“偏移”(Offset)设置。
