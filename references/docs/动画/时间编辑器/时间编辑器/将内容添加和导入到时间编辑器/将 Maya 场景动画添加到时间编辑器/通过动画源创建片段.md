# 通过动画源创建片段

只要时间编辑器中存在[动画源](../../使用时间编辑器片段/时间编辑器动画源.md)，便可以使用它们在动画轨迹上创建动画片段。只要 Maya 中存在基于曲线的动画，[大纲视图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4B9A9A3A-83C5-445A-95D5-64104BC47406)或“源”(Sources)菜单中（位于[时间编辑器菜单栏](../../时间编辑器界面概述/时间编辑器菜单栏.md) “源”(Sources)菜单）便会显示动画源。

与从外部文件导入动画的方式类似，您只能通过场景中当前存在的动画源创建对象的片段。

**注**

动画源可以包含当前场景中不存在的对象的动画（例如，用于重映射目的）。请将场景中的动画源视为您可能使用的动画库。

通过场景中已有的动画源创建片段

1. 在[时间编辑器菜单栏](../../时间编辑器界面概述/时间编辑器菜单栏.md)中，展开“源”(Sources)菜单。

2. 选择“从动画源创建片段”(Create a Clip from Animation Source)，然后选择列出的源之一。

该动画源将作为片段添加到场景中。

您还可以使用鼠标中键将动画源从[大纲视图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4B9A9A3A-83C5-445A-95D5-64104BC47406)拖动到时间编辑器中的动画轨迹上。以下动画显示了正由大纲视图“源”(Sources)菜单中的一系列不同动画设置动画的 Sven 角色。
