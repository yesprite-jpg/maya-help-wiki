# 恢复删除的时间编辑器动画

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../assets/Maya-Animation/GUID-472E7E3E-6373-4BF3-BE2C-9D3DDCAE7719.gif) <!-- baize:img-hook downloaded=true reason="正文 194 字 <300 且带图" -->

如果在时间编辑器中删除了某个片段，则其动画将消失，但原始动画仍在场景中。在时间编辑器 “源”(Sources)菜单中选择“应用到场景”(Apply to Scene)，将动画恢复到场景并随即重新为对象设置动画。

**注**

也可以在

大纲视图

中找到源文件夹。
