# 时间编辑器的导出当前选择(Export Selction)选项

打开时间编辑器的导出当前选择(Export Selction)选项

- 在时间编辑器动画片段上单击鼠标右键，然后从[时间编辑器“片段”(Clip)上下文菜单](../使用时间编辑器片段/时间编辑器“片段”%28Clip%29上下文菜单.md)中选择“导出选定对象”(Export Selected)。

#### 将选定片段导出到文件(Export Selected Clips To Files)

从以下导出选项中进行选择：

##### FBX

打开文件浏览器，您可从中将选定片段另存为 FBX 文件。

##### Maya ASCII

打开文件浏览器，您可从中将选定片段另存为 Maya .*ma* 文件。以 ASCII 格式保存文件后，您可以在文本编辑器中打开并查看文件进行疑难解答。

##### Maya 二进制

打开文件浏览器，您可从中将选定片段另存为 Maya .*mb* 文件。

#### 缩略图(Thumbnail)/播放预览(Playblast)选项

单击“保存缩略图/播放预览”(Save Thumbnail/Playblast)选项，可激活“捕捉缩略图/播放预览”(Capture Thumbnail/Playblast)按钮。单击此按钮可打开[捕捉缩略图/播放预览(Capture Thumbnail/Playblast)选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-95E518E7-9ABA-4863-8C8B-E712BB21AC5A)，您可从中捕捉随场景文件一起保存的图像或图像序列。
