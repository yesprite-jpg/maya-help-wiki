# 设置关键帧首选项

您可以在“首选项”(Preferences)窗口中自定义“时间滑块”(Time Slider)关键帧标记的外观。

编辑关键帧首选项

1. 单击“动画控件”(Animation controls)中的“动画首选项”(Animation Preferences)按钮 ![图：单击“动画控件”(Animation controls)中的“动画首选项”(Animation Preferences)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-6FCAD178-4170-4108-8BB1-F25EEF8F5430.png) <!-- baize:img-hook downloaded=false reason="正文 327 字 ≥300，非承重" -->。

  “首选项”(Preferences)窗口打开[“时间滑块”(Time Slider)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-51A80586-9EEA-43A4-AA1F-BF1370C24A64.htm)类别。

2. 在“时间滑块”(Time Slider)区域，您可以编辑关键帧标记首选项。

3. （可选）在“类别”(Categories)框中，选择“动画”(Animation)以查看并编辑其他动画首选项。

4. 单击“保存”(Save)为您的场景保存当前的关键帧首选项，或者单击“取消”(Cancel)放弃所做的任何更改。
