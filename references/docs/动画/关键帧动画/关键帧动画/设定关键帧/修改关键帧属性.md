# 修改关键帧属性

可按以下方式设定关键帧属性：

- “动画”(Animation)菜单集的[“关键帧”(Key)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单.md)菜单包含用于设置和控制关键帧的条目。

- [路径动画](../../../路径动画/路径动画.md)使用 3D 曲线设定动画对象的方向。

- [“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)和[“通道盒”(Channel Box)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4C954FB2-8B6A-4BBD-9695-DF432616D0D2)中具有为显示的属性设定关键帧的菜单项。

- 您可以使用键盘[动画热键](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0639ADA0-EBE5-4703-A874-92C80E4A0516)来设定变换节点属性的关键帧。

- 通过运行时命令编辑器，可以输入自定义 MEL 或 Python 脚本以创建运行时命令。您可以使用[标记菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8BA1A3AA-4C44-4779-8B22-0AAE3627E8EB)来编辑关键帧。

- [“曲线图编辑器”(Graph Editor)](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)允许您设定和编辑现有动画的关键帧。

- [“摄影表”(Dope Sheet)编辑器](../编辑关键帧/使用摄影表编辑关键帧/“摄影表”%28Dope%20Sheet%29编辑器.md)允许您设定和编辑现有动画的关键帧。
