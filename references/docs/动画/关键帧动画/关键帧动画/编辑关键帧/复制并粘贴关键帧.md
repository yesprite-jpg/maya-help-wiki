# 复制并粘贴关键帧

重要指南

- 将包括多个动画曲线的关键帧复制和粘贴到多个属性时，请特别注意关键帧的选择顺序，因为该顺序会影响粘贴的顺序。

- 从“曲线图编辑器”(Graph Editor)或“摄影表”(Dope Sheet)中的多个属性复制关键帧时，应从各编辑器的大纲视图中选择属性，而不应从视图区域进行选择。

在[粘贴关键帧选项(Paste Key Options)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/粘贴关键帧选项%28Paste%20Key%20Options%29.md)窗口中，执行以下操作之一：

- 单击“粘贴关键帧”(Paste Keys)以设定“粘贴关键帧”(Paste Keys)选项并粘贴当前剪切或粘贴的关键帧。“粘贴关键帧选项”(Paste Keys Options)窗口将关闭。

- 单击“应用”(Apply)以设定“粘贴关键帧”(Paste Keys)选项并粘贴当前剪切或复制的关键帧。“粘贴关键帧选项”(Paste Keys Options)窗口保持打开状态。

- 单击“关闭”(Close)以放弃对“粘贴关键帧”(Paste Keys)选项所做的任何更改并关闭“粘贴关键帧选项”(Paste Keys Options)窗口。

## 复制并粘贴单个关键帧

1. 单击“时间滑块”(Time Slider)中的关键帧。

  当前时间指示器将移动到单击的位置，且该关键帧现已选定。

2. 执行下列操作之一：

  - 单击鼠标右键，然后从显示的菜单中选择“复制”(Copy)。

  - 选择“关键帧 > 复制”(Key > Copy)。

3. 单击“时间滑块”(Time Slider)。

  “当前时间指示器”(Current Time Indicator)将移动到单击的位置。

4. 执行下列操作之一：

  - 单击鼠标右键并从显示的菜单中选择“粘贴 > 粘贴”(Paste > Paste)。

  - 从[关键帧(Key)菜单](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单.md)中选择“关键帧 > 粘贴”(Key > Paste)。

  - 按住 Shift+S 键的同时单击并从显示的标记菜单中选择“粘贴关键帧”(Paste Keys)。

## 复制并粘贴多个关键帧

1. 按住 Shift 键并在“时间滑块”(Time Slider)中的关键帧范围上拖动。

  现在已选中关键帧范围，并亮显为红色。

2. 执行下列操作之一：

  - 单击鼠标右键，然后从显示的菜单中选择“复制”(Copy)。

  - 选择“关键帧 > 复制”(Key > Copy)。

3. 按住 Shift 键并在“时间滑块”(Time Slider)中您希望粘贴的关键帧添加到、替换或与其合并的关键帧范围上拖动。

  时间范围现在已选定，并且以红色亮显。

4. 执行下列操作之一：

  - 单击鼠标右键并从显示的菜单中选择“粘贴 > 粘贴”(Paste > Paste)。

  - 从[关键帧(Key)菜单](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单.md)中选择“关键帧 > 粘贴”(Key > Paste)。

  - 按住 Shift+S 键的同时单击并从显示的标记菜单中选择“粘贴关键帧”(Paste Keys)。
