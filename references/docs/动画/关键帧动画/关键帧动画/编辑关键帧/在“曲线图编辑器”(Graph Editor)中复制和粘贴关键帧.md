# 在“曲线图编辑器”(Graph Editor)中复制和粘贴关键帧

复制曲线中的关键帧并将其粘贴到同一曲线中

1. 在场景视图中，选择要复制和粘贴关键帧的动画对象。

2. 在“曲线图编辑器”(Graph Editor)的大纲视图中，选择要复制关键帧的特定通道，并按 F 键以在视图中框显曲线。

  选定通道的曲线将出现在“曲线图编辑器”(Graph Editor)的当前视图中。

3. 选择要复制的关键帧，然后按 Ctrl + C。

  **注**

  在粘贴之前，请务必单击曲线视图。

4. 在“曲线图编辑器”(Graph Editor)的曲线视图中，将当前时间指示器移动到要粘贴已复制关键帧的时间。

5. 按 Ctrl + V。

  ![图：按 Ctrl + V。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-6C63D39E-DA34-4216-A981-47E135A594C6.gif) <!-- baize:img-hook downloaded=false reason="正文 3133 字 ≥300，非承重" -->

6. （可选）若要查看[粘贴关键帧选项(Paste Keys Options)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/粘贴关键帧选项%28Paste%20Key%20Options%29.md)，请在“曲线图编辑器”(Graph Editor)菜单栏中选择“编辑 > 粘贴”(Edit > Paste) > ![图：（可选）若要查看粘贴关键帧选项(Paste Keys Options)，请在“曲线图编辑器”(Graph Editor)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3133 字 ≥300，非承重" --> 。

7. 如果需要在当前时间覆盖任何关键帧，请在“粘贴关键帧选项”(Paste Keys Options)中启用 “选定关键帧会覆盖指定时间范围”(Selected keys override specified time range)。

同时复制曲线中的关键帧并将其粘贴到同一对象的不同曲线中

1. 在场景视图中，选择要复制和粘贴关键帧的动画对象。

2. 在“曲线图编辑器”(Graph Editor)的大纲视图中，选择要复制关键帧的特定通道，并按 F 键以在视图中框显曲线。

  选定通道的曲线将出现在“曲线图编辑器”(Graph Editor)的当前视图中。

3. 选择要复制的关键帧，然后按 Ctrl + C。

  ![图：选择要复制的关键帧，然后按 Ctrl + C。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-58E4D95F-FC52-4C49-89D7-08FD5F126DD6.gif) <!-- baize:img-hook downloaded=false reason="正文 3133 字 ≥300，非承重" -->

4. 在“曲线图编辑器”(Graph Editor)的大纲视图中，选择要粘贴已复制关键帧的特定通道，并按 F 键以在视图中框显曲线。

  选定通道的曲线将出现在“曲线图编辑器”(Graph Editor)的当前视图中。

5. 按 Ctrl + V。

  **注**

  在粘贴之前，请务必单击曲线视图。

6. （可选）在“曲线图编辑器”(Graph Editor)菜单栏中，选择“编辑 > 粘贴”(Edit > Paste) > ![图：（可选）在“曲线图编辑器”(Graph Editor)菜单栏中，选择“编辑 粘贴”(Edit Paste) 以查看粘贴关…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3133 字 ≥300，非承重" --> 以查看[粘贴关键帧选项(Paste Keys Options)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/粘贴关键帧选项%28Paste%20Key%20Options%29.md)。

7. 选择与已复制关键帧的计时匹配的“时间范围”(Time Range)，并选择“粘贴方法”(Paste Method)。

8. 如果需要覆盖指定“时间范围”(Time Range)中的任何关键帧，请启用 “选定关键帧会覆盖指定时间范围”(Selected keys override specified time range)。

9. 单击“粘贴”(Paste)。

同时复制曲线中的关键帧并将其粘贴到另一对象的不同曲线中

1. 在场景视图中，选择要复制和粘贴关键帧的动画对象。确保已在该对象上创建关键帧，因此相应通道将显示在“曲线图编辑器”(Graph Editor)的大纲视图中。

2. 在“曲线图编辑器”(Graph Editor)的大纲视图中，选择该对象和要复制关键帧的特定通道。

3. 选择要复制的关键帧，然后按 Ctrl + C。

4. 在“曲线图编辑器”(Graph Editor)的大纲视图中，选择新对象和要粘贴已复制关键帧的特定通道，并按 F 键以在视图中框显曲线。

  选定通道的曲线将出现在“曲线图编辑器”(Graph Editor)的当前视图中。

5. 单击“曲线图编辑器”(Graph Editor)的曲线视图，然后按 Ctrl+ V。

7. 单击“粘贴”(Paste)。
