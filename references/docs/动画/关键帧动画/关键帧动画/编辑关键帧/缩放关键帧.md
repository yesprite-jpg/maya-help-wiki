# 缩放关键帧

可以通过缩放关键帧来更改一系列关键帧的持续时间，或更改动画曲线分段的值。

**注**

可以使用

“动画”(Animation)首选项（在“设置”(Settings)下）

的

“曲线图编辑器”(Graph Editor)

区域中的

“关键帧大小”(Key Size)

选项来更改曲线图编辑器图表视图中显示的关键帧的大小。

**注**

警告：

如果

“固定”(Fixed)

类型的切线在要缩放的关键帧和动画曲线分段范围内，则可能无法保留动画曲线的形状。

设置[缩放关键帧选项](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/缩放关键帧选项%28Scale%20Keys%20Options%29.md)

1. 选择“关键帧 > 缩放”(Key > Scale) > ![图：选择“关键帧 缩放”(Key Scale) 。 如果处于启用状态的是“时间范围-全部”(Time Range-All)选…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1348 字 ≥300，非承重" -->。

  - 如果处于启用状态的是“时间范围-全部”(Time Range-All)选项，则会缩放当前对象的所有关键帧。

  - 如果处于启用状态的是“时间范围-开始/结束”(Time Range-Start/End)选项，则仅缩放指定的“开始”(Start)时间和“结束”(End)时间之间的关键帧。

  - 如果处于启用状态的是“时间范围-时间滑块”(Time Range-Time Slider)选项，则仅缩放范围滑块的“开始”(Start)时间和“结束”(End)时间之间的关键帧。

  有关这些选项的一些额外提示：

  - 通过“时间缩放/枢轴”(Time Scale/Pivot)选项可以将动画范围的持续时间缩减一半。

  - 若要缩放动画，而又不影响此范围之前和之后的动画曲线，请选择“比例/枢轴方法”(Scale/Pivot Method)。

    与缩放区域相邻的关键帧和动画曲线分段会在时间上偏移已压缩或展开的缩放范围量，但是它们的形状将保留。

缩放关键帧

1. 执行下列操作之一：

  - 若要选择单个关键帧，请单击“时间滑块”(Time Slider)中的关键帧。

    “当前时间指示器”将移至单击位置，且关键帧已选定。

  - 若要选择多个关键帧，请按住 Shift 键并在“时间滑块”(Time Slider)中的关键帧范围内进行拖动。

    该范围内的关键帧现已选中并以红色亮显。

2. 执行下列操作之一：

  - 单击“缩放关键帧”(Scale Keys)以设定“缩放关键帧选项”(Scale Keys Options)并缩放当前关键帧。

    关闭“缩放关键帧选项”(Scale Keys Options)窗口。

  - 单击“应用”(Apply)以设定“缩放关键帧选项”(Scale Keys Options)并缩放当前关键帧。

    “缩放关键帧选项”(Scale Keys Options)窗口保持打开状态。

  - 单击“关闭”(Close)放弃对“缩放关键帧选项”(Scale Keys Options)所做的任何更改，并关闭“缩放关键帧选项”(Scale Keys Options)窗口。

通过“曲线图编辑器”(Graph Editor)中的区域工具，能够以交互方式按时间（水平）或值（垂直）缩放关键帧，或按时间移动整个关键帧区域。

以交互方式缩放多个关键帧

1. 在“曲线图编辑器”(Graph Editor)中，选择“区域工具”(Region Tool) ![图：在“曲线图编辑器”(Graph Editor)中，选择“区域工具”(Region Tool) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-38E8A26E-F981-406B-91D4-CE47B3030208.png) <!-- baize:img-hook downloaded=false reason="正文 1348 字 ≥300，非承重" -->。

2. 在图表视图区域中，拖动以选择要缩放的关键帧区域。

  图表视图区域的选定区域周围显示两侧均带控制柄的选择框。

3. 拖动整个选定框以移动整个区域，或拖动框两侧的控制柄以展开和收拢的框，如下所示：

  - 水平拖动，以便随着时间的推移缩短或延长区域。

  - 垂直拖动，以便增加或减小区域中值的范围。

  默认情况下，关键帧会捕捉到时间和值的整个值。
