# “摄影表”(Dope Sheet)大纲视图

“摄影表”(Dope Sheet)大纲视图以层次形式来表示选定对象的属性。“摄影表”(Dope Sheet)大纲视图按照类型和对象将属性组织到各组中。这样，您就可以同时操纵整组属性。例如，对列在大纲视图中的对象的所有旋转属性进行概述，这些属性可用于操纵“摘要组旋转”(Summary group Rotate)。这种分组的组织按降序排列如下：

## 大纲视图分组(Outliner groupings)

### 摘要(Summary)

按属性类型分组的所有选定对象的所有关键帧。

### 对象(Objects)

“摄影表”(Dope Sheet)大纲视图中选定对象的所有关键帧属性。

### 复合属性(Compound attributes)

特定类型的所有单个属性，例如平移、旋转等。

### 属性(Attributes)

单个属性是“摄影表”(Dope Sheet)大纲视图层次的最低级别。

**注**

当摘要、对象和复合属性组在“摄影表”(Dope Sheet)大纲视图中处于收拢状态时，表明并未选中收拢层次内的属性，因此在视图区域中执行操作时不会对这些属性进行编辑。
