# “摄影表”(Dope Sheet)视图区域

“摄影表”(Dope Sheet)的视图区域沿垂直轴分层显示关键帧。它沿水平轴将时间显示为单元或块。

**注**

在“摄影表”(Dope Sheet)视图区域中显示的时间块是整数值时间分段数；也就是说，时间 2 处的块包括从 2 到 3 的动画信息范围，不包括时间 3 处的信息。

已设置动画的属性用实线包围起来以指示其范围。块的颜色定义“摄影表”(Dope Sheet)的层次内属性或属性组的放置。

## 使用“摄影表”(Dope Sheet)操纵器编辑时间和关键帧的范围

请参见[在“摄影表”(Dope Sheet)中操纵一定范围的时间和关键帧](../../使用摄影表编辑关键帧.md)。

## 关键帧和曲线颜色

### 蓝(Blue)

所有显示的对象的所有关键帧（摘要对象）。

### 深绿(Dark green)

“摄影表”(Dope Sheet)大纲视图中选定对象的所有可设置关键帧属性（对象组）。

### 浅绿(Light green)

某个特定类型（如平移、旋转等）的所有单独的属性（复合属性）。

### 黑(Black)

未选定的各个属性的关键帧。

### 黄(Yellow)

选定的关键帧。

### 灰度(Gray)

值为 0 的关键帧。

## “摄影表”(Dope Sheet)弹出菜单

在视图区域中的任意位置单击鼠标右键可打开“摄影表”(Dope Sheet)弹出菜单。

## “摄影表”(Dope Sheet)中的声音

根据“首选项”(Preferences)窗口中的设置，会在“摄影表”(Dope Sheet)视图区域中出现声音。

## “选择工具”(Select Tool)、“移动工具”(Move Tool)和“缩放工具”(Scale Tool)

除了工具栏中的“摄影表”(Dope Sheet)工具之外，“选择工具”(Select Tool)、“移动工具”(Move Tool)和“缩放工具”(Scale Tool)也用于在“摄影表”(Dope Sheet)视图区域中操纵关键帧。由于“摄影表”(Dope Sheet)大纲视图的层次性质，可以按类型编辑属性组。这使得可以立即在大量对象上执行功能强大的计时编辑。请参见[选择工具](../../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29图表视图.md#WS17956D7ADBC6E736475032DC117AE308AAE-7FBF)、[移动关键帧工具](../../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29图表视图.md#WS17956D7ADBC6E736475032DC117AE308AAE-7FBE)和[缩放关键帧工具](../../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29图表视图.md#WS17956D7ADBC6E736475032DC117AE308AAE-7FBD)。

## 导航视图区域

- 若要在视图区域中水平或垂直滚动，请按 Alt 或 Option 键 (Mac OS X) 并使用鼠标中键进行拖动。

- 若要放大或缩小，请按 Alt 或 Option 键并使用鼠标右键拖动。

- 若要在特定区域上放大，请按 Ctrl+Alt 并拖动该区域。

- 若要从特定区域缩小，请按 Ctrl+Alt 并使用鼠标中键拖动该区域。
