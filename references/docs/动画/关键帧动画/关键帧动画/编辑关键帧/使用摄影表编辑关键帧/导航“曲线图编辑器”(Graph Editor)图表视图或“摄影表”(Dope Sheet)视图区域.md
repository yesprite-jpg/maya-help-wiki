# 导航“曲线图编辑器”(Graph Editor)图表视图或“摄影表”(Dope Sheet)视图区域

- 若要垂直和水平滚动图表视图，请按住 Alt 键或 Option 键 (Mac OS X)，并单击鼠标中键进行拖动。

- 若要均匀缩放图表视图，请按 Alt 键或 Option 键并拖动，或单击鼠标右键并拖动。

- 若要缩放图表视图，请在按住 Alt 或 Option 键和 Shift 键的同时拖动或使用鼠标右键拖动。

- 在“曲线图编辑器”(Graph Editor)中，可以使用方括号热键（[ 和 ]）移动到上一个或下一个视图。这些是相同的热键，用于在视口的摄影机视图之间移动。按左方括号 ([) 可移动到上一个视图，或者按右方括号 (]) 可移动到下一个视图。
