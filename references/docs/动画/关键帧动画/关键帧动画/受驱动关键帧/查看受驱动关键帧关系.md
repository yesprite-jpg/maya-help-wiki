# 查看受驱动关键帧关系

创建受驱动关键帧关联属性后，可以循环浏览关键帧，以查看对象在每一帧的状态。这一点在设置多个受驱动关键帧，或在“曲线图编辑器”(Graph Editor)中编辑受驱动关键帧曲线时非常有帮助。

检查对象在受驱动关键帧时的状态

1. 在场景视图中，选择具有受驱动属性的对象。

2. 在[“设置受驱动关键帧”(Set Driven Key)](“设置受驱动关键帧”%28Set%20Driven%20Key%29窗口.md)窗口中，选择“关键帧 > 转到下一个”(Key > Go To Next)或“关键帧 > 转到上一个”(Key > Go To Previous)。
