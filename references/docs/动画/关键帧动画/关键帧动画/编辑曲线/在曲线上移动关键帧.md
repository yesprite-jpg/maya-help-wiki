# 在曲线上移动关键帧

默认情况下，在“曲线图编辑器”(Graph Editor)中，您只需单击和拖动，便可在曲线上移动选定的关键帧。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Animation/GUID-3B23D7CA-A06A-40F1-9F35-E6449683DBCE.gif) <!-- baize:img-hook downloaded=true reason="正文 141 字 <300 且带图" -->

**注**

提示：

若要将关键帧一次移动一帧，可按

Shift

+

9

将其向左移动，按

Shift

+

0

将其向右移动。
