# 更改切线权重

在 Maya 中，默认情况下切线是非加权的，这意味着它们处于锁定状态，您只能更改其角度而非长度。如果要通过拖动来调整切线长度，则必须将切线类型更改为**“加权”(Weighted)**。

如果切线是非加权的并已锁定，则切线控制柄在[“曲线图编辑器”(Graph Editor)图表视图](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29图表视图.md)中显示为三角形。如果切线是加权的，则切线控制柄显示为方形。

非加权切线：您可以更改角度，但不能更改长度

加权切线：您可以更改角度和长度

**非加权切线（三角形）控制柄**仅调整切线角度，切线长度已锁定，不可调整，而**加权（方形）切线控制柄**既可以调整长度又可以调整角度。更改切线的长度可调整位置的缓入和缓出。

更改切线权重

1. 在[曲线图编辑器(Graph Editor)](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)中，右键单击关键帧，然后选择“加权”(Weighted)。

2. 接下来，在[“切线”(Tangents)菜单](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“切线”%28Tangents%29菜单.md)中，选择“自由切线长度”(Free Tangent Length)以确保切线已解除锁定（自由）。
