# 将关键帧添加到曲线

在[曲线图编辑器(Graph Editor)](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)中将关键帧添加到动画曲线

1. 在“曲线图编辑器”(Graph Editor)中，选择该曲线。

2. 请执行下列任一操作：

  - 从工具栏中选择“插入关键帧”(Insert Keys)工具 ![图：从工具栏中选择“插入关键帧”(Insert Keys)工具 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-02DF1766-6F61-4938-89C2-F8E485910316.png) <!-- baize:img-hook downloaded=false reason="正文 432 字 ≥300，非承重" -->。

  - 从菜单栏中选择“关键帧 > 添加关键帧”(Keys > Add Key)工具或“关键帧 > 插入关键帧”(Keys > Insert Keys)工具。

3. 拖动选择曲线，然后单击鼠标中键以在曲线上添加新的关键帧。

  添加到曲线的所有关键帧都将具有与相邻关键帧相同的切线类型，以保持原始动画曲线分段的形状。

一旦将关键帧添加到当前动画曲线，则可以选择关键帧并调整其设置。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-F6330163-C2B0-4FC9-BA0D-E7E14973AB83.gif) <!-- baize:img-hook downloaded=false reason="正文 432 字 ≥300，非承重" -->

从动画曲线中删除关键帧

在“曲线图编辑器”(Graph Editor)中，选择要删除的关键帧并按 Delete 键，或者在该关键帧上单击鼠标右键，然后从显示的弹出菜单中选择“编辑 > 删除”(Edit > Delete)。

一旦将关键帧添加到当前动画曲线，则可以选择关键帧并调整其设置。
