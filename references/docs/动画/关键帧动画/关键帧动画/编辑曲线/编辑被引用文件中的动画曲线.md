# 编辑被引用文件中的动画曲线

您可以编辑父场景引用的动画曲线。编辑操作包括添加、删除和移动关键帧以及更改切线类型。

编辑引用的动画曲线

1. 在[“文件引用”(File References)首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BFB2BE49-E33C-4D15-B817-D02E6F526B8B)中，启用“允许编辑引用的动画曲线”(Allow Referenced Animation Curves to be Edited)首选项（在“动画首选项”(Animation Preferences)的“引用的动画曲线”(Referenced Animation Curves)部分中）。

  启用该首选项后，您可以按照与编辑任何其他曲线相同的方式来编辑引用的曲线。

  **注**

  引用动画曲线时，此曲线会暗显（原始曲线颜色的 40%）并带有黑色锁定关键帧。

  ![图：在“文件引用”(File References)首选项中，启用“允许编辑引用的动画曲线”(Allow Reference…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-95CF75D5-4DCA-44BC-A902-FC3C36689CCD.png) <!-- baize:img-hook downloaded=false reason="正文 1091 字 ≥300，非承重" -->

  “曲线图编辑器”(Graph Editor)中的动画曲线：**A**. 引用、已锁定，**B**. 引用、未锁定

2. 编辑引用的曲线。

  在编辑引用的曲线（例如添加、移动或删除关键帧，或者更改切线和切线类型）时，所有编辑操作都将存储在文件中的引用节点中，并可以将其导出为 .editMB 或 .editMA 引用编辑文件。可以将该文件指定给另一个场景以传播引用编辑。请参见[将引用编辑导出到脱机文件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E2D1A00B-A90C-443D-AFC5-B819A037C5B6)和[将引用编辑指定给脱机文件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8D2F8B56-8546-42A7-B31D-A088D1EC2698)。

3. 在保存引用编辑之前，可以在“引用编辑”(Reference Edits)窗口中查看和删除编辑。

  若要打开“引用编辑”(Reference Edits)窗口，请在“大纲视图”(Outliner)中的引用节点上单击鼠标右键，然后选择“引用 > 列出编辑”(Reference > List Edits)。请参见[移除引用编辑](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EE30F765-7192-47AB-9A38-6BD225598EFD)。

当您在“曲线图编辑器”(Graph Editor)中修改引用的动画曲线时，也可以使用“缓冲区曲线”(Buffer Curve)选项比较引用的曲线和结果动画。

编辑引用曲线时查看或交换引用的动画和结果动画

1. 在编辑引用曲线之前，请在“曲线图编辑器”(Graph Editor)中选择它。

2. 从菜单栏中选择“曲线 > 缓冲区曲线 > 引用”(Curves > Buffer Curve > Reference)。

  这会拍摄被引用曲线的快照，并将其显示在图表视图区域中。

3. 编辑引用曲线，使用缓冲区引用曲线作为原始被引用曲线形状的可视提醒。

  （可选）若要将编辑的引用曲线交换回原始引用曲线，请执行下列操作之一：

  - 从菜单栏中选择“曲线 > 交换缓冲区曲线”(Curves > Swap Buffer Curve)。

  - 单击工具栏中的“交换缓冲区曲线”(Swap Buffer Curve) ![图：单击工具栏中的“交换缓冲区曲线”(Swap Buffer Curve) 。 提示： 如果在工具栏中看不到“交换缓冲区曲线…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-E669CC84-B51B-4D22-A974-66F4101D36FE.png) <!-- baize:img-hook downloaded=false reason="正文 1091 字 ≥300，非承重" -->。
