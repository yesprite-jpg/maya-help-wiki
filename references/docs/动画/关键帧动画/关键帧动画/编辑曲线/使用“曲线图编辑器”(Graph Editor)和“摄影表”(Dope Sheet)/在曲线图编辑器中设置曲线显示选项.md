# 在曲线图编辑器中设置曲线显示选项

## 显示已归一化曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B15E8721-519A-4274-8D17-9181721471C4.png) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->

归一化动画曲线

1. 选择要重新归一化其曲线的动画对象。

2. 打开“曲线图编辑器”(Graph Editor)。

  出现的“曲线图编辑器”(Graph Editor)将在图表视图中显示选定对象的所有动画曲线。

3. 执行下列操作之一：

  - 在曲线图编辑器”(Graph Editor)菜单栏中，选择“视图 > 显示已归一化”(View > Display Normalized)。

  - 在“曲线图编辑器”(Graph Editor)工具栏中，单击“启用归一化曲线显示”(Enable Normalized Curve Display)图标 (![图：在“曲线图编辑器”(Graph Editor)工具栏中，单击“启用归一化曲线显示”(Enable Normalized …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-288CC232-066B-4756-8B88-D0FA80C50709.png) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->)。

  将缩放当前显示在“曲线图编辑器”(Graph Editor)的图表视图中的所有曲线，以适配在 -1 到 1 的范围内。仅缩放显示的曲线，而不是基础动画。

禁用归一化曲线显示

1. 选择要将其曲线还原到非归一化状态的动画对象。

2. 打开“曲线图编辑器”(Graph Editor)。

  出现的“曲线图编辑器”(Graph Editor)将在曲线视图中显示选定对象的所有动画曲线。

3. 在“曲线图编辑器大纲视图”(Graph Editor Outliner)中，选择要禁用归一化显示的通道。

4. 执行下列操作之一：

  - 在曲线图编辑器”(Graph Editor)菜单栏中，选择“视图 > 显示已归一化”(View > Display Normalized)。

  - 在“曲线图编辑器”(Graph Editor)工具栏中，单击“禁用归一化曲线显示”(Disable Normalized Curve Display)图标 (![图：在“曲线图编辑器”(Graph Editor)工具栏中，单击“禁用归一化曲线显示”(Disable Normalized…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-60A2E66B-FB06-4EAF-A5B6-FC6E484748E1.png) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->)。

  “曲线图编辑器”(Graph Editor)图表视图中的曲线将返回到其原始显示。

重新归一化曲线

1. 选择要重新归一化其曲线的动画对象。

2. 在“曲线图编辑器大纲视图”(Graph Editor Outliner)中，选择要重新归一化曲线的通道。

3. 执行下列操作之一：

  - 在“曲线图编辑器”(Graph Editor)菜单栏中，选择“视图 > 重新归一化”(View > Renormalize)。

  - 在“曲线图编辑器”(Graph Editor)工具栏中，单击“重新归一化曲线”(Renormalize curves)图标 (![图：在“曲线图编辑器”(Graph Editor)工具栏中，单击“重新归一化曲线”(Renormalize curves)图…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-234B5E3B-F4BB-49FB-A8B4-222085D1C8EB.png) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->)。

  将缩放当前显示在“曲线图编辑器”(Graph Editor)的图表视图中的所有选定曲线，以适配在 -1 到 1 的范围内。仅缩放显示的曲线，而不是基础动画。

## 显示堆叠的曲线

默认情况下，曲线将在图表视图中重叠显示。可以切换以查看单个曲线的堆叠。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-CA9CCA2F-FF68-4F75-9E5D-C5C59F14A373.png) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->

若要查看曲线的堆叠显示，请从“曲线图编辑器”(Graph Editor)菜单栏中选择“视图 > 堆叠视图”(View > Stacked View)。有关详细信息，请参见[堆叠的曲线](../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“视图”%28View%29菜单.md#GUID-ABB47176-9119-47F2-8466-6FA19C427F9F__GUID-6EC326DA-F871-40BA-B8EE-6C443ECFFC59)。

**注**

提示：

在[颜色设置(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)中自定义“曲线图编辑器”(Graph Editor)的单个曲线颜色。您还可以在[“动画”(Animation)首选项（在“设置”(Settings)下）](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0817C74B-C95C-4E5F-BCFA-26DEE1D7747F)的“堆叠视图间距”(Stacked View Spacing)设置中修改水平道宽度。

**注**

注意：

如果在“堆叠的曲线”(Stacked Curves)启用时使用“缩放关键帧工具”(Scale Keys Tool)或“晶格变形器关键帧工具”(Lattice Deformer Keys Tool)，则仅可修改时间值。

禁用曲线的堆叠显示

从“曲线图编辑器”(Graph Editor)菜单栏中，再次选择“视图 > 堆叠视图”(View > Stacked View)。

## 仅显示直接连接的曲线

可以针对选定通道限制显示在图表视图中的曲线。

仅在图表视图中显示直接连接的曲线

1. 在“曲线图编辑器大纲视图”(Graph Editor Outliner)中，选择要限制曲线显示的通道。

2. 从“曲线图编辑器”(Graph Editor)菜单栏中，禁用“列表 > 显示上游曲线”(List > Show Upstream Curves)选项。

针对选定通道再次显示所有曲线

1. 在“曲线图编辑器”(Graph Editor)菜单栏中，启用“列表 > 显示上游曲线”(List > Show Upstream Curves)。

## 显示受影响的曲线区域

可以设置“曲线图编辑器”(Graph Editor)，以显示受选定关键帧或切线影响的曲线部分。当您尝试衡量关键帧对前后动画的影响时，这很有用。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9DB7C704-CF6C-4487-B085-B246A4E7F65F.gif) <!-- baize:img-hook downloaded=false reason="正文 1989 字 ≥300，非承重" -->

1. 在[“曲线图编辑器”(Graph Editor)“视图”(View)菜单](../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“视图”%28View%29菜单.md)中，启用“亮显受影响曲线”(Highlight Affected Curves)，然后：

  - 选择一个**关键帧**：将亮显受影响曲线上关键帧的每一侧

  - 选择**多个关键帧**：将亮显受选择影响的整个曲线范围

  - 选择一条**切线**：将亮显受选定切线影响的曲线分段（在选定侧）

  - 选择**多条切线**：仅亮显受选定切线影响的部分
