# 简化曲线

简化曲线

1. 在“曲线图编辑器”(Graph Editor)中，选择曲线。

2. 在菜单栏上选择“曲线 > 简化曲线”(Curves > Simplify Curve) > ![图：在菜单栏上选择“曲线 简化曲线”(Curves Simplify Curve) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 304 字 ≥300，非承重" -->。

3. 在显示的窗口中设置[“简化曲线选项”(Simplify Curve Options)](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“曲线”%28Curves%29菜单/“简化曲线”%28Simplify%20Curve%29选项.md)。

  **注**

  可能要尝试各种值容差和“时间容差”(Time Tolerance)值，以获得所需的结果。

4. 执行下列操作之一：

  - 单击“简化”(Simplify)以设定“简化曲线”(Simplify Curve)选项，并将这些设置应用到当前曲线。

  - 单击“应用”(Apply)以设定“简化曲线”(Simplify Curve)选项，并将这些设置应用到当前曲线。

  将对指定时间范围内的当前曲线上的关键帧进行平均计算。
