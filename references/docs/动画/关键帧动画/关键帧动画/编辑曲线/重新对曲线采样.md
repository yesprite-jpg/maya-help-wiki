# 重新对曲线采样

重新对曲线采样

1. 在“曲线图编辑器”(Graph Editor)中选择该曲线。

2. 在菜单栏上选择“曲线 > 重新对曲线采样”(Curves > Resample Curves) > ![图：在菜单栏上选择“曲线 重新对曲线采样”(Curves Resample Curves) 。 随即显示“重新对曲线采样选项…](../../../../../assets/Maya-Animation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 269 字 <300 且带图" -->。

  随即显示“重新对曲线采样选项”(Resample Curve Options)窗口。请参见[重新对曲线采样](../编辑关键帧/使用摄影表编辑关键帧/“摄影表”%28Dope%20Sheet%29编辑器/“摄影表”%28Dope%20Sheet%29菜单栏.md#GUID-FED85068-B947-422D-82C9-8A846EEE4D22__GUID-2C448D39-D256-4A8C-92CE-045696BABB68)。

3. 设定选项。

4. 单击“重采样”(Resample)以设置“重新对曲线采样”(Resample Curve)选项，或者单击“应用”(Apply)以设置“重新对曲线采样”(Resample Curve)选项，然后将这些设置应用到当前曲线。

  将统一在当前曲线上设置关键帧，并且它们的数量将减少。
