# 插入关键帧替换重定时标记

在创建重定时标记并设置了动画序列的计时之后，可以通过插入关键帧替换重定时标记来锚定计时更改。

插入关键帧以替换重定时标记

1. 在标记上单击鼠标右键，然后从显示的菜单中选择“插入关键帧”(Insert Key)。

  Maya 会在当前在重定时标记下显示的所有选定通道上插入关键帧。如果没有选定曲线，会在此帧处为当前显示在图表视图中的所有曲线插入一个关键帧。

  **注**

  添加的关键帧的切线基于在

  “动画（设置）首选项”(Animation (Settings)preferences)

  中指定的

  “默认入切线”(Default In Tangent)

  /

  “默认出切线”(Default Out Tangent)

  （默认情况下为

  “自动”(Auto)

  切线），它可以调整曲线的形状。
