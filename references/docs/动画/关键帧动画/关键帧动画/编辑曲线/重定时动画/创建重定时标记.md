# 创建重定时标记

创建重定时标记

1. 选择含有要重定时的动画的对象。

2. 在“曲线图编辑器”(Graph Editor)中，选择要影响的所有通道，然后单击[“工具栏”(toolbar)](../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29工具栏.md)中的 ![图：在“曲线图编辑器”(Graph Editor)中，选择要影响的所有通道，然后单击“工具栏”(toolbar)中的 ，或选…](../../../../../../assets/Maya-Animation/GUID-96B1004C-80CD-490F-87AA-87F06CE320BE.png) <!-- baize:img-hook downloaded=true reason="正文 272 字 <300 且带图" -->，或选择“编辑 > 变换工具 > 重定时工具”(Edit > Transformation Tools > Retime Tool)。

  这将启用图表视图区域中的“重定时工具”(Retime Tool)。

3. 在图表视图中双击可围绕要修改的动画曲线分段创建重定时标记。（如果希望将所有曲线移动到不同时间，还可以创建单个标记。）

  每次双击会添加一个重定时标记。
