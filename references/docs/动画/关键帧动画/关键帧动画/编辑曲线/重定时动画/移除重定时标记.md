# 移除重定时标记

只要选定对象不变，重定时标记就会一直在图表视图中。可以在“曲线图编辑器”(Graph Editor)中更改工具，然后切换回“重定时工具”(Retime Tool)并继续调整标记。

删除重定时标记

- 双击标记，或者单击标记底部的删除图标 ![图：双击标记，或者单击标记底部的删除图标 。](../../../../../../assets/Maya-Animation/GUID-9851F03C-B918-41A4-9F2A-C96B098D0FCE.png) <!-- baize:img-hook downloaded=true reason="正文 172 字 <300 且带图" -->。

清除图表视图中的所有重定时标记

- 选择场景中的其他对象。
