# 使重定时标记捕捉到帧

在拖动重定时标记以调整动画计时时，您可以强制重定时标记捕捉到整帧。

使重定时标记捕捉到帧

1. 在“曲线图编辑器”(Graph Editor)中，选择“变换工具 > 重定时工具”(Transformation Tools > Retime Tool) > ![图：在“曲线图编辑器”(Graph Editor)中，选择“变换工具 重定时工具”(Transformation Tools…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 320 字 ≥300，非承重" -->（或者如果“重定时工具”(Retime Tool)图标 ![图：在“曲线图编辑器”(Graph Editor)中，选择“变换工具 重定时工具”(Transformation Tools…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96B1004C-80CD-490F-87AA-87F06CE320BE.png) <!-- baize:img-hook downloaded=false reason="正文 320 字 ≥300，非承重" --> 显示在[工具箱](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F4FCE554-1FA5-447A-8835-63EB43D2690B)区域中，请双击该图标）。

2. 在“重定时设置”(Retime Settings)中，启用[“捕捉帧上的标记”(Snap Markers on Frame)](../../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单.md#GUID-6B2EBCB3-766F-48D1-A079-7B5672AF54D1__GUID-4F4C74CB-A226-4AAD-96D5-E904A2F5AB68)。

  **注**

  “重定时设置”(Retime Settings)

  显示在

  “工具设置”(Tool Settings)

  窗口中，位于“曲线图编辑器”(Graph Editor)之外。
