# 更改重定时标记的颜色

更改重定时标记的颜色

1. 选择“窗口 > 设置/首选项 > 颜色设置”(Windows > Settings/Preferences > Color Settings)以打开[颜色设置(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)窗口。

2. 在“常规”(General)选项卡上，展开“动画编辑器”(Animation Editors)部分。

3. 使用颜色样例或滑块调整“重定时工具”(Retime Tool)的任何组件。
