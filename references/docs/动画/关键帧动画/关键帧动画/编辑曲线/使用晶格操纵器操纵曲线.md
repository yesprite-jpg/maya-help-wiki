# 使用晶格操纵器操纵曲线

使用晶格操纵器使动画曲线变形

1. 从[曲线图编辑器工具栏](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29界面概述/“曲线图编辑器”%28Graph%20Editor%29工具栏.md#WS17956D7ADBC6E736475032DC117AE308AAE-7FC6)中选择“晶格变形关键帧工具”(Lattice Deform Keys Tool) ![图：从曲线图编辑器工具栏中选择“晶格变形关键帧工具”(Lattice Deform Keys Tool) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-7DFFB022-8187-4F24-A4E7-435E7776578C.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->。

2. 从“工具设置”(Tool Settings)窗口中设置“晶格变形关键帧工具”(Lattice Deform Keys Tool)选项。

3. 在要变形的曲线上选择关键帧以定义目标曲线区域。

  此时，晶格会显示在曲线视图中。晶格围绕选定的关键帧形成了一个边界框。

  ![图：在要变形的曲线上选择关键帧以定义目标曲线区域。 此时，晶格会显示在曲线视图中。晶格围绕选定的关键帧形成了一个边界框。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-33E136EF-286A-438D-A35D-C8AE716F2008.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->

4. 选择要操纵的晶格点、晶格边或晶格单元（单击它们即可）。

  按住 Shift 键并单击晶格点，以将其包含在您的选择中或从选择中移除。一次最多可以选择一条晶格边或一个晶格单元。

5. 执行下列操作之一：

  - 对于晶格边、晶格单元或单个晶格点，拖动可使目标曲线区域变形。

    ![图：对于晶格边、晶格单元或单个晶格点，拖动可使目标曲线区域变形。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-14E298BE-3419-45E6-AB8B-BC8A5F4C1672.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->

  - 对于晶格点组，按鼠标中键并拖动组可使目标曲线区域变形。

    ![图：对于晶格点组，按鼠标中键并拖动组可使目标曲线区域变形。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C8D64C3A-4F7B-4269-AB5C-136140CCA953.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->

  - 如果要缩放晶格区域，请启用“晶格变形关键帧工具”(Lattice Deform Keys Tool)中的“中键缩放”(Middle Button Scales)选项，然后按鼠标中键并拖动以缩放选定的晶格区域。缩放晶格会使受影响的曲线变形。

    ![图：如果要缩放晶格区域，请启用“晶格变形关键帧工具”(Lattice Deform Keys Tool)中的“中键缩放”(M…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-6AA2A3B2-E526-45D2-B6DB-33B5FF36C016.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->

  - 您还可以使用“晶格变形关键帧工具”(Lattice Deform Keys Tool)，将位于单个（水平或垂直）图表视图轴中的关键帧变形。

    ![图：您还可以使用“晶格变形关键帧工具”(Lattice Deform Keys Tool)，将位于单个（水平或垂直）图表视图…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-6C0B9C55-1FD2-4716-A524-60A41CCD4C48.png) <!-- baize:img-hook downloaded=false reason="正文 709 字 ≥300，非承重" -->

  使用“晶格变形关键帧工具”(Lattice Deform Keys Tool)使沿着单个轴的关键帧变形时，选择某行（垂直）或某列（水平）中的一个晶格点就会选中该行或该列中的所有点。

  例如，如果在水平晶格上选择晶格控制点，则选定点所在的列中的所有晶格点也会被激活。并非所有选定的晶格点都是可见的，具体取决于“曲线图编辑器”(Graph Editor)中的当前推拉视图比例。选定晶格点是否可见不影响该工具的运行。
