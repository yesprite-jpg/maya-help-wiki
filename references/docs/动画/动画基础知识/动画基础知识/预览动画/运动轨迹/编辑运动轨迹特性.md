# 编辑运动轨迹特性

默认情况下，运动轨迹显示为具有白色关键帧和粉红色计时调整钮的红线。可以使用“通道盒”(Channel Box)或“属性编辑器”(Attribute Editor)编辑这些颜色和其他显示特性。

**注**

在可见情况下，当切线设定为显示在

“曲线图编辑器”(Graph Editor)

中时，它们都显示为相同颜色。

编辑运动轨迹特性

1. 若要显示运动轨迹属性，请执行下列操作之一：

  - 选择运动轨迹或任何显示在运动轨迹上的关键帧，然后选择“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的 motionTrail*n*HandleShape 对象。

  - 在运动轨迹上单击鼠标右键并从显示的菜单中选择 motionTrail*n*Handle。

  所有运动轨迹颜色属性都显示在“MotionTrailShape 属性”(MotionTrailShape Attributes)标题下。

2. 根据需要调整特性。有关设置的示例，请参见[运动轨迹特性](运动轨迹特性.md)。

有关运动轨迹特性的详细信息，另请参见[“创建可编辑的运动轨迹”(Create Editable Motion Trail)选项](“创建可编辑的运动轨迹”%28Create%20Editable%20Motion%20Trail%29选项.md)。

## 隐藏或删除运动轨迹

删除运动轨迹

在[大纲视图(Outliner)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4B9A9A3A-83C5-445A-95D5-64104BC47406)中选择运动轨迹（名称类似于 *motionTrail1Handle*），然后按 Delete 键。

隐藏运动轨迹

在[大纲视图(Outliner)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4B9A9A3A-83C5-445A-95D5-64104BC47406)中选择运动轨迹（名称类似于 *motionTrail1Handle*），然后按 Ctrl + H 键。若要再次显示此运动轨迹，请再次在“大纲视图”(Outliner)中选择此运动轨迹，然后按 Shift + H 键。
