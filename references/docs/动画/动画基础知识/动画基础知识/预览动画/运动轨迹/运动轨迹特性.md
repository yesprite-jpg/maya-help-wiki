# 运动轨迹特性

#### 绘制(Draw)

通过“选择时”(When Selected)、“始终”(Always)和“X 射线绘制”(Xray Draw)这三个设置，可以设置运动轨迹可见的时间。“X 射线绘制”(Xray Draw)显示对象内的运动轨迹。否则，运动轨迹经过其顶部。

#### 轨迹绘制模式(Trail Draw Mode)

从下列选项中选择：

##### 恒定(Constant)

显示运动轨迹。

##### 过去/未来(Past/Future)

可用于通过按“轨迹颜色”(Trail Color)和“附加轨迹颜色”(Extra Trail color)设置定义的颜色区分帧，查看哪个动画在当前帧之前和之后出现。（请参见“运动轨迹颜色/大小设置”。）在采用标准运动轨迹颜色的当前帧之后出现的动画。

![图：恒定(Constant) 显示运动轨迹。 过去/未来(Past/Future) 可用于通过按“轨迹颜色”(Trail C…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-BC3CBC6E-652F-485F-AFB6-D198FF902D3F.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

##### 替代帧(Alternating Frames)

以“轨迹颜色”(Trail Color)和“附加轨迹颜色”(Extra Trail Color)设置中定义的替代颜色显示每个帧。（请参见“运动轨迹颜色/大小设置”。）这样您就可以沿轨迹查看动画的速度：帧分段越小，动画就越慢；而帧分段越长，动画就越快。

![图：恒定(Constant) 显示运动轨迹。 过去/未来(Past/Future) 可用于通过按“轨迹颜色”(Trail C…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-E1A11579-C696-44B1-84A6-630D1C93534F.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 褪色帧(Fade Frames)

创建褪色效果，该效果按指定的帧数持续。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D3C52460-0C0B-428B-85FC-2CA336D8E76E.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 之前/之后绘制帧(Draw Frames Before/After)

可用于设置在当前帧之前/之后可见的运动轨迹的长度。

#### 轨迹厚度(Trail Thickness)

可用于指定运动轨迹的大小。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9C8814D0-0738-4CBC-9AFD-84874E4AB8D1.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 运动轨迹颜色/大小设置

不同的运动轨迹选项有相应的颜色和大小设置。可以为轨迹、备用轨迹、关键帧、活动关键帧、标记和帧交叉指定颜色。还可以指定关键帧的大小。

#### 显示关键帧数(Show Keyframe Numbers)

在动画中设置每个关键帧的点上显示编号。激活“给所有关键帧上色”(Color All Keyframes)以便为所有关键帧设置特定的颜色。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-3668B80D-C706-4DB1-9E4E-1B9ABE45C031.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 显示帧交叉(Show Frame Crosses)

在动画中每个帧出现的点上显示标记。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-CC55DC54-B1F7-4228-A19E-9D884CBF907E.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 显示帧数(Show Frame Numbers)

显示每个帧的帧编号。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B6D60E78-8A28-47AE-B95D-1E1F23EB8022.gif) <!-- baize:img-hook downloaded=false reason="正文 988 字 ≥300，非承重" -->

#### 编辑入/出切线(Edit In/Out Tangents)

显示入/出加权切线关键帧。请参见[显示和编辑切线](修改运动轨迹上的关键帧或切线.md#GUID-FC9AE83B-11C9-45C2-A364-AFCDF23BD125__GUID-5E2969F0-9DC9-4C7C-A2D4-B293C8E3BBD4)。

#### 编辑入/出调整钮(Edit In/Out Beads)

显示具有加权切线关键帧的曲线的入/出调整钮。请参见[显示和编辑计时调整钮](修改运动轨迹上的关键帧或切线.md#GUID-FC9AE83B-11C9-45C2-A364-AFCDF23BD125__OL_50DB8C7F34614C1E9624442BCEBEB890)。

#### 添加关键帧(鼠标左键)(Add Keyframes (LMB))

可用于单击以添加关键帧，修改已设置关键帧之外的运动轨迹。
