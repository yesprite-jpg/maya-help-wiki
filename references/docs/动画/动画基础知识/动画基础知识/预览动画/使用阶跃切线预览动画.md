# 使用阶跃切线预览动画

像所有关键帧均具有阶跃切线一样快速预览动画

1. 右键单击“时间滑块”(Time Slider)，并切换“启用阶跃预览”(Enable Stepped Preview)选项。

  如果启用“启用阶跃预览”(Enable Stepped Preview)，播放动画可以在对象碰到每个关键帧时快速查看这些对象的位置。如果禁用“启用阶跃预览”(Enable Stepped Preview)，曲线将返回到其原始切线类型。
