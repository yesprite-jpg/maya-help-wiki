# 运动轨迹

可编辑运动轨迹可让您在 3D 场景中预览动画，并以交互方式调整关键帧。运动轨迹在动画模型周围直观地表示关键帧，从而可以直接调整动画的计时、关键帧、切线和位置。

有关编辑运动轨迹上的关键帧、切线和计时调整钮的详细信息，请参见[修改运动轨迹上的关键帧或切线](运动轨迹/修改运动轨迹上的关键帧或切线.md)。

## 关键帧和切线

可以在运动轨迹上为所有具有可编辑切线类型（样条线、线性、钳制、平坦、固定、高原和自动）的关键帧显示交互式切线。可以为选定关键帧同时显示入切线和出切线。

## 计时调整钮

可以在运动轨迹上显示和调整计时调整钮，以便控制动画在每个关键帧上的缓入和缓出。每个调整钮表示时间中的一帧。通过调整关键帧任一侧的计时调整钮之间的间距，可以减慢或加快对象接近和远离关键帧时的移动速度。拉伸计时调整钮将减慢对象进入或离开关键帧时的移动速度，而压缩调整钮将加快移动速度。

**注**

计时调整钮只能为具有加权切线的曲线显示。
