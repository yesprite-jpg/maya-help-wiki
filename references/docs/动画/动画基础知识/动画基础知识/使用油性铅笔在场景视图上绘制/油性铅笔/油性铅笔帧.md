# 油性铅笔帧

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-F0230CE0-4340-4C24-B9C1-3EEA9E9A2EFF.png) <!-- baize:img-hook downloaded=false reason="正文 372 字 ≥300，非承重" -->

一个油性铅笔帧将添加到“时间滑块”(Time Slider)中，表示各时间点的每个油性铅笔草图。默认情况下，仅油性铅笔草图添加到“时间滑块”(Time Slider)的当前摄影机显示中。（请参见[控制“时间滑块”中油性铅笔帧的显示方式](../使用油性铅笔帧和图像/控制“时间滑块”%28Time%20Slider%29中油性铅笔帧的显示方式.md)。）

您可以在“时间滑块”(Time Slider)中移动、剪切、复制和粘贴油性铅笔帧以调整其显示时间。请参见[剪切、复制和粘贴油性铅笔帧](../使用油性铅笔帧和图像/剪切、复制和粘贴油性铅笔帧.md)和[移动油性铅笔帧](../使用油性铅笔帧和图像/移动油性铅笔帧.md)。

若要保存油性铅笔帧，以便将其导出到其他软件或在 Maya 中导入和查看它们，请参见[保存和共享油性铅笔草图](../使用油性铅笔帧和图像/保存和共享油性铅笔草图.md)。

**注**

油性铅笔不遵循

“时间滑块(Time Slider)”首选项

中的

“捕捉到整个帧”(Snap to whole frames)

设置，因此时间轴中的缩放关键帧可以将油性铅笔草图移到一半的位置或帧的其他部分。
