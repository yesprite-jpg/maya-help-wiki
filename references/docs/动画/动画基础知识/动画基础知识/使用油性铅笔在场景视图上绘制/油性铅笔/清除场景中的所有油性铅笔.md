# 清除场景中的所有油性铅笔

当完成使用油性铅笔标记场景时，可以在移交快照之前清除所有草图。您可以删除场景中的所有油性铅笔帧，或仅删除特定摄影机上的帧。

**注**

提示：

若要退出

“油性铅笔”(Grease Pencil)

工具，请按

Q

。

1. 在“时间滑块”(Time Slider)上单击鼠标右键，然后执行下列任意操作：

  - 选择“油性铅笔 > 删除帧 > 全部”(Grease Pencil > Delete Frames > All)可从场景删除所有油性铅笔图像。

  - 选择“油性铅笔 > 删除帧”(Grease Pencil > Delete Frames) > *<camera name>* 以仅删除特定摄影机上的帧。

  - 在某些情况下，您可以选择“油性铅笔 > 删除帧”(Grease Pencil > Delete Frames) > greasePencilSequence*<n>* （其中 n 是一个顺序编号），以清除保留在场景中的但不是以特定摄影机为父对象的所有油性铅笔节点。

    （如果剪切一个序列中的最后油性铅笔帧，或如果您在使用“面板 > 沿选定对象观看”(Panels > Look Through Selected )所创建的临时摄影机上创建了油性铅笔帧，这将有可能发生。）

  以下警告显示在命令行旁边，用于指示油性铅笔节点将被移除。

  // Warning: line 1: Removing grease pencil node network

  **注**

  当从单个摄影机删除帧时将显示此警告，即使油性铅笔帧保留在其他摄影机中。
