# 油性铅笔限制

- 油性铅笔在以下项中不受支持：

  - 高质量渲染器(High Quality Renderer)

  - 摄影机序列器(Camera Sequencer)

  - 为已设置动画对象的子对象的摄影机

- 时间轴中的油性铅笔帧：

  - 无法在不同摄影机之间进行剪切、复制和粘贴

  - 如果缩放关键帧，会移动到一半的帧或一部分帧

    （之所以发生这种情况，是因为油性铅笔没有遵循[“时间滑块”(Time Slider)首选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-51A80586-9EEA-43A4-AA1F-BF1370C24A64.htm)中的“捕捉到整个帧”(Snap to whole frames)设置。）

- 草图在渲染视图中不能正确渲染。

- 在 Viewport 2.0 中，油性铅笔不能与屏幕空间环境光遮挡或景深一起使用。

  （如果添加油性铅笔帧，环境光遮挡将消失。景深会模糊油性铅笔笔刷笔划。）
