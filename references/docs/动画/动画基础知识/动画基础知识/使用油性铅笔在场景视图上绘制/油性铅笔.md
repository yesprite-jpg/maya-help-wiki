# 油性铅笔

“油性铅笔”(Grease Pencil)为您在监视器中在不同时间点绘制二维草图提供了清洁和非破坏性方式。您可以绘制移动的姿势和圆弧，或生成快照和背景。可以创建单个油性铅笔草图来标记快照，或创建图像的整个序列和播放预览以生成小型手绘影片。请参见[使用油性铅笔在场景视图上绘制](../使用油性铅笔在场景视图上绘制.md)。

添加到场景中的油性铅笔草图实际上是一种连接到活动摄影机的图像平面（透视或正交），因此，如果翻滚场景，草图将保持在原位。您可以在任何透视或正交摄影机中每帧添加一个油性铅笔草图。如果最后一项操作是创建油性铅笔帧，则使用“G”热键会创建一个新的帧。“G”热键不会从头创建一个帧。
