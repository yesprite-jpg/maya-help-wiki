# 删除油性铅笔帧

从“时间滑块”(Time Slider)移除油性铅笔帧

1. 在“时间滑块”(Time Slider)中，转到您要移除的具有油性铅笔草图的帧。

2. 单击[“油性铅笔”(Grease Pencil)](../../../../动画引用/动画引用/动画工具/“油性铅笔”%28Grease%20Pencil%29工具.md)工具中的 ![图：单击“油性铅笔”(Grease Pencil)工具中的 。 将从“时间滑块”(Time Slider)中移除油性铅笔帧，…](../../../../../../assets/Maya-Animation/GUID-767EDA70-8E4A-4319-BCDB-F212B3C00B3E.png) <!-- baize:img-hook downloaded=true reason="正文 293 字 <300 且带图" -->。

  将从“时间滑块”(Time Slider)中移除油性铅笔帧，在您播放场景时图像将不再显示。

**注**

如果您已保存场景，油性铅笔图像文件将仍保存在磁盘上的默认项目目录中。（另请参见

保存和共享油性铅笔草图

。）

从磁盘中删除油性铅笔图像

1. 导航到当前项目的默认项目目录。

2. 删除任何不需要的油性铅笔图像。

**注**

提示：

若要退出

“油性铅笔”(Grease Pencil)

工具，请按

Q

。
