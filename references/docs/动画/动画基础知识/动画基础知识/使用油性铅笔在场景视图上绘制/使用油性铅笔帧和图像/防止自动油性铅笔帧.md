# 防止自动油性铅笔帧

打开“油性铅笔”(Grease Pencil)工具后，可以在向其移动了“时间滑块”(Time Slider)的任何帧上进行绘制。在[油性铅笔工具(Grease Pencil Tool)选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E489292B-6CA7-4CF1-9BDD-3BB2C180454D)菜单中关闭“自动创建帧”(Auto Create Frames)选项，可以禁用此功能。
