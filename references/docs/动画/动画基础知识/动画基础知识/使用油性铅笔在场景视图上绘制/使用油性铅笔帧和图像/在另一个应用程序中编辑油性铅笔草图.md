# 在另一个应用程序中编辑油性铅笔草图

使用油性铅笔图像保存场景后，您可以在外部应用程序（如 Autodesk® SketchBook®）中编辑草图。

您可以打开和编辑油性铅笔图像文件（当它们被保存在磁盘上时）：

若要导入归档的[“油性铅笔”(Grease Pencil)](../../../../动画引用/动画引用/动画工具/“油性铅笔”%28Grease%20Pencil%29工具.md)帧，请执行以下操作：

1. 打开“油性铅笔”(Grease Pencil)工具(“视图 > 摄影机工具 > 油性铅笔工具”(View > Camera Tools > Grease Pencil Tool))。

2. 在“油性铅笔”(Grease Pencil)工具中，单击 ![图：在“油性铅笔”(Grease Pencil)工具中，单击 。将打开文件浏览器。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B885E82C-3A18-45B5-9098-15967A8280DD.png) <!-- baize:img-hook downloaded=false reason="正文 774 字 ≥300，非承重" -->。将打开文件浏览器。

3. 在“导入”(Import)文件浏览器窗口中，找到油性帧归档文件，然后单击“导入”(Import)。

  归档文件将导入场景中，所有帧位于正确的时间处。

或直接从 Maya 启动图像编辑程序，如下所示：

1. 请确保已将包含油性铅笔草图的场景保存至少一次。

2. 打开 [Hypershade 窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-252707EC-4AAF-4D3F-9600-804F783652B7)（“窗口 > 渲染编辑器 > Hypershade”(Window > Rendering Editors > Hypershade)），并切换到“纹理”(Textures)选项卡。

3. 选择包含要编辑的草图的 GreasePencil 文件。

4. 打开[属性编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)，然后单击“图像名称”(Image Name)字段下的“编辑”(Edit)。

  Maya 将打开已设置为打开系统上 .png 文件的图像编辑应用程序。请参见[指定默认媒体播放器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D4284B32-3B66-4712-BAA0-66BA6DB08187)，了解有关更改启动应用程序的信息。

5. 在外部应用程序中编辑和保存图像。

  **注**

  重要：

  在其他应用程序中保存油性铅笔草图时，请确保采用相同文件名以及透明背景，以便可以按预期在 Maya 中重新加载这些图像。

6. 切换回 Maya 并单击“属性编辑器”(Attribute Editor)中的“重新加载”(Reload)（在“图像名称”(Image Name)字段下），来重新加载更新的油性铅笔图像。
