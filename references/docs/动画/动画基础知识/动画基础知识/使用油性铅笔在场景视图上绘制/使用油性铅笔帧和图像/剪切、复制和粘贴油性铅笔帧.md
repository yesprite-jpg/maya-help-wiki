# 剪切、复制和粘贴油性铅笔帧

您可以使用与操纵关键帧基本相同的方式来操纵“时间滑块”(Time Slider)上的油性铅笔帧。

1. 在“时间滑块”(Time Slider)中选择您需要的帧（或按住 Shift 键并选择多个帧），然后单击鼠标右键，并选择“剪切”(Cut)、“复制”(Copy)或“粘贴”(Paste)。

**注**

- 油性铅笔帧不能在不同的摄影机之间剪切、复制和粘贴。

- 如果选定帧在时间轴上同时显示油性铅笔草图和关键帧，该操作会剪切、复制和粘贴两者。

- 如果您剪切了序列中最后一个油性铅笔帧，greasePencilSequence 节点将保留在场景中，直到您通过在“时间滑块”(Time Slider)上单击鼠标右键，然后选择“油性铅笔 > 删除帧”(Grease Pencil > Delete Frames) > greasePencilSequence 将其删除。
