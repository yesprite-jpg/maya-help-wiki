# 播放预览油性铅笔图像序列

在不同时间点绘制了一系列油性铅笔图像后，可以播放预览这些图像以创建一个快速的二维动画影片。

播放预览油性铅笔草图

1. 确保“油性铅笔”(Grease Pencil)在面板“显示 > 播放预览显示”(Show > Playblast Display)的选项中处于启用状态。

2. 选择窗口 > 播放预览(Window > Playblast)，或参见[播放预览动画](../../预览动画/播放预览动画.md)获得详细信息。
