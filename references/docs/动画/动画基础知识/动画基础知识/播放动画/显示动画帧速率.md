# 显示动画帧速率

显示场景视图中动画的帧速率

1. 选择[“显示 > 平视显示仪”(Display > Heads Up Display)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0E9D9594-6664-4B69-B944-8B69E9551415) > “帧速率”(Frame Rate)。

  帧速率显示在当前视图的右下侧。
