# 应用动画快照

以下示例说明了如何使用动画快照创建类似于楼梯的模型。

使用动画快照

1. 选择“创建 > NURBS 基本体 > 平面”(Create > NURBS Primitives > Plane)。

  将在场景中显示一个简单的平面曲面。

  ![图：选择“创建 NURBS 基本体 平面”(Create NURBS Primitives Plane)。 将在场景中显示一…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-220B10B6-9A49-4DFB-B54A-EFC8BAD0435C.png) <!-- baize:img-hook downloaded=false reason="正文 950 字 ≥300，非承重" -->

  这将作为楼梯的底部台阶。如果需要，可以缩放平面并移动其 CV，以使平面看起来更像台阶。

  ![图：选择“创建 NURBS 基本体 平面”(Create NURBS Primitives Plane)。 将在场景中显示一…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-DBCFFA9E-C76D-4367-86AC-C096C10AA7FA.png) <!-- baize:img-hook downloaded=false reason="正文 950 字 ≥300，非承重" -->

2. 选择“动画”(Animation)菜单(按 F4 键）。

3. 平移台阶，以使其一条窄边接触世界原点。

4. 按 Insert 键或 Home 键 (Mac OS X) 以显示步长的枢轴点。

5. 将枢轴点平移到世界原点。

6. 再次按 Insert 键或 Home 键退出枢轴点模式。

7. 回放动画，并选择“关键帧 > 设置关键帧”(Key > Set Key)以在开始时间设置关键帧。

8. 为场景指定一个较短的播放范围。例如，24 帧。

9. 将“当前时间”(Current Time)指示器拖动到播放范围的末尾。

10. 将台阶沿 Y 轴向上平移约 10 个单位，然后设置一个关键帧。

  这将创建台阶垂直移动的结束位置。

11. 在“通道盒”(Channel Box)中输入 720 作为“旋转 Y”(Rotate Y)，然后设置一个关键帧（按 S 键）。

  这将创建台阶旋转的结束位置。

12. 回放并播放动画以观察台阶的移动。

13. 选择该台阶。

14. 选择“可视化 > 创建动画快照”(Visualize > Create Animation Snapshot) > ![图：选择“可视化 创建动画快照”(Visualize Create Animation Snapshot) 。 将打开“动画…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 950 字 ≥300，非承重" -->。

  将打开[“动画快照选项”(Animation Snapshot Options)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“可视化”%28Visualize%29菜单/创建动画快照选项%28Create%20Animation%20Snapshot%20Options%29.md)窗口。

15. 对于“时间范围”(Time Range)，启用“时间滑块”(Time Slider)，然后将“按时间”(By Time)设置为 1。

  这些设置将在整个“时间滑块”范围内，按照固定时间间隔创建动画几何体的快照副本。“按时间”(By Time)的值设置创建快照的时间间隔。

  而如果为“时间范围”(Time Range)选项启用了“开始/结束”(Start/End)，则可以为动画几何体输入“开始时间”(Start Time)和“结束时间”(End Time)（时间范围）。

16. 在“动画快照选项”(Animation Snapshot Options)窗口中，单击“快照”(Snapshot)按钮创建楼梯。

  请耐心等待操作完成。

  **注**

  提示：

  按 Esc 键可退出长时间的快照计算。

  ![图：在“动画快照选项”(Animation Snapshot Options)窗口中，单击“快照”(Snapshot)按钮创…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A4F86311-0647-42BA-84E0-CBBF0D06FF9E.png) <!-- baize:img-hook downloaded=false reason="正文 950 字 ≥300，非承重" -->

  原始对象和动画保持不变。在“大纲视图”(Outliner)中，台阶的副本包含在新组 snapshotGroup 下。
