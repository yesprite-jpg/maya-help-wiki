# 应用动画扫描

以下示例说明了如何使用动画扫描来创建类似于盘旋的动物触角的模型。

使用动画扫描

1. 选择“创建 > NURBS 基本体 > 圆形”(Create > NURBS Primitives > Circle)。

  一个圆将显示在场景视图中。

2. 沿 Z 轴将圆移动 8 个单位。

3. 缩放圆的大小，直到它的半径大约为 3 个单位。

4. 将圆旋转 90 度（使其垂直于栅格）。

5. 将圆的枢轴移动到原点，这样在动画中它会围绕原点旋转。（另请参见[更改枢轴点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-150B390E-840B-4FE3-B8E9-8DEBCE7CEC97)。）

6. 按 Insert 键或 Home 键以显示圆的枢轴点。

7. 在“变换属性”(Transform Attributes)条目字段中输入值 0 0 0，或者将枢轴点拖动到原点。

8. 再次按 Insert 键或 Home 键退出枢轴点模式。

  ![图：再次按 Insert 键或 Home 键退出枢轴点模式。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D76DC0FA-0AD7-4FF2-B77E-186A39D51EFD.png) <!-- baize:img-hook downloaded=false reason="正文 691 字 ≥300，非承重" -->

9. 切换到“动画”(Animation)菜单集（按 F4 键）。

10. 确保“当前时间指示器”(Current Time Indicator)位于“时间滑块”(Time Slider)的开始位置，并为圆的变换设定一个关键帧。

  这是此动画的圆的起始位置。

11. 将“当前时间指示器”(Current Time Indicator)移动到播放范围末端。

12. 将“旋转 X”(Rotate X)设定为 720，使圆大约旋转两圈。

13. 将圆向 Y 轴上方移动大约 10 个单位。

14. 将圆缩放为 0。

15. 为变换设定关键帧（按 S）。

  现在，您已建立了圆的结束状态。

16. 按“播放”(Play)查看圆的动画。

17. 选择“可视化 > 创建动画扫描”(Visualize > Create Animated Sweep) > ![图：选择“可视化 创建动画扫描”(Visualize Create Animated Sweep) 。 此时将显示创建动画扫…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 691 字 ≥300，非承重" -->。

  此时将显示[创建动画扫描选项](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“可视化”%28Visualize%29菜单/创建动画扫描选项%28Create%20Animated%20Sweep%20Options%29.md)。

18. 确保将“时间范围”(Time Range)设定为“时间滑块”(Time Slider)，并将“按时间”(By Time)值设定为 1。

19. 单击“动画扫描”(Anim Sweep)按钮。
