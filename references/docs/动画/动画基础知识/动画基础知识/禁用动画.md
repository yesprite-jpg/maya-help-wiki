# 禁用动画

禁用可以隔离特定运动，并将焦点对准它。例如，处理手臂和腿部已设置动画的模型时，可以使用禁用功能关闭手臂或腿部的动画。

可以禁用选定动画通道来暂时禁用动画，无需从已设置动画的对象断开其曲线。请参见[禁用通道](../../关键帧动画/关键帧动画/编辑曲线/禁用通道.md)。您还可以对选定对象禁用关键帧。请参见[禁用关键帧](../../关键帧动画/关键帧动画/编辑关键帧/禁用关键帧.md)。

**注**

禁用的通道在“通道盒”(Channel Box)中显示为棕色。

当禁用已设置动画的对象的关键帧或通道时，系统会为每个动画通道生成一个禁用通道。请参见[禁用节点](../../动画引用/动画引用/动画节点/禁用.md)。还可以通过为该禁用节点的状态（开/关）设置动画来禁用一段时间范围。

为禁用节点设置动画

1. 在“Hypergraph”中选择禁用节点。

2. 在“通道盒”(Channel Box)中执行以下操作：

  - 将“禁用”(Mute)设置为 1 可以打开禁用节点。

  - 将“禁用”(Mute)设置为 0 可以关闭禁用节点。
