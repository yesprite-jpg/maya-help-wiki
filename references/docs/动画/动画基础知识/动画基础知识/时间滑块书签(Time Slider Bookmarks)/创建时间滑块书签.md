# 创建时间滑块书签

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 1051 字 ≥300，非承重" -->

“时间滑块书签”(Time Slider Bookmarks)可用于标记或亮显[时间滑块(Time Slider)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-827ED8CD-C6AA-4495-8B5E-2FC98C8D49EE.htm)上的区域。

创建书签

1. 在“时间滑块”(Time Slider)上选择要添加书签的帧。（按住 Shift 键并在“时间滑块”(Time Slider)上拖动以选择帧。）

  **注**

  可以为单帧或一系列帧添加书签。

2. 单击[范围滑块(Range Slider)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9E054A1-A5D0-412C-976A-F57C0F6960B1)中的“书签”(Bookmark)图标 ![图：单击范围滑块(Range Slider)中的“书签”(Bookmark)图标 。 “书签”(Bookmark)图标位于“…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-69C40894-3EC0-46C2-A50C-CC215539EFE2.png) <!-- baize:img-hook downloaded=false reason="正文 1051 字 ≥300，非承重" -->。

  ![图：单击范围滑块(Range Slider)中的“书签”(Bookmark)图标 。 “书签”(Bookmark)图标位于“…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A76BAD3A-EC77-47A4-A490-B1EAE4F2A8FE.png) <!-- baize:img-hook downloaded=false reason="正文 1051 字 ≥300，非承重" -->

  “书签”(Bookmark)图标位于“时间滑块”(Time Slider)下方

2. 将打开[“创建书签”(Create Bookmark)窗口](“创建时间滑块书签”%28Create%20Time%20Slider%20Bookmark%29窗口.md)。由于已选择帧，因此对话框中的“开始帧”(Start frame)和“结束帧”(End frame)已填充。（**Alt **(**Option**) + **T**：创建书签(Create bookmark)）如果未选择任何帧，则将使用当前帧及其后的帧在当前时间创建单帧书签。

  ![图：单击范围滑块(Range Slider)中的“书签”(Bookmark)图标 。 “书签”(Bookmark)图标位于“…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-95335916-AD3C-493D-A442-9BF3ABDDC0FA.png) <!-- baize:img-hook downloaded=false reason="正文 1051 字 ≥300，非承重" -->

3. （可选）命名书签。

4. 为书签选择一种颜色。如果不选择颜色，将指定默认颜色。

5. 单击“创建”(Create)。书签将显示在选定帧的上方。

将光标悬停在书签上可显示书签的名称和持续时间。确保在“首选项”(Preferences)> [帮助(Help)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2B90FD26-20F6-4CF6-8A68-2DD4AD6CF334) >“弹出帮助”(Popup Help)中已启用**“显示工具动画演示”(Display Toolclips)**。

**注**

提示：

  **Alt (Option) + Shift + T**：快速创建书签(Quick Create Bookmark) - 创建不带名称的书签并指定随机颜色

  通过在书签上单击鼠标右键，可以仅访问影响此书签的设置。

## 更新书签

也可以使用新信息更新现有书签。

使用选择的帧更新书签

1. 按住 Shift 键并拖动以在“时间滑块”(Time Slider)上选择帧。

2. 在要更新的书签上单击鼠标右键。将显示[“时间滑块书签”(Time Slider Bookmark)菜单](“时间滑块书签”%28Time%20Slider%20Bookmark%29菜单.md)。

3. 单击**“使用当前选择更新书签”(Update Bookmark with selection)**。

## 编辑书签

创建书签后，在书签上单击鼠标右键，然后选择“编辑”(Edit)以显示[“创建书签”(Create Bookmark)窗口](“创建时间滑块书签”%28Create%20Time%20Slider%20Bookmark%29窗口.md)，从中可以对书签进行修改。

也可以在“时间滑块”(Time Slider)上单击鼠标右键，然后从[“动画控件”(Animation Controls)菜单](../../../动画引用/动画引用/动画工具/“动画控件”%28Animation%20controls%29菜单.md)中选择“书签管理器”(Bookmark Manager)。“书签管理器”(Bookmark Manager)可用于编辑场景中的所有书签。有关编辑书签的详细信息，请参见[书签管理器(Bookmark Manager)](时间滑块书签管理器.md)。
