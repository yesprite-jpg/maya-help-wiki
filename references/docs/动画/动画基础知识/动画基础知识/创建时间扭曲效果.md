# 创建时间扭曲效果

通过时间扭曲可以在全局级别更改动画的计时。Maya 中的时间扭曲会创建一条特定曲线，其唯一作用是修改（或扭曲）动画计时。通过时间扭曲曲线可以集中管理多条动画曲线的整体排序，而不是单独调整每条平移、旋转和缩放曲线。

有几种方法可以在动画中创建时间扭曲曲线。

- [使用时间编辑器创建和编辑时间扭曲](../../时间编辑器/时间编辑器/在时间编辑器中编辑动画/在时间编辑器中重定时动画/使用时间编辑器创建和编辑时间扭曲.md)

- [使用 Trax 创建和编辑时间扭曲](../../Maya%20中的非线性动画/Maya%20中的非线性动画/Trax%20编辑器/操纵片段/使用%20Trax%20创建和编辑时间扭曲.md)
