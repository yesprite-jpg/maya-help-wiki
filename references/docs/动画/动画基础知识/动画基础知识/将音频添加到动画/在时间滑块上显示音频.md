# 在时间滑块上显示音频

导入音频文件时，音频波形会自动显示在“时间滑块”(Time Slider)中。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-3FDF5689-3650-4942-8CF0-EFB194FCA4D3.png) <!-- baize:img-hook downloaded=false reason="正文 1172 字 ≥300，非承重" -->

**注**

提示：

通过在[颜色设置(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)（位于“动画”(Animation)区域中）中更改“声音”(Sound)色样，可以更改波形的默认颜色。

如果导入多个音频文件，那么“时间滑块”(Time Slider)会自动切换到“使用 Trax 声音”(Use Trax Sounds)模式，从而将每个声音文件表示为实线，而不是波形。

可以通过三种方法指定在“时间滑块”(Time Slider)中显示哪个音频文件

- 从“动画”(Animation)菜单集 (F4) 的[音频(Audio)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“音频”%28Audio%29菜单.md)菜单的“声音”(Sounds)区域中选择音频文件。

- 在[播放选项(Playback Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-9853B7B5-8AD5-46F6-A921-A3771A505AD1.htm)的“音量”(Volume)图标 ![图：在播放选项(Playback Options)的“音量”(Volume)图标 上单击鼠标右键，然后从场景中加载的音频文件…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A2FE50FE-BF80-4EFA-94CA-2D7DB09B34B6.png) <!-- baize:img-hook downloaded=false reason="正文 1172 字 ≥300，非承重" --> 上单击鼠标右键，然后从场景中加载的音频文件列表中进行选择。

- 在“时间滑块”(Time Slider)上单击鼠标右键，然后从显示的弹出菜单中选择“音频”(Audio)> *音频文件*。（其中 *audio file* 是要显示的音频文件的名称。）

  所选择的声音的音频文件波形显示在“时间滑块”(Time Slider)中，并在播放期间播放。

**注**

播放速度必须设置为“实时”(Real-time)，否则您只能在拖动时听到声音，但在播放过程中听不到。为此，请右键单击 Maya 的

时间滑块

，并从“播放速度”(Playback Speed)选项中选择“实时”(Real-time)。

在“时间滑块”(Time Slider)上显示多个音频文件

- 在“时间滑块”(Time Slider)上单击鼠标右键，然后选择“音频 > 使用 Trax 声音”(Audio > Use Trax Sounds)。

  波形消失，并显示一条线以表示已导入的声音文件。

## 删除音频文件

您可以从场景中禁用音频文件，也可以完全移除音频文件：

可以通过三种方法从场景中删除音频文件

- 选择“音频 > 删除声音”(Audio > Delete Sounds)

- 在[播放选项(Playback Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-9853B7B5-8AD5-46F6-A921-A3771A505AD1.htm)的“音量”(Volume)图标 ![图：在播放选项(Playback Options)的“音量”(Volume)图标 上单击鼠标右键，然后展开“删除声音”(De…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A2FE50FE-BF80-4EFA-94CA-2D7DB09B34B6.png) <!-- baize:img-hook downloaded=false reason="正文 1172 字 ≥300，非承重" --> 上单击鼠标右键，然后展开“删除声音”(Delete Sounds)卷展栏，其中显示了与场景关联的所有音频文件的列表。选择要删除的文件。

- 在“时间滑块”(Time Slider)上单击鼠标右键，选择“声音 > 删除声音”(Sound > Delete Sounds)，然后展开“删除声音”(Delete Sounds)卷展栏，其中显示了与场景关联的所有音频文件的列表。选择要删除的文件。

可以通过两种方法从“时间滑块”(Time Slider)中清除音频文件

- 在[播放选项(Playback Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-9853B7B5-8AD5-46F6-A921-A3771A505AD1.htm)的“音量”(Volume)图标 ![图：在播放选项(Playback Options)的“音量”(Volume)图标 上单击鼠标右键，然后选择“禁用”(Off)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A2FE50FE-BF80-4EFA-94CA-2D7DB09B34B6.png) <!-- baize:img-hook downloaded=false reason="正文 1172 字 ≥300，非承重" --> 上单击鼠标右键，然后选择“禁用”(Off)。

- 在“时间滑块”(Time Slider)上单击鼠标右键，然后选择“声音 > 禁用”(Sound > Off)。这将禁用音频。
