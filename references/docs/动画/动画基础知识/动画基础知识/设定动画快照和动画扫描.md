# 设定动画快照和动画扫描

使用“可视化 > 创建动画快照”(Visualize > Create Animation Snapshot) 和“可视化 > 创建动画扫描”(Visualize > Create Animation Sweep)可以从平面或曲线等动画对象生成一个新形状。请参见[应用动画快照](设定动画快照和动画扫描/应用动画快照.md)和[应用动画扫描](设定动画快照和动画扫描/应用动画扫描.md)。

动画快照以播放范围的间隔创建动画对象的副本。动画快照适用于 NURBS 或多边形几何体。不能对通过动力学和反向运动学 (IK) 设置动画的对象使用动画快照。

## 动画快照生成的几何体

如果动画快照过程中启用“构建历史”(Construction History)，可以编辑动画以影响生成的几何体。

**注**

提示：

若要使用动画快照通过表达式或反向运动学 (IK) 等动画类型创建几何体，可以使用

“关键帧 > 烘焙动画”(Key > Bake Animation)

将对象的动画类型转化为动画曲线。

由于动画快照和动画扫描会评估动画并为每个“按时间”(By Time)位置创建几何体，因此复杂的对象和动画会消耗大量时间来处理。

## 动画扫描

使用“动画扫描”通过动画的曲线创建曲面几何体。动画扫描适用于与连接到几何体的所有节点具有显式连接的动画对象变换。例如，通过动力学、反向运动学 (IK) 和自引用表达式设置动画的几何体不能用于生成的动画快照几何体。动画扫描类似于执行曲线的动画快照以及后续“放样”(Loft)操作。

一个简单的动画扫描示例就是，创建一个直径减小的螺旋管，很像动物的角。请参见[应用动画扫描](设定动画快照和动画扫描/应用动画扫描.md)。

## 启用或禁用动画快照和动画扫描计算

选择“修改 > 节点求值 > 快照”(Modify > Evaluate Nodes > Snapshots)。启用时，“快照”(Snapshots)菜单项旁边会出现一个复选标记，禁用时将会消失。

## 快照和扫描构建历史

动画快照和动画扫描创建构建历史。这意味着您可以编辑用于生成动画快照和动画扫描几何体的动画。

通过禁用构建历史，执行复杂的动画快照和动画扫描操作可以节省大量的处理时间。要删除构建历史，请选择“编辑 > 按类型删除全部 > 历史”(Edit > Delete All by Type > History)。
