# 导出 .atom 动画

使用 [Atom 导出器选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF#GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF__GUID-8E21318C-4EE9-41F8-8DF4-27F771372033)，您可以指定要导出的精确时间范围和通道。您还可以设置是否在导出的 .atom 文件中包含约束、静态值和动画层。

导出动画的步骤

1. 选择含有要导出的动画的对象。

  例如，选择角色骨架或控制装备的根对象。

  **注**

  如果选择多个层次，则选择顺序很重要。稍后导入此 .atom 文件时，还必须以希望接收导入动画的顺序来选择目标对象。

2. 选择“文件 > ATOM > 导出动画”(File > ATOM > Export Animation)。

3. 在显示的[“Maya Atom 导出器选项”(Maya Atom Exporter Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF#GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF__GUID-8E21318C-4EE9-41F8-8DF4-27F771372033)中，在“Atom 文件”(Atom file)字段中输入导出动画的文件名（然后单击 ![图：在显示的“Maya Atom 导出器选项”(Maya Atom Exporter Options)中，在“Atom 文件…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-DF281E46-00A8-46E8-A709-3672AEBA0224.png) <!-- baize:img-hook downloaded=false reason="正文 920 字 ≥300，非承重" --> 以浏览并指定位置）。

4. 设置选项来指示要导出哪些动画以及如何将它们导出到 .atom 文件。例如：

  - 选择所需的[“包含”(Include)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF#GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF__GUID-CC76012E-4D50-4491-A444-ADBBC1C2DDAE)选项，以及是否保存“设置受驱动关键帧”(Set Driven Key)动画、“约束”(Constraints)、“静态值”(Static Values)、“已烘焙动画”(Baked Animation)、“动画层”(Animation Layers)或“控制点”(Control Points)。

    **注**

    重要：

    如果选择在 .atom 文件中包含

    “约束”(Constraints)

    或

    “设置受驱动关键帧”(Set Driven Key)

    动画，则无法基于角色层次执行简单的导入。（有关详细信息，请参见

    导入 .atom 动画

    。）

  - 设定[“层次”(Hierarchy)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF#GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF__GUID-CA24D120-5F10-48B9-8048-8ECF5FAF43D8)选项来指定要从中导出动画的对象。

    **注**

    如果要基于指定的模板文件导出动画，请设定为

    “模板”(Template)

    。（请参见

    定义角色模板进行动画导出

    。）

  - 使用[“时间范围”(Time Range)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF#GUID-DFC34004-6E79-42A5-A3CD-7B9A4072D7CF__GUID-5FF5CA65-E8D3-460F-A368-49B85BC2FF5E)选项来指定要导出的动画片段。

  **注**

  提示：

  要导出单个姿势，请将

  “时间范围”(Time Range)

  设定为

  “单帧”(Single Frame)

  ，然后在

  “开始时间”(Start Time)

  字段中输入帧。

5. 单击“应用并关闭”(Apply and Close)。

  Maya 会将包含动画的 .atom 文件保存在指定的位置。

  **注**

  如果选定对象具有名称空间，则名称空间将包含在 .atom 文件中。
