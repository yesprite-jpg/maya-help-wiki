# “曲线图编辑器”(Graph Editor)颜色

[曲线图编辑器(Graph Editor)](../../曲线图编辑器%28Graph%20Editor%29.md)使用颜色指定曲线和关键帧的不同状态。

**注**

可以在

颜色设置(Color Settings)

中自定义这些颜色和其他曲线图编辑器颜色。

可以在[颜色设置(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)中自定义这些颜色，也可以在[“曲线图编辑器”(Graph Editor)“更改曲线颜色”(Change Curve Color)选项](../“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单/曲线图编辑器%28Graph%20Editor%29的更改曲线颜色%28Change%20Curve%20Color%29选项.md)（位于[“曲线图编辑器”(Graph Editor)“编辑”(Edit)菜单](../“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单.md)中）中自定义这些颜色。

## 曲线图编辑器曲线颜色

默认情况下，在“曲线图编辑器”(Graph Editor)中曲线以特定颜色表示以反映曲线所表示的轴。可以在[“曲线图编辑器”(Graph Editor)的“更改曲线颜色”(Change Curve Color)选项](../“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单/曲线图编辑器%28Graph%20Editor%29的更改曲线颜色%28Change%20Curve%20Color%29选项.md)（位于[“曲线图编辑器”(Graph Editor)“编辑”(Edit)菜单](../“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单.md)中）中自定义单个动画曲线的颜色。

#### 红色曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D4145B1A-8BA0-4F04-8B0B-3C961FC8A295.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

红色曲线指示 X 轴上的动画，无论是平移、旋转还是缩放动画。 Maya 中的红色用于表示 X 轴。

#### 绿色曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-DB39F60D-17F6-4CAE-8C84-B7C1AC30F985.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

绿色曲线指示 Y 轴上的动画，无论是平移、旋转还是缩放动画。Maya 中的绿色用于表示 Y 轴。

#### 蓝色曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A776F9C8-D929-423D-AB16-5F7156369413.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

蓝色曲线指示 Z 轴上的动画，无论是平移、旋转还是缩放动画。 Maya 中的蓝色用于表示 Z 轴。

#### 烘焙通道

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-E652A291-DE2D-44D2-B633-6735734A0ED4.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

烘焙通道会在曲线的每一帧上放置关键帧。

#### 灰色曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9E32F8EF-6604-4F88-81BA-E263EEE8D9BF.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

带有黑色关键帧的灰色曲线是锁定的曲线。

#### 淡入曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-5940C6EC-E3DF-4A2A-ADE3-888AE5A32F97.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

带有普通关键帧的淡入曲线是禁用曲线或通道。

#### 紫色曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-8226FC48-C705-4E01-8452-827EBE943E2E.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

紫色曲线是时间扭曲或速度曲线。通过时间扭曲曲线，您可以修改（或扭曲）动画计时，以便可以在一个位置管理多个动画曲线的整体序列化，而不是单独调整每个平移、旋转和缩放曲线。有关详细信息，请参见[创建时间扭曲效果](../../../动画基础知识/动画基础知识/创建时间扭曲效果.md)。

#### 暗显曲线

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-CF881627-7E01-4E87-98CE-0BF8E66A0EDB.png) <!-- baize:img-hook downloaded=false reason="正文 1448 字 ≥300，非承重" -->

淡入“曲线图编辑器”(Modern Graph Editor)的“曲线”(Curves)的曲线是引用的曲线，这意味着它们链接到被引用文件中的动画。默认情况下，它们不可编辑：这显示为黑色（锁定）关键帧。
