# “曲线图编辑器”(Graph Editor)图表视图

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B2F66856-465B-4662-9D6A-5E590558BF4C.gif) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

“曲线图编辑器”(Graph Editor)的图表视图显示动画曲线分段、关键帧和关键帧切线。

在“曲线图编辑器”(Graph Editor)中的任何位置单击鼠标右键，可打开包含“曲线图编辑器”(Graph Editor)菜单栏项目的弹出菜单。

除了工具栏中的“曲线图编辑器”(Graph Editor)工具以外，您可以使用“选择工具”(Select Tool)、“移动工具”(Move Tool)和“缩放工具”(Scale Tool)来操纵“曲线图编辑器”(Graph Editor)的图表视图中的关键帧。

## 曲线图编辑器时间标尺

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-5C0F4822-C946-4EE4-9CFE-9D6D78AEF59C.png) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

时间标尺是沿“曲线图编辑器”(Graph Editor)运行的标尺。在时间标尺中，您可以拖动时间标记以在特定位置设置关键帧。

可以在[颜色设置(Color settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)中更改时间标尺背景、时间标签（编号）以及时间标尺标记的颜色。

## “曲线图编辑器”(Graph Editor)的“播放范围着色”(Play Range Shade)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-D05F9597-803C-4628-8E60-966E962D19E5.gif) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

“曲线图编辑器”(Graph Editor) **的“播放范围着色”(Play Range Shade)**与 Maya 的[范围滑块(Range Slider)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9E054A1-A5D0-412C-976A-F57C0F6960B1)相链接，但例外情况是它控制“曲线图编辑器”(Graph Editor)图表视图中的播放范围。如果在“曲线图编辑器”(Graph Editor)中拖动“播放范围着色”(Play Range Shade)以调整播放范围的大小，则将同时调整视口底部[范围滑块(Range Slider)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9E054A1-A5D0-412C-976A-F57C0F6960B1)的大小。

若要调整“播放范围”(Play Range)的大小，请沿时间标尺拖动“播放范围着色”(Play Range Shade)（深色区域）。

## 选择工具(Select Tool)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A796F128-D706-4E45-988F-2A4ED0314383.png) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

使用“选择工具”(Select Tool)来选择图表视图中的曲线、分段、切线和关键帧。

使用鼠标按钮向下扫描以选择区域的内容。可以单击动画曲线、切线控制柄，或关键帧以选择单个条目。

## 移动关键帧工具(Move Keys Tool)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-F9E2811A-D073-4DA6-9C26-8E5FD346484F.png) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

使用“移动关键帧工具”(Move Keys Tool)选择并操纵图表视图的组件。

仅当“曲线图编辑器”(Graph Editor)处于活动状态时，“移动工具”(Move Tool)的“移动关键帧设置”(Move Key Settings)才可用。

请参见[移动关键帧工具(Move Keys Tool)](../../../动画引用/动画引用/动画工具/移动关键帧工具%28Move%20Keys%20Tool%29.md)（位于[曲线图编辑器编辑(Edit)菜单](../“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“编辑”%28Edit%29菜单.md)中）。

## 缩放关键帧工具(Scale Keys Tool)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9F97FDEB-367C-41E4-88CB-21AF46152EAD.png) <!-- baize:img-hook downloaded=false reason="正文 1365 字 ≥300，非承重" -->

使用“缩放工具”(Scale Tool)，可在图表视图中缩放动画曲线分段的区域和关键帧的位置。请参见[缩放关键帧工具(Scale Keys Tool)](../../../动画引用/动画引用/动画工具/缩放关键帧工具%28Scale%20Keys%20Tool%29.md)。

区域中的

“关键帧大小”(Key Size)

选项来更改曲线图编辑器图表视图中显示的关键帧的大小。
