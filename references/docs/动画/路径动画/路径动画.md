# 路径动画

设置对象动画以便沿三维轨迹穿过场景。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-A17735E1-D66E-4774-B58F-C11491900803.gif) <!-- baize:img-hook downloaded=false reason="正文 307 字 ≥300，非承重" -->

为一个或多个在场景中沿既定三维路径移动的对象设置动画的过程称为“路径动画”。该路径称为“运动路径”，与用来编辑动画的[运动轨迹](../动画基础知识/动画基础知识/预览动画/运动轨迹.md)明显不同。可通过以下两种方式创建路径动画：

- 使用曲线工具创建路径，或者确定现有路径并将对象连接到该路径。

- 移动对象，使其穿过场景中的一系列位置，从而创建一条经由这些位置的路径。

默认情况下，已设置动画的对象与沿路径全长的路径方向一致。创建基本路径动画后，可以通过各种不同的方式对其进行细化，如下所示：

- 重新定形路径。

- 将对象的方向更改为沿整个路径的路径或路径的特定部分。

- 为对象设置动画，使其在路径中围绕曲线变形（弯曲）。

- 更改对象沿整个路径或特定路径部分移动的速度。
