# 编辑运动路径

查看路径动画后，您可能希望更改对象的路线，或者提高或降低对象移动的平滑度。根据路径的创建方式，路径上可能存在可用于重新定形路径的编辑点或控制顶点。如果这些点无法提供足够的控制，则可添加更多点。编辑点直接位于路径上并可精确控制路径对齐，但可能会创建锐角。控制顶点是用于构造曲线的切线相交点，移动这些顶点会使曲线更改更平滑。

以下过程介绍了基本曲线编辑。有关详细信息，请参见[编辑 NURBS 曲线和曲面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-862176F7-BCD6-4570-A7C1-74A59F8F60FF)和[编辑 NURBS](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-42B12A89-9EAC-45E1-89D3-7D97E45D48D3)。

重新定形运动路径

1. 选择路径，然后单击鼠标右键以查看标记菜单。

2. 选择“编辑点”(Edit Point)、“曲线点”(Curve Point)或“控制顶点”(Control Vertex)。

  这些点沿路径显示。

3. 从“工具箱”(Tool Box)中选择“移动工具”(Move Tool)，然后单击要移动的点。

  对象操纵器将显示在该点上。

4. 沿任意方向移动对象操纵器以重新定形路径。

## 删除运动路径

若要删除运动路径，请选择该路径并按 Delete 键。

若要删除场景中的所有运动路径，请选择“编辑 > 按类型删除全部 > 运动路径”(Edit > Delete All by Type > Motion Paths)。

## 从运动路径分离对象

使用节点编辑器分离对象

1. 选择要从运动路径中移除的对象。

2. 将其显示在[节点编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-23277302-6665-465F-8579-9BC734228F69)中并显示其连接。

3. 选择对象与运动路径相关节点之间的每个连接，然后按 Delete 键。
