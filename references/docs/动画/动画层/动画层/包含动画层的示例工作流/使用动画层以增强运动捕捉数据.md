# 使用动画层以增强运动捕捉数据

动画层尤其适用于处理运动捕捉数据。只能编辑动画中需要更改的特定点，且不能更改其他数据。

动画层可以使用运动捕捉数据来协助解决很多常见问题，包括实体穿透、手脚振动和不稳定的地板接触。还可以使用动画层来确保对象碰到场景中的特定目标。

以下步骤介绍了一个工作流示例，其中用到了动画层的运动捕捉数据，以在角色的腕部接触地面时稳住它。

使用动画层来校正或增强运动捕捉数据

1. 将一个运动捕捉数据序列加载到场景中。

  本示例中介绍的场景带有两足动物骨架的运动捕捉数据。

  在本示例动画中，腕部在第 27 帧时与地板接触，但手的位置出现颤抖，而且并不自然。我们希望手在第 27 帧接触地面，然后在第 27 帧至第 40 帧之间保持稳定。可以修改这些帧之间的动画以在手与地面接触后保持稳定。

  ![图：将一个运动捕捉数据序列加载到场景中。 本示例中介绍的场景带有两足动物骨架的运动捕捉数据。 在本示例动画中，腕部在第 27…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9953ADD5-4175-45F9-90F0-A56862CCD404.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" -->

2. 执行以下操作，在肩部和腕部之间插入一个链解算器：

  - 从主菜单栏选择“骨架 > IK 控制柄工具”(Skeleton > IK Handle Tool)![图：从主菜单栏选择“骨架 IK 控制柄工具”(Skeleton IK Handle Tool)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" -->。

  - 选择肩部作为起始关节，然后选择腕部作为末关节。（请参见[创建 IK 控制柄](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A68E47F5-8F28-48C1-9B0F-370AA57ADDA8)。）

  - 在“IK 控制柄设置”(IK Handle Settings)中，选择“单链解算器“(Single-Chain Solver)作为“当前解算器”(Current solver)。

  **注**

  本示例采用单个链 IK 解算器，但也可以使用 HumanIK 装备上的效应器来达到相同的效果。

  在接下来的步骤中，将使用 IK 控制柄作为效应器来操纵腕部位置。

3. 选择创建好的 IK 控制柄，然后选择“动画层编辑器”(Animation Layer Editor)菜单栏中的“层 > 从选定对象创建覆盖层”(Layers > Create Override Layer From Selected)。（请参见[创建动画层](../创建动画层/创建动画层.md)。）

  将在“动画层编辑器”(Animation Layer Editor)堆栈中为 IK 控制柄创建名为 AnimLayer1 的新覆盖层。

  默认情况下，所有控制柄的属性将被添加到层中，包括其“IK 融合”(IK Blend)值。（请参见[从动画层添加和移除属性](../创建动画层/添加和移除动画层中的属性.md)。）

4. 双击新层并将其重命名为“Stabilize_Hand”，然后单击 ![图：双击新层并将其重命名为“Stabilize_Hand”，然后单击 以禁用该层。 禁用该层后即可查看原始动画，并识别希望修…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-19CE71CC-E524-485F-A573-C020FDA7455B.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" --> 以禁用该层。

  禁用该层后即可查看原始动画，并识别希望修改的帧。尽管该层还不包含动画，但它处于“覆盖”(Override)模式，这会导致 IK 控制柄显示在一个无效的位置，除非禁用该层。

  默认情况下，层在禁用后会被锁定，无法接收关键帧。可以禁用“动画层编辑器”(Animation Layer Editor)中的“选项 > 锁定禁用层”(Options > Lock Muted Layers)来更改该选项。在接下来的步骤中，我们将解除锁定这个新层，以使它可以接收关键帧。

5. 播放动画以确定要稳定手/腕部的地方。

  ![图：播放动画以确定要稳定手/腕部的地方。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-EBD12A7C-78C3-4E49-ABCB-884CB41C6E37.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" -->

6. 单击 ![图：单击 解除锁定层，以便设定关键帧。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-288B6923-3007-4DBA-BBAD-246D563A2002.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" --> 解除锁定层，以便设定关键帧。

7. 选择 IK 控制柄，在第 27 帧设定一个关键帧。

  这会在第 27 帧固定 IK 控制柄的位置。（请参见[设定动画层上的对象的关键帧](../在层上设置动画/设定动画层上的对象的关键帧.md)。）

  在“动画层编辑器”(Animation Layer Editor)中，注意 Stabilize_Hand 层上的绿色“交通灯”反馈。这表示该层可用于设定关键帧。

  由于在第 3 步中为 IK 控制柄创建了层，因此在控制柄上设定的关键帧将被包含在该层上。由于该层处于“覆盖”(Override)模式，其动画将在取消禁用层并播放场景中的动画时覆盖运动捕捉数据。

8. 单击 ![图：单击 以取消禁用层并播放场景中的结果动画。 在接下来的步骤中，将设定控制柄“IK 融合”(IK blend)值的关键帧，…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9DF03F09-4C95-47AB-A3D2-9F5FD735ECEB.png) <!-- baize:img-hook downloaded=false reason="正文 1753 字 ≥300，非承重" --> 以取消禁用层并播放场景中的结果动画。

  在接下来的步骤中，将设定控制柄“IK 融合”(IK blend)值的关键帧，以使其效果（修改原始动画）被融合到多个帧中。

9. 设定控制柄“IK 融合”(IK Blend)值的关键帧，如下所示：

  - 转至第 0 帧（在希望修改手/腕部动画之前），将“IK 融合”(IK blend)值设定为 0，并设定一个关键帧。

  - 转至第 20 帧（希望修改后的动画在此处开始融合到原始数据），将“IK 融合”(IK Blend)值设定为 0，并设置一个关键帧。

  - 转至第 27 帧（希望修改后的动画在此处完全覆盖原始动画），将“IK 融合”(IK Blend)值设定为 1，并设置一个关键帧。

10. 在“曲线图编辑器”(Graph Editor)中，调整刚才设定的“IK 融合”(IK Blend)关键帧以使用线性切线。（请参见[编辑切线](../../../关键帧动画/关键帧动画/编辑曲线/编辑切线.md)和[线性](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29/“曲线图编辑器”%28Graph%20Editor%29菜单/“曲线图编辑器”%28Graph%20Editor%29%20“切线”%28Tangents%29菜单.md#GUID-43A4FE2C-4863-4EA6-B6AE-6D2B6757F6C7__GUID-809B2936-77CF-4A06-BC13-2211644D26BD)。）

  在第 27 帧后，手将与地面接触并稳定下来。

11. （可选）如果对修改感到满意，可以使用运动捕捉数据合并或烘焙修改的动画。请参见[合并动画层](../操纵动画层/合并动画层.md)和[烘焙动画层](../操纵动画层/烘焙动画层.md)。
