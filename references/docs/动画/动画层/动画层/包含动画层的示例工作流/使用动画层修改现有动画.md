# 使用动画层修改现有动画

使用动画层可以方便地扩大、减小或以其他方式编辑现有动画，而不会丢失原始工作。

例如，如果制作流程要求在完成细节工作之前完成大致的动画序列，则可以使用动画层分隔并锁定已确认的动画层，使其无法编辑，然后继续在其他层上添加细节。

下列步骤描述了使用动画层修改现有动画的常规工作流。

修改现有动画

1. 加载现有动画。

2. 选择要修改其动画的对象，然后单击“从选定对象创建层”图标 ![图：选择要修改其动画的对象，然后单击“从选定对象创建层”图标 。请参见创建动画层。 该操作会为选定对象创建动画层。默认情况下…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C8645E83-E124-4F36-9694-0C964122AC7D.png) <!-- baize:img-hook downloaded=false reason="正文 776 字 ≥300，非承重" -->。请参见[创建动画层](../创建动画层/创建动画层.md)。

  该操作会为选定对象创建动画层。默认情况下，会将对象的所有属性添加到该层。

  **注**

  无论如何选择，都可以在层上组织动画。

  可以为场景中的所有对象创建一个层，每个对象一个层，或者甚至每个要设置动画的属性一个层。

  本示例介绍了为某个层上的单个对象修改动画，但可以将来自多个对象的属性添加到一个层上。

3. 使用“通道盒”(Channel Box)或“关系编辑器”(Relationship Editor)可以将对象的属性添加到动画层以及从动画层移除对象的属性。请参见[将属性添加到动画层和从动画层移除属性](../创建动画层/添加和移除动画层中的属性.md)。

  例如，如果计划仅修改对象的 translateZ 和 translateY 值，则可以仅在层上保留这些值并移除所有其他属性。

4. 操纵该对象，然后在其 translateZ 和 translateY 值上设置关键帧。设置关键帧时，会在动画层上设定新的关键帧。请参见[设定动画层上的对象的关键帧](../在层上设置动画/设定动画层上的对象的关键帧.md)。

5. 在场景中播放结果动画，从层查看修改的动画的效果。

6. 使用动画层工具来比较修改动画后的结果与未修改动画的结果：

  - 为已设置动画的对象启用重影。请参见[显示分层动画的重影](../在层上设置动画/显示分层动画的重影.md)。

  - 切换层的“禁用”按钮 ![图：切换层的“禁用”按钮 。请参见禁用、锁定和单放动画层。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9DF03F09-4C95-47AB-A3D2-9F5FD735ECEB.png) <!-- baize:img-hook downloaded=false reason="正文 776 字 ≥300，非承重" -->。请参见[禁用、锁定和单放动画层](../在层上设置动画/禁用、锁定和单放动画层.md)。

7. （可选）请执行下列操作之一：

  - 如果对修改过的动画感到满意，可以将分层动画与原始动画合并或烘焙分层动画，然后保存结果。请参见[合并动画层](../操纵动画层/合并动画层.md)和[烘焙动画层](../操纵动画层/烘焙动画层.md)。

  - 如果希望保持原始动画不变，可以删除该动画层以丢弃修改过的动画。请参见[删除动画层](../操纵动画层/删除或清空动画层.md)。
