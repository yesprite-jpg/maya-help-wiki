# 动画层堆栈

使用创建动画层的顺序在“动画层编辑器”(Animation Layer Editor)中堆栈它们。默认情况下，层以从下到上的顺序来堆栈，这意味着新层将被添加到层窗格顶部，同时现有层将被下推。

如果愿意，可以更改堆栈以上至下的顺序显示，其中新层被添加到层窗格底部。（请参见[更改动画层堆栈显示](../视图分层动画/更改动画层堆栈显示.md)）。

**注**

在本文档中，假定了默认堆栈显示。

无论选择以哪种方式显示堆栈，动画层始终有效地堆栈在基础动画(BaseAnimation)顶部。

## 求值顺序

可以更改堆栈中的单个层顺序来组织层（请参见[重新排序和设置动画层父子关系](../对动画层重新排序.md)），但是很重要的一点是，首先了解这可能影响结果动画的方式。

更改堆栈中的层顺序会更改 Maya 计算结果动画的顺序。如果您的层都不共享同一属性，则计算顺序无关紧要，同时重新排列层不会更改结果。

如果不止一个层上的关键帧具有相同的属性，以下层模式会在重新排列层时影响结果动画：

- [动画层模式](动画层模式.md)

  [“覆盖”(Override)模式](动画层模式.md#WS1A9193826455F5FF6026605B1181237E9461603)中的动画层会阻塞来自任何之前具有共享属性层的动画。更改“覆盖”(Override)层的位置会更改它要覆盖的层。

  大多数情况下，在[“相加”(Additive)模式](动画层模式.md#WS1A9193826455F5FF6026605B1181237E94615FF)中更改层顺序不会更改结果。但是，如果“相加”(Additive)层包含布尔属性（如可见性）或枚举类型属性，在“覆盖”(Override)模式中始终会计算这些属性。

- 旋转累积(Rotation Accumulation)（位于[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)主题中）

- 缩放累积(Scale Accumulation)（位于[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)主题中）

此外，重新排列共享属性的层会影响哪个层接收关键帧。在所有这三种层设置关键帧模式中，层在堆栈中的顺序会影响 Maya 考虑它们接收关键帧的顺序。有关每一设置关键帧模式以及 Maya 如何管理接收关键帧层的详细信息，请参见“选项”菜单（位于[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)主题中）中的“选定层中的关键帧”(Key in Selected Layer(s))、“上一活动层中的关键帧”(Key in Last Active Layer(s))和“混合”(Hybrid)。

## 动画层层次

可以建立和断开动画层的父子关系，以在堆栈中创建一个层次，允许您以逻辑方式组织和编组动画层。请参见[建立和断开动画层的父子关系](../对动画层重新排序/建立和断开动画层的父子关系.md)。

如果将层组织到层次中，需要注意的是，父层的状态会以以下方式影响子层：

- 禁用父层会禁用其子层。当它们的父对象被禁用时，不能取消禁用子层，尽管它们可以独立于父对象被禁用。

- 子对象层的权重受其父对象权重的影响。通过将其自己的“权重”(Weight)值与其父对象的“权重”(Weight)值相乘，计算结果动画中的子对象权重。

  例如，如果子层的“权重”(Weight)为 1，同时其父对象层的“权重”(Weight)为 0.5，则会在结果中播放子层动画的一半。

  **注**

  提示：

  如果仅使用父层来组织子层组，可以将父层留空，同时保持其“权重”(Weight)被设定为 1。这避免了父对象和子对象权重相乘所产生的任何问题。

- 默认情况下，如果其父层收拢并取消选择，子层将被取消选择，同时在其收拢的父对象被选定时选定。使用[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)主题的“选项”(Options)菜单中的“选择收拢的父对象下的子对象”(Select Children Under Collapsed Parent)选项，可以更改此行为。

  根据选定的层设置关键帧模式，子层仍可接收关键帧，即使它们的父对象层收拢，同时被取消选择。有关每一设置关键帧模式的信息，请参见[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)主题中的“选项”(Options)菜单。
