# 动画层状态

动画层的状态决定它是否接收关键帧，以及是否在其他窗口和编辑器中显示其信息。动画层可以被描述为以下状态：

- **活动**：如果层要接收关键帧，它就是活动的。“动画层编辑器”(Animation Layer Editor)中显示的活动层的层名称旁边带一个绿色圆点![图：活动：如果层要接收关键帧，它就是活动的。“动画层编辑器”(Animation Layer Editor)中显示的活动层的…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-4772FE35-6E5B-43A0-A072-2354B3057420.png) <!-- baize:img-hook downloaded=false reason="正文 325 字 ≥300，非承重" -->。可以同时有多个活动的层。

- **受影响**：如果层包含当前选定对象的属性，但是不是活动的，它就会受影响。“动画层编辑器”(Animation Layer Editor)中显示的受影响层的层名称旁边带一个红点![图：受影响：如果层包含当前选定对象的属性，但是不是活动的，它就会受影响。“动画层编辑器”(Animation Layer E…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-5E48AECF-F04E-4CAA-B949-FAEB71664207.png) <!-- baize:img-hook downloaded=false reason="正文 325 字 ≥300，非承重" -->。

- **选定**：如果层在“动画层编辑器”(Animation Layer Editor)中亮显，它就已被选定。选定层不一定是活动的，具体取决于选择的设定关键帧模式。
