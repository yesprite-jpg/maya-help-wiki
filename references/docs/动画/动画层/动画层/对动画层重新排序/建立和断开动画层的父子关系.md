# 建立和断开动画层的父子关系

可以建立动画层的父子关系，以在“动画层编辑器”(Animation Layer Editor)中创建层次关系。有关父子层关系的详细信息，请参见[动画层层次](../了解分层动画/动画层堆栈.md#WS1A9193826455F5FF6026605B1181C8F4F2E-14C9)。

建立动画层的父子关系

1. 选择要使其成为另一个层的子级的动画层。

2. 按住鼠标中键将该层拖放到其父层上。

  选定层成为将其拖动到的层的子层。

**注**

提示：

如果父层已具有其他子层，可以展开父层并将新的子层放到层次中的任意位置。如果将新的子层放到收拢的父层上，它将放置在层次中子层的最后一个位置。

断开动画层的父子关系

1. 选择要断开父子关系的子动画层。

2. 按住鼠标中键将层拖动到堆栈顶级的任何位置。

  选定层不再是子层。

  **注**

  提示：

  您也可以断开层的父子关系，并通过按住鼠标中键将其拖动到

  “基础动画”(BaseAnimation)

  栏来自动将其放置在堆栈的顶部。
