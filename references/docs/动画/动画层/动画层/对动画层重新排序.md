# 对动画层重新排序

动画层在“动画层编辑器”(Animation Layer Editor)堆栈中的顺序非常重要，因为这会影响在场景中计算结果动画的方式。有关动画层顺序如何影响结果的详细信息，请参见[动画层堆栈](了解分层动画/动画层堆栈.md)。

对层重新排序

1. 选择要重新排序的动画层。

2. 执行下列操作之一：

  - 使用鼠标中键将动画层拖到堆栈中的新位置。

    **注**

    使用此方法，可以在对层重新排序的同时设置层的父关系。

    拖动时，将显示一条黑线或矩形轮廓，指示将放置层的位置。如果该层将置于两个层之间，则会显示一条黑线。如果将为层设置父关系，则会在将成为其父级的层的周围显示一个矩形轮廓。
