# 动画层编辑器

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-4AB6AA8F-094A-422B-981B-D2867DCC6E66.png) <!-- baize:img-hook downloaded=false reason="正文 1078 字 ≥300，非承重" -->

访问动画层编辑器：

- 切换到“通道盒”(Channel Box)下面的“动画”(Anim)选项卡。

- 若要将“动画层编辑器”(Animation Layer Editor)作为单独的窗口打开，请切换到“通道盒”(Channel Box)底部的“动画”(Anim)选项卡，然后从“动画层编辑器”(Animation Layer Editor)菜单栏中选择“显示 > 浮动窗口”(Show > Floating Window)。

“动画层编辑器”(Animation Layer Editor)允许您操纵动画层和更改动画层融合在一起以创建结果动画的方式。

**注**

您也可以在

时间编辑器

片段上创建层，以便修改现有片段动画。请参见

将片段层添加到时间编辑器

。时间编辑器片段层的行为与 Maya 动画层类似，但这些层专用于时间编辑器片段，因为您无法同时使用动画层和片段层驱动时间编辑器动画。

动画层编辑器包含菜单栏、工具栏和动画层窗格。
