# 合并动画层

可以将多个动画层合并在一起，以创建一个包含所有相同对象、属性和动画的层。

可以使用默认合并选项合并动画层，或打开“合并层选项”(Merge Layers Options)以指定如何进行合并。

使用默认选项合并动画层

1. 选择要合并的层。

  **注**

  选择顺序无关紧要。将根据层在堆栈中的顺序合并这些层。

2. 执行下列操作之一：

  - 单击鼠标右键，并从弹出菜单中选择“合并层”(Merge Layers)。

  - 从“动画层编辑器”(Animation Layer Editor)菜单栏中选择“层 > 合并层”(Layers > Merge Layers)。

    将从合并的层创建一个包含所有对象、属性和动画的新层。

    将从堆栈中删除合并的层，新层将取代堆栈中位置最低的合并层。

1. 选择要合并的层。

  - 从“动画层编辑器”(Animation Layer Editor)菜单栏中选择“层 > 合并层”(Layers > Merge Layers) ![图：从“动画层编辑器”(Animation Layer Editor)菜单栏中选择“层 合并层”(Layers Merge …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 558 字 ≥300，非承重" -->。

3. 根据需要设定合并选项。（请参见[动画层编辑器菜单栏](../动画层编辑器/动画层编辑器菜单栏.md)中的“合并层”(Merge Layers)部分）。

4. 单击“烘焙”(Bake)。

  将从合并的层创建一个包含所有对象、属性和动画的新层。
