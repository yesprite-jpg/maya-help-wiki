# 烘焙动画层

可以像烘焙其他关键帧动画一样烘焙层中的动画。使用“烘焙模拟选项”(Bake Simulation Options)，您可以选择是否要在烘焙之后保留原始动画层。

烘焙层中的动画

1. 选择场景中您要烘焙其分层动画曲线的对象。

2. 从主菜单栏中，选择“关键帧 > 烘焙动画”(Key > Bake Animation) > ![图：从主菜单栏中，选择“关键帧 烘焙动画”(Key Bake Animation) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 583 字 ≥300，非承重" -->。

3. 在[“烘焙模拟选项”(Bake Simulation Options)](../../../动画引用/动画引用/“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/烘焙模拟选项%28Bake%20Simulation%20Options%29.md)窗口中，选择您要使用的烘焙选项。例如：

  - 使用“烘焙到”(Bake To)选项以指定您希望将动画烘焙到基础动画(BaseAnimation)还是新层中。

  - 如果您要在所选对象的动画烘焙后将其属性从所有关联的层移除，请将“烘焙层”(Baked layers)设置为“移除属性”(Remove Attributes)。

    **注**

    注意：

    当

    “烘焙层”(Baked layers)

    设置为

    “移除属性”(Remove Attributes)

    时，所选对象的关键帧将从所有未禁用的关联层移除。如果您的工作流将使用类似 take 的层，则会禁用所有您要在烘焙层之前保留的带关键帧的层。

  - 如果您不需要结果动画的每帧都具有一个关键帧，请启用“智能烘焙”(Smart Bake)。

  ![图：在“烘焙模拟选项”(Bake Simulation Options)窗口中，选择您要使用的烘焙选项。例如： 使用“烘焙到…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-359B89F6-49E0-463D-8BD5-0C82FA6A8DDD.png) <!-- baize:img-hook downloaded=false reason="正文 583 字 ≥300，非承重" -->

4. 单击“烘焙”(Bake)。

  根据您选择的选项，选定对象中的动画将与场景中的基础动画(BaseAnimation)合并，或者将称为 “BakeResultsn” 的新层将添加到堆栈中。
