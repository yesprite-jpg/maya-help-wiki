# 复制动画层

有两种方法可以复制动画层。可复制动画层以创建具有相同对象和属性的重复层；也可复制层以创建具有相同对象、属性和动画的重复层。

复制含有动画的动画层

1. 选择要复制的动画层。

2. 执行下列操作之一：

  - 单击鼠标右键，并从弹出菜单中选择“复制层”(Copy Layer)。

  - 从“动画层编辑器”(Animation Layer Editor)菜单栏中选择“层 > 复制层”(Layers > Copy Layer)。

  包含相同对象、属性和动画的重复层将创建和放置在堆栈中的选定层下。

复制不含动画的动画层

1. 选择要复制的动画层。

2. 执行下列操作之一：

  - 单击鼠标右键，并从弹出菜单中选择“复制层(无动画)”(Copy Layer (No Animation))。

  - 选择“层 > 复制层(无动画)”(Layers > Copy Layer (No Animation))。

  包含相同对象和属性的重复层（但没有动画）将创建和放置在堆栈中的选定层下。
