# 在层上设置动画

## 加载现有动画以使用层

加载现有动画并开始创建动画层时，可以使用“基础动画”(BaseAnimation)栏访问“动画层编辑器”(Animation Layer Editor)中的现有动画。

加载现有动画以使用层

1. 加载包含现有动画的场景。

2. [创建动画层](创建动画层/创建动画层.md)。（可以创建一个空动画层，或为选定对象创建一个动画层。）

  尽管仅创建了一个层，也将注意到“基础动画”(BaseAnimation)栏显示在“动画层编辑器”(Animation Layer Editor)中。通过“基础动画”(BaseAnimation)栏可以使用层工具访问现有动画。

3. （可选）如果在层上工作时不希望原始的非分层动画曲线接收关键帧，请单击以锁定“基础动画”(BaseAnimation)栏。

  可以锁定“基础动画”(BaseAnimation)栏，但是因为它不是一个层，所以无法禁用它，单放它，或将它设置为其他层的子层。若要禁用或单放“基础动画”(BaseAnimation)栏所表示的动画，请将它提取到某个层上。请参见[将动画提取到动画层或从动画层提取动画](操纵动画层/将动画提取到动画层或从动画层提取动画.md)。

  **注**

  您还可以将层添加到

  时间编辑器

  中的现有动画，但要执行该操作，您必须使用时间编辑器片段层。您无法同时使用动画层和片段层驱动动画，因为这会产生冲突。请参见

  将片段层添加到时间编辑器

  。
