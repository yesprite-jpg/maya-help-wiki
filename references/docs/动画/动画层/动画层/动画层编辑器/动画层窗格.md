# 动画层窗格

动画层窗格中显示动画层的堆栈。有关堆栈本身的信息，请参见[动画层堆栈](../了解分层动画/动画层堆栈.md)。

“动画层”(Animation Layer)窗格包含三个影响堆栈中动画层的主要组件：

- 动画层按钮

- 活动关键帧反馈

- 权重滑块

每个组件如下所述。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-4D2DC31B-07F7-4547-9D1E-3441640CC454.png) <!-- baize:img-hook downloaded=false reason="正文 1475 字 ≥300，非承重" -->

使用“显示”(Show)菜单中的选项，可以指定希望动画层窗格显示创建的所有动画层（“显示 > 所有层”(Show > All Layers)），还是仅显示包含在场景中选择的对象属性的动画层（“显示 > 所有受影响层”(Show > All Affected Layers)）。

可以使用“动画层”(Animation Layer)窗格[重新排序动画层](../对动画层重新排序.md)（在堆栈中上移或下移层），或者[建立和断开动画层的父子关系](../对动画层重新排序/建立和断开动画层的父子关系.md)。也可以[更改动画层堆栈显示](../视图分层动画/更改动画层堆栈显示.md)来翻转堆栈中层的显示。

在动画层上设置对象的关键帧后，将在该窗格中的每一层上显示活动关键帧反馈。

## 动画层按钮

动画层按钮显示在堆栈中每个动画层的旁边。

“选项”(Options)

菜单中的

“右侧按钮”(Buttons on Right)

可更改这些按钮的显示位置。

## 活动关键帧反馈

动画层窗格中每层上的可视化反馈显示，如果在当前时间设定关键帧，则将为哪一层设定关键帧。每个动画层的状态取决于在“选项”(Options)菜单中选择的关键帧模式。（请参见[动画层状态](../了解分层动画/动画层状态.md)和[为动画层上的对象设定关键帧](../在层上设置动画/设定动画层上的对象的关键帧.md)。）

## 权重滑块

使用“权重”(Weight)滑块可以控制结果中播放层的动画的程度。

默认情况下，动画层的“权重”(Weight)值设定为 1，意味着来自该层的动画将在结果中完全播放。将“权重”(Weight)值设定为 0 可有效地禁用层，这样便不会在场景中播放该层的任何动画。

请参见[动画层权重](../了解分层动画/动画层权重.md)。
