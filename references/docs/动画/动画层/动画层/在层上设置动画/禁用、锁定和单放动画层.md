# 禁用、锁定和单放动画层

您可以使用[动画层按钮](../动画层编辑器/动画层窗格.md#WS73099CC142F487552A50A53111913E7C26F-71D0)来禁用、锁定和单放单个动画层。[动画层按钮](../动画层编辑器/动画层窗格.md#WS73099CC142F487552A50A53111913E7C26F-71D0)也适用于动画层的重影选项。

**注**

提示：

也可以[选择动画层节点](选择动画层节点.md)，然后使用“通道盒”(Channel Box)或“属性编辑器”(Attribute Editor)来设定打开或关闭层的禁用、锁定和单放属性。

禁用层

1. 在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的禁用 ![图：在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的禁用 按钮。 禁用动画层时，该符号变…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-19CE71CC-E524-485F-A573-C020FDA7455B.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" --> 按钮。

  禁用动画层时，该符号变为红色 ![图：禁用动画层时，该符号变为红色 ，并且层名称显示为灰色。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9DF03F09-4C95-47AB-A3D2-9F5FD735ECEB.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" -->，并且层名称显示为灰色。

  **注**

  禁用父层时，也禁用了其子层。

单放层

1. 在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的单放 ![图：在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的单放 按钮。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-1A7596D3-68CA-48DB-BFB5-D1964536DFBC.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" --> 按钮。

**注**

如果单放一个或多个动画层，则自动激活所有其他层的“禁用”选项，因此只有单放层的动画才回放。

您也可以使用“唯一只用”(Exclusive Solo)选项快速单放选定的动画层，以及禁用所有其他动画层。

唯一只用动画层

1. 选择要单放的动画层。

2. 从弹出菜单中单击鼠标右键，并选择“唯一只用”(Exclusive Solo)。

  单放选定的动画层，而禁用所有其他动画层。

锁定一个动画层

1. 在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的锁形 ![图：在“动画层编辑器”(Animation Layer Editor)中单击层名称旁边的锁形 按钮。 该层已锁定 ，不再接收…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-7F7C1290-B782-4EF6-954C-26C49E888867.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" --> 按钮。

  该层已锁定 ![图：该层已锁定 ，不再接收关键帧。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-288B6923-3007-4DBA-BBAD-246D563A2002.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" -->，不再接收关键帧。
