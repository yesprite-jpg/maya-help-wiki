# 查看层权重动画

可以在“时间滑块”(Time Slider)、“曲线图编辑器”(Graph Editor)或“摄影表”(Dope Sheet)中查看动画层本身的可设置动画属性（如“权重”(Weight)）。

若要设置这些动画编辑器以显示所选层的权重动画，请执行以下操作：

在时间滑块中查看层的权重动画

1. 在“时间滑块”(Time Slider)上单击鼠标右键，然后选择“显示关键帧 Tick > 显示层权重”(Display Key Ticks > Show Layer Weight)（如果还未启用）。

  动画层的权重关键帧将显示在“时间滑块”(Time Slider)中。

在“曲线图编辑器”(Graph Editor)中查看层的权重动画

1. 打开“曲线图编辑器”(Graph Editor)，在大纲视图区域中单击鼠标右键，然后选择“自动展开层”(Auto-expand layers)（如果还未启用）。

2. 再次在大纲视图区域中单击鼠标右键，然后选择“动画层过滤器 > 显示层权重”(Animation Layers Filter > Show Layer Weight)（如果还未启用）。

  用于层的权重显示的曲线。

在“摄影表”(Dope Sheet)中查看层的权重动画

1. 打开“摄影表”(Dope Sheet)，在大纲视图区域中单击鼠标右键，然后选择“动画层过滤器 > 显示层权重”(Animation Layers Filter > Show Layer Weight)。
