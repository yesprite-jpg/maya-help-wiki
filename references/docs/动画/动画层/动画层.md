# 动画层

在场景中创建并融合多个级别的动画，而不破坏原始动画。

使用动画层可以在一个场景中创建和融合多个级别的动画。创建层之后可用于组织新的关键帧动画，或者用于在不覆盖原始曲线的情况下在现有动画顶层设定关键帧。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-C16FC21C-55F9-453F-87A3-0002A9738557.png) <!-- baize:img-hook downloaded=false reason="正文 1043 字 ≥300，非承重" -->

动画层将动画保持在场景中，每层均包含关于各自指定属性的动画曲线。动画层以堆叠形式出现在“动画层编辑器”(Animation Layer Editor)中，并根据各种设置的情况而定融合在一起，从而创建在场景中播放的结果动画。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-F225637A-3B65-40DA-BDCF-3EF83F741C0E.png) <!-- baize:img-hook downloaded=false reason="正文 1043 字 ≥300，非承重" -->

例如，您可能会加载一个动画序列，其中有一个角色在奔跑和跳跃，然后您希望在顶层创建一个新的动画层，以尝试修改跳跃动作。可以观看原始动画，以确定要在 Y 轴哪一点的位置上放大角色的运动，然后在新层上设定关键帧，以便查看 translateY 值的更改如何影响跳跃动作。如果对修改后的跳跃动作感到满意，则可选择合并动画层。如果决定保留原始动画不变，则可丢弃该层。

您可能对 2D 图像编辑程序中分层功能的使用比较熟悉。除了期望的基本层功能外，Maya 动画层还可用于：

- 在不覆盖原始曲线的情况下修改动画。

  （[使用动画层修改现有动画](动画层/包含动画层的示例工作流/使用动画层修改现有动画.md)）

- 对您为各种对象和属性设定的关键帧进行追踪记录。

  （例如，请参见[为单独动画层上的两个角色设置关键帧](动画层/包含动画层的示例工作流/为单独动画层上的两个角色设置关键帧.md)。）

- 在不影响其他元素的情况下，更改场景的特定元素。

  （例如，[使用动画层以增强运动捕捉数据](动画层/包含动画层的示例工作流/使用动画层以增强运动捕捉数据.md)。）

- 将一个或多个对象和属性指定到单独的层上。

  （[从动画层添加和删除属性](动画层/创建动画层/添加和移除动画层中的属性.md)）

- 设定是否用层来覆盖堆叠中较低的层。

  （[设定动画层模式](动画层/创建动画层/设定动画层模式.md)）

- 通过互相之间结成父子关系来组织层。

  （[建立和断开动画层的父子关系](动画层/对动画层重新排序/建立和断开动画层的父子关系.md)）

- 使用层的结成父子关系、覆盖层和禁用功能的组合来创建动画录制。

  （[将动画层用作 Take](动画层/包含动画层的示例工作流/将动画层用作%20Take.md)）

**注**

您还可以将层添加到

时间编辑器

中的现有动画，但要执行该操作，您必须使用时间编辑器片段层。您无法同时使用动画层和片段层驱动动画，因为这会产生冲突。请参见

将片段层添加到时间编辑器

。

与 2D 图像编辑程序类似，Maya 中的动画层也可以执行以下操作：

- 重新组织并更改层的顺序。

  （[对动画层重新排序](动画层/对动画层重新排序.md)）

- 对每一层的效果禁用、取消禁用和设置权重。

  （请参见[禁用、锁定和单放动画层](动画层/在层上设置动画/禁用、锁定和单放动画层.md)和[为动画层的权重设置关键帧](动画层/在层上设置动画/为动画层的权重设置关键帧.md)。）

- 进行增量更改并比较不同层上的结果。

- 预览和测试更改。

  （[显示分层动画的重影](动画层/在层上设置动画/显示分层动画的重影.md)）

- 合并层。

  （[合并动画层](动画层/操纵动画层/合并动画层.md)）

“动画层编辑器”(Animation Layer Editor)可为您提供创建和操纵动画层所需的所有工具和选项。

有关您可以对动画层执行的操作的详细信息，请参见[包含动画层的示例工作流](动画层/包含动画层的示例工作流.md)。若要开始在层上创建动画，请参见[创建动画层](动画层/创建动画层/创建动画层.md)和[在层上设置动画](动画层/在层上设置动画.md)。
