# 删除几何缓存

删除所有几何缓存

1. 选择要删除其所有几何缓存的对象。

2. 在“动画”(Animation)菜单集中，选择“缓存 > 几何缓存 > 删除缓存选项”(Cache > Geometry Cache > Delete Cache Options)。

  对象的所有几何缓存节点和对应的缓存片段都将被删除。对象在磁盘上的几何缓存文件是否也将被删除取决于当前的“删除几何缓存选项”(Delete Geometry Cache Options)窗口设置。请参见[删除缓存选项(Delete Cache Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D5370748-09E0-44DB-B397-B2D8A269D150)。

删除几何缓存帧

1. 选择要从中删除各个几何缓存帧或一系列帧的对象。

2. 在“属性编辑器”(Attribute Editor)中，启用要从中删除帧的几何缓存并禁用所有其他缓存。

3. 在“动画”(Animation)菜单集中，选择“缓存 > 几何缓存 > 删除缓存帧”(Cache > Geometry Cache > Delete Cache Frame)。

  在“删除几何缓存帧选项”(Delete Geometry Cache Frames Options)窗口中指定的帧或一系列帧将从对象的几何缓存中删除。将对因删除帧而导致的几何缓存中的间距进行线性插值。请参见[删除缓存帧(Delete Cache Frame)选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-ADC29764-2B7E-4B27-BEF0-172FB1A00284)。
