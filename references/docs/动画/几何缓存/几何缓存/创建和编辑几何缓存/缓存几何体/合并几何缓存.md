# 合并几何缓存

您可以合并多个几何缓存以将它们烘焙到单个缓存。要合并的缓存可以按时间顺序定位，也可以不按时间顺序定位。

如果要合并的缓存在时间上重叠，则重叠的缓存的区域将根据缓存的当前输入权重设置和其任何权重贴图进行融合。

如果要合并的缓存不重叠，而是彼此之间存在间距，则将对这些间距进行线性插值，而且不会将这些间距的任何缓存数据保存到合并的缓存。例如，有三个要合并的缓存：缓存 1（帧 15-25）、缓存 2（帧 25-35）和缓存 3（帧 40-50）。合并这些缓存时，生成的合并的缓存的长度将为帧 15-50，但帧 36-39 将不包含缓存数据。

合并几何缓存

1. 选择要合并其几何缓存的对象。

2. 在“属性编辑器”(Attribute Editor)中，启用要合并的缓存并禁用所有其他缓存。将仅合并对象的已启用的缓存。

3. 在“动画”(Animation)菜单集中，选择“缓存 > 几何缓存 > 合并缓存”(Cache > Geometry Cache > Merge Caches) > ![图：在“动画”(Animation)菜单集中，选择“缓存 几何缓存 合并缓存”(Cache Geometry Cache M…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 642 字 ≥300，非承重" -->。

  此时将显示“合并几何缓存选项”(Merge Geometry Cache Options)窗口。请参见[并缓存选项(Merge Caches Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8F0F10A7-EF5F-4F74-8E03-46FC8BB22A55)。

4. 设定合并选项，然后单击“合并”(Merge)或“应用”(Apply)。

  将根据“合并几何缓存选项”(Merge Geometry Cache Options)窗口中的设置合并对象的所有已启用的缓存，同时创建一个新几何缓存节点、一个缓存文件和一个 XML 描述文件。合并的几何缓存将禁用，它们在磁盘上的对应的缓存文件不会被覆盖或删除。
