# 分离几何缓存文件

分离所有几何缓存文件

1. 选择要将其所有几何缓存文件与其分离的对象。

2. 在“动画”(Animation)菜单集中，选择“缓存 > 几何缓存 > 删除缓存”(Cache> Geometry Cache > Delete Cache) > ![图：在“动画”(Animation)菜单集中，选择“缓存 几何缓存 删除缓存”(Cache Geometry Cache D…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 601 字 ≥300，非承重" -->。

  此时将显示“删除几何缓存选项”(Delete Geometry Cache Options)窗口。请参见[删除缓存选项(Delete Cache Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D5370748-09E0-44DB-B397-B2D8A269D150)。

3. 启用“保持文件”(Keep Files)，然后单击“删除”(Delete)或“应用”(Apply)。

  对象的所有选定的几何缓存节点和片段将删除，它们在磁盘上的对应的缓存文件将与对象分离。

分离单个或多个几何缓存文件

1. 选择要将几何缓存文件与其分离的对象。

2. 在“动画”(Animation)菜单集中，选择“缓存 > 几何缓存 > 删除缓存”(Cache> Geometry Cache > Delete Cache) > ![图：在“动画”(Animation)菜单集中，选择“缓存 几何缓存 删除缓存”(Cache Geometry Cache D…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 601 字 ≥300，非承重" -->。

  此时将显示“删除几何缓存选项”(Delete Geometry Cache Options)窗口。请参见[删除缓存选项(Delete Cache Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D5370748-09E0-44DB-B397-B2D8A269D150)。

3. 启用“保持”(Keep)文件”。

4. 在“选择要删除的缓存”列表中，执行下列操作之一：

  - 单击要与对象分离的单个几何缓存的名称。

  - 按住 Shift 键并单击要与对象分离的多个几何缓存的名称。

5. 单击“删除”(Delete)或“应用”(Apply)。

  选定几何缓存的节点和片段将删除，它们在磁盘上的关联的缓存文件将于其对象分离。
