# 快照

该节点存储“摄影机序列器”(Camera Sequencer)中使用的单个快照的所有数据。

若要查看选定镜头的属性，请用鼠标右键单击快照，然后从出现的菜单中选择“属性编辑器”(Attribute Editor)。

## 摄影机快照属性

#### 镜头摄影机(Shot Camera)

该快照的活动摄影机。

#### 开始帧(Start Frame)

Maya 时间轴中的快照开始帧。

#### 结束帧(End Frame)

Maya 时间轴中的快照结束帧。

#### 序列开始帧(Sequence Start Frame)

序列时间轴中的快照开始帧。

#### 序列结束帧(Sequence End Frame)

序列时间轴中的快照结束帧。

#### 缩放(Scale)

应用于快照的 Maya 帧范围的比例因子。

#### 前保持(Pre Hold)

添加到序列时间轴中快照前面的帧的固定数。

#### 后保持(Post Hold)

添加到序列时间轴中快照后面的帧的固定数。

#### 快照名称(Shot Name)

显示并可编辑快照名称。

## 图像属性(Image Attributes)

这些属性可使您在编辑播放预览快照时使用的播放预览输出分辨率。

#### 分辨率宽度(Resolution width)

输入播放预览输出的宽度值。默认值为 1024。

#### 分辨率高度(Resolution height)

输入播放预览输出的高度值。默认值为 778。

请参见[播放预览摄影机快照](../../../Maya%20中的非线性动画/Maya%20中的非线性动画/摄影机序列器%28Camera%20Sequencer%29/播放预览摄影机快照.md)。

## 过渡属性(Transition Attributes)

#### 过渡入/出类型(Transition In/Out Type)

用于快照的“入”(In)或“出”(Out)过渡类型。

#### 过渡入/出长度(Transition In/Out Length)

“入”(In)或“出”(Out)过渡效果发生的时间量。

请参见[创建快照之间的过渡](../../../Maya%20中的非线性动画/Maya%20中的非线性动画/摄影机序列器%28Camera%20Sequencer%29/创建摄影机快照/创建快照之间的过渡.md)。
