# 动画控件(Animation controls)

用于开发动画计时的 Maya 控件包括“时间滑块”(Time Slider)、“范围滑块”(Range Slider)、“播放控件”(Playback Controls)和“播放选项”(Playback Options)。还可以从“播放选项”(Playback options)区域快速访问和编辑动画首选项。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-563CFAC7-6F3D-4E0C-A705-3D1E6687E688.png) <!-- baize:img-hook downloaded=false reason="正文 899 字 ≥300，非承重" -->

[范围滑块(Range Slider)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9E054A1-A5D0-412C-976A-F57C0F6960B1)和[播放选项(Playback Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-9853B7B5-8AD5-46F6-A921-A3771A505AD1.htm)之间是“当前角色”(Current Character)和“当前动画层”(Current Animation Layer)菜单，可显示场景中使用的任何角色集和动画层。有关详细信息，请参见[设置当前角色集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-22D2DD39-D298-4007-97F1-8C67F42CF424)和[动画层](../../../动画层/动画层.md)。

## 时间滑块(Time Slider)

“时间滑块”(Time Slider)用于控制播放范围、关键帧和播放范围内的受控关键点。“时间滑块”(Time Slider)底部的蓝色条带是[“缓存播放”(Cached Playback)状态行](../../../缓存播放%28Cached%20Playback%29/缓存播放%28Cached%20Playback%29/使用“缓存播放”%28Cached%20Playback%29以提高播放速度.md)，沿顶部的彩色条带是[时间滑块书签(Time Slider Bookmarks)](../../../动画基础知识/动画基础知识/时间滑块书签%28Time%20Slider%20Bookmarks%29.md)。

有关详细信息，请参见[时间滑块](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-827ED8CD-C6AA-4495-8B5E-2FC98C8D49EE.htm)。

## 播放控件(Playback Controls)

播放控件是用于播放和步进动画的按钮。播放范围显示在“时间滑块”(Time Slider)中。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-B4AB7BDA-DB3E-4952-814B-10DAFE28CD1F.png) <!-- baize:img-hook downloaded=false reason="正文 899 字 ≥300，非承重" -->

有关详细信息，请参见[播放控件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-277ADCBF-6277-4B32-81E0-AEB6D081153F)。

## 范围滑块(Range Slider)

范围滑块用于控制“时间滑块”(Time Slider)中反映的播放范围。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-8B0E5AE1-9C1D-447C-8D72-412B09CA7D76.png) <!-- baize:img-hook downloaded=false reason="正文 899 字 ≥300，非承重" -->

有关如何使用范围滑块调整播放范围大小的详细信息，请参见[范围滑块](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9E054A1-A5D0-412C-976A-F57C0F6960B1)。

## 播放选项(Playback Options)

“播放选项”(Playback Options)可用于更改有关动画播放的设置。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-9B1A9797-6C1C-49EA-AEFA-391A9E28A6B3.png) <!-- baize:img-hook downloaded=false reason="正文 899 字 ≥300，非承重" -->

**A.**“帧速率”(Framerate)菜单 **B.** 循环(Loop) **C.** 缓存播放(Cached Playback) **D.** 音量(Volume) **E.** 自动关键帧(Auto Key) **F.** 动画首选项(Animation Preferences)

有关其中每个设置的详细信息，请参见[播放选项(Playback Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/files/GUID-9853B7B5-8AD5-46F6-A921-A3771A505AD1.htm)。
