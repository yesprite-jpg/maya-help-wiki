# 重定时工具(Retime Tool)

在[曲线图编辑器(Graph Editor)](../../../曲线图编辑器%28Graph%20Editor%29/曲线图编辑器%28Graph%20Editor%29.md)中，单击 ![图：在曲线图编辑器(Graph Editor)中，单击 ，或选择“编辑 变换工具 重定时工具”(Edit Transform…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-96B1004C-80CD-490F-87AA-87F06CE320BE.png) <!-- baize:img-hook downloaded=false reason="正文 664 字 ≥300，非承重" -->，或选择“编辑 > 变换工具 > 重定时工具”(Edit > Transformation Tools > Retime Tool)启用“重定时工具”(Retime Tool)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-2993B3C0-419F-4771-93D0-75D73BD395C8.gif) <!-- baize:img-hook downloaded=false reason="正文 664 字 ≥300，非承重" -->

使用“重定时工具”(Retime Tool)可以使您可以直接调整动画序列中关键帧移动的计时。请参见[重定时动画](../../../关键帧动画/关键帧动画/编辑曲线/重定时动画.md)。

对于在具有多个 Autodesk 应用程序的流程中工作的动画师，类似的动画重定时工具可在 3ds Max、Softimage 和 MotionBuilder 中使用。

- 若要退出“重定时工具”(Retime Tool)，请选择任何其他工具。

- 您可以自定义“重定时工具”(Retime Tool)操纵器[颜色设置(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)窗口的颜色。

**注**

“重定时设置”(Retime Settings)

显示在

“工具设置”(Tool Settings)

窗口中，位于“曲线图编辑器”(Graph Editor)

之外。

#### 捕捉帧上的标记(Snap Markers on Frame)

启用该选项后，重定时标记会随拖动捕捉到图表视图区域中的整个帧。禁用该选项后，可以在帧之间拖放标记。（请参见[使重定时标记捕捉到帧](../../../关键帧动画/关键帧动画/编辑曲线/重定时动画/使重定时标记捕捉到帧.md)。）
