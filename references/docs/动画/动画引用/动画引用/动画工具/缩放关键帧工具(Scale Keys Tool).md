# 缩放关键帧工具(Scale Keys Tool)

在“曲线图编辑器”(Graph Editor)中，使用“缩放工具”(Scale Tool)可在图表视图中缩放动画曲线分段的区域和关键帧的位置。

**注**

可以使用

“动画”(Animation)首选项（在“设置”(Settings)下）

的

“曲线图编辑器”(Graph Editor)

区域中的

“关键帧大小”(Key Size)

选项来更改曲线图编辑器图表视图中显示的关键帧的大小。

在“缩放工具设置”(Scale Tool Settings)窗口中，可以选择两种方法在图表视图中缩放关键帧。若要显示“缩放工具设置”(Scale Tool Settings)窗口，请在“曲线图编辑器”(Graph Editor)为活动窗口时双击“缩放工具”(Scale Tool)图标。

有关详细信息，请参见[缩放关键帧](../../../关键帧动画/关键帧动画/编辑关键帧/缩放关键帧.md)和[缩放曲线](../../../关键帧动画/关键帧动画/编辑曲线/缩放曲线.md)。

选择“变换工具 > 缩放关键帧工具”(Transformation Tools > Scale Keys Tool) > ![图：选择“变换工具 缩放关键帧工具”(Transformation Tools Scale Keys Tool) 以打开以下…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 750 字 ≥300，非承重" --> 以打开以下“缩放关键帧设置”(Scale Key Settings)。

#### 类型(Type)

设定下列选项之一：

- “操纵器”(Manipulator)可以通过使用操纵器盒样式来缩放关键帧。

- “光标为中心”(Gestural)更改关键帧在图表视图中缩放的方式，使鼠标位置可确定缩放向量。

#### 仅缩放选定关键帧(Only scale selected keys)

启用该选项后，“缩放关键帧工具”(Scale Keys Tool)仅影响选定的关键帧。禁用该选项后，“缩放关键帧工具”(Scale Keys Tool)影响所有关键帧。

也可以选择“编辑 > 变换工具 > 缩放关键帧”(Edit > Transformation Tools > Scale Keys) > ![图：也可以选择“编辑 变换工具 缩放关键帧”(Edit Transformation Tools Scale Keys) 以…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Animation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 750 字 ≥300，非承重" --> 以打开“缩放关键帧”(Scale Key Tool)选项窗口。请参见[“缩放关键帧选项”(Scale Key Options)](../“动画”%28Animation%29菜单集/“关键帧”%28Key%29菜单/缩放关键帧选项%28Scale%20Keys%20Options%29.md)。
