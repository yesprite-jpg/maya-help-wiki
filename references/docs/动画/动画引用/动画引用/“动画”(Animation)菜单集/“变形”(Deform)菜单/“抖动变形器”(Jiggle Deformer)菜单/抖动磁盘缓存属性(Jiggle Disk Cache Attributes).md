# 抖动磁盘缓存属性(Jiggle Disk Cache Attributes)

- 在“动画”(Animation)、“建模”(Modeling)和“绑定”(Rigging)菜单集中：“变形 > (创建)抖动 > 抖动磁盘缓存属性”(Deform > (Create) Jiggle > Jiggle Disk Cache Attributes)

请参见 [jiggleCache](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A050D0C8-F0C0-4B45-B00F-53CFAA723C69)。
