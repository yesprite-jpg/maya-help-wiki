# “场景时间扭曲”(Scene Time Warp)菜单

## 添加场景时间扭曲

- 在“动画”(Animation) [菜单集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D90A2BDB-FD05-4528-8A95-C33A02D15129) (**F4**) 中：“关键帧 > 场景时间扭曲”(Key > Scene Time Warp) >

创建场景时间扭曲曲线，作为全局时间节点的直接输入。

**注**

场景中每次只能有一个时间扭曲曲线。

启用时，时间扭曲曲线修改时间节点生成的时间。请参见[场景时间扭曲效果](../../../../动画基础知识/动画基础知识/创建时间扭曲效果/场景时间扭曲效果.md)和[创建全局时间扭曲效果](../../../../动画基础知识/动画基础知识/创建时间扭曲效果/场景时间扭曲效果/创建全局时间扭曲效果.md)。

## 选择场景时间扭曲

选择场景时间扭曲曲线。选定时间扭曲曲线时，该曲线将在“曲线图编辑器”(Graph Editor)中显示，其属性在“属性编辑器”(Attribute Editor)中显示。

## 删除场景时间扭曲

删除场景时间扭曲曲线，从场景中移除时间扭曲效果。请参见[移除全局时间扭曲效果](../../../../动画基础知识/动画基础知识/创建时间扭曲效果/场景时间扭曲效果/移除全局时间扭曲效果.md)。

## 启用场景时间扭曲

启用时，时间扭曲曲线修改时间节点生成的时间。禁用时，时间扭曲曲线对时间节点无影响。
