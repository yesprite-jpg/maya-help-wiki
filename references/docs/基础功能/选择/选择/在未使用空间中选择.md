# 在未使用空间中选择

未使用空间为对象以外的区域。当光标位于未使用空间时，可以进行选择并调整组件。

在未使用空间中选择

1. （可选）激活调整模式（**热键：`**）。

2. 将光标移出对象。

  当光标位于选择前容差时，组件将自动亮显以用于选择。请参见[选择组件前亮显组件](选择组件前亮显组件.md)。

  **注**

  提示：

  在

  “选择”(Selection)首选项

  中调整

  “选择未使用空间”(Select dead space)

  和

  “调整未使用空间”(Tweak dead space)

  来控制选择前容差。例如，如果

  “选择未使用空间”(Select dead space)

  设置为 10，则选择前容差为 10 个像素。如果光标在对象的 10 个像素以内，这样将亮显组件。

3. 执行下列操作之一：

  - 单击以选择组件。

  - 在调整模式下，拖动以移动组件。
