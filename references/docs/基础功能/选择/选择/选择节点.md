# 选择节点

若要选择节点，请执行下列任一操作：

- 打开[大纲视图](../../节点和属性/节点和属性/大纲视图%28Outliner%29.md)，然后从列表中选择节点。

- 选择与节点关联的对象，在“属性编辑器”(Attribute Editor)中单击节点的选项卡，并在“属性编辑器”(Attribute Editor)底部单击“选择”(Select)。

- 选择与节点关联的对象，然后在“通道盒”(Channel Box)中单击该节点的标题。

- 选择与节点关联的对象，将其显示在[节点编辑器](../../节点和属性/节点和属性/使用节点编辑器创建节点网络/节点编辑器%28Node%20Editor%29.md)中，显示其连接，然后在图表中单击节点。

- 打开 [Hypergraph](../../节点和属性/节点和属性/“Hypergraph”概述.md)，选择“图表 > 输入和输出连接”(Graph > Input and Output Connections)，然后在图表中单击节点。

选定节点后，可以打开“显示操纵器工具”(Show Manipulator Tool)（“修改 > 变换工具 > 显示操纵器工具”(Modify > Transformation Tools > Show Manipulator Tool)）以显示节点的自定义操纵器。
