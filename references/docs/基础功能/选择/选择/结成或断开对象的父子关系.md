# 结成或断开对象的父子关系

通过结成对象的父子关系，您可以暂时将某些对象与其他对象关联，以便在平移父对象时，子对象会跟随移动。

结成对象的父子关系

1. 按住 Shift 键并选择一组对象。选择的最后一个对象将成为父对象。在此示例中为黄色球体。

  ![图：按住 Shift 键并选择一组对象。选择的最后一个对象将成为父对象。在此示例中为黄色球体。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-72C88153-E370-4B36-A7E7-56F88D65D54B.png) <!-- baize:img-hook downloaded=false reason="正文 610 字 ≥300，非承重" -->

2. 仍然按住 Shift 键，并按 **P** 键。最后选择的对象（在此示例中为黄色球体）将成为其他选定对象的父对象。您可以分别变换任何结成父子关系的对象，但移动父对象时，子对象会随之移动。

这些更改反映在“大纲视图”(Outliner)中，其中子对象在展开父对象时可见。

您可以在[父对象选项(Parent options)](../../基本参考/基本参考/主菜单/“编辑”%28Edit%29菜单/“父对象”%28Parent%29选项.md)中设置用于结成父子关系的不同选项，例如，设置“父对象方法”(Parent Method)。

断开对象的父子关系

1. 选择要从父组中移除的对象，在此示例中为绿色圆柱体。

  ![图：选择要从父组中移除的对象，在此示例中为绿色圆柱体。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-73145DAD-A7AF-480D-892B-044D637BE311.gif) <!-- baize:img-hook downloaded=false reason="正文 610 字 ≥300，非承重" -->

2. 按 **Shift**+**P** 将从父组中排除选定对象。

这些更改反映在“大纲视图”(Outliner)中，其中子对象在展开父对象时可见。

您可以在[断开父子关系选项(Unparent options)](../../基本参考/基本参考/主菜单/“编辑”%28Edit%29菜单/“断开父子关系”%28Unparent%29选项.md)中设置用于结成父子关系的不同选项，例如，设置“断开父子关系方法”(Unparent Method)。

**注**

如果显示警告，指出对象已经是“世界”的子对象，请在脚本编辑器中使用

-world

命令移除作为给定对象的父对象的世界。-

removeObject(-rm)

用于移除每个指定对象的直接父对象。

若要仅从父对象中移除形状的单个实例，请指定该形状的路径。如果存在单个父对象，则将从场景中删除该对象。
