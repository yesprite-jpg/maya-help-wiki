# 扩大和收缩多边形组件或 NURBS CV

扩大多边形组件或 NURBS CV 的选择

1. 选择组件或 CV。

2. 使用“选择 > 增长”(Select > Grow)进行展开，也可以按住 **Shift + .**（句点）进行展开。

**注**

扩大选择后，会将其展开至其相邻组件（即：与所选组件接触的组件）。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-AB739D52-4F3D-4A79-A435-A46B86291DE4.png) <!-- baize:img-hook downloaded=false reason="正文 314 字 ≥300，非承重" -->

此外，还可以按住 **Shift** 键并单击以选择多个部分。请注意，光标将变为 **+**（加号）以表明多个选择处于活动状态。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-6A13B398-3107-47DE-8AF4-41B4A5766CE3.gif) <!-- baize:img-hook downloaded=false reason="正文 314 字 ≥300，非承重" -->

收缩多边形组件或 NURBS CV 的选择

1. 选择组件或 CV。

2. 使用“选择 > 收缩”(Select > Shrink)。

**注**

收缩选择后，将减去所选组件的外环。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-00AB0F80-53E8-4AF4-A213-35C1AE4768E5.gif) <!-- baize:img-hook downloaded=false reason="正文 314 字 ≥300，非承重" -->

此外，还可以按住 **Ctrl** 键并单击以取消选择各个部分。光标将变为 **-**（减号）以表明单个取消选择处于活动状态。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-EDA77F50-BCB3-48C9-BA2C-7E97BE796FB2.gif) <!-- baize:img-hook downloaded=false reason="正文 314 字 ≥300，非承重" -->
