# 使对象不可选（模板）

对象模板化之后，它将显示为线框，且无法在视图中选择。如果要查看对象所在的位置、但不想将其选中，则此选项非常有用。

对象已模板化

| 目标 | 操作 |
|---|---|
| 将对象模板化，使其无法选择。 | 选择要模板化的对象，然后选择“显示 > 对象显示 > 模板”(Display > Object Display > Template)。 或 选择对象，然后打开[属性编辑器](../../节点和属性/节点和属性/查看和编辑属性/属性编辑器%28Attribute%20Editor%29.md)。在“形状”(Shape)选项卡上，打开“对象显示”(Object Display)选项并选择“模板”(Template)。 |
| 将对象的层模板化。 | 将对象添加到[显示层编辑器(Display Layer Editor)](../../场景管理/场景管理/组织对象/组织显示层中的对象/显示层编辑器.md)中的层，然后单击选定层对应的第三个框以便显示 T。有关该显示的视频，请参见[一次编辑层上的所有对象](../../场景管理/场景管理/组织对象/组织显示层中的对象/一次编辑层上的所有对象.md)。 ![图：将对象添加到显示层编辑器(Display Layer Editor)中的层，然后单击选定层对应的第三个框以便显示 T。有…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F3B5217B-9960-48ED-98E0-95AFF57F5AA8.png) <!-- baize:img-hook downloaded=false reason="正文 625 字 ≥300，非承重" --> 继续单击此框，直到它变空并使对象再次可选为止。 也可以单击此框直到出现 R 为止，在不更改显示模式的情况下使对象不可选。 |
| 选择已模板化的对象。 | 使用 [Hypergraph](../../节点和属性/节点和属性/“Hypergraph”概述.md) 或[大纲视图](../../节点和属性/节点和属性/大纲视图%28Outliner%29.md)。已模板化的节点在“Hypergraph”和大纲视图中具有不同的颜色。 或 单击状态行（工具栏）中的“按层次和组合选择”(Select by hierarchy and combinations)图标 ![图：单击状态行（工具栏）中的“按层次和组合选择”(Select by hierarchy and combinations)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-718B1103-FF85-44DA-961A-83724323607D.png) <!-- baize:img-hook downloaded=false reason="正文 625 字 ≥300，非承重" -->，然后单击选择遮罩的“模板”(Template)图标 ![图：单击状态行（工具栏）中的“按层次和组合选择”(Select by hierarchy and combinations)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-80135BE6-C2C9-4C12-B02A-612F5F0A0E33.png) <!-- baize:img-hook downloaded=false reason="正文 625 字 ≥300，非承重" -->。 |
| 使已模板化的对象再次可选。 | 选择已模板化的节点（如上所述），然后选择“显示 > 对象显示 > 取消模板”(Display > Object Display > Untemplate)。 |
