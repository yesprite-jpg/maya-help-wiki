# 通过拖选调整框选大小

您可以使用[“拖选”(Drag)](../选择样式.md#GUID-1FD959BC-DF23-49F2-B17A-35C402D18402__SECTION_BF7854AAC43B43A5B097897EFA4391D6)选项在现有框选中添加和删除组件。

| 目标 | 操作 |
|---|---|
| 使用“拖选”(Drag)选项将组件添加到框选中。 | 打开“拖选”(Drag)选项，然后按住 Shift 键并单击未选定组件，然后进行拖动。 |
| 使用“拖选”(Drag)选项将组件从框选中删除。 | 打开“拖选”(Drag)选项，然后执行以下其中一个操作： 按住 Ctrl 键并拖过选定组件。 按 Shift 键并单击选定组件，然后进行拖动。 |
| 使用 Tab 拖选选项将组件添加到框选。 | 打开“框选”(Marquee)选项时，按住 Tab 键，然后单击未选组件，进行拖动。 |
| 使用 Tab 拖选选项从框选中删除组件。 | 打开“框选”(Marquee)选项后，按住 Tab 键，然后单击选定组件，进行拖动。 |
