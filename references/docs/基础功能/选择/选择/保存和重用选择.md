# 保存和重用选择

您可以将选定对象、组件或组保存在快速选择集中。这些集有助于：

- 快速选择常用的对象集或组件集。

- 保存复杂选择，因此不必重选每个对象或组件即可稍后重用它。

如果需要将集添加到划分，也可以创建其他类型的集以供选择。有关详细信息，请参见[集和划分](../../场景管理/场景管理/组织对象/集和划分.md)。

创建快速选择集

1. 选择多个对象、对象组件或组。

2. 选择“创建 > 集 > 快速选择集”(Create > Sets > Quick Select Set)。

3. 输入集的名称。

  也可以单击“添加到工具架”(Add to Shelf)按钮，将其作为图标添加到当前工具架，以便于访问。

有关如何选择集成员、显示和隐藏集成员，将成员添加到集、从集中移除成员和删除集的信息，请参见[创建和编辑集](../../场景管理/场景管理/组织对象/集和划分/创建和编辑集.md)。
