# 选择样式

选择样式用于确定您在场景中选择组件的方法。Maya 中存在两种选择样式：“框选”(Marquee)和“拖选”(Drag)。在“工具设置”(Tool Settings)（双击“选择工具”(Select tool)图标 ![图：选择样式用于确定您在场景中选择组件的方法。Maya 中存在两种选择样式：“框选”(Marquee)和“拖选”(Drag)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-D4A44CDF-0983-41D9-BCAE-D887B17B8959.png) <!-- baize:img-hook downloaded=false reason="正文 567 字 ≥300，非承重" -->）或[建模工具包(Modeling Toolkit)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D4CD168A-34F2-465B-A39C-DE20B34E5535)中，可以设置选择样式。

## 框选

“框选”(Marquee)选择样式在您要选择的组件上绘制一个矩形框。拖动框选框，然后按住 Alt 键并将其拖到新位置，可以通过交互方式调整框选内容。

**注**

使用 Tab 键可以在两个选择样式间快速地切换。框选后按住 Tab 键可临时激活 Tab

“拖选”(Drag)

选择，可让您在现有框选中快速添加和移除组件。请参见

通过拖选调整框选大小

。

## 拖选

“拖选”(Drag)类似于没有笔刷大小的[“绘制选择”(Paint Selection)](通过绘制选择组件.md)。此选择样式可以让您将光标拖到您要选择的组件上。

通过“拖选”(Drag)选择，还可以在光标不接触顶点时进行选择，从而使选择快速而轻松。默认情况下，Maya 的选择前亮显和“拖选”(Drag)选择将亮显离光标最近的组件。

**注**

提示：

在

选择工具设置

或

建模工具包

中禁用

“亮显最近组件”(Highlight nearest component)

，以仅在光标位于组件顶部时才亮显它们。请参见

选择组件前亮显组件

。
