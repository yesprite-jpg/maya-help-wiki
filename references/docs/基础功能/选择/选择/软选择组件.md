# 软选择组件

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-34D0237E-0ED2-4D64-9520-E70023A5078D.gif) <!-- baize:img-hook downloaded=false reason="正文 733 字 ≥300，非承重" -->

按 B 键以软选择顶点、面或边

借助“软选择”(Soft Selection)，您可以采用有机的方式选择顶点、边、面、UV 甚至多个网格。它有助于在模型上创建平滑的渐变或轮廓，而不必手动变换每个顶点。或者，您也可以使用[“雕刻”(Sculpting)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DD0B15C0-5E2C-4A60-AC26-5E409B1084D8)来实现相同的效果。

其工作原理是，从选定组件到选择区周围的其他组件保持一个衰减，来创建平滑过渡效果。例如，如果在平面中心选择一个顶点并向上平移来创建钉形，同时不使用“软选择”(Soft Selection)，其侧面就会非常陡峭，这个点也会非常明晰。启用“软选择”(Soft Selection)后，渐变和尖端会更加平滑。

在 NURBS 或多边形网格上软选择组件

1. 切换到所需的组件选择模式。

2. 从“工具箱”(Tool Box)中选择一个变换工具。

3. 按 **b** 键以启用“软选择”(Soft Select)。

  **注**

  对于所有变换工具，还可以从

  ”工具设置编辑器“(Tool Settings Editor)

  中启用

  “软选择”(Soft Selection)

  并修改

  “软选择”(Soft Selection)

  设置。或者，也可以使用变换工具标记菜单（有关详细信息，请参见

  标记菜单

  ）。

4. 在场景中，将光标移至网格上以预览衰减区域。

  衰减区域以颜色渐变表示。渐变将应用到衰减区域中的所有组件。

5. 通过以下两种方法之一调整衰减区域：

  - 按住 **b** 键并单击鼠标中键向左或向右拖动，以从 0 开始增大或减小衰减区域的大小。

  - 按住 **b** 键并向左或向右拖动，以从最后一个半径值调整衰减区域的大小。

  ![图：通过以下两种方法之一调整衰减区域： 按住 b 键并单击鼠标中键向左或向右拖动，以从 0 开始增大或减小衰减区域的大小。 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-A9B22DFE-D67E-42FA-B7C3-89F431EF5E6B.gif) <!-- baize:img-hook downloaded=false reason="正文 733 字 ≥300，非承重" -->

  按住 B 键并拖动以调整选择区域的大小

6. 选择组件。

  衰减区域内的所有组件都被选中，并且会显示选定的变换工具操纵器。

7. 使用操纵器来变换位于衰减区域内的组件。

**注**

“软选择”(Soft Selection)

不会创建历史节点。
