# 仅选择未阻挡的组件

默认情况下，拖动选择会选择鼠标下的所有组件。在着色模式下查看场景时这一点会导致问题，因为您的选择可能包含视图中隐藏的组件。

可以使用“基于摄影机的选择”(Camera based selection)仅选择具有到摄影机的清晰视线的组件。这样会确保您不会意外选择看不到的组件。

仅选择未阻挡的组件

1. 执行下列操作之一：

  - 在“选择”(Selection)首选项（“窗口 > 设置/首选项 > 首选项 > 选择”(Windows > Settings/Preferences > Preferences > Selection)）中启用“基于摄影机的选择”(Camera based selection)。

    这是一个全局首选项，可为所有变换工具启用基于摄影机的选择。

  - 当有任何变换工具处于活动状态时，在“属性编辑器”(Attribute Editor)的“公用选择选项”(Common Selection Options)下启用“基于摄影机的选择”(Camera based selection)。

2. 选择场景中的对象。

  Maya 仅会从摄影机的视点选择未被其他组件阻挡的组件。

或者，也可以使用“选择”(Selection)首选项、“公用选择选项”(Common Selection Options)或“建模工具包”(Modeling Toolkit)中的“自动基于摄影机的选择”(Automatic Camera based selection)选项，让 Maya 自动在着色模式下查看场景时启用“基于摄影机的选择”(Camera based selection)，并在线框或 X 射线模式下查看时将其禁用。
