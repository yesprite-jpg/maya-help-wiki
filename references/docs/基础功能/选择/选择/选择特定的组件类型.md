# 选择特定的组件类型

下表包含选择某些组件类型的提示。它们遵循用于选择组件的相同常规图案，但说明某些选择技术或组件类型可能不明显。

**注**

提示：

您也可以使用

建模工具包(Modeling Toolkit)

来选择不同的多边形组件。请参见

“建模工具包”(Modeling Toolkit)选择模式

。

| 目标 | 操作 |
|---|---|
| 选择多边形面。 | 在多边形集上单击鼠标右键，然后选择“面”(Face)，或者按 F11 键。 通过选择每个面中心的点，或取决处于的“选择面的方式”(Select faces with)模式选择面，来选择面本身（请参见[选择首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8C8BA1F4-59EE-4A02-BFE7-9193C0D6F5BE)）。 |
| 选择多边形边。 | 在多边形集上单击鼠标右键，然后选择“边”(Edge)，或者按 F10。 |
| 选择多边形顶点。 | 在多边形集上单击鼠标右键，然后选择“顶点”(Vertex)，或者按 F9。 |
| 在曲线上选择任意点。 | 在曲线上单击鼠标右键，然后选择“曲线点”(Curve Point)。 单击并拖动以沿曲线选择点。 |
| 在曲面上选择等参线。 | 在曲面上单击鼠标右键，然后选择“等参线”(Isoparm)。 在想要运行的方向单击可见的等参线，然后拖动到所需的位置。 |
| 在曲面上选择任意点。 | 在曲面上单击鼠标右键，然后选择“曲面点”(Surface Point)。 在等参线上单击并拖动以选择曲面上的点。 |
| 选择 NURBS 曲面面片。 | 在 NURBS 曲面上单击鼠标右键，然后选择“曲面面片”(Surface Patch)。 在面片中心选择点。 |

**注**

提示：

可以通过单击并拖动以围绕要选择的对象创建选择矩形，用蚂蚁线选择多个组件。
