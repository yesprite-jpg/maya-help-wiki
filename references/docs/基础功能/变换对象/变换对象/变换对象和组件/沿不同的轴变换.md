# 沿不同的轴变换

在“移动工具”(Move Tool)、“旋转工具”(Rotate Tool)和“缩放工具”(Scale Tool)设置中，可以选择要用于变换的轴。（若要访问这些设置，请在工具箱中双击相应的工具。）

**注**

只能对发生在

“对象”(Object)

空间的缩放变换设置动画。但是，如果同时在所有三个轴上缩放对象，则此对象将始终在

“对象”(Object)

空间中缩放，不考虑当前设置。

**注**

在

“对象”(Object)

空间之外的任何空间中缩放对象均会忽略对象的缩放限制。但是，于任何空间中同时在所有三个轴上缩放对象将遵循此对象的缩放限制。

**注**

在

“对象”(Object)

空间中只能缩放对象，不能缩放组件（例如关节）。

### 沿激活的对象轴移动或缩放

可以将“移动工具”(Move Tool)或“缩放工具”(Scale Tool)设置为沿激活的对象轴移动或缩放对象。

沿激活的对象轴移动对象

1. 创建构造平面（“创建 > 构造平面”(Create > Construction Plane)）。

2. 旋转平面。

3. 选定平面后，单击“状态行”(Status Line)中的“激活”(Make Live)图标 ![图：选定平面后，单击“状态行”(Status Line)中的“激活”(Make Live)图标 ，或选择“修改 激活”(Mo…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-D74884C1-B136-4190-ACA4-866BE1EAF4B9.png) <!-- baize:img-hook downloaded=false reason="正文 888 字 ≥300，非承重" -->，或选择“修改 > 激活”(Modify > Make Live)。

4. 创建其他对象（此处为多边形圆环）。

5. 在工具箱中，双击“移动工具”(Move Tool)图标。

6. 在“移动工具”(Move Tool)选项的“移动设置”(Move Settings)部分，将“轴方向”(Axis Orientation)更改为“沿激活对象的轴”(Along Live Object Axis)。

  “移动工具”(Move Tool)操纵器控制柄将对齐到构造平面。

7. 执行下列操作之一：

  - 拖动控制柄以沿着曲面的两个方向移动圆环，或与曲面精确垂直。

  - 拖动中心控制柄或某个平面控制柄。

    圆环将捕捉到构造平面，并且移动将约束到该平面的曲面。

### 将“移动/缩放”(Move/Scale)轴的方向设置为朝向组件

可以将“移动工具”(Move Tool)/“缩放工具”(Scale Tool)设置为沿通过顶点、边或面选择定义的轴变换选定的对象。请参见[设置自定义轴方向](../更改枢轴点/设置自定义轴方向.md)。
