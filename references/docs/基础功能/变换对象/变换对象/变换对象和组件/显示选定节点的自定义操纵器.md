# 显示选定节点的自定义操纵器

选择节点，然后选择“修改 > 变换工具 > 显示操纵器工具”(Modify > Transformation Tools > Show Manipulator Tool)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Basics/GUID-75310CCC-39E0-4E98-B51F-FEA25A39D118.png) <!-- baize:img-hook downloaded=true reason="正文 183 字 <300 且带图" -->

操纵器可用于以直观的方式编辑节点的属性。

**注**

自定义操纵器仅在“构建历史”(Construction History)已启用时显示。
