# 在变换期间保留纹理

当变换对象顶点时 UV 不会默认移入 UV 空间中。因此，对象的纹理可能会变得扭曲。要避免出现这种情况，请在“工具设置编辑器”(Tool Settings Editor)中针对正在使用的任何变换工具启用“保持 UV”(Preserve UVs)选项。
