# 使用精确值移动、旋转和缩放

尽管可以轻松使用“移动工具”(Move Tool)、“旋转工具”(Rotate Tool)和“缩放工具”(Scale Tool)的操纵器变换对象和组件，但有时需要使用精确值。可以使用“通道盒”(Channel Box)或状态行中的“输入框”(Input box)执行该操作。

**注**

以下影片显示针对视频优化的 Maya 配置；显示的用户界面与您设置的用户界面可能稍有不同。例如，

“输入框”(Input box)

显示为展开状态，而默认情况下它通常处于收拢状态。

在通道盒中输入精确的变换值

1. 选择对象或组件。

2. 在[通道盒](../../../节点和属性/节点和属性/查看和编辑属性/通道盒%28Channel%20Box%29.md)中，在相应的 X、Y 或 Z 通道字段中为平移（移动）、旋转和/或缩放属性输入一个值。

在“输入框”(Input box)中输入精确的变换值

1. 选择对象或组件。

2. 选择“移动工具”(Move Tool)、“旋转工具”(Rotate Tool)或“缩放工具”(Scale Tool)。

3. 在[状态行（工具栏）](../../../界面概述/界面概述/状态行（工具栏）.md)右端的“输入框”(Input box)中，单击文本框旁边的图标，然后选择“绝对变换”(Absolute Transform)或“相对变换”(Relative Transform)。

  ![图：在状态行（工具栏）右端的“输入框”(Input box)中，单击文本框旁边的图标，然后选择“绝对变换”(Absolute…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-DDD669B5-A646-42E2-B93C-DBA4C98CEBA6.png) <!-- baize:img-hook downloaded=false reason="正文 792 字 ≥300，非承重" -->

  **注**

  如果选择

  “绝对变换”(Absolute Transform)

  ，请确保对象的变换值已冻结（或设置为 0），因为在

  “输入框”(Input box)

  中输入这些值会将其重置。

4. 单击输入字段，然后在相应的字段中键入 X、Y 和 Z 值。有关示例，请参见[翻转对象](翻转对象.md)。

**注**

如果要将选定的 NURBS 对象移动到极限距离或将 NURBS 对象缩放到极限尺寸，可能需要激活高精度 NURBS 显示，以便正确查看对象。可以在“显示”标题下“NURBS”类别中的[窗口 > 设置/首选项> 首选项(Window > Settings/Preferences > Preferences)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A62CF59A-3600-4709-A3B7-0F2DB83EC829)中找到高精度 NURBS 显示设置。
