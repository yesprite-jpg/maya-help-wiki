# 设置自定义轴方向

使用“工具设置”(Tool Settings)中的“设定为组件”(Set to Component)、“设置为点”(Set to Point)、“设置为边”(Set to Edge)和“设置为面”(Set to Face)命令，可以将变换工具的 X 轴定向到点、边或面。

**注**

这些命令仅影响轴方向，而不影响枢轴位置。若要更改枢轴点的位置，请

激活自定义枢轴编辑模式

。

设置自定义轴方向

1. 选择对象。

2. 双击[工具箱](../../../界面概述/界面概述/工具箱%28Tool%20Box%29.md)中的变换工具图标之一。

3. 在显示的“工具设置”(Tool Settings)中，单击“自定义”(Custom)字段旁边的 ![图：在显示的“工具设置”(Tool Settings)中，单击“自定义”(Custom)字段旁边的 ，然后选择选项之一。 此…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-D78345F7-0FE4-45BF-AB44-307DB98C0997.png) <!-- baize:img-hook downloaded=false reason="正文 454 字 ≥300，非承重" -->，然后选择选项之一。

  此时将显示“方向操纵器”(Orient Manipulator)窗口。

4. 执行下列操作之一：

  - 选择一个顶点。

  - 选择一个边。

  - 选择一个面。

  - 选择对象。

  **注**

  提示：

  若要在另一个对象上进行选择，请先右键单击该对象，然后选择

  “多重”(Multi)

  。

5. 操纵器 X 轴的方向根据选定的组件或对象更新：

  - 操纵器 X 轴指向选定的顶点。

    ![图：操纵器 X 轴指向选定的顶点。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-CD741DBE-1820-4D7A-A45F-AF1F0A83D3B9.png) <!-- baize:img-hook downloaded=false reason="正文 454 字 ≥300，非承重" -->

  - 操纵器 X 轴沿选定边对齐。

  - 操纵器 X 轴沿选定面的面法线对齐。

  - 操纵器 X 轴对齐到另一个对象的轴方向。
