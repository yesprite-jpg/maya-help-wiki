# 激活自定义枢轴编辑模式

当您在对象模式或者组件模式下建模时，自定义枢轴编辑模式允许您调整枢轴的位置和轴方向。（请参见[选择模式](../../../选择/选择/选择模式.md)。）

激活自定义枢轴编辑模式

1. 选择网格上的对象或组件。

2. 选择变换工具。

3. 执行下列操作之一：

  - 按住 D 键以临时进入自定义枢轴编辑模式。

  - 按 D 键或 Insert 键。

  - 单击“工具设置”(Tool Settings)中的“编辑枢轴”(Edit Pivot)。

  将显示自定义枢轴操纵器（组合了平移和旋转操纵器）。如果您正在组件模式下建模，多组件选择模式将激活。

4. 调整枢轴位置和轴方向。

  **注**

  提示：

  使用

  “操纵器首选项”(Manipulator preferences)

  中的

  “枢轴操纵器”(Pivot Manipulator)

  选项隐藏或调整自定义枢轴操纵器的方向控制柄。

退出自定义枢轴编辑模式

1. 执行下列操作之一：

  - 释放 D 键。

  - 按 D 键或 Insert 键。

  - 单击“工具设置”(Tool Settings)中的“编辑枢轴”(Edit Pivot)。

  - 选择其他变换工具。

    **注**

    切换工具时，会保留自定义枢轴。
