# 使用节点编辑器创建节点网络

若要打开“节点编辑器”(Node Editor)，请选择“窗口 > 节点编辑器”(Windows > Node Editor)。节点编辑器是工作流（如装备）的首选编辑器。详细信息请参见[节点编辑器](使用节点编辑器创建节点网络/节点编辑器%28Node%20Editor%29.md)。

Hypershade 是创建着色器网络的首选编辑器。有关详细信息，请参见[使用 Hypershade 的外观开发](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-447C9ADA-A285-483E-A93D-6ED1B2792D5F)。
