# 场景的两个视图：层次和依存关系

在 Maya 中有两种基本方法查看场景：

- 作为[场景层次](场景层次.md)：节点的层次列表。

  在此方法下，显示的是节点之间的父子关系。您可以使用[大纲视图(Outliner)](大纲视图%28Outliner%29.md)来查看和编辑此视图类型的场景。

  “大纲视图”(Outliner)显示场景中所有对象的层次列表。

- 作为[依存关系图](依存关系图.md)：节点之间的连接关系图。

  在此方法下，显示的是节点之间的输入输出关系。您可以使用 [Hypergraph](“Hypergraph”概述.md) 或[节点编辑器(Node Editor)](使用节点编辑器创建节点网络/节点编辑器%28Node%20Editor%29.md)来查看和编辑此视图类型的场景。

  “Hypergraph”显示一个长方体网络来表示节点，以及表示节点关系的连接线。
