# Hypergraph 的“书签”(Bookmarks)菜单

#### 创建书签(Create Bookmark)

将当前节点排列另存为快速引用。选择相应的选项以命名书签，否则会为该书签指定一个默认名称。

#### 书签编辑器(Bookmark Editor)

打开“书签”(Bookmarks)窗口，在其中可以编辑保存的书签。
