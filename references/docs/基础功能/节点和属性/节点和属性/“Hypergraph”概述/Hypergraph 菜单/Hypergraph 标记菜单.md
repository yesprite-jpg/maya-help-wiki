# Hypergraph 标记菜单

在“Hypergraph”中的任意位置按住 Shift + 单击鼠标右键，从以下选项中进行选择。

#### 显示所有连接(Show all Connections)

显示场景层次中每个节点的连接起点和终点。

#### 显示来自选定对象的连接(Show from Selected)

显示来自选定节点的连接。

#### 显示指向选定对象的连接(Show to Selected)

显示指向选定节点的连接。

#### 显示指向/来自选定对象的连接(Show to/from Selected)

显示指向和来自选定节点的连接。

#### 切换连接标签(Toggle Connection Label)

切换约束连接的标签。启用时，标签将显示在每条连接线上方。请参见[在 Hypergraph 中显示连接](../../查看和更改节点之间的输入和输出关系/在%20Hypergraph%20中显示连接.md)。

#### 变形器连接(Deformer Connections)

启用时，将在由约束连接的两个节点之间显示绿色线。箭头表示连接方向。

![图：启用时，将在由约束连接的两个节点之间显示绿色线。箭头表示连接方向。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-50ED64DA-D36B-4D54-96A6-42EC72B61E26.png) <!-- baize:img-hook downloaded=false reason="正文 667 字 ≥300，非承重" -->

#### 约束连接(Constraint Connections)

启用时，将在由约束连接的两个节点之间显示蓝色线。箭头表示连接方向。

![图：启用时，将在由约束连接的两个节点之间显示蓝色线。箭头表示连接方向。 提示： 选择“切换连接标签”(Toggle Conn…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-7910E667-EAAB-4667-B25C-793A88106141.png) <!-- baize:img-hook downloaded=false reason="正文 667 字 ≥300，非承重" -->

**注**

提示：

选择“切换连接标签”(Toggle Connection Label)以在每个连接线上方显示约束的名称。请参见[在 Hypergraph 中显示连接](../../查看和更改节点之间的输入和输出关系/在%20Hypergraph%20中显示连接.md)。

#### 表达式连接(Expression Connections)

启用时，将在由表达式连接的两个节点之间显示红色线。箭头表示连接方向。

![图：启用时，将在由表达式连接的两个节点之间显示红色线。箭头表示连接方向。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-FF32BA24-0105-40E0-8F38-E3736350AC9C.png) <!-- baize:img-hook downloaded=false reason="正文 667 字 ≥300，非承重" -->

**注**

提示：

通过选择[“颜色设置”(Color Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1FC6CC4E-6C21-44FA-A58B-AC31ED57B591)并展开 Hypergraph/Hypershade，可以更改连接线的颜色编码。
