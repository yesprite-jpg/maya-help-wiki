# 控制在编辑器中显示的对象或属性类型

“大纲视图”(Outliner)、“Hypergraph”、“曲线图编辑器”(Graph Editor)、“摄影表”(Dope Sheet)和“关系编辑器”(Relationship Editor)可立即过滤掉您不感兴趣的信息。

临时从编辑器显示中过滤掉对象或属性

1. 执行下列操作之一：

  | 目标 | 操作 |
  |---|---|
  | 仅显示名称中带特定文本的项目。 | 在文本过滤器框中键入文本，然后按 Enter 键。星号 (*) 可与任何内容匹配。问号 (?)可与任何单个字符匹配。 例如，若要显示名称以 spot 开头的所有项目，请在文本过滤器框中键入 spot*。若要显示名称中包含 new 的项目，请键入 *new*。 |
  | 仅显示特定类型的对象。 | 在“显示 > 对象”(Show > Objects)子菜单中，选择要显示的对象类型。 若要再次显示所有对象类型，请选择“显示 > 对象 > 清除以下项”(Show > Objects > Clear Below)。 |
  | 仅显示特定类型的属性。 | 在显示属性的编辑器（具有角色的“关系编辑器”(Relationship Editor)和已启用“显示 > 属性(通道)”(Display > Attributes (Channels))的“大纲视图”(Outliner)）中： 在“显示 > 属性”(Show > Attributes)子菜单中，选择要显示的对象类型。 若要再次显示所有对象类型，请选择“显示 > 属性 > 清除以下项”(Show > Attributes > Clear Below)。 |
  | 仅显示与选择类型相同的对象或属性。 | 选择“显示 > 显示选定类型”(Show > Show Selected Type(s))。 |
  | 显示所有对象和属性。 | 选择“显示 > 显示全部”(Show > Show All)。 |
