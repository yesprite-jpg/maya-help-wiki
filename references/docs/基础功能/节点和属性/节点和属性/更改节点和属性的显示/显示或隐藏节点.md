# 显示或隐藏节点

| 目标 | 操作 |
|---|---|
| 展开或收拢节点下的层次。 | 在“大纲视图”(Outliner)中，单击节点名称左侧的加号或减号图标。 在“Hypergraph”中，双击节点。 |
| 显示辅助节点类型。 | 在编辑器中，选择“显示 > 显示辅助节点”(Show > Show Auxiliary Nodes)。 |
| 控制隐藏作为辅助节点的节点类型。 | 在编辑器中，选择“显示 > 辅助节点”(Show > Auxiliary Nodes)。 若要从隐藏列表中删除节点，请在顶部列表中单击该节点，再单击“从列表中移除”(Remove From List)。 若要将节点添加到隐藏列表，请在底部列表中单击该节点，再单击“添加”(Add)将节点“添加到隐藏列表(以上)”(Hide List (Above))。 |
| 显示或隐藏“Hypergraph”中的图形节点。 | 在“Hypergraph”中，选择“选项 > 显示 > 形状节点”(Options > Display > Shape Nodes)。 |
| 显示或隐藏“Hypergraph”中的隐藏节点。 | 在“Hypergraph”中，选择“选项 > 显示 > 隐藏的节点”(Options > Display > Hidden Nodes)。 |
| 显示或隐藏“Hypergraph”中的对拓节点。 | 在“Hypergraph”中，选择“选项 > 显示 > 对拓节点”(Options > Display > Underworld Nodes)。 仅在图形节点可见时，对拓节点才可见。 |

**注**

可以导出选定的已连接节点。即使构建历史输入选项（“历史”(History)）处于禁用状态，选定节点仍保持其历史节点属性连接。在某些情况下，隐藏或取消选择的辅助节点可能会断开这些节点连接。对于此特定工作流，建议在编辑器的

“显示”(Show)

菜单中启用辅助节点的显示，以确保它们都包含在选择中，然后再导出。请参见

“导出全部”(Export All)/“导出当前选择”(Export Selection)选项

。
