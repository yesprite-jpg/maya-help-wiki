# “节点编辑器”(Node Editor)中的属性过滤

使用“节点编辑器”(Node Editor)中样例下方的过滤器字段来过滤属性。例如，如果要分离出与颜色相关的属性，请键入“col”，系统将仅显示包含字母“col”的属性。

可以通过输入属性长名称或其 UI 名称进行过滤，例如“轴向细分数”或 subdivisionsAxis。
