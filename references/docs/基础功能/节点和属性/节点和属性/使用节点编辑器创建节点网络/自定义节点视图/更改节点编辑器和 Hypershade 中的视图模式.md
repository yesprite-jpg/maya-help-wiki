# 更改节点编辑器和 Hypershade 中的视图模式

有五种在“节点编辑器”(Node Editor)内查看节点的方式：简单模式、已连接模式、完全模式、查看所有属性或自定义属性视图。有关视图模式的详细信息，请参见[节点编辑器视图模式](../节点编辑器%28Node%20Editor%29.md#GUID-23277302-6665-465F-8579-9BC734228F69__SECTION_A7AD706DF2D34B81AB771432E5740CB9)。

本主题同时适用于节点编辑器和 Hypershade。

## 更改所有节点的视图模式

如果“节点编辑器”(Node Editor)中无节点亮显（活动），则单击工具栏中的图标，或从节点编辑器的“编辑”(Edit)菜单中选择相同选项，或使用“编辑”(Edit)菜单快捷方式将影响所有节点。

**注**

也可以在“首选项”(Preferences)窗口中自定义该选项，并且节点会在下次创建“节点编辑器”(Node Editor)窗口时以选定的视图模式显示。详细信息请参见[节点编辑器首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-29B4D1FC-1861-4828-8236-6E6F1F24BFD3)。
