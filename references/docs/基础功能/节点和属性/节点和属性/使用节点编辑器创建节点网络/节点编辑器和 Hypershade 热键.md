# 节点编辑器和 Hypershade 热键

下面是可以在节点编辑器和 Hypershade 中使用的预指定热键的列表。

也可以指定自己的自定义热键。请参见[将热键指定给命令](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-92F8EBD9-A658-4A1E-9D85-571B5B809F52)。

| **热键** | **描述(Description)** |
|---|---|
| 1, 2, 3, 4 | 在查看模式之间切换：简单模式、已连接模式、完全模式以及显示所有属性/自定义属性视图（如果存在自定义属性列表）。 |
| 5 | 在节点名称/节点类型/无节点标题之间切换显示。 |
| =/- | 放大/缩小。 |
| Delete/Backspace 键 | 从场景中移除节点。 |
| Tab 键 | 创建节点。 |
| , | 选择连接的上游节点。 |
| . | 选择连接的下游节点。 |
| / | 选择连接的上游和下游节点。 |
| Ctrl + l | 从图表中移除所有的选定节点。 注： l 键是小写的 L。 |
| Ctrl + / | 从图表中移除所有的未选定节点。 |
| Ctrl + , | 从图表中移除所有上游节点（包括选定节点）。 |
| Ctrl + . | 从图表中移除所有下游节点（包括选定节点）。 |
| Shift + , 这也是 < 键。 | 重新绘制上游节点。 |
| Shift + . 这也是 > 键。 | 重新绘制下游节点。 |
| Shift + / 这也是 ? 键。 | 重新绘制上游和下游节点。 |
|  |  |
| 仅适用于节点编辑器 |  |
| s | 切换节点中的属性搜索字段 |
| C | 同步节点编辑器/视口选择。 注： C 为大写模式；即，Shift + C。 |
| V | 切换选择样例大小 |
| 左/右箭头键 | 行进式拾取同级节点。 |
| 上/下箭头键 | 行进式拾取父/子节点。 |
| p | 在固定和取消固定之间切换。 |
| l | 排布图表。 注： l 键是小写的 L。 |
|  |  |
| 仅适用于 Hypershade |  |
| @ | 单放选定节点。 |
| # | 移除单放。 |
| ! | 单放上次单放的节点/属性。 |
|  |  |
