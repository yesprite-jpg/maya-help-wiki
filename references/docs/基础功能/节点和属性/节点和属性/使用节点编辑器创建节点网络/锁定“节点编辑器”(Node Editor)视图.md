# 锁定“节点编辑器”(Node Editor)视图

可以锁定“节点编辑器”(Node Editor)视图，以便图表中不显示您创建的任何新节点。

单击此图标 ![图：单击此图标 以解除锁定视图。默认情况下，节点编辑器视图处于锁定状态。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-469D721A-A822-41A6-AF49-B74C0AE5E5C0.png) <!-- baize:img-hook downloaded=false reason="正文 435 字 ≥300，非承重" --> 以解除锁定视图。默认情况下，节点编辑器视图处于锁定状态。

在锁定模式 ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-469D721A-A822-41A6-AF49-B74C0AE5E5C0.png) <!-- baize:img-hook downloaded=false reason="正文 435 字 ≥300，非承重" --> 下，仍可以使用以下方法创建新节点，并且它们将在“节点编辑器”(Node Editor)中显示：

- Tab 键。详细信息请参见[创建节点](在“节点编辑器”%28Node%20Editor%29中创建节点.md#GUID-6217CD2A-0CDB-41C4-AC47-BD5169BE070C__GUID-306946B7-B3AA-4AF2-9395-E11FA7FDE993)。

- 使用鼠标中键将节点从创建节点窗格（单击工具栏上的 ![图：使用鼠标中键将节点从创建节点窗格（单击工具栏上的 ）或“大纲视图”(Outliner)拖动到“节点编辑器”(Node E…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-1938F4A7-9C1D-49F5-830C-8E51F13C3C8F.png) <!-- baize:img-hook downloaded=false reason="正文 435 字 ≥300，非承重" -->）或“大纲视图”(Outliner)拖动到“节点编辑器”(Node Editor)（拖放式创建）。

**注**

在锁定模式下仍可以执行删除和撤消操作。

但是，在场景视图中创建的节点，或者通过在创建节点窗格中单击创建的节点（也就是说，未使用拖放创建），不会显示在节点编辑器中。
