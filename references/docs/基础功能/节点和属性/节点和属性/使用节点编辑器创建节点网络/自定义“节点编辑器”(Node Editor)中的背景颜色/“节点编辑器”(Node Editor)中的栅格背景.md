# “节点编辑器”(Node Editor)中的栅格背景

## 切换栅格背景

您可以通过选择或取消选择“显示 > 栅格”(Display > Grid)或单击 ![图：您可以通过选择或取消选择“显示 栅格”(Display Grid)或单击 以开启和关闭栅格背景。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-61B00525-4F57-4772-821B-C81467DB4C3A.png) <!-- baize:img-hook downloaded=false reason="正文 365 字 ≥300，非承重" --> 以开启和关闭栅格背景。

## 捕捉到栅格

您可以通过选择“显示 > 栅格捕捉”(Display > Grid Snapping)或单击 ![图：您可以通过选择“显示 栅格捕捉”(Display Grid Snapping)或单击 以将节点捕捉到栅格。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-C16958BF-0B1E-431B-A565-94C883298ABC.png) <!-- baize:img-hook downloaded=false reason="正文 365 字 ≥300，非承重" --> 以将节点捕捉到栅格。

## 切换捕捉

您可以按 X 键切换栅格捕捉状态。例如，在处理节点时，如果栅格捕捉处于禁用状态，您可以按住 X 键暂时启用。一旦释放 X 键，将禁用栅格捕捉。

## 栅格和背景颜色

您可以导航到“窗口 > 设置/首选项 > 颜色设置”(Windows > Settings/Preferences > Color Settings)以自定义栅格和背景的颜色。在“常规”选项卡上，展开“节点编辑器”(Node Editor)区域，然后单击“栅格”(Grid)和“背景”(Background)旁边的颜色样例，使用“颜色选择器”(Color Chooser)选择颜色。
