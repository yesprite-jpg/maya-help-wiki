# “节点编辑器”(Node Editor)标记菜单

除“节点编辑器”(Node Editor)工具栏和菜单之外，“节点编辑器”(Node Editor)标记菜单还为您提供了自定义“节点编辑器”(Node Editor)图表的其他方式。

在[节点编辑器(Node Editor)工作区](../节点编辑器%28Node%20Editor%29.md)中的空白区域单击鼠标右键将显示一个标记菜单，通过它可以访问用于创建和显示节点网络的命令。

| [创建节点(Create Node)](../在“节点编辑器”%28Node%20Editor%29中创建节点.md) | 打开“创建节点”(Create Node)窗口，用于创建新的着色器节点。如果“创建”(Create)选项卡当前已关闭，这将非常有用。 |

| 对视口选择上的材质制图(Graph Materials on Viewport Selection) | 在工作区中显示连接到任何选定对象的所有着色网络。 |
| 选择图表中的所有对象(Select All in Graph) | 在 Hypershade 图形中亮显所有节点。 |

| 显示(Display) | 通过选择提供的任一选项来自定义图表。 |
| 显示(Show) | 过滤工作区中要显示的节点类型。默认情况下，显示“摄影机”(Cameras)、“着色组”(Shading Groups)和“着色节点”(Shading Nodes)。 |

在[节点编辑器(Node Editor)工作区](../节点编辑器%28Node%20Editor%29.md)中的节点上单击鼠标右键将显示一个标记菜单，通过它可以访问相对于该节点有用的命令。

| 菜单项 | 效果 |
|---|---|
| [选择/重新绘制/移除流节点(Select/Regraph/Remove Stream Nodes)](../节点编辑器%28Node%20Editor%29中的选择/在节点编辑器或%20Hypershade%20中选择上游和或下游节点.md) | 用于选择和修改其他节点相对于工作区中选定节点的显示状态。 |
| 输入(Inputs) | 列出所有提供节点属性的输入（上游）节点。 |
| 输出(Outputs) | 列出所有由节点属性馈送的输出（下游）节点。 |
| 重命名(Rename) | 用于重命名节点。 |
| [切换样例大小(Toggle Swatch Size)](../自定义节点视图/在节点编辑器和%20Hypershade%20中切换节点样例大小.md) | 增大或减小节点样例的大小。此选项仅影响通过其访问标记菜单的节点。 |
| [切换选择样例大小(Toggle Selection Swatch Size)](../自定义节点视图/在节点编辑器和%20Hypershade%20中切换节点样例大小.md) | 增大或减小工作区中所有选定样例的大小。您也可以使用快捷方式 v。 |
| [编辑自定义属性列表(Edit Custom Attribute List)](../自定义节点视图/在“节点编辑器”%28Node%20Editor%29中自定义节点属性列表.md) | 用于修改在工作区中对特定节点显示和隐藏的属性。创建自定义属性列表后，单击 ![图：用于修改在工作区中对特定节点显示和隐藏的属性。创建自定义属性列表后，单击 以提交更改。请参见自定义节点属性列表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-01F0B285-2776-4A14-9B4D-0BE4F560BA3C.png) <!-- baize:img-hook downloaded=false reason="正文 2017 字 ≥300，非承重" --> 以提交更改。请参见[自定义节点属性列表](../自定义节点视图/在“节点编辑器”%28Node%20Editor%29中自定义节点属性列表.md) |
| 显示所有属性(Show All Attributes) | 显示选定节点的所有属性。所有属性的显示仅对该绘制实例有效。如果对节点重新制图，或者更改节点的视图模式，则必须重新选择此选项才可再次显示其所有属性。 |
| [添加属性(Add Attributes)](../../查看和编辑属性/创建、编辑或删除自定义属性.md) | 打开“添加属性”(Add Attribute)窗口，用于创建选定节点的自定义属性。 |
| [删除属性(Delete Attributes)](../../查看和编辑属性/创建、编辑或删除自定义属性.md) | 打开“删除属性”(Delete Attribute)窗口，用于移除选定节点的自定义属性。 |

在[节点编辑器(Node Editor)工作区](../节点编辑器%28Node%20Editor%29.md)中的连接上单击鼠标右键将显示一个标记菜单，通过它可以访问相对于该连接有用的命令。

| 菜单项 | 效果 |
|---|---|
| 断开连接(Break Connection) | 移除链接的节点之间的连接。 |
| 隔离连接的节点(Isolate connected nodes) | 减少工作区显示的内容，仅显示由选定连接相连的节点。 |
| 选择连接的节点(Select connected nodes) | 选择由选定连接相连的所有节点。 |
