# 显示连接

第一次打开“节点编辑器”(Node Editor)时，会在您的场景视图中绘制选定对象。

若要对您选择的节点网络制图，请参见以下各部分。

## 显示节点连接

若要显示节点连接，请执行以下操作：

1. 在 Maya 中选择任何节点或对象，然后单击“节点编辑器”(Node Editor)工具栏上的 ![图：在 Maya 中选择任何节点或对象，然后单击“节点编辑器”(Node Editor)工具栏上的 图标，以显示输入和输出节…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-2DAD0BAA-9888-4075-B3DB-3C45B5CF4481.png) <!-- baize:img-hook downloaded=false reason="正文 666 字 ≥300，非承重" --> 图标，以显示输入和输出节点连接。

有关每个连接颜色所代表的连接图例，请参见[节点编辑器中的连接颜色](连接节点/“节点编辑器”%28Node%20Editor%29中的连接颜色.md)。

## 属性的排列顺序

每个节点的属性按如下顺序排列：

1. 平移、旋转、缩放和可见性属性。

2. 仅可用作输出的属性。

3. 既可用作输入又可用作输出的属性。

4. 仅可用作输入的属性。

## 对选定对象的着色网络制图

可以对场景视图中选定对象的着色网络制图。

1. 在场景视图中，选择要对其着色网络制图的对象。

2. 在“节点编辑器”(Node Editor)中的任意空白区域上单击鼠标右键以访问工作区标记菜单，然后选择“对视口选择上的材质制图”(Graph Materials on Viewport Selection)。

## 连接线的亮显
