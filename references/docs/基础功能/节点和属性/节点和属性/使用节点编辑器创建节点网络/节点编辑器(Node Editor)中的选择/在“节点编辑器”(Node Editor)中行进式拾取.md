# 在“节点编辑器”(Node Editor)中行进式拾取

您可以使用上/下和左/右箭头键，在“节点编辑器”(Node Editor)中行进式拾取，就好像在场景视图和“大纲视图”(Outliner)中一样。使用左/右箭头键在整个同级节点中行进式拾取，而使用上箭头键在整个父节点中行进式拾取，并使用下箭头键在整个子节点中行进式拾取。相应的节点在“节点编辑器”(Node Editor)、场景视图和“大纲视图”(Outliner)中选择。

请参见[定义自定义拾取漫游层次](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-791CC2FC-DE9F-440A-B1F5-F76AF61024C8)。
