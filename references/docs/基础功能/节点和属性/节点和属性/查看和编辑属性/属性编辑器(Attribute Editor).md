# 属性编辑器(Attribute Editor)

打开属性编辑器

- 选择“窗口 > 常规编辑器 > 属性编辑器”(Windows > General Editors > Attribute Editor)。

- 选择“窗口 > UI 元素 > 属性编辑器”(Windows > UI Elements > Attribute Editor)。

- 选择“关键帧 > 属性编辑器”(Key > Attribute Editor)。

- 单击“属性编辑器”(Attribute Editor)图标 ![图：单击“属性编辑器”(Attribute Editor)图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-1606AD95-415D-4B74-94A1-52D68AB1336E.png) <!-- baize:img-hook downloaded=false reason="正文 723 字 ≥300，非承重" -->。

- 按 Ctrl+A（如果使用默认热键集）。

  **注**

  如果再次按 Ctrl+A，则会打开

  通道盒(Channel Box)

  。

“属性编辑器”(Attribute Editor)将列出选定对象上的属性。使用位于“属性编辑器”(Attribute Editor)顶部的选项卡可以选择连接到所显示节点的节点。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-831AA6A8-EBBC-482A-912E-A6D3C2CDCBD2.png) <!-- baize:img-hook downloaded=false reason="正文 723 字 ≥300，非承重" -->

通道盒提供了可设置关键帧的动画属性的更精简视图，而属性编辑器则提供了完整的图形控件，不仅可以用来编辑文本框，而且还可以编辑属性。请参见[属性编辑器图形控件](属性编辑器%28Attribute%20Editor%29/使用“属性编辑器”%28Attribute%20Editor%29.md#GUID-240DEBFF-A7A1-466E-9F1D-004E1F823A50__WS17956D7ADBC6E736-4CE538CA117AE30C631-7FFD)。

**注**

提示：

您可以使用

“属性编辑器”(Attribute Editor)

顶部节点选项卡上方的滚轮，或者在最右侧的箭头按钮上单击鼠标右键，轻松选择所需的节点：

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-84D11FC3-FCF4-4A0A-9CDF-045EFB7C972E.png) <!-- baize:img-hook downloaded=false reason="正文 723 字 ≥300，非承重" -->

**注**

若要在属性编辑器中垂直平移，请使用滚轮或按住 Alt 键并使用鼠标中键拖动（对于 Mac，请按住 Opt 键并使用鼠标中键拖动）。若要快速平移，请按住 Ctrl 和 Alt 键并使用鼠标中键拖动（对于 Mac，请按住 Ctrl 和 Opt 键并使用鼠标中键拖动）。
