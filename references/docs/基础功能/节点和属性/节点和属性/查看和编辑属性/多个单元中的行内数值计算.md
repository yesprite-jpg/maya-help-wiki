# 多个单元中的行内数值计算

可以同时在“组件编辑器”(Component Editor)和“属性总表”(Attribute Spread Sheet)的多个单元中执行数值计算和基于百分比的计算。

执行计算

1. 选择要操作的单元。

2. 在活动单元中，输入操作的前缀和值。

3. 按 Enter 键。

所有选定单元都会获得操作指定的新值。

## 示例

为选定单元添加值

1. 选择要操作的单元。

2. 在活动单元中输入 +=4.0。

选定单元的值增加了 4.0。

在选定单元中减去百分比

1. 选择要操作的单元。

2. 在活动单元中输入 -=50%。

选定单元的值相对于当前值减少了一半。

**注**

由于受其他因子约束，某些值会存在限制，从而可能导致无法更改为所需的值。
