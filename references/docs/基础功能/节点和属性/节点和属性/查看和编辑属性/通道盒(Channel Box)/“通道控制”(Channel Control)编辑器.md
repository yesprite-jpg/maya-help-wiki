# “通道控制”(Channel Control)编辑器

- 选择**“窗口 > 常规编辑器 > 通道控制”(Window > General Editors > Channel Control)**

使用“通道控制”(Channel Control)编辑器，可以同时管理多个对象（即使对象类型不同）及其属性。另请参见[编辑对象的可设置关键帧性](使通道可设置关键帧或不可设置关键帧.md)和[在不删除属性的情况下禁用属性的可编辑性](在不删除属性的情况下禁用属性的可编辑性.md)。

“通道控制”(Channel Control)编辑器有两个选项卡。“可设置关键帧”(Keyable)选项卡用于编辑属性的设定关键帧能力；“已锁定”(Locked)选项卡用于编辑属性的锁定情况。

为对象设定关键帧时，对象通道状态会影响设置动画的对象通道。使用“自动关键帧”(Auto Key)和“关键帧 > 设置关键帧”(Key > Set Key)（快捷方式：**S** 键）方法为对象设置动画时，“可设置关键帧”(keyable)和“不可设置关键帧”(nonkeyable)这两种通道状态能够让您指定对象的哪些通道可以设置关键帧。有关详细信息，请参见[使用自动关键帧](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4268F6E4-C35D-4222-BB47-B5BE5CD0B3A3)和[“关键帧”(Key)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-FA1DF2DA-86C9-49EE-A23A-8749E4D31822#GUID-FA1DF2DA-86C9-49EE-A23A-8749E4D31822__GUID-1D4E83B6-FDDA-43B0-9488-4AA032CC98D0)。

“通道控制”(Channel Control)编辑器的“可设定关键帧”(Keyable)选项卡包含三列：“可设定关键帧”(Keyable)、“隐藏的不可设定关键帧的项”(Nonkeyable Hidden)和“显示的不可设定关键帧的项”(Nonkeyable Displayed)。这些列中列出了当前选定对象的属性。当属性名称位于“可设定关键帧”(Keyable)或“显示的不可设定关键帧的项”(Nonkeyable Displayed)列中时，属性将显示在“通道盒”(Channel Box)中。当属性名称位于“隐藏的不可设定关键帧的项”(Nonkeyable Hidden)列中时，通道不会显示在“通道盒”(Channel Box)中。
