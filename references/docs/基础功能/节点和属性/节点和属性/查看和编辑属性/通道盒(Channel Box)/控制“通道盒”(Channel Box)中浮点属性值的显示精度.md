# 控制“通道盒”(Channel Box)中浮点属性值的显示精度

1. 在“通道盒”(Channel Box)中，选择“编辑 > 设置 > 更改精度”(Edit > Settings > Change Precision)。

2. 键入显示在“通道盒”(Channel Box)和“属性总表”(Attribute Spread Sheet)中的小数位数。
