# 编辑完成的命令（构建历史）

查看完整的构建历史

1. 选择对象。

2. 单击[状态行（工具栏）](../../../界面概述/界面概述/状态行（工具栏）.md)上的构建输入按钮 ![图：单击状态行（工具栏）上的构建输入按钮 或构建输出按钮 ，然后选择 “所有输入”(All Inputs)或“所有输出”(A…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-80FA8C8E-D093-4B44-B4FF-F3A83F8E09EF.png) <!-- baize:img-hook downloaded=false reason="正文 839 字 ≥300，非承重" --> 或构建输出按钮 ![图：单击状态行（工具栏）上的构建输入按钮 或构建输出按钮 ，然后选择 “所有输入”(All Inputs)或“所有输出”(A…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-DE9218A2-08A8-4C5B-A4C9-ABD3CF98094C.png) <!-- baize:img-hook downloaded=false reason="正文 839 字 ≥300，非承重" -->，然后选择 “所有输入”(All Inputs)或“所有输出”(All Outputs)。

  “输入操作列表”(List of input operations)或“输出操作列表”(List of output operations)窗口将会显示。

  这些窗口列出了所选对象的构建历史内的所有节点。可以使用[“节点状态”(Node State)](../节点的常规属性%28General%20attributes%29/节点行为%28Node%20behavior%29.md#GUID-4BBDEBF1-A4F1-4EE3-B225-A1E808AFA206__GUID-C71CCA33-4EFC-4581-B707-58C185D473D9)下拉菜单来更改节点行为，并可以使用“过滤器”(Filter)选项设置是否在所选对象的“属性编辑器”(Attribute Editor)中显示节点属性。（“列表”(List)显示节点，“包括”(Include)过滤出节点。）

**注**

使用鼠标中键拖动某个项目，以在

“输入操作列表”(List of input operations)

或

“输出操作列表”(List of output operations)

窗口中将其重新定位。此操作仅适用于变形器，不适用于建模操作。

使用构建历史修改对象

1. 选择对象。

2. 执行下列操作之一：

  - 按下 A 单击对象，然后从显示的标记菜单中选择“选择所有输入”(Select All Inputs)。

  - 单击[状态行（工具栏）](../../../界面概述/界面概述/状态行（工具栏）.md)上的构建输入按钮 ![图：单击状态行（工具栏）上的构建输入按钮 或构建输出按钮 ，然后从显示的菜单中选择一个节点。 提示： 选中输入或输出节点旁的…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-80FA8C8E-D093-4B44-B4FF-F3A83F8E09EF.png) <!-- baize:img-hook downloaded=false reason="正文 839 字 ≥300，非承重" --> 或构建输出按钮 ![图：单击状态行（工具栏）上的构建输入按钮 或构建输出按钮 ，然后从显示的菜单中选择一个节点。 提示： 选中输入或输出节点旁的…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-DE9218A2-08A8-4C5B-A4C9-ABD3CF98094C.png) <!-- baize:img-hook downloaded=false reason="正文 839 字 ≥300，非承重" -->，然后从显示的菜单中选择一个节点。

    **注**

    提示：

    选中输入或输出节点旁的选项框

    ，以在

    “属性编辑器”(Attribute Editor)

    中打开节点进行编辑。

  - 在“属性编辑器”(Attribute Editor)中，选择待编辑历史节点的选项卡。

  - 在“通道盒”(Channel Box)中，单击节点名称。

3. 在“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中编辑节点属性。

  若要显示此节点的自定义操纵器，请选择“修改 > 变换工具 > 显示操纵器工具”(Modify > Transformation Tools > Show Manipulator Tool)。
