# 针对节点类型创建“属性编辑器”(Attribute Editor)模板

针对节点类型创建模板

1. 使用 XML 或自行选择的纯文本编辑器创建模板。请参见[属性编辑器模板的各个部分](“属性编辑器”%28Attribute%20Editor%29模板的各个部分.md)。

  **注**

  提示：

  也可以使用

  “属性编辑器”(Attribute Editor)

  模板生成器创建自定义模板。请从

  http://area.autodesk.com/bonus_tools

  联机下载此 Bonus Tool，或者选择

  “帮助 > Maya 资源和工具 > 下载 Bonus Tools”(Help > Maya Resources and Tools > Download Bonus Tools)

  。

2. 将模板另存为 AE<NodeType>Template.xml，其中 AE 和 Template 将文件指定为“属性编辑器”(Attribute Editor)模板，而 Nodetype 是为其创建模板的节点类型。

  例如，**“Blinn”**着色器节点的自定义“属性编辑器”(Attribute Editor)模板名为 AEblinnTemplate.xml。
