# 将回调链接到脚本

您可以使用回调将属性链接到一个执行任意数量函数的复杂脚本。例如，使用回调脚本，可以通过影响场景的方式调整属性编辑器控件。

下图中显示在 Maya 中创建的坦克。该坦克的主节点处于选中状态，且该坦克在属性编辑器(Attribute Editor)中以默认视图显示。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-29E6C6C4-E092-4AAD-8AE0-50F1D5F17458.png) <!-- baize:img-hook downloaded=false reason="正文 768 字 ≥300，非承重" -->

下图中选择了名为**“动画”(Animation)**的视图。此视图已进行自定义，可满足动画师的需求。例如，已禁用细节(Details)属性。因此，场景中隐藏了坦克的细节。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-3F430503-2797-4284-98A9-F08113EF4F72.png) <!-- baize:img-hook downloaded=false reason="正文 768 字 ≥300，非承重" -->

此视图已在名为 AETransformTemplate.xml 的自定义模板中创建，它会调用一个名为 AEtankControlAnim 的程序：

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-FC0C7088-52B5-42D5-A9A9-250F8D5D3443.png) <!-- baize:img-hook downloaded=false reason="正文 768 字 ≥300，非承重" -->

AEtankControlAnim 可在 MEL 或 Python 中创建（请参见[创建自定义属性控件](创建自定义属性控件.md)）并包含回调脚本。

回调脚本可完成两个任务：

1. 根据属性类型创建控件。

  例如，细节(Details)属性的属性声明中包含以下代码行：

  ```text
<attribute name='details' type='maya.bool'>
```

  由于类型为 maya.bool，因此(Attribute Editor)属性编辑器创建了一个复选框。有关类型的列表，请参见[属性类型](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D2DF8C97-0AFE-4EDE-938C-B99BF1E46B6E#GUID-D2DF8C97-0AFE-4EDE-938C-B99BF1E46B6E__WS1A9193826455F5FF-12BA6B3A11A9C207460-70ED)。

2. 当更改控件的值时，将运行另一个脚本，即更改命令。这样，可以保持属性编辑器(Attribute Editor)与属性同步。

为了更改细节(Details)属性，在AEtankControlAnim 程序中又添加了几行代码。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F0267533-0CA6-48F9-9641-9FF1674F8FE8.png) <!-- baize:img-hook downloaded=false reason="正文 768 字 ≥300，非承重" -->

名为 tankControlAnimCB 的更改命令启动另一个脚本，从而确保在(Attribute Editor)属性编辑器布局中关闭(Details)细节复选框。
