# 在“通道盒”(Channel Box)、“属性编辑器”(Attribute Editor)和“节点编辑器”(Node Editor)中显示易读、长或短属性名称

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Basics/GUID-4AB6AA8F-094A-422B-981B-D2867DCC6E66.png) <!-- baize:img-hook downloaded=true reason="正文 241 字 <300 且带图" -->

这些编辑器中的默认（易读(Nice)）属性名称容易读懂，但无法在表达式或 MEL 脚本中使用。若要显示属性实际的内部名称，请使用“长”(Long)或“短”(Short)选项。请参见[属性名称](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F0C690E1-B2F1-4C17-85B2-2EC3E9A317A1)。

  在“通道盒”(Channel Box)中，从“编辑 > 通道名称”(Edit > Channel Names)中选择所需的选项。

  在“属性编辑器”(Attribute Editor)和“节点编辑器”(Node Editor)中，从“显示 > 属性名称”(Display > Attribute Names)中选择所需的选项。
