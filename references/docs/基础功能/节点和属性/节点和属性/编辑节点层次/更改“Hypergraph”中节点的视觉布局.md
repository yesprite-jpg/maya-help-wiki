# 更改“Hypergraph”中节点的视觉布局

| 目标 | 操作 |
|---|---|
| 在自动和手动布局之间切换。 | 选择下列选项之一： 选项 > 排布 > 自动布局(Options > Layout > Automatic Layout)。 选项 > 排布 > 自由形式布局(Options > Layout > Freeform Layout)。 |
| 以自由形式布局移动节点。 | 拖动节点。 |
| 在自由形式布局的背景下显示图像。 | 若要加载图像，请选择“视图 > 设置背景图像”(View > Set Background Image)。 若要启用或禁用图像，请选择“视图 > 显示背景图像”(View > Show Background Image)。 |
| 重置自由形式布局中的节点位置。 | 选择“编辑 > 重置自由形式布局”(Edit > Reset Freeform Layout)。 |
| 在水平或垂直堆叠根节点自动布局之间切换。 | 选择下列选项之一： 选项 > 方向 > 水平(Options > Orientation > Horizontal)。 选项 > 方向 > 垂直(Options > Orientation > Vertical)。 选项 > 方向 > 图解(Options > Orientation > Schematic)。 |
| 更改“Hypergraph”中节点显示的颜色。 | 在该节点的“属性编辑器”(Attribute Editor)中，转到“绘制覆盖”(Drawing Overrides)。（可能需要展开“对象显示”(Object Display)才能看到该区域。）启用“启用覆盖”并使用颜色滑块设置颜色。 必须启用“Hypergraph”中的“节点显示覆盖颜色”(Node Display Override Color)才能显示颜色的更改。更改层的颜色将覆盖该节点的显示设置。 |
