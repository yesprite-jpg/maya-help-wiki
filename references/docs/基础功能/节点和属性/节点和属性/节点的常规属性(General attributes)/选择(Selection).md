# 选择(Selection)

对于选定父节点时是否也选择子节点，您可以进行自定义。您可以选择在选定父节点时始终选择子节点，以便以后再也不用进行选择；或者，根据每个对象的设置确定是否选择子节点。您可以从“首选项”(Preferences)窗口（“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)）中，在[“选择首选项”(Selection preferences)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8C8BA1F4-59EE-4A02-BFE7-9193C0D6F5BE)下，通过“选择子对象亮显”(Selection Child Highlighting)下拉列表选择其中一个选项。

如果选择根据每个对象的设置确定（即，从下拉列表中选择“使用对象亮显设置”(Use object highlight setting)），则可以禁用本部分中“属性编辑器”(Attribute Editor)的“选择子对象亮显”(Selection Child Highlighting)选项，以便在选定父节点时不亮显该子节点。如果已启用该选项，则在选定父节点时会亮显该子节点。
