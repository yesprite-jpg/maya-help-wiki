# 构建历史

使用 Maya 时，大多数操作都会在所处理对象的构建历史中创建节点。在每个工作点处，当前场景是迄今为止所创建的所有节点的结果。

例如，可以让曲线围绕一个中心旋转，创建新的曲面，该曲面将具有此曲线形状的横截面。将此动作应用到此曲线时，系统将创建新的旋转节点。新的节点以此曲线的形状作为输入。该节点具有一些属性，可以控制如何通过曲线创建曲面。此外，它以生成的曲面作为输出。

这种节点链，从曲线到旋转节点再到曲面，称为曲面的构建历史。有关构建历史的最重要一点在于，您可以通过编辑节点属性和节点之间的连接来更改它。曲线可以重新定形或者可以更改旋转节点上的属性，生成的曲面将自动更新。

构建历史是 Maya 中依存关系图的一部分。构建历史是指创建了场景的操作历史，而整个依存关系图则是指节点之间的所有连接（输入和输出）。

构建历史的一些常见用途如下：

- 在“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中编辑节点的变换属性。

- 在 Hypergraph 或“节点编辑器”(Node Editor)中更改节点属性之间的依存关系。

- 使某些节点处于非活动状态，同时专注于编辑其他节点。

- 删除对象或动画的全部或部分构建历史，在当前状态下“烘焙”它。这样做可以减少场景的重算时间和文件大小，但是通过简化操作序列，它也可能会更改对象外观。请参见下方的**删除构建历史**。

启用或禁用构建历史创建

在[“状态行”(Status line)（工具栏）](../../界面概述/界面概述/状态行（工具栏）.md)中，单击“构建历史开/关”(Construction History On/Off)图标 ![图：在“状态行”(Status line)（工具栏）中，单击“构建历史开/关”(Construction History O…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-788A9B17-45E3-4D6B-B86A-B5249B5C980B.png) <!-- baize:img-hook downloaded=false reason="正文 746 字 ≥300，非承重" -->。

删除构建历史

选择“编辑 > 按类型删除历史”(Edit > Delete by Type > History)。
