# 优化场景大小

Maya 中有多种功能可用于缩小场景大小并降低场景复杂性。

使用“优化场景大小”(Optimize Scene Size)窗口可从场景中移除空信息、无效信息和未使用信息。例如，如果收到有关 mental ray 未知节点的错误消息，请打开“优化场景大小”(Optimize Scene Size)选项，然后从列表中选择**“未知节点”(Unknown Nodes)**。

若要打开“优化场景大小”(Optimize Scene Size)选项，请执行以下操作：

- 选择“文件 > 优化场景大小”(File > Optimize Scene Size) > ![图：选择“文件 优化场景大小”(File Optimize Scene Size) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 764 字 ≥300，非承重" -->。

**注**

使用

“优化场景大小”(Optimize Scene Size)

所做的更改无法撤消。请在优化之前使用其他名称保存文件，以避免覆盖原始文件。

| 目标 | 操作 |
|---|---|
| 从选定对象中移除构建历史。 只有在确定不需要再次编辑对象的历史时，才执行此操作。 | 选择对象，然后选择“编辑 > 按类型删除 > 历史”(Edit > Delete by Type > History)。有关详细信息，请参见[构建历史](../../节点和属性/节点和属性/构建历史.md)。 |
| 请勿将面板布局与场景一起保存。 | 在[“UI 元素”(UI Elements)首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B67AE9E4-83EA-444F-AC8A-13DB57BC65BB)（“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)）中，关闭“将面板布局与文件一起保存”(Save Panel Layouts with File)。 |
| 移除未使用的文件引用。 | 选择“文件 > 引用编辑器”(File > Reference Editor)。 在“引用编辑器”(Reference Editor)中，选择“文件 > 清理引用”(File > Clean Up Reference)。 |
| 删除静态动画通道。 | 编辑 > 按类型删除 > 静态通道(Edit > Delete by Type > Static Channels)。有关详细信息，请参见[通道或静态通道选项](../../基本参考/基本参考/主菜单/“编辑”%28Edit%29菜单/“按类型删除”%28Delete%20by%20Type%29菜单/“通道”%28Channels%29或“静态通道”%28Static%20Channels%29选项.md)。 |
