# 组织对象

可以使用组，集、划分、容器和层关联场景中的相关对象。

各种策略如下所述：

- “组”(Groups) – 使用组可以对一组对象执行基础的选择和变换，这些对象如同一体，但实际并未组合网格。详细信息请参见[将对象分组](组织对象/将对象分组.md)。

- “集和划分”(Sets and Partitions) – 集是一组可以作为一体进行变换和选择且不会改变场景层次的对象。划分是一组互斥集，对象不能包含在同一划分的多个集中。详细信息请参见[集和划分](组织对象/集和划分.md)或[创建和编辑集](组织对象/集和划分/创建和编辑集.md)。

- “显示层”(Display layers) – 一组单独变换和选择的对象。您可以使层不可见来减少场景中遮挡视线的对象数量。您也可以模板化或引用层，使其中的所有对象不可选但仍存在于场景中。详细信息请参见[组织显示层上的对象](组织对象/组织显示层中的对象/创建和管理显示层.md)。

- “渲染层”(Render layers) - 您可以将任何对象指定给每个层都具有不同材质的多个层。这样您就可以使用 Maya 渲染器的任何组合为每个帧创建多个图像。有关详细信息，请参见 [Maya 渲染设置](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-646154F9-E4D2-4A3E-A0D9-B2F062960A4E)。

- “容器”(Containers) - 由单个容器节点表示的一组节点。内部节点中的属性子集可以发布到容器节点。
