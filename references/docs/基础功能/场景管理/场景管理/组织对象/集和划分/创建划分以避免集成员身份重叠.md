# 创建划分以避免集成员身份重叠

利用划分，可以将集分组到一起，并同时确保集不会共享其成员。

可以将集添加到划分中，但无法将快速选择集添加到划分中。

创建划分

1. 在“大纲视图”(Outliner)中，选择要包含在新划分中的集。

2. 执行下列操作之一：

  - 从 Maya 主菜单中，选择“创建 > 集 > 划分”(Create > Sets > Partition) > ![图：从 Maya 主菜单中，选择“创建 集 划分”(Create Sets Partition) ，然后为划分添加名称。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" -->，然后为划分添加名称。

  - ![图：在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 创建划分”(Sets Create P…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" --> 在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 > 创建划分”(Sets > Create Partition) > ![图：在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 创建划分”(Sets Create P…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" -->，并为划分添加名称。

  现在系统将防止划分中的集拥有重叠的成员身份。 如果选择的集包含重叠成员，则会在帮助行中显示警告。

在划分中创建新的集

1. 选择要包含在新集中的项目。

2. 执行下列操作之一：

  - 从 Maya 主菜单中，选择“创建 > 集 > 集”(Create > Sets > Set) > ![图：从 Maya 主菜单中，选择“创建 集 集”(Create Sets Set) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" -->。

  - ![图：如果所有集成员都是对象，也可以在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 创建集”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" --> 如果所有集成员都是对象，也可以在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 > 创建集”(Sets > Create Set) > ![图：如果所有集成员都是对象，也可以在“大纲视图”(Outliner)中单击鼠标右键以显示其上下文菜单，然后选择“集 创建集”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1313 字 ≥300，非承重" -->。

3. 执行下列操作之一：

  - 若要仅在集已排除时（即，该集不与划分中的其他任何集重叠）将该集添加到划分中，请单击“仅在排除时”(Only If Exclusive)。

  - 若要将集添加到划分并移除已存在于划分中其他集内的任何成员，请单击“通过设置为排除”(By Making Exclusive)。

4. 从“划分”(Partition)下拉列表中选择要向其添加集的划分名称。

5. 单击“应用”(Apply)和“关闭”(Close)。

  如果选择“仅在排除时”(Only If Exclusive)且此集的成员身份与划分中其他集的成员身份重叠，则 Maya 不会将此集添加到划分中，并在帮助行中显示警告。

将集添加到划分中

1. 选择“窗口 > 关系编辑器 > 划分”(Windows > Relationship Editors > Partitions)。

2. 在左侧，单击要编辑的划分。

3. 在右侧，单击以便亮显要添加到划分中的集。

也可以在“大纲视图”(Outliner)中选择要添加到划分的集，然后在“关系编辑器”(Relationship Editor)的“划分”(Partition)面板中，单击划分，然后选择“编辑 > 添加选定项目”(Edit > Add Selected Items)。

从划分中移除集

1. 选择“窗口 > 关系编辑器 > 划分”(Windows > Relationship Editors > Partitions)。

2. 在“划分”(Partition)面板中，单击划分名称旁边的 + 以显示其内容。

3. 单击要移除的集。

4. 选择“编辑 > 从划分中移除亮显的项”(Edit > Remove Highlighted From Partition)。

删除划分

1. 选择“窗口 > 关系编辑器 > 划分”(Windows > Relationship Editors > Partitions)。

2. 选择划分，然后选择“编辑 > 删除亮显对象”(Edit > Delete Highlighted)。

  删除划分不会删除划分中的成员集。
