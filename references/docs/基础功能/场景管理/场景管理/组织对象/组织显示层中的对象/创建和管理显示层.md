# 创建和管理显示层

| 目标 | 操作 |
|---|---|
| 显示“层编辑器”(Layer Editor)。 | 选择“窗口 > UI 元素 > 通道盒/层编辑器”(Windows > UI Elements > Channel Box/Layer Editor)，或者单击“状态行”(Status Line)（工具栏）中的“显示或隐藏通道盒/层编辑器”(Show or hide the Channel Box/Layer Editor)按钮。 将弹出菜单设置为“显示”(Display)。 |
| 创建新层。 | 在“层编辑器”(Layer Editor)中选择“层 > 创建空层”(Layers > Create Empty Layer)，或单击“层编辑器”(Layer Editor)的工具栏上的“创建新层”(Create a new layer)按钮。 |
| 重命名一个层。 | 在“层编辑器”(Layer Editor)中双击该层并在层窗口中键入新名称。 |
| 将选定对象指定到层。 | 在“层编辑器”(Layer Editor)中选择层，在该层上单击鼠标右键，然后选择“添加选定对象”(Add Selected Objects)。 您也可以单击“创建新层”(Create a new layer)按钮，自动将选定对象指定给新层。 |
| 将选定对象从其所在的层中移除。 | 在该层上单击鼠标右键，然后选择“移除选定对象”(Remove Selected Objects)。 |
| 删除层。 | 在“层编辑器”(Layer Editor)中选择层，然后选择“层 > 删除选定层”(Layers > Delete Selected Layers)。 |
| 删除层，而不删除任何对象。 | 在“层编辑器”(Layer Editor)中，选择“层 > 删除未使用的层”(Layers > Delete Unused Layers)。 |
