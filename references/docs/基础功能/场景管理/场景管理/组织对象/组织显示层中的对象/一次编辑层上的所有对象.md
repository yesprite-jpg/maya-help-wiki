# 一次编辑层上的所有对象

| 目标 | 操作 |
|---|---|
| 显示“层编辑器”。 | 选择“窗口 > UI 元素 > 通道盒/层编辑器”(Windows > UI Elements > Channel Box/Layer Editor)，或者单击“状态行”(Status Line)（工具栏）中的“显示或隐藏通道盒/层编辑器”(Show or hide the Channel Box/Layer Editor)按钮。 将弹出菜单设置为“显示”(Display)。 |
| 显示或隐藏层。 | 单击层名称旁的左列。 框中的“V”表示此层可见。 |
| 在播放期间隐藏层。 | 单击层名称旁的第二列。 框中的“P”表示在播放期间该层是可见的。关闭“P”以在播放期间隐藏该层。 |
| 更改层上所有对象的线框颜色。 | 在“层编辑器”(Layer Editor)中双击该层。 在“编辑层”(Edit Layer)窗口中，“颜色”(Color)下拉列表包含“索引”(Index)和 RGB 选项。 选择“索引”(Index)，然后单击一种颜色；或者，选择“RGB”，然后单击或双击颜色框以从“颜色选择器”(Color Chooser)拾取一种颜色。 |
| 在法线、引用和模板之间循环层的显示类型。 | 单击层名称旁的列，在三个值之间循环： 空框表示层中的对象正常并可供选择。 “T”表示层中的对象已模板化：它们显示在线框中且不可选。 “R”表示层中的对象已被引用：它们不可选，但保持当前的显示模式。 |

**注**

除了层窗口中可用的设置之外，层的

“属性编辑器”(Attribute Editor)

中还包含其他不常使用的属性。若要显示层的

“属性编辑器”(Attribute Editor)

，请在

“层编辑器”(Layer Editor)

中选择层，然后选择

“层 > 属性”(Layers > Attributes)

。
