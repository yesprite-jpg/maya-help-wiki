# 删除(Delete)

| 目标 | 操作 |
|---|---|
| 删除选择。 | 选择“编辑 > 删除”(Edit > Delete)，或按 Delete 键。 |
| 从选定对象中删除特定类型的组件。 | 从“编辑 > 按类型删除”(Edit > Delete by Type)子菜单中选择一个项目。 |
| 删除特定类型的所有对象。 | 从“编辑 > 按类型删除全部”(Edit > Delete All by Type)子菜单中选择一个项目。 |
