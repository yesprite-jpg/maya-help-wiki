# 创建基本 3D 对象和曲线

当您开始建模时，需要创建对象。开始建模时，最简单的方法是通过创建几何基本体（如球体、立方体、圆柱体和平面，它们可以成为更复杂对象的基础）完成。绘制曲线为创建 3D 对象提供了基础，或者您也可以使用它们完成其他目的。

**注**

要观看有关如何创建基本体并绘制曲线的视频，请参见

创建和编辑对象

。

## 从使用样例模型开始

您可以加载包含模型的示例场景，作为您完成自我创作的起点。默认情况下，这些场景已随 Maya 一起安装。

加载示例场景

1. 打开[内容浏览器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9221B2E8-7E68-4ECB-94DC-ABEB21E956BF)，然后单击“示例”(Examples)选项卡。

2. 打开所需的模型文件夹，然后将模型拖放到视图面板中。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-4A3827EE-02EB-4DB2-927F-150778FEA9EB.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->

## 创建多边形基本体

若要创建多边形基本体的 3D 对象，请打开“多边形”(Polygons)工具架，并单击左端处的任何 3D 形状图标。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-8FF554A5-3AF0-4B7E-A34A-DED41C6F1425.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->

此外，您也可以选择“创建 > 多边形基本体”(Creat > Polygon Primitives)，然后从子菜单中选择基本体形状之一。

选择“创建 > 多边形基本体 > (形状)(Create > Polygon Primitives > (Shape)) > ![图：选择“创建 多边形基本体 (形状)(Create Polygon Primitives (Shape)) 时，您可以为每…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->时，您可以为每个形状类型设置默认选项。下次创建该基本体时将使用这些设置。请参见[“多边形基本体选项”(Polygon Primitives Options)](../../基本参考/基本参考/主菜单/“创建”%28Create%29菜单/“多边形基本体”%28Polygon%20Primitives%29选项.md)。

有关创建多边形基本体的详细信息，请参见[创建多边形基本体](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6D21314A-54AD-41D4-AFC0-AAED13CD50A6)

## 创建 NURBS 基本体

若要创建 NURBS 基本体 3D 对象（曲面），请打开“曲线/曲面”(Curves/Surfaces)工具架，并单击该工具架中间处的任何 3D 形状图标。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-E3B066F5-CC15-42FD-B4F7-C077955B58DE.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->

此外，您也可以选择“创建 > NURBS 基本体”(Create > NURBS Primitives)，然后从子菜单中选择一个选项。

选择“创建 > NURBS 基本体 > (形状)(Create > NURBS Primitives > (Shape)) > ![图：选择“创建 NURBS 基本体 (形状)(Create NURBS Primitives (Shape)) 时，您可以为…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->时，您可以为每个形状类型设置默认选项。下次创建该基本体时将使用这些设置。请参见[“NURBS 基本体选项”(NURBS Primitives Options)](../../基本参考/基本参考/主菜单/“创建”%28Create%29菜单/“NURBS%20基本体”%28NURBS%20Primitives%29选项.md)。

有关创建 NURBS 基本体的详细信息，请参见[创建 NURBS 基本体](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-47BBC51D-CEBF-4233-B2DF-AF3E6A6AB8AA)。

## 创建或绘制曲线

若要创建基本体 NURBS 曲线，请打开“曲线/曲面”(Curves/Surfaces)工具架，并单击左端的圆形或方形图标。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-C4687717-C7D9-48F0-8975-8E58B79FA289.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->

若要绘制曲线，请单击圆形或方形图标右侧的其中任一曲线图标，然后开始在视图面板中的不同位置单击，以便绘制曲线中的点。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F12E7888-1F9D-4F76-BA6F-D657FB484BC6.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->

此外，您也可以选择 “创建 > 曲线工具”(Creat > Curve Tools)，然后从子菜单中选择一个选项。

选择“创建 > 曲线工具 > (Tool) > ![图：选择“创建 曲线工具 (Tool) ”(Create Curve Tools (Tool)时，可以为每个曲线工具设置默认…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1256 字 ≥300，非承重" -->”(Create > Curve Tools > (Tool)时，可以为每个曲线工具设置默认选项。下次使用此工具绘制曲线将使用这些设置。请参见 [“CV 曲线工具选项”(CV Curve Tool Options)](../../基本参考/基本参考/主菜单/“创建”%28Create%29菜单/“CV%20曲线工具”%28CV%20Curve%20Tool%29选项.md)、[“EP 曲线工具选项”(EP Curve Tool Options)](../../基本参考/基本参考/主菜单/“创建”%28Create%29菜单/“EP%20曲线工具”%28EP%20Curve%20Tool%29选项.md)和[“Bezier 曲线工具选项”(Bezier Curve Tool Options)](../../基本参考/基本参考/主菜单/“创建”%28Create%29菜单/“Bezier%20曲线工具”%28Bezier%20Curve%20Tool%29选项.md)。

有关绘制曲线的详细信息，请参见[绘制曲线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2B521AD9-1CB2-43C9-8385-388D118A5AF3)。
