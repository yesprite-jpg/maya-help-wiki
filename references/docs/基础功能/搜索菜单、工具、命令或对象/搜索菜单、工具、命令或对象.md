# 搜索菜单、工具、命令或对象

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->

使用“搜索”(Search)字段，可以在 Maya 中快速找到要查找的内容。这将根据您的搜索条件列出相关项，然后您可以从列表中直接进行选择或运行。搜索结果可能包括：

- 菜单

- 工具

- 场景对象

- MEL/Python 命令

即使您不知道要搜索的功能的确切名称，Maya 也会根据您输入的内容进行推测并显示相关项。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-5CE41B04-5341-4E16-8A1D-490A4D3B137E.gif) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->

搜索菜单/工具/命令

1. 单击“工具箱”(Toolbox)下的“搜索”(Search)图标 (![图：单击“工具箱”(Toolbox)下的“搜索”(Search)图标 ()，或者按 Ctrl + F 以打开“搜索”(Sea…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-FB1B1EDE-74C7-4E7C-8410-B9D09F2274EA.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->)，或者按 Ctrl + F 以打开“搜索”(Search)字段。

2. （可选）单击搜索字段左侧的模式按钮以切换到适当的模式。

  - “搜索”(Search)模式 (![图：“搜索”(Search)模式 () 用于查找菜单或工具。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-9C2003BF-8CCB-4C22-B5F0-43C6D1A60B03.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->) 用于查找菜单或工具。

  - “选择”(Select)模式 (![图：“选择”(Select)模式 () 用于查找场景中的对象。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F42AF57A-DEF1-402C-A741-565FCA7EDACE.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->) 用于查找场景中的对象。

  - “Python”模式 (![图：“Python”模式 () 用于查找 Python 命令。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-24601C11-2B9E-4150-9482-2F59F25855A2.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->) 用于查找 Python 命令。

  - “MEL”模式 (![图：“MEL”模式 () 用于查找 MEL 命令。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-D8BB0C85-408A-4DFD-98B0-D6E58B89CF2F.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->) 用于查找 MEL 命令。

也可以使用 Ctrl + F 来循环切换这些模式。

**注**

如果将

“搜索”(Search)

重映射到新的热键，则可以改用自定义热键进行循环，但

前提是

所选的热键支持修饰键（如 Ctrl/Alt）。

3. 在搜索字段中输入文本。

  - 文本可以与命令/菜单/工具的直接名称相关，甚至可以与其关联的关键字相关（例如，“hair”显示 XGen 结果，或者“Water”显示 Bifrost 或 BOSS）。

  - 在 MEL 或 Python 模式下，可以从“搜索”(Search)字段运行特定的命令或命令序列（例如，搜索“polyCube -w 20; polyBevel;”会创建一个宽度为 20 的多边形立方体，并进行倒角处理）。

  - 在“搜索”(Search)模式下，可以通过使用 = 开始搜索（或在搜索栏的现有条目中按 Tab 键）来进入正则表达式模式。

  - 在“选择”(Search)模式下，还可以使用 / 开始搜索以搜索特定的节点类型（例如，搜索“/camera/”将返回场景中所有摄影机的列表，而搜索“/camera/persp”将专门返回透视摄影机）。您也可以将它与正则表达式模式结合使用。

  当您在字段中输入文本时，Maya 将自动显示完全匹配以及同义词的匹配结果。对于多字词条目，“搜索”(Search)将分别匹配每个单词的结果（例如，键入“co br”会返回所有结果，如“Content Browser”和“Comb Brush”）。

4. 选择命令以执行它，或在结果中亮显命令时按 Enter 键。

  - 通过单击相应搜索结果中的选项框，可以访问菜单/工具设置。

  - 通过单击搜索结果右侧的 i 图标来查找有关搜索结果的额外帮助。

  - 通过按住 Ctrl 键并单击命令，或亮显命令然后按 Ctrl + Enter 键，可以执行此命令，而无需关闭“搜索”(Search)字段。如果要多次执行命令，这将非常有用。

  **注**

  默认情况下，

  “搜索”(Search)

  会在启动时自动显示最近搜索过的六个命令，即使搜索字段中没有任何内容也是如此。

## 按标记过滤结果

您可以使用标记过滤搜索之后显示的结果。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-BFAC13FA-1921-4E73-8C0A-1F41A1D98ABC.gif) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->

过滤结果

1. 按 Ctrl + F 以打开“搜索”(Search)字段。

2. 单击搜索字段右侧的标记按钮 (![图：单击搜索字段右侧的标记按钮 ()（或者按 :）。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-C07F8199-EA04-467A-B6C7-AA8AD684D847.png) <!-- baize:img-hook downloaded=false reason="正文 1248 字 ≥300，非承重" -->)（或者按 :）。

3. 单击要包含的标记。

您可以通过在搜索栏中单击标记，来从搜索中移除相应的标记。
