# 工作区

工作区是各种窗口和面板以及其他界面选项的有序排列。预定义的“工厂”工作区包含默认的“Maya 经典”(Maya Classic)工作区，以及另外几个专用于执行各组任务的工作区。此外，您也可以根据自己的需求创建和共享自定义工作区。

您可以修改当前工作区，方法包括：打开、关闭和移动窗口、面板和其他 UI 元素，以及停靠和取消停靠窗口和面板。

无需明确保存对工作区所做的更改。切换到其他工作区或关闭 Maya 时，您所做的更改将自动保存，并在下次切换回该工作区或重新启动 Maya 时还原。

- 对预定义工作区所做的更改将以覆盖的形式保存。您可以通过以下方式随时还原工作区的原始配置：切换到工作区，然后选择“窗口 > 工作区 > 将‘[工作区]’重置为出厂默认值”(Windows > Workspaces > Reset "[Workspace]" to Factory Default)（或者，从“工作区”(Workspace)下拉菜单中选择“重置当前工作空间”(Reset Current Workspace)）。

- 仅保存对自定义工作区所做的更改。如果已进行更改，但尚未切换到其他工作区或关闭 Maya，则可以按照与还原覆盖更改相同的方式还原所做的更改。

与旧版[面板布局](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-CE65526A-6427-4177-8780-337D74512F40)功能相比，通过工作区可以更灵活地自定义界面。特别是，工作区可用于将面板移动和停靠到任何位置，而面板布局仅控制[视图面板](视图面板.md)中的排列。另一个区别就是，工作区将自动作为单独的文件存储到用户目录中并持续存在，而面板布局则存储在场景文件中。

## 切换工作空间

请执行下列任一操作：

- 从主菜单栏最右侧的“工作区”(Workspace)选择器中，选择一个项目。

  ![图：从主菜单栏最右侧的“工作区”(Workspace)选择器中，选择一个项目。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-C1F0E0B0-2134-4863-B894-0954D45DC37A.png) <!-- baize:img-hook downloaded=false reason="正文 711 字 ≥300，非承重" -->

- 从“窗口 > 工作区”(Windows > Workspaces)菜单中选择一个项目。
