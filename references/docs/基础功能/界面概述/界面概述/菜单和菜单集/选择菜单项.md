# 选择菜单项

在 Maya 中，可以使用不同的方法从菜单中选择项目：

- Maya 窗口顶部的主菜单。请参见[菜单和菜单集](../菜单和菜单集.md)。

- 工具架，其中最常用的菜单项还提供了图标；例如，“装备”(Rigging)菜单集中的常用命令在“装备”(Rigging)工具架中提供了图标。请参见[工具架](../工具架.md)。

- 热盒。请参见[从热盒选择操作](从热盒选择操作.md)

- 标记菜单。请参见[标记菜单](标记菜单.md)

## 操作和工具

几乎所有的菜单项都是操作，但也有一些工具。

  选择某个操作菜单项时，将在选定对象或组件上执行该操作。

  根据您选择对象的顺序不同，某些操作的工作方式也有所不同。例如，先选择要约束的所有对象，然后选择上次创建约束时要约束的对象。

  如果顺序很重要，Maya 窗口底部的帮助行中会显示选择顺序的说明。

  选择某个工具菜单项时，该工具将会激活。稍后，您可以在对象或组件上使用该工具。工具处于活动状态时，帮助行中会显示使用说明。

  该工具将保持活动状态，直到您通过选择另一个工具退出为止。

“曲线”(Curves)和“曲面”(Surfaces)菜单中的许多项可以从操作转化为工具（反之亦然），请参见[在操作和工具之间切换操作](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-70065EC3-64FE-44F2-B71A-D02F110809AA)。

## 快速重复最后菜单项

通过 Maya 主菜单中的菜单项或使用鼠标中键时出现的“面板”(Panel)菜单，您可以快速重复最后一个操作。例如，如果最后一个操作是打开“窗口 > 动画编辑器 >曲线图编辑器 ”(Windows > Animation Editors > Graph Editor)，则使用鼠标中键单击“窗口”(Windows)菜单可重新打开“曲线图编辑器”(Graph Editor)。这也适用于子菜单。

在[“面板”(Panel)菜单](../../../基本参考/基本参考/面板菜单.md)上使用鼠标中键可切换单选或复选框选择（如果可用）。

**注**

您不能使用鼠标中键对

“面板 > 渲染器”(Panel > Renderer)

菜单项重复同样的操作。
