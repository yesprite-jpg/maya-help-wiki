## “套索工具”(Lasso Tool)选项

#### 绘制样式(Draw Style)

设定套索是否会自己自动关闭。

#### 打开(Open)

当绘制套索时，形状会保持打开。

#### 闭合(Closed)

当绘制套索时，Maya 将连接结束点和开始点以显示封闭的空间。

#### 组件选择(Component Selection)

设定 Maya 在套索区域中选择组件的精度。

#### 快速(Fast)

当释放鼠标按钮时，使用套索形状的近似来选择组件的速度稍微更快。

#### 精确(Accurate)

当释放鼠标按钮时，使用套索的精确形状，但会花费更长的时间来选择组件。

在较新的计算机上，“快速”(Fast)和“精确”(Accurate)组件选择之间的速度差异很小。
