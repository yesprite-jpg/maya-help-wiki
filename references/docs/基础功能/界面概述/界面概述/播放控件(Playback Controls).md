# 播放控件(Playback Controls)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-B4AB7BDA-DB3E-4952-814B-10DAFE28CD1F.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

“播放控件”是一组播放动画和遍历动画的按钮。播放范围显示在“时间滑块”(Time Slider)中。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-D90C7E2D-381E-420C-9019-A157507C8058.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击转到开头按钮转到播放范围的起点。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-B26B3FF7-7BB8-4200-BE97-3ABC946BECDC.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击后退帧按钮后退一个时间。默认热键：Alt + ,（逗号）键用于 Windows 和 Linux；Option +,（逗号）键用于 Mac OS X。Linux 用户应该确定其 Alt 键功能是否已与 Super 键切换，以解释此热键指令和本主题中的其他热键指令。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-EFD795E4-F0D0-4F50-A1DF-04ACC04F5F90.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击后退关键帧按钮后退一个关键帧。默认热键：,（逗号）键。

**注**

提示：

仅当选择了已设置关键帧的对象，且关键帧显示在

时间滑块(Time Slider)

中时，此按钮才可用。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-791D9CC0-E9F9-4B84-8B2B-AB8B8DD9FA25.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击向后播放按钮以反向播放。按 Esc 键停止播放。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-58B15465-A0A8-4E09-94B8-04077466106A.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击向前播放按钮以正向播放。默认热键：Alt + v 用于 Windows 和 Linux；Option + v 用于 Mac OS X。按 Esc 键可停止播放。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-B2646A96-36F2-4FFF-A4D0-217F229585B6.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击前进关键帧按钮前进一个关键帧。默认热键：.（句点）键。

**注**

提示：

仅当选择了已设置关键帧的对象，且关键帧显示在

时间滑块(Time Slider)

中时，此按钮才可用。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-6849F994-603D-4031-AEDB-0DF448289E8A.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击前进帧钮前进一个时间（或帧）。默认热键：Alt + .（句点）键用于 Windows 和 Linux；Option + .（句点）键用于 Mac OS X。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-69EF3DBD-B407-495F-8D2D-7323CECE837B.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击转到结尾按钮转到播放范围的结尾。

#### ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-6E9CAAF6-396C-4DCB-95C3-545218A61404.png) <!-- baize:img-hook downloaded=false reason="正文 576 字 ≥300，非承重" -->

单击停止按钮停止播放。此按钮仅在播放动画时显示，用于替换向前播放或向后播放按钮。默认热键：Esc 键。
