# 范围滑块(Range Slider)

范围滑块（位于[时间滑块](时间滑块%28Time%20Slider%29.md)下方）用于控制“时间滑块”(Time Slider)中体现的播放范围。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F8FB07B8-EF85-4B10-AAEF-7AEE0B2E3391.png) <!-- baize:img-hook downloaded=false reason="正文 1038 字 ≥300，非承重" -->

**A.** 动画开始时间(Animation Start Time) **B.** 播放开始时间(Playback Start Time) **C.**“范围滑块”(Range Slider)栏 **D.** 播放结束时间(Playback End Time) **E.** 动画结束时间(Animation End Time) **F.**“时间滑块书签”(Time Slider Bookmark)图标 **G**. “角色集”(Character Set)菜单 **H.**“动画层”(Animation Layer)菜单

有关显示在范围滑块旁边的“帧速率”(Framerate)、“循环”(Loop)、“自动关键帧”(Auto Key)和“动画”(Animation)图标的信息，请参见[播放选项](播放选项%28Playback%20Options%29.md)。

**注**

“时间滑块书签”(Time Slider Bookmarks) (

F

) 和“角色集”(Character Set)菜单 (

G

) 在 Maya LT 中不可用。

#### 动画开始时间

（上图中的 **A**。）

该字段用于设定动画的开始时间。

#### 播放开始时间

（上图中的 **B**。）

该字段用于显示播放范围的当前开始时间。可输入新的开始时间（包括负值）来更改该时间。如果输入的值大于播放结束时间，播放结束时间将被调整为大于播放开始时间的时间单位。

#### “范围滑块”(Range Slider)栏

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-FDB0BD8C-3F23-46F0-883A-C87C9380D568.gif) <!-- baize:img-hook downloaded=false reason="正文 1038 字 ≥300，非承重" -->

（上图中的 **C**。）

拖动范围滑块的任意一端可手动延长或缩短播放范围。

#### 播放结束时间

（上图中的 **D**。）

该字段用于显示播放范围的当前结束时间。可以输入新的结束时间来更改此时间。如果输入的值小于播放开始时间的值，播放开始时间将移动到小于播放结束时间的时间单位。

也可以从“动画首选项”(Animation Preferences)窗口编辑上述设置。

**注**

对范围滑块所做的更改可撤消。您可以使用

“合并时间更改”(Consolidate Time Changes)

选项在

撤消首选项

中更改此设置。

#### 动画结束时间

（上图中的 **E**。）

该字段用于设定动画的结束时间。

#### “时间滑块书签”(Time Slider Bookmark)图标

（上图中的 **F**。）
