# 层编辑器(Layer Editor)

默认情况下，层编辑器显示在[通道盒(Channel Box)](../../节点和属性/节点和属性/查看和编辑属性/通道盒%28Channel%20Box%29.md)面板的底部。单击“通道盒/层编辑器”(Channel Box/Layer Editor)图标可将其打开。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-4851D584-0F1B-4011-8D86-46B1C9F8CFC1.png) <!-- baize:img-hook downloaded=false reason="正文 612 字 ≥300，非承重" -->

“层编辑器”(Layer Editor)包含许多选项卡，支持您显示两个不同的编辑器来处理不同类型的层。

- [显示层](../../场景管理/场景管理/组织对象/组织显示层中的对象.md)用于组织和管理场景中的对象，例如，用于设置可见性和可选性的层。

- [动画层](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-5C202CB8-EB3C-4ADE-B203-5F93A9FD9104)用于融合、锁定或禁用动画的多个级别。

在所有情况下，都有一个默认层，对象在创建后最初放置在该层。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-E83BDF36-F0AC-4741-BF68-F4D4E8CE1F69.png) <!-- baize:img-hook downloaded=false reason="正文 612 字 ≥300，非承重" -->

如果在“首选项”(Preferences)窗口（选择“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)，然后选择“UI 元素”(UI Elements)）中禁用“在通道盒内显示层编辑器”(Show Layer Editor within Channel Box)选项，则可独立显示“层编辑器”(Layer Editor)。

然后，单击状态行中的“层编辑器”(Layer Editor)图标将其打开。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-F4FA1F6A-8235-440F-AEDB-41AD14DC2B94.png) <!-- baize:img-hook downloaded=false reason="正文 612 字 ≥300，非承重" -->

**注**

早期版本的

“层编辑器”(Layer Editor)

中提供的

渲染层编辑器

已替换为此新渲染设置系统。如果要使用传统渲染层系统，请打开“首选项”(Preferences)窗口中，选择

“渲染”(Rendering)

类别，然后选择

“传统渲染层”(Legacy Render Layers)

作为

“首选渲染设置系统”(Preferred Render Setup system)

。
