# 共享工作区

您可以轻松导出和导入工作区，与其他用户共享。工作区将以 .json 格式存储为文本文件。

## 导出工作区

若要导出[保存的工作区](创建自定义工作区.md)，仅需在首选项文件夹的 workspaces/ 子文件夹中找到其文件，然后将其复制到可供其他用户访问的位置即可。有关首选项文件夹的默认位置，请参见[保存(Save)首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A11EDD96-3362-4186-BE82-A245B46A0165)。

## 导入(Import)首选项

1. 选择“窗口 > 工作区 > 导入工作区文件”(Windows > Workspaces > Import Workspace Files)（或者，从“工作区”(Workspace)下拉菜单中选择“导入工作区文件”(Import Workspace Files)）。

2. 导航到要导入的文件所在的位置。

3. 选择一个或多个文件。

4. 单击“导入”(Import)。
