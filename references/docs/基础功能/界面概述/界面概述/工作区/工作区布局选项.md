# 工作区布局选项

“工作区布局选项”(Workspace layout options)窗口可将工作区与各种界面选项相关联。若要打开该窗口，请选择“窗口 > 工作区”(Windows > Workspaces) > [工作区名称] > ![图：“工作区布局选项”(Workspace layout options)窗口可将工作区与各种界面选项相关联。若要打开该窗口…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 365 字 ≥300，非承重" -->。

#### 将菜单集链接到此工作区(Link a Menu Set to this workspace)

切换到此工作区时激活选定菜单集。若要创建自定义菜单集，请参见[自定义菜单集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-28BE157E-C4A0-4840-9D93-913914078025)。

#### 将热键集链接到此工作区(Link a Hotkey Set to this workspace)

切换到此工作区时激活选定热键集。若要创建自定义热键集，请参见[热键编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-36D24C0F-19E4-411E-8CA9-DB7B64C3E6EA)。

#### 将 VP2.0 预设链接到此工作区(Link a VP2.0 Preset to this workspace)

切换到此工作区时加载视口选项的预设。若要创建自定义视口预设，请参见 [Viewport 2.0 选项](../../../基本参考/基本参考/面板菜单/面板菜单：渲染器/Viewport%202.0%20选项.md)。
