# 工具设置(Tool Settings)

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-BDEE3BCC-48A6-4187-AA76-1E659594DF93.png) <!-- baize:img-hook downloaded=false reason="正文 306 字 ≥300，非承重" -->

“工具设置”(Tool Settings)面板将为当前选定工具显示许多工作选项。例如，可以在此面板中设置选择（如下所示）、移动、旋转、缩放工具的许多选项。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-049A912A-37E3-4B1E-BDAD-DA602436D651.png) <!-- baize:img-hook downloaded=false reason="正文 306 字 ≥300，非承重" -->

若要打开“工具设置”(Tool Settings)面板，请执行以下操作之一：

- 在[状态行](状态行（工具栏）.md)右侧，单击侧栏图标中的“工具设置”(Tool Settings)图标。

- 双击[工具箱](工具箱%28Tool%20Box%29.md)中的任何工具图标（例如，“选择”(Select)或“移动”(Move)工具。

- 选择“窗口 > 常规编辑器 > 工具设置”(Windows > General Editors > Tool Settings)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-8F93C40F-EF93-458D-A3E6-075D77DCD09A.gif) <!-- baize:img-hook downloaded=false reason="正文 306 字 ≥300，非承重" -->

通过工具箱和侧栏图标打开“工具设置”(Tool Settings)面板
