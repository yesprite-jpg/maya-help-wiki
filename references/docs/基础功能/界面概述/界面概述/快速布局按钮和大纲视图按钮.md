# 快速布局按钮和大纲视图按钮

快速布局按钮和大纲视图按钮位于[工具箱](工具箱%28Tool%20Box%29.md)的正下方。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../assets/Maya-Basics/GUID-337C3B3C-50A0-46D4-BFA6-2CA14B78C212.png) <!-- baize:img-hook downloaded=true reason="正文 111 字 <300 且带图" -->

- 最上面的三个按钮可将视图面板切换为一个窗格、四个窗格或两个窗格并列放置。您可以单击鼠标右键查看其他选项。

- 底部按钮将打开[大纲视图](../../节点和属性/节点和属性/大纲视图%28Outliner%29.md)。
