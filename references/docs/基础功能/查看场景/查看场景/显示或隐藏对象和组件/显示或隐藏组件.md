# 显示或隐藏组件

使用“显示 > NURBS”(Display > NURBS)和“显示 > 多边形”(Display > Polygons)子菜单以及“显示 > 隐藏”(Display > Hide)和“显示 > 显示”(Display > Show)子菜单中的项目。

**注**

提示：

处于组件选择模式下时，Maya 会自动显示选定对象上的组件。

| 目标 | 操作 |
|---|---|
| 隐藏选定多边形组件：面（多边形）、边或顶点（点）。 | 执行下列操作之一： 按 Ctrl+H 或 H 键 选择“显示 > 隐藏 > 隐藏当前选择”(Display > Hide > Hide Selection) 注： 选定的边和顶点会在隐藏之前转化为面。 |
| 隐藏未选定对象或组件。 | 按 Alt+H |
| 显示选定组件。 | 按 Shift+H |
| 显示选定对象上所有隐藏的多边形组件。 | 执行下列操作之一： 按 Ctrl+Alt+H 或 Shift+H 在组件模式下，当未选择其他组件或已选定多个隐藏和非隐藏组件时按 H 键。 使用“显示 > 显示 > 所有组件”(Display > Show > All Components)。 |
| 显示上次隐藏的一组组件或对象。 | 按 Ctrl+Shift+H |
| 显示或隐藏选定对象上的 NURBS 组件。 | 使用“显示 > NURBS”(Display > NURBS)子菜单。 |
| 显示所有 NURBS 曲面上的 CV。 | 选择“显示 > 显示 > 所有曲面”(Display > Show > All Surface CVs)。 |
| 显示或隐藏选定多边形上的背面（隐藏在其他面后面的多边形面）。 | 选择“显示 > 多边形 > 背面消隐”(Display > Polygons > Backface Culling)。 |
