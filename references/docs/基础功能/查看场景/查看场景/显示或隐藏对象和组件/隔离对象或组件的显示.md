# 隔离对象或组件的显示

通过显示在场景视图上方的[视图面板](../../../界面概述/界面概述/视图面板.md)中的“隔离选择”(Isolate Select)命令，可以仅显示场景中的某些对象或组件。每个面板都保留自己的“隔离选择”(Isolate Select)设置。

与显示 > 隐藏(Display > Hide)命令不同，“隔离选择”(Isolate Select)支持隔离组件（多边形顶点、面和边、NURBS CV 或细分曲面的面）和对象，并且只影响显示，而不影响渲染。

| 目标 | 操作 |
|---|---|
| 仅在面板中显示选定对象/组件。 | 执行下列操作之一： 在面板中，启用“显示 > 隔离选择 > 查看选定对象”(Show > Isolate Select > View Selected)。 按 **Ctrl** + **1** |
| 当选择更改时始终仅在面板中显示选定对象。 | 在面板中，启用“显示 > 隔离选择 > 自动加载选定对象”(Show > Isolate Select > Auto Load Selected Objects)。 |
| 选择隔离子集中是否将包含新对象。 | 在面板中，启用或禁用“显示 > 隔离选择 > 自动加载新对象”(Show > Isolate Select > Auto Load New Objects)。 |
| 关闭“自动加载”时在隔离子集中添加或移除对象。 | 在面板中： 若要将隔离子集更改为当前选择，请选择“显示 > 隔离选择 > 加载选定对象”(Show > Isolate Select > Load Selected Objects)。 若要将当前选择添加到隔离子集，请选择“显示 > 隔离选择 > 添加选定对象”(Show > Isolate Select > Add Selected Objects)。 若要从隔离子集中移除当前选择，请选择“显示 > 隔离选择 > 移除选定对象”(Show > Isolate Select > Remove Selected Objects)。 |
| 保存并重用隔离设置。 | 在面板中： 若要保存当前的隔离设置，请选择“显示 > 隔离选择 > 书签 > 为当前对象建立书签”(Show > Isolate Select > Bookmarks > Bookmark Current Objects)。 若要撤消隔离子集，请从“显示 > 隔离选择 > 书签”(Show > Isolate Select > Bookmarks)子菜单中选择该隔离子集。 |
