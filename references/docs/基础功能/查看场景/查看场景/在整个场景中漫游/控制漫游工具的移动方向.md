# 控制漫游工具的移动方向

控制移动方向

1. 激活漫游模式。请参见[在整个场景中漫游](../在整个场景中漫游.md)。

2. 单击并按住鼠标按钮（请参见[控制漫游速度](控制漫游工具的速度.md)），然后按以下键或热键之一：

  **注**

  当漫游模式处于活动状态时，鼠标可以控制移动速度，键盘可以控制移动方向。您必须同时使用鼠标和键盘才能在整个场景中漫游。例如，要以较慢的速度向前移动，请单击鼠标中键并按 W 键或按上箭头键。

  | 目标 | 使用该箭头键 | 使用此移动热键 |
  |---|---|---|
  | 向后移动 | 下箭头键 | S |
  | 向前移动 | 上箭头键 | W |
  | 向左移动 | 左 | A |
  | 向右移动 | 右 | D |
  | 向上移动 |  | Q 或 /（正斜线） |
  | 向下移动 |  | E 或 '（单引号） |
  | 沿对角移动 | 向上 + 向左或向右 向下 + 向左或向右 | W + A 或 D S + A 或 D |
