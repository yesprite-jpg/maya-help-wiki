# 控制漫游工具的速度

控制漫游工具的速度

1. 激活漫游模式。请参见[在整个场景中漫游](../在整个场景中漫游.md)。

2. 单击并按住鼠标按钮：

  - 单击鼠标左键使用正常速度。

  - 单击鼠标中键使用较慢的速度。

  - 单击鼠标右键使用较快的速度。

  **注**

  提示：

  调整

  “漫游设置”(Walk Settings)

  中的

  “漫游速度倍增”(Walk speed multiplier)

  ，以加快或降低默认漫游速度。

3. 按住鼠标键，然后按箭头键或移动热键。请参见[控制漫游工具的移动方向](控制漫游工具的移动方向.md)。

  **注**

  当漫游模式处于活动状态时，鼠标可以控制移动速度，键盘可以控制移动方向。您必须同时使用鼠标和键盘才能在整个场景中漫游。例如，要以较慢的速度向前移动，请单击鼠标中键并按 W 键或按上箭头键。
