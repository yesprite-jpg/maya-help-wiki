# 翻滚、平移、推拉、侧滚或缩放摄影机

通过移动摄影机了解环视场景的不同方法。

若要环视场景，可以移动当前位于视图面板中的摄影机。这适用于任何类型的摄影机。

有关可用摄影机导航工具的完整列表，请参见[摄影机工具(Camera Tools)菜单](../../../基本参考/基本参考/面板菜单/面板菜单：“视图”%28View%29/“摄影机工具”%28Camera%20Tools%29菜单.md)。

|---|---|

| ![图：平移摄影机](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-5C4FA735-59C2-43D4-8848-B5084F38068D.gif) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" --> 平移摄影机 | Alt + 鼠标中键拖动 或 选择“视图 > 摄影机工具 > 平移工具”(View > Camera Tools > Track Tool) |
| ![图：推拉摄影机](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-18D73B28-DD55-4448-9C6C-BB021AB4C30A.gif) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" --> 推拉摄影机 | 按住 Alt 键并单击鼠标右键拖动或单击鼠标左键和中键拖动 或 选择“视图 > 摄影机工具 > 推拉工具”(View > Camera Tools > Dolly Tool) 或 按住 Alt 和 Ctrl 键并拖动要推拉到的场景部分周围的框。 如果将框从左侧拖动到右侧，则推入。 如果从右到左拖动框，则进行拉摄。 |
