# 返回默认视图和上一个视图

您可以在会话中在摄影机拥有的不同视图之间切换，或者将视图保存为书签以便随时返回。

| 目标 | 操作 |
|---|---|
| 返回摄影机的默认视图 | 按 Alt+Home 或 在视图面板中，选择“视图 > 默认视图”(View > Default View) |
| 在视图历史中返回。 | 按 [ |
| 在视图历史中前进。 | 按 ] |
| 撤消或重做当前摄影机视图。 | 在视图面板中选择“视图 > 撤消视图更改”(View > Undo View Change)或“重做视图更改”(Redo View Change) |
| 添加（保存）当前摄影机视图书签。 | 单击视图面板工具栏中的“书签”(Bookmark)图标 ![图：单击视图面板工具栏中的“书签”(Bookmark)图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-2E11C6F3-C583-4711-ACB7-19103254171A.png) <!-- baize:img-hook downloaded=false reason="正文 569 字 ≥300，非承重" -->。 或 选择“视图 > 书签 > 编辑书签”(View > Bookmarks > Edit bookmarks)。 单击“新建书签”(New bookmark)，可将当前摄影机视图保存到书签。 将书签名称更改为说明性的内容。 书签将保存到该摄影机，而非视图面板。 |
| 返回已添加书签的视图。 | 在“书签”(Bookmark)图标 ![图：在“书签”(Bookmark)图标 上单击鼠标右键，然后选择一个书签。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-2E11C6F3-C583-4711-ACB7-19103254171A.png) <!-- baize:img-hook downloaded=false reason="正文 569 字 ≥300，非承重" --> 上单击鼠标右键，然后选择一个书签。 或 选择“视图 > 书签”(View > Bookmarks)，然后单击书签名称。 |
| 将书签添加到工具架 | 打开要向其添加书签的工具架。 选择“视图 > 书签 > 编辑书签”(View > Bookmarks > Edit bookmarks)。 单击书签。 单击“添加到工具架”(Add to shelf)。 |
