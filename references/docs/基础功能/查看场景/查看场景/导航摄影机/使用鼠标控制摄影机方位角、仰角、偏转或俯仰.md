# 使用鼠标控制摄影机方位角、仰角、偏转或俯仰

| 在面板上，选择... | 按住鼠标左键... |
|---|---|
| 视图 > 摄影机工具 > 方位角仰角工具(View > Camera Tools > Azimuth Elevation Tool) | 左右拖动鼠标可改变方位角。 上下拖动鼠标可改变仰角。 |
| 视图 > 摄影机工具 > 偏转-俯仰工具(View > Camera Tools > Yaw-Pitch Tool) | 左右拖动鼠标可改变偏转。 上下拖动鼠标可改变俯仰。 |
| 视图 > 摄影机工具 > 飞行工具(View > Camera Tools > Fly Tool) | 拖动以改变偏转和俯仰。 按住 Ctrl 键的同时上下拖动以前进或后退。 |
