# 查看渲染和播放预览图像和动画

1. 请执行下列任一操作：

  - 要查看图像，请从主菜单栏中选择“文件 > 查看图像”(File > View Image)。

  - 要查看动画，请选择“文件 > 查看序列”(File > View Sequence)。

2. 在显示的“打开”(Open)文件浏览器中，选择目标图像并单击“打开”(Open)。

  默认情况下，会启动 FCheck 以显示图像或图像序列。

  **注**

  重要：

  自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

  应用程序首选项

  （

  “窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

  ）中选择其他默认图像查看器。（另请参见

  指定默认媒体播放器

  。）
