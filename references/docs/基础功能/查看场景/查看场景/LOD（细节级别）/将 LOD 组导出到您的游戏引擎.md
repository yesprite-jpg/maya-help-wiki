# 将 LOD 组导出到您的游戏引擎

1. 在“大纲视图”(Outliner)或“Hypershade”中选择 LOD_Group_*n* 节点。

  （有关设置 LOD 的信息，请参见[创建 LOD 组](创建%20LOD%20组.md)。）

2. 从主菜单栏中选择“文件 > 导出当前选择”(File > Export Selection)。

3. 在“导出当前选择”(Export Selection)窗口中，设定“FBX 导出”(FBX Export)作为文件类型。

  **注**

  重要：

  为了确保 LOD 阈值设置能够传递，请在

  “导出当前选择”(Export Selection)

  窗口中确认

  “动画”(Animation)

  处于启用状态且

  “FBX 插件版本”(FBX plug-in version)

  为 2016.1 或更高版本。

4. 输入文件名，然后单击“导出当前选择”(Export Selection)。

  包含 LOD 的 FBX 文件将保存到指定的位置。

有关将 LOD 导入到您的游戏引擎的详细信息，请参见游戏引擎文档。
