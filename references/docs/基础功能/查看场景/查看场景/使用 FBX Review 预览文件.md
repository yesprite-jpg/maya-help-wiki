# 使用 FBX Review 预览文件

FBX Review 使您可以在 FBX Review 应用程序中无缝启动导出的文件。

1. 下载并安装 FBX Review 应用程序。

  选择“帮助 > 尝试使用其他 Autodesk 产品 > FBX Review”(Help > Try Other Autodesk Products > FBX Review)以打开下载页面。

2. 将场景导出为 FBX 文件，需要注意以下事项：

  - 使用传统的导出工作流（[将对象导出到新文件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-664060EB-EA35-4CD3-83EB-CBCAF59B4495)），您可以保存 FBX 文件并在稍后根据需要使用 FBX Review 查看。

  - 使用“游戏导出器”(Game Exporter)，您可以打开“导出后在 FBX Review 中查看文件”(View File in FBX Review after Export)选项，以在导出后立即启动该应用程序并查看该文件。（请参见[使用“游戏导出器”(Game Exporter)导出动画片段](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-31148EE5-CAA8-48F2-9E51-3C9712EE8A14)或[使用“游戏导出器”(Game Exporter)导出模型](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1D758D66-04CC-40DC-A667-479408AD0AAB)。）
