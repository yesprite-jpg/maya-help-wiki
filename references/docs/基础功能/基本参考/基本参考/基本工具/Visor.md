# Visor

Visor 可用于在使用 [Trax 编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-33C829F4-635C-4DEB-956C-6A54BEE1EC89)的同时访问动画源和片段内容。它提供了以下选项卡：“角色片段”(Character Clips)、“角色姿势”(Character Poses)、“未使用的片段”(Unused Clips)和“未使用的姿势”(Unused Poses)。有关详细信息，请参见[将 Visor 与 Trax 结合使用](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D1359607-4AA9-4637-B15A-71EE755EB682)。

以前可从 **Visor** 中获得的所有采样内容现在均可从[**内容浏览器**](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9221B2E8-7E68-4ECB-94DC-ABEB21E956BF)中获得。
