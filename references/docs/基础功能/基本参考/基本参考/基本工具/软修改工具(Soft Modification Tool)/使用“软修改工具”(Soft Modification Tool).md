# 使用“软修改工具”(Soft Modification Tool)

在设置“软修改工具”(Soft Modification Tool)的选项时，它们会影响执行的下一次软修改，而不是当前的软修改。建议在使用该工具前设定这些选项。如果要编辑当前选定软修改的选项，可以在“属性编辑器”(Attribute Editor)中调整 **softMod** 节点上的属性。

有关 softMod 变形器节点属性，请参见 Maya 技术文档中的 [softMod](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Commands/softMod.html) 命令。

使用软修改来变形对象或组件

1. 通过选择“修改 > 变换工具 > 软修改”(Modify > Transformation Tools > Soft Modification) > ![图：通过选择“修改 变换工具 软修改”(Modify Transformation Tools Soft Modificat…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 672 字 ≥300，非承重" --> ，查看或设置工具选项。有关详细信息，请参见[软修改(Soft Modification)选项](软修改%28Soft%20Modification%29选项.md)。

2. 选择要变形的对象或组件。

3. 选择“修改 > 变换工具 > 软修改”(Modify > Transformation Tools > Soft Modification)。

4. 使用操纵器创建一个变形。

  启用“颜色反馈”(Color Feedback)后，可以查看“软修改”(Soft Modification)工具的影响区域。

5. 调整 **softMod** 属性以便以交互方式修改变形。

  **注**

  提示：

  如果在

  选择首选项

  中启用

  “单击拖动选择”(Click Drag Select)

  ，可以轻松选择

  “软修改工具”(Soft Modification Tool)

  ，然后单击拖动对象进行修改。这样可以在一个对象上快速执行几个修改。

  请参见[示例 2：不会创建历史的软修改](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A8EDEF67-6D1E-4EBF-B3D7-2C6E2A578D8A)。
