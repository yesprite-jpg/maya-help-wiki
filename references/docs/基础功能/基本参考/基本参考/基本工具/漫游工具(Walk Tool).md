# 漫游工具(Walk Tool)

“漫游工具”(Walk Tool)可让您使用游戏中使用的同类第一人称摄影机控件来控制 Maya 的透视摄影机。

若要打开“漫游”(Walk)工具，请使用热键 Alt + X，或从面板菜单中选择“视图 > 摄影机工具 > 漫游工具”(View > Camera Tools > Walk Tool)。

Maya 处于漫游模式下时，光标将变为一个多方向的箭头 ![图：Maya 处于漫游模式下时，光标将变为一个多方向的箭头 ，并且视口底部会显示一条平视显示仪消息。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-B696A75B-7C3F-4F08-9E06-653F7C9E03C9.png) <!-- baize:img-hook downloaded=false reason="正文 575 字 ≥300，非承重" -->，并且视口底部会显示一条平视显示仪消息。

**注**

重要：

当漫游模式处于活动状态时，鼠标可以控制移动速度，键盘可以控制移动方向。您必须同时使用鼠标和键盘才能在整个场景中漫游。例如，要以较慢的速度向前移动，请单击鼠标中键并按 W 键，或按上箭头键。

## 鼠标控件

| 目标 | 操作 |
|---|---|
| 环视场景 | 拖动光标。 |
| 选择一个正常的速度 | 单击鼠标左键 |
| 选择一个较慢的速度 | 单击鼠标中键 |
| 选择一个较快的速度 | 单击鼠标右键 |

请参见[控制漫游工具的速度](../../../查看场景/查看场景/在整个场景中漫游/控制漫游工具的速度.md)。

## 键盘控件

| 目标 | 使用该箭头键 | 使用此移动热键 |
|---|---|---|
| 向后移动 | 下箭头键 | S |
| 向前移动 | 上箭头键 | W |
| 向左移动 | 左 | A |
| 向右移动 | 右 | D |
| 向上移动 |  | Q 或 /（正斜线） |
| 向下移动 |  | E 或 '（单引号） |
| 沿对角移动 | 向上 + 向左或向右 向下 + 向左或向右 | W + A 或 D S + A 或 D |

请参见[控制漫游工具的移动方向](../../../查看场景/查看场景/在整个场景中漫游/控制漫游工具的移动方向.md)。

| 目标 | 操作 |
|---|---|
| 蹲伏 | Ctrl 提示： 按住 Ctrl 键可以激活蹲伏模式，直到松开此键为止。按 Ctrl 键一次可以激活蹲伏模式，直到再次按 Ctrl 键为止。 |
| 放大 | 向上滚动鼠标滚轮。 |
| 缩小 | 向下滚动鼠标滚轮。 |
