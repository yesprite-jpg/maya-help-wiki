# 通用操纵器(Universal Manipulator)

- 修改 > 变换工具 > 通用操纵器(Modify > Transformation Tools > Universal Manipulator)

“通用操纵器”(Universal Manipulator)合并了“移动工具”(Move Tool)、“旋转工具”(Rotate Tool)和“缩放工具”(Scale Tool)的功能。还可以使用它输入精确的值来直接在场景视图缩放和旋转对象。

## 通用操纵器选项

当“通用操纵器”(Universal Manipulator)处于活动状态时，可以在[工具设置(Tool Settings)](../../../界面概述/界面概述/工具设置%28Tool%20Settings%29.md)中设置下列选项：

### 变换空间(Transform Space)

#### 局部(Local)

通用操纵器遵循对象的轴。

#### 世界(World)

通用操纵器遵循世界空间轴。

### 旋转枢轴(Rotate Around)

#### 中心(Center)

绕对象的中心旋转。

#### 枢轴(Pivot)

绕枢轴点旋转。必须移动枢轴点，使其远离对象的中心，该选项才能生效。有关详细信息，请参见[更改枢轴点](../../../变换对象/变换对象/更改枢轴点.md)。
