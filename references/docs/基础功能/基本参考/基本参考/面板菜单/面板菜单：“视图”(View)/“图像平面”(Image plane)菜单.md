# “图像平面”(Image plane)菜单

从面板菜单中选择“视图 > 图像平面”(View > Image Plane)，导入要用作图像平面的文件或访问图像平面的属性。

另请参见[图像平面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E2490B87-087E-476A-9C1D-A917D009001A)和[创建、编辑或定位图像平面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F72F8E1B-EFFE-400E-BD92-5441BE9CD28F)。

#### 导入图像(Import Image)

导入图像文件以用作图像平面。

#### 导入影片(Import Movie)

导入影片文件以在图像平面上显示。

#### 图像平面属性(Image plane attributes)

访问图像平面的属性。
