# “方位角仰角工具”(Azimuth Elevation Tool)选项

“方位角”(Azimuth)工具用于在透视视图中围绕兴趣中心旋转摄影机。

摄影机视线相对于地平面的角称为仰角；摄影机视线相对于地平面垂直平面的角称为方位角。

打开“方位角仰角工具”(Azimuth Elevation Tool)选项

- 在[“视图”(View)面板](../../../../../界面概述/界面概述/视图面板.md)的[面板菜单](../../../面板菜单.md)中，选择“视图 > 摄影机工具 > 方位角仰角工具” (View > Camera Tools > Azimuth Elevation Tool) > ![图：在“视图”(View)面板的面板菜单中，选择“视图 摄影机工具 方位角仰角工具” (View Camera Tools …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Basics/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 337 字 ≥300，非承重" -->

#### 比例(Scale)

调整摄影机移动的速度。滑块范围为 0.01 到 10。默认值为 1。

#### 旋转类型(Rotation type)

控制摄影机移动是“方位角仰角”移动，还是“偏转俯仰”移动。

**注**

提示：

按住 Shift 键可约束摄影机的移动。
