# “侧滚工具”(Roll Tool)选项

绕水平轴旋转显示。

打开“侧滚工具”(Roll Tool)选项

- 在[“视图”(View)面板](../../../../../界面概述/界面概述/视图面板.md)的[面板菜单](../../../面板菜单.md)中，选择“视图 > 摄影机工具 > 侧滚工具” (View > Camera Tools > Roll Tool) > ![图：在“视图”(View)面板的面板菜单中，选择“视图 摄影机工具 侧滚工具” (View Camera Tools Rol…](../../../../../../../assets/Maya-Basics/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 177 字 <300 且带图" -->

#### 侧滚比例(Roll Scale)

调整摄影机移动的速度。滑块范围为 0.01 到 10。默认值为 1。
