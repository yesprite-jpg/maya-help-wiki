# “缩放工具”(Zoom Tool)选项

更改摄影机的焦距。放大相当于使用长焦镜头。缩小类似于使用广角镜头。在透视和正交视图中都可以进行缩放。

打开“缩放工具”(Zoom Tool)选项

- 在[“视图”(View)面板](../../../../../界面概述/界面概述/视图面板.md)的[面板菜单](../../../面板菜单.md)中，选择“视图 > 摄影机工具 > 缩放工具”(View > Camera Tools > Zoom Tool) > ![图：在“视图”(View)面板的面板菜单中，选择“视图 摄影机工具 缩放工具”(View Camera Tools Zoom…](../../../../../../../assets/Maya-Basics/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 245 字 <300 且带图" -->

**注**

若要在不更改观察角度的情况下靠近或远离，请使用[推拉](“推拉工具”%28Dolly%20Tool%29选项.md)。

#### 缩放比例(Zoom Scale)

改变摄影机移动的速度。滑块范围为 0.01 到 3。默认值为 1。
