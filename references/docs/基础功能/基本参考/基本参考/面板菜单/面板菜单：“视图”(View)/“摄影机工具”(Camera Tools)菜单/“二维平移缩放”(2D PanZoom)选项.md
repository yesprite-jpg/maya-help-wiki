# “二维平移/缩放”(2D Pan/Zoom)选项

启用二维平移或二维缩放模式，使您能够以交互方式进行平移或缩放。请参见[在二维中平移和缩放](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A7CAE8D4-B3B0-4FF8-8405-4DF3427A8DB8)。

打开“二维平移/缩放”(2D Pan/Zoom)选项

- 在[“视图”(View)面板](../../../../../界面概述/界面概述/视图面板.md)的[面板菜单](../../../面板菜单.md)中，选择“视图 > 摄影机工具 > 二维平移/缩放” (View > Camera Tools > 2D Pan/Zoom) > ![图：在“视图”(View)面板的面板菜单中，选择“视图 摄影机工具 二维平移/缩放” (View Camera Tools …](../../../../../../../assets/Maya-Basics/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 208 字 <300 且带图" -->

#### 缩放比例(Zoom scale)

调整移动的速度。

#### 模式(Mode)

在“二维平移”(2D Pan)和“二维缩放”(2D Zoom)工具之间进行选择。
