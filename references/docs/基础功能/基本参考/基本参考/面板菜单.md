# 面板菜单

显示或隐藏面板菜单

- 按 Shift+M 可启用或禁用面板菜单。

  ![图：按 Shift+M 可启用或禁用面板菜单。](../../../../assets/Maya-Basics/GUID-AEE1A8F1-6723-47FA-B38E-961385B110F6.gif) <!-- baize:img-hook downloaded=true reason="正文 84 字 <300 且带图" -->

面板菜单将在场景视图之上显示。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../assets/Maya-Basics/GUID-4FB1D402-42F4-4D78-A2E6-5B7138BE2794.png) <!-- baize:img-hook downloaded=true reason="正文 84 字 <300 且带图" -->
