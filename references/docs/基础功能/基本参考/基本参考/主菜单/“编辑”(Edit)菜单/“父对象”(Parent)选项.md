# “父对象”(Parent)选项

使用这些选项可设置在选择“编辑 > 父对象”(Edit > Parent)时会发生的状况。另请参见[建立或断开对象父子关系](../../../../选择/选择/结成或断开对象的父子关系.md)与[查看和编辑节点层次](../../../../节点和属性/节点和属性/编辑节点层次.md)。

### 父对象方法(Parent Method)

选择要对选定对象进行的操作：

#### 移动对象(Move Objects)

将对象从当前父对象移动到新的父对象（最后选定的对象）。

#### 添加实例(Add Instance)

在新组下创建实例，而不是移动对象。

#### 保持位置(Preserve Position)

启用“保持位置”(Preserve Position)时，通过更改已结成父子关系对象的变换矩阵可以保持总世界空间的位置。
