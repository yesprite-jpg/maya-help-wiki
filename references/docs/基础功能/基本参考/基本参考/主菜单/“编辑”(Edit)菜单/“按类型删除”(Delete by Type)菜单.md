# “按类型删除”(Delete by Type)菜单

使用该子菜单中的选项，可以删除场景中特定类型的所有对象，而不必单独选择每个对象。

#### 历史(History)

从当前选择中删除构建历史，在当前状态下“烘焙”。删除历史可以提高场景的性能并降低其文件大小。有关相关信息，请参见[构建历史](../../../../节点和属性/节点和属性/构建历史.md)、[编辑完成的命令（构建历史）](../../../../节点和属性/节点和属性/查看和编辑属性/编辑完成的命令（构建历史）.md)和[依存关系图](../../../../节点和属性/节点和属性/依存关系图.md)。

#### 非变形器历史(Non-Deformer History)

从对象变形中删除上游历史节点，或同时删除上游和下游历史节点，然后烘焙剩余的历史。如果要从对象历史或其他任何会降低场景重新计算速度的节点中删除建模操作，这将非常有用。若要了解此命令的可用选项，请参见[非变形器历史选项](“按类型删除”%28Delete%20by%20Type%29菜单/“非变形器历史”%28Non-Deformer%20History%29选项.md)。

#### 通道(Channels)

从选定对象中删除部分或所有通道。若要了解此命令的可用选项，请参见[通道或静态通道选项](“按类型删除”%28Delete%20by%20Type%29菜单/“通道”%28Channels%29或“静态通道”%28Static%20Channels%29选项.md)。

#### 静态通道(Static Channels)

从选定对象中删除部分或所有静态通道。若要了解此命令的可用选项，请参见[通道或静态通道选项](“按类型删除”%28Delete%20by%20Type%29菜单/“通道”%28Channels%29或“静态通道”%28Static%20Channels%29选项.md)。

#### 约束(Constraints)

从选择中删除所有约束，包括任何现有对称连接。有关信息，请参见[断开对称连接](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B15D4D00-C38D-41B8-A8C3-430B852C7E88)。

#### 运动路径(Motion Paths)

删除场景或当前选择中的所有动画运动路径。

#### 非粒子表达式(Non-particle Expressions)

删除场景或当前选择中的所有非粒子表达式。若要了解此命令的可用选项，请参见[非粒子表达式选项](“按类型删除”%28Delete%20by%20Type%29菜单/“非粒子表达式”%28Non-particle%20Expressions%29选项.md)。

#### 声音(Sounds)

删除场景或当前选择中的所有声音或选定声音。

#### 控制器(Controllers)

删除场景中的所有动画控制器。

#### 资产

删除场景或当前选择中的所有资产。

#### 刚体(Rigid Bodies)

删除场景或当前选择中的所有刚体。
