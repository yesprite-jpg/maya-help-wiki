# 删除缓存选项(Delete Cache Options)

使用这些选项可设置在选择“缓存 > 几何缓存 > 删除缓存”(Cache > Geometry Cache > Delete Cache)时发生的情况。另请参见[删除几何缓存](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-828F34D3-D28B-46D9-BC2E-6B2E7909ADA7)。

### 磁盘上的文件(Files on Disk)

设定下列选项之一：

#### 删除文件(Delete Files)

指定删除与选定几何缓存节点关联的磁盘上的几何缓存文件。

#### 保持文件(Keep Files)

指定从当前对象中分离与选定几何缓存节点关联的磁盘上的几何缓存文件。

#### 选择要删除的缓存(Select caches to delete)

在该列表中，可以选择要从当前对象删除的几何缓存节点。该列表仅在当前对象具有多个几何缓存时可用。
