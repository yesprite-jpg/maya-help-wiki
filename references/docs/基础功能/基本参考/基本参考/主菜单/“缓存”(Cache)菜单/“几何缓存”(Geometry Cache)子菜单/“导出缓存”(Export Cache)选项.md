# “导出缓存”(Export Cache)选项

使用这些选项可设置在选择“缓存 > 几何缓存 > 导出缓存”(Cache > Geometry Cache > Export Cache)创建几何缓存时发生的情况。“导出几何缓存选项”(Export Geometry Cache Options)窗口中的选项与“创建几何缓存选项”(Create Geometry Cache Options)中的相同。有关详细信息，请参见[创建新缓存选项(Create New Cache Options)](创建新缓存选项%28Create%20New%20Cache%20Options%29.md)。另请参见[创建和编辑几何缓存](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F338ECB1-F4C3-4632-9168-EB917C2353DC)。
