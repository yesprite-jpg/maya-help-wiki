# 归档场景选项(Archive Scene Options)

使用这些选项可设置在选择“文件 > 归档场景”(File > Archive Scene)时会发生什么变化。另请参见[归档场景](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C2E5B5A5-7AF1-49B8-B0C1-24CF0AB5C0FD)。

#### 包含卸载引用的外部文件(Include external files of unloaded references)

启用后，与已卸载文件引用关联的所有文件（如纹理）都包含在归档中。“包含卸载引用的外部文件”(Include external files of unloaded references)默认情况下处于禁用状态。
