# “创建 ATOM 模板”(Create ATOM Template)选项

打开“Maya Atom 模板选项”(Maya Atom Template Options)窗口。另请参见[定义角色模板以进行动画导入和导出](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F9154A73-6A6B-4A27-949A-42D7B4395845)。

#### 模板路径(Template Path)

通过该选项可以输入文件名，并浏览到想要保存 .atom 模板文件的位置。

#### 创建视图(Create View)

启用时，Maya 会将包含当前选定对象和属性的视图添加到在“模板路径”(Template Path)字段中指定的模板文件。（如在常规[模板视图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F2616A37-4119-428D-BE50-9DB9C43796EE#GUID-F2616A37-4119-428D-BE50-9DB9C43796EE__GUID-D0F39D6A-4FA6-4C11-B408-ACC8C2B8CE61)主题中所述，角色模板视图实质上是组织在一起实现特定用途的一组属性）。

**注**

提示：

在

“视图”(View)

字段中输入视图的名称，然后单击

“应用”(Apply)

。

#### 视图

“创建视图”(Create View)处于启用状态时，可以输入该视图的名称。

#### 层次(Hierarchy)

通过该选项可以指定模板是仅存储选定对象中的信息，还是存储层次所有对象的信息。（“选定”(Selected)仅根据您的当前选择存储动画，而“下方”(Below)会存储选定对象的层次中的所有已设置动画的属性。）

#### 通道

通过该选项可以指定要保存在模板文件中的通道。“所有可设置关键帧”(All Keyable)会保存选定对象动画的所有可设置关键帧的通道。“来自通道盒”(From Channel Box)仅保存在“通道盒”(Channel Box)中选定的通道。
