# 导出到脱机文件选项(Export to Offline File Options)

使用这些选项可设置选择“文件 > 导出到脱机文件”(File > Export to Offline File)时会发生什么变化。请参见[导出到脱机文件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E2D1A00B-A90C-443D-AFC5-B819A037C5B6)。

## 常规选项(General Options)

#### 文件类型(File type)

将文件类型设置为“editMB”或“editMA”。默认为“editMA”。

#### 默认文件扩展名(Default file extensions)

为 Maya ASCII 文件名添加文件扩展名 .ma，并为 Maya 二进制文件名添加文件扩展名 .mb。

## 目标选项(Target Options)

#### 导出节点(Export nodes)

设置要导出哪些场景对象的编辑。选定对象导出所有选定对象的编辑。被引用文件为在“引用编辑器”(Reference Editor)中选定的所有引用导出编辑。

## 包括选项(Include Options)

用于设置要在导出中包括的编辑类型。

## 引用选项(Reference Options)

#### 包括 setAttr 编辑(Include setAttr edits)

启用后，导出包含对 setAttr 属性所做的编辑。

## 文件类型特定选项(File Type Specific Options)

本部分中的选项根据您在“常规选项”(General Options)中选择的“文件类型”(File Type)进行更改。

## 缩略图/播放预览选项(Thumbnail/Playblast Options)

这些选项与[保存场景选项(Save Scene Options)](保存场景选项%28Save%20Scene%20Options%29.md)中的选项相同。有关使用这些选项的信息，请参见[创建场景文件的缩略图和播放预览](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67B3FB68-AAA4-415D-A37B-1EAC461613C0)。
