# “Bezier 曲线工具”(Bezier Curve Tool)选项

使用这些选项可设置在选择“创建 > 曲线工具 > Bezier 曲线工具”(Create > Curve Tools > Bezier Curve Tool)时创建的工具属性。另请参见[创建 Bezier 曲线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-772705B6-D2EC-4151-820C-7C916D4F60B2)。

#### 操纵器模式(Manip Mode)

确定选择定位点并单击鼠标中键后出现的操纵器。

### 选择模式(Select Mode)

确定如何操纵定位点切线。

#### 法线选择(Normal Select)

在操纵切线时，切线保持完整，且切线两侧在其中任意一侧缩放时均保持同等权重。

对创建平滑、对称的曲线非常有用。

#### 加权选择(Weighted Select)

在操纵切线时，切线保持完整，但只会缩放选定的一侧。

对创建向一侧加权的平滑曲线非常有用。

#### 切线选择(Tangent Select)

在操纵切线时，切线中断，且只会缩放选定的一侧。

对创建尖点非常有用。
