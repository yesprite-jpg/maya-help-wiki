# “EP 曲线工具”(EP Curve Tool)选项

使用这些选项可设置在选择“创建 > 曲线工具 > EP 曲线工具”(Create > Curve Tools > EP Curve Tool)时创建的工具属性。另请参见[绘制 NURBS 曲线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2B521AD9-1CB2-43C9-8385-388D118A5AF3)。

#### 曲线次数(Curve Degree)

“曲线次数”(Curve Degree)越高，曲线越平滑。默认设置（“3 立方”(3 Cubic)）适用于大多数曲线。

#### 结间距(Knot spacing)

结间距指定 Maya 如何将 U 位置值指定给结。“弦长”(Chord length)结间距可以更好地分布曲率。如果使用生成的曲线构建曲面，则曲面显示纹理贴图的效果可能更好。

“一致”(Uniform)结间距生成的曲线 U 位置值更容易预测。
