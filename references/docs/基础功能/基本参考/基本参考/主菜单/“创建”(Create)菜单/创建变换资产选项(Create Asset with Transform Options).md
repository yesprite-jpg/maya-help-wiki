# 创建变换资产选项(Create Asset with Transform Options)

使用这些选项，可设置选择“创建 > 资产 > 创建变换资产”(Create > Asset > Create Asset with Transform)时创建的资产属性。另请参见[创建资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A59BDB0A-0CB8-4485-A325-EA928AE59D3B)。

### 创建变换资产(Create Asset with Transform)效果

#### 运算(Operation)

确定是否已创建或预览资产。如果您希望在单击“应用”(Apply)或“应用并关闭”(Apply and Close)之后才会实际创建资产，请选择“创建变换资产”(Create asset with Transform)。否则，请选择“预览内容”(Preview contents)，在这种情况下，已设置选项但未创建资产。

### 包括选项(Include Options)

选择要包括在资产中的连接节点。
