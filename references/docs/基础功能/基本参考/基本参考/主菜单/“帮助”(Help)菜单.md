#### Maya 帮助(Maya Help)

在默认 Web 浏览器中加载 Maya **帮助** 。还可以在界面中的任意位置按 F1 键来加载帮助。

有两个版本的 Maya 帮助：默认联机版本，以及可以下载并安装在本地计算机中的脱机版本。两个版本均显示在 Web 浏览器中，保证您始终能够访问 Maya 文档。有关详细信息，请参见[使用 Maya 帮助](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7682F78F-7F32-48C6-834E-A9C40A04C77D)。
