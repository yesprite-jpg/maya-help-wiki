# 显示选项(Show Options)

您可以从“显示 > 显示”(Display > Show)子菜单中选择以下选项。另请参见[显示或隐藏组件](../../../../查看场景/查看场景/显示或隐藏对象和组件/显示或隐藏组件.md)。

#### 显示当前选择(Show Selection)

显示选定对象。

热键：Shift+H

#### 显示上次隐藏的项目(Show Last Hidden)

显示上次隐藏的选择。

热键：Ctrl+Shift+H

#### 所有曲面 CV(All Surface CVs)

显示场景中所有 NURBS 曲面上的所有 CV。

#### 所有组件(All Components)

显示选定对象上所有隐藏的多边形组件。

热键：Ctrl+Alt+H

#### 全部(All)

显示所有隐藏对象，无论它们是否已选定。

该菜单中的其他选项可以显示场景中的其他特定对象，如笔划路径曲线、摄影机和流体。
