# 添加到资产选项(Add to Asset Options)

使用这些选项可通过添加或移除节点来修改资产。如果选择两个以上资产，则 Maya 会返回错误。另请参见[将节点添加到资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E59A03D0-1B0E-4FEB-AED6-53156E17C1B1)。

#### 包括已连接的节点(Include Connected)

（仅用于添加到资产）除了选定节点外，任何通过传入或传出连接而连接的节点也将添加到选定资产。

#### 包括着色器(Include Shaders)

（仅用于添加到资产）除了选定节点外，任何已连接的着色器节点也将添加到选定资产。

#### 包括层次(Include Hierarchy)

除了选定节点外，再根据选定选项添加或删除层次中的其他节点。
