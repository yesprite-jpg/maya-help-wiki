# “高级资产”(Advanced Assets)子菜单

使用这些选项可帮助您管理高级资产。另请参见[使用资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7BBE4BC1-4B18-47DA-A972-62121764AFBF)。

## “节点发布”(Node Publishing)选项

在高级资产中发布节点时，将使用这些选项。

#### 发布为选择变换(Publish as Selection Transform)

确定在以资产为中心的选择中作为资产选择变换并用作可能父定位点和子定位点的节点。详细信息请参见[以资产为中心的选择](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A7BA2418-A28B-4BED-B07E-D1F1D4420F88#WS1A9193826455F5FF-6507591011913E8F4B8-57C3)。

#### 发布父定位点(Publish Parent Anchor)

将节点设置为保留其栓信息。这允许您对节点执行层次或名称更改，而不会断开其与未来子节点的关系。详细信息请参见[发布或取消发布节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EB86A4B0-DFAC-4B14-AB52-7355F09500B0)。

#### 发布子定位点(Publish Child Anchor)

将节点设置为保留其栓信息。这允许您对节点执行层次或名称更改，且不会断开其与未来父节点的关系。详细信息请参见[发布或取消发布节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EB86A4B0-DFAC-4B14-AB52-7355F09500B0)。

## 节点取消发布(Node Unpublishing)

希望在高级资产中取消发布节点时，将使用这些选项。

#### 取消发布选择变换(Unpublish Selection Transform)

将节点集重置为资产的选择变换（这会将以资产为中心的选择还原为默认行为）。详细信息请参见[以资产为中心选择](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A7BA2418-A28B-4BED-B07E-D1F1D4420F88#WS1A9193826455F5FF-6507591011913E8F4B8-57C3)

#### 取消发布父定位点(Unpublish Parent Anchor)

将当前作为资产的父定位点发布的节点重置为不保留其栓信息。详细信息请参见[发布或取消发布节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EB86A4B0-DFAC-4B14-AB52-7355F09500B0)

#### 取消发布子定位点(Unpublish Child Anchor)

将当前作为资产的子定位点发布的节点重置为不保留其栓信息。详细信息请参见[发布或取消发布节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EB86A4B0-DFAC-4B14-AB52-7355F09500B0)

## 设置当前资产(Set Current Asset)

可以将场景中的某个资产设置为当前资产。只有不带变换的未引用资产才可以设置为当前资产。当某个资产设置为当前资产后，后续创建的所有节点都将自动放置在该资产中。

请参见[设置当前资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2F9941C2-1D52-47C9-93E8-1CE9D2CF6BFC)。
