# “编辑属性”(Edit Attribute)选项

设置这些选项可控制属性的名称和其他详细信息。另请参见[创建、编辑或删除自定义属性](../../../../节点和属性/节点和属性/查看和编辑属性/创建、编辑或删除自定义属性.md)。

您可以对自定义属性执行以下编辑操作：

- 重命名自定义属性。

  从“属性”(Attributes)列表中进行选择，并在“新名称”(New Name)文本框中修改名称。

  **注**

  在属性名称中，除下划线 (_) 和井号 (#) 以外的所有标点都是非法字符。

- 添加、移除或修改最小值和最大值（适用于整型(Integer)、“浮点型”(Float)以及向量(Vector)类型属性）。

  从“属性”(Attributes)列表中选择属性，然后启用或禁用“具有最小值”(Has Minimum)以及“具有最大值”(Has Maximum)复选框，，并在相应的“最小值”(Min) /“最大值”(Max)文本框中键入值。

- 控制“通道盒”(Channel Box)中自定义属性的显示。

  从“属性”(Attributes)列表中选择属性，然后启用或禁用“可设定关键帧”(Keyable)复选框。启用“可设置关键帧”时，自定义属性将在“通道盒”(Channel Box)中显示。

- 更改枚举(Enum)字符串。

  在“属性”(Attributes)列表中选择“枚举”(Enum)属性，并在“枚举”(Enum)列表中修改字符串，修改方式与创建方式相同。

  **注**

  不能对字符串属性设置关键帧。

  **注**

  当创建向量类型的自定义属性时，会创建三个子属性（nameX、nameY 和 nameZ，名称即为属性名称）。

  例如，如果创建了名为“Speed”的向量属性，则子对象就是SpeedX、SpeedY 以及 SpeedZ。无法访问父向量的“数值属性的特性”(Numeric Attribute Properties)（“可设置关键帧”(Keyable)和“最小值”(Min) /“最大值”(Max)）。必须选择一个子属性并修改其“数值属性的特性”(Numeric Attribute Properties)。
