# 导出资产代理选项(Export Asset Proxy Options)

使用这些选项可设置在选择“修改 > 资产 > 导出代理资产”(Modify > Asset > Export Proxy Asset)时发生的情况。请参见[创建代理资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D64E88C-5AA9-42A9-9C42-E85555EE6B3C)。

#### 名称(Name)

确定代理资产中定位器对象的名称。

#### 创建自(Create from)

确定代理资产是创建自场景中的选定资产，还是创建自同一资产的模板（假定当前已指定模板）。如果自模板创建，会向代理资产发布占位符属性。

#### 新建代理(New proxy)

确定是将代理导出到新文件，还是显示在当前场景其创建自的资产旁边。
