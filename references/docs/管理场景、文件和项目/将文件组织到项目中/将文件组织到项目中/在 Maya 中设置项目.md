# 在 Maya 中设置项目

使用项目可管理与场景关联的所有文件。

由于场景可能取决于不同位置中的多个资源，因此项目使您可以跟踪与场景相关的文件（通过将它们存储在同一位置中）。

设置项目

1. 从菜单栏转到“文件 > 设置项目”(File > Set Project)，或在任一文件管理器对话框中单击“设置项目”(Set Project)按钮。

2. 导航到所需文件夹。

3. 单击“设置”(Set)。

设置项目时，会创建与场景关联的文件夹的目录结构。其中一些文件夹是场景文件夹、模板文件夹、渲染数据文件夹和源图像文件夹。在根项目文件夹中可能有多个子文件夹。请参见下面的“项目子文件夹”。

还创建了 *workspace.mel* 文件，并将其添加到项目。请参见 [Workspace.mel 文件](Workspace.mel%20文件.md)。

每次打开或保存文件时，Maya 都会在当前设置的项目文件夹的 Scenes 文件夹中搜索。因此，在每次开始处理新文件时设置项目是很好的做法，即使可以在项目文件夹外部进行浏览和保存。请参见下面的“项目和相对路径”。

与团队合作或使用多台计算机时，项目很有用，因为设置项目后，您的场景资产组织在同一位置中。因此，例如，如果您向同事发送场景文件，则该文件没有与之关联的纹理或脚本。如果改为发送项目文件，则您的同事打开文件时，Maya 可以找到处理它所需的所有相关文件。而且，由于所有文件都在同一位置中，因此处理项目中的场景使创建备份变得很容易。请参见[共享 Maya 项目](共享%20Maya%20项目.md)。

**注**

如果打开“项目窗口”(Project Window)（“文件 > 项目窗口”(File > Project Window)），则可以找到正在处理的项目的位置路径。[项目窗口(Project Window)](项目窗口%28Project%20Window%29.md)会显示每种类型的资源将保存到的文件夹。

您可以在此窗口中查看为“文件路径”(File Path)设置的规则。如果具有使用单个位置中的纹理的多个项目，则可能希望编辑文件规则。

## 项目子文件夹

使用[项目窗口](项目窗口%28Project%20Window%29.md)或 *workspace.mel* 文件，可以看到在项目目录中源化/保存文件的位置。以下是最常见的位置：

- 已加载和保存的文件：<project>\scenes

- 纹理：<project>\sourceimages

- 播放预览：<project>\movies

- 已渲染的图像：<project>\image

## 项目和相对路径

项目使用相对路径查找与项目关联的文件。例如，加载纹理时，Maya 首先在项目的 *sourceimages* 文件夹中查找。首次加载此纹理时，图像名称将此用作标记为 sourceimage\<*image file*> 的相对路径。

这样，您就可以将文件移动到具有 sourceimages 文件夹（即，包含相同的结构）的任何项目。这将成为*相对*文件路径规则。如果在文件路径规则之外加载纹理，则该路径将变为绝对的，例如 C:\textures\<*image file*>。可以在 [workspace.mel](Workspace.mel%20文件.md) 文件中读取文件路径规则。

**注**

提示：

如果您不确定所有的相对文件和绝对文件位于何处，请将场景文件移动到单个文件夹，因为默认情况下

Maya

将搜索它。事实上，如果删除文件夹而不使用

“项目窗口”(Project Window)

，则在场景文件所在的位置保存输出文件。
