# 创建新项目

创建新项目时，可使用 Maya 默认生成的位置和名称，也可以自己指定自定义位置和名称。用户还可以新建文件规则以指定自定义文件的自定义数据位置。请参见[创建自定义数据位置](创建自定义数据位置.md)。

开始新的项目

1. 选择“文件 > 项目窗口”(File > Project Window)。

2. 在“项目窗口”(Project Window)中，单击“新建”(New)。

  Maya 使用默认的项目位置和名称填充“项目窗口”(Project Window)。

  **注**

  在

  “项目窗口”(Project Window)

  中选择

  “编辑 > 清除设置”(Edit > Clear Settings)

  可以清除当前设置的全部项目位置。要恢复默认的项目位置，请选择

  “编辑 > 重置设置”(Edit > Reset Settings)

  。

3. 在“当前项目”(Current Project)文本框中键入新项目的名称。

4. 单击“位置”(Location)右侧的浏览 ![图：单击“位置”(Location)右侧的浏览 图标，然后指定项目目录的位置。 此位置也称为项目的根目录。可以使用此位置作为…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-DF112C02-6505-451D-BCA2-40B345450B1B.png) <!-- baize:img-hook downloaded=false reason="正文 764 字 ≥300，非承重" --> 图标，然后指定项目目录的位置。

  此位置也称为项目的根目录。可以使用此位置作为主项目位置、次项目位置以及任何其他添加至项目中的位置。

5. 要更改主项目位置的目录，请单击文本字段结尾处的浏览 ![图：要更改主项目位置的目录，请单击文本字段结尾处的浏览 图标，然后指定新目录。 否则，将把“主项目位置”(Primary P…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-DF112C02-6505-451D-BCA2-40B345450B1B.png) <!-- baize:img-hook downloaded=false reason="正文 764 字 ≥300，非承重" --> 图标，然后指定新目录。

  否则，将把“主项目位置”(Primary Project Locations)添加至指定的项目根“位置”(Location)。

6. 要更改次级数据位置或转换器数据位置的目录，请选择“编辑”(Edit)，然后单击文本字段结尾处的浏览 ![图：要更改次级数据位置或转换器数据位置的目录，请选择“编辑”(Edit)，然后单击文本字段结尾处的浏览 图标以指定新目录。 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-DF112C02-6505-451D-BCA2-40B345450B1B.png) <!-- baize:img-hook downloaded=false reason="正文 764 字 ≥300，非承重" --> 图标以指定新目录。

  否则，将把“次项目位置”(Secondary Project Locations)添加至指定的项目根“位置”(Location)。

7. 单击“接受”(Accept)以保存更改并关闭“项目窗口”(Project Window)。

  若没有项目目录和子目录，则该操作会完成项目目录和子目录的创建。
