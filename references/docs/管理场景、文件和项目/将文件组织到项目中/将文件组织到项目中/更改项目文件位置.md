# 更改项目文件位置

通过为文件位置指定不同目录，可以更改项目存储不同类型的文件的位置。例如，可以更改项目“主项目位置”(Primary Project Locations)的目录和名称。

更改项目文件存储位置

1. 选择“文件 > 项目窗口”(File > Project Window)。

2. 若要更改主项目位置的目录，请单击其文本字段结尾处的浏览 ![图：若要更改主项目位置的目录，请单击其文本字段结尾处的浏览 图标，然后指定新目录。](../../../../assets/Maya-ManagingScenes/GUID-DF112C02-6505-451D-BCA2-40B345450B1B.png) <!-- baize:img-hook downloaded=true reason="正文 292 字 <300 且带图" --> 图标，然后指定新目录。

3. 若要更改次级或转换器数据位置的目录，请确保已选择“编辑”(Edit)，然后单击浏览 ![图：若要更改次级或转换器数据位置的目录，请确保已选择“编辑”(Edit)，然后单击浏览 图标并指定新位置。 选择“使用默认值…](../../../../assets/Maya-ManagingScenes/GUID-DF112C02-6505-451D-BCA2-40B345450B1B.png) <!-- baize:img-hook downloaded=true reason="正文 292 字 <300 且带图" --> 图标并指定新位置。

  选择“使用默认值”(Use Defaults)将以默认的位置和名称来填充次级和转换器数据位置。
