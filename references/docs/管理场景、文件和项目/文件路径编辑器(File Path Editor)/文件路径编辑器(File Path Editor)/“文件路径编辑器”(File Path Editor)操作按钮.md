# “文件路径编辑器”(File Path Editor)操作按钮

通过“文件路径编辑器”(File Path Editor)操作按钮可以执行下列操作：

#### 刷新列表(Refresh List)

更新“文件路径编辑器”(File Path Editor)浏览器的内容以匹配 Maya 的当前状态。

#### 重新指定文件路径(Repath Files)

打开“重新指定路径”(Repath)窗口，可以为选定节点选择新的路径。请参见[“重新指定路径”(Repath)和“操作预览”(Actions Preview)窗口](“重新指定路径”%28Repath%29和“操作预览”%28Actions%20Preview%29窗口.md)。

**注**

提示：

您也可以通过在浏览器中的任意位置单击鼠标右键并从弹出菜单中选择

#### 替换字符串(Replace String)

打开“替换字符串”(Replace String)工具，您可以对浏览器中选定的元素执行搜索和替换功能。请参见[替换字符串(Replace String)工具](“替换字符串”%28Replace%20String%29工具.md)。

#### 自动解析(Auto Resolve)

打开“自动解析”(Auto Resolve)窗口，您可以对选定节点重新指定路径并选择相应选项，在一个操作中将重新指定路径的文件复制到新位置。
