# 文件路径编辑器(File Path Editor)

此工具列出了 Maya 场景中所含引用、纹理、音频节点和图像平面的所有目录路径。

若要打开“文件路径编辑器”(File Path Editor)，请选择“窗口 > 常规编辑器 > 文件路径编辑器”(Windows > General Editors > File Path Editor)。

“文件路径编辑器”(File Path Editor)可用于快速而轻松地诊断并修复未解析的路径，允许您重新指定断开的纹理路径，如文件纹理编辑器。

**注**

还可以使用

filePathEditor

命令来诊断和修复未解析的路径。
