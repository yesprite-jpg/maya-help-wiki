# 将对象导出到新文件

| 目标 | 操作 |
|---|---|
| 将选定对象导出到文件。 | 选择文件 > 导出当前选择(File > Export Selection)。 |
| 将场景导出为特定文件格式。 | 选择文件 > 导出全部(File > Export All)。 |

**注**

- mayaAscii 和 mayaBinary 文件格式是仅有的保留场景中所含全部信息的两种格式。使用“导出选项”(Export Options)框设置导出的输出格式将更改当前和后续导出操作使用的默认导出格式。如果将输出格式设定为非 mayaAscii 或 mayaBinary 的格式，并使用该格式导出，然后在未保存整个文件的情况下退出，则您可能会丢失数据。

  务必在导出文件浏览器中检查导出类型，确保正在使用预期文件格式写入文件。

- 若要使用非本地的文件格式（例如，OBJ 或 DXF）保存场景数据，必须加载该文件格式的插件。
