# 将时间编辑器片段导出到游戏导出器

[“时间编辑器”(Time Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E4B5DB7D-7351-4561-BD8B-60AC9D48DDF6)可用于将动画片段及其参数导出到[“游戏导出器”(Game Exporter)](../游戏导出器%28Game%20Exporter%29.md)中。

若要在“游戏导出器”(Game Exporter)中使用动画片段，请执行以下操作：

1. 在“时间编辑器”(Time Editor)中选择一个或多个片段。

2. 选择“文件 > 游戏导出器”(File > Game Exporter)。

  此时将显示“游戏导出器”(Game Exporter)窗口。默认情况下，“TE 动画默认值”(TE Anim Default)选项导出场景中的所有预设。

3. 在“时间编辑器片段”(Time Editor Clips)选项卡下，单击 ![图：在“时间编辑器片段”(Time Editor Clips)选项卡下，单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-BD307FD8-2871-4CFE-942F-4349FC916D13.png) <!-- baize:img-hook downloaded=false reason="正文 514 字 ≥300，非承重" -->。

4. 片段名称、开始帧和结束帧等选定片段特性将添加到“游戏导出器”(Game Exporter)。

  ![图：片段名称、开始帧和结束帧等选定片段特性将添加到“游戏导出器”(Game Exporter)。 注： 这些片段是只读的。 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-45D1B4E1-EFE6-422F-ACF8-B9A498735686.png) <!-- baize:img-hook downloaded=false reason="正文 514 字 ≥300，非承重" -->

  **注**

  - 这些片段是只读的。

  - 默认情况下启用“烘焙动画”(Bake Animation)。

  - 如果在时间编辑器中未选择任何片段的情况下单击 ![图：如果在时间编辑器中未选择任何片段的情况下单击 ，则游戏导出器将显示一条有关选择片段的错误消息。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-BD307FD8-2871-4CFE-942F-4349FC916D13.png) <!-- baize:img-hook downloaded=false reason="正文 514 字 ≥300，非承重" -->，则游戏导出器将显示一条有关选择片段的错误消息。

5. 在“路径”(Path)文本框中，输入要导出已添加片段的目录。

6. 在“文件名”(Filename)文本框中，输入要导出的文件的名称。

7. 单击“导出”(Export)。

若要删除片段，请单击 ![图：若要删除片段，请单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-5F88D3FE-F5E9-49BD-8AAB-A3A56A690CCD.png) <!-- baize:img-hook downloaded=false reason="正文 514 字 ≥300，非承重" -->。
