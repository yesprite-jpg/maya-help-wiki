# 文件引用辅助对象脚本

会将许多文件引用辅助对象脚本作为“Maya Bonus Tools”的一部分进行提供。“Bonus Tools”是一些很有用的 Maya 脚本和插件的免费集合，可从 Autodesk 网站 ([www.autodesk.com/maya-bonustools](http://www.autodesk.com/maya-bonustools)) 下载。

从 Autodesk 网站下载“Bonus Tools”

1. 在 Maya 中，从[“帮助”(Help)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E1AB1D0E-88F6-4CDC-A110-407F75FE660C)的“高级”(Advance)部分中选择“下载 Bonus Tools”(Download Bonus Tools)。

  可能需要注册才能获得访问 Autodesk 网站某些区域的权限。完成安装后，会立即在 Maya 内 Bonus Tools 自己的下拉菜单中显示“Bonus Tools”。
