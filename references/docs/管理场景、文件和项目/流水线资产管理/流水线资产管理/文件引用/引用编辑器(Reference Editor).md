# 引用编辑器(Reference Editor)

打开“引用编辑器”(Reference Editor)

- 在主菜单栏中：“文件 > 引用编辑器”(File > Reference Editor)

- 在场景视图中：“面板 > 面板 > 引用编辑器”(Panels > Panel > Reference Editor)

通过“引用编辑器”(Reference Editor)，可以管理场景中的文件和代理引用。

您还可以使用“大纲视图”(Outliner)管理和编辑文件和代理引用。

下表简要概述了使用“引用编辑器”(Reference Editor)的任务。

| 目标 | 操作 |
|---|---|
| 创建文件引用。 | 选择[“文件 > 创建引用”(File > Create Reference)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/files/GUID-655708E4-9CAE-475A-8810-AB65E8193FA0.htm)。请参见[创建文件引用](创建文件引用.md)。 |
| 卸载引用。 | 选择要卸载的引用，然后选择“引用 > 卸载引用”(Reference > Unload Reference)。请参见[加载和卸载文件引用](使用文件引用/卸载和重新加载文件引用.md)。 |
| 重新加载之前加载的引用。 | 选择“引用 > 重新加载引用”(Reference > Reload Reference)。请参见[加载和卸载文件引用](使用文件引用/卸载和重新加载文件引用.md)。 |
| 锁定或解锁引用 | 选择要锁定或解锁的引用，然后选择“引用 > 锁定引用”(Reference > Lock Reference)或“引用 > 取消锁定引用”(Reference > Unlock Reference)。请参见[锁定文件引用](使用文件引用/锁定文件引用.md)。 |
| 将引用替换为代理引用。 | 选择要添加代理引用的现有文件引用，然后选择“代理 > 添加代理”(Proxy > Add Proxy)。 在文件浏览器中，导航到希望用作代理引用的文件，然后单击“引用”(Reference)。 |
| 移除代理引用。 | 选择要移除的代理引用，然后选择“代理 > 移除代理”(Proxy > Remove Proxy)。 |
| 复制引用。 | 选择要复制的引用，然后选择“引用 > 复制引用”(Reference > Duplicate Reference)。请参见[复制文件引用](使用文件引用/复制文件引用.md)。 |
| 移除引用。 | 选择要移除的引用，然后选择“引用 > 移除引用”(Reference > Remove Reference) |
| 保存引用编辑。 | 选择具有要保存的引用编辑的引用，然后选择“文件 > 保存引用编辑”(File > Save Reference Edits)。请参见[引用编辑](引用编辑.md)。 |
| 将对场景中的引用所做的更改导出到编辑文件。 然后可以将这些编辑指定给另一个引用对象。 | 选择具有要指定的引用编辑的引用。 选择“文件 > 导出到脱机文件”(File > Export to Offline File)。 请参见[导出到脱机文件](引用编辑/将引用编辑导出到脱机文件.md)。 |
| 将引用编辑指定给另一个引用对象。 引用编辑必须首先导出到编辑文件。 | 选择要将引用编辑指定给的引用，然后选择“文件 > 指定脱机文件”(File > Assign Offline File)。 在浏览窗口中，选择包含要应用的编辑的编辑文件。 请参见[指定脱机文件](引用编辑/将引用编辑指定给脱机文件.md)。 |
