# 预览未加载的内容

使用“预览未加载的内容”(Preview unloaded content)选项可查看场景中未加载引用的层次。如果需要，可以在[“大纲视图”(Outliner)上下文菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-77994E64-9574-4E95-9540-B3CA881D96CD)中选择“重新加载”(Reload)以快速重新加载引用。

查看已卸载的引用的内容

1. 在“大纲视图”(Outliner)中，在已卸载的引用上单击鼠标右键，然后从显示的菜单中选择“引用 > 预览未加载的内容”(Reference > Preview unloaded content)。

  “大纲视图”(Outliner)显示未加载的引用的层次。

2. 在已卸载的引用上再次单击鼠标右键，然后选择以下选项之一：

  - 隐藏未加载的内容预览(Hide unloaded content preview)，可隐藏内容。

  - 刷新未加载的内容预览(Refresh unloaded content preview)，可查看最近对已卸载的引用所做的更改。
