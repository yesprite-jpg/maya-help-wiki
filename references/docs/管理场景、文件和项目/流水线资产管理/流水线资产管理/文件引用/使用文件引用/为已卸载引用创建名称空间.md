# 为已卸载引用创建名称空间

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../assets/Maya-ManagingScenes/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=true reason="正文 206 字 <300 且带图" -->

在创建引用或打开包含引用的文件时，即使您不加载引用本身，也可以选择创建引用的名称空间。

若要执行此操作，请在选择“文件 > 打开”(File > Open)或“文件 > 创建引用”(File > Create Reference)时启用“保留已卸载的名称空间”(Reserve unloaded namespaces)。

启用此选项后，将为这些引用创建并保留名称空间，以免该名称空间误用于其他节点和引用，导致在最终加载原始引用时发生冲突。
