# 锁定文件引用

可以使用“锁定”(Lock)选项锁定文件引用，以防止其在场景中引用时被意外修改。启用时，“锁定”(Lock)选项可以防止对与文件引用相关的所有属性和节点进行编辑。您可以从[“大纲视图”(Outliner)上下文菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-77994E64-9574-4E95-9540-B3CA881D96CD)、“创建引用选项”(Create Reference Options)窗口和[“引用编辑器”(Reference Editor)](../引用编辑器%28Reference%20Editor%29.md)访问“锁定”(Lock)选项。

使用“锁定”(Lock)选项时，请注意以下事项：

- 如果引用具有已锁定属性的文件，则文件将保持锁定状态，无论是否在创建引用时启用“锁定”(Lock)。

- 无法为已锁定的引用指定引用编辑。

- 加载和卸载引用不影响其锁定状态。

- 可以使用 MEL 脚本指定要从引用的锁定状态排除的属性。无论排除了哪种属性，“锁定”(Lock)选项始终锁定已引用文件的所有节点。

请参见[锁定文件引用](锁定文件引用/锁定文件引用.md)。

## 自定义锁定设置以排除属性

引用被锁定后，除了几个特定的属性和节点类型之外的所有节点和属性在默认情况下都会被锁定。可以使用 MEL 程序自定义引用“锁定”(Lock)选项，以便排除特定属性。排除后，将可以对这些属性进行编辑。

有两个 MEL 程序可以用于自定义锁定设置，以排除属性。一个程序指定要排除的单个属性，而另一个程序根据节点类型指定要排除的属性。使用该程序，可将指定节点类型的整个属性集从锁定中排除。MEL 程序包含在 Maya 中，可在 Maya 安装目录的脚本文件夹中找到。

**注**

可以创建自定义 MEL 程序来覆盖随 Maya 附带的 MEL 程序。必须以与 Maya 所附带程序完全相同的名称来命名该自定义 MEL 程序。还必须确保这些文件被放在 Maya 脚本路径中。

请参见[从锁定引用排除属性](锁定文件引用/从锁定引用排除属性.md)。

有关在 Maya 中使用 MEL 程序的详细信息，请参见[MEL 概述](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-60178D44-9990-45B4-8B43-9429D54DF70E)指南。有关在特定产品级环境中自定义锁定设置的详细信息，请参见下文。
