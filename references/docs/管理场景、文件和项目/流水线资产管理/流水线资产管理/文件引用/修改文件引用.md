# 修改文件引用

您可以在父场景中编辑被引用对象的属性，而不更改被引用子场景文件中的原始数据。在处理打开的父场景中的被引用数据时，可执行在非被引用场景中工作时可执行的许多相同编辑。这些编辑存储在当前打开的父场景的引用节点中。可以对文件引用进行以下编辑：

- 设置与非被引用节点之间的父子关系。例如，可以将被引用子场景文件中的节点设置为父场景中节点的父对象，反之亦然。

- 连接其中的一个或多个连接端点出现在被引用子场景文件中的节点和属性。请参见[保存到引用文件的内容](引用编辑/关于保存引用编辑.md#GUID-F03C1EFC-0085-47A6-9752-745D2A5C9917__SECTION_7B2428E164384006A545D26CFD159B0E)。

- 断开其中的一个或多个连接端点出现在被引用子场景文件中的节点和属性。

- 在被引用子场景文件中设定节点的属性。

- 将动态属性添加到被引用子场景文件中的节点。

- 删除之前在被引用子场景文件中的节点上添加的动态属性。

- 修改被引用文件中动画曲线。

可以将在选定文件引用的父场景中进行的编辑保存到磁盘上相应的被引用文件。这些编辑将转移到子引用文件中，因此它们不再位于父场景中。请参见[保存引用编辑](引用编辑器%28Reference%20Editor%29/“引用编辑器”%28Reference%20editor%29菜单.md#WS17956D7ADBC6E736-4CE538CA117AE30C631-7FA0)
