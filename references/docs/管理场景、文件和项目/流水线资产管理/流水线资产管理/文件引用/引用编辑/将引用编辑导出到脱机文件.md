# 将引用编辑导出到脱机文件

您可以将场景中的引用编辑（例如对几何体的更改或新的节点连接）导出到 .editMB 或 .editMA 引用编辑文件。然后，可将该编辑文件应用于其他对象以对其调用相同的更改。

例如，如果已开始使用基础循环行走动画，则可以导出多种不同的调整，如阔步、拖步和行进，并将其中每种调整导出到不同的文件。然后可以将这些编辑应用于其他角色。

可以导出场景中某个资产、某个被引用文件或一组选定节点上的编辑内容。导出引用编辑之前，可以查看它们以确保文件中包含正确的编辑。请参见[列出引用编辑](列出引用编辑.md)。

**注**

悬挂连接（到未导出节点的连接）和引用编辑将保存到具有占位符名称空间的编辑文件。应用这些编辑时，Maya 会将占位符替换为应用该文件的引用的名称空间，或者使用“:”代表导入到主场景。

不会导出默认节点。例如，如果更改了默认着色器（“lambert1”）并导出编辑，则不会导出更改的“lambert1”。

## 从选定节点导出引用编辑

从一组选定节点导出引用编辑

1. 按住 Shift 键的同时在场景中选择要从中导出编辑内容的节点。

2. 选择文件 > 导出到脱机文件(File > Export to Offline File)。

  将显示文件浏览器。

3. 导航到要存储编辑内容的文件夹并输入文件的名称。默认情况下，Maya 将这些文件放置在当前项目中名为 scenes\edits 的子文件夹中。

4. 单击“导出到脱机文件”(Export to Offline File)。

  Maya 会创建包含引用编辑的指定文件，扩展名为 .editMA 或 .editMB。不能在 Maya 中打开这些文件，但可以将其指定给其他文件。有关详细信息，请参见[指定脱机文件](将引用编辑指定给脱机文件.md)。

还可以导出特定被引用文件的编辑内容。

## 导出被引用文件上的编辑内容

导出被引用文件上的编辑内容

1. 通过执行下列操作之一来访问[导出到脱机文件选项(Export to Offline File Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B29122B2-8835-4165-AEE4-3008D55F1D18)：

  - 在“引用编辑器”(Reference Editor)（“文件 > 引用编辑器”(File > Reference Editor)）中，选择要从中导出编辑内容的被引用文件，然后选择“文件 > 导出到脱机文件”(File > Export to Offline File) > ![图：在“引用编辑器”(Reference Editor)（“文件 引用编辑器”(File Reference Editor)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1226 字 ≥300，非承重" -->。

2. 在“导出到脱机文件选项”(Export to Offline File Options)中，设置导出选项，然后单击“导出到脱机文件”(Export to Offline File)。

3. 导航到要存储编辑内容的文件夹并输入文件的名称。默认情况下，Maya 将这些文件放置在当前项目中名为 scenes\edits 的子文件夹中。

4. 单击“导出到脱机文件”(Export to Offline File)。
