## 文件引用创建选项

有关创建文件引用时常用的选项，请参见下表。

| 目标 | 操作 |
|---|---|
| 用定位器创建引用。 | 访问“引用选项”(Reference Options)窗口。 确保“分组”(Group)和“定位器”(Locator)选项已启用。 单击“引用”(Reference)。 |
| 延缓加载引用。 | 访问“引用选项”(Reference Options)窗口。 在“常规选项”(General Options)中，启用“延缓”(Deferred)。 在创建引用后，它将以空载状态添加到场景中，且仅在手动加载时才会显示。 |
| 用名称空间创建引用。 请参见[名称空间](../../../名称空间/名称空间.md)。 重要： 使用名称空间创建引用之后，永远不会删除名称空间。使用此名称空间的所有被引用对象将受影响，不会再按预期工作。如果不再需要将被引用对象与特定名称空间相关联，请使用“名称空间编辑器”(Namespace Editor)将其移除。请参见[移除名称空间](../../../名称空间/名称空间/移除名称空间.md)。 | 访问“引用选项”(Reference Options)窗口。 在“名称空间选项”(Namespace Options)部分中，确保启用了“使用名称空间”(Use Namespaces)。 请参见[在引用或导入时创建名称空间](../../../名称空间/名称空间/创建名称空间.md#GUID-E173CC3D-1638-499C-9F38-73735934D8E5__GUID-634FBA5A-4D93-4729-BC46-C8DA66D94807)。 |
| 使用共享显示层创建引用。 | 访问“引用选项”(Reference Options)窗口。 在“共享节点选项”(Shared Node Options)中，启用“显示层”(Display Layers)。 在创建引用时，与子场景关联的层将集成到父场景中。 |
| 使用共享着色网络创建引用。 | 访问“引用选项”(Reference Options)窗口。 在“共享节点选项”(Shared Node Options)中，启用“着色网络”(Shading Networks)。 在创建引用时，与子场景关联的着色网络将集成到父场景中。 |
