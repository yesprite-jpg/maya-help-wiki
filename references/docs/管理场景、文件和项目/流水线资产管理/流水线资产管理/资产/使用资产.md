# 使用资产

创建资产时，Maya 会按照多种方式排列节点：

- 在“Hypergraph: 连接”(Hypergraph Connections)编辑器中，由该资产封装的所有内部节点都显示为带有圆形边界的单个节点。

- 在“大纲视图”(Outliner)中，由该资产封装的所有内部节点都显示在新资产节点下方。

- 相应的条目将显示在“通道盒”(Channel Box)的“输入”(Inputs)和“输出”(Outputs)上方。

可以展开资产节点以显示其内容（请参见[资产的各个部分](资产的各个部分.md)）。

## 资产类型

在 Maya 中有两种类型的资产，您可以采用不同的方式与每一种资产进行交互。

- **变换资产**是指具有变换属性且在场景中可以像组节点一样操纵的资产。也可以像任何其他节点一样，设置 DAG 层次中的资产的父对象。设置为变换资产的子对象的任何节点会自动放置在该资产内部。

  变换资产较简单，且允许直接操纵，因而最适合需要放置在场景或 DAG 层次（例如，几何体或组）中的节点。

- **高级资产**没有关联的变换。这些资产不属于 DAG 层次，资产本身不能设置为层次中的父对象。但是，内部节点可作为定位点发布并放置在 DAG 层次（如有必要）中。

  高级资产最适合不需要与 DAG 层次大量交互的节点的集合，或不在同一 DAG 层次中的节点的集合（例如，着色器网络或角色装备）。

在这两种情况下，均可添加和修改属性并建立属性与资产节点（和放置在其中的节点）的连接，就像处理 Maya 中的其他节点一样。

有关连接的详细信息，请参见[连接输入和输出属性](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7895A9BC-ADE9-4BFA-94C8-5FFB3B28B403)。
