# 资产的各个部分

当资产节点自身不显示在场景视图中时，它们会显示在多个编辑器中。此外，如果选择的对象已由场景视图中的资产进行封装，则该资产会与已发布的属性一同显示在“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中。有关已发布属性的详细信息，请参见[已发布的属性和节点](已发布的属性和节点.md)。

资产在“Hypergraph: 连接”(Hypergraph Connections){编辑器中显示为具有倒角边的节点。如果展开这些节点中的一个，就可以看到多个部分：

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-534C9920-7226-4C73-8DF6-7E723E72407B.png) <!-- baize:img-hook downloaded=false reason="正文 847 字 ≥300，非承重" -->

| 封装的节点 | 半透明区域中显示的节点是资产封装的节点。场景中的每个节点都只能放置到单个资产（嵌套资产除外）。 |
|---|---|
| 未发布的属性连接 | 显示来自/前往其他节点并去往/来自未发布属性的传入和传出连接。当锁定未发布的属性时，就不会建立或断开未发布的属性连接。 |
| 已发布的属性 | 表示已发布到资产界面的内部节点属性，对于在一个位置显示内部节点属性的子集非常有用。默认情况下，这些连接不可见。通过启用“选项 > 显示关系连接”(Options > Show Relationship Connections)并禁用“选项 > 合并连接”(Options > Merge Connections)（二者都位于“Hypergraph: 连接”(Hypergraph Connections)编辑器中），可以显示连接。每个已发布的属性一个连接，该连接从属性的内部节点显示到资产边界。 |
| 已发布的属性连接 | 显示从已发布属性连接到外部节点的连接。通过连接线上的方形可以将已发布的属性连接与未发布的属性连接区分开来。 如果已发布属性连接到了其他资产的已发布属性，则两个端点都会显示方形。 如果已发布属性是已合并连接的一部分，则当所有已合并连接都已发布时会显示为实体正方形，否则显示为空心的正方形。 注： 使用“传递属性值”(Transfer Attribute Values)选项将传递连接从一个资产传递到另一资产时，只会传递已发布的属性连接。 注： 引用资产时，已发布的属性连接将与已发布的属性名称相对应，而不会与内部节点的名称相对应。 |
