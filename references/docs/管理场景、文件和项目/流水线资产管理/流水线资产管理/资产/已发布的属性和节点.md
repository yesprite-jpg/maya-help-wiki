# 已发布的属性和节点

## 已发布的属性

将节点属性发布到资产可以使此属性在资产级别可见。已发布的属性由三部分组成：

- 内部节点属性。

- 资产上的*已发布的名称*。

- 从内部节点属性到已发布名称的关系连接。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-448E4218-AFA1-449C-9CFB-D0CCFB9A62D8.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->

已发布的属性可以修改，就像直接修改对应的已封装属性的值。这允许：

- 使多个内部节点的属性可以从一个位置访问。

- 将未发布的属性和节点层次隐藏在资产内部，防止受到篡改。

- 简化处理复杂对象时的界面。

- 在资产级别对封装的属性进行重命名和重新映射。

已发布的属性组成了资产的*界面*，并且在资产锁定后仍然可以编辑。因此，通过发布一组属性，然后锁定资产，就可以确保用户只能通过给定的已发布属性与该资产的内容进行交互。

如果资产上存在已发布的名称，但此名称未连接到内部节点属性，则这一已发布的名称为*未绑定*。修改未绑定属性不会影响资产内容。使用“资产编辑器”(Asset Editor)可以为已发布的名称绑定和取消绑定属性。

已发布的属性可以从子资产发布到父资产。这样就可以构建资产层次，更好地管理场景。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-E8FE557B-DAA5-4A92-B56B-F81AFDEF1523.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->

例如，在汽车场景中可以为前轮创建名为 front_wheel_AST 的资产，此资产由命名为 car_AST 的整车资产封装。然后可以先将车轮旋转发布到 front_wheel_AST，然后再将这些已发布的属性发布到 car_AST。

也可以将资产节点自身的属性发布到自身。如果要在锁定资产本身的情况下允许美工人员更改视图或控制其他资产属性，这将非常有用。

模板使用已发布的名称定义其需要的已发布属性。

用户也可以发布节点。有关详细信息，请参见[已发布的节点](已发布的属性和节点.md#WS73099CC142F48755-63C0748611A1FA08F71-32AB)。

## 已发布的节点

与发布属性类似，用户可以将节点发布到资产。对于任一类型资产而言，已发布的节点是资产处于“黑箱模式”(Black Box mode)时唯一可见、可选和可操纵的封装节点（在“大纲视图”(Outliner)、“属性编辑器”(Attribute Editor)和“通道盒”(Channel Box)中）。

特别是对于**高级资产**而言，已发布的节点也可以用于定义封装 DAG 节点和外部 DAG 节点在层次中的交互方式。除了两种类型资产通用的节点发布方式之外，高级资产还允许以三种不同方式发布 DAG 节点。

- 作为父定位点

- 作为子定位点

- 作为资产的选择变换

父定位点和子定位点分别识别高级资产中的节点是否允许成为资产外节点的父对象或子对象。选择变换可用作以资产为中心选择中选定的节点（有关详细信息，请参见[以资产中心选择](导航资产/选择资产.md#WS1A9193826455F5FF-6507591011913E8F4B8-57C3)）并且有助于将用户引导至资产中的主节点。

**注**

**对于变换资产**，资产节点本身充当父定位点、子定位点和选择变换。用户不能手动发布这些内容。

以下是发布资产节点的几种常用方式：

- 最简单的工作流是将单个封装节点发布为高级资产的选择变换。在场景内选择了资产中的任何对象后，系统将自动选择作为选择变换的这一节点（假设已启用“以资产为中心选择”(Asset centric selection)）。选择变换也将用作父定位点和子定位点，这样选择变换就可以作为 DAG 中外部节点的父对象，即使资产已锁定。

  **注**

  “创建资产”(Create Asset)选项窗口提供了在创建时通过这种方式自动发布根的选项。有关详细信息，请参见[创建资产](创建和移除资产/创建资产.md)。

- 为了添加功能，可以在根变换之外发布多个父定位点或子定位点。之后，当资产锁定时，这些父定位点和子定位点中的每个定位点将成为 DAG 中的父对象。

- 发布通常在资产处于“黑箱模式”(Black Box mode)时仍想访问的节点。例如，发布角色装备上的控件，使得在“大纲视图”(Outliner)中仍可以看到这些控件以及在场景中选择这些控件。

在文件输入和输出过程中，与其他关系相比，Maya 处理已发布节点父关系的方式较为特殊。父定位点和子定位点依赖父对象/子对象的**已发布的名称**来管理对象之间的关系，而不是直接使用节点名称。这特别适用于处理文件引用。

例如，假设用户引用带有花束的文件并将其用作父文件中手臂的父对象。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-16C4EA89-FCAF-41B6-8781-99018DDCA9E0.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-058A4410-2231-46B2-A4B8-51987EB368FC.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->

如果更改花束文件的层次或名称，Maya 将无法保持父文件中手臂和花束之间的关系，因为 DAG 路径已经发生更改。因此花束将失去它的所有关系数据并重置为原始状态。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-85B2B544-49AB-417F-88AF-11CED9BED207.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-B752FD8B-1813-45D9-9254-F1CB4581A8B0.png) <!-- baize:img-hook downloaded=false reason="正文 2038 字 ≥300，非承重" -->

通过将花束封装到资产中并将 bouquet_GRP 发布为子定位点可以避免此问题。然后就可以更改花束的名称和结构且不会影响与手臂的关系。

## 隐藏非已发布的属性和节点

已发布的属性和节点代表了用户可以访问的资产各部分。资产中的其余属性和节点可以通过以下方式隐藏：将属性或节点设置为“黑箱”(Black Box)模式（有关“黑箱”(Black Box)模式的详细信息，请参见[隐藏未发布的节点和属性](导航资产/隐藏未发布的节点和属性.md)）。

但是，即使无法看到这些属性和节点，用户仍可以对其进行修改。若要防止这种情况的发生，也可以锁定资产。资产锁定后，用户只能将已发布的节点用作父对象/子对象以及修改已发布的资产（有关锁定资产的详细信息，请参见[锁定资产](导航资产/锁定资产.md)）。

组合使用这两个功能可以确保用户只按预期方式与资产进行交互。
