# 本地化资产用户界面

您可以自定义模板和视图，为资产提供翻译的已发布名称和描述。<label> 和 <description> 元素（可用于更改资产的显示文本）支持显示不同语言的文本。请参见[本地化元素：界面标签和描述](../资产模板的各个部分.md#WS1A9193826455F5FF-12BA6B3A11A9C207460-7E68)。

本地化模板或视图中的显示文本

1. 将 <label> 和 <description> 标记添加到显示文本需要本地化的元素中（如果这两个标记尚未存在）。

  标签和描述可以添加到模板文件的任何元素中。详细信息请参见[资产模板的各个部分](../资产模板的各个部分.md)。

2. 在标签和描述标记内，通过添加 language 属性定义要使用的语言。

  ![图：在标签和描述标记内，通过添加 language 属性定义要使用的语言。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F93140CC-2ABF-4813-809D-84C56F2523A8.png) <!-- baize:img-hook downloaded=false reason="正文 447 字 ≥300，非承重" -->

3. 在 <label> 和 <description> 标记内，输入要显示在资产用户界面中的文本。

  **注**

  <label> 文本将作为属性名称显示在“属性编辑器”(Attribute Editor)中，当用户鼠标悬停在“资产编辑器”(Asset Editor)中的该属性上时作为工具提示显示。<description> 文本作为“属性编辑器”(Attribute Editor)中属性上的工具提示显示。
