# 为资产指定模板

在保存资产模板后可以将其指定给其他资产。

将模板指定给另一个资产时，该模板中的所有在该资产上尚不存在的已发布名称将自动发布到该资产。然后，资产中节点的相关属性可以与模板的已发布名称绑定。

可以使用“资产编辑器”(Asset Editor)或“属性编辑器”(Attribute Editor)指定模板。

使用资产编辑器指定模板

  固定资产的已发布属性和节点显示在右侧面板中，其名称显示在“资产编辑器”(Asset Editor)标题栏中。

2. 从“资产编辑器”(Asset Editor)菜单栏中选择“模板 > 指定 > 指定新模板”(Template > Assign > Assign New Template)。

  文件浏览器中将打开当前项目的 assets 子目录。

3. 选择先前保存的模板，然后单击“选择”(Select)。

  模板现已指定给选定资产，模板的已发布名称将列在“资产编辑器”(Asset Editor)右侧面板的“未绑定”(Unbound)标题下。已指定模板的名称显示在右侧面板上方的“模板”(Template)字段中。

  现在已经指定了含有已发布名称列表的模板，下面可以继续将资产节点的属性与这些已发布名称绑定。

将属性与模板中的已发布名称绑定

1. 在“资产编辑器”(Asset Editor)中选择指定了模板的资产，然后单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)中选择指定了模板的资产，然后单击“固定资产”图标 。 资产的已发布属性（已绑…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=false reason="正文 1449 字 ≥300，非承重" -->。

  资产的已发布属性（已绑定和未绑定）及其已发布节点显示在右侧面板中。来自模板的未绑定的已发布名称显示在“未绑定”(Unbound)区域。

  **注**

  如果未绑定的已发布名称不是来自模板，则会显示黄色“选择”图标 ![图：如果未绑定的已发布名称不是来自模板，则会显示黄色“选择”图标 ；如果来自模板，则没有“选择”图标。来自模板的已发布名称不…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-E748DE86-93BD-48B8-9C03-E75879FF98A0.png) <!-- baize:img-hook downloaded=false reason="正文 1449 字 ≥300，非承重" -->；如果来自模板，则没有“选择”图标。来自模板的已发布名称不显示“选择”图标是因为这些名称无法重命名或删除。

2. 在“资产编辑器”(Asset Editor)的左侧面板中展开资产内容。

3. 展开右侧面板中的“未绑定”(Unbound)标题，查看模板定义的已发布名称列表。

4. 在左侧面板中选择要绑定的属性。

  **注**

  如果选择的属性具有斜体样式，则表明该属性已绑定到已发布名称，因此必须先在“资产编辑器”(Asset Editor)的右侧面板中取消绑定（使用已发布名称旁的“取消绑定”图标 ![图：如果选择的属性具有斜体样式，则表明该属性已绑定到已发布名称，因此必须先在“资产编辑器”(Asset Editor)的右侧…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-6524565D-19CA-4226-9DB7-7E197AE08279.png) <!-- baize:img-hook downloaded=false reason="正文 1449 字 ≥300，非承重" -->）后才能将其绑定到新的已发布名称。

5. 在右侧面板中，找到属性要绑定到的已发布名称，然后单击“绑定”图标 ![图：在右侧面板中，找到属性要绑定到的已发布名称，然后单击“绑定”图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-FBE8085A-7D7F-4950-B2C4-C13C3E776F93.png) <!-- baize:img-hook downloaded=false reason="正文 1449 字 ≥300，非承重" -->。

  左侧面板中选定的属性现已发布且已绑定到右侧面板中选定的名称。刷新“资产编辑器”(Asset Editor)后，该属性将移动到给定节点的已绑定属性列表中。

  （请参见[绑定/取消绑定属性或节点](../编辑资产/绑定取消绑定属性或节点.md)。）

7. 继续在左侧面板中选择属性并将其绑定到来自模板的名称，直到资产的所有必需属性都已发布和绑定。
