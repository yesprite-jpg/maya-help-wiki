# 自定义模板视图

尽管可以通过编辑资产的模板文件来更改资产属性的基本布局（请参见[编辑资产模板](编辑资产模板.md)），但是通过添加多个视图能够为同一资产设置多个布局。

某些信息（如标签和说明）在模板和视图中都可以提供。若已提供特定于视图的定义，此类定义将优先于模板级别的定义。

有关视图定义中允许的 XML 元素的详细信息，请参见[视图元素](../资产模板的各个部分.md#WS1A9193826455F5FF-12BA6B3A11A9C207460-7E8A)。

下图提供了有关视图 XML 元素的简要概述以及这些元素在“属性编辑器”(Attribute Editor)中的显示方式。

自定义视图

1. [打开模板进行编辑](编辑资产模板.md)，并找到要更改的视图定义。

2. 通过执行下列任一操作编辑视图定义：

  - [从视图中移除属性](自定义模板视图.md#WS73099CC142F48755-42A8108711A530FF1D3-5214)

  - [对视图中的属性重新进行排序或分组](自定义模板视图.md#WS1A9193826455F5FF-156C9AA7119D8906FDE-16C1)

  - [更改一组属性的标题](自定义模板视图.md#WS1A9193826455F5FF-4FDFBFFB11A5310C890-49D2)

  - [显示子属性及各自的控件](自定义模板视图.md#WS73099CC142F48755-42A8108711A530FF1D3-7324)

  - [仅显示复合属性的组控件](自定义模板视图.md#WS1A9193826455F5FF-4FDFBFFB11A5310C890-49C6)

  - [添加显示在属性编辑器中的工具提示](自定义模板视图.md#WS1A9193826455F5FF-12BA6B3A11A9C207460-6159)

3. 保存 XML 模板文件。

4. [在 Maya 中重新加载模板](重新加载资产模板.md)。

找到模板文件中的视图定义

1. 打开选择的 XML 编辑器并加载模板文件。

  默认情况下，创建的资产模板保存在当前项目的 assets 子目录中。（请参见[创建资产模板](创建资产模板.md)。）

2. 搜索 XML 文件，找到待更改视图的名称。

  例如，若要查找名为“ShadingArtist”的视图，可以搜索视图名称“ShadingArtist”。（有关将视图添加到模板文件中的信息，请参见[为资产模板添加视图](为资产模板添加视图.md)。）

  视图定义位于 <view> 元素标记之间。请参见[资产模板的各个部分](../资产模板的各个部分.md)，以了解模板文件图。

  可以编辑此视图定义中的元素来更改视图的显示方式。

从视图中移除属性

默认情况下，在创建视图时会将模板中的所有属性都添加到视图中。这些属性在视图定义中通过 <property> 元素表示。<property> 元素指模板中按名称提供的属性。

可以编辑视图定义，以便移除不希望显示在特定视图中的任何属性。

1. 在视图定义中，删除表示不希望显示在该视图中的任何属性的 <property> 元素。

  ![图：在视图定义中，删除表示不希望显示在该视图中的任何属性的 <property 元素。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-713A5643-DE72-4D09-BB41-ED975446E258.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

2. 保存并关闭 XML 文件。

  在 Maya 中重新加载模板，然后选择修改后的视图使其处于活动状态，这样对应于所删除 <property> 元素的属性将不再显示在窗口和编辑器中。

更改视图中属性的显示名称

在每个视图中，可以使用每个特性定义中的 <label> 元素，在“属性编辑器”(Attribute Editor)中更改相应属性的显示名称。

1. 如果特性定义中没有 <label> 元素，请向其中添加。

  **注**

  提示：

  在将 <label> 标记添加到特性定义中时，确保删除特性定义结尾处的尾部反斜杠 /，并添加结束 </property> 标记。

2. 编辑 <label> 元素中的文本字符串。

  ![图：编辑 <label 元素中的文本字符串。 注： 更改 <label 文本时也会更改“资产编辑器”(Asset Edito…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-C2D8F08D-28DC-4651-B237-F29AEA5A87C7.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

  **注**

  更改 <label> 文本时也会更改“资产编辑器”(Asset Editor)中显示为属性工具提示帮助的内容。默认情况下，“资产编辑器”(Asset Editor)基于属性的 <type> 和 <label> 元素显示工具提示。

  ![图：编辑 <label 元素中的文本字符串。 注： 更改 <label 文本时也会更改“资产编辑器”(Asset Edito…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-D6811D38-E57F-4772-9822-D7BC497A9279.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

对视图中的属性重新进行排序或分组

1. 在视图定义中，选择并剪切整个 <property> 元素。

2. 将该元素粘贴到视图定义中的一个新位置。

  ![图：将该元素粘贴到视图定义中的一个新位置。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-13A6422E-5330-4B40-8FE7-87433BBDF532.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

3. 完成视图中的属性重组后，保存 XML 模板文件并关闭 XML 编辑器。

更改视图中一组属性的标题

在继续这些步骤前，请确保在创建视图时，在“添加视图选项”(Add View Options)中选择“按节点分组”(Group By Node)布局。

1. 执行下列操作之一：

  - 如果组名称不需要包含空格或特殊字符，则只需编辑 <group> 元素中的 name 文本字符串。

    ![图：如果组名称不需要包含空格或特殊字符，则只需编辑 <group 元素中的 name 文本字符串。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-796ADC73-98B4-4F94-9A91-B4301A44F161.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

  - 如果希望组名称包含空格或特殊字符，则将 <label> 元素添加到组定义中，并对其进行编辑。

    ![图：如果希望组名称包含空格或特殊字符，则将 <label 元素添加到组定义中，并对其进行编辑。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-725FEBD2-31B4-437C-B9D1-A9CAED2D0138.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

在视图中显示子属性及各自的控件

1. 将视图添加到模板时，请确保在“添加视图选项”(Add View Options)中启用“展开复合”(Expand Compounds)。（请参见[为资产模板添加视图](为资产模板添加视图.md)。）

  启用“展开复合”(Expand Compounds)后，复合的子属性将分别添加到视图定义中。

  ![图：将视图添加到模板时，请确保在“添加视图选项”(Add View Options)中启用“展开复合”(Expand Com…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-38E23A9F-8DA5-483C-B2C9-9666474E860F.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

  因此，它们随各自的控件一起显示。

  ![图：将视图添加到模板时，请确保在“添加视图选项”(Add View Options)中启用“展开复合”(Expand Com…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-A621FEEB-D6ED-4327-B8AB-84FEFB2AEF74.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

2. （可选）如果要仅显示子属性（及各自的控件），可以从视图定义中移除父属性（及其组控件）。（请参见[从视图中移除属性](自定义模板视图.md#WS73099CC142F48755-42A8108711A530FF1D3-5213)。）

在视图中仅显示复合属性的组控件

1. 创建视图时，禁用“添加视图选项”(Add View Options)中的“展开复合”(Expand Compounds)。请参见[为资产模板添加视图](为资产模板添加视图.md)。

  禁用“展开复合”(Expand Compounds)后，子属性不会单独列在视图定义中，因此父属性（及其子属性）将通过组控件显示。

  ![图：创建视图时，禁用“添加视图选项”(Add View Options)中的“展开复合”(Expand Compounds)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-5A39848E-399A-4FD7-B8B0-BD79DDF0B343.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

更改显示在属性编辑器中的工具提示

可以设置每个视图，以便在资产用户将鼠标悬停在“属性编辑器”(Attribute Editor)中的属性上时显示不同的工具提示。这样可显示任何对用户有帮助的信息。

1. 在视图定义中，找到含有待编辑工具提示的特性定义。

2. 如果特性定义中没有 <description> 元素，请向其中添加。

  **注**

  提示：

  在添加 <description> 标记时，确保删除特性定义结尾处的尾部反斜杠 /，并添加结束 </property> 标记。

3. 在 <description> 标记之间输入属性编辑器工具提示。

  ![图：在 <description 标记之间输入属性编辑器工具提示。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-CB62EFFD-52FA-41A3-8A5A-3A356B336453.png) <!-- baize:img-hook downloaded=false reason="正文 2090 字 ≥300，非承重" -->

4. （可选）如果希望工具提示文本以不同的语言显示，也可以添加 <language> 标记。请参见[本地化资产用户界面](本地化资产用户界面.md)和[本地化元素：界面标签和说明](../资产模板的各个部分.md#WS1A9193826455F5FF-12BA6B3A11A9C207460-7E68)。

5. 保存 XML 模板文件。
