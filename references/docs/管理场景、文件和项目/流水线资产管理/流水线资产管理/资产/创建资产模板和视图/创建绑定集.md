# 创建绑定集

绑定集创建节点属性到模板文件中已发布名称的映射。在 Maya 中将模板应用到其他资产时，可以使用“自动绑定”(Autobind)功能，根据绑定集自动将属性发布和绑定到该资产。

创建绑定集

1. 将要包含在绑定集中的属性发布到资产。

2. 打开“资产编辑器”(Asset Editor)（[资产 > 资产编辑器(Assets > Asset Editor)](../资产编辑器%28Asset%20Editor%29.md)）。

3. 在“资产编辑器”(Asset Editor)中，选择资产并单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)中，选择资产并单击“固定资产”图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=false reason="正文 463 字 ≥300，非承重" -->。

4. 选择[模板 > 创建绑定集(Template > Create Binding Set)](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS73099CC142F48755-385A98B0121D1BB015F-31D7)。

  Maya 将绑定集信息添加到模板。

**注**

如果已发布名称未绑定到已发布属性，绑定集将它们映射到占位符值。

可以在任何时间用附加的已发布属性或名称更新绑定集。

更新绑定集

1. 将任何附加的属性或名称发布到资产中。

2. 在“资产编辑器”(Asset Editor)中，选择[模板 > 更新绑定集(Template > Update Binding Set)](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS73099CC142F48755-385A98B0121D1BB015F-31D3)。

  Maya 更新在模板文件中的绑定集。

可以通过选择[模板 > 移除绑定集(Template > Remove Binding Set)](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS73099CC142F48755-385A98B0121D1BB015F-31CF)从模板移除绑定集。
