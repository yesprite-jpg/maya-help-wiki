# 编辑资产模板

可以修改资产的模板文件以更改资产界面。把资产的“视图模式”(View Mode)设置为“使用模板”(Use Template)且“视图名称”(View Name)设置为“无”(None)时，可以在 Maya 中看到更改。

下图显示的“属性编辑器”(Attribute Editor)适用于使用指定了基本、默认模板的资产。尚未对资产模板进行编辑。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-12EFD934-FEF7-40C7-BE34-7BFA324986B0.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

可以在选择的 XML 编辑器中编辑资产模板文件。（有关模板文件的详细信息，请参见[资产模板的各个部分](../资产模板的各个部分.md)和[模板文件格式](../模板文件格式.md)。）下图显示的“属性编辑器”(Attribute Editor)适用于模板文件经过简单修改的相同资产。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-4197376E-12DA-4808-AA19-581CC4C98600.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

打开模板文件并进行编辑

1. 打开文本或 XML 编辑器，导航以选择之前保存的模板文件。（请参见[创建资产模板](创建资产模板.md)。）

  默认情况下，创建的 XML 模板文件保存在当前项目的 assets 子目录中。

**注**

每次在外部编辑器中编辑模板文件，都必须在 Maya 中重新加载模板才能看到所做更改。请参见[重新加载资产模板](重新加载资产模板.md)。

在模板中重命名已发布的属性名称

1. 请编辑 <attribute> 元素中的 name 文本字符串。

  ![图：请编辑 <attribute 元素中的 name 文本字符串。 注： <attribute 元素的 name 中不能包含…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-14707C8A-D48C-44BD-8512-756CB82E1534.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

  **注**

  <attribute> 元素的 name 中不能包含空格、特殊字符或多字节字符。如果要显示含空格或特殊字符的属性名称，请添加 <label> 元素来包含此类名称。

更改资产的显示名称

1. 编辑 <attribute> 定义中的 <label> 元素。

  ![图：编辑 <attribute 定义中的 <label 元素。 与属性名称不同，<label 元素可以包含空格、特殊字符和多…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-6B737ED7-CC44-43D9-B370-BACB232FC2B9.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

  与属性名称不同，<label> 元素可以包含空格、特殊字符和多字节字符。

  **注**

  编辑 <label> 元素也会更改显示在“资产编辑器”(Asset Editor)中属性上的工具提示文本。

对已发布的属性名称重新进行排序

1. 选择并剪切整个 <attribute> 元素。

2. 将元素粘贴至新的位置。

  ![图：将元素粘贴至新的位置。 请勿将选定的属性元素粘贴至其他属性元素的内部，因为此结构将无法验证。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F6BF6323-009E-4AC3-8716-AF8A2E50C931.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

  请勿将选定的属性元素粘贴至其他属性元素的内部，因为此结构将无法验证。

从模板中移除已发布的属性名称

1. 删除整个 <attribute> 元素。

更改在“属性编辑器”已发布名称上显示的工具提示

1. 编辑属性 <description> 元素中的文本。

  **注**

  提示：

  可以将 <description> 标记中的文本本地化。请参见[本地化资产用户界面](本地化资产用户界面.md)。

  ![图：编辑属性 <description 元素中的文本。 提示： 可以将 <description 标记中的文本本地化。请参见…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-E9FEEEE3-24D8-4D7A-B586-227DBE220568.png) <!-- baize:img-hook downloaded=false reason="正文 933 字 ≥300，非承重" -->

**注**

“资产编辑器”(Asset Editor)还会显示基于属性的 <type> 和 <label> 元素的工具提示。
