# 保存资产模板

指定模板后，保存现有模板即可使用添加到资产的任何已发布名称更新模板。

保存模板

1. 在“资产编辑器”(Asset Editor)的左侧面板中，选择包括要保存模板的资产并单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)的左侧面板中，选择包括要保存模板的资产并单击“固定资产”图标 。](../../../../../../assets/Maya-ManagingScenes/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=true reason="正文 254 字 <300 且带图" -->。

2. 在“资产编辑器”(Asset Editor)菜单栏上，选择“模板 > 保存”(Template > Save)。

系统将添加模板文件中不存在的任何来自已固定资产的已发布名称，并保存模板文件。

**注**

如果计划与其他用户共享模板文件，则应该为模板文件设置写保护，防止其他用户覆盖原始模板文件。

模板（默认情况下）保存在当前项目的 assets 子目录中。
