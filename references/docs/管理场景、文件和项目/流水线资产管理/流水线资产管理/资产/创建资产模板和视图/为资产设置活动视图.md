# 为资产设置活动视图

可以使用“资产编辑器”(Asset Editor)或“属性编辑器”(Attribute Editor)为资产设置活动视图。活动视图定义了 Maya 窗口和编辑器中资产的界面。

在设置视图前，必须已经为资产指定了包含视图的模板。（请参见[为资产指定模板](为资产指定模板.md)和[为资产模板添加自定义视图](为资产模板添加视图.md)。）

为资产设置自定义视图（资产编辑器）

1. 在左侧面板中，选择资产并单击“锁定资产”图标 ![图：在左侧面板中，选择资产并单击“锁定资产”图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=false reason="正文 445 字 ≥300，非承重" -->。

2. 从“资产编辑器”(Asset Editor)菜单栏中选择[视图 > 模式 > 使用模板(View > Mode > Use Template)](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS1A9193826455F5FF-4F542F6211C79DEA861-1E03)（如果尚未选择）。

3. 选择[视图 > 名称(View > Name)](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS1A9193826455F5FF-4F542F6211C79DEA861-1DFF)，然后从自定义视图列表中选择。

为资产设置自定义视图（“属性编辑器”）

1. 在“属性编辑器”(Attribute Editor)中选择资产选项卡，展开“资产属性”(Asset Attributes)标题。

2. 单击“视图模式”(View Mode)并选择“使用模板”(Use Template)（如果尚未选择）。

3. 单击“视图名称”(View Name)按钮，然后从显示的弹出菜单中选择一个视图。
