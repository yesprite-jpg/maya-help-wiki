# 为资产模板添加视图

可为每个模板添加多个视图，根据需要为资产的属性创建多个自定义布局。

为模板添加视图后，可以编辑模板文件，以自定义视图布局。请参见[自定义模板视图](自定义模板视图.md)。

为模板添加视图

1. 在“资产编辑器”(Asset Editor)的左侧面板中，选择已指定模板的资产，然后单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)的左侧面板中，选择已指定模板的资产，然后单击“固定资产”图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=false reason="正文 734 字 ≥300，非承重" -->。

2. 在“资产编辑器”(Asset Editor)菜单栏上，选择[视图 > 添加(View > Add) >](../资产编辑器%28Asset%20Editor%29.md#GUID-2BB770AC-6B1F-48E3-814C-DCCC72DD6EA5__WS73099CC142F48755-575EAB4C124F5234AA8-549B) ![图：在“资产编辑器”(Asset Editor)菜单栏上，选择视图 添加(View Add) 。 此时将出现“添加视图选项”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 734 字 ≥300，非承重" -->。

  此时将出现“添加视图选项”(Add View Options)对话框。

3. 在“添加视图选项”(Add View Options)中，执行下列操作：

  - 输入新视图的名称。

    选择视图时，该名称将显示在“资产编辑器”(Asset Editor)的“视图 > 名称”(View > Name)列表中，或显示在“属性编辑器”(Attribute Editor)的“视图名称”(View Name)字段中。将资产设置为使用该视图后，名称也将作为标题显示在资产的“资产编辑器”(Asset Editor)和“属性编辑器”(Attribute Editor)中。

  - 定义所需的视图选项。有关每个选项的说明，请参见[资产编辑器](../资产编辑器%28Asset%20Editor%29.md)。

    **注**

    提示：

    - 如果要自定义该视图，请保留“布局模式”(Layout Mode)的“按节点分组”(Group By Node)设置。该选项用于对 XML 模板文件中的属性进行分组，便于以后更轻松地查找和组织这些属性。

    - 如果希望复合的子属性在该视图中具有各自的界面控件，请启用“展开复合”(Expand Compounds)。

4. 单击“应用并关闭”(Apply and Close)。

根据选定的“添加视图选项”(Add View Options)，新视图将成为固定资产的活动视图。

**注**

提示：

如果要锁定资产，但又团队成员能够切换视图，请在为模板添加新视图后，将 viewName 属性发布到资产中。
