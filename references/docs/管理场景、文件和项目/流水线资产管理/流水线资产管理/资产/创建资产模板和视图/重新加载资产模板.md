# 重新加载资产模板

如果在 Maya 外部更新了模板 XML 文件，则需要重新加载该模板，才能将更改同步到资产。

例如，如果在自定义视图中使用外部 XML 重新组织属性，则需要重新加载模板才能显示更改。

重新加载模板

1. 在“资产编辑器”(Asset Editor)的左侧面板中，选择使用已更新模板的资产，然后单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)的左侧面板中，选择使用已更新模板的资产，然后单击“固定资产”图标 。](../../../../../../assets/Maya-ManagingScenes/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=true reason="正文 224 字 <300 且带图" -->。

2. 在“资产编辑器”(Asset Editor)菜单栏上，选择“模板 > 重新加载”(Template > Reload)。

  Maya 会重新加载模板并更新各窗口和中的属性显示。
