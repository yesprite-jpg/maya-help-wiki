# 在节点编辑器中查看和连接资产

您可以绘制节点网络，您的资产在“节点编辑器”(Node Editor)中显示为节点。每个资产的内部成员都将被隐藏，只有已发布的属性将和节点一同显示。

## 已发布的属性

可以创建到已发布属性的连接和自已发布属性的连接。在单击输入或输出主端口，以及节点以完全模式显示时，已发布的属性和资产节点的连接属性将可用。将鼠标悬停在连接线上可查看连接的详细信息。

在本例中，比例 Eh 是 canuck 资产的已发布属性，因此是可见的，并且可以连接到其他节点。成员节点的其他未发布属性将被隐藏。

## 未发布的属性

资产的未发布的属性被隐藏，但它们的连接都是可见的。“节点编辑器”(Node Editor)显示从 superport 的连接，您可将鼠标悬停在连接线上以查看连接的详细信息。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-AC2CE82C-8EA2-4033-9EF1-5B610209A1BC.png) <!-- baize:img-hook downloaded=false reason="正文 519 字 ≥300，非承重" -->

**注**

对作为资产一部分的对象制图时，可以选择对资产而不是节点自身制图，并显示已发布的属性连接，而不是原始属性连接。若要执行此操作，请在“节点编辑器”(Node Editor)菜单中启用“显示 > 使用资产和已发布的属性”(Display > Use Assets and Published Attributes)。您还可以在“首选项”(Preferences)窗口的[节点编辑器(Node Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-29B4D1FC-1861-4828-8236-6E6F1F24BFD3)区域中设定首选项。
