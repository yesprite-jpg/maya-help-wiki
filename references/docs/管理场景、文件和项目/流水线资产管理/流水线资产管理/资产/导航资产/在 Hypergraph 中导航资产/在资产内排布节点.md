# 在资产内排布节点

在已展开资产中调整节点布局的方法与在“Hypergraph”其余部分中调整节点布局的方法相同。但是请注意，各资产的单个布局都独立于“Hypergraph”和其他资产布局。因此，可以有内部布局不同的多个资产。

## 相关主题

- [“Hypergraph”概述](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-5EC40DB1-FBD9-4553-A2FD-6D3508C9B868)

更改资产布局

1. 在“Hypergraph: 连接”(Hypergraph Connections)编辑器中，右键单击 (![图：在“Hypergraph: 连接”(Hypergraph Connections)编辑器中，右键单击 () 资产的边界。](../../../../../../../assets/Maya-ManagingScenes/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=true reason="正文 257 字 <300 且带图" -->) 资产的边界。

2. 从弹出菜单中选择“布局资产”(Layout Asset)。

3. 在显示的列表中为资产选择布局。

  有关图表布局的完整列表，请参见[“选项”(Options)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-80135B8E-0F59-4C7B-A969-73FE766F4FF5)。
