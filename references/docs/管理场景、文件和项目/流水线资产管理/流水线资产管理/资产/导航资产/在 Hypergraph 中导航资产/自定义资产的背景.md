# 自定义资产的背景

默认情况下，资产节点是半透明的。因此，可以部分地看到外部节点或资产节点下方的连接。从 Hypergraph 选项菜单中选择“选项 > 不透明资产”(Options > Opaque Assets)，可以使资产节点不透明。请参见[不透明资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-80135B8E-0F59-4C7B-A969-73FE766F4FF5#GUID-80135B8E-0F59-4C7B-A969-73FE766F4FF5__WS1A9193826455F5FF-4F542F6211C79DEA861-1C6E)。

还可以将“Hypergraph”中每个资产的背景设置为自定义图像。这样有助于直观地识别资产。

自定义“Hypergraph”中资产的背景

1. 在“Hypergraph: 连接”编辑器中，在资产边界上单击鼠标右键 (![图：在“Hypergraph: 连接”编辑器中，在资产边界上单击鼠标右键 ()，然后在弹出菜单中选择“设置背景图像”(Set…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 434 字 ≥300，非承重" -->)，然后在弹出菜单中选择“设置背景图像”(Set Background Image)。

  **注**

  必须在边界的任意边而不是右侧上单击鼠标右键 (![图：必须在边界的任意边而不是右侧上单击鼠标右键 ()。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 434 字 ≥300，非承重" -->)。

  此时将显示“调整背景图像”(Adjust Background Image)窗口。

2. 在“图像名称”(Image Name)字段中输入图像文件的路径，或单击“加载”(Load)并在浏览器窗口中导航选择文件。

3. 选择“适配宽度”(Fit to Width)或“适配高度”(Fit to Height)。

4. 使用值字段或滑块调整图像大小。
