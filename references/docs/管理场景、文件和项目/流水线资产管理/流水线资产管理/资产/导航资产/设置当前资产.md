# 设置当前资产

如果将资产设置为当前资产，则任何创建的后续节点都将自动添加到该资产中。

设置当前资产

1. 选择“修改 > 资产 > 高级资产 > 设置当前资产”(Modify > Asset > Advanced Assets > Set Current Asset)。

2. 从显示的列表中选择资产。

用户还可以在“Hypergraph: 连接”(Hypergraph Connections)编辑器中的资产上单击鼠标右键 ![图：用户还可以在“Hypergraph: 连接”(Hypergraph Connections)编辑器中的资产上单击鼠标右键…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 346 字 ≥300，非承重" -->，然后选择“将资产设置为当前资产”(Set Asset as Current)。

通过选择“显示 > 平视显示仪 > 当前资产”(Display > Heads Up Display > Current Asset)，可以将平视显示仪设置为在场景面板的右下角显示当前资产。

**注**

默认节点（如 ikSolver 和 UI 相关节点）不能放置到资产中，即使此资产已设置为当前资产。
