# 将多个属性发布到一个已发布的名称上

多个属性可以发布到资产的单个已发布名称上。这样您可以使用资产（例如粒子网络）的单个字段或控件对所有属性进行控制。

若要执行此操作，首先必须一个创建控制所有内部节点上特定属性的“动态属性”(Dynamic Attribute)。然后可以将这一“动态属性”(Dynamic Attribute)发布到资产上。

有关设置“动态属性”(Dynamic Attribute)的详细信息，请参见[添加动态属性](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-5590A3EF-A611-4AD8-BC03-3EFE2E967E29)。

有关发布属性的详细信息，请参见[发布或取消发布属性](发布或取消发布属性.md)。
