# 在资产之间传递属性值

使用“传递属性值”(Transfer Attribute Values)选项可以将值和连接从一个资产传递到另一个。Maya 将来自任何名称相同的已发布属性的值从源资产复制到目标资产。

提供多个功能强大的选项来配置属性传递。有关详细信息，请参见[传递属性值选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DB5835DD-C3D4-48A6-855D-3A0A673EB4D3)。

在资产之间传递属性值

1. 从“大纲视图”(Outliner)选择源资产。

2. 按住 Shift 键并选择目标资产。

3. 选择“编辑 > 传递属性值”(Edit > Transfer Attribute Values) > ![图：选择“编辑 传递属性值”(Edit Transfer Attribute Values) ，以设置“传递属性值选项”(T…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 395 字 ≥300，非承重" --> ，以设置“传递属性值选项”(Transfer Attribute Values Options)。

  所有同名的属性值将从源资产传递到目标资产。

4. 根据需要设定选项后，选择“应用”(Apply)或“应用并关闭”(Apply and Close)。
