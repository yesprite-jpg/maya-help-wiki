# 示例：交换机器人的手臂（仅限“高级资产”）

此示例将显示如何使用资产、文件引用、“传递属性值”(Transfer Attribute Values)选项和“发布子定位点”(Publish Child Anchor)选项，交换机器人模型上的不同手臂。

**注**

虽然本示例着重于如何使用“高级资产”完成此操作，但是也可以使用“带变换的资产”，在不发布任何节点的情况下完成此操作。

假设一个机器人模型由引用了其他文件的不同身体部位组成（有关引用资产的详细信息，请参见[资产和文件引用](../资产和文件引用.md)）。这些身体部位中的每个部位都由资产用相应的已发布属性封装。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-2C99D9DD-2DDF-43F6-AE5F-1FCDD0B189CB.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->

假设在一个新动画中，机器人必须举起很重的板条箱。但是，这些手臂对于该动画而言过小。

如果打开引用的手臂文件，可以看到原始手臂由 L_RobotArm_AST 封装。这里可以建模第二个功能更强大的手臂。

创建第二个手臂

1. 选择“创建 > 资产 > 创建资产”(Create > Asset > Create Asset) > ![图：选择“创建 资产 创建资产”(Create Asset Create Asset) 。 此时将显示“创建高级资产选项”(…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->。

  此时将显示“创建高级资产选项”(Create Advanced Asset Options)窗口。

2. 将资产命名为 L_PowerArm_AST。

3. 单击“应用并关闭”(Apply and Close)。

4. 选择“修改 > 资产 > 高级资产 > 设置当前资产”(Modify > Asset > Advanced Assets > Set Current Asset) L_PowerArm_AST。

5. 为新手臂建模。

  所有新的手臂几何体都将自动在 L_PowerArm_AST 节点下创建。

6. 使用 L_RobotArm_AST 上对应属性和节点的名称，发布相应属性和节点。

7. 完成后，选择“修改 > 资产 > 高级资产 > 设置当前资产”(Modify > Asset > Advanced Assets > Set Current Asset)，然后选择“无”None。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-5AA5720C-488B-43FA-BA33-C4137A7F6F42.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->

现在就拥有了两个资产，每个都封装了一只手臂。但是，如果使用“传递属性值”(Transfer Attribute Values)选项切换主机器人文件引用的手臂，则会得到以下结果。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-A74DDA2F-5BF1-472D-B62D-16ACF8D749E0.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->

手臂显示在另一只手臂的上方，未正确转换。如果需要仔细查看层次，可以看到引用的手臂不再正确定位在角色的层次中（它们已从各自组之下消失）。这是因为主机器人场景不再识别资产下的任何节点（有关详细信息，请参见[已发布的节点](../已发布的属性和节点.md#WS73099CC142F48755-63C0748611A1FA08F71-32AB)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-FAE61659-C793-4C66-ACF8-2CA5C69FAED5.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->

要正确交换手臂，必须先将新手臂发布为子对象，然后再传递其属性。

交换机器人手臂

1. 在手臂文件中，选择节点 L_powerArm_GRP。此组正好在 L_powerArm_CNT 节点的下方，是组成新手臂的所有几何体的组合。

2. 选择“修改 > 资产 > 高级资产 > 节点发布 > 发布子锚点”(Modify > Asset > Advanced Assets > Node Publishing > Publish Child Anchor)。

3. 选择 L_robotArm_AST，然后按住 ![图：选择 L_robotArm_AST，然后按住 并选择 L_powerArm_AST。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" --> 并选择 L_powerArm_AST。

4. 选择“编辑 > 传递属性值”(Edit > Transfer Attribute Values) > ![图：选择“编辑 传递属性值”(Edit Transfer Attribute Values) 。 此时将显示“传递属性值选项…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->。

  此时将显示“传递属性值选项”(Transfer Attribute Values Options)窗口。

5. 启用“值”(Value)。

6. 将“输入连接”(In connections)设置为“从源传递”(Transfer from source)。

7. 将“关系”(Relationships)设置为“传递父/子关系”(Transfer parent/child relationships)。

8. 将“重命名”(Rename)设置为“重命名目标资产”(Rename target asset)。

9. 单击“应用并关闭”(Apply and Close)。

10. 隐藏对应于旧机器人手臂的显示层。

11. 保存文件。

新手臂在资产 L_robotArm_AST 下组织，而旧手臂在资产 L_robot_arm_ASTOrig 下组织。

现在，如果打开主机器人文件，机器人手臂将替换为新的、看起来更为有力的手臂。因为已将这些手臂发布为源文件中的子对象，所以 Maya 知道这些手臂是层次中的一部分，并使用它们的节点信息，而非它们的名称，确定它们在层次中的位置。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-04D69E90-3BAC-4404-B728-13BC23BD86E2.png) <!-- baize:img-hook downloaded=false reason="正文 1672 字 ≥300，非承重" -->

只要新手臂的已发布属性匹配旧手臂的已发布属性，任何关联操作（如动画）都将从旧手臂传递到新手臂。
