# 编辑已发布属性的值

可以采用与其他节点属性进行交互的相同方法来与资产的已发布属性进行交互。利用选定的资产节点，可以完成下列操作：

- 使用“通道盒”(Channel Box)直接编辑每个已发布属性的值。

- 在“属性编辑器”(Attribute Editor)中，使用“已发布的属性”(Published Attributes)部分中的滑块等控件来编辑值。

**注**

默认情况下，已发布的属性会显示在“属性编辑器”(Attribute Editor)中，同时还在该属性自己的“属性编辑器”(Attribute Editor)实例中显示同一控件（例如，布尔属性会显示复选框，而颜色属性会显示滑块及颜色样例，依此类推）。这也就意味着，如果在资产中为对象发布 translateX、translateY 和 translateZ，“属性编辑器”(Attribute Editor)将以字段中的三个值来显示这些属性，而不会以三个单独的滑块来显示。通过按住 ![图：默认情况下，已发布的属性会显示在“属性编辑器”(Attribute Editor)中，同时还在该属性自己的“属性编辑器”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-6BC67455-3D71-444F-B249-B8161AD6821F.png) <!-- baize:img-hook downloaded=false reason="正文 683 字 ≥300，非承重" --> + ![图：默认情况下，已发布的属性会显示在“属性编辑器”(Attribute Editor)中，同时还在该属性自己的“属性编辑器”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 683 字 ≥300，非承重" --> 并用鼠标向左或向右拖动相应的字段，可以利用虚拟滑块来修改这些值。如果希望显示三个滑块，可以设置一个具有自定义视图的资产模板。请参见[为资产模板添加自定义视图](../创建资产模板和视图/为资产模板添加视图.md)。

在“属性编辑器”(Attribute Editor)中，还可以修改资产的属性，例如，“类型”(Type)、“所有者”(Owner)、“创建日期”(Creation Date)、“模板路径”(Template Path)、“视图名称”(View Name)及“图标名称”(Icon Name)。在“资产属性”(Asset Attributes)标题下可以找到所有这些选项。也可以使用“注释”(Notes)字段来添加有关资产的附加信息。
