# 自动绑定资产

如果当前模板具有关联的绑定集，则可以使用“自动绑定”(Autobind)功能自动发布和绑定属性。有关绑定集的详细信息，请参见[创建绑定集](../创建资产模板和视图/创建绑定集.md)。

自动绑定资产

1. 选择要自动绑定的资产。

2. 打开“资产编辑器”(Asset Editor)（[资产 > 资产编辑器(Assets > Asset Editor)](../资产编辑器%28Asset%20Editor%29.md)）。

3. 在“资产编辑器”(Asset Editor)中，选择资产并单击“固定资产”图标 ![图：在“资产编辑器”(Asset Editor)中，选择资产并单击“固定资产”图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-F9B182B8-BA9F-4BAC-9C23-20BF314F9514.png) <!-- baize:img-hook downloaded=false reason="正文 410 字 ≥300，非承重" -->。

4. 选择“模板 > 指定 > 指定新模板”(Template > Assign > Assign New Template)。

  此时将显示文件浏览器。

5. 导航到模板，然后单击“打开”(Open)按钮。

6. 选择“模板 > 自动绑定资产”(Template > Autobind Asset)。

  Maya 自动绑定资产时可能需要等候片刻。绑定完成后，右侧面板将更新，显示所有已成功完成自动绑定的属性。

  如果模板的绑定集无法在资产中找到适当的属性进行属性映射，则相应的已发布名称将保留在“未绑定”(Unbound)区域中。
