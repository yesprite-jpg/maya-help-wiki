# 替换被引用的资产

可以在场景中用新资产替换被引用的资产，只要两者的已发布属性相符就不会丢失任何引用编辑（如动画）。

替换场景中的被引用资产

1. 选择[文件 > 引用编辑器(File > Reference Editor)](../../文件引用/引用编辑器%28Reference%20Editor%29.md)。

  此时将出现“引用编辑器”(Reference Editor)窗口。

2. 选择“引用编辑器”(Reference Editor)中的被引用文件。

3. 选择“引用 > 替换引用”(Reference > Replace Reference)。

  将显示文件浏览器。

4. 选择要替换引用的文件。

  用新文件的内容替换场景中的被引用资产。

只要新文件具有与旧资产同名的资产和一组同名的已发布属性，新资产将保留对旧资产所做的任何引用编辑。

替换引用也适用于已发布的定位点。例如，如果有一个道具文件需要根据某个父文件中角色的手设置为其子对象，则可将道具在其自己的文件中发布为子定位点，然后将一个引用设置为手的子对象。然后可以创建多个版本的道具（所有这些道具都有唯一的几何体和名称），并在所有这些道具上发布一个具有相同名称的子定位点。接下来可按照上述方法将各种道具交换到角色的手中或从其手中交换出来。有关其他示例，请参见[示例：交换机器人的手臂](../编辑资产/示例：交换机器人的手臂（仅限“高级资产”）.md)。
