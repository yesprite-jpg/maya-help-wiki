# 将资产导出为文件引用

可以将现有场景中的资产导出为引用。这将创建包含选定节点的子文件，并自动创建这两个文件之间相应的文件引用关系。详细信息请参见[将对象导出为被引用文件](../../../../导入和导出文件/导入和导出文件/将对象导出为被引用文件.md)。

将场景中的资产导出为引用

1. 选择要导出的资产。

2. 选择文件 > 导出当前选择(File > Export Selection) > ![图：选择文件 导出当前选择(File Export Selection) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 371 字 ≥300，非承重" -->。

3. 在[“导出当前选择选项”(Export Selection Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/files/GUID-A1E550E4-1510-4D45-A811-5E424A8D3924.htm)中，启用“仅保持一个引用”(Keep only a reference)。

4. （可选）您也可以使用“包括选项”(Include Options)部分以包括资产外部的其他数据，例如其他动画或着色器。由资产封装的所有内容自动包括在内。

5. 单击“导出当前选择”(Export Selection)。

6. 在显示的文件浏览器中，选择一个位置并输入引用文件的名称。

Maya 将所有选定节点导出到外部文件。然后就创建了从外部文件中的资产到父场景的引用。
