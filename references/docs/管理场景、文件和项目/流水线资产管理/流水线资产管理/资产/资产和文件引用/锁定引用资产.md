# 锁定引用资产

当您保存文件供以后引用时，可以锁定其中所有的资产，这样在父文件中就只能对资产的已发布的属性进行操作。此外，您还可以锁定文件本身，以确保不会将引用编辑从父文件保存到此文件中。

锁定未发布的属性供引用

1. 打开要引用的文件，然后选择“文件 > 场景另存为”(File > Save Scene As) > ![图：打开要引用的文件，然后选择“文件 场景另存为”(File Save Scene As) ，以打开场景另存为选项(Save…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 539 字 ≥300，非承重" -->，以打开场景另存为选项(Save Scene As Options)。

2. 在“引用选项”(Referencing Options)区域，将“资产未发布”(Asset unpublished)设置为“锁定”(Lock)。

3. （可选）将“锁定文件”(Lock File)设置为“锁定”(Lock)。

  这将防止用户从父文件保存任何引用编辑到该文件。

4. 单击“场景另存为”(Save Scene As)并输入文件的名称。

  保存文件时，会锁定场景中所有资产的所有未发布的属性。这相当于为文件中的每个资产选择“修改 > 资产 > 锁定未发布的属性”(Modify > Assets > Lock Unpublished Attributes)。有关详细信息，请参见[锁定资产](../导航资产/锁定资产.md)。

锁定对于引用的资产非常重要，因为对未发布的属性所做的更改在资产级别是不可见的。同样，如果替换了引用的资产，保存到未发布属性的更改会丢失。锁定可确保用户使用已发布的属性，从而避免出现这些问题。
