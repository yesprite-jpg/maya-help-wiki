# 移除资产

移除资产

1. 在“Hypergraph: 连接”(Hypergraph Connections)编辑器中选择要移除的资产节点。

2. 选择[编辑 > 资产 > 移除资产(Edit > Asset > Remove Asset)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-CB0EF7E3-F5B9-4CCB-9E1C-472038F1FAEC#GUID-CB0EF7E3-F5B9-4CCB-9E1C-472038F1FAEC__WS1A9193826455F5FF-4F542F6211C79DEA861-1CA8)。

这样就可以从“Hypergraph”的图形区域移除选定资产节点，并将其从文件中删除。所删除资产中的节点将移到父资产（如果存在）中，或者移到依存关系图的顶层。请注意，与资产内部节点之间的所有连接（包括已发布的和未发布的）都将保留。

**注**

无法从场景中移除锁定的资产。

移除场景中的所有资产

1. 选择“编辑 > 按类型删除全部 > 资产”(Edit > Delete All by Type > Assets)。

  这样就可以移除场景中的所有资产，但它们的内容仍然保留在场景中。
