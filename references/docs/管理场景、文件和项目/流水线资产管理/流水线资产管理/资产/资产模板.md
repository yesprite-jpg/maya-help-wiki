# 资产模板

资产模板是 XML 文件，可用于为资产创建公用的可互换的用户界面。对于每个模板，可以创建已发布属性的多个自定义视图。可以自定义每个视图及其各自的布局、属性标签和说明（工具提示）。

创建资产并定义其已发布属性后，可以保存包含已发布属性和已发布节点名称的模板。（请参见[创建资产模板](创建资产模板和视图/创建资产模板.md)。）下次创建相同种类的资产时，可以加载已保存的模板，以使用相同的已发布名称设置新资产。（请参见[为资产指定模板](创建资产模板和视图/为资产指定模板.md)。）

**注**

提示：

还可以将使用相同模板的所有资产设置为在“Hypergraph”和“大纲视图”(Outliner)中显示相同图标。（请参见[使用自定义图标标记资产](导航资产/使用自定义图标标记资产.md)）。

模板由资产使用资产的“模板名称”(Template Name)属性进行引用，该属性告知资产要使用哪个模板。（请参见[模板命名约定](模板文件格式.md#WS73099CC142F48755-42A8108711A530FF1D3873)。）每个模板文件都存储指定资产所需的一组已发布属性名称。这使您可以快速轻松地创建同一种类的其他资产，而不会错失任何所需的属性。通过将模板另存为单独的文件，可以独立于特定场景文件建立模板库，您可以整个制作流程中重复使用这些模板。

将模板指定给场景中的资产后，可以将资产的属性绑定到模板的未绑定属性。

例如，可以使用同一资产模板设置场景中的所有聚光灯，从而为所有聚光灯资产提供一个公用界面。由于所有聚光灯资产具有完全相同的一组已发布属性，因此可以使用“替换引用”(Replace Reference)或“传递属性值”(Transfer Attribute Values)在它们之间轻松地交换控件和动画。（请参见[替换被引用的资产](资产和文件引用/替换被引用的资产.md)和[在资产之间传递属性值](编辑资产/在资产之间传递属性值.md)。）

使用模板为资产创建公用界面是可选的。但是，如果保存模板，则还可以为每个模板定义多个视图或布局。通过模板视图，可以完全自定义资产界面，进而在“资产编辑器”(Asset Editor)、“属性编辑器”(Attribute Editor)、“大纲视图”(Outliner)和“通道盒”(Channel Box)中更改属性的分组、组织和命名方式。

## 模板视图

通过模板视图，可以定义在 Maya 窗口和编辑器中显示资产的已发布属性的方式。根据您的生产要求，可以为每个模板创建多个视图。（请参见[为资产模板添加视图](创建资产模板和视图/为资产模板添加视图.md)）

模板视图实际上是按特定目的分组并组织在一起的一组已发布资产属性。通过为一个模板创建一组不同的视图，可以按制作流程所需的任何目的创建不同的用户界面。（请参见[自定义模板视图](创建资产模板和视图/自定义模板视图.md)。）

例如，可以创建自定义模板视图以执行以下操作：

- 在“大纲视图”(Outliner)、“属性编辑器”(Attribute Editor)、“资产编辑器”(Asset Editor)和“通道盒”(Channel Box)中自定义资产属性的基本显示方式。

  重新组织资产显示，以更改属性的分组和顺序。

- 控制团队中的每个成员可查看和修改哪些属性。

  通过为每个用户创建一个模板视图，可以指定允许相应用户访问的属性。例如，可以分别为团队中的建模者、装配师和动画设计者创建一个视图。

  可以将每个用户所需的控件和属性分组到专门为它们设计的界面中。由于每个用户只能修改为其添加的属性，因此不会出现团队成员意外覆盖与其工作无关的属性的危险。

- 对项目中的每个任务或每项指定所需的属性进行分组。

  为团队成员在项目中需要完成的每个任务设置一个视图。通过在模板视图中仅包括指定任务所需的属性，可以简化每个用户的工作流。用户在完成项目工作后可以在不同视图之间进行切换，同时还可以在搜索所需属性方面节省时间。

有关设置您自己的自定义视图的信息，请参见[为资产模板添加视图](创建资产模板和视图/为资产模板添加视图.md)和[自定义模板视图](创建资产模板和视图/自定义模板视图.md)。

## 模板绑定集

通过绑定集，可以创建已发布名称与它们绑定到的属性的映射，并将映射存储到资产的模板中。然后可以使用此映射自动绑定使用相同模板的未来资产。这样可以避免独立发布每个属性。有关详细信息，请参见[创建绑定集](创建资产模板和视图/创建绑定集.md)。

当创建绑定集时，Maya 会在模板文件中创建一组条目，这些条目会自动将所有已发布名称与它们当前绑定到的节点名称相关联。如果希望绑定集更广泛地起作用，可以在外部打开模板文件并将这些名称替换为正则表达式。

例如，可以使用绑定集和自动绑定功能执行以下操作：

- 向后匹配资产。

  打开现有资产并将您的模板应用于该资产。自动绑定资产。所有先前的未绑定属性或与绑定集映射采用不同方式绑定的属性都会被发布并绑定（或重新绑定），以便与模板相匹配。

- 创建相同类型的多个角色。

  创建绑定集的第一个角色后，可以创建资产并将相应的属性发布到该资产。然后可以创建当前资产的绑定集。创建绑定集的第二个角色时，请应用相同的模板并自动绑定资产。所有属性都会按照模板发布和绑定。然后可以处理其余的所有未绑定属性。

- 管理相同资产的迭代版本。

  创建资产并发布相应的属性后，请创建绑定集。即使当前项目已结束，也可以在下一代版本中重复使用该绑定集作为相同的基础资产。然后可以自动绑定下一代资产并无限期重复此过程。
