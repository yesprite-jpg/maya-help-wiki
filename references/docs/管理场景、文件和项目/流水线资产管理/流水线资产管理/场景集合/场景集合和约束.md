# 场景集合和约束

您可以在“场景集合”工作流中使用[约束](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7665A291-FAA7-44C0-BDEB-A6C83482116C)来约束集合引用节点和集合引用成员的位置、方向或移动。集合引用成员包含嵌套的集合引用节点和场景表示所包含的对象。在集合引用节点和成员上创建的约束的行为方式与在典型 Maya 对象和对象层次上创建的约束相同。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-80B55EE6-D090-41A7-9C07-028D434759B4.png) <!-- baize:img-hook downloaded=false reason="正文 517 字 ≥300，非承重" -->

将约束与场景集合配合使用，您可以：

- 在集合引用节点、集合引用成员与集合引用层次外部的对象之间创建约束。

- 在“场景集合”层次的任何级别，向集合引用节点和集合引用成员添加约束。

  请参见[场景集合和约束示例](场景集合和约束/场景集合和约束示例.md)。

- 将集合引用成员约束到多个目标对象。

  请参见[场景集合和约束节点连接](场景集合和约束/场景集合和约束节点连接.md)。

- 在受约束 assemblyReference 节点的各种表示之间切换，而不会丢失约束行为。

  请参见[切换约束的表示](场景集合和约束/切换约束的表示.md)。

**注**

不能直接向缓存和定位器表示添加约束。将 assemblyDefinition 节点引用到场景中时，应用于该节点的约束不会保留。请参见

场景集合和约束节点连接

。

约束集合引用成员时，约束节点会显示在“大纲视图”(Outliner)中的受约束集合引用成员下方。与典型 Maya 对象之间的约束相同，约束节点是受约束对象的子对象。但对于集合引用，约束节点不是集合引用的成员。
