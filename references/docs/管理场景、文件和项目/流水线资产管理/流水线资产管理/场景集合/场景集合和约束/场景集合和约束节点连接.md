# 场景集合和约束节点连接

在集合引用节点或集合引用成员上创建约束时，将对这些对象应用添加连接编辑和建立父子关系编辑。根据所创建约束的类型，可能会对这些对象应用多个连接编辑。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-864A09CD-C2B5-414B-8FA8-5304E8F66C34.png) <!-- baize:img-hook downloaded=false reason="正文 611 字 ≥300，非承重" -->

与其他场景集合编辑一样，从场景中卸载集合引用节点或集合引用成员后，将不再应用编辑。当集合引用成员是受约束对象并且已卸载时，将创建一个 fosterParent 节点作为已卸载的集合引用成员的占位符。请参见[切换约束的表示](切换约束的表示.md)。

当约束连接编辑被移除时，例如通过在“列出集合编辑”(List Assembly Edits)窗口中将其选中，然后单击“移除选定编辑”(Remove Selected Edits)，约束节点仍停留在场景中

**注**

约束连接不再受限制。它们不具有与

“平移”(Translate)

、

“旋转”(Rotate)

、

“缩放”(Scale)

和

“可见性”(Visibility)

属性连接相同的限制。请参见

在场景集合节点之间建立属性连接

。

集合引用成员对象可以是任意数量的约束的目标。例如，assemblyReference 节点可以同时是两个“点”(Point)和一个“方向”(Orientation)约束的目标。对于每种约束类型，可将集合引用成员对象约束到一个目标对象。例如，场景表示包含的对象一次只能受一个目标对象的“点”(Point)约束。它可同时受“点”(Point)约束和“方向”(Orient)约束。
