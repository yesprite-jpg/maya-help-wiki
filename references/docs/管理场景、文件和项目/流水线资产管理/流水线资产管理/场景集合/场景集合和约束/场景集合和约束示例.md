# 场景集合和约束示例

下面的部分提供了有关如何在场景集合工作流中使用约束的示例。

## 示例 1：目标和受约束对象是 assemblyReference 节点

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-7BC358CA-A949-4C44-AAA5-3F20DFBE270B.png) <!-- baize:img-hook downloaded=false reason="正文 614 字 ≥300，非承重" -->

### 用例

在本示例中，目标对象是游轮模型的一个分层集合引用（具有包含其他 assemblyReference 节点的场景表示的 assemblyReference 节点）。此集合引用包含了游轮的多个表示，每个都有不同级别的细节。受约束对象是站在游轮甲板上的角色的集合引用。动画模拟游轮模型在水上的运动时，此角色也遵循同样的运动。此设置允许根据所需快照的需要快速切换各个集合引用（游轮和角色）的不同表示。

## 示例 2：目标对象是集合引用成员，受约束对象是 assemblyReference 节点

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-1E2F5C72-4DF9-4D67-ACE1-8720DA4D0966.png) <!-- baize:img-hook downloaded=false reason="正文 614 字 ≥300，非承重" -->

### 用例

道具对象的集合引用（如手电筒或铁撬棍）被限制到其他集合引用的成员。动画显示角色时，道具保持在角色的手中。

## 示例 3：目标和受约束对象是集合引用成员

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-D257E5E4-F8A8-4BBA-817D-8CCEF0CDAE2E.png) <!-- baize:img-hook downloaded=false reason="正文 614 字 ≥300，非承重" -->

### 用例

集合引用成员（角色装备的手动控制）被限制到另一个集合引用的集合引用成员（即汽车模型的方向盘）。当方向盘转动时，角色的手保持接触方向盘。

## 示例 4：目标是 assemblyReference 节点或集合引用成员，受约束对象是主场景 Maya 对象

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-6A82563D-DB07-4B7D-859C-367831870B00.png) <!-- baize:img-hook downloaded=false reason="正文 614 字 ≥300，非承重" -->

### 用例

主场景对象（如用户定义的摄影机）是目标对象，它约束着某个集合引用成员，例如游轮模型的某个部分。当游轮模型移动或前后摆动时，摄影机仍保持固定并持续跟踪该游轮的运动。
