# 准备创建表示

若只对资产使用简单的[定位器表示](../场景集合基础知识/集合表示.md#GUID-E0F5484D-6F7F-4F8D-B298-DD21160C272F__GUID-CB48764E-006A-4D12-83E3-9EE874007E46)，则创建表示之前不需要额外的设置。但是，如果要将[缓存](../场景集合基础知识/集合表示.md#GUID-E0F5484D-6F7F-4F8D-B298-DD21160C272F__GUID-23A5B3A9-A648-4E52-B013-C4DBB4D90B5B)或[场景表示](../场景集合基础知识/集合表示.md#GUID-E0F5484D-6F7F-4F8D-B298-DD21160C272F__GUID-A3079837-357C-4A19-B970-D92FA05501F6)添加到[集合定义](../场景集合基础知识/集合定义.md)，请确保所需的所有文件都已包含在 Maya 项目目录中。默认情况下，[添加表示](添加集合表示.md)之后，添加缓存表示和添加场景表示命令可浏览项目 cache/alembic 和 scene 目录。

- 要为对象添加[缓存表示](../场景集合基础知识/集合表示.md#GUID-E0F5484D-6F7F-4F8D-B298-DD21160C272F__GUID-23A5B3A9-A648-4E52-B013-C4DBB4D90B5B)，请确保基于 Alembic 的缓存文件存在于 cache/alembic 目录中。

- 要添加[场景表示](../场景集合基础知识/集合表示.md#GUID-E0F5484D-6F7F-4F8D-B298-DD21160C272F__GUID-A3079837-357C-4A19-B970-D92FA05501F6)，请确保将文件保存在 scene 目录中。

- 若要将边界框用作表示，请把这些对象转换为边界框，然后将其保存为 Alembic 缓存或 Maya 场景文件。请参见[将边界框用作表示](将边界框对象用作表示.md)。

**注**

重要：

请勿在表示文件中使用名称空间。
