# 创建集合定义

每个资产的[集合定义](../场景集合基础知识/集合定义.md)必须保存为单独的 Maya .ma 或 .mb 文件。（Maya 文件只能包含一个 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md) 节点。）

创建集合定义

1. 通过选择“文件 > 新建场景”(File > New Scene)启动一个新的 Maya 场景。

  **注**

  提示：

  由于一个集合定义也就是一个场景文件，因此，为了轻松识别场景目录中的集合定义，可以为场景文件名附加后缀

  _AD

  。

2. 执行下列操作之一：

  - 选择“创建 > 场景集合 > 创建集合定义”(Create > Scene Assembly > Create Assembly Definition) > ![图：选择“创建 场景集合 创建集合定义”(Create Scene Assembly Create Assembly Def…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 677 字 ≥300，非承重" -->。

  - ![图：在“大纲视图”(Outliner)的空白位置单击鼠标右键 ，然后从显示的菜单中选择“场景集合 创建集合定义”(Scene…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 677 字 ≥300，非承重" -->在“大纲视图”(Outliner)的空白位置单击鼠标右键 ，然后从显示的菜单中选择“场景集合 > 创建集合定义”(Scene Assembly > Create Assembly Definition) > ![图：在“大纲视图”(Outliner)的空白位置单击鼠标右键 ，然后从显示的菜单中选择“场景集合 创建集合定义”(Scene…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 677 字 ≥300，非承重" -->。

3. 在“集合定义选项”(Assembly Definition Options)窗口中，设置所需的选项并单击“创建”(Create)。

  例如，默认情况下会将定位器表示添加到集合定义中，除非禁用 “添加定位器表示”(Add Locator representation)。

  集合定义节点将添加到场景中，并显示在“大纲视图”(Outliner)中，由文件图标 ![图：集合定义节点将添加到场景中，并显示在“大纲视图”(Outliner)中，由文件图标 来表示。有关 assemblyDef…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-37B71363-BDA7-4AF4-8AB6-C16B1EADC643.png) <!-- baize:img-hook downloaded=false reason="正文 677 字 ≥300，非承重" --> 来表示。有关 assemblyDefinition 节点属性的信息，请参见 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md)。

  （可选）现在，可以将“缓存”(Cache)和“场景”(Scene)表示添加您到集合定义中。请参见[添加集合表示](添加集合表示.md)。

  **注**

  提示：

  重命名集合定义节点，以使其与所表示的资产的名称相匹配。
