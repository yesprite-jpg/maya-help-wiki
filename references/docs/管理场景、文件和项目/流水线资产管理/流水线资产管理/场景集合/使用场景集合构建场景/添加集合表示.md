# 添加集合表示

添加表示之前，保存基于 Alembic 的缓存和计划用作表示的 Maya 场景文件。请参见[准备创建表示](准备创建表示.md)。

可以使用“大纲视图”(Outliner)、场景视图菜单或“属性编辑器”(Attribute Editor)将[集合表示](../场景集合基础知识/集合表示.md)添加到[集合定义](../场景集合基础知识/集合定义.md)中。

将表示添加到集合定义中

1. 在“大纲视图”(Outliner)中，选择 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md) 节点。

2. 执行下列任一操作：

  - ![图：在“大纲视图”(Outliner)或场景视图中单击鼠标右键 ()，然后从显示的菜单中选择“场景集合”(Scene Ass…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 1109 字 ≥300，非承重" -->在“大纲视图”(Outliner)或场景视图中单击鼠标右键 ()，然后从显示的菜单中选择“场景集合”(Scene Assembly)。

  - 在“属性编辑器”(Attribute Editor)中，展开“集合表示”(Assembly Representations)标题。

3. 选择（或单击）“添加缓存表示”(Add Cache representation)、“添加场景表示”(Add Scene representation)或“添加定位器表示”(Add Locator representation)。

  如果选择了“添加定位器表示”(Add Locator representation)，将在场景中显示定位器。

  **注**

  提示：

  对于“定位器”(Locator)表示，可以使用“数据”(Data)属性来添加注释。当“定位器”(Locator)为活动表示时，注释文本将在场景中的定位器附近显示。

  如果选择了“添加缓存表示”(Add Cache representation)或“添加场景表示”(Add Scene representation)，Maya 将浏览项目 cache/alembic 和 scene 目录查找文件。

4. （可选）如果要使该表示处于活动状态，请启用“加载表示”(Load representation)。

  请参见[切换活动集合表示](切换活动集合表示.md)。

  如果“加载表示”(Load representation)已启用，则新添加的表示将作为活动表示添加到场景中。“大纲视图”(Outliner)和场景视图的“场景集合”(Scene Assembly)菜单中的可用表示列表列出了新表示。集合定义的“属性编辑器”(Attribute Editor)中的“表示列表”(Representation List)列出了新表示。

**注**

提示：

使用箭头图标，可以更改列表中表示的顺序。“表示列表”(Representation List)的排序还定义了表示将如何显示在“大纲视图”(Outliner)和场景视图菜单中。

添加表示后，可以修改“表示属性”(Representation Attributes)，如表示的“标签”(Label)。请参见 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md)。

**注**

不能删除或重命名场景表示包含的节点。
