# 将动画曲线添加到场景集合节点

可以将动画曲线数据添加到 assemblyReference 节点和场景表示包含的节点。可以对集合引用层次的所有级别节点进行这些连接。最高级别的集合引用节点可存储及跟踪将动画曲线连接到节点的编辑。动画曲线数据驻留在 assemblyReference 节点或场景表示的源文件中。
