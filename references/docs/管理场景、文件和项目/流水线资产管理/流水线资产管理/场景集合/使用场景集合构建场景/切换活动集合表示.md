# 切换活动集合表示

assemblyDefinition 节点的活动表示当前会显示在场景中以表示产品级资产。

您可以根据现有任务的性能要求更改处于活动状态的集合表示。例如，在遮挡场景时，您可能只希望定位器表示处于活动状态，但在以后决定如何为角色设置灯光以进行渲染时，则需要场景表示。

**注**

活动表示状态与场景一同保存。重新打开场景时，将自动加载上一个活动表示。

切换表示

1. 在“大纲视图”(Outliner)中，选择包含要切换的表示的 assemblyReference 或 assemblyDefinition 节点。

2. 执行下列任一操作以选择所需的表示：

  - 在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ![图：在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ，然后从显示的菜单中选择“场景集合”(Scene Asse…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 516 字 ≥300，非承重" -->，然后从显示的菜单中选择“场景集合”(Scene Assembly)。

    可用表示显示在“场景集合”(Scene Assembly)菜单的顶部。活动表示以粗体显示。

  - 在“属性编辑器”(Attribute Editor)中，展开“集合表示”(Assembly Representations)标题，然后从“活动表示”(Active Representation)列表中进行选择。

所选表示现在处于活动状态，并显示在场景中。
