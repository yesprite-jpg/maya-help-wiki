# 卸载活动的集合表示

当您不再需要查看场景中显示的对象时，可以卸载活动表示。卸载活动表示不会从 assemblyDefinition 节点中移除表示，因此您仍可以选择表示再次使其处于活动状态。

卸载活动表示

1. 在“大纲视图”(Outliner)中，选择包含要卸载的引用的集合引用或集合定义。

2. ![图：在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ，然后从显示的菜单中选择“场景集合”(Scene Asse…](../../../../../../assets/Maya-ManagingScenes/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=true reason="正文 276 字 <300 且带图" -->在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ，然后从显示的菜单中选择“场景集合”(Scene Assembly)。

3. 选择“卸载活动表示”(Unload active representation)。

  引用已卸载，并不再显示在场景中。
