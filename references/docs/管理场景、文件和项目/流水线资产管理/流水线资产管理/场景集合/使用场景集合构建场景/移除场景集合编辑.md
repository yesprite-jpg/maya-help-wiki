# 移除场景集合编辑

您可以在当前场景中移除应用于嵌套的 assemblyReference 节点和场景表示包含的节点的顶级集合编辑。如果场景已保存，仍可以移除在保存之前的编辑。

**注**

无法从当前场景中移除在“列出集合编辑”(List Assembly Edits)窗口中显示为不可移除的编辑。必须打开包含 assemblyReference 节点或场景表示的源文件才能移除这些编辑。请参见[不可移除的编辑](../场景集合引用/“列出集合编辑”%28List%20Assembly%20Edits%29窗口.md#GUID-19AAFD06-3917-4FAE-A179-FFE96A13E592__GUID-1F050B3C-BC84-429C-BAB5-F4A1ECB1C2F5)。

移除场景集合编辑

1. 在“大纲视图”(Outliner)中，选择具有要移除的编辑的 assemblyReference 节点。

2. 在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ![图：在“大纲视图”(Outliner)或场景视图中，单击鼠标右键 ，然后从显示的菜单中选择“场景集合 列出编辑”(Scene…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 469 字 ≥300，非承重" -->，然后从显示的菜单中选择“场景集合 > 列出编辑”(Scene Assembly > List Edits)。

3. 在“列出集合编辑”(List Assembly Edits)窗口中，选择要移除的编辑。

  如果要移除的编辑未显示，请更改“显示”(Show)选项。请参见[列出场景集合编辑](列出场景集合编辑.md)。

4. 若要移除选定的编辑，请单击[移除编辑](../场景集合引用/“列出集合编辑”%28List%20Assembly%20Edits%29窗口.md#GUID-19AAFD06-3917-4FAE-A179-FFE96A13E592__GUID-D3685B4D-E396-49F0-976E-121A609A0A04)。
