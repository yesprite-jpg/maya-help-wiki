# 使用集合引用来集合场景

创建集合引用

1. 执行下列操作之一：

  - 选择“创建 > 场景集合 > 创建集合引用”(Create > Scene Assembly > Create Assembly Reference)。

  - ![图：在“大纲视图”(Outliner)的空白位置单击鼠标右键 ，然后从显示的菜单中选择“场景集合 创建集合引用”(Scene…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 882 字 ≥300，非承重" -->在“大纲视图”(Outliner)的空白位置单击鼠标右键 ，然后从显示的菜单中选择“场景集合 > 创建集合引用”(Scene Assembly > Create assembly reference)。

  **注**

  重要：

  您还可以使用

  assembly

  MEL 命令创建 assemblyReference 节点。但是，不要使用

  createNode

  命令创建此节点。

2. 在显示的“设置定义文件”(Set Definition File)窗口中，选择要引用的集合定义文件。

3. 在“名称空间选项”(Namespace Options)中，设置所需的选项并单击“打开”(Open)。

  例如：

  - 若要使用名称空间，请确保“使用名称空间”(Use namespaces)处于启用状态。

    默认情况下，表示名称空间采用集合定义文件名。请参见[名称空间](../../../../名称空间/名称空间.md)。

  - 若要为名称空间指定文本字符串，请选择“字符串”(String)并在显示的字段中键入该名称空间。

  在“大纲视图”(Outliner)中，将显示 assemblyReference 节点，由 ![图：在“大纲视图”(Outliner)中，将显示 assemblyReference 节点，由 图标表示。默认情况下，新的集…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-73DC5FB2-79A1-47B7-B0BB-9A028CD26E46.png) <!-- baize:img-hook downloaded=false reason="正文 882 字 ≥300，非承重" --> 图标表示。默认情况下，新的集合引用将继承引用的 assemblyDefinition 节点的名称。

**注**

提示：

在场景视图中处理表示时，可以使用以下方法快速访问 assemblyReference 节点和

“场景集合”(Scene Assembly)

菜单。

  在“首选项”(Preferences)窗口中启用“以资产为中心选择”(Asset centric selection)。请参见[选择首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8C8BA1F4-59EE-4A02-BFE7-9193C0D6F5BE)。

  选择表示可选择其 assemblyReference 节点。

- ![图：在表示上单击鼠标右键 () 并从显示的菜单中选择“选择集合”(Select Assembly)。 该表示的 assemb…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-339814BD-5F9D-4AF0-AD24-9C56C81EB765.png) <!-- baize:img-hook downloaded=false reason="正文 882 字 ≥300，非承重" -->在表示上单击鼠标右键 () 并从显示的菜单中选择“选择集合”(Select Assembly)。

  该表示的 assemblyReference 节点处于选定状态。

现在可以通过在表示上单击鼠标右键并从显示的菜单中选择表示来访问“场景集合”(Scene Assembly)菜单。
