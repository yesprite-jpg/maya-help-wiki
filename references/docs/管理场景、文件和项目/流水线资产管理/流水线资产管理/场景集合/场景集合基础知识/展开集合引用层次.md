# 展开集合引用层次

在创建集合引用层次之后，可以通过创建包含集合引用的其他级别的集合定义来继续构建大型场景或布局。该工作流可能会提供从单个 Maya 场景文件内对大量数据集的访问。例如，可以执行以下操作：

- 将 Maya 场景文件（包含多个 assemblyReference 节点）添加为场景表示。

- 创建与多个 assemblyReference 节点包含相同生产资产的 Alembic 缓存。将该缓存作为缓存表示添加到集合定义节点。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-2E772C2B-DC6B-48FE-9A8C-4A9A426C0C22.png) <!-- baize:img-hook downloaded=false reason="正文 416 字 ≥300，非承重" -->

通过该工作流，可以持续构建生产资产，同时在场景集合层次中的所有表示之间进行访问和切换。如果特定快照序列需要不同的构建版本，则可以作为场景表示在这些变化之间进行切换（如果需要）。

在下图中，通过 *City_AR.ma* assemblyReference 节点在顶层级定义场景集合层次。在该排列中，可以从 *City_AR.ma* assemblyReference 节点切换由 *Bld_AD.ma* 定义的场景表示。
