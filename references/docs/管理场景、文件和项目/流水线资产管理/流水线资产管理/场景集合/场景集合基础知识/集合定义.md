# 集合定义

有关您的生产资产及其各种[集合表示](集合表示.md)的信息存储在集合定义（[assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md) 节点）中。通过集合定义，可以在生产资产的不同表示之间进行切换。由于 Maya 场景仅可以包含一个 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md) 节点，因此每个集合定义必须保存为单独的 .ma 或 .mb 场景文件。（请参见[创建集合定义](../使用场景集合构建场景/创建集合定义.md)。）

在创建 [assemblyDefinition](../场景集合引用/场景集合节点/assemblyDefinition.md) 节点时，它将显示在“大纲视图”(Outliner)、“节点编辑器”(Node Editor)和由图标 ![图：在创建 assemblyDefinition 节点时，它将显示在“大纲视图”(Outliner)、“节点编辑器”(Nod…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-37B71363-BDA7-4AF4-8AB6-C16B1EADC643.png) <!-- baize:img-hook downloaded=false reason="正文 441 字 ≥300，非承重" --> 表示的“Hypergrap”中。

## 重要说明

在使用场景中的集合定义时，请考虑以下事项：

- 仅一个集合定义可以被集合引用节点引用。如果场景包含多个集合定义节点，则会出现错误，且不会引用任何集合定义。

- 对集合定义节点和其他 Maya 节点或其他集合定义节点进行分组或建立父子关系可能会导致不可预测的结果。

- 场景集合和 Maya [文件引用](../../文件引用.md)不兼容。
