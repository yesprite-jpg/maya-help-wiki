# 使用场景集合构建场景

以下步骤概述了如何使用[场景集合](../场景集合.md)设置一个大场景。

使用场景集合构建场景

1. [创建新项目](../../../将文件组织到项目中/将文件组织到项目中/创建新项目.md)。

  如果您已创建 Maya 项目，场景集合设置最为简单。这样可以确保所需的默认目录（例如 scene 和 cache 目录）在您开始之前便已存在。

2. [对于您希望在场景中的每项产品级资产，准备创建表示](使用场景集合构建场景/准备创建表示.md)。

3. [对于每项资产，创建集合定义](使用场景集合构建场景/创建集合定义.md)。

4. [向集合定义添加集合表示](使用场景集合构建场景/添加集合表示.md)。

5. [使用集合引用来集合场景](使用场景集合构建场景/使用集合引用来集合场景.md)。

6. [通过构建集合引用的层次展开场景](场景集合基础知识/展开集合引用层次.md)。
