# 创建过滤器来指定要渲染的表示

您可以使用“自定义”(Custom ) “渲染表示”(Render representation)选项来创建一个指定要在渲染时间渲染哪些表示的过滤器。

有关 Maya 如何使用过滤器找到和渲染表示的更多信息，请参见[指定要渲染的集合引用](指定要渲染的集合表示.md)。若要仅渲染处于活动状态的表示，请参见[渲染活动表示](渲染活动表示.md)。

**注**

“场景集合”(Scene Assembly)

“渲染表示”(Render representation)

选项设计用于集合引用。使用这些选项渲染集合定义可能不会输出所需的结果。

创建指定要在渲染时渲染哪些表示的过滤器

1. 选择“窗口 > 渲染编辑器”(Window > Render Editors) >[渲染设置(Render Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-59DFB8B7-776B-4243-B404-A3D602FF8CFD)，打开“渲染设置”(Render Settings)窗口。

2. 在“渲染设置”(Render Settings)窗口中，单击“公用”(Common)选项卡。

3. 浏览至[场景集合(Scene Assembly)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-854C7738-90C1-4518-9808-559C433F49E8)区域，然后将其展开。

4. 从“渲染表示”(Render representation)列表中，选择[自定义(Custom)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-C3B7F028-5612-41A3-9662-D5AF764AB135)。

5. 若要定义过滤条件，请在以下一个或多个字段中键入信息：

  - [表示名称(Representation Name)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-B4291DCD-27B7-4144-928A-9CA8CBF613AE)

  - [表示标签(Representation Label)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-00394E60-37A6-45AA-94BF-BD21C058A838)

  - [表示类型(Representation Type)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-33448643-D405-4603-826B-77CD7E60ABBE)

  若要创建更具体的过滤器，请在多个字段中键入文本。例如，创建一个使用“表示名称”(Representation Name)和“表示类型”(Representation Type)的过滤器来搜索具有指定“名称”(Name)且属于指定“类型”(Type)的表示。

  **注**

  在

  “表示名称”(Representation Name)

  、

  “表示标签”(Representation Label)

  和

  “表示类型”(Representation Type)

  字段中键入的文本区分大小写。确保您的字符串与要渲染的表示的

  “名称”(Name)

  、

  “标签”(Label)

  或

  “类型”(Type)

  属性文本一致。

当您渲染场景（[渲染 > 批渲染(Render > Batch Render)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9F22DAD-4037-40EE-A6A5-A2E7C6F75E74)或渲染 > 渲染当前帧(Render > Render Current Frame)）时，将渲染活动表示。

**注**

使用

“自定义渲染表示”(Custom Render representation)

选项时，若要提高渲染性能，请使用批渲染（

“渲染 > 批渲染”(Render > Batch Render)

）或从命令行执行渲染。从

“渲染视图”(Render View)

窗口中进行渲染可能会比预期时间要长。
