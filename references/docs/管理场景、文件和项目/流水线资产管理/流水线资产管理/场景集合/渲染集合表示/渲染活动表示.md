# 渲染活动表示

使用“活动表示”(Active Representation) “渲染表示”(Render representation)选项，可以渲染场景中当前处于活动状态的所有表示。“活动表示”(Active Representation)是默认的“场景集合”(Scene Assembly)渲染设置。

您还可以指定要渲染的表示。请参见[创建过滤器来指定要渲染的表示](创建过滤器来指定要渲染的表示.md)。

渲染活动表示

1. 选择“窗口 > 渲染编辑器 > 渲染设置”(Windows > Rendering Editors > Render Settings)以打开“渲染设置”(Render Settings)窗口。

2. 在“渲染设置”(Render Settings)窗口中，单击“公用”(Common)选项卡。

3. 浏览到[“场景集合”(Scene Assembly)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-854C7738-90C1-4518-9808-559C433F49E8)区域，然后将其展开。

4. 请确保从“渲染表示”(Render representation)列表中选择[“活动表示”(Active Representation)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-865DA22B-1BEA-409B-A404-384E4396A64D)。

当您渲染场景（[渲染 > 批渲染(Render > Batch Render)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E9F22DAD-4037-40EE-A6A5-A2E7C6F75E74)或渲染 > 渲染当前帧(Render > Render Current Frame)）时，将渲染活动表示。
