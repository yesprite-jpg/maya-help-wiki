# 指定要渲染的集合表示

使用“自定义场景集合”(Custom Scene Assembly)渲染设置，可以根据表示的[名称(Name)](../场景集合引用/场景集合节点/assemblyDefinition.md#GUID-9250CB75-70F0-4F3B-A0FC-B40B081BC531__GUID-19C986FE-6E20-44D8-AF23-828009D79EC7)、[标签(Label)](../场景集合引用/场景集合节点/assemblyDefinition.md#GUID-9250CB75-70F0-4F3B-A0FC-B40B081BC531__GUID-70FCA395-1017-48B6-BFB6-61C428126707)和[类型(Type)](../场景集合引用/场景集合节点/assemblyDefinition.md#GUID-9250CB75-70F0-4F3B-A0FC-B40B081BC531__GUID-C883DACA-98D5-4FC5-A728-9CA1D369CDE0)指定要渲染的表示。

通过“场景集合”(Scene Assembly)“自定义”(Custom)渲染设置可以将轻量场景资产用于布局或照明，然后在渲染时使用这些资产的高分辨率场景表示。例如，可以打开一个包含集合引用节点（其对象的缓存表示设为活动表示）的场景，然后批渲染对象的场景表示。此工作流使您可以在渲染几何体的高分辨率版本的同时，加载并查看场景对象的轻量表示，因此可节省场景的加载时间。

如果从“渲染表示”(Render representation)列表中选择“自定义”(Custom)，“渲染设置”(Render Settings)窗口将显示[表示名称(Representation Name)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-B4291DCD-27B7-4144-928A-9CA8CBF613AE)、[表示标签(Representation Label)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-00394E60-37A6-45AA-94BF-BD21C058A838)和[表示类型(Representation Type)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__GUID-33448643-D405-4603-826B-77CD7E60ABBE)字段。可在这些字段中键入字符串值来创建过滤器，以便 Maya 在渲染时使用此过滤器来查找、激活并渲染表示。

| 自定义(Custom) 渲染表示(Render representation)字符串 | 对应的表示属性(Representation Attributes)字符串 |
|---|---|
| 表示名称(Representation Name) | 名称(Name) |
| 表示标签(Representation Label) | 标签(Label) |
| 表示类型(Representation Type) | 类型 |

渲染时，Maya 将从集合层次中最上层的集合引用节点开始，在各个集合引用中搜索与指定“名称”(Name)、“标签”(Label)或“类型”(Type)搜索条件匹配的表示。如果发现匹配表示，该表示即会变成活动状态。然后，Maya 将搜索因上次激活而载入场景中的任何生成的集合引用。请参见[场景集合自定义渲染设置示例](场景集合自定义渲染设置示例.md)。

**注**

提示：

对要渲染的表示进行命名，以便按

“表示名称”(Representation Name)

或

“表示标签”(Representation Label)

对其进行过滤。同时必须确保过滤器也能找到包含要渲染的表示的嵌套集合引用节点。例如，父集合引用节点的表示可能不符合指定的过滤器条件，但其表示中有一个包含子集合引用成员，而这些成员具有的表示符合此条件。在这种情况下，渲染时将不会激活父集合引用节点中的任何表示，因而它的任何子集合引用成员都不会出现在渲染中。

若要创建更具体的过滤器，请在多个字段中键入文本。例如，创建一个使用“表示名称”(Representation Name)和“表示类型”(Representation Type)的过滤器来搜索具有指定“名称”(Name)且属于指定“类型”(Type)的表示。

**注**

在

“表示名称”(Representation Name)

、

“表示标签”(Representation Label)

和

“表示类型”(Representation Type)

字段中键入的文本区分大小写。确保您的字符串与要渲染的表示的

“名称”(Name)

、

“标签”(Label)

或

“类型”(Type)

属性文本一致。

请参见[创建过滤器来指定要渲染的表示](创建过滤器来指定要渲染的表示.md)。

也可以使用正则表达式来创建用于指定表示的过滤器。请参见[使用正则表达式指定要渲染的表示](使用正则表达式指定要渲染的表示.md)。
