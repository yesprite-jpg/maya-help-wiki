# 对 Alembic 缓存进行着色和渲染

可使用与 Maya 几何体相同的材质和工作流为标准 Alembic 文件包含的对象指定着色器。当从 [Alembic 导入](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DEA2C5A5-3D04-4081-BBDE-8D9DC788AF02)窗口选择[合并](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DEA2C5A5-3D04-4081-BBDE-8D9DC788AF02#GUID-DEA2C5A5-3D04-4081-BBDE-8D9DC788AF02__GUID-062FCD60-7420-4161-8770-F29F2AA4B4A5)时，Alembic 对象将继承其原始对象的着色。

请参见[合并 Alembic 和 Maya 几何体](使用%20Maya%20对象合并%20Alembic%20缓存.md)以及[导入 Alembic 缓存文件](导入%20Alembic%20缓存文件.md)。

Alembic 对象可以使用 Maya 软件渲染器或 Arnold for Maya 进行渲染。
