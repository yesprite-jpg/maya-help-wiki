# 创建场景文件的缩略图和播放预览

保存或导出场景文件（选择“文件 > 保存场景”(File > Save Scene) > ![图：保存或导出场景文件（选择“文件 保存场景”(File Save Scene) 、“文件 场景另存为”(File Save…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-ManagingScenes/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 628 字 ≥300，非承重" -->、“文件 > 场景另存为”(File > Save Scene As)、“文件 > 导出全部”(File > Export All)、“文件 > 导出当前选择”(File > Export Selection)或“文件 > 导出到脱机文件”(File > Export to Offline File)）时，可以将缩略图或图像序列（播放预览）与场景文件一同保存。这样可以轻松识别[内容浏览器](../../内容浏览器/内容浏览器.md)中的文件。在内容浏览器中将鼠标移动到场景文件缩略图上方时，将运行场景文件播放预览。

缩略图和播放预览仅适用于 Maya ASCII (.ma)、二进制 (.mb) 和 FBX 文件。缩略图以 256 x 256 分辨率保存在项目中用于保存场景文件（例如，项目的 \scenes 文件夹）的 mayaSwatches 文件夹下的 .ma.swatch、.mb.swatch 或 .fbx.swatch 文件中。播放预览保存在 .ma.preview、.mb.preview 或 .fbx.preview 文件中，每帧捕捉一个文件。

有关如何创建场景文件缩略图或播放预览的信息，请观看以下视频。有关这些选项的详细信息，请参见[捕捉缩略图/播放预览(Capture Thumbnail/Playblast)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-95E518E7-9ABA-4863-8C8B-E712BB21AC5A)。
