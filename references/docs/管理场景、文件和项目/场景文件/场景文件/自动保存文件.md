# 自动保存文件

以一定的时间间隔自动保存场景

1. 选择“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)。

  此时将出现“首选项”(Preferences)窗口。

2. 在“类别”(Categories)的“设置”(Settings)区域中，选择“文件/项目”(Files/Projects)。

3. 在“自动保存”(Autosave)区域，打开“启用”(Enable)。

4. 设置其他选项并单击“保存”(Save)按钮。 有关这些选项的描述，请参见[“文件/项目”(Files/Projects)首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8E332DD5-879C-4AFD-8C6C-7C403FEF310F)的“自动保存”(Autosave)部分。

**注**

重要：

如果打开一个自动保存的文件并继续处理它，则该文件不会自动保存。若要继续处理自动保存的文件并使其自动保存，请重命名该文件并将其保存在不同于自动保存文件原有位置的其他位置。

**注**

自动保存的文件与源文件具有相同的基本名称，后跟一个递增的数字。
