# 切换文件的上方向轴

在动画和可视效果中，传统上使用 Y 轴作为“向上”轴或标高轴，使用 X 轴和 Z 轴作为“地面”轴。但是，其他行业传统上使用 Z 轴作为上方向轴，使用 X 轴和 Y 轴作为地面轴。

在 Maya 中，您可以在 Y 和 Z 之间切换上方向轴。

更改场景的上方向轴

1. 选择“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)。

2. 在“设置”(Settings)类别中，从“世界坐标系”(World Coordinate System)区域中选择 **Y** 或 **Z**。

## 轴和 FBX 文件

导入 FBX 文件时可以使用轴转化选项，但它只能作为脚本命令使用，因为 Maya 在导入时已自动计算并应用轴转化。对于命令，请参见 [FBX 导入 MEL 命令](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-699CDF74-3D64-44B0-967E-7427DF800290)中的 FBXImportAxisConversionEnable。

您可以在“FBX 导出器”(FBX Exporter)窗口中设置使用 FBX 导出的文件的轴转化。请参见 [FBX 导出选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-FE8DBEAA-C2DD-43B3-9933-4BA4CDDEAA89)中的“轴转化”(Axis conversion)。

详细信息请参见[“设置”(Settings)首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4D653DC9-57AA-4D8B-987A-5B7A9735CAF0)。
