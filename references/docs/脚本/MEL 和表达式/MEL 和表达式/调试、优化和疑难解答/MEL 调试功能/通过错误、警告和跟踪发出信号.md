# 通过错误、警告和跟踪发出信号

## 错误

[error](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Commands/error.html) 命令以标准 MEL 格式打印错误消息并停止脚本：

```text
$l = `ls -lights`;
if (size($l) == 0) {
	error "No lights in scene";
}
```

该命令将生成以下输出并停止执行：

```text
// Error: No lights in scene //
```

## 警告

[warning](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Commands/warning.html) 命令以标准 MEL 格式打印警告消息但不停止脚本：

```text
$l = `ls -lights`;
if (size($l) == 0) {
	warning "No lights in scene";
}
```

该命令将生成以下输出：

```text
// Warning: No lights in scene //
```

错误和警告命令都具有 -showLineNumber 标志。将该标志设定为 true 将显示出现警告或错误的文件和行号。将该标志设定为 false 将抑制行号。

```text
warning -showLineNumber true "No lights";
// Warning: file: C:\test.mel line 2: No lights //
```

## 跟踪

[trace](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Commands/trace.html) 命令以字符串形式打印 Maya 的标准错误输出。

```text
trace "Entering the loop";
while ($i < 10) {
	setAttr("nurbsSphere"+$i+".translateX",5);
}
trace "Exiting the loop";
```

使用 -where 标志将在输出中显示出现跟踪命令的文件和行号。
