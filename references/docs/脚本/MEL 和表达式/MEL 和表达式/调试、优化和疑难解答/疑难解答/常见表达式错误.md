# 常见表达式错误

编写表达式时可能会犯两种错误：语法错误和逻辑错误。语法错误包括拼写出错、属性名称不完整、分号忽略以及其他导致表达式无法编译和执行的疏忽。对于语法错误，Maya 将以消息方式向“脚本编辑器”(Script Editor)解释错误。

逻辑错误是指导致出现异常动画结果的推理错误。表达式的语法有效，但逻辑错误使 Maya 无法执行您所需的功能。更有甚者，语句还有可能将会某个操作锁定至永久性的循环中，结果导致 Maya 可能会停止操作。

由于 Maya 无法检测逻辑错误，因此，它不能显示错误消息。这样，这些错误很难发现，并且需要进行更多的分析才能解决。若要解决逻辑错误，显示相关属性和变量的内容通常十分有用。请参见[显示属性和变量内容](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Scripting/files/GUID-F79F4482-BCE6-4285-8B20-9D84D0309E4F.htm)。
