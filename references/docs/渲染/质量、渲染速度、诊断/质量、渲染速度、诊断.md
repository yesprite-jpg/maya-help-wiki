# 质量、渲染速度、诊断

## 图像质量和渲染速度

生成渲染图像始终涉及选择影响图像质量（抗锯齿和采样）、渲染速度还是同时这这两者。 换句话说，始终需要权衡速度与质量。

## 提高渲染图像质量

可以通过抗锯齿以及减少[瑕疵](质量、渲染速度、诊断/提高渲染图像质量/瑕疵.md)和[闪烁](质量、渲染速度、诊断/提高渲染图像质量/抗锯齿和闪烁.md)来提高渲染质量。有关抗锯齿的详细信息，请参见[提高渲染图像质量](质量、渲染速度、诊断/提高渲染图像质量.md)和[调整抗锯齿](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/调整抗锯齿.md)。

## 提高渲染速度

可以对许多设置进行调整来提高场景、曲面和/或阴影渲染的速度，以及摄影机渲染场景的速度。若要了解有关提高渲染速度的策略，请参见[提高整体渲染速度](质量、渲染速度、诊断/提高整体渲染速度.md)。

### 减少内存

在某些情况下，还可以减少渲染所使用的内存来缩短渲染时间。请参见[减少内存使用量](质量、渲染速度、诊断/提高整体渲染速度/减少内存使用量.md)。

### 减小文件大小（Maya 矢量渲染器）

复杂的场景和某些 Maya 矢量“渲染设置”(Render Settings)可能会产生非常大的 SWF 或 SVG 文件，这些文件不适合联机传送。

如果使用 Maya 矢量渲染器创建 SWF 或 SVG 文件以进行联机传送，则可修改场景并调整 Maya 矢量“渲染设置”(Render Settings)以找到在图像质量和文件大小之间的最佳折衷。请参见[减小矢量渲染文件大小的策略](质量、渲染速度、诊断/提高整体渲染速度/减小矢量渲染文件大小的策略.md)。
