# 提高整体渲染速度

若要使场景的渲染速度更快，请执行以下任一操作：

- 对于 Maya 软件，使用“渲染 > 运行渲染诊断”(Render > Run Render Diagnostics)来诊断场景以找到更快渲染场景的方式。可以使用该工具监视场景的优化程度，并搜索可能发生的限制和潜在问题。有关渲染诊断的详细信息，请参见[运行诊断](运行诊断.md)。

- 执行场景优化：

  - 选择“文件 > 优化场景大小”(File > Optimize Scene Size) > ![图：选择“文件 优化场景大小”(File Optimize Scene Size) ，以打开或关闭选项来优化场景中的所有对象…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 804 字 ≥300，非承重" -->，以打开或关闭选项来优化场景中的所有对象，并移除未使用的或无效的元素。请参见[优化场景大小选项(Optimize Scene Size Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6798B37D-0FF0-4ED3-A151-5CC648BB8CED)。

  - 对于 Maya 软件渲染，请使用块有序纹理设置。请参见[使用 BOT（块有序纹理）缓存纹理文件](提高整体渲染速度/减少内存使用量.md)。

  - 如果场景中包含具有构建历史的对象，并且您不再需要它，请将其删除。有关详细信息，请参见[构建历史](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-503E227B-EF49-4A78-B3CA-7EAC588017C9)。

- 避免内存交换：

  - 关闭所有应用程序，然后再渲染以最大化可用于渲染的内存（如果从壳或命令行渲染则包括 Maya）。

  - 设定 TEMP 或 TMPDIR 变量作为临时渲染缓存文件的位置：-TMPDIR (Linux) 或 - TEMP（Windows 和 Mac OS X）以使有足够的空间容纳临时渲染文件。确保这些变量的值指向本地快速硬盘驱动器，而不是网络驱动器。

- 对于 Maya 软件，“测试分辨率”(Test Resolution)（“渲染 > 测试分辨率”(Render > Test Resolution)）可用于在较低分辨率下对场景进行测试渲染。有关测试渲染策略的详细信息，请参见[与 IPR 可视化交互](../../可视化和渲染图像/可视化和渲染图像/渲染场景/与%20IPR%20可视化交互.md)。

- 对于 Maya 软件，如果场景包含几个相同的曲面（例如，多个球体），请使用[“渲染设置: Maya 软件”选项卡](../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口/“渲染设置”%28Render%20Settings%29“Maya%20软件”%28Maya%20Software%29选项卡.md)中的“优化实例”(Optimize Instances)来提高渲染性能。

- 如果不需要运动模糊，可将其禁用。对于 Maya 软件渲染器，尽可能使用 2D 运动模糊，而不是 3D 运动模糊。有关详细信息，请参见[渲染设置窗口](../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)中的 2D 运动模糊全局属性和 3D 运动模糊。
