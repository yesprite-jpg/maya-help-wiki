# 加快曲面渲染速度

请执行下列任一操作：

- 在对象的“属性编辑器”(Attribute Editor)上，使用单面而不是双面曲面（默认设置）。最大速度增益用于 Maya 硬件渲染器。

- 细分大型曲面需要大量内存，因此尽可能使用多个小曲面来代替一个大型曲面。处理较小的曲面时，渲染器更有效。

- 对于 Maya 软件渲染和 Maya 硬件渲染，请使用凹凸贴图，而不是置换贴图。

- 对于 Maya 软件渲染，请使凹凸贴图更平坦。若要执行该操作，请减小“Alpha 增益”(Alpha Gain)属性的值，这样可平滑凹凸贴图并减少自适应着色的采样数。仅当“边缘抗锯齿”(Edge Anti-aliasing)设定为“最高质量”(Highest Quality)时，该技术才适用。“Alpha 增益”(Alpha Gain)较低时，纹理凹凸外观较平坦。

- 对于 Maya 软件渲染，使用置换贴图时请启用“使用置换边界框”(Use Displacement Bounding Box)。

- 对于 Maya 软件渲染，尽可能使用分层纹理，而不是分层着色器。（有关详细信息，请参见[分层着色器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6DFCE108-8C98-4365-9D60-8A44149052A6)和 [2D 和 3D 纹理](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9FF65726-D8C2-4DB2-81A5-AFDCEBC10381)。）

- 对于 Maya 软件渲染，如果对场景进行光线跟踪，请将“反射限制”(Reflection Limit)和“折射限制”(Refraction Limit)设置为产生可接受结果的最小值。

- 对于 Maya 软件渲染，在 Linux 上的[“渲染设置: Maya 软件”选项卡](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口/“渲染设置”%28Render%20Settings%29“Maya%20软件”%28Maya%20Software%29选项卡.md)中，“使用文件缓存”可避免在渲染过程中重新细分相同的曲面。启用“使用文件缓存”(Use File Cache)可将几何数据存储在指定位置（默认位置为 /usr/tmp，但是可以通过键入 setenv TMPDIR *xxx* 设置一个新位置，其中 *xxx* 是将该文件输出到的目录的名称）中的一个单独文件中。
