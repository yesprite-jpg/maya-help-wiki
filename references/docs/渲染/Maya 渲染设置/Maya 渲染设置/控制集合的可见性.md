# 控制集合的可见性

通过启用或禁用集合控制其可见性。只有已启用的集合才会影响层且可见。

若要启用或禁用集合，请单击 ![图：若要启用或禁用集合，请单击 图标。已启用的集合使用 图标表示，而已禁用的集合则使用 和对角线图案表示。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-29C963C6-F4ED-4E14-B130-DAEF49E211D9.png) <!-- baize:img-hook downloaded=false reason="正文 597 字 ≥300，非承重" --> 图标。已启用的集合使用 ![图：若要启用或禁用集合，请单击 图标。已启用的集合使用 图标表示，而已禁用的集合则使用 和对角线图案表示。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-29C963C6-F4ED-4E14-B130-DAEF49E211D9.png) <!-- baize:img-hook downloaded=false reason="正文 597 字 ≥300，非承重" --> 图标表示，而已禁用的集合则使用 ![图：若要启用或禁用集合，请单击 图标。已启用的集合使用 图标表示，而已禁用的集合则使用 和对角线图案表示。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-D5653D72-ED4D-4BCB-8C53-D7D9E7A442DC.png) <!-- baize:img-hook downloaded=false reason="正文 597 字 ≥300，非承重" --> 和对角线图案表示。

  只有已启用的集合才在视口中可见，且包含在“渲染视图”(Render View)和批渲染中。

  通过将集合设置为隔离选定对象，可以进一步控制视口中的可见性。请参见[在视口中显示集合的隔离子集](在视口中显示集合的隔离子集.md)。

  如果禁用某个集合，则其相应的覆盖也会遭到禁用。请参见[禁用覆盖](在渲染层中为集合创建覆盖.md#GUID-AA669F09-9CDB-4327-BC37-3E4ECD6A0E69__SECTION_6BE233D2C5CF403C89409E3B644DA7F0)。

**启用/禁用条件按自上而下的顺序进行解释**。因此，如果两个（或更多）集合共享对象且分别处于启用和禁用状态，则列表中排在最下面的集合将确定共享对象是否包含在层中。

在本示例中，集合 Killamari_body_eyes 包含角色的身体和眼睛。

同时，集合 Killamari_eyes_eyesGlass 包含角色的眼睛和眼镜。

由于 Killamari_eyes_eyesGlass 在层次中位于 Killamari_body_eyes 的下面，且 Killamari_eyes_eyesGlass 设置为已启用，因此，角色的眼睛包含在层中。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-7B1E3A66-0C7D-47C8-AD09-2236BFEE5B88.png) <!-- baize:img-hook downloaded=false reason="正文 597 字 ≥300，非承重" -->

现在，如果反转这两个集合的顺序：如果 Killamari_body_eyes 在层次中位于 Killamari_eyes_eyesGlass 的下面，且 Killamari_body_eyes 设置为已禁用，则 Killamari_body_eyes 集合优先，并且角色的眼睛会从层中排除。
