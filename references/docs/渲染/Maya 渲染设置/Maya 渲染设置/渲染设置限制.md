# 渲染设置限制

渲染设置系统不支持以下各项：

- 将属性从“渲染设置”(Render Settings)窗口拖放到“特性编辑器”(Property Editor)以创建覆盖

  相反，您可以在“渲染设置”(Render Settings)窗口中，在要覆盖的属性上单击鼠标右键，然后选择“为可见层创建绝对覆盖”(Create Absolute Override for Visible Layer)或“为可见层创建相对覆盖”(Create Relative Override for Visible Layer)。请参见[为渲染层创建渲染设置覆盖](为渲染层创建渲染设置覆盖.md)

- 由表达式或动画曲线上的关键帧驱动的覆盖属性不能与渲染设置一起导出。

- 如果集合中缺少成员且层列表较长，则您可能需要向下滚动层列表来查找标有 ![图：如果集合中缺少成员且层列表较长，则您可能需要向下滚动层列表来查找标有 图标的层和集合。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-26F4BBA7-E3E5-4772-9D3A-9CEE46601D39.png) <!-- baize:img-hook downloaded=false reason="正文 319 字 ≥300，非承重" --> 图标的层和集合。
