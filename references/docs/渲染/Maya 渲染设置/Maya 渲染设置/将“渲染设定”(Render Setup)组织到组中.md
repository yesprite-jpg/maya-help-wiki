# 将“渲染设定”(Render Setup)组织到组中

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 310 字 ≥300，非承重" -->

您可以对“渲染设定”(Render Setup)集合进行分组，然后将这些组导出为 .json 并在新场景中重用模板。

通过单击鼠标右键并选择“创建组”(Create Group)，在层或集合内创建组。不支持嵌套组。

您可以[隔离选择](在视口中显示集合的隔离子集.md)组，这也会隔离选择其所有成员（子组和集合）。

您可以像集合一样[启用和禁用](控制集合的可见性.md)组。如果禁用组，也会禁用其成员（子组和集合）。

若要导出组，请单击鼠标右键，然后选择“导出选定对象”(Export Selected)，就像导出任何集合一样。可以将此模板导入到任何层、集合或组中。

如果导出包含组的层，或者通过“导出全部”(Export All)导出“渲染设定”(Render Setup)模板（包括组），则组将包含在模板中。
