# 渲染

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-F6BFC0BF-FDE2-4D7A-9ECE-CE74683A2B35.png) <!-- baize:img-hook downloaded=false reason="正文 913 字 ≥300，非承重" -->

渲染是 3D 计算机图形生成过程中的最后阶段。

虽然较宽的渲染上下文首先为对象执行着色和纹理操作以及照明场景，但渲染过程在曲面、材质、灯光和运动处理到最终图像或图像序列时结束。

## 可视化与最终渲染

构建场景（为对象执行着色和纹理操作、照明场景、定位摄影机等）时，您希望在生成最终渲染的图像或图像序列之前多次使其可视化。该过程可能会涉及（具体取决于您的特定项目）创建和设置其他摄影机。请参见[创建摄影机](../摄影机设置/摄影机设置/创建摄影机.md)和[调整摄影机及其属性](../摄影机设置/摄影机设置/创建摄影机/调整摄影机及其属性.md)。

在早期迭代期间显示场景以检测并更正图像质量问题，或者在花费时间执行最终渲染之前估计并减少最终渲染所用的时间。您可以[在视口中](../使用%20Viewport%202.0/使用%20Viewport%202.0.md)可视化您的场景，通过[使用 IPR 的 Maya 软件渲染器](../可视化和渲染图像/可视化和渲染图像/渲染场景/与%20IPR%20可视化交互.md)以交互方式渲染；或者，如果您使用的是 [Arnold for Maya 渲染器](../选择渲染器/选择渲染器/Arnold%20for%20Maya%20渲染器.md)，请在 [Arnold 渲染视图](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/Arnold+RenderView+Window)中以交互方式渲染。

您可以从 Maya 内以交互方式[渲染单帧](../可视化和渲染图像/可视化和渲染图像/渲染场景/渲染单帧.md)或[多帧序列](../可视化和渲染图像/可视化和渲染图像/渲染场景/以交互方式渲染帧序列.md)，即动画或动画的一部分。或者，您也可以对一个或多个帧进行[批渲染](../可视化和渲染图像/可视化和渲染图像/渲染场景/批渲染静止图像或动画.md)或[命令行渲染](../渲染实用程序/渲染实用程序/命令行渲染器/从命令行渲染.md)。

在开始最终渲染之前，请务必要[选择渲染器](../选择渲染器/选择渲染器.md)，并在[“渲染设置”(Render Settings)窗口](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/打开“渲染设置”%28Render%20Settings%29窗口.md)中设置渲染图像的[文件名](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/设定文件名语法.md)、[格式](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/设定已渲染图像的文件格式.md)和[分辨率](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/设定分辨率和像素纵横比.md)。

## 成功渲染的关键

渲染的关键是在所需的可视复杂程度与确定在给定的时间段内可以渲染多少帧的渲染速度之间找到平衡。

渲染涉及许多复杂的计算，可能会使计算机在较长时间内处于忙碌状态。渲染过程从 Maya 内每个子系统中提取数据并组合在一起，然后解释它自己与细分、纹理贴图、着色、剪裁和照明相关的数据。

生成渲染图像始终都需要您选择是影响图像质量（抗锯齿和采样）、图像的渲染速度还是两者都受影响。

最高质量的图像通常需要花费的渲染时间也最长。高效方法的关键是能在尽可能少的时间内生成质量足够好的图像，以便满足最终的生产期限。换句话说，如果只选择最经济的选项值，则只能生成特定项目可以接受的图像质量。

有关如何调整渲染的采样质量的信息，请参见[调整抗锯齿](../可视化和渲染图像/可视化和渲染图像/为渲染调整场景设置/调整抗锯齿.md)和 [Arnold for Maya 用户手册：采样](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/Sampling)。
