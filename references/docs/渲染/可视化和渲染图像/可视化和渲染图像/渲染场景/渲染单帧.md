# 渲染单帧

从 Maya 的主窗口中渲染或重新渲染单帧时，会在“渲染视图”(Render View)中显示渲染。有关使用“渲染视图”(Render View)的详细信息，请参见[关于渲染视图渲染](../渲染方法/关于渲染视图渲染.md)。

会自动将该图像保存到当前项目的 images 目录中。

**注**

提示：

请以 1:1 的分辨率渲染以获得最快的反馈。

**注**

在

“渲染视图”(Render View)

面板中导航与在大多数其他视图面板中导航类似。可以使用相同的键盘快捷方式缩放和平移视图。

从 Maya 内渲染帧

1. 在 Maya 主窗口中，单击“渲染当前帧”(Render Current Frame)按钮，或选择“渲染 > 渲染当前帧”(Render > Render Current Frame)。

  Maya 会渲染当前场景，并在渲染过程中在“渲染视图”(Render View)中显示图像。

从 Maya 内重新渲染帧

1. 从主菜单栏中选择“渲染 > 重做上一次渲染”(Render > Redo Previous Render)。

  Maya 渲染先前摄影机中的场景，并像它在“渲染视图”(Render View)窗口中渲染那样显示图像。

取消正在进行中的渲染

1. 按 Esc 键。
