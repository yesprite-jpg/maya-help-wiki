# 以交互方式渲染帧序列

可以通过以下三种方式渲染帧序列：

- 选择“渲染 > 渲染序列”(Render > Render Sequence)，然后从 Maya 中渲染动画。

  如果您没有 Arnold 许可，选择此选项可在渲染序列时不带水印。

- 通过选择“渲染 > 批渲染”(Render > Batch Render)，[从 Maya 中进行批渲染](批渲染静止图像或动画.md)。

- [从命令行进行批渲染](../../../渲染实用程序/渲染实用程序/命令行渲染器/从命令行渲染.md)。

  若要使用 Arnold for Maya 从命令行进行批渲染，请参见 [使用 Arnold for Maya 进行批渲染](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/Batch+Rendering)。

  如果您有 Arnold 许可，还可以选择第二种和第三种方式以在渲染图像时不带水印。

使用“渲染序列”(Render Sequence)渲染动画

  在“渲染设置”(Render Settings)窗口 >“公用”(Common)选项卡中，设置要渲染的帧。

  从[“渲染”(Rendering)菜单集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D90A2BDB-FD05-4528-8A95-C33A02D15129)中，选择“渲染 > 渲染设置”(Render > Render Settings)以打开“渲染设置”(Render Settings)窗口。

  在“文件输出 > 元数据 > 帧/动画扩展名”(File Output > Metadata > Frame/Animation ext)下（其中元数据包括名称、类型、值），选择带有 # 的任意选项，例如：name.#.ext。此选项确定渲染图像文件名的格式，并在下面的部分中激活“帧范围”(Frame Range) >“开始帧”(Start frame)和“结束帧”(End frame)属性。

  现在可以使用这些属性设置帧范围。

2. 选择“渲染 > 渲染序列”(Render > Render Sequence) > ![图：选择“渲染 渲染序列”(Render Render Sequence) ，打开“渲染序列”(Render Sequenc…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2830 字 ≥300，非承重" -->，打开“渲染序列”(Render Sequence)选项窗口。

  “渲染序列”(Render Sequence)窗口的标题栏指出要渲染的帧，例如，帧: 1-10(Frame: 1-10)。

  默认情况下，图像将保存到项目的 images 文件夹。若要将它们添加到“渲染视图”(Render View)，请启用“添加到渲染视图”(Add to Render View)。

  **注**

  提示：

  您还可以从“渲染视图”(Render View)菜单或“渲染视图 > 渲染”(Render View > Render)标记菜单中选择“渲染 > 渲染序列”(Render > Render Sequence) > ![图：您还可以从“渲染视图”(Render View)菜单或“渲染视图 渲染”(Render View Render)标记菜单…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2830 字 ≥300，非承重" -->。

  可以通过“渲染设置”(Render Settings)窗口 >“公用”(Common)选项卡验证将渲染图像保存到的路径。

3. 单击“渲染序列”(Render Sequence)开始渲染。

  “脚本编辑器”(Script Editor)中将显示消息，指示渲染的进度。

  如果已将图像添加到“渲染视图”(Render View)，请使用“渲染视图”(Render View)窗口底部的滑块滚动渲染图像序列。

## 其他渲染序列选项

“渲染序列”(Render Sequence)还提供以下选项：

- 从所有摄影机或仅从特定摄影机进行渲染

- 渲染场景中的区域

- 将渲染图像保存到项目的 images 文件夹或备用位置

- 将所有层或所有摄影机中的渲染图像添加到“渲染视图”(Render View)以便预览

此外，如果使用“渲染设定”(Render Setup)，则可以执行下列操作：

- 渲染所有层或仅渲染当前层

- 忽略或考虑局部覆盖

### 从所有摄影机或从特定摄影机进行渲染

若要从特定摄影机进行渲染，请从“当前摄影机”(Current Camera)下拉列表中选择它。在场景中创建的任何摄影机会自动添加到此列表。

若要从所有可渲染摄影机进行渲染，请启用“所有启用渲染的摄影机”(All Render-Enabled Cameras)。禁用此选项后，将仅渲染“当前摄影机”(Current Camera)。

**注**

提示：

如果“当前摄影机”(Current Camera)下拉列表显示为非活动，请检查是否已禁用“所有启用渲染的摄影机”(All Render-Enabled Cameras)。

### 渲染区域

此功能支持渲染场景中的区域。

在“渲染视图”(Render View)中框选要渲染的区域，然后启用“渲染序列”(Render Sequence)选项窗口中的“渲染区域”(Render Region)，并单击“渲染序列”(Render Sequence)。

### 选择图像的输出文件位置

默认情况下，渲染图像将保存到项目的 images 文件夹。若要设置备用位置，请通过“备用输出文件位置”(Alternate Output File Location)属性导航到该文件夹。

仅为当前 Maya 会话保存自定义的文件夹位置，在打开新的或现有场景后或退出并重新启动 Maya 后会清除此位置。

若要验证默认路径，请查看“渲染设置”(Render Settings)窗口 >“公用”(Common)选项卡。

### 将图像保存到“渲染视图”(Render View)

启用“添加到渲染视图”(Add to Render View)可将图像保存到“渲染视图”(Render View)，并使用窗口底部的滑块来滚动渲染图像序列。

启用“添加所有层”(Add All Layers)可添加所有层的渲染图像，启用“添加所有摄影机”(Add All Cameras)可将所有摄影机的渲染图像添加到“渲染视图”(Render View)。禁用这些选项将仅保存活动层和活动摄影机中的图像。

### 渲染所有层

如果已使用[渲染设定(Render Setup)](../../../Maya%20渲染设置/Maya%20渲染设置.md)划分场景，则可以渲染所有可渲染层或仅渲染当前层。启用“所有启用渲染的层”(All Render-Enabled Layers)可渲染所有层。让其保留禁用状态将仅渲染活动层。

### 忽略局部覆盖

在批渲染期间，[局部渲染覆盖](../../../Maya%20渲染设置/Maya%20渲染设置/仅将覆盖应用于交互式渲染器.md)将被忽略。渲染序列时，您可以选择在渲染中忽略或考虑局部覆盖。启用或禁用“忽略局部覆盖”(Ignore Local Overrides)选项。

该选项适用于保存到“渲染视图”(Render View)的图像以及保存的图像文件。

### 使用当前设置渲染序列

若要使用上次保存的设置渲染序列，请单击“渲染视图”(Render View)工具栏或“渲染”(Rendering)工具架中的 ![图：若要使用上次保存的设置渲染序列，请单击“渲染视图”(Render View)工具栏或“渲染”(Rendering)工具架…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-A2F5ADEC-7E76-4464-A903-227E1E26AC37.png) <!-- baize:img-hook downloaded=false reason="正文 2830 字 ≥300，非承重" -->。

## 渲染 Arnold AOV

将 AOV 添加到场景中，然后在渲染序列时将其输出并保存到磁盘。

1. 在“渲染设置”(Render Settings)窗口 >“AOV”(AOVs)选项卡中，[将 AOV 添加到场景中](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/AOVs)。

2. 确认在“渲染序列”(Render Sequence)窗口中选择的“渲染选项”(Render Options)正确。这些选项应用于渲染序列和 AOV。

  例如，如果启用“渲染所有层”(Render All Layers)但禁用“渲染所有摄影机”(Render All Cameras)，则系统将渲染每个渲染层的 AOV 并将其保存到磁盘，但仅渲染当前摄影机。

3. （可选）将一个 AOV 保存到“渲染视图”(Render View)中。在“渲染设置”(Render Settings)窗口中，从“AOV > 旧版 > Maya 渲染视图 > 渲染视图 AOV”(AOVs > Legacy > Maya Render View > Render View AOV)下拉列表中选择所需的通道。

4. 单击“渲染序列”(Render Sequence)开始渲染。
