# 使用多个处理器进行渲染

可以在具有多个处理器的计算机上使用部分或所有可用处理器渲染场景。

**注**

在批渲染包含聚光灯、材质透明度和光线跟踪阴影的场景时，我们建议使用单个处理器。

在具有多个处理器的计算机上从 Maya 中进行渲染

1. 从 Maya 窗口中，选择[渲染 > 批渲染(Render > Batch Render)](../../../渲染参考/渲染参考/“渲染”%28Rendering%29菜单集/“渲染”%28Render%29菜单/批渲染选项%28Batch%20Render%20Options%29.md) > ![图：从 Maya 窗口中，选择渲染 批渲染(Render Batch Render) 。 将显示“批渲染帧”(Batch R…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 608 字 ≥300，非承重" -->。

  将显示“批渲染帧”(Batch Render Frame)窗口。

2. 若要使用计算机上的所有可用处理器进行渲染，请启用“使用所有可用处理器”(Use all available processors)。

3. 若要只使用计算机上的某些可用处理器进行渲染，请禁用“使用所有可用处理器”(Use all available processors)并将“要使用的处理器数”(Number of Processors to Use)设定为要使用的处理器数。

4. 单击“批渲染”(Batch Render)。

  此时 Maya 会渲染动画。

在具有多个处理器的计算机上，从 Shell 或命令行进行渲染（仅适用于 Maya 软件渲染）

1. 键入：

  Render -r sw -n <# of processors to render on> <scene>

  （如果不使用 -n 选项，则只有一个处理器用于渲染。）

示例（仅适用于 Maya 软件渲染）：

- 若要使用一个处理器进行渲染，请键入：

  Render <scene>

- 若要使用两个处理器进行渲染，请键入：

  Render -n 2 <scene>

- 若要使用计算机上的所有处理器进行渲染，请键入：

  Render -n 0 <scene>
