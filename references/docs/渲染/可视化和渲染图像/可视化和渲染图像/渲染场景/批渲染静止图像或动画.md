# 批渲染静止图像或动画

可以按**两种**方式进行批渲染：**从 Maya 内部**或**通过命令行渲染器**。请参见[从命令行渲染](../../../渲染实用程序/渲染实用程序/命令行渲染器/从命令行渲染.md)。

从 Maya 内部批渲染

1. 指定要渲染的帧。

  默认情况下，Maya 渲染场景的当前帧。若要渲染动画，必须在[“渲染设置”(Render Settings)窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口/“渲染设置”%28Render%20Settings%29“公用”%28Common%29选项卡.md#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__WS73099CC142F48755-4BC38C931187AA80BC9-339E)的“公用”(Common)选项卡中指定要渲染动画的开始帧和结束帧。

  在“帧/动画扩展名”(Frame/Animation ext)下拉列表中，选择带有 # 的任一选项；例如，name.#.ext。“帧范围”(Frame Range)区域中的“开始帧”(Start frame)和“结束帧”(End frame)属性将变为活动状态，您可在其中设置帧范围。

2. 单击渲染 > 批渲染(Render > Batch Render)进行批渲染。

3. 您还可以执行以下任何操作：

  - 若要取消渲染，请单击“渲染 > 取消批渲染”(Render > Cancel Batch Render)。

  - 若要显示正在渲染的图像，请单击渲染 > 显示批渲染(Render > Show Batch Render)。

    **注**

    - 若要设置批渲染选项，请选择“渲染 > 批渲染”(Render > Batch Render) > ![图：若要设置批渲染选项，请选择“渲染 批渲染”(Render Batch Render) ，打开“批渲染”(Batch Re…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 760 字 ≥300，非承重" -->，打开“批渲染”(Batch Render)窗口。有关批渲染选项的描述，请参见[批渲染选项](../../../渲染参考/渲染参考/“渲染”%28Rendering%29菜单集/“渲染”%28Render%29菜单/批渲染选项%28Batch%20Render%20Options%29.md)。

    - 在远程计算机上使用“Maya 批渲染器”(Maya Batch Renderer)时，计算机之间的用户帐户信息（例如，用户名）必须一致，以确保用户验证可正常运行。

    - 如果渲染呈黑色，但在[渲染当前帧(Render Current Frame)](渲染单帧.md)窗口中起作用，请删除“Hypershade”窗口中的任何未使用节点。请参见 [Hypershade 的“编辑”(Edit)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EF6DFB31-CFCF-428D-8961-3D96CE673F99)中的“删除未使用节点”(Delete Unused Nodes)。

      在 Linux 上，可以选择用于渲染当前场景的远程主机。
