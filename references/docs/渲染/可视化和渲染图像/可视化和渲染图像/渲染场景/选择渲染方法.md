# 选择渲染方法

在渲染场景之前，应该诊断场景是否存在可能会影响图像质量和渲染时间的常见问题。请参见[运行诊断](../../../质量、渲染速度、诊断/质量、渲染速度、诊断/运行诊断.md)。

## 可视化场景

尽管可以渲染场景以查看其外观，但是使用以下方法可视化场景可能会更快：

| 目标 | 操作 |
|---|---|
| 对静止图像或动画的单帧进行更改时，查看这些更改。 | 使用“交互式真实照片级渲染”(Interactive Photorealistic Rendering) (IPR)。IPR 会更新显示，以显示最近的更改，但是对可以看到的内容存在一些限制。有关详细信息，请参见[关于交互式真实照片级渲染 (IPR)](../渲染方法/关于交互式真实照片级渲染%20%28IPR%29.md)。 |
| 在进行渲染时查看静止图像或动画（或它的一个区域）的单帧的外观。 | 使用“渲染视图”(Render View)，特别是“渲染区域”(Render Region)。“渲染视图”(Render View)的限制比 IPR 更少，因此可以看到更多内容，但会花费更长的时间来进行渲染。渲染场景的区域可减少可视化场景所需的时间。有关详细信息，请参见[关于渲染视图渲染](../渲染方法/关于渲染视图渲染.md)。 |
| 查看场景视图中的灯光、对象和纹理，而不进行渲染。 | 使用硬件纹理。这实际上不会执行渲染，而只是可以看到进行渲染时场景的近似外观。有关详细信息，请参见[在场景视图中查看着色和灯光](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DE4AA402-E716-4BDF-ACA8-025A4BCFAF35)。 |
| 快速查看完全渲染的静止图像、动画的单帧或动画的外观。 | 以较低的分辨率渲染。有关详细信息，请参见[测试渲染低分辨率静止图像或帧](测试渲染低分辨率静止图像或帧.md)和[测试渲染低分辨率动画](测试渲染低分辨率动画.md)。 |

## 执行最终渲染

| 渲染... | 操作 |
|---|---|
| 静止图像或动画的单帧。 | 使用“渲染视图”(Render View)。有关详细信息，请参见[渲染单个帧](渲染单帧.md)。 |
| 静止图像、动画的单帧或动画。 | 批渲染。有关详细信息，请参见[批渲染静止图像或动画](批渲染静止图像或动画.md)。 |
| 静止图像、动画的单帧或动画。 | 命令行渲染。有关详细信息，请参见[从命令行渲染](../../../渲染实用程序/渲染实用程序/命令行渲染器/从命令行渲染.md)。 |
