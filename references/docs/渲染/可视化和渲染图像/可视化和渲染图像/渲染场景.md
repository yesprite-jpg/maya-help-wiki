# 渲染场景

精确的工作流步骤以及执行它们的顺序都是变化的。渲染是个反复的过程，在该过程中可以调整灯光、纹理和摄影机；调整各种场景和对象设置；可视化更改；然后，对结果感到满意时，可以渲染最终的图像。

完成对象的着色和纹理以及向场景中添加灯光和可渲染的摄影机后，可以渲染该场景。以下工作流概述了典型的步骤。

1. 确定要使用的渲染器：

  - 有关每个 Maya 渲染器的详细信息，请参见 [Maya 软件渲染器](../../选择渲染器/选择渲染器/Maya%20软件渲染器.md)、[Maya 硬件 2.0 渲染器](../../选择渲染器/选择渲染器/Maya%20硬件%202.0%20渲染器.md)、[Arnold for Maya 渲染器](../../选择渲染器/选择渲染器/Arnold%20for%20Maya%20渲染器.md)和 [Maya 向量渲染器](../../选择渲染器/选择渲染器/Maya%20矢量渲染器.md)。

  - 若要选择渲染器，请参见[选择渲染器](../../选择渲染器/选择渲染器.md)。

2. 在状态行中单击 ![图：在状态行中单击 以打开“渲染设置”(Render Settings)窗口，并调整选定渲染器的场景设置。 在此窗口中，可以…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-C7A0A6B1-AA7A-417A-9F2E-9F9630EF0124.png) <!-- baize:img-hook downloaded=false reason="正文 772 字 ≥300，非承重" --> 以打开[“渲染设置”(Render Settings)窗口](../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)，并调整选定渲染器的场景设置。

  在此窗口中，可以设置渲染图像的[文件名](为渲染调整场景设置/设定文件名语法.md)、[格式](为渲染调整场景设置/设定已渲染图像的文件格式.md)和[分辨率](为渲染调整场景设置/设定分辨率和像素纵横比.md)，还可以调整[渲染输出的质量设置](为渲染调整场景设置/调整抗锯齿.md)。例如，您可能希望使用较低的质量设置进行预览渲染，而对最终渲染图像使用较高的质量设置。

3. 使用渲染设置系统将场景划分为渲染层（可选）。

  请参见 [Maya 渲染设置](../../Maya%20渲染设置/Maya%20渲染设置.md)。

4. 以迭代方式对场景进行测试渲染，以可视化对材质、纹理、灯光、摄影机和对象所做的更改。

  - 要在调整着色器网络时可视化纹理、凹凸贴图和材质，请参见[使用 Hypershade 的外观开发](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-447C9ADA-A285-483E-A93D-6ED1B2792D5F)。

  - 要实时可视化场景的照明、阴影和其他更改，请参见 [Viewport 2.0](../../使用%20Viewport%202.0/使用%20Viewport%202.0.md)。

  - 要在软件渲染时以交互方式可视化场景调整，请参见[与 IPR 可视化交互](渲染场景/与%20IPR%20可视化交互.md)。

5. 如果对结果感到满意，则可渲染最终图像。

  - [渲染单帧](渲染场景/渲染单帧.md)

  - [以交互方式渲染帧序列](渲染场景/以交互方式渲染帧序列.md)。

  - 请参见[从命令行渲染](../../渲染实用程序/渲染实用程序/命令行渲染器/从命令行渲染.md)。

    **注**

    当在 Linux 平台上工作并使用 Maya 软件渲染器进行渲染时，可以选择将（渲染）输出消息发送到文件而不是 shell。使用命令

    maya >& logfile

    ，可创建名为

    logfile

    的文件，并且在 Maya 中进行渲染时所有输出消息都会保存到该文件。
