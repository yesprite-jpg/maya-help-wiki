# 为渲染调整场景设置

在渲染最终图像或图像序列之前，您可能需要设置或调整以下设置：

- 选择[渲染器](../../选择渲染器/选择渲染器.md)。

- 选择渲染输出的[文件名](为渲染调整场景设置/设定文件名语法.md)、[格式](为渲染调整场景设置/设定已渲染图像的文件格式.md)和[分辨率](为渲染调整场景设置/设定分辨率和像素纵横比.md)

- 调整渲染的采样质量。例如，您可能希望使用较低的质量设置进行预览渲染，但对最终渲染图像使用较高的质量设置。请参见[调整抗锯齿](为渲染调整场景设置/调整抗锯齿.md)和 [Arnold for Maya 用户手册：采样](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/Sampling)。

  您还可以将设置作为预设导出，然后导入和重用此预设，以便每次都使用相同的设置进行渲染。请参见[将“渲染设置”(Render Settings)作为预设导出和导入](../../Maya%20渲染设置/Maya%20渲染设置/导出渲染设置/将“渲染设置”%28Render%20Settings%29作为预设导出和导入.md)。

- 如果您的场景分为多个单独的层，则选择要渲染的层。请参见 [Maya 渲染设置](../../Maya%20渲染设置/Maya%20渲染设置.md)。

- 添加效果，例如[运动模糊](为渲染调整场景设置/设定运动模糊.md)。

- 选择要从中渲染的摄影机，并/或[将一个或多个摄影机设置为可渲染](../../摄影机设置/摄影机设置/创建摄影机/使现有的摄影机可渲染.md)。

可以在“渲染设置”(Render Settings)窗口中设置这些选项。请参见[“渲染设置”(Render Settings)窗口](../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)。
