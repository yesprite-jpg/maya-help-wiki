# 为渲染图像启用颜色通道、深度通道和遮罩通道

## Maya 软件渲染器

默认情况下，如果使用 Maya 软件渲染器进行渲染，则会在图像输出中生成颜色通道 (RGB) 和 Alpha（遮罩）通道。您还可以启用该选项以包括深度通道。

### 在渲染图像中启用 Alpha 和/或深度通道

在[“渲染设置”(Render Settings)窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md) >“公用”(Common)选项卡 >“文件输出”(File Output)部分中，从“可渲染摄影机”(Renderable Camera)下拉列表中选择要从中渲染的摄影机，并切换以下选项以包括或排除 Alpha 通道或深度通道：

- Alpha 通道（遮罩）

- 深度通道（Z 深度）

**注**

在凹凸贴图或置换贴图期间，如果某个图像文件包含一个遮罩通道，那么该遮罩通道会用于置换贴图和凹凸贴图。如果缺少遮罩通道，那么 RGB 的亮度会用于置换贴图和/或凹凸贴图。

如果希望使用亮度信息作为 Alpha，请启用“Alpha 为亮度”(Alpha Is Luminance)属性（位于文件纹理的“属性编辑器”(Attribute Editor)的“颜色平衡”(Color Balance)区域中）。

有关遮罩通道的详细信息，请参见[颜色、遮罩 (Alpha) 和深度通道](../渲染输出/颜色、遮罩%20%28Alpha%29%20和深度通道.md)。

## Arnold for Maya 渲染器

默认情况下，如果使用 Arnold for Maya 渲染器进行渲染，则会以 .exr 格式生成包含 Alpha (RGBA) 通道的图像。

有关 Alpha 通道和深度通道的详细信息，请参见 [AOV](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/AOV)、[Z 深度 AOV](https://support.solidangle.com/display/a5AFMUGCHS/Z+Depth+AOV) 和 [Cryptomatte](https://docs.arnoldrenderer.com/display/A5AFMUGCHS/Cryptomatte)。
