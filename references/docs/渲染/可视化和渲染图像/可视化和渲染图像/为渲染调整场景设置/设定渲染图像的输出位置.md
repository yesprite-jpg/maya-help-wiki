# 设定渲染图像的输出位置

若要**查找您的渲染图像的保存位置**，请单击主工具栏上的 ![图：若要查找您的渲染图像的保存位置，请单击主工具栏上的 以打开“渲染设置”(Render Settings)窗口。图像的保存…](../../../../../assets/Maya-Rendering/GUID-C7A0A6B1-AA7A-417A-9F2E-9F9630EF0124.png) <!-- baize:img-hook downloaded=true reason="正文 295 字 <300 且带图" --> 以打开“渲染设置”(Render Settings)窗口。图像的保存路径将显示在**“公用”(Common)选项卡的顶部**。默认情况下，此路径是项目位置中的 images 目录。有关如何设置项目的信息，请参见[在 Maya 中设置项目](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D5CA162A-0956-49C6-9FAC-2F73DCF03409)。

修改渲染图像的保存位置

1. 选择“文件 > 项目窗口”(File > Project Window)，然后在[项目窗口(Project Window)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A570696B-95A4-4ED7-87EE-A7EAB63156CF)中更改“图像”(Images)的目录。

  **注**

  提示：

  使用含

  Render

  和

  -rd

  选项的 Shell 或命令行进行渲染时，也可以设定渲染文件的保存位置。

  有关信息，请参见[关于命令行渲染](../渲染方法/关于命令行渲染.md)。
