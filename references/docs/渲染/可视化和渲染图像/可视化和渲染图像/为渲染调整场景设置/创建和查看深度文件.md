# 创建和查看深度文件

仅适用于 Maya 软件渲染器。

深度通道表示对象与摄影机之间的距离。

创建深度文件的步骤

1. 启用[“渲染设置”(Render Settings)窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)中的“深度通道(Z 深度)”(Depth Channel (Z Depth))。

2. 打开可渲染摄影机的“属性编辑器”(Attribute Editor)（要在其中创建深度文件）。

  从当前视图中选择“视图 > 摄影机属性编辑器...”(View > Camera Attribute Editor...)。请参见[摄影机属性编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15)。

3. 在摄影机的“属性编辑器”(Attribute Editor)的“输出设置”(Output Settings)部分（“最近”(Closest)可见深度”或“最远可见深度”(Furthest Visible Depth)）中，选择“深度类型”(Depth Type)。

查看深度通道的步骤

1. 使用 [FCheck](../../../渲染实用程序/渲染实用程序/使用%20FCheck.md) 查看动画文件。

  **注**

  自 Maya 2020 起，FCheck 在 macOS 上不再受支持。

2. 按 **z** 即可看见深度通道。

如果使用的是 **Arnold for Maya**，请参见 [Z 深度 AOV](https://support.solidangle.com/display/a5AFMUGCHS/Z+Depth+AOV)。
