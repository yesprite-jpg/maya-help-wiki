# 设定分辨率和像素纵横比

可以从预设的渲染分辨率列表中选择，也可以手动设置分辨率选项。

设置渲染图像的分辨率和像素纵横比

1. 在[“渲染设置”(Render Settings)窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)的“公用”(Common)选项卡的“图像大小”(Image Size)部分中，从“预设”(Presets)下拉列表中选择预设的渲染分辨率（例如，640 x 480）。

  如果您未看到合适的预设，请手动设置以下属性以输出到未列出的设备：

  - 宽度(Width)、高度(Height)

  - 像素纵横比(Pixel Aspect Ratio)

有关分辨率的详细信息，请参见[分辨率](../渲染输出/分辨率%28Resolution%29.md)。

有关像素纵横比的详细信息，请参见[像素纵横比](../渲染输出/像素纵横比%28Pixel%20aspect%20ratio%29.md)。
