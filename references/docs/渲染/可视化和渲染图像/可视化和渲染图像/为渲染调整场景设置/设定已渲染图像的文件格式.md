# 设定已渲染图像的文件格式

Maya 可以将已渲染图像文件保存为多种标准图像文件格式中的任一种。如果使用的是任何 Maya 渲染器（例如 Maya 软件或 Maya 硬件 2.0），则默认情况下 Maya 会以 Maya 图像文件格式 (.iff) 保存渲染的图像文件。如果使用的是 Arnold for Maya 渲染器，则默认情况下会以 .exr 格式保存渲染的图像文件。

有关受支持的文件格式的完整列表，请参见[文件格式](../渲染输出/文件格式.md)。

设定已渲染图像的文件格式

1. 在[“渲染设置”(Render Settings)窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)的“公用”(Common)选项卡的“文件输出”(File Output)部分中，从下拉列表中选择“图像格式”(Image Format)。

**注**

对于不能包含遮罩或深度通道的图像格式，Maya 会生成单独的遮罩或深度文件。
