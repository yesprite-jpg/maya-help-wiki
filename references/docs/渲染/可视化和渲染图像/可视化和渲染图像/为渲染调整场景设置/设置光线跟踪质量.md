# 设置光线跟踪质量

光线跟踪是一种渲染类型，系统会计算摄影机与光源之间的各条光线的路径。要了解有关如何进行光线跟踪以生成阴影的详细信息，请参见[光线跟踪阴影](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BC9C9AFE-D90E-4B54-8A2E-22ED1C89A06C#WS17956D7ADBC6E73650E6F747117AE324699-7FEF)。 要了解有关如何进行光线跟踪以生成反射的详细信息，请参见[真实反射](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-858263F7-CF7F-4400-90EB-760BB9790A0E)。

Maya 软件渲染器支持光线跟踪。Maya 硬件 2.0 渲染器不支持它。

1. 在“渲染设置”(Render Settings)窗口 >“Maya 软件”(Maya Software)选项卡 >“光线跟踪质量”(Raytracing Quality)部分中，启用“光线跟踪”(Raytracing)。

2. 调整“反射”(Reflections)、“折射”(Refractions)和“阴影”(Shadow)的采样数，以设置光线跟踪质量。请参见[“渲染设置”(Render Settings)：“Maya 软件”(Maya Software)选项卡](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口/“渲染设置”%28Render%20Settings%29“Maya%20软件”%28Maya%20Software%29选项卡.md#GUID-09B4478C-214D-49C5-BEDC-BB6D196DC623__WS17956D7ADBC6E736-7EB1F595117AE33AD8D-7FD4)。
