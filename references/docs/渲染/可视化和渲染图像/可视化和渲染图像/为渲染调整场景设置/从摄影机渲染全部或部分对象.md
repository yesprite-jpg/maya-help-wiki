# 从摄影机渲染全部或部分对象

默认情况下，场景仅包含一个可渲染的摄影机（原始透视摄影机），该摄影机会渲染场景中的所有对象。可以更改该设置以仅渲染场景中的选定对象。

如果将另一个摄影机添加到场景中，并希望使其成为可渲染的（或者希望使其中一个默认正交摄影机成为可渲染的），那么必须将该摄影机设定为可渲染的（请参见[使现有的摄影机可渲染](../../../摄影机设置/摄影机设置/创建摄影机/使现有的摄影机可渲染.md)）。

仅渲染场景中的选定对象

1. 选择要渲染的对象。

2. 在[“渲染设置”窗口](../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)的“文件输出”(File Output)区域中，从“可渲染摄影机”(Renderable Camera)下拉列表中选择摄影机。

3. 在“渲染视图”(Render View)窗口中，选择“渲染 > 仅渲染选定对象”(Render>Render Selected Objects Only)。

4. 渲染场景。
