# 分辨率(Resolution)

图像分辨率是位图图像的全部像素大小。例如，NTSC 视频输出的分辨率是 720 x 486。显示分辨率是屏幕 1 英寸面积上的像素数量。显示分辨率以每英寸像素数 (ppi) 表示。大多数显示器的显示分辨率为约 72 ppi。如果输出用于打印，请考虑 300 ppi 左右的显示分辨率。

若要设定像素纵横比，请参见[设定分辨率和像素纵横比](../为渲染调整场景设置/设定分辨率和像素纵横比.md)。

**注**

每英寸像素数 (ppi) 和每英寸点数 (DPI) 这两个术语通常可自由互换。然而，每英寸像素数仅适用于屏幕分辨率，它以像素显示图像。每英寸点数仅适用基于纸张的图像，它使用颜色点来打印。
