# 渲染文件输出位置

默认情况下，Maya 会将渲染图像保存到当前项目的 *images* 目录中。但是，可以更改该位置以保存到任何目录中。

若要设定文件输出位置，请参见[设定渲染图像的输出位置](../为渲染调整场景设置/设定渲染图像的输出位置.md)。

**注**

如果要渲染具有遮罩通道或深度通道的图像，而渲染图像的文件格式不支持遮罩通道或深度通道，那么 Maya 可能会将遮罩通道作为单独的文件保存在当前项目的

mask

目录中，并将深度通道作为单独的文件保存在当前项目的

depth

目录中。

IFF 和 RLA 文件格式都可以保存遮罩通道和深度通道的信息。有关按各种文件格式处理遮罩通道和深度通道的详细信息，请参见[支持的文件格式](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3FDB6F01-1830-4AB3-BB91-287A64A269A6)。
