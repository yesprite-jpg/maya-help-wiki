# 通过重新应用规则自动更改现有的输入颜色空间

可以重新应用“输入颜色空间规则”(Input Color Space Rules)，以重置场景中的现有“文件”(File)纹理和其他图像输入使用的“颜色空间”(Color Space)。如果已更改规则，或者如果要将颜色管理应用于以前未使用它的现有场景，则这可能很有用。

1. 如果具有您不希望规则更改其颜色空间的任何图像节点，请确保在其属性中已激活“忽略颜色空间输入规则”(Ignore Color Space Input Rules)。

2. 在[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)中，请确保根据需要设置“输入颜色空间规则”(Input Color Space Rules)。请参见[定义规则以为输入文件指定颜色空间](配置颜色管理/定义规则以便将颜色空间指定给输入文件.md)。

3. 单击“将规则重新应用至场景”(Reapply Rules to Scene)。
