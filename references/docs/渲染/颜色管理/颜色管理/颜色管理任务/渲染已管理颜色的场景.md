# 渲染已管理颜色的场景

渲染场景时，可以选择指定输出颜色变换。输出变换旨在将颜色值从渲染空间转化到更适合显示的颜色空间。

您可以激活“将输出变换应用于渲染器”(Apply Output Transform to Renderer)，然后在[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)中指定要应用的特定“输出变换”(Output Transform)。可以将“输出变换”(Output Transform)设置为“使用视图变换”(Use View Transform)，以使用与首选项中配置的视图和显示空间相同的视图和显示空间。

**注**

渲染器可能不支持

“将输出变换应用于渲染器”(Apply Output Transform to Renderer)

选项。

一般而言：

- 如果您正在渲染将使用设备显示的预览图像或查看未将恰当的视图变换应用于场景线性图像的软件时，可应用输出变换。例如，如果正在渲染动画书以预览请求批准的动画或照明，请启用该选项。

- 如果您正在渲染用于合成或需要场景线性颜色值的其他任务的最终图像，请不要应用输出变换。例如，如果正在渲染将与活动操作板集成的 3D 元素，请确保该选项处于禁用状态。如果要渲染到高动态范围图像格式（如 EXR），则也应该将此选项保持禁用状态，因为许多其他图像处理应用程序假定这些文件是线性的并在默认情况下应用视图变换。

当“应用输出变换”(Apply Output Transform)处于启用状态时，应禁用“渲染视图”(Render View)中的视图变换。否则，输出变换将烘焙到渲染的颜色值中，然后会在其基础上应用视图和显示，这将导致双重变换。

提示：

如果只想从具有烘焙的视图变换的

“渲染视图”(Render View)

保存帧，请确保已在

“文件 > 保存图像”(File > Save Image)

选项中选择

“保存已管理颜色的图像”(Save Color-Managed Image)
