# 对当前场景启用或禁用颜色管理

可以为每个场景启用或禁用颜色管理。

1. 打开[“首选项”(Preferences)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A62CF59A-3600-4709-A3B7-0F2DB83EC829)。

2. 在左侧选择[“颜色管理”(Color Management)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)类别。

3. 切换“启用颜色管理”(Enable Color Management)。

颜色管理设置存储在场景中。但是如果要使用 [OCIO 配置文件](../../使用%20Maya%20的旧版颜色管理%20%28SynColor%29/在%20SynColor%20模式下使用%20OCIO%20配置文件.md)或[颜色管理策略](使用颜色管理策略（外部首选项文件）.md)，在重新打开场景时，这些设置可能会被覆盖。

请注意，激活颜色管理将自动为 Viewport 2.0 启用“浮点渲染目标”(Floating Point Render Target)，并将“格式”(Format)设置为 R32G32B32A32_FLOAT。如果遇到较旧图形卡的性能问题，则可以更改这些设置，但是之后可能会在视口中看到颜色剪裁、条带和其他瑕疵。此外，使用“滴管”(Eyedropper)工具拾取视口中的颜色可能会导致颜色值不正确。

如果要启用颜色管理，可能需要进行某些其他设置：

- 若要选择渲染空间，请参见[此处](选择渲染空间.md)。

- 若要选择默认视图变换，请参见[此处](选择用于预览的视图.md)。

- 若要定义将颜色空间指定给纹理和其他输入图像的规则，请参见[此处](定义规则以便将颜色空间指定给输入文件.md)。

- 如果要为已经有材质、灯光和其他颜色元素的现有场景启用颜色管理，请参见[此处](../将颜色管理应用于现有场景.md)。

- 有关可能需要进行的某些其他显示和渲染设置的信息，请参见[此处](重要的颜色管理设置.md)。
