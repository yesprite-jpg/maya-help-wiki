# 重要的颜色管理设置

使用颜色管理时，应该进行某些显示和渲染设置：

- 为了在视口中获得最佳效果，请确保已启用“浮点渲染目标”(Floating Point Render Target)，且“格式”(Format)设置为 R32G32B32A32_FLOAT - [Viewport 2.0 选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BBB6035-2A02-41BB-AF2D-99D9BEE580F1)中有这些设置，并且[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)中也有这些设置。使用颜色管理时，这些值通常是默认值。但是，如果在使用较旧显卡时遇到性能问题，则可以更改这些设置，但是之后在使用颜色管理时，可能会在视口中看到颜色剪裁、条带和其他瑕疵。此外，使用“滴管”(Eyedropper)工具拾取视口中的颜色可能会导致颜色值不正确。

  在[渲染设置(Render Settings)窗口](../../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)中，确保将“使用以下渲染器渲染”(Render Using)设置为“Maya 硬件 2.0”(Maya Hardware 2.0)或其他支持 Maya 颜色管理的渲染器（例如，Arnold）。有关详细信息，请查阅渲染器对应的文档。

  Maya 软件渲染器不支持颜色管理。

- 如果要渲染图像以进行进一步处理，如合成和分级，请确保[渲染设置(Render Settings)窗口](../../../../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口.md)的“公用”(Common)选项卡上的“文件输出”(File Output) “图像格式”(Image format)已设置为支持高动态范围值的格式（如 OpenEXR）。

- 根据您的渲染器，可能还需要设置其他选项，才能确保渲染器与 Maya 颜色管理兼容。
