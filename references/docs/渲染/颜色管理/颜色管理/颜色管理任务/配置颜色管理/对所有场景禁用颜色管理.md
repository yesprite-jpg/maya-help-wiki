# 对所有场景禁用颜色管理

如果您从不使用颜色管理，则可使用外部颜色管理首选项文件对所有场景将其禁用。

**注**

警告：

使用此方法将更改在您打开和重新保存的每个场景中存储的颜色管理设置。

1. 打开[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)。

2. 禁用“启用颜色管理”(Enable Color Management)。

3. 单击“导出 CM 首选项”(Export CM Pref)，然后指定目录和文件名。

**注**

重要：

不要覆盖 Maya prefs/ 文件夹中的 synColorConfig.xml。

**注**

若要对多台计算机使用同一文件，请将 MAYA_COLOR_MANAGEMENT_POLICY_FILE 环境变量设置为该文件的网络路径和名称。

有关常规使用外部颜色管理首选项的详细信息，请参见[使用颜色管理策略（外部首选项文件）](使用颜色管理策略（外部首选项文件）.md)。
