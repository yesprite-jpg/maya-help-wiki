# 配置颜色管理

始终建议在首次启动新项目或场景时配置颜色管理。这是因为颜色管理会影响颜色控件和灯光的工作方式，因此，如果您在应用材质和创建灯光后更改设置，则后面将需要进行大量调整。

您可以通过以下几种方法配置颜色管理：

- 您可以单独设置首选项，例如，渲染空间、视图、显示以及其他选项。该操作可以通过下列方式完成：

  - 手动，即：使用[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)。

  - 使用 MEL 或 Python 命令。 在技术文档中搜索“colorManagementPrefs”。

  颜色管理首选项将用于新场景，但要在[新建场景选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8F961875-1D41-4C52-9CD5-B90DE75C546C)中设置颜色管理是否默认为启用。大部分设置都将保存在场景文件中，但是如果要使用颜色管理策略或已设置 OCIO 环境变量，则在打开场景时这些设置可能会被覆盖。

- 在首选项中，可以指定要使用的 OCIO 配置文件。这将确定可用的空间以及其他设置。配置文件的路径将保存在场景文件中，但与其他设置一样，如果要使用策略或已设置 OCIO 环境变量，则在打开场景时该路径将被覆盖。

- OCIO 环境变量将覆盖存储在场景中的配置文件路径和名称，并允许在整个工具中或者逐项目或逐场景强制实施配置。但是，OCIO 环境变量也会被策略覆盖。

- 配置颜色管理设置后，可以保存和加载策略（颜色管理首选项文件）。启动新场景或打开保存的场景时，这些文件或策略可用于强制实施特定的颜色管理设置。若要逐项目或逐快照指定策略，可以使用 MAYA_COLOR_MANAGEMENT_POLICY_FILE 环境变量。
