# 将颜色管理应用于现有场景

尽管始终最好在首次启动新项目或场景时配置颜色管理，但是您可能会发现有必要将颜色管理应用于尚未使用它的现有场景。

1. 打开未使用颜色管理的现有场景。

2. 启用和配置颜色管理，如[配置颜色管理](配置颜色管理.md)中所述。

3. 如果在面板工具栏中未看到颜色管理控件，请确保“渲染器”(Renderer)已设置为 Viewport 2.0。

4. 如果图像输入的“颜色空间”(Color Space)不正确，则可以手动更改它们，如[为纹理和其他图像输入指定颜色空间](为纹理和其他图像输入指定颜色空间.md)中所述。这适用于“文件”(File)纹理和图像平面。

  如果有许多要更改的节点，则定义和重新应用颜色空间输入规则可能更快。请参见[通过重新应用规则自动更改现有的输入颜色空间](通过重新应用规则自动更改现有的输入颜色空间.md)。

5. 由场景中材质和灯光使用的任何颜色和颜色渐变都被解释为在渲染颜色空间中。可能需要修改它们，如[检查或拾取已管理颜色的颜色值](指定或检查已管理颜色的颜色值.md)中所述。
