# 手动配置自定义颜色变换链的准则

尽管 Autodesk 颜色管理提供了适当的工具可自动应用所需的变换以便在颜色空间之间进行转化，但在某些特殊情况下，您必须更好地控制要应用的特定变换。本部分介绍如何将位于 Autodesk 颜色变换集合中的组件用作构建块以集合特定任务的自定义转化。

在创意后期制作产品中，您可以选择使用“自定义”(Custom)模式指定从该集合到其他源的变换，或者创建多个此类变换的链。对于其他应用程序，您可能需要使用文本或 XML 编辑器创建和编辑 .ctf 文件。在任一情况下，请参见[自定义颜色变换](手动配置自定义颜色变换链的准则/自定义颜色变换.md)以了解详细信息。

具体应用什么样的变换视情况而定。可以将这些情况划分为不同的类别，并对每种类别进行类似的处理。
