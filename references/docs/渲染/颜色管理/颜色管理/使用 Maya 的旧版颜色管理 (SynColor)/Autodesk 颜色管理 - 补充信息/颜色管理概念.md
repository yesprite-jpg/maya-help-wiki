# 颜色管理概念

颜色管理可以使颜色在不同的设备和媒体中尽可能精确地重现。与颜色校正不同，颜色管理的目的不是更改颜色，而是在不同的情况下保留感知颜色。

**本节内容**

- **[什么是颜色空间？](颜色管理概念/什么是颜色空间？.md)** 颜色空间允许用户和软件使用数字表示来明确表达颜色。

- **[颜色管理工作流](颜色管理概念/颜色管理工作流.md)** 颜色管理包含在颜色空间之间转化颜色值。此转化发生在颜色流水线的特定点。

- **[使用连接空间在颜色空间之间转化](颜色管理概念/使用连接空间在颜色空间之间转化.md)** 通常需要沿着图像流水线在颜色空间之间进行多次转化。例如，可能需要将来自不同空间的几个输入转化为通用工作空间，以便可以合成和融合它们，然后将它们转化为另一个空间用于输出。 Autodesk 颜色管理使用连接空间执行这些转化。

- **[ACES](颜色管理概念/ACES.md)** 学院色彩编码系统 (ACES) 是由电影艺术与科学学院的科学和技术委员会开发的图像交换框架。

- **[选择工作颜色空间](颜色管理概念/选择工作颜色空间.md)** Autodesk 颜色管理允许您将任何颜色空间用作工作空间，并支持许多常用和标准颜色空间。在导入时，图像会自动从其输入颜色空间转化为工作空间。此外，某些应用程序允许您在颜色空间之间进行切换以执行特定操作。
