# 颜色变换文件

Autodesk 颜色管理随附的颜色变换以 CTF 格式的独立文件提供。此外，Autodesk 颜色管理还可以导入许多第三方 LUT 和变换格式。

**本节内容**

- **[Autodesk 颜色变换集合](颜色变换文件/Autodesk%20颜色变换集合.md)** Autodesk 颜色管理集合中的变换是基于 Academy/ASC XML 颜色变换格式的 CTF 文件。其中包括多个用于不同目的的类别。

- **[支持的颜色变换文件格式](颜色变换文件/支持的颜色变换文件格式.md)** 除了本地 CTF 格式外，使用 Autodesk 颜色管理的应用程序还可以读取若干 LUT 和变换文件格式。导入后，这些格式将转化为本地运算符。支持导出变换的 Autodesk 产品会将其导出为 CTF 文件。
