# 颜色管理入门

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-4AB6AA8F-094A-422B-981B-D2867DCC6E66.png) <!-- baize:img-hook downloaded=false reason="正文 1284 字 ≥300，非承重" -->

颜色管理为您提供了场景线性工作流的优势，同时仍可在视口和“渲染视图”(Render View)中显示适用于您的显示的预览。 默认颜色管理系统为 OpenColorIO v2 (OCIO v2)。

**注**

有关 OCIO 的背景信息，请访问 [opencolorio.org](https://opencolorio.org/)。

## 设置颜色管理

  打开[颜色管理首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2D9BBB9D-49F0-44C6-8BFF-B237FD8ED746)并确保颜色管理处于启用状态。

  通常，默认情况下对新场景启用颜色管理，但是可以在[新建场景选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8F961875-1D41-4C52-9CD5-B90DE75C546C)中更改此行为。

2. 如果项目使用特定的 OCIO 配置，请将“OCIO 配置路径”(OCIO Config Path)设置为磁盘上的完整路径和文件名。

  **注**

  如果在启动

  Maya

  时遇到与颜色管理相关的延迟，请确保 OCIO 配置文件包含

  environment

  部分。该部分是否为空无关紧要，例如：

  ```text
environment:
  {}
```

  如果在启动 Maya 之前已将 OCIO 环境变量设置为配置文件的名称和路径，则“OCIO 配置路径”(OCIO Config Path)为只读。

3. 将“渲染空间”(Rendering Space)设置为用于渲染的工作颜色空间。请参见[选择渲染空间](颜色管理任务/配置颜色管理/选择渲染空间.md)。

4. 确保“显示”(Display)适合您的显示设备。

5. 将“视图”(View)设置为最适合您的项目的预览。请参见[选择用于预览的视图](颜色管理任务/配置颜色管理/选择用于预览的视图.md)。

6. 在“输入颜色空间规则”(Input Color Space Rules)中，（可选）设置用于为纹理指定颜色空间的规则。至少应设置“默认”(Default)规则，以指定大多数图像输入使用的颜色空间。可以基于文件命名约定添加其他规则。请参见[定义规则以为输入文件指定颜色空间](颜色管理任务/配置颜色管理/定义规则以便将颜色空间指定给输入文件.md)。

  默认情况下，会将由规则确定的颜色空间用作新的 2D 文件纹理和其他图像输入的初始设置。您仍可以按[为纹理和其他图像输入指定颜色空间](颜色管理任务/为纹理和其他图像输入指定颜色空间.md)中所述单独更改每个设置。

7. 如果要将颜色管理应用于已经有材质、纹理和灯光的现有场景，请参见[将颜色管理应用于现有场景](颜色管理任务/将颜色管理应用于现有场景.md)。

8. 有关您可能需要进行的某些查看和渲染设置，请参见[重要的颜色管理设置](颜色管理任务/配置颜色管理/重要的颜色管理设置.md)。

**注**

在使用 Turtle 插件烘焙纹理颜色时，不应当启用颜色管理。如果执行此操作，则视口预览将不准确。

## 添加已管理颜色的图像输入

将 2D 文件纹理和其他图像输入添加到场景中时，需要指定其输入“颜色空间”(Color Space)（如果与规则指定的不同）。有关详细信息，请参见[为纹理和其他图像输入指定颜色空间](颜色管理任务/为纹理和其他图像输入指定颜色空间.md)。

## 预览场景

当您工作时，视图变换和显示变换将在视口和“渲染视图”(Render View)中提供最终颜色预览。但是，您可以暂时关闭视图变换和显示变换，或者选择其他视图用于诊断或其他用途。请参见[预览已管理颜色的场景](颜色管理任务/预览已管理颜色的场景.md)。

对于播放预览，“将输出变换应用于播放预览”(Apply Output Transform to Playblast)选项应用选定变换以便从渲染空间转化。通常应该启用此选项，以允许使用未对场景线性图像应用相应视图变换的设备或查看软件来播放结果。

## 渲染场景

渲染场景时，可以选择在输出变换中烘焙，具体取决于要渲染一个预览还是渲染图像以供合成等进一步处理。请参见[渲染已管理颜色的场景](颜色管理任务/渲染已管理颜色的场景.md)。

## 旧版颜色管理功能

出于兼容考虑，defaultViewColorManager 节点在场景中仍然可用。但是，不使用其选项。
