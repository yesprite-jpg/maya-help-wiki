# 使用 Render 命令行实用程序进行网络渲染

## 以交互方式渲染帧序列

渲染动画时，可以渲染帧序列而无需进行批渲染。为方便起见，您也可以将这些图像添加到“渲染视图”(Render View)中进行预览。请参见[以交互方式渲染帧序列](../../可视化和渲染图像/可视化和渲染图像/渲染场景/以交互方式渲染帧序列.md)。

## 批渲染

若要通过命令行执行命令行渲染和网络渲染，请使用首选第三方渲染器或从 [Solid Angle](https://www.autodesk.com.cn/products/arnold/subscribe) 网站购买 Arnold 批渲染节点。

如果使用 Arnold for Maya 执行命令行渲染，则渲染图像在显示时将带有水印。

## 管理网络渲染

可以使用 Backburner 或其他第三方渲染器自动执行该过程。有关网络渲染过程中如何使用 Backburner 管理渲染作业和渲染节点的信息，请参见[使用 Backburner 进行网络渲染](使用%20Backburner%20进行网络渲染.md)。

**注**

在开始之前，您必须具有联网的工作站。如果工作站未联网，请与系统管理员联系。

1. 在每台计算机上安装 Maya。

  我们建议您将安装降低到最低要求。例如，安装时不一定要在每台计算机上加载所有选件（例如，文档）。

2. 在每个渲染工作站上启动 Render 命令。

  这可以通过命令行“Render”命令手动实现。若要自动实现，请使用简单的脚本功能。有关更多选项，请参见命令行“Render”帮助 (render -h)。
