# 管理 Maya 网络渲染

可以以两种方式来管理 Maya 网络渲染：

- 手动。请参见[使用渲染命令行实用程序进行网络渲染](使用%20Render%20命令行实用程序进行网络渲染.md)。

- 自动，由 Backburner 或其他第三方解决方案提供。有关详细信息，请参见[使用 Backburner 进行网络渲染](使用%20Backburner%20进行网络渲染.md)。

## 计算机准备

Maya 网络渲染需要经适当配置的计算机网格。

**注**

提示：

Maya 网络渲染可能会同时通过网络读取和写入许多文件。确保网络带宽可以处理该流量。考虑在每个局部渲染节点上渲染文件，然后传输到最终目标。

### 文件访问

使用的所有文件、场景和纹理必须存储每个渲染工作站可以访问的位置。您可以执行下列操作之一来达到这一点：

- 从中心渲染服务器提供文件给所有渲染工作站。必须为您的环境调整文件权限。

- 传输文件给每个渲染工作站的本地存储。

### 插件

确保用于渲染场景的所有渲染工作站已安装这些插件，同时每个渲染工作站都有这些插件的有效许可证。如果渲染工作站不拥有正使用插件的许可证，您可能会发现它处理的每帧都失败。

**注**

提示：

缓存场景中的数据，以防止帧、计算机、效果等之间的不必要差异。

**注**

这里有许多第三方解决方案可提供网络渲染解决方案。请查看 Conductor Partner 以了解可用解决方案。
