# 摄影机设置

在 Maya 中查看场景时，您是通过摄影机查看的。将其视为一个处于电影布景中的导演，正在通过摄影机镜头进行观察。视野受限于可从镜头中查看的范围。

默认情况下，Maya 有四个摄影机，可供您在面板中查看场景：透视摄影机和三个与默认场景视图相关的正交摄影机（侧、顶、前）。在为对象进行建模、设置动画、着色和应用纹理时，可通过这些摄影机（面板）进行观察。若要在这些摄影机之间进行切换，请打开“面板”(Panels)菜单，并从“透视”(Perspective)或“正交”(Orthographic)子菜单中选择一个摄影机。

## 创建和调整摄影机

选择“创建 > 摄影机 > 摄影机”(Create > Cameras > Camera)以创建基本摄影机。您可能希望为更复杂的动画创建其他类型的摄影机，或者为三维渲染创建立体摄影机。有关详细信息，请参见 [Maya 摄影机类型](摄影机设置/Maya%20摄影机类型.md)。

创建摄影机后，可以执行以下操作：

- 使用各种工具（如翻滚、推拉和二维平移/缩放）导航摄影机（请参见[摄影机工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-DDE25A30-0D59-4F92-8150-98DD12EF39DE)）。有关视频演示，请参见[导航摄影机](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3DAAB0F6-A4E8-4C1A-B4E5-E9912EE09558)。

- [使用摄影机框显场景](摄影机设置/使用摄影机框显场景.md)。

- 通过[摄影机属性编辑器(Camera Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15)调整摄影机及其属性。按照[这些基本提示操作以确保逼真的摄影机](摄影机设置/创建摄影机/调整摄影机及其属性.md)。

  **注**

  也可以在创建摄影机时设置摄影机属性（请参见

  创建摄影机选项

  ）。

- 如果有多个摄影机，请选择您要沿其查看场景的摄影机。请参见[沿摄影机观看](摄影机设置/创建摄影机/沿摄影机观看.md)。

- 显示用于表示渲染边界、摄影机光圈等的视图导向或边界。请参见[显示胶片门、分辨率门和其他视图导向](摄影机设置/使用摄影机框显场景/显示胶片门、分辨率门和其他视图导向.md)。

- 启用和调整景深，以便场景中的一些对象锐聚焦，而其他对象模糊或超出焦点，具体取决于它们与摄影机的距离。请参见[调整景深](摄影机设置/创建摄影机/调整景深.md)和[摄影机属性编辑器(Camera Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15#GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15__WS17956D7ADBC6E73642AE5CD3117AE33B5CB-7FA3)中的景深(Depth of Field)。

## 查看摄影机与渲染摄影机

默认情况下，场景中仅包含一个能够渲染场景中所有对象的可渲染摄影机（原始透视摄影机）。

如果场景中有多个摄影机，则可以通过将其他摄影机添加到[“渲染设置”(Render Settings)窗口](../渲染参考/渲染参考/渲染窗口和编辑器/“渲染设置”%28Render%20Settings%29窗口/“渲染设置”%28Render%20Settings%29“公用”%28Common%29选项卡.md#GUID-546B9BE6-612D-4D21-948E-5DF542CAE64B__WS73099CC142F48755-4BC38C931187AA80BC9-339D)的“可渲染摄影机”(Renderable Cameras)部分，使这些摄影机可渲染。请参见[使现有的摄影机可渲染](摄影机设置/创建摄影机/使现有的摄影机可渲染.md)。
