# 显示胶片门、分辨率门和其他视图导向

可以启用或禁用视图参考线，以便正确地确定特定类型信息的安全边界：电视广播的安全动作和文本，或者渲染边界。

显示视图导向以正确地确定特定类型信息的安全边界：电视广播的安全动作和文本、摄影机光圈或渲染边界。

选择[“视图 > 摄影机设置”(View > Camera Settings)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/files/GUID-C092B9DA-C523-4566-9209-ACCBFAEE8285.htm)，并启用要显示的导向。也可以通过[摄影机属性编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15#GUID-C3EBB008-7DBE-4B9D-B9AC-1DA974CEFE15__WS17956D7ADBC6E73642AE5CD3117AE33B5CB-7F9A)（“视图 > 摄影机属性编辑器 > 显示选项”(View > Camera Attribute Editor > Display Options)）执行此操作。

可同时显示多个导向。以下介绍一些可用导向。

## 分辨率门

“分辨率门”(Resolution Gate)的尺度表示渲染分辨率（要渲染的区域）。渲染分辨率值在视图中显示在“分辨率门”(Resolution Gate)上方。可以在“渲染设置”(Render Settings)窗口的“图像大小”(Image Size)区域中更改这些尺度。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-46BE6907-0049-4DE2-8AD0-AF96D82974D3.png) <!-- baize:img-hook downloaded=false reason="正文 1059 字 ≥300，非承重" -->

启用该选项时，将为“渲染设置”(Render Settings)窗口中指定的当前分辨率显示可渲染区域。通常指定比“胶片门”(Film Gate)选项更为精确的渲染图像。另外，将摄影机“过扫描”(Overscan)属性设定为 2.0，以便可以查看指定分辨率以外的更多区域。

有关详细信息，请参见[“摄影机设置”(Camera settings)选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/files/GUID-C092B9DA-C523-4566-9209-ACCBFAEE8285.htm)。

## 胶片门

显示一个边界，用于指示摄影机视图的区域（真实世界的摄影机在胶片上进行记录）。胶片门的维度表示摄影机光圈的尺度。

胶片门并不表示渲染区域。使用摄影机“属性编辑器”(Attribute Editor)中的“摄影机光圈”(Camera Aperture)和“胶片适配”(Film Fit)属性，可以自定义该区域。也可以使用“渲染设置”(Render Settings)窗口中的“图像大小”(Image Size)选项来设定渲染分辨率，然后选择锁定“设备纵横比”(Device aspect ratio)，或设定“设备纵横比”(Device aspect ratio)属性。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-4BECE641-E4CB-42FC-99F8-B2AC185EDD27.png) <!-- baize:img-hook downloaded=false reason="正文 1059 字 ≥300，非承重" -->

有关详细信息，请参见[“摄影机设置”(Camera settings)选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/files/GUID-C092B9DA-C523-4566-9209-ACCBFAEE8285.htm)。

## 安全动作

如果计划在电视屏幕上显示渲染的图像，请启用该选项来显示一个框，以定义您应在其中保留所有场景动作的区域。

若要了解有关安全动作和安全标题边界的详细信息，请参见[显示电视制作的安全显示区域](显示电视制作的安全显示区域.md)。

## 安全标题

如果计划在电视屏幕上显示渲染的图像，请启用该选项来显示一个框，以定义您应在其中保留所有场景文本（标题）的区域。

若要了解有关安全动作和安全标题边界的详细信息，请参见[显示电视制作的安全显示区域](显示电视制作的安全显示区域.md)。
