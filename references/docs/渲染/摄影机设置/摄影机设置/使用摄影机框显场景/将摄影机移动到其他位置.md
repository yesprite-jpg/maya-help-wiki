# 将摄影机移动到其他位置

可以在视图中将摄影机作为一个对象显示，并使用标准操纵器对其进行移动。这就像正手持一个摄影机，通过该摄影机您不需要从一个位置移至另一个位置进行观察（例如，从手包移至桌子）；您的手就是操纵器。例如，如果要查看摄影机的路径或者调整视锥或剪裁平面，通过这种方式移动摄影机非常有用。

若要在通过摄影机观察的同时移动摄影机，请参见[设置摄影机的目标](设置摄影机的目标.md)。

移动摄影机

1. 选择摄影机，然后使用“移动工具”(Move tool)。

  请参见[移动工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)。
