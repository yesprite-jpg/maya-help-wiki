# 沿摄影机观看

如果有多个摄影机，则可以切换查看场景所用的摄影机。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-7EA84B14-9ABD-4938-A6DD-9BBD2679080D.gif) <!-- baize:img-hook downloaded=false reason="正文 352 字 ≥300，非承重" -->

沿摄影机观看

1. 执行下列操作之一：

  - 若要沿选定摄影机观看，请打开[面板(Panels)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)菜单，然后选择“沿选定对象观看”(Look Through Selected)（这也适用于对象）。

  - 若要沿另一个摄影机观看，请单击[面板(Panels)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)，然后从“透视”(Perspective)或“正交”(Orthographic)子菜单中选择摄影机名称。

**注**

提示：

摄影机视图位于场景视图顶部的[面板(Panels)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)菜单中。如果“面板”(Panels)菜单不可见，请按 **Shift**+**M** 以显示或隐藏“面板”(Panels)菜单。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-7F253B01-B7C5-4BD0-A0B7-431B51B0690E.gif) <!-- baize:img-hook downloaded=false reason="正文 352 字 ≥300，非承重" -->

**注**

与摄影机类似，沿对象观看时，对象在场景中的位置将会受到推拉、翻滚或缩放的影响。
