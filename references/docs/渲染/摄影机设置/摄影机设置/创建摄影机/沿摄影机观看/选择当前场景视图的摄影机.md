# 选择当前场景视图的摄影机

选择框显当前场景视图的摄影机，以显示摄影机的“属性编辑器”(Attribute Editor)（已隐藏除外）或沿摄影机观看时对准摄影机。

有关场景视图（实际为摄影机）的详细信息，请参见[摄影机设置](../../../摄影机设置.md)主题中的“*查看摄影机与渲染摄影机*”。

选择当前场景视图的摄影机

1. 在视图[面板菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)中，选择“视图 > 选择摄影机”(View > Select Camera)。
