# 附录：使用传统渲染过程

包含以下信息以供参考。如果要使用 Maya 软件渲染器，建议您使用渲染层，而不是渲染过程。详细信息请参见[渲染层概述](../../可视化和渲染图像/可视化和渲染图像/传统渲染层和渲染过程/传统渲染层概述.md)。

**注**

提供的

新渲染设置系统

现已取代传统渲染层，是 Maya 中的

默认系统

。这种新方法可简化复杂场景的管理以便进行渲染，如今已成为建议的工作流。有关详细信息，请参见

Maya 渲染设置

。

在过程中渲染时，会以不同方式渲染场景的属性。在过程中渲染可以精确地控制对象的颜色和落到它们上的阴影。

通常，在过程中渲染可以单独渲染场景的各种属性，如颜色、阴影和高光。可以细微调整场景，而无需通过在合成程序中修改不同过程来重新渲染。

## 美景过程

这是默认过程。可以从渲染层的“属性编辑器”(Attribute Editor)选择您的渲染过程。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-3338AE82-BD70-49CF-BF18-3D85AF937D24.png) <!-- baize:img-hook downloaded=false reason="正文 908 字 ≥300，非承重" -->

将产生由阴影过程和颜色过程生成的组件的完整渲染。由于颜色过程会产生由漫反射过程和高光过程生成的组件的完整渲染，因此美景过程会结束产生所有可能组件的完整渲染。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-46BAB939-3F27-4D36-A565-3B7223929439.png) <!-- baize:img-hook downloaded=false reason="正文 908 字 ≥300，非承重" -->

如果需要在合成软件包或绘制应用程序中独立调整阴影，请分别运行颜色过程和阴影过程。

## 颜色过程

仅生成图像的颜色组件。不会生成任何阴影信息。

颜色过程细分为漫反射过程和高光过程。

## 阴影过程

仅生成图像的阴影组件。不会生成任何颜色信息。

## 漫反射过程

仅执行漫反射着色。漫反射过程包含漫反射和环境光信息，并由颜色、透明度和“漫反射系数”(Diffuse Coeff)调整。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-5168F6DC-6E2C-4F71-A976-04D4947FC0C8.png) <!-- baize:img-hook downloaded=false reason="正文 908 字 ≥300，非承重" -->

## 高光过程

仅执行高光着色。高光组件的调整方式有所不同，具体取决于与对象关联的材质的类型。Phong、PhongE、Blinn 和各向异性材质会以不同方式生成高光贡献。在 Phong 材质上，高光过程可以使用余弦幂和高光颜色进行调整。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-450FF560-F034-4219-8DA8-4A9D6AA594B4.png) <!-- baize:img-hook downloaded=false reason="正文 908 字 ≥300，非承重" -->

**注**

不会为高光过程生成任何遮罩或 Alpha 通道，建议另外合成高光过程。

## 自定义阴影和反射过程

您也可以使用 useBackground 材质创建自定义阴影和反射过程，这种材质可捕捉阴影和/或反射。在渲染阴影过程时，将使用包含阴影信息的遮罩通道创建黑色图像。合成器可以使用此通道对阴影的外观进行模糊、变亮、变暗等处理。在渲染反射过程时，将在遮罩通道中使用白色遮罩创建 RGB 图像。

若要使用“使用背景”(Use Background)材质捕捉阴影和反射，请参见[捕捉 Alpha 通道的阴影](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6F36BC0B-2706-4BEA-93DF-48D8A5D2D64D)。
