# “纹理”(Texturing)菜单

## 绘制(Painting)

#### 3D 绘制工具(3D Paint Tool)

选择“3D 绘制工具”(3D Paint Tool)作为当前绘制笔刷。

请参见 [3D 绘制工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F7BDD112-2BEF-4B8C-94D7-356012774172)和 [3D 绘制工具设置](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-11EAC728-8E0A-46F6-A0D8-A68E3D60DD13)。

## PSD

#### 创建 PSD 网络(Create PSD Network)

创建一个可用作纹理贴图的 PSD 纹理网络。将出现[“创建 PSD 网络选项”(Create PSD Network Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-982EC2B2-64CC-4359-9483-7378760593EB)。

请参见[将 PSD 网络用作 Maya 中的纹理](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A7687378-DC86-4B80-A208-80AC151BFE54)

#### 编辑 PSD 网络(Edit PSD Network)

打开“编辑 PSD 网络选项”(Edit PSD Network Options)窗口，以便您可以编辑 PSD 网络的设置（如“UV 集”(UV Set)）和材质的默认属性。请参见[创建 PSD 网络选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-982EC2B2-64CC-4359-9483-7378760593EB)。

#### 更新 PSD 网络

当修改连接到 Maya PSD 节点（在 Maya 中）的 PSD 文件（在 Adobe Photoshop 中）时，可以更新（刷新）Maya 中的图像以立即显示修改。

请参见[更新 PSD 网络](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-648C6045-45B5-49FB-9FA5-77A8D67835FF)。

## Projection

#### 创建纹理引用对象(Create Texture Reference Object)

为选定曲面创建纹理引用对象以将 3D 纹理或投影的 2D 纹理锁定到该曲面。当曲面动画显示或变形时，纹理将与曲面保持在一起，这将产生非常自然的效果。

另请参见[创建纹理引用对象](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630#GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630__WS73099CC142F48755-3D114B7511812357EFE-796E)。

#### 删除纹理引用对象(Delete Texture Reference Object)

删除选定曲面的纹理引用对象（如果存在）。若要选择选定曲面的一个引用对象以删除该对象，请使用“纹理 > 选择纹理引用对象”(Texturing > Select Texture Reference Object)，或在通道盒中单击引用对象的标题。

另请参见[选择和删除纹理引用对象](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630#GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630__WS73099CC142F48755-3D114B7511812357EFE-7964)。

#### 选择纹理引用对象(Select Texture Reference Object)

为选定曲面（如果存在）选择纹理引用对象。也可以在“通道盒”(Channel Box)中单击其标题。

另请参见[选择和删除纹理引用对象](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630#GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630__WS73099CC142F48755-3D114B7511812357EFE-7964)。

## Nurbs

#### NURBS 纹理放置工具(NURBS Texture Placement Tool)

提供用于选定曲面的 2D 纹理放置操纵器。创建 2D 纹理时，“纹理放置工具”(Texture Placement Tool)图标将会显示在 Maya 工具栏中。

有关详细信息，请参见[纹理放置与标签映射](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-972AEA39-808F-4393-8556-019BF43E9AD5)。

选择“纹理放置工具设置”(Texture Placement Tool Settings)窗口中的“纹理 > NURBS 纹理放置工具”(Texturing > NURBS Texture Placement Tool) > ![图：选择“纹理放置工具设置”(Texture Placement Tool Settings)窗口中的“纹理 NURBS 纹…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1156 字 ≥300，非承重" -->，并设置以下属性：

“修改纹理”(Modify texture) - 控制纹理的哪个“2D 纹理放置”(2D Texture Placement)属性（“曲面放置”(Surface placement)或“标签映射”(Label Mapping)）可以进行交互调整。
