# cameraSet 节点

创建多立体装备时，将创建 cameraSet 节点。有关多立体装备的详细信息，请参见[创建多重摄影机装备](../../../../摄影机设置/摄影机设置/使用立体摄影机/创建多重摄影机装备.md)。

#### 活动(Active)

设置此标志可确定是否应该绘制该层。

#### 顺序(Order)

设置该标志可确定该层的处理顺序。如果两层具有相同的顺序编号，则从 0 层处理到 N 层。

#### 清晰深度(Clear Depth)

设置此标志可指示渲染该层之前是否应清除视口深度缓冲区。该选项可确保第一个绘制的对象（例如，第一层中）不会遮挡后续层中绘制的对象。
