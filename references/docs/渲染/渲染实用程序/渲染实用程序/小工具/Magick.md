# Magick

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../assets/Maya-Rendering/GUID-18F963A9-A2D7-4CA7-B4B1-EDBC323666BF.png) <!-- baize:img-hook downloaded=true reason="正文 221 字 <300 且带图" -->

magick 工具可以处理、连接图像并将图像从一种格式转换为另一种格式。为了获取选项列表，请在 shell 窗口中键入 magick convert -h。

**注**

  在 Maya 的先前版本中，它是 imconvert 工具。对于 Linux 和 Windows，当支持的版本更新到 7.0.10 时，该工具的名称已更改。

- 有关转换文档的信息，请参见 [https://imagemagick.org/script/convert.php](https://imagemagick.org/script/convert.php)

  该工具仅适用于 Windows 和 Linux 平台。
