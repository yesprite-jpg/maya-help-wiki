# “FCheck”窗口

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

“FCheck”显示两个窗口。“FCheck 播放”(FCheck Playback)窗口显示打开的图像或序列。根据不同的平台，“播放”(Playback)窗口中的菜单项也有所不同。

打开“FCheck”时，它会记住以前的设置。例如，如果以 60 FPS 查看动画序列，则下次使用“FCheck”时，FPS 将设置为 60。

有关 Windows 上的菜单项的信息，请参见 [FCheck 文件菜单](../渲染工具参考/渲染工具窗口和编辑器/FCheck%20引用/“Fcheck”%20“文件”%28File%29菜单.md)。

有关查看选项和调整设置的信息，请参见[显示键](../渲染工具参考/渲染工具窗口和编辑器/FCheck%20引用/FCheck%20中的显示键.md)和[图像调整键](../渲染工具参考/渲染工具窗口和编辑器/FCheck%20引用/FCheck%20中的图像调整键.md)。

## Windows/Linux

与“播放”(playback)窗口一起，会出现“FCheck”命令提示窗口以显示图像信息。图像信息显示在用于打开“FCheck”的 Shell 窗口中的 Linux 上。
