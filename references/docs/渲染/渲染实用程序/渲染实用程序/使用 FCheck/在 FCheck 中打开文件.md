# 在 FCheck 中打开文件

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

在 Windows 上在 FCheck 中打开文件

1. 启动 FCheck。

  有关详细信息，请参见[在 Windows 上启动 FCheck](启动“FCheck”.md#WS73099CC142F48755-3D114B7511841AEFA9F-4A4A)。

2. 在“播放”(Playback)窗口中，选择“文件 > 打开图像”(File > Open Image)或“文件 > 打开动画”(File > Open Animation)。

  将显示文件浏览器。

3. 在文件浏览器中，选择要查看的图像或动画序列的第一帧，然后单击“打开”(Open)。

  在“FCheck 播放”(FCheck Playback)窗口中将显示图像或动画。

4. 使用键盘命令操纵图像或序列。

  有关键盘命令的详细信息，请参见[显示键](../渲染工具参考/渲染工具窗口和编辑器/FCheck%20引用/FCheck%20中的显示键.md)。

  **注**

  提示：

  也可以使用命令行在 Windows 中打开文件。请按照

  使用 -n 选项打开动画

  中的步骤操作，获得更多详细信息。

在 Linux 上在 FCheck 中打开文件

1. 启动包含图像或序列的 FCheck。

  有关详细信息，请参见[在 Linux 上启动 FCheck](启动“FCheck”.md#GUID-45C097EE-8D45-4F82-B817-F3B1D2F9A76D__WS17956D7ADBC6E7365228C7F8117AE33CB28-7FF2)。

2. 使用键盘命令操纵图像。

  有关键盘命令的详细信息，请参见[显示键](../渲染工具参考/渲染工具窗口和编辑器/FCheck%20引用/FCheck%20中的显示键.md)。

  **注**

  提示：

  使用

  “FCheck”

  可以打开和查看进行中的渲染。若要在

  “FCheck 播放”(FCheck Playback)

  窗口中更新部分完成的图像，请使用“u”热键。有关通过 Maya 使用

  “FCheck”

  的信息，请参见

  通过 Maya 使用“Fcheck”

  。

通过选择“视图 > 全屏”(View > Full Screen)，可以按全屏大小显示图像。
