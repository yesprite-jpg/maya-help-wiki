# 结合使用“FCheck”和声音

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

“FCheck”可以导入声音文件，使其与图像序列相关联，并与图像序列同步播放。

在 Windows 上导入声音文件

1. 选择“文件 > 导入声音”(File > Import Sound)。

在 Windows 上启用或禁用声音

1. 选择“文件 > 开关声音”(File > Toggle Sound)。
