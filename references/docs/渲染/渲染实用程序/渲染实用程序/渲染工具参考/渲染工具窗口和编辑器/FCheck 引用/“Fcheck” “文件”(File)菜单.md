# “Fcheck”  “文件”(File)菜单

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

#### 打开图像(Open Image)

将图像加载到“FCheck 播放”(FCheck Playback)窗口中。

#### 打开动画(Open Animation)

将动画/序列加载到“FCheck 播放”(FCheck Playback)窗口中。

#### 还原(Revert)

将图像或动画重新加载为磁盘上的最新保存状态。

#### 导入声音(Import Sound)

“导入声音”(Imports sound)到“FCheck”查看器中，以便可以播放声音和动画。

#### 开关声音(Toggle Sound)

打开和关闭声音。

#### 保存图像(Save Image)

输入文件名以保存图像。默认情况下会将文件另存为 .iff。

#### 保存动画(Save Animation)

输入文件名以保存动画/序列。默认情况下会将文件另存为 .iff。

#### 退出

退出程序。
