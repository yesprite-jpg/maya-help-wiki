# FCheck 中的显示键

使用“FCheck”显示图像时，可以使用下列关键帧或“FCheck 信息”(FCheck Info)窗口来控制显示。

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

| Windows/Linux | 操作 |
|---|---|
| a | 显示图像中的 Alpha 位平面通道。 |
| b | 显示图像中的蓝色位平面通道。 |
| c | 通过合并包含在三个 RGB 平面中的颜色值来显示图像。 |
| f | 在单缓冲区模式和双缓冲区模式之间切换。默认模式取决于计算机的显卡。 |
| g | 显示图像中的绿色位平面通道。 |
| k | 启用和禁用 Kodak Cineon 校正。 |
| m | 显示图像中的遮罩。 |
| p | 打印输出当前亮度、Gamma 和饱和度值。 |
|  | 显示 Alpha 位平面通道。 |
| r | 显示图像中的红色位平面通道。 |
| x | 显示负值。 |

| F12 | 显示图像分片的边界。 |
| *下列各项使用数字小键盘键* |  |
| 0 | 放大。 |
| . （数字小键盘上的句点） | 缩小。 |
| 1 到 9 | 按 1 到 9 之间的数字可滚动当前图像。若要滚动得更快，请按 Shift 和 Alt 与数字的组合。 |
