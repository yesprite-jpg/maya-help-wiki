# FCheck 鼠标控件

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

下表介绍了在“FCheck”中使用的鼠标控件：

| 鼠标按钮 | 描述 |
|---|---|
| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-Rendering/GUID-E6AA6067-ED4E-4D5F-AC56-A72B3A42B808.png) <!-- baize:img-hook downloaded=true reason="正文 287 字 <300 且带图" --> | 单击并拖动鼠标可拖动整个序列的帧。向左拖动鼠标可反转，向右拖动鼠标可前进。 |
| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-Rendering/GUID-82CD9632-C244-4452-85A5-52805BE4AB22.png) <!-- baize:img-hook downloaded=true reason="正文 287 字 <300 且带图" --> | （Windows 和 Linux）在播放窗口上单击鼠标中键可光标之下显示像素的坐标。坐标会显示在命令行窗口中。 |
| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-Rendering/GUID-1990D688-BDEB-4EF0-BDE8-9EDC3DB5D85F.png) <!-- baize:img-hook downloaded=true reason="正文 287 字 <300 且带图" --> | （Windows 和 Linux）单击鼠标右键可在图像平面上激活点绘制工具。单击鼠标右键并拖动以创建流动的线。 |
