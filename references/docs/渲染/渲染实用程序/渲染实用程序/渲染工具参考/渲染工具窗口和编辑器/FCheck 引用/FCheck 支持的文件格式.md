# FCheck 支持的文件格式

“FCheck”的固有文件格式是 Maya“图像文件格式” (IFF)。如果文件不是 IFF 格式，“FCheck”将使用称为*“toimg”*的外部转化器对图像或动画进行转化。转化可以让“FCheck”在其播放窗口中显示图像或动画。以下是“FCheck”支持的文件格式列表。

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

| 格式 | 扩展名 |
|---|---|
| Abekas NTSC 或 PAL | .yuv |
| Alias | .als |
| 浏览 |  |
| GIF | .gif |
| JPEG | .jpg |
| Kodak Cineon | .cin |
| Lucas Film | .lff |
| Pixibox PXB 和 SCN | .pxb 或 .scn |
| PPM raw/ascii | .ppm |
| Prisms | .pri |
| Quantel | .qtl |
| SGI | .rgb、.sgi 或 .bw |
| Avid Softimage | .pic |
| Targa RGB/BW | .tga |
| TIFF 6.0 | .tif 或 .tiff |
| Vista | .vst |
| Wavefront RLA | .rla |
