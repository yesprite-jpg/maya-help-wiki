# FCheck 中支持的保存格式

“FCheck”也可以用多种文件格式保存。下面列出了 FCheck 中支持的保存格式：

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

| 格式 | 延伸 |
|---|---|
| Maya IFF | .iff |
| Silicon Graphics | .rgb, .sgi or .bw |
| Adobe®Photoshop® | .ps |
| Targa | .tga |
| TIFF | .tif |
| GIF (Windows/Linux) | .gif |
| JPEG | .jpg |
| JPEG-2000 (Mac OS X) | .jp2 |
| PNG | .png |
| Apple PICT | .pict |
| Windows 16 位或 32 位位图 | .bmp |
| MacPaint | .pntg |
| Apple QuickTime 图像 | .qtif |
