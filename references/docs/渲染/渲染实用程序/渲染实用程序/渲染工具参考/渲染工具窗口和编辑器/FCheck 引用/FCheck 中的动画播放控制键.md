# FCheck 中的动画播放控制键

**注**

重要：

自 Maya 2020 起，FCheck 在 macOS 上不再受支持。可以在

应用程序首选项

（

“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)

）中选择其他默认图像查看器。

使用以下键控制“FCheck”中的动画播放。

| Windows/Linux | 操作 |
|---|---|
| 逗号 | 连续向后播放动画。 |
| 周期 | 连续向前播放动画。 |
| 空格 | 暂停动画。再次按下继续。 |

| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" --> + . | 设定当前帧为动画的结束帧。 |
| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-C48CB823-0167-41AE-B7CF-85871AC36213.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" --> + , | 向后播放动画一次。 |
| ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-C48CB823-0167-41AE-B7CF-85871AC36213.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" --> + . | 向前播放动画一次。 |
| - | 减慢动画的播放速度。 |
| + | 加快动画的播放速度 |
| 右箭头 | 继续到动画暂停后的下一帧。 |
| 左箭头 | 后退到暂停动画的上一帧。 |
| ![图：+ 右箭头](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-6BC67455-3D71-444F-B249-B8161AD6821F.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" --> + 右箭头 | 继续到动画的最后一帧。 |
| ![图：+ 左箭头](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Rendering/images/GUID-6BC67455-3D71-444F-B249-B8161AD6821F.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" --> + 左箭头 | 返回到动画的第一帧。 |
| s | 连续向前和向后循环播放动画。（摇摆） |
| t | 实时播放动画，必要时跳过图像。 |
