# 关于 FieldAssembler

**注**

FieldAssembler 仅适用于 Microsoft® Windows®。对于 Linux，请使用 交替。对于 Apple® Mac OS ® X，请使用非线性编辑器或合成应用程序。有关详细信息，请参见 [交替](../小工具/交替.md)。

FieldAssembler 工具交替渲染场图像。场是由作为在 NTSC 设备上显示的交替线组成的图像。

每个场图像仅包含半个全帧，并且每个场都存储在单独的文件中。设计将在 NTSC 设备上播放的动画时，以这种方式渲染图像非常有用。但是，若要在计算机屏幕上查看这些图像或将其传递到某些其他计算机程序，例如合成软件，需要重新将其集合为完整图像。发生这种情况时，有一半的文件，并且每个文件包含的数据翻倍。

打开“FieldAssembler”

1. 请执行下列任一操作：

  - 在命令提示下，键入 FieldAssembler。

  - 在 C:\Program Files\Autodesk\<版本>\bin 中，双击 FieldAssembler.exe。

  其中，*<版本>* 表示 Maya 版本；例如：*Maya2016*

有关“FieldAssembler”菜单项目的信息，请参见[文件菜单命令](../渲染工具参考/渲染工具窗口和编辑器/FieldAssembler/“文件”%28File%29%20菜单命令.md)、[编辑菜单命令](../渲染工具参考/渲染工具窗口和编辑器/FieldAssembler/“编辑”%28Edit%29菜单命令.md)和[帮助菜单命令](../渲染工具参考/渲染工具窗口和编辑器/FieldAssembler/“帮助”%28Help%29菜单命令.md)。
