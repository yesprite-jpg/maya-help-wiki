# 使用自定义渲染器

假如您要使用自己的自定义渲染器，该渲染器 XML 文件名必须遵从格式 *myRendererName*Renderer.xml。使用环境变量 MAYA_RENDER_DESC_PATH 为自定义渲染器描述 XML 文件设定其他目录。

可以在 Maya 程序目录的 bin/renderDesc 文件夹中查找示例。
