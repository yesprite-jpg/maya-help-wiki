# 查看对象的 Maya 细分设置

有关 Maya 默认细分设置的信息，请参见[主细分和次细分过程](../细分和近似简介/Maya%20细分/主细分和次细分过程.md)。

查看对象的 Maya 细分设置

1. 选择您想查看其细分设置的对象。

2. 打开“属性编辑器”(Attribute Editor) (![图：打开“属性编辑器”(Attribute Editor) (+A)。](../../../../../assets/Maya-Rendering/GUID-6BC67455-3D71-444F-B249-B8161AD6821F.png) <!-- baize:img-hook downloaded=true reason="正文 152 字 <300 且带图" -->+A)。

3. 单击形状选项卡（例如，nurbsSphereShape1）。

  将出现形状节点的属性。

4. 展开“细分”(Tessellation)区域。
