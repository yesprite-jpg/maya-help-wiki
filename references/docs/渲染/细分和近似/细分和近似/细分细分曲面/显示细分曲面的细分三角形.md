# 显示细分曲面的细分三角形

查看细分曲面镶嵌细分三角形

1. 选择对象。

2. 单击[“修改 > 转化 > 细分曲面到多边形”(Modify > Convert > Subdiv to Polygons)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-31FAF0FF-6EE1-4360-A65A-FFED15C12BBD)将细分曲面转化为多边形曲面以用作临时可视化对象。
