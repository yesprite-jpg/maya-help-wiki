# 性能提高技巧

此部分介绍了如何提高 Maya 的性能，以便您可以更快地移动对象、播放动画、渲染和工作。

- [更高效地使用 Maya](性能提高技巧/最有效地使用%20Maya.md) 从不同方面介绍了诸多提示和最佳实践，有助于改善性能。

- [使用求值管理器提高性能](性能提高技巧/使用解算管理器提高性能.md)介绍了一款高级工具，使您可以将工作分散到可用 CPU 和 GPU 资源之中，从而提高性能。

- [分析场景以提高性能](性能提高技巧/分析场景以提高性能.md)向您介绍了如何分析动画以查找瓶颈和性能下降问题。
