# 在求值管理器中启用动力学支持

默认情况下，已禁用求值管理器对 Nucleus 动力学的支持。要启用动力学支持，请在[命令行](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F4FCE554-1FA5-447A-8835-63EB43D2690B#GUID-F4FCE554-1FA5-447A-8835-63EB43D2690B__GUID-DFE40A4D-E6E5-4380-B86A-AED162980B17)中运行以下脚本：

```text
evaluator -name dynamics -c "disablingNodes=unsupported";
evaluator -name dynamics -c "handledNodes=dynamics";
evaluator -name dynamics -c "action=evaluate";
```

要还原默认（已禁用）行为，请运行以下脚本：

```text
evaluator -name dynamics -c "disablingNodes=legacy2016";
evaluator -name dynamics -c "handledNodes=none";
evaluator -name dynamics -c "action=none";
```

如果遇到动力学问题（例如，求值管理器从平行模式中切换），则可以运行返回问题节点列表的脚本。请参见[识别制约性能的动力学节点](标识会降低性能的动力学节点.md)。
