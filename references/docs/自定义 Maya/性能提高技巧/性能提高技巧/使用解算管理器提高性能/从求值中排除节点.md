# 从求值中排除节点

可以暂时禁用求值管理器对有问题节点的求值。有问题的节点会导致播放速度减慢，因此禁用它们可提高性能。这样，您可以对场景所需的对象求值。

可以使用[分析器](../分析场景以提高性能/分析器.md)识别导致速度减慢的节点。请参见[使用分析器查找动画瓶颈](../分析场景以提高性能/在分析器中查找动画瓶颈.md)。

从求值中排除某个节点

1. 选择该节点。

2. 在属性编辑器的“节点行为”(Node Behavior)部分中，启用[“冻结”(Frozen)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4BBDEBF1-A4F1-4EE3-B225-A1E808AFA206#GUID-4BBDEBF1-A4F1-4EE3-B225-A1E808AFA206__GUID-116AD6D1-99CC-4435-9E6B-7DDCC98C8377)选项。

  这将禁用选定节点的求值。

**注**

节点冻结仅限于求值管理器的“串行”(Serial)和“平行”(Parallel)模式，而“旧版 DG”(Legacy DG)模式计算常用方式，而不考虑任何冻结状态设置。请参见

首选项(Preferences)

窗口（

“窗口 > 设置/首选项 > 动画类别”(Windows > Settings/Preferences > Animation category)

）的“求值”(Evaluation)部分。

有关可提高场景性能的更多工具，请参见[求值工具包](解算工具包%28Evaluation%20Toolkit%29.md)。
