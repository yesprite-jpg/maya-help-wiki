# “资产”(Assets)首选项

可以在[首选项(Preferences)窗口](../“首选项”%28Preferences%29窗口.md)的“资产”(Assets)类别中设置以下首选项。

若要返回到出厂默认设置，请在此窗口中选择“编辑 > 还原默认设置”(Edit > Restore Default Settings)。请注意，这将重置“首选项”(Preferences)窗口中每个类别的首选项。

有关创建和使用资产的信息，请参见[资产](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1826F831-E3D1-4045-B6B9-F7D34360C331)。

## 资产

#### 大纲视图(Outliner)

如果启用该选项，那么在“大纲视图”(Outliner)中选择资产时，会自动在场景中选择资产的选择变换。

#### 通道盒(Channel Box)

使用该选项可以设定将模板应用于资产时或未将模板应用于资产时可以在“通道盒”(Channel Box)中显示的已发布属性的最大数量。为获得最佳性能，建议的设置为 400。

#### 属性编辑器(Attribute Editor)

允许您选择已发布属性的排列。
