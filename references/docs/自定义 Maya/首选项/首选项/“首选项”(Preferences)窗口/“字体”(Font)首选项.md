# “字体”(Font)首选项

可以在[首选项(Preferences)窗口](../“首选项”%28Preferences%29窗口.md)的“字体”(Font)类别中设置以下首选项。

若要返回到出厂默认设置，请在此窗口中选择“编辑 > 还原默认设置”(Edit > Restore Default Settings)。请注意，这将重置“首选项”(Preferences)窗口中每个类别的首选项。

## Viewport 2.0 字体大小(Viewport 2.0 Font Size)

对于 Viewport 2.0 字体（例如，平视显示和注释），请在以下大小中选择：

- 默认字体大小

- 中号字体大小(Maya 2010)(Medium Font Size (Maya 2010))：选择该选项以恢复为在 Maya 2010 中使用的字体大小。

- 自定义字体大小(Custom Font Size)：选择此选项以使用下面滑块来自定义字体大小。

  - 小号 UI 字体大小(Small UI Font Size)：使用此属性来为以下项设置视口字体大小：

    - 平视显示仪，除了“帧速率”(Frame Rate)和“原点轴”(Origin Axis)

    - 关节标签

    - IK 控制柄标签

    - 摄影机 UI

    - 多边形挤出工具

    - 通用操纵器

  - UI 字体大小(UI Font Size)：未在上面列出的项目通常使用此字体大小。

**注**

提示：

如果字体大小不自动更新，可以选择场景视图中的任意对象进行视图刷新。
