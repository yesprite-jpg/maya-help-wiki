# “文件引用”(File References)首选项

可以在[首选项(Preferences)窗口](../“首选项”%28Preferences%29窗口.md)的“文件引用”(File References)类别中设置以下首选项。

若要返回到出厂默认设置，请在此窗口中选择“编辑 > 还原默认设置”(Edit > Restore Default Settings)。请注意，这将重置“首选项”(Preferences)窗口中每个类别的首选项。

有关被引用文件的信息，请参见[文件引用](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-238914C9-4129-454C-99D7-B8C57AF423DB)。

## 文件引用(File References)

#### 允许编辑引用的动画曲线(Allow edits on referenced animation curves)

选择该项可允许编辑被引用文件中的动画曲线。请参见[编辑被引用文件中的动画曲线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4F933D99-AB11-48B3-A1C8-B1D401058E8D)。在[曲线图编辑器(Graph Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6D38EAEA-6032-471E-BD0E-54A74D4443C0)中引用动画曲线时，它将以暗色（40% 的原始曲线颜色）显示，并带有黑色锁定关键帧。

另请参见：[编辑被引用文件中的动画曲线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4F933D99-AB11-48B3-A1C8-B1D401058E8D)。

#### 允许锁定和解除锁定针对引用属性的编辑(Allow locking and unlocking edits on referenced attributes)

选择该项可允许锁定和解除锁定被引用文件中的属性值。请参见[锁定属性值](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-015DADAC-332D-4D16-A4E0-87A5CE30D727)。
