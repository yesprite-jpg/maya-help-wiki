# XGen 首选项(XGen Preferences)

可以在[首选项(Preferences)窗口](../“首选项”%28Preferences%29窗口.md)的“XGen”类别中设置以下首选项。

若要返回到出厂默认设置，请在此窗口中选择“编辑 > 还原默认设置”(Edit > Restore Default Settings)。请注意，这将重置“首选项”(Preferences)窗口中每个类别的首选项。

## 缓存选项(Cache Options)

#### 内存缓存大小

指定将 XPD 缓存和 PTEX 文件写入磁盘时使用的最大系统内存量。

请参见[管理 XGen 文件和目录](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E4714F1D-C4F6-49FD-9B89-FDE72CF9296F)。

## Viewport 2.0

#### 绘制方法

设置绘制基本体时要使用的渲染器。设置为“硬件实例”(Hardware Instance)时，Maya 使用 Viewport 2.0 渲染。设置为“旧版”(Legacy)时，Maya 使用 XGen 软件渲染器。实例化大量高分辨率归档对象时，使用“旧版”(Legacy)可提高性能。

## 线程(Threading)

#### 多线程(Multithreading)

启用线程以提高基本体生成、修改器处理和面片求值的性能。
