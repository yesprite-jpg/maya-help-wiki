# 编辑工具架内容

| 目标 | 操作 |
|---|---|
| 从工具架移除图标。 | 用鼠标中键将图标拖动到工具架栏右上角的垃圾桶图标。 |
| 重新排列工具架上的图标。 | 用鼠标中键拖动到工具架上的不同位置。 |
| 将图标移动到另一工具架。 | 用鼠标中键拖动到目标工具架选项卡。 |
| 将图标复制到另一工具架上。 | 按住 Ctrl 键并使用鼠标中键将图标拖动到目标工具架选项卡。 |
