# 创建自定义工具架

创建自定义工具架

1. 选择默认工具架旁边的 ![图：选择默认工具架旁边的 “新建工具架”(New Shelf)。](../../../../../assets/Maya-Customizing/GUID-A6A5C1A6-8085-49CA-8F03-916AD3E63B54.png) <!-- baize:img-hook downloaded=true reason="正文 172 字 <300 且带图" --> > “新建工具架”(New Shelf)。

2. 输入新工具架的名称，然后单击“确定”(Ok)。

3. [将工具操作菜单项或脚本添加到工具架](向工具架添加工具、操作、菜单项或脚本.md)以添加所需的工具。
