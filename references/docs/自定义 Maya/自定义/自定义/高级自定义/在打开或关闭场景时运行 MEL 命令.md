# 在打开或关闭场景时运行 MEL 命令

[MEL 脚本节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-296601E8-F5C7-425C-AA8C-4BE5AB69C486)可以将 MEL 脚本附着到场景中，并在场景打开（从磁盘加载）或关闭（用户打开另一场景文件或启动新场景时）时运行该脚本。

有关创建脚本节点以及使用它们来触发事件的信息，请参见[创建或编辑脚本节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1008E969-3AB8-479C-B2F4-FF5F589A23C6)。
