# 更改 Maya 的操作语言

Maya 通过读取计算机上的设置检测操作语言。但是，您可以将语言更改为英语，即便操作系统 (OS) 使用的是另一种语言。另请参见[运行日语或简体中文界面的 Maya](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-771DA1CA-1C72-4A32-8441-A16D8645925E)。

**在非英语操作系统环境中以英语运行 Maya (Windows)**

您需要在 Windows 操作系统中创建新的环境变量。

**注**

重要：

您必须在

Windows

系统首选项中设置环境变量，而不是在

Maya.env

文件中设置。在 Maya.env 文件中更改此变量不会对 Maya 的行为产生影响。

1. 打开 Windows 环境变量。根据您的 Windows 版本，环境变量位于不同的位置：

  - Windows 7 之前的版本：找到“我的电脑”图标，然后从显示的下拉列表中选择“属性”。在**“系统属性”**窗口中，单击**“高级”**选项卡，然后单击**“环境变量”**。

  - Windows 7：在计算机名称上单击鼠标右键，然后依次选择**“属性”**和**“高级系统设置”**。单击**“环境变量”**。

  - Windows 10：在 Windows“搜索”字段中键入**“环境变量”**打开**“环境变量”**窗口。

2. 在“<*您的姓名*> 的用户变量”区域，单击**“新建”**。

3. 在**“变量名”**文本字段中键入：MAYA_UI_LANGUAGE。

4. 在**“变量值”**文本字段中键入：en_US

5. 启动 Maya。

**注**

提示：

在更改 Maya 的操作语言以后，如果要运行日语/简体中文 Maya，可以将环境变量值设置为

ja_JP

（针对日语）和

zh_CN

（针对简体中文）或删除环境变量列表中的变量。

**在非英语操作系统环境中以英语运行 Maya (Mac OS X)**

1. 单击**“系统首选项”**图标。

2. 选择“语言和区域”。

3. 将首选的非英语语言添加到“首选语言”中。

4. 选择该新语言作为操作系统的主要语言。

5. 重新启动您的计算机。

6. 启动 Maya。
