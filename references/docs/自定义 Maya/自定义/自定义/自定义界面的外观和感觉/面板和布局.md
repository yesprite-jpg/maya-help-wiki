# 面板和布局

“视图”(View)面板内的面板排列称为“布局”。

Maya 具有一些预定义布局，您可以通过单击界面左侧的[快速布局按钮](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-693FBB4C-4010-4D55-8215-67FBE19114E7)进行使用。在快速布局按钮上单击鼠标右键，可以查看其他布局和选项。

作为面板布局的替代方法，您可以使用[工作区](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0384C282-3CA1-4587-9775-F7164D3F6980)自定义界面。工作区可用于将面板移动和停靠到任何位置，而不仅仅是控制[视图面板](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-455539A6-3506-458C-92DA-14F171C14553)中的排列。另一个区别就是，工作区将自动作为单独的文件存储到用户目录中并持续存在，而面板布局则存储在场景文件中。
