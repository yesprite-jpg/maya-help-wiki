# 更改用户界面分辨率（缩放）

可以调整 Maya 界面的分辨率（比例），以利于在高分辨率显示器（如超高清或 4K 显示器）或者 Retina 显示屏和绘图板上运行。该界面可以进行缩放以提供更好的图标和文本可读性。

更改界面分辨率

1. 打开[首选项(Preferences)窗口](../../../首选项/首选项/“首选项”%28Preferences%29窗口.md)（选择“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)）。

2. 选择[界面首选项(Interface preferences)](../../../首选项/首选项/“首选项”%28Preferences%29窗口/界面首选项%28Interface%20Preferences%29.md)类别（如未选定）。

3. 调整“界面缩放”(Interface Scaling)部分中的设置。

  ![图：调整“界面缩放”(Interface Scaling)部分中的设置。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Customizing/images/GUID-34F501D0-CD1E-4D67-9BDB-FB57C3E430A4.png) <!-- baize:img-hook downloaded=false reason="正文 527 字 ≥300，非承重" -->

**注**

对于运行 4K 显示器的 Mac OS X 操作系统，**“界面缩放”(Interface Scaling)**部分在“界面首选项”(Interface Preferences)中不显示：

- 在已启用 Retina 的设备上，Maya 自动使用最佳的显示设置，因此“使用自定义缩放”(Use custom scaling)设置不可用。

- 如果将 MacBook Pro (Retina) 与 4K 显示器一起使用，则操作系统版本必须是 10.9.3 或更高版本。

如果界面文本太小，请尝试更改显示器的**“系统首选项”(System Preferences)**。在 Apple 支持网站上查找文章“调整 Retina 显示屏的分辨率”。
