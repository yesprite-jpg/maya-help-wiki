# 多点触控输入手势

若要将 Maya 与多点触控设备配合使用，请确保启用[界面首选项(Interface preferences)](../../../首选项/首选项/“首选项”%28Preferences%29窗口/界面首选项%28Interface%20Preferences%29.md)中的**“多点触控手势”(Multi-touch Gestures)**首选项。如果您的设置包含受支持的多点触控设备，并且使用最新的驱动程序，便无需再进行任何配置。

如果您的工作站中包含装有最新驱动程序的受支持多点触控设备，则 Maya 可识别以下输入/动作。

**注**

重要：

(

Mac OS X

) 如果启用触控板作为多点触控设备，请禁用“系统偏好设置”的

“触控板 > 更多手势”(Trackpad > More Gestures)

下的

“在全屏显示的应用程序之间推送”(Swipe between full-screen apps)

和

“任务控制”(Mission·control)

，以防止 Mudbox 手势与触控板默认定义的手势发生冲突。
