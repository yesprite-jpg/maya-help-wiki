# 更改 Maya 的文件保存位置

默认情况下，Maya 会将文件保存到 **Projects** 文件夹。

首次启动 Maya 时，将在以下位置创建默认项目：

  C:\Users\yourUsername\Documents\maya\projects\default (Windows)

  /home/yourUsername/maya/project/default (Linux)

  /Users/yourUsername/Documents/maya/projects/default (macOS)

您也可以通过选择“文件 > 项目窗口”(File > Project Window)查找当前项目位置。

Projects 可用于集中存储与场景相关的文件以进行跟踪。之所以采用这种方式，是因为场景可能会依赖于来自不同位置的多个资源。 详细信息请参见[将文件组织到项目中](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9CE78B5A-7E9F-45E6-AB6D-66795E5656F4)。 “项目窗口”(Project Window)会显示每种类型的资源将保存到的文件夹。

除非执行下列任一操作，否则文件将保存到此默认项目：

  设置其他项目。若要执行此操作，请参见[在 Maya 中设置项目](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D5CA162A-0956-49C6-9FAC-2F73DCF03409)。

  为项目选择其他默认位置。

为项目选择其他默认位置

1. 从 Maya [主菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3DB1C040-051F-4C2A-83F8-D806455FCEFF)选择“窗口 > 首选项”(Windows > Preferences)。

2. 选择“文件/项目”(Files/Projects)类别，然后在“项目设置”(Project Settings)区域中，将某个位置设置为默认项目目录。

  下次通过选择“文件 > 项目窗口”(File > Project Window)并单击“新建”(New)来**创建新项目**时，将在指定的位置创建项目。

  您还可以设置目录，以便 Maya 每次都从此项目开始。
