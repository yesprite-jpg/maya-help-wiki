# 缺少插件疑难解答

您日常使用 Maya 所需的大部分插件会自动加载。如果尝试访问菜单项或工具时，帮助行中出现错误消息，或如果发现缺少期望的菜单项，这可能意味着未加载相应的功能插件。

如果您怀疑场景中未加载某个插件，请进行检查以确保已使用“插件管理器”(Plug-in Manager)（“窗口 > 设置/首选项 > 插件管理器”(Windows > Settings/Preferences > Plug-in Manager)）加载该插件。另请参见[加载或卸载 Maya 插件](加载或卸载%20Maya%20插件.md)。

有关由插件控制的功能的详细信息，请参见 [Maya 随附插件列表](Maya%20随附插件列表.md)。
