# 创建或编辑标记菜单

创建新的标记菜单的过程共分两步：首先，创建标记菜单。然后，通过将标记菜单指定给热键或热盒区域而实际使用该标记菜单。

可以添加设置了不同标记菜单的多个版本的同一工具。例如，您可以在选定“推动”(Push)选项时添加“雕刻曲面工具”(Sculpt Surfaces Tool)并在选定“拉动”(Pull)操作时再添加另一个“雕刻曲面工具”(Sculpt Surfaces Tool)。这只适用于工具，而不适用于常规的菜单项（操作）。

| 目标 | 操作 |
|---|---|
| 打开标记菜单编辑器。 | 选择“窗口 > 设置/首选项 > 标记菜单编辑器”(Windows > Settings/Preferences > Marking Menu Editor)。 |
| 开始新的标记菜单。 | 在“标记菜单编辑器”(Marking Menu Editor)中，单击“创建标记菜单”(Create Marking Menu)。 |
| 编辑现有的标记菜单。 | 在“标记菜单编辑器”(Marking Menu Editor)中，单击要编辑的标记菜单的名称，然后单击“编辑标记菜单”(Edit Marking Menu)。 |
| 将项目添加到标记菜单。 | 开始新的标记菜单或编辑现有的标记菜单。 使用鼠标中键将项目拖动到标记菜单编辑器中的空白处。可执行以下任意操作： 从“工具箱”(Tool Box)中拖动一个工具。 从工具架拖动一个工具架项目。 从“脚本编辑器”(Script Editor)拖动一个选定文本。 |
| 更改项目的标签或脚本。 | 在项目上单击鼠标右键，然后选择“编辑菜单项”(Edit Menu Item)。 |
| 使用项目打开子菜单。 | 在标记菜单编辑器的空白处单击鼠标右键，并选择“弹出子菜单”(Popup Submenu)。 完成子菜单的编辑后，关闭该子菜单的窗口。 |
| 删除项目。 | 在项目上单击鼠标右键，并选择“删除菜单项”(Delete Menu Item)。 |
| 设置标记菜单的显示时间。 | [为热键指定标记菜单](为热键指定标记菜单.md) [将标记菜单添加到热盒中](将标记菜单添加到热盒中.md) |
