# 自定义热盒

按住空格键以显示热盒，然后执行下列任一操作来对其进行自定义：

| 目标 | 操作 |
|---|---|
| 更改热盒中可用的功能 | 在热盒的中心单击鼠标右键，然后从标记菜单中选择“热盒风格”(Hotbox Style)，然后选择下列选项之一： 区域和菜单行(Zones and menu rows) 显示所有菜单以及包含热盒上、下、左、右各个方向的标记菜单的“区域”。 仅区域(Zones only) 不显示所有菜单。 仅中心区域(Center zone only) 仅显示中心标记菜单。这将使热盒等同于热键标记菜单。 |
| 更改哪些附加菜单可用 | 单击“热盒控件”(Hotbox Controls)，然后在出现的标记菜单中拖动以显示用于显示或隐藏热盒菜单的子菜单。 |
| 更改访问附加菜单的方式 | 单击“热盒控件”(Hotbox Controls) >“热盒风格”(Hotbox Style)，并启用“中心区域右键弹出菜单”(Center zone RMB Popups)。 |
