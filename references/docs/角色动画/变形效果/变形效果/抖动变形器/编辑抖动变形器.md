# 编辑抖动变形器

禁用或删除所有抖动对象的抖动缓存

1. 选择“变形 > (创建)抖动 > [抖动磁盘缓存属性](../变形器参考/“变形”%28Deform%29菜单/“抖动变形器”%28Jiggle%20Deformer%29菜单/抖动磁盘缓存属性%28Jiggle%20Disk%20Cache%20Attributes%29.md)”(Deform > (Create) Jiggle > Jiggle Disk Cache Attributes)以显示属性编辑器。

2. 在“所有缓存的控件”(Control For All Caches)区域：

  - 单击“删除所有缓存”(Delete All Caches)。

  - 从“启用状态”(Enable Status)菜单中，选择“禁用全部”(Disable All)。

删除特定对象的抖动缓存

1. 选择要应用抖动变形器的对象。

2. 打开[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)并选择“jiggleCache”选项卡。（展开“属性编辑器”(Attribute Editor)的尺寸以查看所有选项卡。）

3. 单击“删除缓存”(Delete Cache)。

提示：

如果要为此变形器创建衰减（或渐变效果），以使变形效果在指定的距离后减少或衰减，请使用
