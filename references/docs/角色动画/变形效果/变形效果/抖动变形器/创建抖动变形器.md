# 创建抖动变形器

创建抖动变形器

1. 选择要抖动的点或整个对象。

2. 选择“变形 > (创建)抖动”(Deform > (Create) Jiggle) > ![图：选择“变形 (创建)抖动”(Deform (Create) Jiggle) 。 此时将显示“抖动变形器选项”(Jiggl…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 681 字 ≥300，非承重" -->。

  此时将显示[“抖动变形器选项”(Jiggle Deformer Options)](../变形器参考/“变形”%28Deform%29菜单/“抖动变形器”%28Jiggle%20Deformer%29菜单/“抖动变形器”%28Jiggle%20Deformer%29选项.md)窗口。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[“变形器 > (创建)抖动”(Deformers > (Create) Jiggle)](../变形器参考/“变形”%28Deform%29菜单/“抖动变形器”%28Jiggle%20Deformer%29菜单/“抖动变形器”%28Jiggle%20Deformer%29选项.md)和[高级变形器选项](../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

4. 单击“创建”(Create)来创建抖动变形器。选项窗口将关闭。可以单击“应用”(Apply)使窗口保持打开状态并继续调整设置。

5. 播放动画以检查结果。

  **注**

  若要应用效果，您可以播放动画两次。

  ![图：播放动画以检查结果。 注： 若要应用效果，您可以播放动画两次。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-162AA1BB-0756-4238-BB18-C138FF0359D0.gif) <!-- baize:img-hook downloaded=false reason="正文 681 字 ≥300，非承重" -->

6. 在播放动画之后，使用以下工具调整抖动：“绘制抖动权重工具”(Paint Jiggle Weights Tool)。请参见[绘制抖动变形器权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-7496A4C7-4B78-4098-874A-F458E64A9D3F.htm)。

**注**

提示：

如果要为此变形器创建衰减（或渐变效果），以使变形效果在指定的距离后减少或衰减，请使用

组件标记

。请参见

创建变形器衰减

。

为抖动变形器创建磁盘缓存

1. 选择[“变形 > (创建)抖动 > 抖动磁盘缓存”(Deform > (Create) Jiggle > Jiggle Disk Cache)](../变形器参考/“变形”%28Deform%29菜单/“抖动变形器”%28Jiggle%20Deformer%29菜单/“抖动磁盘缓存”%28Jiggle%20Disk%20Cache%29选项.md) > ![图：选择“变形 (创建)抖动 抖动磁盘缓存”(Deform (Create) Jiggle Jiggle Disk Cach…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 681 字 ≥300，非承重" -->。

2. 将显示“创建磁盘缓存选项”(Create Disk Cache Options)窗口。

3. 设定创建选项。

  请参见[抖动磁盘缓存选项](../变形器参考/“变形”%28Deform%29菜单/“抖动变形器”%28Jiggle%20Deformer%29菜单/“抖动磁盘缓存”%28Jiggle%20Disk%20Cache%29选项.md)。

4. 执行下列操作之一：

  - 单击“创建”(Create)以创建抖动缓存。选项窗口将关闭。

  Maya 创建抖动缓存，并为场景中的每个抖动变形器创建一个永久性抖动缓存文件。这些文件位于当前项目的 *data* 文件夹中，并被命名为 *scene*_jiggle*n*.mcj。
