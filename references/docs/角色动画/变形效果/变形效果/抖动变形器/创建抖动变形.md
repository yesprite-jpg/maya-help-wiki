# 创建抖动变形

您可以先设定创建选项再创建一个变形器，或者使用当前创建选项创建一个变形器并稍后编辑选项。请参见[创建抖动变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-76E1987D-CF05-4E84-9D50-CD651A1E1F8B.htm)。

## 通过绘制调整抖动权重

在为对象或特定点创建抖动变形器后，可以通过绘制各个点的抖动权重的值调整其抖动。通常，在抖动区域的中央区域使用较大的抖动权重值，在抖动区域的边缘使用较小的值，可以获得最佳效果。最好使值从中心到边缘逐渐减小。请参见[绘制抖动权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-7496A4C7-4B78-4098-874A-F458E64A9D3F.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3DE9)。

## 在遮罩的抖动变形器上绘制权重

当您在选定顶点上绘制权重时，笔划仅应用于与选定顶点对应的权重。实际上，未选定的顶点作为遮罩，其中仅选定的顶点受您执行的绘制或泛洪的影响。

在创建遮罩前，您必须首先创建抖动变形器。有关遮罩曲面的详细信息，请参见[限制绘制区域](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-97E0B720-5F75-4078-8E91-A86EB1542EEA)。

## 泛洪抖动变形器

泛洪抖动变形器就像是拿一个巨大的笔刷并将其设置应用到整个簇。当泛洪变形器时，变形器中每个顶点的权重根据为工具设定的值和运算而更改。

若要泛洪簇，请按[绘制抖动权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-7496A4C7-4B78-4098-874A-F458E64A9D3F.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3DE9)下的步骤操作，但不执行步骤 7 中的绘制，而是单击“泛洪”(Flood)按钮或使用热键 Alt + F（Linux 和 Windows）或 Option + F (Mac OS X)。

**注**

提示：

若要平滑抖动权重之间的过渡，请选择平滑绘制操作和泛洪抖动变形器。

## 将权重值映射到抖动变形器

通过使用“绘制簇权重工具”(Paint Cluster Weights Tool)，可以相对 UV 将属性值映射到曲面顶点上。使用映射的值将工具的设置应用到簇顶点。

有关贴图的详细信息，请参见[贴图属性](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-18457833-2003-41E2-A174-BCF0B18957A5)。
