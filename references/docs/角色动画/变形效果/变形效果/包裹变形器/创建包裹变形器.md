# 创建包裹变形器

创建包裹变形器包括创建想要用作包裹影响对象的对象、设定创建选项以及随后的创建包裹变形器。

**注**

注意：

创建变形器之后，请避免更改可变形对象的点（例如，CV、顶点或晶格点）的数量。更改点的数量可能会导致意外的变形效果。请尽可能确保您对可变形对象的拓扑满意之后，再开始使用变形器。可能需要保存该对象的副本，以防将来需要执行进一步的建模。在创建包裹变形器后，还应避免更改包裹影响对象的点（CV 或顶点）的数量。

在创建包裹变形器前，创建要用作包裹影响对象的对象。

**注**

创建包裹变形器所需的时间因包裹影响对象的分辨率而异。分辨率还会影响操纵包裹变形器时的变形计算时间。

创建要用作包裹影响对象的对象

1. 为希望用作包裹影响对象的一个或多个 NURBS 曲面、NURBS 曲线或多边形曲面建模。

  请注意，CV 或顶点的形状和分布可能会影响包裹变形效果。通常，可能会希望影响对象中的点（例如，CV）比要变形的对象中的点少。

2. 定位希望用作包裹影响对象的对象。将它们放置在希望变形的对象周围，以便它们可以影响这些对象。

3. 如果要将多个对象用作一个包裹影响对象，现在请将这些对象分组到一起。必须在将所有这些对象分组到一起之后，再创建包裹变形器。但是，请注意，在已创建包裹变形器之后，还可以添加包裹影响对象。请参见[添加和移除包裹影响对象](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6222A8C7-DC36-4BF8-8747-5A1D29BAAE77.htm#WS17956D7ADBC6E7367963D214117AE310C91-7FF7)。

创建包裹变形器

1. 选择要变形的对象。

2. 选择先前创建的希望用作包裹影响对象的对象或对象组。

3. 选择“变形 > 包裹”(Deform > Wrap) > ![图：选择“变形 包裹”(Deform Wrap) 。 此时将显示“包裹选项”(Wrap Options)窗口。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1025 字 ≥300，非承重" -->。

  此时将显示[“包裹选项”(Wrap Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-291D9A2D-2DD1-4B1C-B4FA-1DC78F72B535.htm)窗口。

4. 设定创建选项。

  请参见[包裹选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-291D9A2D-2DD1-4B1C-B4FA-1DC78F72B535.htm)和[高级变形器选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3D228DBA-C968-4870-9B1D-8C2C60DE6970.htm)。

5. 执行下列操作之一：

  - 单击“创建”(Create)来创建一个包裹变形器。这些选项会关闭。

  Maya 会为每个要变形的对象创建包裹变形器节点。Maya 还会为每个包裹影响对象创建包裹基础对象。“大纲视图”(Outliner)列出包裹基础对象，默认情况下会隐藏这些对象。请注意，如果使用多个影响对象，且因此已将它们分组到一起，那么会将基础对象放置到与影响对象相同的组中。

  创建时间可能会有所不同，具体取决于可变形对象和包裹影响对象的数量和分辨率。

  - 单击“保存”(Save)可保存创建选项，而不创建包裹变形器。选项窗口将保持打开。

  - 单击“重置”(Reset)可重置为默认创建选项。选项窗口将保持打开。

  - 单击“关闭”(Close)可关闭窗口。

创建包裹变形效果

1. 移动、旋转或缩放包裹影响对象。

2. 移动包裹影响对象的点。

3. 编辑添加到包裹影响对象的通道，然后编辑包裹变形器的通道。
