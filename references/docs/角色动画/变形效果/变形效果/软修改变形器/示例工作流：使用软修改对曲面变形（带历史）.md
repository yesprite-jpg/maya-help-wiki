# 示例工作流：使用软修改对曲面变形（带历史）

该示例显示了如何使用“软修改工具”(Soft Modification Tool)交互变形对象。

1. 在“装备”(Rigging)菜单集中，选择“变形 > 软修改”(Deform > Soft Modification)。

2. 单击要修改的曲面的某个部分。

  ![图：单击要修改的曲面的某个部分。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-DFE467CB-1166-4F6F-AE03-1B43D27E46DC.png) <!-- baize:img-hook downloaded=true reason="正文 217 字 <300 且带图" -->

3. 移动操纵器以创建变形。

  ![图：移动操纵器以创建变形。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-677DAA49-AC52-4774-AC9B-8486D41B83EF.png) <!-- baize:img-hook downloaded=true reason="正文 217 字 <300 且带图" -->

4. 单击循环索引以显示衰减操纵器。

  ![图：单击循环索引以显示衰减操纵器。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-749042D1-9F2F-42C4-84DE-0721C96D66D8.png) <!-- baize:img-hook downloaded=true reason="正文 217 字 <300 且带图" -->

5. 拖动衰减操纵器圆形以调整衰减半径。

  ![图：拖动衰减操纵器圆形以调整衰减半径。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-649B1CC9-52A1-4C0C-8178-69AB1799AD97.png) <!-- baize:img-hook downloaded=true reason="正文 217 字 <300 且带图" -->

6. 调整 [softMod](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Nodes/softMod.html) 节点“衰减曲线”(Falloff Curve)以交互方式调整变形的衰减。

7. 移动衰减操纵器以重新定位变形。

  ![图：移动衰减操纵器以重新定位变形。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-64E739AE-A6CC-46B4-AFF2-C6B0F3C48FA7.png) <!-- baize:img-hook downloaded=true reason="正文 217 字 <300 且带图" -->
