# 调整“软修改工具”(Soft Modification Tool)衰减操纵器的大小

可以通过使用 B 热键轻松地调整软修改变形的影响区域。B 热键，结合使用鼠标移动，可以从场景视图中快速调整“软修改工具”(Soft Modification Tool)的衰减操纵器的大小。

调整“软修改工具”(Soft Modification Tool)衰减操纵器的大小

1. 在场景视图中，选择要调整软修改变形衰减的 S 图标。

  ![图：在场景视图中，选择要调整软修改变形衰减的 S 图标。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-745A08CB-8360-4F62-B73A-4563BA24FD03.png) <!-- baize:img-hook downloaded=false reason="正文 311 字 ≥300，非承重" -->

2. 选择“修改 > 变换工具 > 软修改”(Modify > Transformation Tools > Soft Modification)。

  “软修改工具”(Soft Modification Tool)操纵器出现。

  ![图：选择“修改 变换工具 软修改”(Modify Transformation Tools Soft Modificatio…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-1E4F641C-BAD2-4E5B-A12F-3BC965EC6B47.png) <!-- baize:img-hook downloaded=false reason="正文 311 字 ≥300，非承重" -->

3. 按 b 键以显示衰减操纵器，然后按 b 键并拖动以调整操纵器的大小。

  ![图：按 b 键以显示衰减操纵器，然后按 b 键并拖动以调整操纵器的大小。 在您拖动时操纵器大小随之改变，调整软修改变形的衰减…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-0F652C2A-9FF3-4F1F-A07C-DE078B0B54BF.png) <!-- baize:img-hook downloaded=false reason="正文 311 字 ≥300，非承重" -->

  在您拖动时操纵器大小随之改变，调整软修改变形的衰减半径和影响区域。
