# 创建正弦变形器

创建正弦变形器时，可以先设定创建选项，然后再创建变形器，也可以使用当前创建选项立即创建变形器。如果不确定当前的创建选项是什么，则在创建变形器前检查这些选项将可节省以后用于调整变形器属性的时间。

**注**

注意：

在创建变形器后，应避免更改可变形对象的点（例如，CV、顶点或晶格点）的数量。更改点数可能会导致意外的变形效果。请确保在对可变形对象的拓扑满意后再开始使用变形器。保存对象的副本，以防需要进行进一步的建模。

创建正弦变形器

1. 选择要变形的对象。

2. 选择“变形 > (创建)非线性 > 正弦”(Deform > (Create) Nonlinear > Sine) > ![图：选择“变形 (创建)非线性 正弦”(Deform (Create) Nonlinear Sine) 。 此时将显示“正弦…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 604 字 ≥300，非承重" -->。

  此时将显示[“正弦选项”(Sine Options)](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“正弦”%28Sine%29选项.md)窗口。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[正弦选项](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“正弦”%28Sine%29选项.md)和[高级变形器选项](../../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

4. （可选）设定创建选项时，还可以执行下列操作：

  - 选择“编辑 > 保存设置”(Edit > Save Settings)以保存创建选项，并保持选项窗口的打开状态。

  - 选择“编辑 > 重置设置”(Edit > Reset Settings)以将选项重置为其默认值，并保持选项窗口的打开状态。

5. 执行下列操作之一：

  - 单击“创建”(Create)来创建正弦变形器，然后关闭选项窗口。选项窗口将关闭。

  - 单击“应用”(Apply)来创建正弦变形器，并保持选项窗口打开。

  - 单击“关闭”(Close)来关闭该窗口。
