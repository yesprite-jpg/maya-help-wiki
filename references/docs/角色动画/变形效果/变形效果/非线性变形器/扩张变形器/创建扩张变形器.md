# 创建扩张变形器

创建扩张变形器时，可以首先设定创建选项，然后创建变形器，或者可以立即通过当前创建选项创建变形器。如果不确定当前的创建选项，请在创建变形器之前检查这些选项，则可避免您之后花费时间调整变形器的属性。

**注**

注意：

创建变形器后，应该避免更改可变形对象的点（例如，CV、顶点或晶格点）数。更改点的数量可能会导致意外的变形效果。请尽可能确保在获得满意的可变形对象的拓扑之后再开始使用变形器。保存对象的副本，以防日后需要进行进一步的建模。

创建扩张变形器

1. 选择要变形的对象。

2. 选择“变形 > (创建)非线性 > 扩张”(Deform > (Create) Nonlinear > Flare) > ![图：选择“变形 (创建)非线性 扩张”(Deform (Create) Nonlinear Flare) 。 此时将显示“扩…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 736 字 ≥300，非承重" -->。

  此时将显示[“扩张选项”(Flare Options)](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“扩张”%28Flare%29选项.md)窗口。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[扩张选项](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“扩张”%28Flare%29选项.md)和[高级变形器选项](../../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

4. （可选）在设定创建选项时，也可以执行下列操作：

  - 选择“编辑 > 保存设置”(Edit > Save Settings)以保存创建选项而不创建扩张变形器，并保持选项窗口处于打开状态。

  - 选择“编辑 > 重置设置”(Edit > Reset Settings)以将选项重置为其默认值，并保持选项窗口的打开状态。

5. 执行下列操作之一：

  - 单击“创建”(Create)以创建扩张变形器。选项窗口随即关闭。

  - 单击“应用”(Apply)以创建扩张变形器，并保持选项窗口处于打开状态。

  - 单击“关闭”(Close)，关闭该窗口。

创建扩张变形效果

1. 操纵扩张变形器控制柄。

2. 编辑扩张变形器通道和属性。

  有关创建和编辑变形效果的详细信息，请参见[编辑扩张非线性变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9DF10225-79CF-4978-BABA-D580B003B6E9.htm)。
