# 正弦变形器

正弦变形器用于沿正弦波操纵任意可变形对象。正弦变形器对于角色设置和建模非常有用。正弦变形器包含控制柄，可用于直观控制正弦波效果的范围、振幅和波长。

正弦变形器沿正弦波更改对象的形状。
