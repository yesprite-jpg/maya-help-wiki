# 创建弯曲变形器

创建弯曲变形器时，可以先设定创建选项，然后再创建变形器，也可以使用当前创建选项立即创建变形器。如果不确定当前的创建选项是什么，则在创建变形器前检查这些选项将可节省以后用于调整变形器属性的时间。

**注**

注意：

创建变形器之后，请避免更改可变形对象的点（例如，CV、顶点或晶格点）的数量。更改点的数量可能会导致意外的变形效果。尝试在设置对象的拓扑之后再开始使用变形器，然后保存该对象的副本，以防将来需要执行进一步的建模。

创建弯曲变形器

1. 选择要变形的对象。

2. 在“动画”(Animation)菜单集中选择“变形 > (创建)非线性 > 弯曲”(Deform > (Create) Nonlinear > Bend) > ![图：在“动画”(Animation)菜单集中选择“变形 (创建)非线性 弯曲”(Deform (Create) Nonlin…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 703 字 ≥300，非承重" -->。

  此时将显示[“弯曲选项”(Bend Options)](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“弯曲”%28Bend%29选项.md)窗口。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[弯曲选项](../../变形器参考/“变形”%28Deform%29菜单/“非线性”%28Nonlinear%29菜单/“弯曲”%28Bend%29选项.md)和[高级变形器选项](../../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

4. 单击“创建”(Create)以创建弯曲变形器，然后关闭选项窗口。

  （单击“应用”(Apply)以创建弯曲变形器并保持选项窗口处于打开状态。）

  弯曲变形器控制柄会显示在场景中，其节点将列在“通道盒”(Channel Box)中。这些节点包括弯曲控制柄节点（默认名称：bend*n*Handle），弯曲控制柄形状节点 (bend*n*HandleShape) 和弯曲变形器节点（默认名称：bend*n*）。

创建弯曲变形效果

1. 操纵弯曲变形器控制柄。

2. 编辑弯曲变形器通道和属性（请参见[编辑弯曲非线性变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-AAEFF09F-B950-405F-BD97-4D25D0E1CAA4.htm)）或[绘制非线性变形器权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5C916D3A-32A3-4096-8DDE-87A7E4209167.htm)来调整变形效果。

**注**

提示：

如果要为此变形器创建衰减（或渐变效果），以使变形效果在指定的距离后减少或衰减，请使用

组件标记

。请参见

创建变形器衰减

。
