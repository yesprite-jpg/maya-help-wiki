# 编辑弯曲非线性变形器

通过编辑弯曲控制柄节点和[弯曲变形器节点](../../变形器参考/变形器节点/bend.md)可以编辑弯曲变形器的效果。可以通过移动（平移）、旋转和缩放弯曲控制柄来编辑变形效果。还可以编辑弯曲变形器节点的可设定关键帧的属性（通道），这些属性显示在“通道盒”(Channel Box)中。

**注**

提示：

您也可以绘制权重以调整变形器的效果。请参见

绘制非线性变形器权重

。

操纵弯曲变形器控制柄

1. 选择弯曲变形器控制柄节点（默认名称：bend*n*Handle）。

2. 启用“显示操纵器工具”(Show Manipulator Tool)（默认快捷键：T 键）。

  操纵器在弯曲变形器控制柄上显示，使您能够以交互方式编辑[弯曲](../../变形器参考/变形器节点/bend.md)节点属性。

  ![图：启用“显示操纵器工具”(Show Manipulator Tool)（默认快捷键：T 键）。 操纵器在弯曲变形器控制柄上…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-3E4E1C16-EC23-485C-92E0-072F630B31F8.png) <!-- baize:img-hook downloaded=false reason="正文 1117 字 ≥300，非承重" -->

3. 若要更改变形效果，请执行下列任意操作：

  - 在场景中，选择弯曲变形器控制柄上的操纵器，然后使用鼠标中键拖动进行编辑。

    当您拖动时，“通道盒”(Channel Box)中的“上限”(High Bound)、“下限”(Low Bound)和“曲率”(Curvature)值将更新。

  - 移动（平移）、旋转或缩放控制柄。

  - 通过按 Insert 或 Home 键，移动枢轴点，然后再次按 Insert 或 Home 键，可以移动或旋转控制柄枢轴点。

使用“通道盒”(Channel Box)编辑弯曲约束通道

1. 选择弯曲变形器节点（默认名称：bend*n*）。

  选择弯曲变形器节点的一种快捷方法是选择要变形的对象，然后从“通道盒”(Channel Box)（在“输入”(INPUTS)下）选择历史中的弯曲变形器节点。

  请注意，您还可以使用“通道控制”(Channel Control)编辑器（选择[窗口 > 常规编辑器 > 通道控制(Window > General Editors > Channel Control)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-5636D755-8FA3-4E72-83AD-A67956727D55)）控制哪些属性将作为可设定关键帧的属性（通道）在“通道盒”(Channel Box)中列出。

2. 单击要编辑的通道的名称。

3. 在场景中，按住鼠标中键的同时向左或向右拖动以交互方式更改选定通道的值。移动鼠标时，按 Ctrl 键可进行更精细的控制，按 Shift 键可进行更粗略的控制。

编辑弯曲变形器属性

1. 选择[弯曲](../../变形器参考/变形器节点/bend.md)变形器节点（默认名称：bend*n*）。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

3. 编辑[弯曲](../../变形器参考/变形器节点/bend.md)变形器属性。

**注**

提示：

如果要为此变形器创建衰减（或渐变效果），以使变形效果在指定的距离后减少或衰减，请使用

组件标记

。请参见

创建变形器衰减

。

删除弯曲变形器

1. 选择弯曲变形器控制柄。

2. 选择“编辑 > 删除”(Edit > Delete)，或者按 Backspace 或 Delete 键。

  弯曲变形器控制柄、弯曲变形器控制柄形状和弯曲变形器节点都将被删除。但是，该对象仍将调整节点作为输入节点，因此将保留您可能已进行的任何调整。此外，请注意，不会删除构成变形求值的各种输入节点。
