# 创建晶格变形器

创建晶格变形器

1. 选择一个或多个可变形对象。

2. 选择“变形 > (创建)晶格”(Deform > (Create) Lattice) > ![图：选择“变形 (创建)晶格”(Deform (Create) Lattice) 。 将显示“晶格选项”(Lattice O…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 352 字 ≥300，非承重" -->。

  将显示[“晶格选项”(Lattice Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EE9D875-5FEE-4631-81DE-772C2562B5A8.htm)窗口。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[“变形 > (创建)晶格”(Deform > (Create) Lattice)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EE9D875-5FEE-4631-81DE-772C2562B5A8.htm)和[高级变形器选项](../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

4. 单击“创建”(Create)来创建晶格变形器。骨骼晶格框环绕在对象周围。

5. 使用[移动](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865) (**W**)、[旋转](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C2D0F80C-812B-465D-A634-DB6ECFABFCB3) (**E**) 或[缩放](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-487B6A23-E135-45E2-94F1-B0D59D6B6F33) (**R**) 工具来影响晶格点。

  ![图：使用移动 (W)、旋转 (E) 或缩放 (R) 工具来影响晶格点。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-E6E34AFC-BD23-4723-92C5-D948CDD3A117.gif) <!-- baize:img-hook downloaded=false reason="正文 352 字 ≥300，非承重" -->

6. 编辑晶格变形器通道和属性。

  有关创建和编辑变形效果的详细信息，请参见[晶格变形器和晶格屈肌](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-79A66FE5-56CA-42A5-AB86-01FCE2017D6E.htm)和[编辑晶格变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-D97BD9B6-890E-4066-940F-69E15786EF43.htm)。
