# 线变形器

线变形器类似于雕塑器用来改变固定对象形状的电枢。通过线变形器，可以使用一条或多条 NURBS 曲线来更改对象的形状。有关创建线变形器的快速示例，请参见[创建线变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EE5B6BD-6947-44EB-BF6F-B3F47BA006B1.htm)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-F92C7025-BC2B-43DA-9009-7BECB68C6F82.png) <!-- baize:img-hook downloaded=false reason="正文 795 字 ≥300，非承重" -->

通过线变形器，可使用一条或多条 NURBS 曲线更改可变形对象的形状。在角色设置中，线变形器特别适用于设置唇和眉毛的变形。若要创建更强烈的褶皱效果，也可以使用褶皱变形器。线变形器也可以在建模期间用于 NURBS 或多边形对象的成形。

## 影响线和基础线

用于创建变形的“NURBS 曲线”(NURBS curves)称为影响线，或者就简单地称为线。创建线变形器时，将为每一影响线创建另一条称为基础线的曲线。影响线提供的变形效果基于影响线和基础线之间的差异。

## 限制曲线

限制曲线是可用于限制变形区域的曲线。同其他曲线一样，您可以移动、旋转或缩放限制曲线。您还可以编辑限制曲线的形状。移动、旋转、缩放或编辑限制曲线可更改变形效果。可以创建不带或带有限制曲线的线变形器。创建不带限制曲线的线变形器的工作流少于创建带有限制曲线的线变形器。此外，还可以通过稍后添加限制曲线或使用其他各种方法来限制变形区域。请参见[创建不带限制曲线的线变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EE5B6BD-6947-44EB-BF6F-B3F47BA006B1.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3A47)。

创建带有限制曲线的线变形器类似于创建不带限制曲线的线变形器。主要区别在于，选择要用作影响线的曲线后，再选择要用作每个影响线的限制曲线的其他曲线。请参见[创建带有限制曲线的线变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EE5B6BD-6947-44EB-BF6F-B3F47BA006B1.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3A35)。

## 线衰减定位器

线衰减定位器提供了一种沿影响曲线创建局部化变形效果的方式。

## 变形器操作顺序

如果在将线变形器应用于网格之前对其应用了其他变形器，您可能会发现线变形器未达到预期效果。如果出现这种情况，请尝试使用“属性编辑器”(Attribute Editor)的“线”(Wire)选项卡中的**“绑定到原始几何体”(Bind to Original Geometry)**属性。通过启用此选项，可以明确指定线变形器进行变形时所基于的几何体。
