# 在角色上烘焙变形器

可以在角色上烘焙变形器以便为具有有限变形器支持的游戏引擎近似计算变形。

烘焙角色的变形器

1. 选择“蒙皮 > 烘焙变形到蒙皮权重”(Skin > Bake Deformation to Skin Weights)。此时将显示[“烘焙变形器工具”(Bake Deformer Tool)](../变形器参考/变形器工具/烘焙变形器工具%28Bake%20Deformer%20Tool%29.md)窗口。

2. 右键单击角色层次顶部（例如，髋部），然后从上下文菜单中选择“选择层次”(Select Hierarchy)。此时将选择整个角色骨架。

3. 按 Shift 键并选择角色网格。

  ![图：按 Shift 键并选择角色网格。 选择骨架和网格](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FF6DECB5-490F-4243-8C4F-4004CAABC538.png) <!-- baize:img-hook downloaded=false reason="正文 541 字 ≥300，非承重" -->

  选择骨架和网格

4. 单击“烘焙变形器工具”(Bake Deformer Tool)窗口中的“源”(Source)，将角色的特性添加到“源”(Source)字段。

5. 现在，对目标角色执行相同操作。（右键单击髋部关节，选择“选择层次”(Select Hierarchy)，然后按 Shift 键并选择网格。）

6. 单击“烘焙变形器工具”(Bake Deformer Tool)窗口中的“目标”(Destination)，将角色的特性添加到“目标”(Destination)字段。

7. 单击“应用”(Apply)。源角色将执行一系列快速变换来计算变形器权重。

  ![图：单击“应用”(Apply)。源角色将执行一系列快速变换来计算变形器权重。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-DE0CE7CE-9A3A-41FE-BD5C-287D0E05BB61.gif) <!-- baize:img-hook downloaded=false reason="正文 541 字 ≥300，非承重" -->

可以通过在[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中比较两个角色来验证变形器是否已转化为簇变形器；目标角色将没有变形器选项卡，蒙皮簇除外。
