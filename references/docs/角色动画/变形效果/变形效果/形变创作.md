# 形变创作

形变创作为您提供了不同的工具来完成形状变形任务。 本部分包含有关使用融合变形、目标形状和基础形状以创建基本姿势变形的信息。

形变创作为您提供了不同的工具来完成形状变形任务。

使用融合形变变形器，您可以将对象的形状更改为目标形状的图形，以便在角色上创建面部动画等等。此外，您还可以使用融合变形校正蒙皮角色身体上的变形。您可以使用[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)为对象创建并控制所有融合形变变形器，还可以创建目标形状、设置其权重和关键帧、创建中间帧形状、创建组合图形等。

请参见[融合变形工作流](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-7235BE66-24B2-4765-B1B7-E588AC0481E4.htm)，了解使用融合变形的不同方法的信息。另请参见[目标形状、基础形状和融合变形](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-01EFEC6D-41EA-46AA-81B1-C171DA4316F4.htm)，获取有助于您了解如何使用融合变形的基本信息。

可以结合使用融合变形与姿势插值系统创建姿势空间变形。这样可以根据特定姿势为蒙皮角色和绑定角色添加修正或增强形状，并使这些形状在从一个姿势移动到另一个姿势时进行插值。您可以使用[姿势编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)创建姿势插值器及其姿势和融合变形，然后控制它们，其中包括更改这些变形的插值方式。

请参见[姿势空间变形 (PSD)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-45D389D6-B8E4-4225-B27B-9927BB61C28D.htm) 中的主题（特别是[创建姿势空间变形](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-00699C13-8CA1-450C-937D-57C7B3DFD8C6.htm)），以便快速入门。
