# 在曲线变形器上创建点

在曲线定位器上创建点

1. 创建 NURBS 曲线。

2. 若要在曲线上选择曲线点，请在该曲线上单击鼠标右键 (![图：若要在曲线上选择曲线点，请在该曲线上单击鼠标右键 ()，然后从标记菜单中选择“曲线点”(Curve Point)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 575 字 ≥300，非承重" -->)，然后从标记菜单中选择“曲线点”(Curve Point)。

3. 单击要在曲线定位器约束上创建点的曲线。曲线点显示为小的黄色框。

4. 沿曲线拖动，以调整点在曲线上的位置。

  拖动时，就会移动曲线点。曲线点的位置是根据曲线的 U 参数定义的。

5. 选择“变形 > 曲线上的点”(Deform > Point On Curve) > ![图：选择“变形 曲线上的点”(Deform Point On Curve) 。 将显示“曲线上的点选项”(Point On …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 575 字 ≥300，非承重" -->。

  将显示[“曲线上的点选项”(Point On Curve Options)](../变形器参考/“变形”%28Deform%29菜单/“曲线上的点”%28Point%20On%20Curve%29选项.md)窗口。

6. 设定选项。也可以执行下列操作：

  - 选择“编辑 > 保存设置”(Edit > Save Settings)来保存约束选项并保持选项窗口打开。

  - 选择“编辑 > 重置设置”(Edit > Reset Settings)来重置为默认约束选项并保持选项窗口打开。

7. 执行下列操作之一：

  - 单击“创建”(Create)，在曲线定位器约束上创建点。选项窗口将关闭。

    Maya 使用默认的“曲线上的点”选项，在曲线点上创建定位器。现在曲线点约束到定位器。

    Maya 为每条曲线创建一个最小平方修改器节点（默认名称：leastSquaresModifier*n*）。

  - 单击“应用”(Apply)在曲线定位器约束上创建点，并保持选项窗口打开。

  - 单击“关闭”(Close)以关闭“曲线上的点选项”(Point On Curve Options)窗口。
