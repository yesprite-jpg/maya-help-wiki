# 编辑最小平方修改器属性

最小平方修改器节点控制曲线点与定位器的粘滞距离。如果在曲线上使用多个曲线上的点定位器约束，或者曲线的形状非常复杂，则曲线可能无法始终同时粘滞到所有曲线上的点定位器约束。

使用“属性编辑器”(Attribute Editor)编辑最小平方修改器属性

1. 选择一个定位器用作曲线上的点定位器约束。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。在“属性编辑器”(Attribute Editor)中，转到最小平方修改器节点（默认名称：leastSquaresModifier*n*），这是定位器的输出。（在“通道盒”(Channel Box)中，该节点列在定位器的“输出”下面）。

3. 展开以下标题，查看可用属性：“最小平方修改器属性”(Least Squares Modifier Attributes)、“点约束”(Point Constraints)、“节点行为”(Node Behavior)和“附加属性”(Extra Attributes)。
