# 编辑褶皱变形效果

创建褶皱变形器之后，可以如下列几节中所述，编辑变形器的效果。

## 操纵褶皱变形器的簇变形器控制柄

用于操纵褶皱变形器的簇变形器控制柄（C 图标）的技术与用于操纵常规簇变形器控制柄的相同。有关操纵簇变形器控制柄的信息，请参见[操纵簇控制柄（C 图标）](../簇变形器/关于编辑簇变形效果.md#WS17956D7ADBC6E736-1842C6BB117AE30E92A-7FFC)。

## 编辑褶皱变形器的簇变形器

用于编辑褶皱变形器的簇变形器的技术与用于编辑常规簇变形器的相同。有关编辑簇变形器的信息，请参见[编辑簇变形效果](../簇变形器/关于编辑簇变形效果.md)。

## 编辑褶皱变形器的线变形器

用于编辑褶皱变形器的线变形器的技术与用于编辑常规线变形器的相同。有关编辑线变形器的信息，请参见[编辑线变形器](../线变形器/编辑线变形器.md)。
