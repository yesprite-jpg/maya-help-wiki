# 使用变形变形器镜像几何体

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-57E9DA6F-DB97-48FB-859F-5FA7A7471DF8.png) <!-- baize:img-hook downloaded=false reason="正文 344 字 ≥300，非承重" -->

变形变形器可用于快速镜像几何体。

在本示例中，变形变形器镜像效果将应用于面部模型，并且表情沿 X 轴从角色面部的一侧镜像到另一侧。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-E41DFEE8-CA5B-4045-9613-E61E7C3C3273.gif) <!-- baize:img-hook downloaded=false reason="正文 344 字 ≥300，非承重" -->

变形变形器镜像面部表情。

1. 选择要镜像的几何体。

2. 在[“变形”(Deform)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C1B5085D-3229-4BE8-989E-95C460ADB79C.htm)中，选择“变形”(Morph) > ![图：在“变形”(Deform)菜单中，选择“变形”(Morph) 。此时将显示变形选项(Morph options)窗口。（…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 344 字 ≥300，非承重" -->。此时将显示[变形选项(Morph options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DAC2AA0B-3E70-4F5C-A656-1219219092A1.htm)窗口。（“变形”(Deform)菜单显示在“建模”(Modeling)(**F2**)、“绑定”(Rigging)(**F3**) 或“动画”(Animation)(**F4**) 菜单集中。）

3. 将“变形模式”(Morph Mode)设置为“镜像”(Mirror)。

4. 在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)的“变形”(Morph)选项卡中，从**“镜像方向”(Mirror Direction)**菜单中选择反射轴。

  ![图：在属性编辑器(Attribute Editor)的“变形”(Morph)选项卡中，从“镜像方向”(Mirror Dire…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-E5388EF8-5E74-4F2B-B25F-12F009C79ECF.gif) <!-- baize:img-hook downloaded=false reason="正文 344 字 ≥300，非承重" -->

  面部的右侧从 +x 轴更改为 -y 轴
