# 创建线变形器

若要创建线变形器，可以使用“线工具”(Wire Tool)。所创建的线变形器的特征取决于“线工具”(Wire Tool)的工具设置。默认情况下，“线工具”(Wire Tool)会被设定为创建不带限制曲线的线变形器。

**注**

注意：

创建变形器之后，请避免更改可变形对象的点（例如，CV、顶点或晶格点）的数量。更改点数可能会导致意外的变形效果。请确保在对可变形对象的拓扑满意后再开始使用变形器。保存该对象的副本，以防需要进行进一步的建模。

指定线工具设置

1. 选择“变形 > (创建)线” > ![图：选择“变形 (创建)线” (Deform (Create) Wire)。 此时将显示线工具(Wire Tool)选项窗口…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Create) Wire)。

  此时将显示[线工具(Wire Tool)](../变形器参考/变形器工具/线工具%28Wire%20Tool%29.md)选项窗口。

2. 设置工具选项。

创建不带限制曲线的线变形器

1. 将“线工具”(Wire Tool)的“限制曲线”(Holders)设置设定为禁用（默认为禁用）。

2. 创建要用作影响线的曲线。为获得最佳效果，请将它们放置在可变形对象上或可变形对象附近。

3. 选择“变形 > (创建)线” > ![图：选择“变形 (创建)线” (Deform (Create) Wire)。此时将显示线工具(Wire Tool)选项窗口。…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Create) Wire)。此时将显示[线工具(Wire Tool)](../变形器参考/变形器工具/线工具%28Wire%20Tool%29.md)选项窗口。

  光标将变为十字线图标，并且“线工具”(Wire Tool)图标将显示在“工具箱”(Tool Box)中。现在即可使用“线工具”(Wire Tool)，基于“线工具”(Wire Tool)的当前工具设置创建线变形器。

  “帮助行”会显示信息，以引导您完成创建线变形器的过程。

4. 选择要变形的对象，然后按 Enter 键（Linux 和 Windows）或 Return 键 (Mac OS X)。

5. 选择要用作影响线的所有曲线。

  如果仅对象的曲面上的曲线是要用作影响线的曲线，请在对象上的所有曲线上拖动光标。“线工具”(Wire Tool)会自动仅选择曲线。

6. 按 Enter 键或 Return 键。

  会基于“线工具”(Wire Tool)的设置创建一个线变形器。选定曲线现在是可用于变形选定对象的影响线。

  会为每条影响线创建基础线。会在“大纲视图”(Outliner)中列出基础线。默认情况下，在场景中不会显示基础线，但基础线确实会影响变形效果。线节点会基于每条影响线与其基础线之间的差异来计算变形效果。

  已创建变形器集。变形器集包括可能会受线变形器影响的所有可变形对象的点。

  有关创建和编辑变形效果的详细信息，请参见[编辑线变形效果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-F75CADC0-499C-4C8D-A4B6-4ED2087EDFDF.htm)。

创建变形效果

1. 移动、旋转或缩放影响线。

2. 编辑线变形器的通道。

**注**

提示：

如果要为此变形器创建衰减（或渐变效果），以使变形效果在指定的距离后减少或衰减，请使用

组件标记

。请参见

创建变形器衰减

。

创建带有限制曲线的线变形器

1. 将“线工具”(Wire Tool)的“限制曲线”(Holders)设置设定为启用（默认为禁用）。

2. 在可变形对象上或其附近，创建要用作影响线的曲线。

3. 在可变形对象上或其附近，创建要用作限制曲线的曲线。

4. 选择“变形 > (创建)线”(Deform > (Create) Wire)以打开[线工具](../变形器参考/变形器工具/线工具%28Wire%20Tool%29.md)。

  光标将变为十字线，并且“线工具”(Wire Tool)图标将显示在“工具箱”(Tool Box)中。现在即可使用“线工具”(Wire Tool)，基于“线工具”(Wire Tool)的当前工具设置创建线变形器。

  请注意，“帮助行”会显示信息，以引导您完成创建线变形器的过程。

5. 选择要变形的对象，然后按 Enter 键（Linux 和 Windows）或 Return 键 (Mac OS X)。

6. 选择要用作影响线的曲线，然后按 Enter 键或 Return 键。

7. 选择一条限制曲线，然后按 Enter 键或 Return 键。一条影响线仅可以有一条限制曲线。

8. 通过选择空的空间清除选择列表，然后按 Enter 键或 Return 键。

  **注**

  可以将一条限制曲线指定给多条影响线。若要执行该操作，请拾取一条将成为影响线的曲线，按 Enter 键或 Return 键，然后选择将成为限制曲线的曲线，再次按 Enter 键或 Return 键。拾取下一条将成为影响线的曲线，按 Enter 键或 Return 键，然后选择相同的限制曲线，再次按 Enter 键或 Return 键。对于将指定限制曲线的每条影响线曲线，继续该过程。

9. 准备好创建线变形器后，请通过选择空的空间清除选择列表，然后按 Enter 键或 Return 键。

  会基于“线工具”(Wire Tool)的工具设置创建一个线变形器。选定曲线现在是可用于变形选定对象的影响线。

  会为每条影响线创建基础线。会在“大纲视图”(Outliner)中列出基础线。默认情况下，在场景中不会显示基础线，但基础线确实会影响变形效果。线节点会基于每条影响线与其基础线之间的差异来计算变形效果。

  已创建变形器集。变形器集包括可能会受线变形器影响的所有可变形对象的点。

创建变形效果

1. 移动、旋转或缩放影响线。

2. 编辑线变形器的通道。

  有关创建和编辑变形效果的详细信息，请参见下一节，[编辑线变形效果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-F75CADC0-499C-4C8D-A4B6-4ED2087EDFDF.htm)。

添加影响线

1. 选择要添加到变形器的曲线。

2. 按 Shift 键并单击变形器中的任何线，可选择要将曲线作为影响线添加到其中的变形器。

3. 选择“变形 > (编辑)线 > 添加” > ![图：选择“变形 (编辑)线 添加” (Deform (Edit) Wire Add)。请参见线添加选项。 选定曲线将变成线变…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Edit) Wire > Add)。请参见[线添加选项](../变形器参考/“变形”%28Deform%29菜单/“线”%28Wire%29菜单/线添加选项%28Wire%20Add%20Options%29.md)。

  选定曲线将变成线变形器的影响线。

移除影响线

1. 选择要作为影响线移除的曲线。

2. 选择“变形 > (编辑)线 > 移除” > ![图：选择“变形 (编辑)线 移除” (Deform (Edit) Wire Remove)。请参见线移除选项。 选定曲线将不…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Edit) Wire > Remove)。请参见[线移除选项](../变形器参考/“变形”%28Deform%29菜单/“线”%28Wire%29菜单/“线%20移除”%28Wire%20Remove%29选项.md)。

  选定曲线将不再是影响线。

重置影响线

1. 选择要重置的影响线。

2. 选择“变形 > (编辑)线 > 重置” > ![图：选择“变形 (编辑)线 重置” (Deform (Edit) Wire Reset)。请参见线重置选项。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Edit) Wire > Reset)。请参见[线重置选项](../变形器参考/“变形”%28Deform%29菜单/“线”%28Wire%29菜单/“线重置”%28Wire%20Reset%29选项.md)。

显示基础线

1. 选择影响线。

2. 选择“变形 > (编辑)线 > 显示基础线”(Deform > (Edit) Wire > Show Base Wire)。

创建线组

1. 选择影响线。

2. 选择“变形 > (编辑)线 > 父基础线” > ![图：选择“变形 (编辑)线 父基础线” (Deform (Edit) Wire Parent Base Wire)。请参见线…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Edit) Wire > Parent Base Wire)。请参见[线父基础线选项](../变形器参考/“变形”%28Deform%29菜单/“线”%28Wire%29菜单/“线%20父基础线”%28Wire%20Parent%20Base%20Wire%29选项.md)。

会创建一个线组，其中包含影响线和基础线。会在命名影响线之后命名线组，并会在“大纲视图”(Outliner)中列出该线组。

## 线变形器快速入门

本节介绍如何尽可能快地创建典型的线变形器。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-7642C2F3-E6C6-4E1D-8465-3FE9B7A4FFD0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->

在本示例中，将使用 S 形曲线变形曲面，并用圆形限制变形区域。

示例：创建 NURBS 平面

1. 创建一个“宽度”(Width)为 40、“长度”(Length)为 40、“U 向面片数”(Patches U)为 40、“V 向面片数”(Patches V)为 40、且包含“曲面次数立方”(Surface Degree Cubic)的 NURBS 平面。

2. 为影响线创建曲线。使用“CV 曲线工具”(CV Curve Tool)或“EP 曲线工具”(EP Curve Tool)，在平面的中心区域绘制一条 S 形曲线。

  ![图：为影响线创建曲线。使用“CV 曲线工具”(CV Curve Tool)或“EP 曲线工具”(EP Curve Tool)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FA01E890-906E-4419-93BE-9207AFF1C114.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->

3. 为限制变形区域创建一个圆形。对于本示例，圆形将包围平面上的 S 形曲线。

  ![图：为限制变形区域创建一个圆形。对于本示例，圆形将包围平面上的 S 形曲线。 将使用圆形来限制变形区域。限制变形区域的曲线称…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-46F2440C-79C4-4EEE-925F-F27E31214D35.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->

  将使用圆形来限制变形区域。限制变形区域的曲线称为限制曲线。

4. 请通过执行下列操作创建线变形器：

  - 选择“变形 > (创建)线” > ![图：选择“变形 (创建)线” (Deform (Create) Wire)。这将打开线工具(Wire Tool)选项面板。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->(Deform > (Create) Wire)。这将打开[线工具(Wire Tool)](../变形器参考/变形器工具/线工具%28Wire%20Tool%29.md)选项面板。

  - 在“工具设置”(Tool Settings)窗口中，启用“限制曲线”(Holders)（默认为禁用）。

  - 关闭“工具设置”(Tool Settings)窗口。

  请注意，在工作区中，光标现在呈十字形，指示正在使用“线工具”(Wire Tool)。

  请确保严格按照以下顺序执行接下来的四个步骤。

  - 选择平面，然后按 Enter 键（Linux 和 Windows）或 Return 键 (Mac OS X)。

  - 选择 S 形曲线，然后按 Enter 键或 Return 键。

  - 选择圆形，然后按 Enter 键或 Return 键。

  - 最后，在工作区中不选择任何项目，然后按 Enter 键或 Return 键。

  不选择任何项目会告知 Maya 您已完成限制曲线的选择，并告知 Maya 要创建线变形器。

  Maya 现在会创建线变形器。现在可以操纵 S 形曲线来创建变形效果。请注意，仅圆形内的区域可能会受到影响。

5. 请通过执行下列操作创建变形：

  - 选择 S 形曲线。

  - 向上移动 S 形曲线。

  - 旋转 S 形曲线，以获得漩涡“轮”的变形效果。

    ![图：旋转 S 形曲线，以获得漩涡“轮”的变形效果。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-4441C375-BE77-4725-899D-41C8982F0E22.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->

  平面会向上变形，就好像被吸引到 S 形曲线一样。

  线变形器会使用 S 形曲线来影响变形的形状，因此将该曲线称为影响线。同时，因为圆形限制变形区域，所以将该圆形称为限制曲线。

  ![图：请通过执行下列操作创建变形： 选择 S 形曲线。 向上移动 S 形曲线。 旋转 S 形曲线，以获得漩涡“轮”的变形效果。…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-3468F565-9B47-4376-984B-5EE34EBF75A8.png) <!-- baize:img-hook downloaded=false reason="正文 3276 字 ≥300，非承重" -->
