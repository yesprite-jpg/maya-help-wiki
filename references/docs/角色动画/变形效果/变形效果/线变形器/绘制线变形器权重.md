# 绘制线变形器权重

通过使用“绘制线权重工具”(Paint Wire Weights Tool)设置，您可以用 Artisan 笔刷对目标对象的线权重进行应用、分配和移除。因此可以自由设定线权重，以创建有机的非均匀和非对称变形效果。

还可以使用“镜像变形器权重选项”(Mirror Deformer Weights Options)，将线变形器权重从一个曲面映射到另一个曲面，或在同一曲面内进行映射。请参见[镜像变形器权重](../修改变形器/镜像变形器权重.md)。

绘制线权重时，也可以导入或导出线权重贴图。请参见[导入线权重贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DF0CCC32-C8BC-4C46-A0E3-4E349E738982.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3975)和[导出线权重贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DF0CCC32-C8BC-4C46-A0E3-4E349E738982.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-397E)。

## 导入和导出线权重贴图

导出线权重贴图

1. 为目标形状绘制线权重，直至获得需导出的变形或外观，以作为贴图。

2. 选择变形的目标形状。

3. 打开工具设置中的“属性贴图”(Attribute Maps)区域，然后打开“导出”(Export)区域。

4. 设定“导出”(Export)设置，然后单击“导出”(Export)按钮。有关“导出”(Export)设置的说明，请参见[绘制线权重工具设置](../变形器参考/变形器工具/绘制线权重工具%28Paint%20Wire%20Weights%20Tool%29.md#WS17956D7ADBC6E736-6A42F0D5117AE3104C1-7FF6)。

  显示“导出”(Export)浏览器窗口。

5. 浏览到要将贴图保存到的位置，指定贴图的名称，然后单击“导出”(Export)。默认情况下，Maya 将贴图放置在当前项目的 sourceimages 文件夹中。

  将目标形状的当前变形另存为属性贴图。

导入线权重贴图

1. 选择变形的目标形状。

2. 打开“绘制线权重工具(Paint Wire Weights Tool)”设置中的“属性贴图”(Attribute Maps)区域，然后打开“导入”(Import)区域。

3. 设定“导入”(Import)设置，然后单击“导入”(Import)按钮。有关“导入”(Import)设置的说明，请参见[绘制线权重工具设置](../变形器参考/变形器工具/绘制线权重工具%28Paint%20Wire%20Weights%20Tool%29.md#WS17956D7ADBC6E736-6A42F0D5117AE3104C1-7FF6)。

  显示“导入”(Import)浏览器窗口。

4. 浏览要导入常驻文件的位置，选择贴图文件，然后单击“导入”(Import)。

  目标形状根据导入的属性贴图中所指定的工具设置进行变形。
