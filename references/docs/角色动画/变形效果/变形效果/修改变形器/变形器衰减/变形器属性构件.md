# 变形器属性构件

将变形器添加到几何体时，“变形器属性”(Deformer Attributes)构件就会显示在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中。可使用此表修改衰减效果。

本主题定义“变形器属性”(Deformer Attributes)构件中的设置。有关为变形创建衰减效果的信息，请参见[创建变形器衰减](创建变形器衰减.md)。

“组件标记”(Component Tags)属性以表格格式显示：

#### “变形器属性”(Deformer Attributes)表

在此表中的任意位置单击鼠标右键，然后选择**“列可见性”(Column Visibility)**以在“变形器属性”(Deformer Attributes)表中显示或隐藏列。

#### 索引(Index)

数组中的衰减索引（放置）。

#### 组件标记(Component Tag)

要变形的几何体的“组件标记”(Component Tag)表达式。默认情况下，所有组件都已使用。双击此表单元格以从可用“组件标记”(Component Tags)列表中进行选择。

#### 组 ID(Group ID)

默认情况下，将隐藏此列。若要显示它，请单击鼠标右键，然后从**“列可见性”(Column Visibility)**选项中选择它。

#### 衰减(Falloff)

## “变形器属性”(Deformer Attributes)快捷菜单

在“变形器属性”(Deformer Attributes)表中单击鼠标右键以显示一个菜单，其中包含用于添加、编辑或转化变形器衰减效果的选项。

| 选项 | 功能 |
|---|---|
| **选择结构成员** | 亮显标记了组件的几何体。 |
| **选择衰减(Select Falloff)** | 切换到[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中的关联衰减选项卡，您可以在其中修改与选定衰减相关的设置。 |
| **指定...衰减(Assign...falloff)** | 创建“基本体”(Primitive)、“均匀”(Uniform)、“接近度”(Proximity)、“子集”(Subset)、“融合”(Blend)、“组件”(Component)或“传递”(Transfer)变形器衰减。有关详细信息，请参见[创建变形器衰减](创建变形器衰减.md)。 |
| **断开衰减(Disconnect Falloff)** | 使用衰减节点切断连接，但不删除它们。 |
| **删除衰减(Delete Falloff)** | 移除衰减。 |
| **绘制组件衰减(Paint Component Falloff)** | 仅适用于组件衰减。请参见[创建变形器衰减](创建变形器衰减.md)主题中的**“组件衰减：绘制变形器权重”**。 |
| **移除输入** | 清除来自衰减节点的任何输入连接。 |
| **转化为组件标记(Convert to Component Tags)** | 将选择项转化为[组件标记](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-788B1C8B-7F45-4862-BC42-0A334DFECFD3.htm)。 |
| **权重可视化(Weights Visualization)** | 使用颜色渐变设置将衰减权重显示切换为颜色渐变。有关详细信息，请参见[可视化变形器权重](../../使用变形器/可视化变形器权重.md)。 ![图：使用颜色渐变设置将衰减权重显示切换为颜色渐变。有关详细信息，请参见可视化变形器权重。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-A9E92676-41FE-4946-9558-EB88BF2F5F4B.gif) <!-- baize:img-hook downloaded=false reason="正文 1769 字 ≥300，非承重" --> |
| **列可见性(Column Visibility)** | 显示或隐藏列中的元素。 |
