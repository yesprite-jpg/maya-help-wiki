# 镜像变形器权重

可以从一个曲面到另一个曲面，或者在相同的曲面内镜像变形器权重。也可以在曲面的选定组件上镜像变形器权重。

与镜像蒙皮权重类似，镜像变形器权重时，请注意以下事项以获得最佳效果：

- 曲面应在全局轴上居中，或至少应沿要围绕其镜像的轴对齐。

- 曲面应处于跨镜像平面对称的姿势。

镜像变形器权重

1. 执行下列操作之一：

  - 若要在整个曲面上镜像变形器权重，请选择该曲面。

  - 若要在选定组件上镜像变形器权重，请将指针定位到该曲面上方，单击鼠标右键，然后选择“控制顶点”(Control Vertex)或“顶点”(Vertex)。选择要从其镜像的一侧上的组件和要镜像到的一侧上的组件。

2. 从主菜单栏中，选择“变形 > 编辑 > 镜像变形器权重”(Deform > Edit > Mirror Deformer Weights) > ![图：从主菜单栏中，选择“变形 编辑 镜像变形器权重”(Deform Edit Mirror Deformer Weights…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 433 字 ≥300，非承重" -->。

3. 在[镜像变形器权重选项(Mirror Deformer Weights Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C2E7D525-BF3E-4287-8A7C-DE91FCE45157.htm)窗口中设置选项。

4. 单击“镜像”(Mirror)。
