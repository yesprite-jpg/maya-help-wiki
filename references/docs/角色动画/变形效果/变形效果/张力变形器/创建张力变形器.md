# 创建张力变形器

使用“张力”(Tension)变形器可在不过度挤压和拉伸曲面的情况下模拟曲面张力。它使用网格顶点之间的连接来保持这些顶点之间的（相对）长度。

若要创建“张力”(Tension)变形器，请执行以下操作：

1. 选择要操纵的点或整个对象。

2. 选择“变形 > (创建)张力”(Deform > (Create) Tension) > ![图：选择“变形 (创建)张力”(Deform (Create) Tension) 。 此时将显示张力选项(Tension O…](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 295 字 <300 且带图" -->。

  此时将显示[张力选项(Tension Options)](../变形器参考/“变形”%28Deform%29菜单/张力选项%28Tension%20Options%29.md)。

3. 单击“基本”(Basic)和“高级”(Advanced)选项卡，然后设定创建选项。

  请参见[张力选项](../变形器参考/“变形”%28Deform%29菜单/张力选项%28Tension%20Options%29.md)和[高级变形器选项](../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。
