# 绘制纹理变形器权重

可以使用“绘制纹理权重工具”(Paint Texture Weights Tool)绘制纹理变形器权重。

也可以使用“镜像变形器权重选项”(Mirror Deformer Weights Options)镜像纹理变形器权重。请参见[镜像变形器权重](../修改变形器/镜像变形器权重.md)。

在纹理上绘制权重

1. 选择包含要在其上绘制权重的纹理的曲面。

2. 选择“着色 > 对所有项目进行平滑着色处理”(Shading > Smooth Shade All)或按默认热键 5 以切换到平滑着色模式。

3. 选择“变形 > (绘制权重)纹理变形器”(Deform > (Paint Weights) Texture Deformer) > ![图：选择“变形 (绘制权重)纹理变形器”(Deform (Paint Weights) Texture Deformer) …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1101 字 ≥300，非承重" -->。

  在“绘制属性工具”(Paint Attributes Tool)中，将显示“绘制纹理权重工具”(Paint Texture Weights Tool)设置。请参见[绘制纹理权重工具](../变形器参考/变形器工具/绘制纹理变形器权重工具%28Paint%20Texture%20Deformer%20Weights%20Tool%29.md)。

  **注**

  “绘制纹理权重工具”(Paint Texture Weights Tool)会自动检测曲面上的纹理，然后选择一个进行绘制。

4. 在“显示”(Display)区域中，启用“颜色反馈”(Color Feedback)。颜色反馈可帮助识别曲面上的权重，方法是将权重表示为灰度值（值越小越暗，值越大越亮）。

  **注**

  提示：

  可以使用默认热键 Alt+c（或在 Mac OS X 上为 Option+c），在“绘制属性工具”(Paint Attributes Tool)外部启用和禁用“颜色反馈”(Color Feedback)。

5. 选择要绘制的纹理。在“绘制属性工具”(Paint Attributes Tool)的“绘制属性”(Paint Attributes)区域中，单击 texture*n*.weights 按钮，然后从弹出菜单中选择适当的纹理权重名称。

  请注意，一次仅可以在一个纹理上绘制权重。如果选择多个纹理，则只能在活动纹理（提供颜色反馈）上绘制权重。

  如果曲面只有一个纹理，则可以单独选择曲面。

  选定纹理变为白色，表示权重值为 1（默认值）。

  **注**

  提示：

  如果在单个曲面上绘制，可以跳过步骤 3，在不打开“工具设置”(Tool Settings)窗口的情况下选择纹理，方法是右键单击曲面，并从“绘制”(Paint)命令子菜单中选择适当的纹理权重名称。

6. 选择一个笔刷、绘制操作和值，并在必要时定义其他设置。

7. 在纹理中拖动笔刷。

  **注**

  提示：

  可以从一个纹理快速拾取权重值，并使用热键在另一个纹理或同一个纹理上绘制这些权重值。

  - 选择具有要拾取权重值的纹理。

  - 按住“拾取颜色模式”(Pick Color Mode)热键（默认热键：/），单击具有要拾取权重的纹理的区域，然后释放热键。

  - 如果要在同一纹理上绘制拾取的权重，则在纹理上拖动笔刷。

  如果在另一个纹理上绘制拾取的权重，请选择该纹理，然后在其上拖动笔刷。
