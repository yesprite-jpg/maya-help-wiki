# 创建纹理变形器

创建纹理变形器时会创建两个节点：textureDeformer 和 textureDeformerHandle。TextureDeformer 会变形网格，同时 textureDeformerHandle 控制变形的方向。默认情况下将隐藏 textureDeformerHandle。您可以使其显示在**“属性编辑器”(Attribute Editor)**中，方法是选择“方向”(Direction)作为控制柄；或使其显示在 **TextureDeformer** 工具选项中，方法是选择“方向”(Direction)作为控制柄。

创建纹理变形器

1. 选择可变形对象。

2. 选择“变形 > 纹理”(Deform > Texture) >![图：选择“变形 纹理”(Deform Texture) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 395 字 ≥300，非承重" -->。

3. 在显示的[纹理选项](../变形器参考/“变形”%28Deform%29菜单/纹理选项%28Texture%20Options%29.md)中，设置所需的选项。

4. 在**“属性编辑器”(Attribute Editor)**中，单击纹理属性旁边的贴图按钮 ![图：在“属性编辑器”(Attribute Editor)中，单击纹理属性旁边的贴图按钮 。 系统将显示“创建渲染节点”(Cr…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6DE48C0E-BA28-4944-8596-FBC1466F2975.png) <!-- baize:img-hook downloaded=false reason="正文 395 字 ≥300，非承重" -->。

  系统将显示[“创建渲染节点”(Create Render Node)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4918C294-FAAD-45B5-A896-92161177EEED)窗口。

5. 选择并操纵纹理控制柄。
