# 使用组件标记编辑变形器成员身份

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-18F963A9-A2D7-4CA7-B4B1-EDBC323666BF.png) <!-- baize:img-hook downloaded=false reason="正文 1438 字 ≥300，非承重" -->

使用组件标记表达式可动态定义变形器成员身份。可以在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中每个形状节点的“组件标记”(Component Tags)区域中编辑“组件标记”(Component Tag)成员身份。

**注**

确保已在

“动画”(Animation)首选项（在“设置”(Settings)下）

中激活

“组件标记”(Component Tags)

，系统会为每个几何体节点指定

组件标记节点

。

有关如何使用“组件标记”(Component Tags)定义变形器成员身份的信息，请参见[为几何体指定组件标记](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-788B1C8B-7F45-4862-BC42-0A334DFECFD3.htm)。

#### 选择组件标记

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-7689693A-C472-43F1-AE8C-817ADF6CB019.gif) <!-- baize:img-hook downloaded=false reason="正文 1438 字 ≥300，非承重" -->

1. 在“大纲视图”(Outliner)或视口中选择几何体。

2. 在“属性编辑器”(Attribute Editor)中，单击几何体的形状节点并展开“组件标记”(Component Tags)部分。

3. 在表中的组件标记上单击鼠标右键，然后从菜单中选择**“选择组件”(Select Components)**。如果表中未列出任何内容，请确保选择了几何体。

#### 从组件标记成员身份添加/移除元素

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-40145559-46CE-44A6-81D9-5640F8E0B325.gif) <!-- baize:img-hook downloaded=false reason="正文 1438 字 ≥300，非承重" -->

按选定组件增加或减少组件标记成员身份。

**注**

在一个

组件标记

中只能添加/移除同一组件类型。例如，不能将边添加到面的

组件标记

选择中。

向现有组件标记添加元素

1. 在“属性编辑器”(Attribute Editor)的[组件标记(Component Tags)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)部分中，选择要向其添加更多组件的标记。

2. 转到几何体，按 **Shift** 键，然后选择要添加的组件。

3. 在[“组件标记”(Component Tags)表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)中，在要向其添加组件的标记上单击鼠标右键，然后选择**“添加选定对象”(Add Selected)**。

从现有组件标记中移除元素

1. 在“属性编辑器”(Attribute Editor)的[组件标记(Component Tags)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)部分中，选择要从其减去组件的标记。

2. 转到几何体，按 **Ctrl** 键，然后选择要从分组中减去的组件。

3. 在[“组件标记”(Component Tags)表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)中，在要从中减去组件的标记上单击鼠标右键，然后选择**“移除选定对象”(Remove Selected)**。

1. 在“属性编辑器”(Attribute Editor)的[组件标记(Component Tags)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)部分中，选择要更改组件的标记。

2. 在表中的对应行上单击鼠标右键，然后选择 **“转化为面”(Convert to Faces)**、**“转化为边”(Convert to Edges)**或**“转化为顶点”(Convert to Verts)**。

3. 单击**“选择组件”(Select Components)**以查看更改。

1. 在“属性编辑器”(Attribute Editor)的[组件标记(Component Tags)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)部分中，按住 **Shift** 或 **Ctrl** 键并选择要合并的组件标记。

2. 在表中的对应行上单击鼠标右键，然后选择**“合并”(Merge)**。将从选定标记创建新的**合并标记**。

3. 单击**“选择组件”(Select Components)**以查看更改。

#### 其他组件标记成员身份编辑选项

对于其他选项，在[“组件标记”(Component Tags)表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)中对应的组件标记行上单击鼠标右键，然后选择：

- **删除(Delete)** - 将移除标记。

- **重命名...(Rename...)** - 将打开一个窗口，您可以在其中命名标记。

- **复制(Duplicate)** - 将复制标记。

- **替换为选定对象(Replace with Selected)** - 将使用选定组件填充组件标记成员身份。

- 使用**“清除”(Clear)**可清空组件标记成员身份，以便可以擦除某个组件标记的所有指定，但保留名称以便可以重用。
