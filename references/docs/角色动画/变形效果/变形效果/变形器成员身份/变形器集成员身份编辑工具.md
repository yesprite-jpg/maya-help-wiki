# 变形器集成员身份编辑工具

Maya 针对编辑变形器集成员身份提供了许多方法：

可以使用[关系编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3DA58150-A73D-403E-A988-798DED4956BD)（“窗口 > 关系编辑器 > 变形器集”(Windows > Relationship Editors > Deformer Sets)）编辑变形器集成员身份。“关系编辑器”(Relationship Editor)将列出场景中的所有变形器集，并列出每个集中的所有点。使用“关系编辑器”(Relationship Editor)，还可以提供独占的变形器集成员身份，使一个点仅位于一个集中。。

通过“编辑成员身份工具”(Edit Membership Tool)（“变形 > 编辑”(Deform > Edit) > [编辑成员身份工具(Edit Membership Tool)](../变形器参考/“变形”%28Deform%29菜单.md#GUID-C1B5085D-3229-4BE8-989E-95C460ADB79C__GUID-41000A36-E60C-4590-B58D-25AED6CC509F)）拾取可变形对象点，可以直接编辑变形器集成员身份。请参见[编辑变形器集成员身份](使用“编辑成员身份工具”%28Edit%20Membership%20Tool%29编辑变形器集成员身份.md)。

此外，还可以使用“绘制集成员身份工具”(Paint Set Membership Tool)来绘制变形器集成员身份。该工具为编辑集成员身份提供了一种易于使用的直观方法。请参见[绘制变形器集成员身份](使用“编辑成员身份工具”%28Edit%20Membership%20Tool%29编辑变形器集成员身份/绘制变形器集成员身份.md)。

对于簇、雕刻、晶格和线变形器，可以快速删减变形器集中的所有点。请参见[删减变形器集成员身份](使用“编辑成员身份工具”%28Edit%20Membership%20Tool%29编辑变形器集成员身份/删减变形器集成员身份.md)。

## 独占的变形器集成员身份

“排除”(Exclusive)选项可确保属于每个变形器的集都是互斥的，帮助创建非重叠的变形。请参见[“高级”(Advanced)变形器选项](../变形器参考/变形器节点/“高级”%28Advanced%29变形器选项.md)。

变形器的互斥性是通过将变形器的集放置到划分中来完成的。即使对这些集的成员身份进行编辑，划分也可以保证这些集会继续互斥。若要将变形器集放置到划分中，请使用“关系编辑器”(Relationship Editor)。详细信息请参见[集和划分](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B1DE4646-E52B-4611-87B6-E741F25E284B)。
