# 曲线上的点变形器

可以将 NURBS 曲线上的点（曲线点）约束到定位器。这对于在特定点上沿曲线变形单条曲线非常有用。通过移动（平移）定位器，用户可以更改曲线的形状，而不会被限制为仅可以移动曲线的 CV。此外，在建模时，用户可以使用曲线定位器约束上的点连接两条或多条曲线，使它们相交。请参见[设置曲线上的点变形器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-ECD4D805-EC94-4536-BA89-8749D487EF26.htm)和[曲线上的点选项](变形器参考/“变形”%28Deform%29菜单/“曲线上的点”%28Point%20On%20Curve%29选项.md)。
