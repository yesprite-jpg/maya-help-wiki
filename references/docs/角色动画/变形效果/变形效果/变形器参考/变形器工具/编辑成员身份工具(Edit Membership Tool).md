# 编辑成员身份工具(Edit Membership Tool)

- 在“建模”(Modeling)和“装备”(Rigging)菜单集中：“变形 > 编辑成员身份工具”(Deform > Edit Membership Tool)

- 在“动画”(Animation)菜单集中：“动画变形 > 打开完整的变形菜单 > 编辑成员身份工具”(Anim Deform > Open Full Deform Menu > Edit Memebership Tool)

可以通过“集成员身份工具”(Set Membership Tool)选择可变形对象的点来直接编辑变形器集成员身份。

请参见[编辑变形器集成员身份](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E4211EA1-D15E-4603-BCDA-CADE1CEE74C5.htm)和[绘制集成员身份工具](绘制集成员身份工具%28Paint%20Set%20Membership%20Tool%29.md)。
