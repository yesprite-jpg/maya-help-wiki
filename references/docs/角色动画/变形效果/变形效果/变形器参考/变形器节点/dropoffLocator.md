# dropoffLocator

## 衰减定位器属性(Dropoff Locator Attributes)

与此处列出的“百分比”(Percent)、“参数”(Param)和“局部位置”(Local Position)属性一起，还有以下两个属性可用于控制线衰减定位器的变形效果：“扭曲”(Twist)属性和“封套”(Envelope)属性。这些属性可用作常规变形器节点属性。请参见[常规变形器节点属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-778B7255-F6F9-4056-8952-B28F8E222E72.htm)。

#### 百分比(Percent)

指定定位器对影响线衰减的局部效果。默认情况下，影响线每端均有两个隐式定位器，其“百分比”(Percent)为 1.000。其他定位器的效果与这些定位器的“百分比”(Percent)效果相关。使用该滑块，可选择 0.000 到 1.000 之间的值。默认值为 1.000。请注意，该属性还可用作线变形器的属性。

#### 参数(Param)

指定线衰减定位器在影响线曲线中的位置。该值与曲线的 U 参数相关。请注意，该属性还可用作线变形器的属性。

#### 局部位置(Local Position)

指定线衰减定位器在影响线曲线中的局部位置。
