# 组件标记

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 321 字 ≥300，非承重" -->

组件标记是可以在[“组件标记”(Component Tags)表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)中定义的成员身份标记。组件标记节点替换 [groupID](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-BC570BCC-AB68-4EAC-8C29-0BEB42997580.htm) 节点，并通过消除[调整节点](tweak.md)、groupParts 和 objectSet 节点来整理“节点编辑器”(Node Editor)。您可以使用组件标记表达式来[动态定义变形器成员身份](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6692AD3F-F7BE-450A-8DF3-C4099A412550.htm)以及[定义变形器衰减](../../修改变形器/变形器衰减.md)。

若要使用组件标记，必须在[“动画”(Animation)首选项（在“设置”(Settings)下）](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0817C74B-C95C-4E5F-BCFA-26DEE1D7747F)的**“绑定”(Rigging)**部分中启用**“组件标记”(Component Tags)**选项。这样，每当使用变形器时，就会使用组件标记，而不是 groupID 节点。

按照[为几何体指定组件标记](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-788B1C8B-7F45-4862-BC42-0A334DFECFD3.htm)，使用[“组件标记”(Component Tags)表](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1D7D6E5A-2E20-42F7-91D2-8C18A878919A.htm)创建组件标记成员身份。
