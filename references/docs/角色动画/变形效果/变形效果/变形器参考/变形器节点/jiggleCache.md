# jiggleCache

## 抖动缓存属性(Jiggle Cache Attributes)

#### 缓存文件名(Cache File Name)

当前抖动变形器的缓存名称。

#### 开始时间(Start Time)

抖动缓存数据开始播放的时间。

#### 结束时间(End Time)

抖动缓存数据结束播放的时间。

#### 采样类型(Sampling Type)

选择下列选项之一。

#### 过采样(Over)

对每帧的抖动采样多于一次。例如，“过采样”(Over)采样值为 3，Maya 对每帧的抖动采样 3 次。

#### 欠采样(Under)

对每帧的抖动采样不到一次。例如，“欠采样”(Under)采样值为 3，Maya 每隔 3 帧对抖动采样一次。

#### 采样率(Sampling Rate)

指定每帧的采样数。

#### 删除缓存(Delete Cache)

删除当前抖动变形器的缓存。

## 缓存节点(Caching Node)

#### 磁盘缓存(Disk Cache)

显示当前抖动变形器的名称。
