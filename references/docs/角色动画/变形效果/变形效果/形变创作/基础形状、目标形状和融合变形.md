# 基础形状、目标形状和融合变形

使用融合变形时，了解使用的术语不失为明智之举。根据您的具体工作方式，可能会涉及到几种不同的对象和形状。

- 基础网格（即：基础对象）是要变形的原始对象。这是您要应用融合形变变形器的对象。

- *基础形状*是基础对象开始变形之前的中性姿势。

- 目标对象通常是基础网格的副本。您可以将每个对象修改为唯一姿势（例如，不同的面部表情）。由于您还可以直接修改基础网格，因此无需创建目标对象。

- *目标形状*有时也称为“目标”，是指源于目标对象的形状。您也可以将基础对象直接修改为不同的姿势，并将每个姿势另存为目标形状。顶点与基础形状的偏移将保存在每个目标形状中。

- *融合变形*是指目标形状应用于基础对象而生成的形状。您可以更改每个目标形状的权重，从而更改它对融合变形的影响量。
