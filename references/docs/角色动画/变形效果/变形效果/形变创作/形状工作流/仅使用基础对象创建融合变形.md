# 仅使用基础对象创建融合变形

使用这种变形动画方法，可以直接在基础对象上创建目标形状，而无需创建多个单独的目标对象。这意味着场景中的几何体会减少，从而缩短交互时间。

当然，如果以后决定要为已创建的目标形状创建实际目标对象（请参见[使用多个目标对象创建融合变形](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-42114F0D-8F16-4365-A52C-E0FD70F40852.htm)），则可以执行此操作。请参见[从目标形状创建新对象](../从目标形状创建新对象（重建目标）.md)。这样在操作期间就不必担心选择哪种方法，因为您始终可以根据需要删除和重建目标对象。

  选择要变形的基础对象。

2. 打开[形变编辑器](../形变编辑器.md)，然后单击“创建融合变形”(Create Blend Shape)按钮以创建融合形变变形器（有关其他方法，请参见[创建融合形变变形器](../创建融合形变变形器.md)）。可以为对象创建多个融合形变变形器。

3. 在“形变编辑器”(Shape Editor)中，将自动选择刚创建的融合形变变形器。否则，请选择该融合形变变形器或树视图中的其他融合形变变形器。

  提示：通过在每个融合形变变形器上单击鼠标右键并选择“重命名”(Rename)，可以为其提供描述性名称。

4. 通过单击“添加目标”(Add Target)按钮，将空目标形状添加到选定的融合形变变形器（有关其他方法，请参见[添加目标形状](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E980D990-53FC-47C9-B9B8-C8451E933665.htm)）。继续单击可根据需要添加多个目标形状。

  通过在每个目标形状上单击鼠标右键并选择“重命名”(Rename)，可以为其提供描述性名称。

5. 添加目标形状时，将自动选择其“编辑”(Edit)按钮，以便立即对其进行编辑。

  否则，请选择该目标形状或其他目标形状，确保其权重值不为 0（1 可能最佳），然后单击其“编辑”(Edit)按钮以进入“编辑”(Edit)模式。

6. 使用[雕刻](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-246B90C9-914F-4EC6-8317-349AF2DE90F7)工具或任一[变换](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-59D26516-9183-4154-A5D9-1A581275D06A)工具（移动、旋转或缩放）修改基础对象上的顶点位置。

  您每次所做的修改都是基础对象原始形状的顶点位置增量。此特定信息是为该目标形状而存储，并由[融合变形](../../变形器参考/变形器节点/blendShape.md)节点用于计算基础形状上的形状变形。

7. 完成对象的编辑后，再次单击“编辑”(Edit)按钮以保存对目标形状所做的更改，然后退出“编辑”(Edit)模式。

8. 继续通过该方式编辑其他目标形状。

9. 选择目标形状并拖动其权重滑块（或在文本框中输入一个值），以设置其对基础对象融合变形的影响。请参见[设置目标形状的权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CDC3D7EC-6D02-4319-A4E9-ACCC7ED47D30.htm)。

  **注**

  还可以在通道盒或属性编辑器中设置每个目标形状的权重值。

10. 在时间滑块中，转到要设置关键帧（例如，用于中性表情或姿势）的第一帧。

11. 在形变编辑器中，为目标形状的权重值设置关键帧，如[设置融合变形权重的关键帧](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-F679B46B-00E5-4643-848F-D52F24718B57.htm)中所述。

  重复最后三个步骤，设置随时间变化的形状变形的动画。
