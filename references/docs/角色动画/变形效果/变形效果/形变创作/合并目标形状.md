# 合并目标形状

您可以使用[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)合并多个属于同一融合变形的目标形状。请注意，执行此操作时，将移除所有相关目标上的关键帧。为了避免丢失数据，请先复制已设置关键帧的目标并将其隐藏，然后再与原始目标形状进行合并。

合并目标形状

1. 在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，选择多个属于同一融合变形的目标形状。

2. 在任一目标形状上单击鼠标右键，然后选择“合并目标”(Merge Targets)。

  Maya 将多个选定目标形状合并为一个目标形状。
