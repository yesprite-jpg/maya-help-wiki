# 创建目标形状或融合形变变形器组

在一个融合形变变形器内使用多个目标形状时，对目标形状进行排序分组有助于快速识别。例如，您有一个融合形变变形器，它具有多个影响嘴部的目标形状，但您需要为影响上下嘴唇的形状分别创建一个组。

接下来，您可以为组设置权重值和关键帧，以便快速设置该形状组的动画。请参见[设置融合变形权重的关键帧](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-F679B46B-00E5-4643-848F-D52F24718B57.htm)。

同样，如果某一基础对象有多个融合形变变形器（例如，其目标形状分别影响眼睛和嘴的多个融合形变变形器），则可以采用相同的方式将其放入多个组中。

创建分组的步骤

1. 在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，选择要分组在一起的目标形状或融合形变变形器。

  **注**

  创建组时，不能选择目标形状和融合形变变形器的组合。

  多个目标形状必须位于同一个融合形变变形器下。

  一个目标形状不能属于多个组。

2. 执行下列操作之一：

  - 单击“分组”(Group)图标 ![图：单击“分组”(Group)图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-CBD6B2E0-F89C-431F-BE19-AF84072E4476.png) <!-- baize:img-hook downloaded=false reason="正文 845 字 ≥300，非承重" -->。

  - 按 Ctrl+G。

  - 在选定的项上单击鼠标右键并选择“分组”(Group)。

  - 在形变编辑器菜单栏中，选择“编辑”(Edit) > “分组”(Group)。

这将创建一个组，其中包含选定目标形状或融合形变变形器。融合形变变形器分组后，其所有目标形状均位于该组中对应融合形变变形器的下方。

可以创建任意数量的嵌套组。

  此外，您还可以将融合形变变形器或目标形状拖放到另一个融合形变变形器或目标形状，创建一个包含二者的组。

向组添加成员

- 将目标形状或融合形变变形器拖动到相应的组文件夹或“组”列表内的任意位置。

重命名组

- 双击树中的组名称或在组上单击鼠标右键，选择“重命名组”(Rename Group)并输入新名称。

重新排序组成员

- 在列表中将组成员向上或向下拖动。

从组中移除成员

- 将成员拖动到另一个组，或拖动到融合形变变形器 (BSD) 正下方，使其不位于任何组、但仍位于其相关 BSD 中。
