# 翻转目标形状

通过使用形变编辑器，可以翻转目标形状在基础对象上的位置。翻转将根据您选择的轴移动目标形状，从而生成一个完全反转的形状。翻转类似于使用负值 (-1) 在 X、Y 或 Z 轴方向上缩放对象，但仅影响选定的目标形状。

翻转时不会创建其他目标形状，即：您正在翻转实际的目标形状，而不是创建其翻转版本。如果要执行此操作，请先复制目标形状（请参见[复制目标形状](复制目标形状.md)），然后将其翻转。

翻转目标形状

1. 在[形变编辑器](形变编辑器.md)中，选择一个或多个目标形状或一组目标形状。

2. 选择“形状 > 翻转目标”(Shapes > Flip Target) > ![图：选择“形状 翻转目标”(Shapes Flip Target) ，或者在其中一个选定目标形状上单击鼠标右键，然后选择“翻…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 820 字 ≥300，非承重" -->，或者在其中一个选定目标形状上单击鼠标右键，然后选择“翻转目标”(Flip Target)。

  对于一组目标形状，在组名称上单击鼠标右键，然后选择“翻转组成员”(Flip Group Members)。

3. 在“翻转目标选项”(Flip Target Options)中，选择用于翻转的对称轴（默认情况下，使用对象的 X 轴）。

  目标形状将根据当前选项在基础对象上进行翻转。

## 翻转目标选项(Flip Target Options)

选择用于翻转目标形状的对称轴。

### 对称轴(Symmetry Axis)

- 对象 X/Y/Z(Object X/Y/Z)：使用对象轴心点定义的对象 X、Y 或 Z 轴进行翻转。“对象 X”(Object X)是默认设置。

- 拓扑(Topology)：使用对象的实际拓扑定义轴进行翻转。为了获得更精确的结果，特别是在高分辨率网格中，请使用此方法，而不是“对象 X/Y/Z”(Object X/Y/Z)

  如果尚未为对象定义对称接缝，系统会提示您将选择一条边（已启用边模式）作为翻转轴。

  存储拓扑对称接缝边(Store topological symmetry seam edges)：仅当选择“拓扑”(Topology)时才可用。此选项将上次定义的边存储为用于此融合形变变形器的对称接缝，并与[“镜像目标”(Mirror Target)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E3AB5EFF-1C36-4D11-AC85-DABF6DAD969F.htm)命令共享。如果翻转的目标形状属于另一个融合形变变形器，则系统会提示您再次选择一条边。
