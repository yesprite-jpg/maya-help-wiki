# 复制目标形状

您可以使用形变编辑器复制目标形状或目标形状组。复制一个目标形状时，其属性（例如，权重值的关键帧）也会被复制。复制的目标形状将与原始对象的相同融合形变变形器关联。

复制一组目标形状时，其所有成员均会复制，而不仅仅是复制选定的对象。

**注**

- 如果要复制目标形状的中间帧形状，必须选择这些形状及其招牌目标（请参见[添加中间帧目标形状](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-FF40A342-2F43-42C5-A8C9-8C5E3D91B565.htm)）。

- 您可以复制组合目标形状（请参见[创建组合目标形状](创建组合目标形状.md))，但副本将是不受其他对象驱动的常规目标形状。这也适用于复制驱动程序的目标形状及其组合目标形状的情况。

- 如果原始目标形状具有关联的目标对象（请参见[基础形状、目标形状和融合变形](基础形状、目标形状和融合变形.md)），则不复制。

复制目标形状

  在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，选择一个或多个目标形状或目标形状组以进行复制。

  如果要复制目标形状的的中间帧形状，请将其添加到当前选择。

  选择“形状”(Shapes) > “复制目标”(Duplicate Target)或按 Ctrl+D。

  您还可以在选定的目标形状上单击鼠标右键并选择“复制目标”(Duplicate Target)，或者在选定的组上单击鼠标右键并选择“复制组”(Duplicate Group)。

  目标形状或组及其所有内容均会复制，并使用其名称以及“_copy”后缀直接放在原始目标形状下。您可以根据需要重命名每个副本。
