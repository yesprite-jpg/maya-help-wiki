# 设置目标形状的权重

设置目标形状的权重时，表明您正在定义目标形状对基础对象上的融合变形的影响。您可以使用形变编辑器或通道盒设置目标形状的权重。设置权重后，您可以对多个帧的权重值设置关键帧，从而设置形状的动画。请参见[设置融合变形权重的关键帧](设置目标形状权重的关键帧.md)。

此外，您还可以在形变编辑器中设置一组目标形状的权重，或者在基础对象上设置融合变形本身的总体权重。请参见[缩放融合变形的影响](缩放融合变形的影响.md)。

设置目标形状的权重

1. 在[形变编辑器](形变编辑器.md)中，选择目标形状。

2. 将“权重”(Weight)滑块调整到 0.000 和 1.000（100% 权重）之间的值，或者在“权重”(Weight)文本框中输入一个值。

  值为 0 意味着目标形状不影响基础形状，而值为 1 时，将显示目标形状对基础形状的完整效果。

  在“权重”(Weight)文本框中，可以输入超出 0-1 范围的值，以反转（负值）或放大（超过 1 的值）目标的影响。有关详细信息，请参见[形变编辑器](形变编辑器.md)。

设置一组目标形状的权重

1. 在[形变编辑器](形变编辑器.md)中，创建或选择一组目标形状。请参见[创建目标形状或融合形变变形器组](创建目标形状或融合形变变形器组.md)。

2. 将该组的“权重”(Weight)滑块调整到 0.000 和 1.000（100% 权重）之间的值，或者在“权重”(Weight)文本框中输入一个值。这将为该组的总体权重值设置关键帧，其中包括该组内每个目标形状的当前权重。

3. 若要将该组的权重值重置为 0，请在该组上单击鼠标右键并选择“重置”(Reset)，或者选择“重置组成员”(Reset Group Member)，以便针对该组中的每个目标形状将权重值设置为 0。

将目标形状权重设置为零

1. 在[形变编辑器](形变编辑器.md)中，选择一个或多个目标形状。

2. 选择“形状 > 重置”(Shapes > Reset)，或者在目标形状名称上单击鼠标右键并选择重置(Reset)。

在通道盒中设置目标形状的权重

1. 选择要变形的基础对象。

2. 从“通道盒”(Channel Box)的“输入”列表中，选择其融合形变变形器节点之一（blendShape*n* 节点）。

3. 在其下方，单击要编辑的目标形状通道的名称。

4. 在视图面板中，使用鼠标中键拖动以更改选定通道的权重值，或者在通道的字段中输入一个值。

  按 Ctrl 键的同时拖动以进行更精细的控制，或按住 Shift 键进行更粗略的控制。
