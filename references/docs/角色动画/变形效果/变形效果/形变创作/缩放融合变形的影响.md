# 缩放融合变形的影响

可以缩放整个融合变形本身对基础对象的效果。例如，如果目标形状的累积效果使基础对象的变形超过预期，则可以将“权重”(Weight)设置为介于 0 到 1 之间的某个值，以此缩小总体融合形变变形效果。

选择融合形变变形器（融合变形节点），然后执行以下操作之一：

- 在[形变编辑器](形变编辑器.md)中，拖动选定融合形变变形器的权重滑块，或在文本框中输入“权重”(Weight)值。

- 在“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中，拖动滑块或为融合变形节点的“封套”(Envelope)通道或属性输入一个值。请参见[融合变形节点和属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-D3068F27-E96E-40AD-9BD0-54C31E0FCF4D.htm)。

滑块将指定 0 到 1 之间的值，但也可以输入 -2 到 2 之间的值。如果“权重”(Weight)值为 2，则每个目标形状的影响将翻一倍；如果为 0.5，则每个目标形状的影响将变为原来的一半。如果“权重”(Weight)值为负，则每个目标的影响将会反转。
