# 将对象与不同拓扑融合

您可以使用[融合变形选项(Blend Shape Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C954C197-6D56-4EB8-BEA0-70DD1BBBAD6B.htm)中的“检查拓扑”(Check Topology)选项，创建目标对象的拓扑与基础对象有所不同的融合变形。此选项会检查基础对象和目标对象的顶点数是否相同。

如果要使用多个相同的目标对象创建融合变形（[使用多个目标对象创建融合变形](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-42114F0D-8F16-4365-A52C-E0FD70F40852.htm)），则应在创建融合形变变形器（[创建融合形变变形器](创建融合形变变形器.md)）时启用“检查拓扑”(Check Topology)选项。

如果要使用的目标对象的顶点数与基础对象不同，则应禁用“检查拓扑”(Check Topology)选项。但是，如果顶点的数目不同且此选项已禁用，您可能会看到眼睛融合到鼻子这样的异常融合情况。

如果目标对象和基础对象的顶点数相同，但是它们的顺序不同，则无论“检查拓扑”(Check Topology)启用还是禁用，Maya 都将融合形状。但是，基础对象的顶点位置将变换为目标对象的顶点位置。该更改可能会导致对象无法按照期望的方式进行融合。若要确保基础和目标之间的平滑过渡，请确保基础对象和目标对象中的顶点顺序相同。
