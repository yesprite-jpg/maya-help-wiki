# 编辑目标形状

将目标形状添加到基础对象上的融合形变变形器之后，可以对其进行编辑来创建唯一的形状和姿势。

如果要使用多个目标对象使基础对象变形，则会自动为在针对基础对象创建融合形变变形器时拾取的每个目标对象创建目标形状。编辑每个目标形状时，可以修改相应目标对象的几何体。

可以使用[雕刻](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-246B90C9-914F-4EC6-8317-349AF2DE90F7)和[变换](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9622730D-3D21-451C-8BEE-E01BCC979F91)（平移、旋转和缩放）工具编辑基础对象或目标对象。从对象的基础形状到已编辑形状（增量）的顶点位置差异存储在此目标形状中。

**注**

不能使用变形器（例如，晶格）修改基础对象的形状，然后将这些编辑传递到目标形状。如果将变形器应用于正在编辑的目标形状，则会禁用“编辑”(Edit)模式。激活雕刻或变换工具后，可以继续编辑此目标形状的基础对象或目标对象。

编辑目标形状

1. 选择采用融合形变变形器的对象。

2. 在[形变编辑器](形变编辑器.md)中，选择要修改的目标形状。每次只能编辑一个目标形状。

3. 将目标形状的“权重”(Weight)值设置为所需的任何值。值为 1 时将向您显示编辑的完整效果，通常建议使用此值。请参见[设置目标形状的权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CDC3D7EC-6D02-4319-A4E9-ACCC7ED47D30.htm)。

4. 单击“编辑”(Edit)以激活“编辑”(Edit)模式。该按钮将变为红色，提醒您编辑模式处于活动状态。

5. 使用雕刻和变换（平移、旋转和缩放）工具修改基础对象或目标对象。

  **注**

  通过在

  “形变编辑器”(Shape Editor)

  中的融合变形上单击鼠标右键，然后单击

  “选择基础网格”(Select Base Mesh)，可以快速选择基础对象。

6. 完成对象的修改后，再次单击“编辑”(Edit)以退出“编辑”(Edit)模式。从基础形状到已编辑形状的顶点位置差异存储在此目标形状中。

**注**

对于场景中已存在物理网格的融合变形目标（包括中间帧目标），请直接在场景的目标网格上或直接在基础网格上使用雕刻工具。请避免在场景中同时选中基础网格和物理目标网格时激活雕刻工具，否则可能会遇到视口刷新问题。

如果在场景的物理目标上进行雕刻后基础网格未更新，只需退出雕刻工具（切换工具）或拖动时间轴即可刷新视口。

在基础对象上单放（显示或隐藏）目标形状或中间帧目标

1. 在[形变编辑器](形变编辑器.md)中，选择一个或多个目标形状、目标形状组或中间帧目标。

  还可以选择融合形变变形器，通过更改各个可见性状态隔离所有目标形状的效果。

2. 单击“可见性”(Visibility)列中的小圆，切换选定目标形状或组的可见性。

  若要单放选定目标形状的效果，请按 Alt 键并单击小圆，或者在选定目标形状的名称上单击鼠标右键，然后选择“单放/取消单放”(Solo/Unsolo)。

  可见性处于禁用状态时，权重和编辑将会禁用。
