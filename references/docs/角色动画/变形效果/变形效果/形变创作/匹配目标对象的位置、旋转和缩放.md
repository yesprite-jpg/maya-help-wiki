# 匹配目标对象的位置、旋转和缩放

您可以使用[融合变形](../变形器参考/变形器节点/blendShape.md) “原点”(Origin)属性控制底面的变形是否受目标对象的位置、旋转或缩放的影响。

1. 选择融合形变变形器。请参见[创建融合形变变形器](创建融合形变变形器.md)。

2. 使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)编辑[“原点”(Origin)](../变形器参考/变形器节点/blendShape.md#GUID-9D06EE32-416C-47D8-93D4-0EFA13F9C836__GUID-04C0C524-77E6-4357-897E-709C42716E38)通道或属性。
