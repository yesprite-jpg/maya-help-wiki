# 交换目标对象的顺序

使用多个目标对象为基础对象创建融合形变变形器之后，可以交换目标对象的顺序。这会更改将目标形状应用于基础对象的顺序，从而影响变形动画的序列。

交换两个目标对象

1. 选择要交换其顺序的两个目标对象。

2. 选择“变形 > 融合变形 > 交换”(Deform > Blend Shape > Swap) >![图：选择“变形 融合变形 交换”(Deform Blend Shape Swap) 以打开融合变形交换选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 253 字 <300 且带图" --> 以打开[融合变形交换选项](../变形器参考/“变形”%28Deform%29菜单/“融合变形”%28Blend%20Shape%29菜单/“融合变形交换”%28Blend%20Shape%20Swap%29选项.md)。

3. 在此对话框中设置所需的选项。

在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，通过在“融合形变变形器”(Blend Shape Deformer)列表内向上或向下拖动目标形状，可以轻松更改目标形状的顺序。该操作与使用“交换”(Swap)命令具有相同的效果。
