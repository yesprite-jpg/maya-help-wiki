# 添加组合目标选项

在[形变编辑器](../形变编辑器.md)中选择“创建 > 添加组合目标”(Create > Add Combination Target) > ![图：在形变编辑器中选择“创建 添加组合目标”(Create Add Combination Target) 或“创建 添加当…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 421 字 ≥300，非承重" --> 或“创建 > 添加当前选择作为组合目标”(Create > Add Selection as Combination Target) > ![图：在形变编辑器中选择“创建 添加组合目标”(Create Add Combination Target) 或“创建 添加当…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 421 字 ≥300，非承重" -->，将新目标（基于多个目标形状的组合效果）添加到基础对象的选定融合形变变形器（基于在此处选择的选项）。

#### 类型(Type)

确定如何创建新的融合变形目标。有关详细信息，请参见[添加融合变形目标选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3F747E43-29D1-409D-8F40-C97311C894E6.htm)中的“目标类型”(Target Type)。

#### 方法(Method)

确定合并目标形状的方式。选项包括：

- 相乘(Multiplication) - 乘以驱动目标的权重。

- 最低权重(Lowest weighting) - 使用最低驱动者权重并将其用作组合目标的权重。

- 平滑(Smooth) - 与“最低权重”(Lowest weighting)相同，但是新增了平滑插值。
