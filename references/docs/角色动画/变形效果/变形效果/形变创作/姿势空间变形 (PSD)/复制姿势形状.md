# 复制姿势形状

使用姿势形状进行姿势空间变形时，可能需要复制姿势形状，以便独立于基础网格进行编辑和更新。如果要将形状导入到 Autodesk Mudbox 等其他应用程序进行雕刻和微调，这一点尤其重要。处理完复制的姿势形状后，可以用它来更新原始姿势形状。

复制姿势形状

1. 在[姿势编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)中，选择一个或多个要复制其姿势形状的姿势。

2. 在选定的姿势形状上单击鼠标右键，然后选择“复制姿势形状”(Duplicate Pose Shape)。

  姿势形状将使用其名称加“_Copy”后缀进行复制，且直接放置在原始姿势形状之下。您可以根据需要重命名每个副本。

更新姿势形状

1. 在[姿势编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)中，选择一个或多个要使用编辑过的版本更新其姿势形状的姿势。

2. 在选定的姿势形状上单击鼠标右键，然后选择“更新姿势形状”(Update Pose Shape)。

3. 选择要用于更新姿势形状的网格。

  姿势形状将使用选定网格的形状进行更新。
