# “添加姿势形状连接”(Add Pose Shape Connection)窗口

单击[姿势编辑器(Pose Editor)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)窗口的“高级设置”(Advanced Settings)（右侧）中的“添加”(Add)按钮后，将显示此窗口。使用以下选项可以更加轻松地在姿势和融合变形目标之间创建连接。系统会根据您选择的“融合形变变形器”(Blend Shape Deformer)和“目标”(Target)自动创建连接名称，而不是手动输入名称。

#### 融合形变变形器(Blend Shape Deformer)

用于从当前场景中的可用融合变形节点列表中进行选择。

#### 目标(Target)

用于从当前场景中的可用融合变形目标列表中进行选择。系统根据选定的“融合形变变形器”(Blend Shape Deformer)自动填充此列表。

#### 连接(Connection)

系统根据选定的“融合形变变形器”(Blend Shape Deformer)和“目标”(Target)自动在此字段中填充连接名称。可以编辑连接名称。
