# 创建姿势空间变形

处理蒙皮角色时，如果角色处于特定姿势，通常需要使用特殊形状来修复蒙皮变形问题。变形问题通常出现在角色的关节连接点处，如肩部、下臂、膝盖和腹股沟部位。

使用“姿势编辑器”(Pose Editor)，可以通过名为姿势空间变形 (PSD) 的技术修复这些问题。首先为选定关节创建一个姿势插值器节点，每个节点包含不同的姿势。对于每个姿势，旋转或移动角色中存在蒙皮变形问题的关节，然后创建或使用关联的修正融合变形（称为姿势形状）修复该问题。然后，只要角色的关节达到该姿势，便会自动使用这些融合变形。对于每个形状，可以根据需要为其姿势设置强度（权重），并在这些姿势与蒙皮网格之间插值。

**注**

如果使用的关节受装备中的控件（IK 或其他控件）驱动，请参见

将控制器驱动关节用于姿势空间变形

以获取信息。

## 姿势空间变形的使用提示

创建修正姿势形状时，最好先为所有极端姿势构建形状，然后根据需要添加中间帧姿势形状。

但是，如果要简化此工作流并“即时”创建形状，您可能会遇到每个附加姿势的权重值增加的问题。若要避免此问题，请选择某个特定姿势，然后在[姿势编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)的“高级设置”(Advanced Settings)面板（在姿势编辑器中选择“视图 > 高级”(View > Advanced)，或者在姿势名称上单击鼠标右键并选择“显示高级设置”(Show Advanced Settings)以显示此面板）中激活“独立”(Independent)选项。如果姿势独立，则会从包含其他姿势的归一化计算中移除，并且只能通过其旋转和/或平移衰减进行调整。

在角色上创建具有关联修正形状的姿势

1. 选择与要修复变形的蒙皮区域对应的角色关节。这将是形状的中性姿势。

2. 若要创建新的姿势插值器模式，请执行以下操作之一：

  - 在“建模”(Modeling)、“装备”(Rigging)或“动画”(Animation)菜单集中，选择“变形 > 姿势空间变形 > 创建姿势插值器”(Deform > Pose Space Deformation > Create Pose Interpolator)。

  - 打开[姿势编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2AB6C4C3-75AC-4094-A65C-C232739AFB30.htm)并单击“创建姿势插值器”(Create Pose Interpolator)按钮，或者选择“姿势 > 创建姿势插值器”(Poses > Create Pose Interpolator) > ![图：打开姿势编辑器并单击“创建姿势插值器”(Create Pose Interpolator)按钮，或者选择“姿势 创建姿势…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2391 字 ≥300，非承重" -->。

    - 如果单击“创建姿势插值器”(Create Pose Interpolator)按钮，则会自动创建中性姿势。

    - 如果选择“姿势 > 创建姿势插值器”(Poses > Create Pose Interpolator) > ![图：如果选择“姿势 创建姿势插值器”(Poses Create Pose Interpolator) ，则可决定是（默认）否…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2391 字 ≥300，非承重" -->，则可决定是（默认）否选择“添加中性姿势”(Add Neutral Poses)选项。为获得最佳结果，您应选择此选项，因为中性姿势可以确保当关节处于此中性姿势时，不会激活添加到此姿势插值器节点的其他姿势。

  新节点将显示在“姿势编辑器”(Pose Editor)的“姿势插值器”(Pose Interpolators)面板中。默认情况下，该名称是带有“_poseInterpolator”后缀的关节名称。

4. 选择此节点，可在右侧的姿势面板上查看其默认姿势。起初仅显示三个中性姿势。

5. 将关节旋转或移动到要添加具有关联修正形状的姿势的位置。这将是第一个要添加形状的极端姿势。

6. 在姿势编辑器中，选择姿势插值器节点，然后单击“添加姿势”(Add Pose)按钮，或者选择“姿势 > 添加姿势”(Poses > Add Pose) > ![图：在姿势编辑器中，选择姿势插值器节点，然后单击“添加姿势”(Add Pose)按钮，或者选择“姿势 添加姿势”(Poses…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2391 字 ≥300，非承重" -->，将此当前状态添加为新姿势。

  - 如果此姿势插值器节点尚未连接到融合形变变形器，则将打开[创建姿势形状(Create Pose Shape)窗口](创建姿势形状%28Create%20Pose%20Shape%29窗口.md)，您可在其中创建一个融合形变变形器。

  - 如果蒙皮网格上已存在融合形变变形器，则将打开[添加姿势选项(Add Pose Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C4DA19BB-4B0B-4609-B383-4844BF41E922.htm)，您可从中选择姿势类型（“摆动”(Swing)、“摆动和扭曲”(Swing and Twist)或“扭曲”(Twist)）。

7. 为此新姿势提供一个描述性名称。默认情况下，该名称为 *driverName_rx_ry_rz*。其中，driverName 是关节的名称，rx/ry/rz 是关节在此姿势中的旋转值。

现在，需要校正或增强蒙皮在此姿势中的变形：

8. 创建姿势时，将自动激活其“编辑”(Edit)按钮，以便能够立即编辑网格。确保姿势的“权重”(Weight)值不为 0（通常最好为 1）。

9. 使用雕刻工具或任一变换工具（移动、旋转或缩放）修改蒙皮上的顶点位置。

  您每次所做的修改都是蒙皮原始形状的顶点位置增量。此特定信息是为该姿势形状而存储，并由姿态插值器节点用于计算蒙皮上的变形。

  **注**

  打开摄影机的翻滚工具设置，然后启用

  “翻滚中心: 翻滚枢轴”(Tumble About: Tumble pivot)

  和

  “自动设置翻滚枢轴”(Automatically set tumble pivot)

  选项。这会自动将摄影机的翻滚枢轴调整到上一选择或雕刻笔划。

10. 修复完此姿势的蒙皮后，单击“编辑”(Edit)按钮退出该模式。

现在转到下一个极端姿势：

11. 设置角色的姿势，或者转到时间轴中蒙皮网格以不理想的方式变形或要更改蒙皮形状的帧。

12. 如前所述，单击“添加姿势”(Add Pose)按钮或选择“姿势 > 添加姿势”(Poses > Add Pose) > ![图：如前所述，单击“添加姿势”(Add Pose)按钮或选择“姿势 添加姿势”(Poses Add Pose) ，将此当前状…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2391 字 ≥300，非承重" -->，将此当前状态添加为新姿势。

13. 单击姿势的“编辑”(Edit)按钮，并使用雕刻或变换工具修改蒙皮，完成后再次单击“编辑”(Edit)退出该模式。

14. 旋转受影响的关节，查看如何将姿势形状融合到剩余蒙皮中。旋转关节时，姿势的权重将会相互归一化。姿势的权重值更新范围为 0（无权重）到 1（完全权重），具体取决于关节旋转距存储的姿势有多近。

15. 在面板中双击姿势，或者在姿势上单击鼠标右键，然后选择“转到姿势”(Go To Pose)，快速返回到该姿势（当权重为 100% 时应用）。例如，先后双击中性姿势和创建的姿势，查看当角色处于该姿势时如何自动应用修正形状。

16. 重复此过程来添加和编辑姿势，以便根据需要尽可能为角色创建基于姿势的形状。
