# 从融合变形创建新的目标形状

通过混合目标形状权重设置创建融合变形之后，可以将基础对象的当前融合变形状态烘焙到新的目标形状。

将融合变形保存为新目标形状

1. 在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，拖动一个或多个目标形状的权重滑块，使基础对象以您希望的方式变形。请参见[设置目标形状的权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CDC3D7EC-6D02-4319-A4E9-ACCC7ED47D30.htm)。

2. 选择基础对象。

3. 在形变编辑器中，选择“创建 > 添加当前选择作为目标”(Create > Add Selection as Target)。如果要创建不同类型的目标形状（切线或变换类型），请选择 ![图：在形变编辑器中，选择“创建 添加当前选择作为目标”(Create Add Selection as Target)。如果…](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 296 字 <300 且带图" -->。

  Maya 将为融合形变变形器创建一个新的目标形状，该形状将显示在形变编辑器中。

4. 拖动新目标形状的权重滑块，使此新目标形状成为基础对象上的融合变形。
