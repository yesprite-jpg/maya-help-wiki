# 绘制融合变形权重

通过“绘制融合变形权重工具”(Paint Blend Shape Weights Tool)，可以使用 Maya® Artisan™ 笔刷在具有融合形变变形器（请参见[创建融合形变变形器](创建融合形变变形器.md)）的对象上绘制融合变形权重。

该工具可用于逐顶点设置融合变形权重，从而更精细地控制目标形状对基础形状所具有的影响量。使用该工具还可以为每个目标形状绘制权重，并且可以混合目标形状及创建部分目标。

也可以使用“镜像变形器权重选项”(Mirror Deformer Weights Options)来镜像融合形变变形器权重。请参见[镜像变形器权重](../修改变形器/镜像变形器权重.md)。

绘制融合变形权重时，还可以执行下列操作：

- 从绘制的基础形状创建新的目标形状。请参见[从绘制的基础形状创建新的目标形状](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-950716A4-19CF-4C14-96F1-FD6B4D48663C.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3BAA)。

- 设置绘制的融合变形权重的关键帧，以便在目标形状与其基础形状之间创建动画过渡效果。请参见[设置绘制的融合变形权重的动画](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-950716A4-19CF-4C14-96F1-FD6B4D48663C.htm#GUID-950716A4-19CF-4C14-96F1-FD6B4D48663C__WS1A9193826455F5FF6026605B1181C8F4F2E-3BB7)。

- 导入或导出融合变形权重贴图。

  使用融合变形权重贴图可以将属性值映射到相对于 UV 的基础形状曲面顶点上。借助导入的融合变形权重贴图，使用映射的值可将工具设置应用到基础形状顶点。为了产生很好的导入/导出结果，请确保基础形状具有很好的 UV。请参见[导入融合变形权重贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-950716A4-19CF-4C14-96F1-FD6B4D48663C.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3B91)和[导出融合变形权重贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-950716A4-19CF-4C14-96F1-FD6B4D48663C.htm#WS1A9193826455F5FF6026605B1181C8F4F2E-3B9D)。

绘制融合变形权重

1. 选择基础对象（应用了融合形变变形器的对象）。

2. 打开[形变编辑器](形变编辑器.md)。

3. 在形变编辑器中，选择要绘制其权重的目标形状并将其权重滑块拖动到 1。

  目标形状现在对基础对象的拓扑具有 100% 的影响。

4. 选择[“变形 > (绘制权重)融合变形”(Deform > (Paint Weights) Blend Shape)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E49E9C30-D03A-456D-B7E8-FF99DA8C11E4.htm) > ![图：选择“变形 (绘制权重)融合变形”(Deform (Paint Weights) Blend Shape) 。 “绘制融…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 2418 字 ≥300，非承重" -->。

  “绘制融合变形权重工具”(Paint Blend Shape Weights Tool)设置将在“工具设置”(Tool Settings)编辑器中打开，并且中。请参见[“绘制融合变形权重工具”设置](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E49E9C30-D03A-456D-B7E8-FF99DA8C11E4.htm#WS17956D7ADBC6E736-6A42F0D5117AE3104C1-7FFA)。

5. 在“笔刷”区域中，根据需要调整“不透明度”(Opacity)设置。

6. 在“目标”(Target)区域中，从目标列表中选择要在基础形状上绘制其权重的目标形状。该目标形状与在形变编辑器中其权重设置为 1 的目标形状相同。

设置绘制的融合变形权重的动画

1. 执行下列操作之一：

  - 在场景视图中，选择要设置其绘制的融合变形权重的关键帧的目标形状，然后选择“关键帧 > 设置融合变形目标权重关键帧”(Key > Set Blend Shape Target Weights Keys)。

    该菜单项为选定目标形状设置绘制的融合变形权重的关键帧。

  - 在“绘制融合变形权重工具”(Paint Blend Shape Weights Tool)设置中，从目标列表中选择要设置其绘制的融合变形权重的关键帧的目标形状，然后单击“为选定目标权重设置关键帧”(Key Selected Target Weights)按钮。

    该按钮会为在目标列表中选定的目标形状设置绘制的融合变形权重的关键帧。

从绘制的基础形状创建新的目标形状

1. 按上一过程中的步骤操作，直到已创建要另存为新目标形状的变形。

2. 选择变形的基础形状，然后选择编辑 > 复制(Edit > Duplicate)。

  变形的基础形状的副本会显示在基础形状上。

3. 选择“移动工具”(Move Tool)，然后将变形的基础形状的副本从原始基础形状拖开。

4. 使用当前目标形状的命名约定，重命名变形的基础形状的副本。

5. 选择变形的基础形状的副本，然后按住 Shift 键并单击原始基础形状。

6. 选择“变形 > (编辑)融合变形 > 添加”(Deform > (Edit) Blend Shape > Add) > ![图：选择“变形 (编辑)融合变形 添加”(Deform (Edit) Blend Shape Add) 以打开融合变形添加选…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2418 字 ≥300，非承重" --> 以打开[融合变形添加选项](../变形器参考/“变形”%28Deform%29菜单/“融合变形”%28Blend%20Shape%29菜单/融合变形添加选项%28Blend%20Shape%20Add%20Options%29.md)。

  会将创建的变形基础形状的副本作为新的目标形状添加到融合形变变形中。

导出融合变形权重贴图

1. 在基础形状上绘制融合变形权重，直到获得希望导出为一个贴图的变形或外观为止。

2. 选择绘制的基础形状。

3. 在工具设置中，打开“属性贴图”(Attribute Maps)区域，然后打开“导出”(Export)区域。

4. 设定“导出”(Export)设置，然后单击“导出”(Export)按钮。有关“导出”(Export)设置的描述，请参见[“绘制融合变形权重工具”设置](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E49E9C30-D03A-456D-B7E8-FF99DA8C11E4.htm#WS17956D7ADBC6E736-6A42F0D5117AE3104C1-7FFA)。

  将显示“导出”(Export)浏览器窗口。

5. 浏览到要将贴图保存到的位置，指定贴图的名称，然后单击“导出”(Export)。默认情况下，Maya 会将贴图放置在当前项目的 *sourceimages* 文件夹中。

  会将基础形状的当前变形另存为一个属性贴图。

导入融合变形权重贴图

1. 选择变形的基础形状。

2. 在“绘制融合变形权重工具”(Paint Blend Shape Weights tool)设置中，打开“属性贴图”(Attribute Maps)区域，然后打开“导入”(Import)区域。

3. 设定“导入”(Import)设置，然后单击“导入”(Import)按钮。有关“导入”(Import)设置的描述，请参见[“绘制融合变形权重工具”设置](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E49E9C30-D03A-456D-B7E8-FF99DA8C11E4.htm#WS17956D7ADBC6E736-6A42F0D5117AE3104C1-7FFA)。

  将显示“导入”(Import)浏览器窗口。

4. 浏览到要导入的贴图所在的位置，选择贴图文件，然后单击“导入”(Import)。

  基础形状会根据导入的属性贴图指定的工具设置而变形。
