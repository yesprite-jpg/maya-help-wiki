# 设置目标形状权重的关键帧

使用[形变编辑器](形变编辑器.md)，可以为目标形状、组或融合形变变形器的权重值设置关键帧。在 1 处为单个目标形状的权重设置关键帧会仅对该目标形状的影响设置关键帧，从而忽略其他目标形状的可能融合影响。

设置了权重值的关键帧后，可以在曲线图编辑器中编辑生成的曲线或者在摄影表中编辑关键帧。

**注**

- 若要在“时间滑块”(Time Slider)、“曲线图编辑器”(Graph Editor)和“摄影表”(Dope Sheet)中显示权重关键帧，必须在“形变编辑器”(Shape Editor)中选择融合形变变形器或[融合变形](../变形器参考/变形器节点/blendShape.md)节点，而不是基础对象或目标形状。

- 融合变形逐顶点权重属性设置为不可设置关键帧。若要为这些属性设置关键帧，请使用“脚本编辑器”(Script Editor)或者[“通道盒”(Channel Box)的“通道”(Channels)选项卡](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-19CD9DD8-0119-448F-A1B8-93C82A74B633)中的“为选定项设置关键帧”(Key Selected)或“为所有可设置关键帧的项设置关键帧”(Key All Keyable)菜单项。

为一个或多个选定目标形状的权重设置关键帧

1. 在“时间滑块”(Time Slider)中，单击要设置关键帧的帧。

2. 在[形变编辑器](形变编辑器.md)中，设置每个目标形状的权重，方法是拖动其滑块或者输入一个值以创建所需的融合变形。请参见[设置目标形状的权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CDC3D7EC-6D02-4319-A4E9-ACCC7ED47D30.htm)。

3. 选择一个或多个目标形状，然后执行以下操作之一，使用目标形状的当前权重值在此帧上设置关键帧：

  - 单击选定目标形状的滑块末端的“关键帧”(Key)图标 ![图：单击选定目标形状的滑块末端的“关键帧”(Key)图标 ，使其变为红色。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-08528BBC-C5EA-4094-B6B4-ECF9405CD0A2.png) <!-- baize:img-hook downloaded=false reason="正文 1660 字 ≥300，非承重" -->，使其变为红色。

  - 使用鼠标中键将“关键帧”(Key)图标拖动到时间轴中的帧上。

  - 在“关键帧”(Key)图标上单击鼠标右键，然后选择“当前关键帧”(Key Current)。也可以选择“0 处关键帧”(Key at 0)或“1 处关键帧”(Key at 1)，自动将目标形状的权重值设置为 0 或 1，然后设置关键帧。

  - 在选定目标形状名称上单击鼠标右键，然后选择“关键帧”(Key)。

  - 选择“形状 > 关键帧”(Shapes > Key)。

  这将根据当前权重值为每个选定目标形状设置关键帧。

  如果该目标形状存在关键帧，则“权重”(Weight)文本框将变为红色；如果移动到一个没有关键帧的帧，则将变为粉色；如果已从在该帧处设置了关键帧的对象更改权重值，则将变为淡粉红色。

4. 继续执行这些步骤，在基础对象上设置形状变形的动画。

**注**

可以使用相同的方法为选定融合形变变形器的权重设置关键帧。有关设置 BSD 权重的信息，请参见

设置一组目标形状的关键帧

1. 在“时间滑块”(Time Slider)中，单击要设置关键帧的帧。

2. 在“形变编辑器”(Shape Editor)中，选择或创建一个包含要设置关键帧的目标形状的组。请参见[创建目标形状或融合形变变形器组](创建目标形状或融合形变变形器组.md)。

3. 将该组的权重滑块设置为所需的值。

4. 单击滑块旁边的“关键帧”(Key)图标，或者在选定组上单击鼠标右键并选择“关键帧”(Key)。

  这将为该组的权重值设置关键帧，其中包括该组内每个目标形状的当前权重。

  还可以在该组上单击鼠标右键，然后选择“设置组成员关键帧”(Key Group Members)，直接在每个目标形状上设置关键帧。

移除权重关键帧

1. 在“形变编辑器”(Shape Editor)中，选择一个或多个目标形状、组或融合形变变形器。

2. 在“时间滑块”(Time Slider)中，转到已为选定项目设置关键帧的帧。

3. 在选定项目之一对应的“关键帧”(Key)图标 ![图：在选定项目之一对应的“关键帧”(Key)图标 上单击鼠标右键，然后选择“移除关键帧”(Remove Key)。 这将在此…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-08528BBC-C5EA-4094-B6B4-ECF9405CD0A2.png) <!-- baize:img-hook downloaded=false reason="正文 1660 字 ≥300，非承重" --> 上单击鼠标右键，然后选择“移除关键帧”(Remove Key)。

  这将在此帧上移除每个选定项目的权重对应的关键帧。

使用通道盒设置目标形状权重的关键帧

1. 在“时间滑块”(Time Slider)中，单击要设置关键帧的帧。

2. 在“通道盒”(Channel Box)中，在基础对象的“输入”(INPUT)列表下选择一个目标形状通道。

3. 通过在视图中按住鼠标中键并拖动或者输入一个值，设置目标形状通道的权重值。

4. 按 S 键，或者在目标形状通道上单击鼠标右键，然后选择“为选定项设置关键帧”(Key Selected)。
