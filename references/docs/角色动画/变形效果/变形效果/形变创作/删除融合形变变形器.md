# 删除融合形变变形器

删除融合形变变形器（[融合变形节点](../变形器参考/变形器节点/blendShape.md)）时，会从基础对象中移除该变形器及其所有目标形状。但是，基础对象将调整节点作为输入节点保留，因此会保留可能已对基础对象做出的任何调整。

**注**

删除融合变形节点时，不会删除基础形状的 ShapeOrig 节点，但是如果不想该节点位于场景中，则可手动将其删除或删除对象历史（选择

“编辑 > 按类型删除 > 历史”(Edit > Delete by Type > History)

或按 Alt+Shift+D）。

删除融合形变变形器

1. 选择基础对象，然后执行下列任一操作：

  - 在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中，选择融合形变变形器并单击“删除”(Delete)图标 ![图：在形变编辑器中，选择融合形变变形器并单击“删除”(Delete)图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-3EF7ED14-D815-4F2E-9503-7F54D1715854.png) <!-- baize:img-hook downloaded=false reason="正文 409 字 ≥300，非承重" -->。

  - 在形变编辑器中，在融合形变变形器名称上单击鼠标右键，然后选择“删除”(Delete)。

  - 在通道盒中选择融合变形节点，然后按 Backspace 或 Delete 键 (Mac OS X)，或从主菜单中选择“编辑 > 删除”(Edit > Delete)。
