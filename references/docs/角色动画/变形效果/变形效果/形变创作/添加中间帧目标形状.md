# 添加中间帧目标形状

中间帧目标形状是您以现有目标形状的权重值（介于 0 和 1 之间（但不包括这些值））添加的目标形状。它们使您可以更精细地控制某些变形，尤其适用于面部动画。

中间帧目标形状既可以保持绝对状态，也可以相对于招牌目标形状（创建中间帧形状所使用的目标形状）的状态。如果是相对的，当编辑招牌目标形状（例如，使用雕刻）时，中间帧形状将相对于新形状一起移动。还可以选择要用于使中间帧形状缓入缓出招牌目标形状的插值类型。

创建中间帧目标形状

  在[形变编辑器](形变编辑器.md)中，将目标形状的权重滑块拖动到中间帧形状所需的值。它可以是除 1 以外的任何值。

  选择“创建 > 添加中间帧目标”(Create > Add In-Between Target) > ![图：选择“创建 添加中间帧目标”(Create Add In-Between Target) 以选择中间帧目标形状是绝对形状…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1752 字 ≥300，非承重" --> 以选择中间帧目标形状是绝对形状还是相对于招牌形状，或者在[添加融合变形中间帧目标选项(Add Blend Shape In-Between Target Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DAECBF43-2EC4-47BD-8EB2-E54FE708E349.htm)中设置自定义的最大影响权重值。

  也可以在招牌目标形状的权重滑块上单击鼠标右键，然后选择“添加中间帧目标”(Add In-Between Target)，以在当前权重值处创建绝对中间帧目标形状。“绝对”(Absolute)是默认设置，但可以在[添加融合变形中间帧目标选项(Add Blend Shape In-Between Target Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DAECBF43-2EC4-47BD-8EB2-E54FE708E349.htm)中将其更改为“相对”(Relative)。

中间帧目标形状将添加到招牌目标形状下，以其名称和最大影响权重值作为后缀。

招牌目标形状的权重滑块中将添加一个橙色条，以表示新中间帧目标的最大影响权重。

3. 如果创建了相对中间帧目标形状，请选择“插值”(Interpolation)类型（“线性”(Linear)、“平滑”(Smooth)或“自定义”(Custom)），然后单击小曲线框以编辑用于插值的曲线形状。

  选择中间帧目标形状，然后单击“编辑”(Edit)按钮开始编辑基础对象。招牌目标形状上的权重值将在其权重滑块中自动设置为中间帧形状的橙色条（中间帧形状的最大影响权重）。

  可以重复上述过程，为招牌目标形状添加更多中间帧形状。多个中间帧形状按最大影响权重由低到高排序。

## 将选定对象添加为中间帧目标形状

除了即时创建中间帧目标形状以外，还可以添加选定对象来创建中间帧目标形状，这与使用多个目标对象创建目标形状的方法相同。这可以是基础对象或其他对象。

如果选择多个对象用于添加中间帧形状，选择对象的顺序将影响这些形状的后续权重。第一个选定对象的中间帧形状将使用设置的当前或自定义目标权重，而每个后续中间帧形状会根据选择的对象数量将原始权重增加两倍、三倍或四倍，依此类推。例如，如果选择四个对象，则四个中间帧目标形状的权重将分别为 0.2、0.4、0.6 和 0.8。

将对象添加为中间帧目标形状

1. 在[形变编辑器](形变编辑器.md)中，将招牌目标形状的权重滑块拖动到中间帧形状所需的值。

2. 选择一个或多个要用于中间帧形状的对象。

  选择“创建 > 添加当前选择作为中间帧目标”(Create > Add Selection as In-Between Target) > ![图：选择“创建 添加当前选择作为中间帧目标”(Create Add Selection as In-Between Targ…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1752 字 ≥300，非承重" -->，以选择中间帧目标形状是绝对形状还是相对于招牌形状，或者在[添加融合变形中间帧目标选项(Add Blend Shape In-Between Target Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DAECBF43-2EC4-47BD-8EB2-E54FE708E349.htm)中设置自定义的最大影响权重值。

  也可以在招牌目标形状的滑块上单击鼠标右键，然后选择“添加当前选择作为中间帧目标”(Add Selection as In-Between Target)，以在招牌目标形状的当前权重值处创建绝对中间帧目标形状。“绝对”(Absolute)是默认设置，但可以在[添加融合变形中间帧目标选项(Add Blend Shape In-Between Target Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DAECBF43-2EC4-47BD-8EB2-E54FE708E349.htm)中将其更改为“相对”(Relative)。

4. 如果创建了相对中间帧目标形状，请选择“插值”(Interpolation)类型（“线性”(Linear)、“平滑”(Smooth)或“自定义”(Custom)），然后单击小曲线框以编辑用于插值的曲线形状（拖动曲线上的点）。

  选择中间帧形状，然后单击“编辑”(Edit)按钮开始编辑目标对象。父目标形状上的权重值将在其权重滑块中自动设置为中间帧的橙色条（中间帧的最大影响权重）。
