# 镜像目标形状

可以使用“形变编辑器”(Shape Editor)在基础对象上镜像目标形状。镜像根据所选的轴使目标形状显示在基础对象上的对称中。如果目标形状具有中间帧形状，它们也会被镜像。

镜像时将不会创建其他目标形状，即：您要镜像对象上的实际目标形状，而非创建其镜像版本。如果要执行该操作，请先复制目标形状（请参见[复制目标形状](复制目标形状.md)），然后对其进行镜像。

如果 Maya 中的对称尚未启用，则会对镜像操作激活，但在完成后禁用。如果对称处于启用状态，则会在镜像操作期间忽略其设置，并在镜像完成后恢复。

镜像目标形状

1. 在[形变编辑器](形变编辑器.md)中，选择一个或多个目标形状或一组目标形状。

2. 选择“形变 > 镜像目标”(Shapes > Mirror Target) > ![图：选择“形变 镜像目标”(Shapes Mirror Target) ，或者在选定的目标形状之一上单击鼠标右键并选择“镜像…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 940 字 ≥300，非承重" -->，或者在选定的目标形状之一上单击鼠标右键并选择“镜像目标”(Mirror Target)。

  对于一组目标形状，请在组名称上单击鼠标右键，然后选择“镜像组成员”(Mirror Group Members)。

3. 在“镜像目标选项”(Mirror Target Options)中，选择要用于镜像的方向和对称轴（默认情况下，使用对象的 -X 轴）。

  根据当前选项，目标形状的对称副本将显示在基础对象上。

## 镜像目标选项(Mirror Target Options)

选择要用于镜像目标形状的方向和对称轴。

### 镜像方向(Mirror Direction)

要镜像目标形状的轴方向：+ 或 -（默认）。

### 对称轴(Symmetry Axis)

- 对象 X/Y/Z (Object X/Y/Z)：使用枢轴点定义的对象 X、Y 或 Z 轴进行镜像。“对象 X”(Object X)是默认设置。

- 拓扑(Topology)：使用对象的实际拓扑定义镜像轴。为了获得更精确的结果，尤其是在高分辨率网格中，请使用该方法而非“对象 X/Y/Z”(Object X/Y/Z)。

  如果尚未为对象定义对称接缝，则系统会提示您选择一条边（已启用“边”(Edge)模式）作为镜像轴。

  存储拓扑对称接缝边(Store topological symmetry seam edges)：仅当选择“拓扑”(Topology)时才可用。该选项将最后定义的边存储为用于此融合形变变形器的对称接缝，并与[翻转目标(Flip Target)](翻转目标形状.md)命令共享。如果镜像的目标形状属于另一个融合形变变形器，则系统会提示您再次选择一条边。
