# 可变形对象、点和变形器成员身份

变形器可以在任何可变形对象上创建变形效果，其中包括 NURBS 曲线、NURBS 曲面、多边形曲面（网格）和晶格。

Maya 细分曲面也可变形。若要了解详细信息，可以从 [Maya 文档归档](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D2DE8439-F0D9-41B1-B9BB-F38977E52501)下载**细分曲面手册**。

使用 Maya 的 API 开发工具，可以定义各自的自定义可变形对象。有关详细信息，请参见 Maya 开发人员帮助。

角色的模型可以由一个可变形对象（例如，一个大的多边形曲面）或多组可变形对象（例如，多组 NURBS 曲面）组成。

## 控制点

可变形对象是其结构由控制点定义的任何对象。控制点包括 NURBS 控制顶点 (CV)、多边形顶点有晶格点。在本手册中，控制点通常称为点，可变形对象的控制点通常称为可变形对象点。

当创建支持多边形组件的变形器时，Maya 会自动将边和面转化为顶点。例如，选择循环边，然后选择“创建变形器 > 簇”(Create Deformers > Cluster)将簇添加到选定的边。

## 变形器成员身份

可以使用以下几种方法来编辑变形器集成员身份：

#### 组件标记(Component Tags)

使用“组件标记”(Component Tags)来定义成员身份

“组件标记”(Component Tags)表达式有助于轻松地动态定义变形器成员身份。可以在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中每个形状节点的“组件标记”(Component Tags)区域中编辑“组件标记”(Component Tags)成员身份。

若要使用“组件标记”(Component Tags)，请在[“动画”(Animation)首选项（在“设置”(Settings)下）](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-0817C74B-C95C-4E5F-BCFA-26DEE1D7747F)的“窗口 > 设置/首选项 > 首选项”(Windows > Settings/Preferences > Preferences)中激活**“组件标记”(Component Tags)**选项。这样，系统将自动为每个几何体节点指定组件标记属性。

有关详细信息，另请参见[组件标记节点](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3F9B8FA5-82C0-483C-840E-86784CA4F548.htm)和[为几何体指定组件标记](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-788B1C8B-7F45-4862-BC42-0A334DFECFD3.htm)。

#### 变形器集

创建变形器时，使用变形器集将变形器可能会影响到的所有可变形对象点都放置在一个分组中，称为**“变形器集”**。此集是可编辑的。有关如何编辑集成员身份的详细信息，请参见[变形器集](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DB98594C-782E-41FA-95AA-A6B3612CA775.htm)。
