# 可视化变形器权重

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-889B2E93-B1A5-42D7-9CB5-4408CC0D7121.png) <!-- baize:img-hook downloaded=false reason="正文 431 字 ≥300，非承重" -->

可以激活颜色可视化模式以进行变形器权重设置，从而直观地反馈变形效果。如果要进行变形器衰减疑难解答，这很有用。请参见[创建变形器衰减](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2E227658-3F8B-424F-9B54-F9841FFDFC9E.htm)。

为变形器启用权重可视化

1. 选择应用了变形的几何体，然后在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中打开**“形状”(Shape)**选项卡（例如 *pSphereShape1*）。

2. 展开**“网格控制”(Mesh Controls)**构件，然后从**“权重可视化”(Weights Visualization)**菜单中选择变形器。变形器权重显示为颜色渐变。变形器显示为均匀黄色，因为它均匀应用于几何体。如果使用变形器衰减，您将看到使用颜色显示的衰减区域。
