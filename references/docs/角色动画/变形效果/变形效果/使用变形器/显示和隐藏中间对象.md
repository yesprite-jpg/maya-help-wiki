# 显示和隐藏中间对象

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-18F963A9-A2D7-4CA7-B4B1-EDBC323666BF.png) <!-- baize:img-hook downloaded=false reason="正文 558 字 ≥300，非承重" -->

中间对象是对象在变形之前的形状。变形对象后，仍可通过显示其中间对象查看原来的形状。要判断变形的效果，将中间对象与变形的对象进行比较可能是一种很有用的方法。

另请参见[原始几何体](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-EEF323A6-8692-4D74-8EAA-5481BF437D42.htm)，当您使用[组件标记](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3F9B8FA5-82C0-483C-840E-86784CA4F548.htm)和变形器时，它是中间对象的名称。

显示中间变形对象

1. 选择正在变形的对象。

2. 在[“变形”(Deform)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C1B5085D-3229-4BE8-989E-95C460ADB79C.htm)的“编辑”(Edit)部分中选择“变形 > 显示中间对象”(Deform > Display Intermediate Objects)。

隐藏中间变形对象

1. 选择正在显示的中间对象。

2. 在[“变形”(Deform)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C1B5085D-3229-4BE8-989E-95C460ADB79C.htm)的“编辑”(Edit)部分中选择“变形 > 隐藏中间对象”(Deform > Hide Intermediate Objects)。

3. 更改变形器。

## Show Original Geometry

默认情况下，变形对象几何体上原始几何体的状态处于隐藏状态，但您可以显示它。

**注**

只有具有组件标记且已变形的几何体才允许您访问原始几何体状态。有关如何将组件标记添加到几何体的信息，请参见

为几何体指定组件标记

。

在场景中显示原始几何体：

1. 在查看器窗口中选择几何体。

2. 在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中，转到“<*几何体名称*>Orig”选项卡，然后在“对象显示”(Object Display)构件中，启用**“中间对象”(Intermediate Object)**选项。
