# 使用变形器的动画

可以在变形器的任何可设置关键帧的属性（或通道）上设置关键帧。可以在“通道盒”(Channel Box)、“时间滑块”(Time Slider)、“曲线图编辑器”(Graph Editor)、“摄影表”(Dope Sheet)中设置关键帧，或者可以通过使用 Maya 嵌入式语言 (MEL™) 命令设置关键帧。

设置角色时，可以通过添加新属性然后定义新属性与变形器属性之间的关系，来创建驱动变形器属性的属性。

可以从“添加属性”(Add Attribute)窗口（[修改 > 添加属性(Modify > Add Attribute)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3C81CEBF-A92A-493D-9630-7F9AE4C5B74C)）添加新属性。

可以使用“连接编辑器”(Connection Editor)（[窗口 > 常规编辑器 > 连接编辑器(Windows > General Editors > Connection Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2622D368-1DD5-45BA-9560-93626A5751FD)）、使用“设置受驱动关键帧”(Set Driven Key)窗口（“关键帧 > 设置受驱动关键帧 > 设置”(Key > Set Driven Key > Set) > ![图：可以使用“连接编辑器”(Connection Editor)（窗口 常规编辑器 连接编辑器(Windows Genera…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 520 字 ≥300，非承重" -->）或者通过在“表达式编辑器”(Expression Editor)（[窗口 > 动画编辑器 > 表达式编辑器(Windows > Animation Editors > Expression Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-251640EA-AACC-4F1B-A341-297F0F4CEFE4)）中编写表达式，定义属性之间的关系。
