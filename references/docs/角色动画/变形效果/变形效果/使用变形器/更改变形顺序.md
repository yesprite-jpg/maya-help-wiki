# 更改变形顺序

使用多个变形器变形对象时，变形的最终效果可能会因变形发生的顺序而异。默认情况下，按照为对象创建变形器的顺序进行变形。第一个创建的变形器第一个将对象变形，最后一个创建的变形器最后一个将对象变形。但是，可以更改或重新排列变形顺序，以获得所需效果。

有关常规信息，请参见[节点、历史和变形顺序](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6EC1834B-213C-45F9-B723-0BB8039325FC.htm)。

更改变形顺序

1. 在要变形的对象上单击鼠标右键，然后从标记菜单中选择“输入 > 所有输入”(Inputs > All Inputs)。

2. 在显示的“输入操作列表”(List of input operations)窗口中，使用鼠标中键将变形器拖成您希望的出现顺序。

更改点调整的变形顺序

1. 在要变形的对象上单击鼠标右键，然后从标记菜单中选择“输入 > 所有输入”(Inputs > All Inputs)。

2. 在显示的“输入操作列表”(List of input operations)窗口中，使用鼠标中键拖动您要更改其顺序的调整节点的名称（默认名称：tweak*n*）。
