# 变形效果

可以将变形效果添加到角色和对象以增强其动画。变形器是可以使用简单操纵和关键帧不能进行的方式变换对象或对对象设定动画的工具。在其他软件包中，术语修改器和空间扭曲用于表示 Maya 称为变形器的功能。

变形器有两个主应用程序：建模曲面或将附加变形动画添加到对象。

## 变形器作为建模工具

可以使用变形器作为建模工具，用于塑造 NURBS 或多边形对象。您可以创建变形器（例如，雕刻变形器工具），然后使用它调整模型的形状。使用变形器完成建模时，请将变形器连同其余对象历史一起删除（选择“编辑 > 按类型删除 > 历史”(Edit > Delete by Type > History)）。删除对象的历史时，变形器将会删除，但所有变形操作将烘焙到对象的形状，使其保持最终变形状态。

请注意，在建模上下文中，对象的历史可以称为其构建历史。

## 变形器作为动画工具

可以将变形器用作动画工具。可以创建变形器，用变形器调整目标对象，然后随时间变化为变形器的属性设定关键帧以生成动画。例如，可以为面的模型创建融合形变变形器。然后，随着时间的推移，您可以操纵并在[形变编辑器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC.htm)中为融合形变变形器的目标形状权重设置关键帧，从而创建面部动画。
