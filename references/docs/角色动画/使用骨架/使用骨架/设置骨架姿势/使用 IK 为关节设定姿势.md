# 使用 IK 为关节设定姿势

1. 确定哪个 IK 解算器最适合您要达到的姿势。

  例如，旋转平面解算器是为关节链（如手臂，您希望肩部、肘部和腕部关节在同一平面内旋转）设定姿势的理想之选。请参见 [IK 解算器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-952FC4B3-19A6-4055-B034-3A7D15EC66D6.htm)。

2. 为要单独操纵的每个关节链创建 IK 控制柄。

  请参见[创建 IK 控制柄](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-A68E47F5-8F28-48C1-9B0F-370AA57ADDA8.htm)和[使用 IK 控制柄创建关节链](../构建骨架/设置关节链/创建带有%20IK%20控制柄的关节链.md)。

  请注意，若要使用样条线 IK，您将需要[创建样条线 IK 控制柄](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-356B7E1F-8715-4D8F-978A-888E145B4700.htm)。

3. 操纵 IK 控制柄并设置关键帧。

  使用[移动工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)和[旋转工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C2D0F80C-812B-465D-A634-DB6ECFABFCB3)，可以按与操纵任何其他对象相同的方式操纵 IK 控制柄。另请参见[移动对象和组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-ABF1A141-7860-4234-889B-00278F20B9A3)和[旋转对象和组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-169906C5-CBC4-45CD-8DFB-F716D51D6168)。
