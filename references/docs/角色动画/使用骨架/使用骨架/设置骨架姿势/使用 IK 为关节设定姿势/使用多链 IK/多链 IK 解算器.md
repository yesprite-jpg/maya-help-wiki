# 多链 IK 解算器

多链解算器可以同时解算多个 IK 控制柄。可以使用多链 IK 控制柄来制作复杂运动的动画，例如章鱼角色的触角运动。

带有多链解算器的 IK 控制柄按照与单链 IK 控制柄相同的方式来管理其关节链中的关节。请参见[单链 IK 解算器](../使用单链%20IK/单链%20IK%20解算器.md)。

**注**

IK 控制柄的

“优先级”(Priority)

和

“权重”(Weight)

属性仅应用于多链 IK 解算器。
