# 创建多链 IK 控制柄

1. 创建多链解算器。

  请参见[创建多链解算器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-D9184F1C-0D23-444A-BDA0-654D81C647C9.htm)。

2. 选择 IK 控制柄。

3. 在“属性编辑器”(Attribute Editor)中，选择 ikHandle 节点选项卡。

4. 在“IK 解算器属性”(IK Solver Attributes)部分中，从“IK 解算器”(IK Solver)下拉列表中选择 ikMCsolve。

  当前 IK 控制柄现已受多链 IK 解算器驱动。
