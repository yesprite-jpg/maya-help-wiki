# 删除 IK 控制柄

删除 IK 控制柄

1. 选择 IK 控制柄。

2. 执行下列操作之一：

  - 选择编辑 > 删除(Edit > Delete)。

  - 按 ![图：按 键。](../../../../../../.extension/assets/Maya-CharacterAnimation/GUID-E123888C-A84E-4D3D-92B0-F77B749C63C7.png) <!-- baize:img-hook downloaded=true reason="正文 108 字 <300 且带图" --> 键。

  选定的 IK 控制柄将从场景中删除。但是，IK 解算器节点仍存在于场景中，以便由场景中的其他 IK 控制柄和未来的 IK 控制柄使用。
