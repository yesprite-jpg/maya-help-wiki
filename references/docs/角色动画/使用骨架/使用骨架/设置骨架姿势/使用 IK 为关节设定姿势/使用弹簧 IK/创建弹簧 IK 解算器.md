# 创建弹簧 IK 解算器

加载并激活弹簧 IK 解算器

1. 在“命令行”(Command Line)或“脚本编辑器”(Script Editor)中，键入以下命令：

  ```text
ikSpringSolver;
```

弹簧 IK 解算器目前适用于所有 IK 控制柄。
