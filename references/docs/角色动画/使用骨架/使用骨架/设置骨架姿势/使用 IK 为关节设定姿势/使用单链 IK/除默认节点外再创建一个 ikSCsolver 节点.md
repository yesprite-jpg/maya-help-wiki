# 除默认节点外再创建一个 ikSCsolver 节点

创建其他单链 IK 解算器

1. 在“脚本编辑器”(Script Editor)或“命令行”(Command Line)中，键入以下 MEL 命令：

  ```text
	createNode ikSCsolver;
```

2. 按数字键区的 Enter 键。

  依存关系图中将显示新的 ikSCsolver*n* 节点。

场景中的任意 IK 控制柄均可使用该解算器。请参见[创建 IK 控制柄](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-A68E47F5-8F28-48C1-9B0F-370AA57ADDA8.htm)。
