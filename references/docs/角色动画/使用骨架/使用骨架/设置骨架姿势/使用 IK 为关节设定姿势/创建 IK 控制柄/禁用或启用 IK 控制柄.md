# 禁用或启用 IK 控制柄

禁用 IK 控制柄

1. 选择要禁用的 IK 控制柄。

2. 执行下列操作之一：

  - ![图：) 单击 IK 控制柄并从出现的标记菜单中选择“禁用 ikHandle”(Disable ikHandle)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 313 字 ≥300，非承重" -->) 单击 IK 控制柄并从出现的标记菜单中选择“禁用 ikHandle”(Disable ikHandle)。

  - 选择“骨架 > [禁用选定 IK 控制柄](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-9A36CA06-8824-4E13-B8E8-70746A3B1291)”(Skeleton > Disable Selected IK Handles)。

  选定 IK 控制柄现在已禁用。IK 控制柄已禁用时，它不再驱动其目标关节并且不能进行编辑。

启用 IK 控制柄

1. 选择要启用的 IK 控制柄。

2. 执行下列操作之一：

  - ![图：) 单击 IK 控制柄并从出现的标记菜单中选择“启用 ikHandle”(Enable ikHandle)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 313 字 ≥300，非承重" -->) 单击 IK 控制柄并从出现的标记菜单中选择“启用 ikHandle”(Enable ikHandle)。

  - 选择“骨架 > [启用选定 IK 控制柄](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-4A8D3B78-7A08-4EE5-A069-ACF12D63CBF6)”(Skeleton > Enable Selected IK Handles)。

  选定 IK 控制柄现在已启用。
