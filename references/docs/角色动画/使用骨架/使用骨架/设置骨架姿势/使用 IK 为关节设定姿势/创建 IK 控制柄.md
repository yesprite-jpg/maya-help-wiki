# 创建 IK 控制柄

**注**

提示：

本主题介绍如何将 IK 控制柄添加到现有关节链，但是也可以在创建关节链时创建 IK 控制柄。为此，请参见

创建带有 IK 控制柄的关节链

。

在现有关节链上创建 IK 控制柄

1. 在“装备”(Rigging)菜单集中执行以下操作之一：

  - 选择“骨架 > 创建 IK 控制柄”(Skeleton > Create IK Handle)。

  - 如果要先更改“IK 控制柄设置”(IK Handle Settings)，请选择“骨架 > 创建 IK 控制柄”(Skeleton > Create IK Handle) > ![图：如果要先更改“IK 控制柄设置”(IK Handle Settings)，请选择“骨架 创建 IK 控制柄”(Skele…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 443 字 ≥300，非承重" -->。有关设置信息，请参见 [IK 控制柄工具](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DF30CFD7-88EB-421F-9701-69318A1F3D16.htm)。

    例如，您可以使用“IK 控制柄工具设置”(IK Handle Tool Settings)来选择要用于计算链中关节方向的 IK 解算器。

  光标将变为工具十字线。

2. 单击要用作 IK 控制柄起始关节的关节。

3. 单击要用作 IK 控制柄末关节的关节。

  IK 控制柄将显示在关节链上，连接所选的起始关节和末关节。

  ![图：单击要用作 IK 控制柄末关节的关节。 IK 控制柄将显示在关节链上，连接所选的起始关节和末关节。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-81926FD8-6B98-476E-99B2-BB7BA439E6AC.gif) <!-- baize:img-hook downloaded=false reason="正文 443 字 ≥300，非承重" -->
