# 创建双骨骼 IK 控制柄

将双骨骼解算器指定给 IK 控制柄

1. 选择 IK 控制柄。

2. 在“属性编辑器”(Attribute Editor)中，选择“ikHandlen”选项卡。

3. 在“IK 解算器属性”(IK Solver Attributes)区域中，从“IK 解算器”(IK Solver)下拉菜单中选择“ik2Bsolver”。

  当前 IK 控制柄将立即使用双骨骼 IK 解算器。
