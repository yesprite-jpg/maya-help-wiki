# 创建双骨骼解算器

加载并激活双骨骼 IK 解算器

1. 在“命令行”(Command Line)或“脚本编辑器”(Script Editor)中，执行以下命令：

  ```text
ik2Bsolver;
```

现在，双骨骼 IK 解算器已可用于所有 IK 控制柄。
