# 重定目标工作流

使用 HumanIK 角色解算器，可以设置非破坏性动画重定目标。

重定目标动画

1. 将源和目标角色设置为 HumanIK 角色。请参见[设置 HumanIK 角色](../../../HumanIK/HumanIK/设置%20HumanIK%20角色/创建%20HumanIK%20骨架定义.md)。

2. 设置所需的重定目标选项，然后将动画重定目标。请参见[将动画从一个角色重定目标到另一个角色](../../../HumanIK/HumanIK/设置%20HumanIK%20重定目标/将动画从一个角色重定目标到另一个角色.md)。

3. （可选）[调整重定目标参数](../../../HumanIK/HumanIK/设置%20HumanIK%20重定目标/调整重定目标参数.md)。

4. （可选）[将重定目标的动画烘焙到目标角色](../../../HumanIK/HumanIK/设置%20HumanIK%20重定目标/将重定目标的动画烘焙到目标角色.md)。

  **注**

  不必烘焙即可查看动画重定目标的结果。
