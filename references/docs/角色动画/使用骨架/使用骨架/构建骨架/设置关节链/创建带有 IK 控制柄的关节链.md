# 创建带有 IK 控制柄的关节链

创建带有 IK 控制柄的关节链

1. 在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 > [创建关节](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-6789F045-72A8-49FE-9162-B9F86C737C4C)”(Skeleton > Create Joints) > ![图：在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 创建关节”(Skeleton Create Joint…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 439 字 ≥300，非承重" -->。

  [“关节工具”(Joint Tool)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4357347C-D00F-409F-8938-D0E81E54C8B8.htm)设置面板将显示。

2. 在“关节工具”(Joint Tool)设置中，启用“创建 IK 控制柄”(Create IK Handle)。

  这将使“IK 控制柄设置”(IK Handle Settings)在同一工具面板中变得可用。

3. 根据需要设定“IK 控制柄设置”(IK Handle Settings)。

  例如，根据在操纵此关节链时要使用的 IK 解算类型，将“当前解算器”(Current solver)选项设置为“单链”(Single-Chain)或“旋转平面”(Rotate-Plane)。另请参见 [IK 解算器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-952FC4B3-19A6-4055-B034-3A7D15EC66D6.htm)。

4. 关闭“关节工具”(Joint Tool)设置面板。

现在，当您使用“关节工具”(Joint Tool)创建关节链时，会自动使用关节链创建 IK 控制柄。

**注**

提示：

也可以为现有的关节链创建 IK 控制柄。请参见

创建 IK 控制柄

。
