# 创建关节或关节链

在绘制关节或关节链之前，首先需要用于放置它们的模型。有关创建模型的信息，请参见 [NURBS 建模](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-735A0B9A-2180-4FB8-9A7B-68F21F306E97)或[多边形建模](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-7941F97A-36E8-47FE-95D1-71412A3B3017)。

设定“关节工具”(Joint Tool)设置

1. 在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 > 创建关节”(Skeleton > Create Joints) > ![图：在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 创建关节”(Skeleton Create Joint…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" -->。

  将出现[“关节工具”(Joint Tool)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4357347C-D00F-409F-8938-D0E81E54C8B8.htm)设置面板。

2. 根据需要调整“关节工具”(Joint Tool)设置。

创建关节或关节链

1. 在“装备”(Rigging)菜单集（按 F3 键）中，选择[“骨架 > 创建关节”(Skeleton > Create Joints)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-6991EA14-4EBB-4A1D-BEA8-908E6B870C10)。

2. 在视图中，单击模型上要创建关节的位置。

  **注**

  提示：

  单击以创建关节，单击鼠标中键并拖动来移动之前放置的关节。

3. 在模型上再次单击要创建关节链中的下一个关节的位置。

  将在第一个关节和第二个关节之间出现骨骼。

4. 继续在视图中单击，直到创建完关节链中的所有关节。

5. 按 ![图：按 或 以完成关节链。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6222D533-8226-4499-A976-3C4A762C2345.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" --> 或 ![图：按 或 以完成关节链。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FA1B7B42-B0E1-4BCE-AE0F-14B8DE1EC8FC.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" --> 以完成关节链。

创建在模型中自动居中的关节或关节链

1. 单击“状态行”(Status Line)上的“捕捉到投影中心”(Snap to Projected Center)图标 ![图：单击“状态行”(Status Line)上的“捕捉到投影中心”(Snap to Projected Center)图标 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-39DB6D4F-3BE8-4BB3-8620-6DD3216BD7E7.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" -->，启用居中模式。

2. 在“装备”(Rigging)菜单集（按 F3 键）中，选择[“骨架 > 创建关节”(Skeleton > Create Joints)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-6991EA14-4EBB-4A1D-BEA8-908E6B870C10)。

3. 在视图中，单击模型上要创建关节的位置。

  关节自动在模型中居中。

  **注**

  如果模型具有多个网格层，则居中模式将最小化置换，并会将关节放置在层的中心。

4. 如果需要，请使用“移动工具”(Move Tool)重新定位关节。

  关节在其新位置中动态居中。

5. 在模型上再次单击要创建关节链中的下一个关节的位置。

  骨骼显示在第一个关节和第二个关节之间，第二个关节也是居中显示在模型中。

6. 继续在视图中单击，直到创建完关节链中的所有关节。

7. 按 ![图：按 或 以完成关节链。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6222D533-8226-4499-A976-3C4A762C2345.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" --> 或 ![图：按 或 以完成关节链。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FA1B7B42-B0E1-4BCE-AE0F-14B8DE1EC8FC.png) <!-- baize:img-hook downloaded=false reason="正文 762 字 ≥300，非承重" --> 以完成关节链。
