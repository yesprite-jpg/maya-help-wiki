# 设置首选角度

本主题假定您使用的是“装备”(Rigging)菜单集（按 F3 键）。

**注**

如果要整个关节链或骨架采用其首选角度，请选择关节链的父关节或骨架的根关节。

设定关节的首选角度

1. 选择关节。

2. 选择“骨架 > 设置首选角度”(Skeleton > Set Preferred Angle) > ![图：选择“骨架 设置首选角度”(Skeleton Set Preferred Angle) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 446 字 ≥300，非承重" -->。

3. 在“设置首选角度选项”(Set Preferred Angle Options)中，设置所需的选项。

使关节采用其首选角度

1. 选择关节。

2. 选择“骨架 > 采用首选角度”(Skeleton > Assume Preferred Angle) > ![图：选择“骨架 采用首选角度”(Skeleton Assume Preferred Angle) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 446 字 ≥300，非承重" -->。

3. 在“采用首选角度选项”(Assume Preferred Angle Options)下，设定选项。

  **注**

  也可以通过用鼠标右键 (

  ) 单击链或骨架，然后从出现的标记菜单中选择

  “采用首选角度”(Assume Preferred Angle)

  来设定关节链或骨架的

  “首选角度”(Preferred Angle)

  值。
