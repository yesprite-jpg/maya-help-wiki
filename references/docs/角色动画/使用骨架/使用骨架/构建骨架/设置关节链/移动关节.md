# 移动关节

可以使用绑定的蒙皮移动角色的关节，而不必分离其蒙皮。

移动关节

1. 从“工具箱”(Tool Box)中选择“移动工具”(Move Tool)（热键：W）。

2. 单击要移动的关节。

  将显示当前关节的变换操纵器。

3. 现在，可以按下并拖动变换操纵器以沿着其 X 轴、Y 轴和 Z 轴平移当前关节。

**注**

若要在移动关节时自动调整父关节的旋转轴（以继续指向骨骼下方），请启用[“移动蒙皮关节工具”(Move Skinned Joints Tool)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-27EB7E9A-A5E4-45D3-8FEA-DA52B3DF7404.htm)或[“移动工具”(Move Tool)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)的[“关节方向设置”(Joint Orient Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865#GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865__SECTION_37A0CC9901F44305A0D663A90AE5FBAB)中的“自动确定关节方向”(Automatically Orient Joints)选项。
