# 重定骨架根

通过更改其根关节可以更改骨架的层次。该过程称为重定根。可以早在其创建期间重定骨架根，以便用不同根的测试骨架的行为。

**注**

- 将会删除通过选定为新根关节的关节的任何 IK 控制柄。

- 通过重定骨架会影响骨架的根关节上的任何动画

重定骨架根

1. 选择需要的骨架中的关节作为新根。

  如果选择整个关节链的子关节，骨架的层次则会反转。

  如果选择骨架中间的关节，则会创建两个根关节下方的单独层次。

2. 在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 > [重定骨架根](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483.htm#GUID-5A485049-D0BD-4BBB-BE08-C3D502F17483__GUID-352FF44A-24F5-45E4-9F80-917E28B43382)”(Skeleton > Reroot Skeleton)。
