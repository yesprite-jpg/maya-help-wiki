# 手动确定关节局部轴的方向

手动确定关节局部轴的方向

1. 选择要设定其局部旋转轴方向的关节。

2. 选择“显示 > 变换显示 > 局部旋转轴”(Display > Transform Display > Local Rotation Axes)。

  将显示当前关节的局部旋转轴。

3. 在[状态行（工具栏）](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-86E5CEDA-4100-40AE-8F95-346206CF8456)中单击“按组件类型选择”(Select by Component Type) ![图：在状态行（工具栏）中单击“按组件类型选择”(Select by Component Type) 来启用“按组件类型选择”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-32DDECAE-95A5-4FC1-BA88-9CF80A9D601B.png) <!-- baize:img-hook downloaded=false reason="正文 501 字 ≥300，非承重" -->来启用“按组件类型选择”(Select by component type)模式，然后右键单击“选择杂项组件”(Select miscellaneous components) ![图：在状态行（工具栏）中单击“按组件类型选择”(Select by Component Type) 来启用“按组件类型选择”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-E241F4DE-4A0C-470D-ADA8-1700E700B2ED.png) <!-- baize:img-hook downloaded=false reason="正文 501 字 ≥300，非承重" -->图标，并启用“局部旋转轴”(Local Rotation Axes)。

  ![图：在状态行（工具栏）中单击“按组件类型选择”(Select by Component Type) 来启用“按组件类型选择”…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-F36D518A-CDD3-4ADF-A883-9DFF06A5B73B.gif) <!-- baize:img-hook downloaded=false reason="正文 501 字 ≥300，非承重" -->

  **注**

  “按组件类型选择”(Select by Component Type)

  必须处于活动状态，才会显示

  “选择杂项组件”(Select miscellaneous components)

  图标。

  现在可以选择关节的局部旋转轴了。

4. 选择局部轴。

  ![图：选择局部轴。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-5D3727A2-F2EA-4015-AB58-52BBB32FC32C.png) <!-- baize:img-hook downloaded=false reason="正文 501 字 ≥300，非承重" -->

5. 执行下列操作之一：

  - 从[工具箱](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B345E162-0149-4E09-AC98-48DCFC227F33)中选择并使用[旋转工具](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C2D0F80C-812B-465D-A634-DB6ECFABFCB3)（热键：E）。

  - 如果要输入局部轴的精确方向值，可以使用 MEL 命令，如下所示：

    ```text
	rotate -r -os 180 0 0;
```

    该命令会将当前关节的局部轴围绕其 X 轴旋转 180 度。
