# 插入关节

在现有的关节链中添加关节

1. 在“装备”(Rigging)菜单集（按 F3 键）中，选择“骨架 > 插入关节”(Skeleton > Insert Joints)。

  **注**

  - “插入关节工具”(Insert Joint Tool)没有工具设置。

  - 可将关节插入蒙皮角色的关节链中。但是，要使新插入的关节影响蒙皮，需要将其作为影响添加到蒙皮（[“蒙皮 > 编辑影响 > 添加影响”(Skin > Edit Influence > Add Influence)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9B2EF2CB-25AF-431D-8A53-62311A08B9ED.htm)）。

2. 单击要作为新关节的父对象的关节，然后将其拖动到要放置新关节的位置。

  ![图：单击要作为新关节的父对象的关节，然后将其拖动到要放置新关节的位置。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-B558D907-9DCA-4C5D-A30E-7A8D6C3183D6.gif) <!-- baize:img-hook downloaded=false reason="正文 373 字 ≥300，非承重" -->

3. 重复步骤 2，直到插入所需的所有关节。

4. 添加完关节后，按 Enter 键以退出“插入关节工具”(Insert Joint Tool)。

  已插入关节的骨骼会自动沿着关节链现有骨骼的轴定向。

  如果将关节插入绑定角色的骨架，该角色的绑定姿势会自动调整，并且会保留其蒙皮历史。
