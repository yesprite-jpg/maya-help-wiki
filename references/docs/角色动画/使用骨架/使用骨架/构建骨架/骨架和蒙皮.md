# 骨架和蒙皮

构建骨架时，应该考虑最终要采用哪种蒙皮方法。为将进行平滑蒙皮的对象构建骨架所需的构建策略不同于为刚性蒙皮构建骨架的构造策略或间接蒙皮方法（如晶格蒙皮或折回蒙皮）。

例如，由于平滑蒙皮启用可受多个关节影响的渐进变形，因此，您可以使用关节来创建类似于呼吸或肌肉动作的变形效果。为此使用关节不适用于刚性蒙皮。相反，对于刚性蒙皮，您需要使用屈肌来创建类似的变形效果。
