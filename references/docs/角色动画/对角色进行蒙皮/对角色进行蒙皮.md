# 对角色进行蒙皮

蒙皮是将建模曲面绑定到骨架的过程。可以使用蒙皮将任何模型绑定到其骨架，也可以通过在预先存在的骨架上建模以创建其蒙皮。使用蒙皮将模型绑定到骨架后，它与骨架关节和骨骼的变换相一致或背离。例如，如果使用蒙皮将模型的手臂绑定到其基础骨架，则旋转肘部关节会导致肘部的蒙皮发生折缝和褶皱。

Autodesk® Maya® 中存在三种类型的蒙皮：平滑蒙皮、刚性蒙皮和间接蒙皮。

## 平滑蒙皮

通过平滑蒙皮，您可以创建平滑并相连接的变形效果。平滑蒙皮指定多个关节和其他影响对象可以对模型上的相同点（CV、顶点或晶格点）产生不同的影响。有关平滑蒙皮的详细信息，请参见[平滑蒙皮](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-11007900-329F-40ED-9C38-BE4DB5C39832.htm)。

## 间接蒙皮

通过间接蒙皮，您可以将晶格或包裹变形器作为蒙皮绑定到骨架。如果角色是间接蒙皮的，则摆正其骨架姿势会导致绑定的变形器变换模型的蒙皮。有关间接蒙皮的详细信息，请参见[晶格变形器](../变形效果/变形效果/晶格变形器.md)和[包裹变形器](../变形效果/变形效果/包裹变形器.md)。
