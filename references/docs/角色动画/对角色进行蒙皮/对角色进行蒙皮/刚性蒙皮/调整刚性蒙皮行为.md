# 调整刚性蒙皮行为

如果不喜欢刚性蒙皮的行为，则可以分离蒙皮，编辑骨架或可变对象并设定新的绑定选项，然后重新绑定。蒙皮可以是检查绑定、分离和编辑骨架然后再次绑定的迭代过程。有关分离蒙皮的详细信息，请参见[分离刚性蒙皮](编辑刚性蒙皮/分离刚性蒙皮.md)。

如果只想移动、旋转或缩放某些蒙皮对象或关节，而不更改现有的刚性蒙皮点集和刚性蒙皮点权重，可以通过分离，然后重新附加骨架，或者通过分离，然后仅重新附加选定关节来实现该操作。有关详细信息，请参见[分离和重新附加到骨架](编辑刚性蒙皮/分离和重新附加到骨架.md)和[分离和重新附加选定关节](编辑刚性蒙皮/分离和重新附加选定关节.md)。

若要更改蒙皮变形效果，可以使用“组件编辑器”(Component Editor)或“绘制簇权重工具”(Paint Cluster Weights Tool)编辑刚性蒙皮点权重，与绘制簇变形器权重使用的工具相同。检查绑定时，可以使用“绘制簇权重工具”(Paint Cluster Weights Tool)查看每个关节的影响以及通过绘制对权重做更改。该工具提供了用来修改变形效果的一种直观方式。有关详细信息，请参见[绘制刚性蒙皮权重](设置刚性蒙皮/绘制刚性蒙皮权重.md)。
