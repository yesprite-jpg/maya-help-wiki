# 刚性蒙皮点集

在刚性蒙皮期间，Maya 将为每个关节创建一组刚性蒙皮点。该集包含所有会受特定关节影响的点（NURBS CV、多边形顶点或晶格点）。默认情况下，该集将被组织成一个划分，这意味着该集可以没有公用成员。

您可以在绑定蒙皮之前组织点到集的划分中，排列一些点以成为刚性蒙皮点，而其他点可以受以下的影响，例如，一个作为附近关节父对象的簇或晶格变形器。使用带刚性蒙皮的簇或晶格变形器时获取肩膀等区域平滑变形效果的很好的方法，并为使用屈肌提供了替代方法（请参见[屈肌](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CAD7F9C7-6639-495A-8DA6-C8A4E0FD68FE.htm)）。但是，必须提前计划，并仔细确定哪一个点受什么影响，否则您的角色会受双变形效果的影响。请参见[双重变换效果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-38065B7D-A597-45BB-A99B-AB9A85DC4CA5.htm)。

**注**

已从 Maya 中删除了刚性绑定菜单选项，以简化其他工作流。使用在

刚性蒙皮(Rigid skinning)

主题中提供的脚本命令仍可获得刚性绑定功能。您还可以使用每个顶点 1 个影响的平滑蒙皮获得刚性绑定。

有关集和划分的详细信息，请参见[集和划分](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B1DE4646-E52B-4611-87B6-E741F25E284B)（在手册的“基础知识”部分中）。
