# 绘制刚性蒙皮成员身份

绘制刚性蒙皮点集成员身份

1. 选择刚性蒙皮对象。

2. 转到平滑着色处理模式（热键：按 5）。

3. 选择[“变形 > (绘制权重)集成员身份工具”(Deform > (Paint Weights) Set Membership Tool)](../../../../变形效果/变形效果/变形器参考/变形器工具/绘制集成员身份工具%28Paint%20Set%20Membership%20Tool%29.md) > ![图：选择“变形 (绘制权重)集成员身份工具”(Deform (Paint Weights) Set Membership T…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 488 字 ≥300，非承重" -->。

4. 在“集成员身份”(Set Membership)框中，选择具有要编辑的点成员身份的关节集。

5. 使用笔刷添加、传递或移除集成员身份。

绘制拆痕效果

1. 选择平滑着色处理显示模式（热键：按 5 键）。

2. 选择圆柱体。

3. 选择[“变形 > (绘制权重)簇”(Deform > (Paint Weights) Cluster)](../../../../变形效果/变形效果/簇变形器/绘制簇权重工具.md) > ![图：选择“变形 (绘制权重)簇”(Deform (Paint Weights) Cluster) 。 在“工具设置”(Too…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 488 字 ≥300，非承重" -->。

  在“工具设置”(Tool Settings)窗口的“绘制属性”(Paint Attributes)区域中，请注意 joint1Cluster1.weights 按钮。

4. 选择刚性蒙皮点簇。例如，cluster-joint3Cluster1 > 权重。

  ![图：选择刚性蒙皮点簇。例如，cluster-joint3Cluster1 权重。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-600585C7-8500-4FD9-AD18-D608DB665F92.png) <!-- baize:img-hook downloaded=false reason="正文 488 字 ≥300，非承重" -->

5. 选择另一个刚性蒙皮点簇。例如，选择 cluster-joint4Cluster1 > 权重。

  ![图：选择另一个刚性蒙皮点簇。例如，选择 cluster-joint4Cluster1 权重。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-4492EB48-6878-4EE6-9760-E8A61121A519.png) <!-- baize:img-hook downloaded=false reason="正文 488 字 ≥300，非承重" -->

6. 检查另一个刚性蒙皮点簇。例如，检查 cluster-joint2Cluster1。

  ![图：检查另一个刚性蒙皮点簇。例如，检查 cluster-joint2Cluster1。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-3B27F213-0B26-4691-A0CC-99374C2D8424.png) <!-- baize:img-hook downloaded=false reason="正文 488 字 ≥300，非承重" -->

7. 使用“绘制簇权重工具”(Paint Cluster Weights Tool)的笔刷平滑变形效果。
