# 编辑雕刻屈肌通道

通道是“通道盒”(Channel Box)中显示的可设定关键帧属性。“通道盒”(Channel Box)提供一种简单方式来编辑骨骼晶格屈肌通道。

使用“通道盒”(Channel Box)编辑通道

1. 选择骨骼晶格屈肌节点（默认名称：boneFlexor*n*）。

2. 设定通道。

3. 单击要编辑的通道名称。
