# 复制关节晶格屈肌

创建晶格屈肌并进行调整之后，可能会决定在其他位置也需要有一块类似的晶格屈肌。例如，如果在角色的左肘部关节周围创建晶格屈肌，那么可能会决定在右肘部关节处创建一块类似的晶格屈肌。

此时可以复制关节晶格屈肌。复制关节晶格屈肌时，会复制所有属性值和连接。

请注意，也可以复制骨骼晶格屈肌。

若要复制关节晶格屈肌，请执行下列操作：

1. 转到绑定姿势（[蒙皮 > 转到绑定姿势(Skin > Go To Bind Pose)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-35ECFBC1-A65B-46AF-9542-213BD304C632.htm)）。

2. 选择屈肌（例如，选择名为 jointFfdnLattice 的晶格屈肌）。

3. 选择需要拥有该屈肌的副本的关节。

4. 在命令行中，输入 CopyFlexor。

**注**

已从 Maya 中删除了刚性绑定菜单选项，以简化其他工作流。使用在

刚性蒙皮(Rigid skinning)

主题中提供的脚本命令仍可获得刚性绑定功能。您还可以使用每个顶点 1 个影响的平滑蒙皮获得刚性绑定。
