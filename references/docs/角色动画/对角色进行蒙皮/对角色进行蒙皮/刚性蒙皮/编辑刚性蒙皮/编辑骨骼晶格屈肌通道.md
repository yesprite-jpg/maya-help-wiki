# 编辑骨骼晶格屈肌通道

默认情况下，骨骼晶格屈肌通道所指定的效果是由创建屈肌时为其选择骨骼的关节的子关节驱动的。大多数角色设置情况通常会期望如此。但是，可以指定骨架中的任何其他关节来驱动这些效果。（请参见[重新指定骨骼晶格屈肌关节](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-399A53A4-D7EB-4705-9340-6061EA172459.htm)。）

使用“通道盒”(Channel Box)编辑通道

1. 选择骨骼晶格屈肌节点（默认名称：boneFlexor*n*）。

2. 设定通道。

3. 单击要编辑的通道的名称。
