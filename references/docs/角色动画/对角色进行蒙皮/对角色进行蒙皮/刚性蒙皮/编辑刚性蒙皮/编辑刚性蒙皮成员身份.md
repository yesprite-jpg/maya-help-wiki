# 编辑刚性蒙皮成员身份

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-560FCC11-7234-4C47-AB0E-69D71713D529.png) <!-- baize:img-hook downloaded=false reason="正文 539 字 ≥300，非承重" -->

可以使用“编辑成员身份工具”(Edit Membership Tool)直接编辑刚性蒙皮点集成员身份。要采用更直观的方式，也可以使用“绘制集成员身份工具”(Paint Set Membership Tool)来绘制刚性蒙皮点集成员身份（请参见[绘制刚性蒙皮点集成员身份](绘制刚性蒙皮点集成员身份.md)）。

**注**

还可以使用“关系编辑器”(Relationship Editor)来编辑刚性蒙皮点集成员身份，但是比起使用“编辑成员身份工具”(Edit Membership Tool)或“绘制集成员身份工具”(Paint Set Membership Tool)，这种方法不够直观。

使用“编辑成员身份工具”(Edit Membership Tool)编辑集成员身份

1. 切换到对象选择模式。

2. 选择要编辑其集的关节。

3. 转到组件选择模式（单击“按组件类型选择”图标）。

4. 选择“变形 > > [编辑成员身份工具](../../../../变形效果/变形效果/变形器参考/“变形”%28Deform%29菜单.md#GUID-C1B5085D-3229-4BE8-989E-95C460ADB79C__GUID-41000A36-E60C-4590-B58D-25AED6CC509F)”(Deform > > Edit Membership Tool)。

5. 使用指针选择要更改其刚性蒙皮点集成员身份的点。

6. 要将点添加到当前选定的集中，请按 ![图：要将点添加到当前选定的集中，请按 键并单击要添加的点。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 539 字 ≥300，非承重" --> 键并单击要添加的点。

7. 要从当前选定的集中移除点，请按 ![图：要从当前选定的集中移除点，请按 键并单击这些点。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6BC67455-3D71-444F-B249-B8161AD6821F.png) <!-- baize:img-hook downloaded=false reason="正文 539 字 ≥300，非承重" --> 键并单击这些点。

8. 要将点添加到一些其他的刚性蒙皮点集中，请先选择刚性蒙皮点集的关节。该集中当前存在的点会显示为黄色。现在，如前面所述，通过按 ![图：要将点添加到一些其他的刚性蒙皮点集中，请先选择刚性蒙皮点集的关节。该集中当前存在的点会显示为黄色。现在，如前面所述，通过…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 539 字 ≥300，非承重" --> 键并单击要添加的点，可选中这些点。
