# 编辑关节簇通道和属性

通道是“通道盒”(Channel Box)中显示的可设定关键帧属性。“通道盒”(Channel Box)提供了一种编辑关节簇通道的简便方法。

使用“通道盒”(Channel Box)编辑刚性通道

1. 选择关节簇节点（默认名称：jointnCluster*n*）。

2. 若要编辑通道，请执行以下操作：

  - 单击要编辑的通道的名称。

  - 在场景中，单击鼠标中键并左右移动鼠标。通过移动鼠标，可以交互方式更改选定通道的值。移动鼠标时，请注意按 Ctrl 键可以提供更精细的控制，按 Shift 键可提供精细度较小的控制。

使用“属性编辑器”(Attribute Editor)编辑属性

1. 选择蒙皮簇节点（默认名称：jointCluster*n*）。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

3. 设定属性。
