# 分离刚性蒙皮

绑定蒙皮后，您可能决定要修改骨架、更改绑定姿势或在蒙皮上执行进一步建模。若要执行这些操作，首先必须从骨架上取消绑定蒙皮，然后再次绑定蒙皮。

分离蒙皮将不保留刚性蒙皮点集和刚性蒙皮点权重。如果要保留刚性蒙皮点集，请参见[分离和重新附加到骨架](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-B2047421-3F7F-4EBE-8DCB-66F9909E286B.htm)和[分离和重新附加选定关节](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4004426E-A1D4-41B9-ABD3-131426A68EE9.htm)。

分离蒙皮

1. 选择要分离的蒙皮对象。

2. 选择[“蒙皮 > 取消绑定蒙皮”(Skin > Unbind Skin)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4C4597A6-BC0F-401A-96E9-A81AD26C040E.htm) > ![图：选择“蒙皮 取消绑定蒙皮”(Skin Unbind Skin) 。 此时将显示“取消绑定蒙皮选项”(Unbind Ski…](../../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 266 字 <300 且带图" -->。

  此时将显示“取消绑定蒙皮选项”(Unbind Skin Options)窗口。

3. 单击“分离”(Detach)以分离蒙皮，然后关闭“分离蒙皮选项”(Detach Skin Options)。
