# 编辑刚性蒙皮点权重

使用“组件编辑器”(Component Editor)，您可以直接修改各个刚性蒙皮点权重的值。

查询刚性蒙皮点权重

1. 选择要编辑其权重的刚性蒙皮点。

2. 选择“窗口 > 常规编辑器(Window > General Editors) > [组件编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B698CC5D-2771-488E-98E8-2D4E31DB3B2D)”。

3. 单击“刚性蒙皮”(Rigid Skins)选项卡。“刚性蒙皮”(Rigid Skins)区域列出了指定给 CV、顶点或晶格点的权重，这些点通过刚性蒙皮绑定到骨架的关节。

修改刚性蒙皮点的权重

1. 在“组件编辑器”(Component Editor)电子表格中，单击要编辑的组件数据框。

2. 输入新值并按 ![图：输入新值并按 键 (Windows) 或 键 (Mac OS X)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6222D533-8226-4499-A976-3C4A762C2345.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 键 (Windows) 或 ![图：输入新值并按 键 (Windows) 或 键 (Mac OS X)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FA1B7B42-B0E1-4BCE-AE0F-14B8DE1EC8FC.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 键 (Mac OS X)。

一次修改多个刚性蒙皮点权重

1. 选择要编辑其权重的刚性蒙皮点。

2. 在“组件编辑器”(Component Editor)电子表格中，选择相应的选项卡，然后在要编辑的组件数据框中拖动。您也可以在按住 ![图：在“组件编辑器”(Component Editor)电子表格中，选择相应的选项卡，然后在要编辑的组件数据框中拖动。您也可…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-08667A50-F943-4CA7-AF8B-4BF2A40E3297.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 键的同时选择整行或整列的框。

3. 输入希望所有框包含的值，然后按 ![图：输入希望所有框包含的值，然后按 键 (Windows) 或 键 (Mac OS X)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6222D533-8226-4499-A976-3C4A762C2345.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 键 (Windows) 或 ![图：输入希望所有框包含的值，然后按 键 (Windows) 或 键 (Mac OS X)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-FA1B7B42-B0E1-4BCE-AE0F-14B8DE1EC8FC.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 键 (Mac OS X)。
