# 编辑关节晶格屈肌通道

“通道盒”(Channel Box)提供了一种编辑关节晶格屈肌通道的简便方法。

编辑通道

1. 选择关节晶格屈肌节点（默认名称：jointFlexor*n*）。

2. 设定通道。

3. 单击要编辑的通道的名称。
