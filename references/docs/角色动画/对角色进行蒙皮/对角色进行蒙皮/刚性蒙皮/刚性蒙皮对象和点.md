# 刚性蒙皮对象和点

在刚性蒙皮期间，可以将一个或多个可变形对象绑定到骨架。绑定之后，对象成为刚性蒙皮对象（蒙皮对象或蒙皮），其位置、方向和比例都由骨架的关节控制。可变形对象的点（CV、顶点或晶格点）则称为刚性蒙皮点或蒙皮点。

Maya 通过关节簇节点将刚性蒙皮对象绑定到关节。可更改刚性蒙皮变形效果的一种方法是编辑关节簇属性（或通道）。（请参见[编辑关节簇通道和属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-C8E1EDD2-E108-4833-A9C8-8072DA16AF19.htm)。）

**注**

已从 Maya 中删除了刚性绑定菜单选项，以简化其他工作流。使用在

刚性蒙皮(Rigid skinning)

主题中提供的脚本命令仍可获得刚性绑定功能。您还可以使用每个顶点 1 个影响的平滑蒙皮获得刚性绑定。

## 刚性蒙皮点权重

在刚性蒙皮期间，Maya 为每个刚性蒙皮点（例如，每个 NURBS 曲面的每个 CV）指定刚性蒙皮点权重，用于控制关节对点（例如 CV）的影响。默认情况下，每个关节可均衡影响其最近的蒙皮对象的蒙皮点，但您可以编辑关节影响蒙皮点的量。

刚性蒙皮与平滑蒙皮之间的主要区别在于，刚性蒙皮中仅有一个关节可以影响特定的蒙皮点（CV、顶点或晶格点），但在平滑蒙皮中，许多关节都可以影响相同的蒙皮点。
