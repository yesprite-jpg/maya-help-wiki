# 同时添加多个影响

可以同时向平滑蒙皮的几何体添加多个影响对象。这可以在装备角色时节省时间。

同时向平滑蒙皮的几何体添加多个影响对象

1. 将几何体平滑绑定至其骨架。请参见[绑定平滑蒙皮](../绑定平滑蒙皮.md)。

2. 创建蒙皮几何体的影响对象，并将它们移动到希望它们在影响蒙皮时所在的位置。

3. 选择影响对象，然后按 Shift 键并单击平滑蒙皮几何体以将其包含在选择中。

4. 在“装备”(Rigging)菜单集中，选择[“蒙皮 > 编辑影响 > 添加影响”(Skin > Edit Influences > Add Influence)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9B2EF2CB-25AF-431D-8A53-62311A08B9ED.htm) > ![图：在“装备”(Rigging)菜单集中，选择“蒙皮 编辑影响 添加影响”(Skin Edit Influences Add…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 382 字 ≥300，非承重" -->。

5. 设定影响选项，然后执行以下操作之一：

  - 单击“添加”(Add)将选定对象作为新的影响添加到平滑蒙皮几何体，并关闭“添加影响选项”(Add Influence Options)窗口。

  - 单击“应用”(Apply)将选定对象作为新的影响添加到平滑蒙皮几何体，并使“添加影响选项”(Add Influence Options)窗口保持打开状态。
