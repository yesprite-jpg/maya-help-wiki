# 使用热量贴图绑定平滑蒙皮

绑定蒙皮并基于热量扩散技术设置初始权重

**注**

此方法仅适用于多边形网格。该方法不适用于具有错误形状的面的网格，例如长度为零的边或者任何由两个以上的面共享的边。

1. 选择要绑定的关节和网格，然后选择“蒙皮 > 绑定蒙皮”(Skin > Bind Skin) > ![图：选择要绑定的关节和网格，然后选择“蒙皮 绑定蒙皮”(Skin Bind Skin) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 544 字 ≥300，非承重" -->。

2. 在[绑定蒙皮选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm)中，将[“绑定方法”(Bind Method)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-DF0A38B1-7EF8-496C-8523-C1B5C3A1A321)设置为“热量贴图”(Heat Map)。

  **注**

  仅定义在网格

  内

  的影响对象将在

  “热量贴图”(Heat Map)

  绑定期间发热。例如，如果您将骨架绑定到的末关节延伸出网格，则末关节将不会在绑定期间接收任何权重，并且不会对网格产生任何影响。但是，如果骨骼穿透网格但其关节对象未穿透网格，则从该骨骼发射的所有影响都将传递到父关节，即使父关节超出网格。

3. 调整“热量贴图衰减”(Heatmap falloff)滑块来控制选定影响对象周围权重的衰减。

  这可以帮助减少热量贴图绑定期间小权重跨网格扩散的量。

  默认情况下，“热量贴图衰减”(Heatmap falloff)设置为 0.68，可提供更好的总权重。接近 0 的值可以生成平滑的结果，但可以使小权重在网格曲面的远处扩散。值越接近 1，生成的衰减就越尖锐，这会保持权重更接近影响对象，从而限制小权重的扩散。

4. 单击“绑定蒙皮”(Bind Skin)。
