# 设定点调整

更改点调整的变形顺序

1. 在场景中，将指针移动到蒙皮对象上并单击鼠标右键 (![图：在场景中，将指针移动到蒙皮对象上并单击鼠标右键 ()。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-EAD82E7D-F5FF-4F03-BB2B-BAB585D26B88.png) <!-- baize:img-hook downloaded=false reason="正文 395 字 ≥300，非承重" -->)。

2. 从标记菜单中，选择“输入 > 所有输入”(Inputs > All Inputs)。

3. 将指针移动到要更改其顺序的调整节点的名称（默认名称：tweak*n*）上。

4. ![图：) 的同时在操作的名称上（希望点调整发生所在的位置）拖动，然后释放鼠标按钮。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-D75F7EC7-14A4-4B03-B0A1-C445CF45AC10.png) <!-- baize:img-hook downloaded=false reason="正文 395 字 ≥300，非承重" -->) 的同时在操作的名称上（希望点调整发生所在的位置）拖动，然后释放鼠标按钮。

禁用调整节点

1. 打开调整节点的“属性编辑器”(Attribute Editor)。

2. 在“属性编辑器”(Attribute Editor)中，打开“节点行为”(Node Behavior)。

3. 将“节点状态”(Node State)设定为“无效果”(HasNoEffect)。

启用调整节点

1. 打开调整节点的“属性编辑器”(Attribute Editor)。

2. 在“属性编辑器”(Attribute Editor)中，打开“节点行为”(Node Behavior)。

3. 将“节点状态”(Node State)设定为“正常”(Normal)。
