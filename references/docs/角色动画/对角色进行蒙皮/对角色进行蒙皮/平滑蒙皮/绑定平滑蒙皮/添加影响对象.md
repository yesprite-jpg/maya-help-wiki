# 添加影响对象

可以在平滑蒙皮几何体处于任何姿势的情况下为其添加对象，以创建效果。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-F8D59E6D-D603-4D8F-A2B1-CCF18580FA6D.gif) <!-- baize:img-hook downloaded=false reason="正文 413 字 ≥300，非承重" -->

但是，在平滑蒙皮几何体不处于和处于绑定姿势时添加影响对象产生的结果略有不同。例如，如果向不处于绑定姿势的几何体添加影响对象，则放置影响对象的位置可能会发生某些变形，因为该区域中的权重会重新分布。

添加影响对象

1. 确定影响对象的位置。

2. 选择您希望对象影响的蒙皮或蒙皮对象（例如，NURBS 曲面）。

  **注**

  此过程不适用于单个组件。使用

  “编辑影响”(Edit Influences)菜单

  中的

  “衰减”(Dropoff)

  设置限制影响的范围。

3. 选择影响对象。

4. 选择“蒙皮 > 编辑影响 > 添加影响”(Skin > Edit Influences > Add Influences) > ![图：选择“蒙皮 编辑影响 添加影响”(Skin Edit Influences Add Influences) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 413 字 ≥300，非承重" -->。

5. 在[“编辑影响”(Edit Influences)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9B2EF2CB-25AF-431D-8A53-62311A08B9ED.htm)中设置“添加影响选项”(Add Influence options)，然后单击“添加”(Add)。
