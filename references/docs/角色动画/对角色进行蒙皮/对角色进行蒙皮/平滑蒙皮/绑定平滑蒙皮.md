# 绑定平滑蒙皮

绑定平滑蒙皮包括：设定平滑绑定选项、绑定蒙皮，然后用骨架来检查绑定。

绑定蒙皮

（如果您已经设置了所需的[绑定蒙皮选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm)，请使用这些步骤。）

1. 选择一个或多个可变形对象，然后选择骨架的根关节或肢体的父关节。

2. 选择“蒙皮 > 绑定蒙皮”(Skin > Bind Skin)。

首先设定绑定选项，然后设定绑定蒙皮

1. 选择骨架或关节，然后选择要绑定的可变形对象。

2. 选择“蒙皮 > 绑定蒙皮”(Skin > Bind Skin) > ![图：选择“蒙皮 绑定蒙皮”(Skin Bind Skin) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 729 字 ≥300，非承重" -->。

3. 在显示的[绑定蒙皮选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm)中，执行以下操作：

  - 设置[“绑定方法”(Bind Method)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-DF0A38B1-7EF8-496C-8523-C1B5C3A1A321)以指定您希望初始蒙皮期间关节如何影响附近的蒙皮点。

    有关这些选项如何影响初始蒙皮点权重的详细信息，请参见[平滑蒙皮的绑定方法](平滑蒙皮的绑定方法.md)。

  - 选择要使用的[“蒙皮方法”(Skinning Method)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F.htm#GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F__WS73099CC142F487557BFAA8DA122EC01152F4CDB)。

    例如，如果希望绘制权重在线性和双四元数蒙皮之间融合，请选择[“权重已融合”(Weight Blended)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-DA61F13E-4684-4ECC-BD36-36CA2F3103F5)。请参见[融合平滑蒙皮方法](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-B292915D-EA18-43DA-A817-58DDC3DF879D.htm)。

  - 设置要启用的[“归一化权重”(Normalize Weights)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-502B026E-67AD-456D-B870-1E3CBEDEB0A2)模式。

    （此模式在稍后编辑平滑蒙皮时将变得重要。请参见[平滑蒙皮权重归一化](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-97C10B22-F128-4464-A91C-CD798680365D.htm)。）

  - 设置[“最大影响”(Max Influences)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-496C8853-C876-4B04-885F-E34521CE3496)值以指定多少关节可以影响平滑蒙皮点。

    通常，最多有四个或五个关节可以影响角色的给定平滑蒙皮点。

  - 设置[“衰减速率”(Dropoff Rate)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm#GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812__GUID-B47CA3DD-4FCD-48A3-86E8-FCB70490DC07)以指定权重如何随关节距离而变化。

    （当绑定蒙皮时，“衰减速率”(Dropoff Rate)会应用到所有选定关节。每个关节对特定点的影响随着蒙皮点与关节之间的距离而变化。）

  - 必要时设定其他蒙皮选项。

4. 设置完[绑定蒙皮选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm)后，单击“绑定蒙皮”(Bind Skin)。

  也可以单击“保存”(Save)以保存设置的选项，而不绑定蒙皮。
