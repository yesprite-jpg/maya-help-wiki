# 平滑蒙皮权重归一化

缩小数量使其全部合计为一个的过程称为归一化。

为平滑蒙皮启用归一化后，Maya 会归一化权重值，以便在更改一个权重值时，自动更改受相同因素影响的其他点。

启用归一化后，Maya 会将受特定因素影响的所有蒙皮点的权重视为相互关联。确保所有受影响的蒙皮点值持续合计为一个使 Maya 能够跟踪其相对影响。

通过“归一化权重”(Normalize Weights)下拉菜单（位于“平滑绑定选项”(Smooth Bind Options)、“绘制蒙皮权重工具”(Paint Skin Weights Tool)和 skinCluster 节点中），可以设置希望 Maya 归一化权重的方式。请参见[设置归一化模式和归一化权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5166D596-558A-4010-A51B-B8C859C9DD78.htm)和[归一化权重模式](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F.htm#GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F__WS1A9193826455F5FF-3859B43C1215F53D0F3-74A8)。
