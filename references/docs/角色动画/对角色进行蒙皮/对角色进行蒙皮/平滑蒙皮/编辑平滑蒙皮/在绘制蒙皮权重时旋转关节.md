# 在绘制蒙皮权重时旋转关节

可在使用“绘制蒙皮权重工具”(Paint Skin Weights Tool)时旋转关节。这样，可在绘制蒙皮权重时，测试关节使绑定几何体变形的方式。

在使用“绘制蒙皮权重工具”(Paint Skin Weights Tool)时旋转关节

1. 打开“绘制蒙皮权重工具”(Paint Skin Weights Tool)。

2. 在工具设置的“影响”(Influences)列表中选择待旋转关节的名称。例如，LeftForeArm（肘部）。

  ![图：在工具设置的“影响”(Influences)列表中选择待旋转关节的名称。例如，LeftForeArm（肘部）。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6CDCCB8D-6D1C-42D1-BA60-BE5CC96D6096.png) <!-- baize:img-hook downloaded=false reason="正文 420 字 ≥300，非承重" -->

3. 在场景视图中，单击鼠标中键，从“绘制蒙皮权重工具”(Paint Skin Weights Tool)笔刷切换至旋转操纵器。

  ![图：在场景视图中，单击鼠标中键，从“绘制蒙皮权重工具”(Paint Skin Weights Tool)笔刷切换至旋转操纵器…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-2EDDF0CB-92BE-4884-B3B3-9DB804CC825F.png) <!-- baize:img-hook downloaded=false reason="正文 420 字 ≥300，非承重" -->

4. 使用鼠标中键单击旋转时围绕的旋转轴，然后使用鼠标中键拖动以使关节绕选定的轴旋转。

  ![图：使用鼠标中键单击旋转时围绕的旋转轴，然后使用鼠标中键拖动以使关节绕选定的轴旋转。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-6768DD3B-E0F1-4F65-B43D-BC26D2EEC901.png) <!-- baize:img-hook downloaded=false reason="正文 420 字 ≥300，非承重" -->

5. 按住上下箭头键来选择关节层次上下的其他关节。例如，沿关节层次移动至 LeftArm（肩部）或在层次中向下移动至 LeftForeArmRoll。

  ![图：按住上下箭头键来选择关节层次上下的其他关节。例如，沿关节层次移动至 LeftArm（肩部）或在层次中向下移动至 Left…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-30A5831A-310F-4A04-B895-BAF395743069.png) <!-- baize:img-hook downloaded=false reason="正文 420 字 ≥300，非承重" -->

6. 若要切换回“绘制蒙皮权重工具”(Paint Skin Weights Tool)笔刷，请单击当前选定的关节。
