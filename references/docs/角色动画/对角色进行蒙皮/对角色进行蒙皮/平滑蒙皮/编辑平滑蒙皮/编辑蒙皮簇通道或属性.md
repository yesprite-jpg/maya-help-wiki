# 编辑蒙皮簇通道或属性

使用“通道盒”(Channel Box)编辑通道

1. 选择蒙皮簇节点（默认名称：skinCluster*n*）。

2. 设定通道。

3. 单击要编辑的通道名称。

4. ![图：用鼠标 () 在场景中左右拖动。拖动时，将以交互方式更改选定通道的值。 提示： 拖动时，按 Ctrl 键可以进行更精细的…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-D75F7EC7-14A4-4B03-B0A1-C445CF45AC10.png) <!-- baize:img-hook downloaded=false reason="正文 372 字 ≥300，非承重" -->用鼠标 () 在场景中左右拖动。拖动时，将以交互方式更改选定通道的值。

  **注**

  提示：

  拖动时，按 Ctrl 键可以进行更精细的控制；按 Shift 键可以进行粗糙的控制。

使用“属性编辑器”(Attribute Editor)来编辑蒙皮簇属性

1. 选择蒙皮簇节点（默认名称：skinCluster*n*）。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

3. 展开“平滑蒙皮属性”(Smooth Skin Attributes)、“变形器属性”(Deformer Attributes)、“节点行为”(Node Behavior)和“附加属性”(Extra Attributes)标题以查看所有可用属性。

  有关这些属性的详细信息，请参见 [skinCluster](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F.htm)。
