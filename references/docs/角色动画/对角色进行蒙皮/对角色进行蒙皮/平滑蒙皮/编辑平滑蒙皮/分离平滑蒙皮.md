# 分离平滑蒙皮

绑定蒙皮后，您可能会决定要修改骨架、更改绑定姿势或对蒙皮执行某些进一步建模。若要完成这些任务，您必须首先从骨架取消绑定蒙皮。完成这些修改后，您可以再次绑定蒙皮。

分离蒙皮

1. 选择要分离的蒙皮对象。

2. 选择[“蒙皮 > 取消绑定蒙皮”(Skin > Unbind Skin)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4C4597A6-BC0F-401A-96E9-A81AD26C040E.htm) > ![图：选择“蒙皮 取消绑定蒙皮”(Skin Unbind Skin) 。](../../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 206 字 <300 且带图" -->。

3. 执行下列操作之一：

  - 单击“分离”(Detach)分离蒙皮。

  - 单击“保存”(Save)保存分离选项而不分离蒙皮。

  - 单击“重置”(Reset)重置为默认的分离蒙皮选项。
