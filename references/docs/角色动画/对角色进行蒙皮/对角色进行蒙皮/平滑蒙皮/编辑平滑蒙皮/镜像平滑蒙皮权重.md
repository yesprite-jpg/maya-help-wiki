# 镜像平滑蒙皮权重

为了获得最佳的结果，请执行以下操作：

- 蒙皮几何体应在全局轴上居中，或至少应沿要镜像的轴对齐。

- 蒙皮对象（包括其骨架）应该处于跨镜像平面对称的姿势。

镜像平滑蒙皮权重

1. 执行下列操作之一：

  - 若要在整个蒙皮上镜像蒙皮权重，请选平滑择蒙皮对象。

  - 若要在选定组件上镜像蒙皮权重，请将指针定位到该蒙皮上方，单击鼠标右键，然后选择“控制顶点”(Control Vertex)或“顶点”(Vertex)。选择要从其镜像的一侧上的组件和要镜像到的一侧上的组件。

2. 选择“蒙皮 > 镜像蒙皮权重”(Skin > Mirror Skin Weights) > ![图：选择“蒙皮 镜像蒙皮权重”(Skin Mirror Skin Weights) 以打开镜像蒙皮权重选项。 注： 对于“绘…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 427 字 ≥300，非承重" --> 以打开[镜像蒙皮权重选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-27FE7EDB-4078-473A-B001-C9AFAB3A77A3.htm)。

  **注**

  对于“绘制蒙皮权重工具”(Paint Skin Weights Tool)，“反射”(Reflection)处于禁用状态。可以使用“蒙皮 > 镜像蒙皮权重”(Skin > Mirror Skin Weights)作为替代方法，以便反射蒙皮权重。

3. 设定选项。

4. 单击“镜像”(Mirror)。
