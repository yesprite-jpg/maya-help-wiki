# 绘制蒙皮权重

绘制平滑蒙皮点权重

1. 选择要绘制的平滑蒙皮对象。

2. 通过选择“着色 > 对所有项目进行平滑着色处理”(Shading > Smooth Shade All)（热键：按 5）来启用平滑着色处理模式。

3. 打开绘制蒙皮权重工具（[“蒙皮 > 绘制蒙皮权重工具”(Skin > Paint Skin Weights Tool)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-99189E9D-237F-471E-A02C-BE6593B4828B.htm) > ![图：打开绘制蒙皮权重工具（“蒙皮 绘制蒙皮权重工具”(Skin Paint Skin Weights Tool) ）。 注：…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1073 字 ≥300，非承重" -->）。

  **注**

  已对“绘制蒙皮权重工具”(Paint Skin Weights Tool)禁用“反射”(Reflection)，但是可以使用“镜像蒙皮权重”(Mirror Skin Weights)（在[“蒙皮”(Skin)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-35ECFBC1-A65B-46AF-9542-213BD304C632.htm)的“权重贴图”(Weight Maps)部分中）作为反射蒙皮权重的替代方法。

4. 若要选择某个关节，请执行下列操作之一：

  - 在“绘制蒙皮权重工具”(Paint Skin Weights Tool)的“影响”(Influences)列表中选择关节名称。

    **注**

    提示：

    使用

    “排序”(Sort)

    选项和

    “过滤器”(Filter)

    来调整

    “影响”(Influences)

    列表中显示的内容，并使用大小图标来展开

    或收缩

    “影响”(Influences)列表。

  - 在要绘制的关节上单击鼠标右键，然后在出现的标记菜单中选择“选择影响”(Select Influence)。

  **注**

  提示：

  使用鼠标中键单击关节，然后按向上和向下箭头键来浏览角色的关节层次。

  选择要绘制的影响时，网格显示的颜色反馈（默认情况下）为白色和黑色。可以验证“显示”(Display)标题下是否已启用“颜色反馈”(Color Feedback)。启用“颜色反馈”(Color Feedback)有助于通过将曲面上的权重表示为灰度值（值越小越深，值越大越浅）来对其进行标识。也可以在“渐变”(Gradient)标题下启用“使用颜色渐变”(Use color ramp)以查看颜色中的权重。

  ![图：若要选择某个关节，请执行下列操作之一： 在“绘制蒙皮权重工具”(Paint Skin Weights Tool)的“影响…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-BF8A2B2B-8370-4F57-98CC-D86517362B90.png) <!-- baize:img-hook downloaded=false reason="正文 1073 字 ≥300，非承重" -->

  **注**

  默认热键 Alt+C（Windows 和 Linux）或 Option+C (Mac OS X) 可启用和禁用

  “绘制蒙皮权重工具”(Paint Skin Weights Tool)

  之外的颜色反馈。

5. 确保已在“绘制蒙皮权重工具”(Paint Skin Weights Tool)中设定希望的笔刷、绘制操作、值及其他任何设置。

  例如，确保“权重类型”(Weight Type)下拉列表已设置为“蒙皮权重”(Skin Weight)，并选择希望的[“归一化权重”(Normalize Weights)模式](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F.htm#GUID-2E292C8A-388A-4E77-B42D-165F1C9E1E5F__WS1A9193826455F5FF-3859B43C1215F53D0F3-74A8)。

6. 沿蒙皮拖动以绘制权重。

  绘制的值可设置此关节相对于组成平滑体的其他关节对绘制的顶点的影响力（直到达到在[绑定蒙皮选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CF2C698A-44BB-4CA0-BCB9-DB36500DA812.htm)中指定为“最大影响”(Max Influences)的值）。
