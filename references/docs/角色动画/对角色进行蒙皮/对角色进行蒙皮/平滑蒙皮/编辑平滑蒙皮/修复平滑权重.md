# 修复平滑权重

权重锤工具可快速修复正在产生钉形或不需要的变形并具有权重的顶点。单击权重锤可从相邻顶点指定选定的、具有权重值的顶点。

修复具有不需要的权重的顶点

1. 选择对象。

2. 打开“绑定”(Rigging)菜单集 (**F3**) 中的[“蒙皮”(Skin)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-35ECFBC1-A65B-46AF-9542-213BD304C632.htm)，然后选择**“绘制权重”(Paint Weights)** > ![图：打开“绑定”(Rigging)菜单集 (F3) 中的“蒙皮”(Skin)菜单，然后选择“绘制权重”(Paint Weig…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 487 字 ≥300，非承重" -->。

  此时将打开“绘制蒙皮权重工具”(Paint Skin Weights Tool)。

  ![图：打开“绑定”(Rigging)菜单集 (F3) 中的“蒙皮”(Skin)菜单，然后选择“绘制权重”(Paint Weig…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-BD4B09C0-7838-46F5-BE43-EE86695423F4.png) <!-- baize:img-hook downloaded=false reason="正文 487 字 ≥300，非承重" -->

  绘制权重工具：**A**。模式 **B**。权重锤

3. 在“模式”(Mode)选项中，选择**“绘制”(Paint)**、**“选择”(Select)**或**“绘制选择”(Paint Select)**（请参见上图中的 **A.**）。

  **注**

  提示：

  使用热键 Ctrl + < 和 Ctrl + >，以在这些模式之间进行快速切换。

4. 选择要修复的顶点。

5. 从“绘制蒙皮权重工具”(Paint Skin Weights Tool)影响物列表（请参见上图中的 **B.**）下方的图标或从[“蒙皮”(Skin)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-35ECFBC1-A65B-46AF-9542-213BD304C632.htm)中选择**“锤式蒙皮权重”(Hammer Skin Weights)** ![图：从“绘制蒙皮权重工具”(Paint Skin Weights Tool)影响物列表（请参见上图中的 B.）下方的图标或从…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-786C1026-7F66-4299-8B4E-204DDFA8024F.png) <!-- baize:img-hook downloaded=false reason="正文 487 字 ≥300，非承重" -->。

  “锤式蒙皮权重”(Hammer Skin Weights)为选定顶点指定与其相邻顶点相同的权重值。练习骨架时，可看到更平滑的变形结果。
