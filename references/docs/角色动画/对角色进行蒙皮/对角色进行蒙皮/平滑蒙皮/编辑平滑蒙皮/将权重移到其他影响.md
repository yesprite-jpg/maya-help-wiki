# 将权重移到其他影响

通过移动权重工具，可以轻松地将权重从一个影响移到另一个影响，而不必手动重置或更改权重值。

移动选定顶点的权重

1. 选择具有要重新分配的权重的顶点。

2. 打开绘制蒙皮权重工具（“蒙皮 > 绘制蒙皮权重”(Skin > Paint Skin Weights) > ![图：打开绘制蒙皮权重工具（“蒙皮 绘制蒙皮权重”(Skin Paint Skin Weights) ）。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 530 字 ≥300，非承重" -->）。

3. 在“影响”(Influences)列表中（或在场景中），选择要将权重从中移出的源影响，然后选择一个或多个接收移动的权重的目标影响。

4. 执行下列操作之一：

  - 单击“绘制蒙皮权重工具”(Paint Skin Weights Tool)中的移动权重工具 ![图：单击“绘制蒙皮权重工具”(Paint Skin Weights Tool)中的移动权重工具 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-133C86A9-CDFE-4B3D-9F11-78B88A5B7D9A.png) <!-- baize:img-hook downloaded=false reason="正文 530 字 ≥300，非承重" -->。

  - 从主菜单栏中选择“蒙皮 > 将权重移动到影响”(Skin > Move Weights to Influences)。

  选定顶点的权重将移动到目标影响，蒙皮点现在仅受这些影响的影响。

  **注**

  如果在

  “绘制蒙皮权重工具”(Paint Skin Weights Tool)

  中锁定了影响，则该影响不会接收从邻近影响移动的权重。

  例如，下表说明了随着您将权重从一个源影响移到两个目标影响时选定顶点的权重值的变化。

  ![图：执行下列操作之一： 单击“绘制蒙皮权重工具”(Paint Skin Weights Tool)中的移动权重工具 。 从主…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-CC1866B8-8C13-429D-B1C2-5A6D6CD9F669.png) <!-- baize:img-hook downloaded=false reason="正文 530 字 ≥300，非承重" -->

  **注**

  在此示例中，如果将

  “归一化权重”(Normalize Weights)模式

  设置为

  “交互式”(Interactive)

  ，则移动到目标影响的权重将会归一化，且每个结果为 0.5。
