# 查询蒙皮权重

查询蒙皮点权重

1. 选择要查询其权重的蒙皮点。

2. 选择“窗口 > 常规编辑器”(Window > General Editors) > [组件编辑器(Component Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B698CC5D-2771-488E-98E8-2D4E31DB3B2D)。

3. 单击“平滑蒙皮”(Smooth Skins)选项卡。

  “平滑蒙皮”(Smooth Skins)部分列出了指定给 CV、顶点或晶格点的权重，这些点通过平滑蒙皮绑定到骨架的关节。
