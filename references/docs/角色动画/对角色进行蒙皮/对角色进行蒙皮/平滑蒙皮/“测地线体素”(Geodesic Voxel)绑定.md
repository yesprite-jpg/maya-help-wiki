# “测地线体素”(Geodesic Voxel)绑定

“测地线体素”(Geodesic Voxel)绑定旨在处理可能包含非流形、非防水的相交三角形或包含多个连接组件的网格。这些组件通常会导致自动绑定算法（如热图绑定）出现问题。请参见[通过测地线体素绑定来绑定平滑蒙皮](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E9FC4C94-CDEB-41DC-AF8E-95469EC69BEE.htm)。

此方法可体素化输入几何体，以计算源于骨架和网格上体素之间的测地线距离的绑定权重。

“测地线体素”(Geodesic Voxel)绑定方法还允许您选择多个网格，在整个几何体中提供连续权重，因为所有形状都将被视为单一体积。“测地线体素”(Geodesic Voxel)绑定会计算与线性融合或双四元数蒙皮兼容的影响权重。

**注**

为了有效地使用，

“测地线体素”(Geodesic Voxel)

绑定需要满足两个要求。与其他 Maya 绑定方法不同，使用

“测地线体素”(Geodesic Voxel)

绑定时，必须将所有关节影响封闭在网格体积内。如果不执行此操作，将无法正确计算测地线距离。此外，应将几何体前向面的法线方向设定为指向外部。检查此要求遵循情况的一种简单方法是在视口中启用背面消隐，并直观地检查结果。

## 体素(Voxels)

体素是一个在 3D 中使用的术语，用于描述 3D 对象占用的容量或空间。对于表示以不同方式填充的定期采样空间，体素非常有用。

体素化是将 3D 几何对象转化为一组非常接近输入网格的体素的行为。该过程类似于 2D 中的光栅化过程。

## 退化几何体

退化（或衰退）几何体是指几何体具有与软件认可的标准不同的特性，从而导致某些绑定算法（如 Maya 热图）出现计算问题。退化几何体可以是以下部分（或全部）情况：

- 非流形（非防水）几何体

- 相交形状

- 共面、共线或共点

- 多个连接的组件

- 相交边

- 不能“填充”的形状

- 导致异常或冲突数据的任何其他形式

如果遇到退化几何体错误或警告，请检查您的几何体，确定是否存在这些不一致情况。
