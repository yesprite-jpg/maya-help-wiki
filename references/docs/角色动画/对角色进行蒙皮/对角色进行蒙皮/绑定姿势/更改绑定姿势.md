# 更改绑定姿势

**注**

重要：

此过程将移除所有权重，其中包括自定义权重。

更改绑定姿势

1. 分离蒙皮（选择[“蒙皮 > 取消绑定蒙皮”(Skin > Unbind Skin)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-4C4597A6-BC0F-401A-96E9-A81AD26C040E.htm)。）

2. 根据需要调整骨架和可变形对象。

3. 重新绑定蒙皮（请参见[刚性绑定蒙皮](../刚性蒙皮/设置刚性蒙皮/刚性绑定蒙皮.md)或[绑定平滑蒙皮](../平滑蒙皮/绑定平滑蒙皮.md)）。
