# 可变形对象和蒙皮对象

蒙皮时，将模型的可变形对象绑定到骨架。蒙皮后，模型称为角色蒙皮，可变形对象称为蒙皮对象。

可变形对象可以是由 NURBS 控制顶点 (CV)、多边形顶点或晶格点定义结构的任何对象。NURBS 曲线、NURBS 曲面、多边形曲面（网格）以及晶格变形器都是可变形对象。角色的模型可由一个可变形对象（例如，一个大多边形曲面）组成，也可由可变形对象组（例如，NURBS 曲面组）组成。

通常情况下，角色模型由在层次组中组织的可变形对象（通常为 NURBS 曲面、多边形曲面或其两者）组成。该组织反映了角色外观的结构，并且应该以角色动画的设置方式为基础。例如，NURBS 模型可由一组构成角色脚、腿、躯干、臂、手、颈和头的 NURBS 曲面组成。
