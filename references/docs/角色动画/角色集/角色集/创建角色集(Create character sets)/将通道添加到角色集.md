# 将通道添加到角色集

可以快速将任何对象的通道（属性）添加到角色集。对象无需成为角色集的一部分。

将通道添加到当前角色集

1. 确保要将通道添加到的角色集是当前角色集。

2. 选择要将其某些或全部通道添加到角色集的对象。

3. 在“通道盒”(Channel Box)中，选择要添加到角色集的通道。

4. 选择“关键帧 > [添加到角色集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-FA1DF2DA-86C9-49EE-A23A-8749E4D31822#GUID-FA1DF2DA-86C9-49EE-A23A-8749E4D31822__GUID-07399FA9-8A87-4946-8111-AB04F0418BCE)”(Key > Add to Character Set)。

可以在角色集间移动属性。同样，可以将当前不在某个角色集中的任何数值属性添加到角色集中。

在“大纲视图”(Outliner)中使用拖放功能将通道添加到角色集

1. 在“大纲视图”(Outliner)中，显示属性和目标角色集。

2. ![图：) 将属性拖放到角色集上。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-D75F7EC7-14A4-4B03-B0A1-C445CF45AC10.png) <!-- baize:img-hook downloaded=true reason="正文 279 字 <300 且带图" -->) 将属性拖放到角色集上。
