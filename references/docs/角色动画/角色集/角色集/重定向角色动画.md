# 重定向角色动画

重定向运动是一个过程，通过该过程，可以在角色动画期间随时修改角色的路径或方向。例如，通过重定向角色的运动，您可以在角色的跳转动画末端更改角色的位置，以及角色面对的方向。

可以在角色动画期间的任意点使用重定向控件移动和旋转角色，并为这些新位置和方向设置关键帧。

**注**

您可以使用重定向控件重定向 Maya 中任何类型的运动（关键帧或运动捕捉动画、表达式、动力学等）。
