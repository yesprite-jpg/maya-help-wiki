# 从角色集中移除通道

可以快速地从角色集中移除通道。

移除通道

1. 确保要从其移除通道的角色集是当前角色集。

2. 在“通道盒”(Channel Box)中，选择要从角色集中删除的通道。

3. 选择[“通道盒”(Channel box)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-19CD9DD8-0119-448F-A1B8-93C82A74B633)中的“删除选定项”(Delete Selected)。

Maya 会从当前角色集中移除选定通道。
