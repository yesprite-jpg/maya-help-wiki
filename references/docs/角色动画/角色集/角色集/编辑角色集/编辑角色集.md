# 编辑角色集

编辑角色集包括向集中添加或从集中删除属性。默认情况下，角色集包括角色中包含对象的所有可设置关键帧属性。通常，仅需要使用这些属性中的一部分。将所有这些属性都保留在角色集中可能会导致“通道盒”(Channel Box)中的通道列表过长，具体取决于角色中包含对象的数量和复杂度。因此，创建角色集后，可能会发现需要从角色集中移除某些属性。当然，可以在以后将其重新添加到角色集中。

请参见[集和划分](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B1DE4646-E52B-4611-87B6-E741F25E284B)。 编辑角色集涉及“关系编辑器”(Relationship Editor)的使用。请参见手册的“基础知识”部分中的[关系编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3DA58150-A73D-403E-A988-798DED4956BD)。
