# 合并角色集

可以将多个角色集合并到单个角色集中，而不丢失任何片段数据。

将多个角色集合并到单个字符集中

1. 选择角色集。

2. 从[“关键帧”(Key)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-FA1DF2DA-86C9-49EE-A23A-8749E4D31822)中，选择“合并角色集”(Merge Character Sets)。
