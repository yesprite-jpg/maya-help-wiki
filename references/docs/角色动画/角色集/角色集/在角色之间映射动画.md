# 在角色之间映射动画

使用“角色映射器”(Character Mapper)创建源和目标角色的节点或属性的对应关系，以便您可以在“Trax 编辑器”(Trax Editor)中，在已映射角色之间导入和导出或复制和粘贴动画片段。

通过将一个角色的节点和属性映射或链接到另一个角色的节点和属性，可以创建 [characterMap](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Nodes/characterMap.html) 节点。该节点会存储已映射节点和属性之间的连接数组。只能通过 Maya 访问存储在该节点上的信息。
