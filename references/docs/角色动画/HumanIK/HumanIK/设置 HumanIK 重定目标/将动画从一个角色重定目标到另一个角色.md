# 将动画从一个角色重定目标到另一个角色

从一个角色重定目标到另一个角色

1. [为每个角色创建 HumanIK 骨架定义](../设置%20HumanIK%20角色/创建%20HumanIK%20骨架定义.md)。

2. 打开 [HumanIK 窗口](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9921EDE1-05E2-4062-9F0D-4BADECA29226.htm)，并从[角色(Character)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-46964B80-1DEA-49BB-A7CF-0DBA40D9F87F.htm)中选择目标角色。

  **注**

  目标角色必须具有控制装备。如果选定角色没有任何控制装备，

  Maya

  会创建一个。

3. 从“源”(Source)菜单中，选择*角色*，其中*角色*是源角色的名称。（场景中所有可用的 HumanIK 角色会自动在“源”(Source)菜单中列出。）

  目标角色进行捕捉以匹配源角色的位置。

4. （可选）若要添加目标角色的控制装备到新动画层，请选择 IK 效应器，然后在“动画层编辑器”(Animation Layer Editor)中单击“从选定对象创建层”(Create Layer from Selected)按钮 ![图：（可选）若要添加目标角色的控制装备到新动画层，请选择 IK 效应器，然后在“动画层编辑器”(Animation Laye…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-C8645E83-E124-4F36-9694-0C964122AC7D.png) <!-- baize:img-hook downloaded=false reason="正文 358 字 ≥300，非承重" -->。整个装备将添加到新动画层。
