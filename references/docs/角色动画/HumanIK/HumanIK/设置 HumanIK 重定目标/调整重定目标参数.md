# 调整重定目标参数

调整重定目标参数

1. 在 [HumanIK 窗口](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9921EDE1-05E2-4062-9F0D-4BADECA29226.htm)中，选择 ![图：在 HumanIK 窗口中，选择 “编辑角色定义 编辑 HIK 特性”(Edit Character Definitio…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-39B60BBD-A9DF-46CA-8078-B4277C4CD703.png) <!-- baize:img-hook downloaded=false reason="正文 507 字 ≥300，非承重" --> >“编辑角色定义 > 编辑 HIK 特性”(Edit Character Definition > Edit HIK Properties)。

  重定目标设置显示在“属性编辑器”(Attribute Editor)中的“HIKProperties”选项卡上。

  **注**

  HIKProperties 节点还包含许多其他 HIK 解算器属性，如“解算”(Solving)和“地板接触”(Floor Contact)。这些属性超出本文档的范围。

2. 展开“重定目标特定”(Retarget Specific)标题。

  该区域包含属性，以提供对源和目标角色之间的重定目标的更好控制。有关详细信息，请参见[“重定目标特定”属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-EB2A8BB0-801E-4251-8C4C-09986049CCBB.htm)。

  操纵“达到”(Reach)滑块时使用以下准则：

  - 值为 1 时，目标身体部位完全到达源身体部位。

  - 值为 0.50 时，目标身体部位在源和角色位置的身体部位之间平均。

  - 值为 0 时，对身体部位的影响相当于禁用该选项。

  **注**

  “重定目标特定”(Retarget Specific)区域还包括“拉动”(Pull)和“刚度”(Stiffness)属性。调整这些值是高级技术，同时对于法线重定目标，不建议调整默认值。
