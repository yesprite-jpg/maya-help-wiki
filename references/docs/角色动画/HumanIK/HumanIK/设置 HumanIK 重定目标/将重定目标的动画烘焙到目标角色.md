# 将重定目标的动画烘焙到目标角色

根据在重定目标工作流中所处的位置，可以将重定目标的动画烘焙到目标角色的骨架、控制装备或自定义装备。

例如，不再需要到源角色的链接，或者如果想要将装备导出到 MotionBuilder 时，通常会将动画烘焙到目标角色的控制装备。（请参见[将 HumanIK 装备发送到 MotionBuilder](../将控制装备发送到%20MotionBuilder.md)。）

完成对重定目标的动画的所有调整并对结果满意之后，可以将动画烘焙到目标骨架。

**注**

烘焙重定目标的动画时会使用在

烘焙模拟选项(Bake Simulation Options)

中设置的选项。

将重定目标的动画烘焙到目标角色

1. 在 [HumanIK](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9921EDE1-05E2-4062-9F0D-4BADECA29226.htm) 的[角色(Character)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-46964B80-1DEA-49BB-A7CF-0DBA40D9F87F.htm)中选择要烘焙到的角色。

2. 单击 ![图：单击 ，然后从显示的“烘焙”(Bake)菜单中选择一个选项。请参见 HumanIK 窗口中的烘焙选项。 随着动画烘焙到目…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-39B60BBD-A9DF-46CA-8078-B4277C4CD703.png) <!-- baize:img-hook downloaded=false reason="正文 550 字 ≥300，非承重" -->，然后从显示的“烘焙”(Bake)菜单中选择一个选项。请参见 [HumanIK 窗口中的烘焙选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1704AD41-8435-4AD4-AF29-43EF13803EAC.htm)。

  随着动画烘焙到目标骨架、控制装备或自定义装备，场景中会播放重定目标的动画。对于重定目标的动画的每一帧，Maya 会在每个效应器或关节上设置一个关键帧。

  **注**

  注意：

  如果在重定目标过程中向动画层添加了控制装备，那么分层的动画会覆盖烘焙的动画。禁用或删除层可查看在控制装备上烘焙的动画的结果。

3. （可选）如果已使用完源角色，可以从场景中删除它。
