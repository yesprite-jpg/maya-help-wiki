# 编辑现有 HumanIK 骨架定义

编辑现有 HumanIK 骨架定义

1. 加载具备现有骨架定义的骨架。

2. 在 HumanIK 窗口（“窗口 > 动画编辑器 > HumanIK”(Windows > Animation Editors > HumanIK)）中，单击[定义(Definition)选项卡](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-630B5349-213C-414D-B6C9-D283CE319472.htm)。

3. 在“定义”(Definiton)选项卡工具栏中，单击 ![图：在“定义”(Definiton)选项卡工具栏中，单击 可解除锁定当前骨架定义。 注： 提供的 HumanIK 侧滚骨骼系…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-3A2A631F-5A69-4CF6-9BF3-750ABCFC8B13.png) <!-- baize:img-hook downloaded=false reason="正文 414 字 ≥300，非承重" --> 可解除锁定当前骨架定义。

  **注**

  提供的 HumanIK 侧滚骨骼系统可让您逐肢体最多映射五块侧滚骨骼。如果现有骨架定义已定义侧滚骨骼且是使用早期版本的

  Maya

  创建的，则解除锁定骨架定义将移除侧滚骨骼指定，以便使用

  “定义”(Definition)

  选项卡窗口中的侧滚骨骼视图映射骨骼。请参见

  “角色”(Character)和“名称匹配”(Name Match)视图

  。

4. 在要映射的骨骼上单击鼠标右键，然后选择“更改指定的骨骼”(Change Assigned Bone)。

5. 在显示的下拉列表中，选择另一骨骼的名称并单击“确定”(Ok)。
