# 定义侧滚骨骼行为

可以使用 HumanIK 侧滚骨骼系统逐肢体最多添加五个侧滚骨骼，更好地控制角色上臂、下臂、大腿和小腿的旋转。

通过“属性编辑器”(Attribute Editor)中的侧滚骨骼控件，可以定义在旋转角色的肢体时希望角色的侧滚骨骼有何行为。请参见[侧滚节点](../HumanIK%20角色结构.md#GUID-5DEFC6E5-033C-45D5-9A0E-224E7A35131B__GUID-A6BFFBB6-DA59-4F90-B535-37702C2FAF2F)。

定义侧滚骨骼行为的步骤

1. 执行下列操作之一：

  - 创建新的默认骨架，每个肢体最多有五个侧滚骨骼。请参见[创建和定义 HumanIK 骨架](创建和定义%20HumanIK%20骨架.md)和[骨架设置区域](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3DF80458-E953-4EA8-AE8E-A73627419F1A.htm)。

  - 使用侧滚骨骼定义现有骨架。请参见[为 HumanIK 定义现有骨架](为%20HumanIK%20定义现有骨架.md)。

2. 在 [HumanIK 窗口](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-9921EDE1-05E2-4062-9F0D-4BADECA29226.htm)中，确保将要处理的角色选择为当前“角色”(Character)。

3. 选择 ![图：选择 “编辑角色定义 编辑 HIK 特性”(Edit Character Definition Edit HIK Pro…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-39B60BBD-A9DF-46CA-8078-B4277C4CD703.png) <!-- baize:img-hook downloaded=false reason="正文 940 字 ≥300，非承重" --> >“编辑角色定义 > 编辑 HIK 特性”(Edit Character Definition > Edit HIK Properties)。

4. 在属性编辑器中的“HIKProperties”选项卡上，展开“侧滚和俯仰”(Roll & Pitch)标题。

5. 对于为角色定义的每个侧滚骨骼，请使用“侧滚”(Roll)滑块来定义旋转关联的角色肢体时，每个目标侧滚骨骼受影响的程度。

  可以逐肢体最多映射五个侧滚骨骼。所有侧滚骨骼均被设置为同一肢体骨骼的子对象，且沿该肢体骨骼的侧滚骨骼放置以及每个侧滚骨骼的旋转百分比由每个肢体的侧滚骨骼数量确定。默认情况下，将在“HIKProperties”选项卡上的“左腿”(Left Leg)、“右腿”(Right Leg)、“左臂”(Left Arm)和“右臂”(Right Arm)部分中为每个侧滚骨骼指定值。调整这些值，可更改每个侧滚骨骼的旋转百分比。

  例如，如果已定义“叶左前臂侧滚 1”(Left Fore Arm Roll 1)骨骼，则“左肘侧滚”(Left Elbow Roll)特性控制左前臂侧滚和肘部之间的分布。将“左肘侧滚”(Left Elbow Roll)滑块设定为 0.500 表示在旋转左臂时，左前臂和左肘侧滚之间将分布 50% 的左肘侧滚。

  （如果没有“叶左前臂侧滚 1”(Left Forearm Roll 1)骨骼，则“左肘侧滚”(Left Elbow Roll)会控制左手和肘部之间的分布。）

  **注**

  如果没有为当前角色定义侧滚骨骼，则关联的

  “侧滚”(Roll)

  滑块将设置为默认值 0。
