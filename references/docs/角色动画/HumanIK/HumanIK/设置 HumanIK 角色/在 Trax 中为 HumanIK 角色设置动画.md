# 在 Trax 中为 HumanIK 角色设置动画

在“Trax 编辑器”(Trax Editor)中创建动画剪辑需要使用角色集。如果要为 HumanIK 角色创建片段，并使用 [Trax 编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-33C829F4-635C-4DEB-956C-6A54BEE1EC89)以非线性方式编辑动画，请注意，您必须创建一个角色集以包含 HumanIK 角色（包括所有 FK 和 IK 对象）。请参见[创建角色集](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-A2AAF7B8-4187-4E1B-8BC5-98F84474C0EF.htm)。
