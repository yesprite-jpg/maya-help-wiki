# 将控制装备添加到动画层

将控制装备添加到动画层

1. 在 Maya 中，从“HumanIK 控制”装备中选择效应器。

2. 在“动画层编辑器”(Animation Layer Editor)中，单击“动画”(Anim)选项卡并执行下列操作之一：

  - 选择“层 > 从选定对象创建层”(Layers > Create Layer from Selected)。

  - 单击“从选定对象创建层”(Create Layer from Selected)图标 ![图：单击“从选定对象创建层”(Create Layer from Selected)图标](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-C8645E83-E124-4F36-9694-0C964122AC7D.png) <!-- baize:img-hook downloaded=true reason="正文 226 字 <300 且带图" -->

  将创建包含整个控制装备的新动画层。
