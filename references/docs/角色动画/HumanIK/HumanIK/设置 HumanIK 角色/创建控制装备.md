# 创建控制装备

在拥有包含有效骨架定义的骨架后，即可为您的角色创建控制装备。角色必须具有控制装备才能收到重定目标的动画。

创建控制装备

1. 加载具有有效骨架定义的 HumanIK 角色。（请参见[创建 HumanIK 骨架定义](创建%20HumanIK%20骨架定义.md)。）

2. 请执行下列任一操作：

  - 在“HumanIK”窗口中，从[角色(Character)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-46964B80-1DEA-49BB-A7CF-0DBA40D9F87F.htm)选择 HumanIK 角色，然后从“源”(Source)菜单选择“控制装备”(Control Rig)。

  - 从主菜单栏（“装备”(Rigging)菜单集）中，选择“控制 > 创建控制装备”(Control > Create Control Rig)。

  这样会基于角色的骨架结构为其创建控制装备，且“角色控制”(Character Controls)将切换到“控制”(Controls)选项卡。
