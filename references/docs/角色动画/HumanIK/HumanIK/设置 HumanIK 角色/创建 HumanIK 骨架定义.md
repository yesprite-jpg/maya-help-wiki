# 创建 HumanIK 骨架定义

若要在 HumanIK 设定关键帧或重定工作流目标中发挥作用，角色需要骨架定义。创建骨架定义是映射角色骨架的结构的过程，以便 HumanIK 解算器可以理解它。

HumanIK 角色设置的方法取决于是否要使用现有骨架。

- 若要从现有骨架开始，请参见[为 HumanIK 定义现有骨架](为%20HumanIK%20定义现有骨架.md)。

- 若要构建默认骨架，请参见[创建和定义默认 HumanIK 骨架](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-795BDC06-8A1D-4D58-B55D-FD88D9B5A022.htm)。
