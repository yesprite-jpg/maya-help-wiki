# 角色动画

为场景中的角色和对象设置动画之前，需要通过装备所有角色并对要设置动画的所有对象应用相应的约束和变形器来设置场景。

装备角色也称为角色设置，包括为角色创建骨架和 IK 控制柄、将蒙皮绑定到骨架以及设置变形器和约束。还可以为角色创建变形器，为角色设置动画从而产生一定的效果；例如，抖动腹部（抖动变形器）、皱眉（线变形器）以及伸缩相扑手模型的二头肌（晶格变形器）。

非角色对象也非常重要，它们可以使场景变得栩栩如生。可以将对象约束到场景中的角色或其他模型，从而限制和控制对象的变换。此外，还可以为对象创建变形器，以创建复杂的变形效果。例如，可以对一个球模型应用挤压变形器，然后通过父约束将球约束到角色的手中。使用该设置，可以对角色手部的权重和挤压变形器的属性设置关键帧，从而创建这样的动画：角色双手交替拍球，球在地面上挤压变形并在返回到空中时拉伸还原。

除了为实现动画效果而设置角色和对象以外，还可以设置 Maya® Dynamics™ 以便实现动画效果。可以将动力学对象（例如，粒子发射器、场和流体）约束到场景中的对象或角色。有关详细信息，请参见 [nDynamics 模拟框架](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-923F09A5-52AA-42A7-AC70-827204E50B61)和[流体效果](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2A5FDEDD-9467-432B-B1FA-359C7A2D1D2F)。
