# “编辑影响”(Edit Influences)菜单

#### 添加影响(Add Influence)

#### 几何体(Geometry)

如果您希望影响对象的图形及其变换属性（平移、旋转和缩放）影响蒙皮图形，可启用“使用几何体”(Use Geometry)。如果您仅希望影响对象的变换属性（平移、旋转和缩放）来影响蒙皮图形，可禁用“使用几何体”(Use Geometry)。默认情况下“使用几何体”(Use Geometry)处于启用状态。

#### 衰减(Dropoff)

指定随着与影响对象之间的距离增加其位置影响衰减的速率。指定介于 0.1 与 100 之间的值。默认值为 4.0。

#### 多边形平滑度(Polygon Smoothness)

指定平滑蒙皮点与给定的多边形影响对象的匹配精确度。值越大，变形效果越圆润。设置介于 0.0 与 50.0 之间的值。默认值为 0.0。

#### NURBS 采样数(NURBS Samples)

指定用于对 NURBS 影响对象的图形影响求值的采样数。采样数越大，平滑蒙皮就越接近影响对象的图形。设置介于 1 与 100 之间的值。默认值为 10。

#### 权重锁定(Weight Locking)

指定希望避免影响对象的权重被间接更改，这种情况通常是由于权重绘制和编辑期间的权重归一化引起的（请参见[锁定平滑蒙皮权重](../../../../对角色进行蒙皮/对角色进行蒙皮/平滑蒙皮/编辑平滑蒙皮/锁定平滑蒙皮权重.md)）。Maya 将权重保持为“默认权重”(Default Weight)。默认为关闭。

#### 默认权重(Default Weight)

指定“权重保持”(Weight Holding)处于启用状态时的默认保持权重。默认值为 0.000。

#### 移除影响(Remove Influence)

从蒙皮中移除当前影响对象的影响。移除影响并不会从场景中删除当前影响对象。

#### 设置最大影响(Set Max Influences)

指定可以影响每个蒙皮点的关节和影响对象数量。使用滑块在 0 到 30 之间选择值。默认设置为 5。

#### 移除未使用的影响

从其平滑蒙皮断开蒙皮权重为 0 的所有关节和影响对象。请参见[从平滑蒙皮曲面移除未使用的影响](../../../../对角色进行蒙皮/对角色进行蒙皮/平滑蒙皮/编辑平滑蒙皮/从平滑蒙皮曲面移除未使用的影响.md)。
