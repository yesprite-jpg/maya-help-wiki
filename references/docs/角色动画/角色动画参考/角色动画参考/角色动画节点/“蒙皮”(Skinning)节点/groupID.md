# groupID

Maya 使用 groupID 节点来表示集。

Maya 中的大多数集由单个节点（即 objectSet 节点）组成。但是，组件集是不同的：组件集存储在形状数据中，而不是对象集节点中。每个形状连接到一个 groupId 节点，该节点在场景中存储一个唯一标识符 (ID)，用于标识集在形状的集列表内的成员身份。

**注**

如果在 Hypergraph 中查看形状的历史，则 groupID 节点默认处于隐藏状态。若要查看 groupID 节点，请启用“辅助节点”(auxiliary nodes)显示。请参见

显示或隐藏节点

。

当对对象进行变形时，可以使用组件标记来确定要变形的子集，而不是使用 groupId/groupParts/objectSet 节点以传统方式变形。有关组件标记和成员身份的详细信息，请参见[为几何体指定组件标记](../../../../变形效果/变形效果/变形器成员身份/使用组件标记编辑变形器成员身份/为几何体指定组件标记.md)。
