# 常规蒙皮节点属性

## 变形器属性(Deformer Attributes)

#### 封套(Envelope)

指定变形比例因子。值可以从 0 到 1。默认值为 1。

## 节点行为(Node behavior)

#### 缓存(Caching)

指定 Maya 存储输入求值的结果，然后将这些结果提供给节点。因此，Maya 不必在每次节点需要结果时重新对输入节点求值。如果输入节点无任何更改，则该设置可以提高显示性能，同时不丢失任何结果。但是，请注意，缓存会使用比其他情况下所使用的更多的内存，这可能会使性能受到负面影响。此外，如果对输入节点执行更改，则会分配更多的内存，然后在每次变形时释放一些内存，这也可能会使显示性能受到负面影响。

#### 节点状态(Node State)

选择下列选项之一。

#### 正常(Normal)

指定 Maya 对变形求值并加以显示。Maya 会和平常一样对节点求值。这是默认设置。

#### 无效果(HasNoEffect)

指定 Maya 禁止变形，但显示对象。Maya 会对节点的历史中的节点求值，但不是节点本身。

#### 阻塞(Blocking)

指定 Maya 禁止变形，而不显示对象。Maya 不会向该节点报告输入节点任何求值结果。

#### 等待-正常(Waiting-Normal)

（仅供 Maya 内部使用。）指定如果将依存关系图求值刷新性能设置（[窗口 > 设置/首选项 > 性能设置(Window > Settings/Preferences > Performance Settings)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9F78C71A-0F3B-4194-BC51-AB462D211426)）设定为“需要”(Demand)或“释放”(Release)，则单击“更新”(Update)或释放鼠标按钮时，该节点将呈现“正常”(Normal)状态。

#### 等待-无效果(Waiting-HasNoEffect)

（仅供 Maya 内部使用。）指定如果依存关系图求值刷新性能设置设定为“需要”(Demand)或“释放”，当您单击“更新”(Update)或释放鼠标按钮时，节点将获取“无效果”(HasNoEffect)状态。

#### 等待-阻塞(Waiting-Blocking)

（仅供 Maya 内部使用。）指定如果依存关系图求值刷新性能设置设定为“需要”(Demand)或“释放”(Release)，当您单击“更新”(Update)或释放鼠标按钮时，节点将获取“阻塞”(Blocking)状态。
