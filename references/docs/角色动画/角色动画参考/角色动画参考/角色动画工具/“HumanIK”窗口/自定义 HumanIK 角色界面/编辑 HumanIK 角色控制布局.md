# 编辑 HumanIK 角色控制布局

可以修改 CharacterControlsConfig.xml 或 CustomRigControlsConfig.xml 文件来调整“控制”(Controls)或“自定义绑定”(Custom Rig)角色布局。完成修改后，可以将自定义文件保存在所选位置，然后在 Maya 中加载该文件以查看新布局。

角色控制配置文件位于 **CharacterControls 目录**中：(C:\Program Files\Autodesk\<Maya 版本>\resources\CharacterControls)。
