# 自定义自定义绑定角色定义背景

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-CCD79921-BD87-4820-B968-9219A303F2E1.png) <!-- baize:img-hook downloaded=false reason="正文 424 字 ≥300，非承重" -->

您可以将 HumanIK 自定义绑定角色定义背景的背景图像切换为自定义图像。

更改 HumanIK 自定义绑定角色定义全身视图的背景图像

1. 将自定义图像复制到 CharacterControls 目录中的 DefaultImages 文件夹。

2. 编辑 <View resource> 元素以指向新图像。在以下示例中，图像被命名为 Spaceman_bkgrd。

  ![图：编辑 <View resource 元素以指向新图像。在以下示例中，图像被命名为 Spaceman_bkgrd。 您还可…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-0772671B-E57B-46D4-848B-4EBC15B1C575.png) <!-- baize:img-hook downloaded=false reason="正文 424 字 ≥300，非承重" -->

  您还可以在 CharacterControls 目录中创建一个新文件夹（例如 CustomImages）来保留所有自定义图像。如果创建新文件夹，则必须在配置文件中添加 <ResourcePath> 元素，以告知 Maya 要在该文件夹中搜索图像。

  ![图：编辑 <View resource 元素以指向新图像。在以下示例中，图像被命名为 Spaceman_bkgrd。 您还可…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-EE1E16E0-3690-4693-98E7-AF65A71D5B67.png) <!-- baize:img-hook downloaded=false reason="正文 424 字 ≥300，非承重" -->

  **注**

  提示：

  请勿在配置文件中包含背景图像的文件扩展名。

3. 重新加载该布局时，可以通过拖动 [HumanIK 窗口](../../../“HumanIK”窗口.md)的边缘来调整选项卡的大小，以反映自定义图像的分辨率。

  **注**

  背景图像的宽度定义了在调整窗口大小时，自定义布局可达到的最大宽度。最小宽度固定为 250 像素，无法更改。
