# “控制”(Controls)选项卡

打开控制(Controls)选项卡

- 打开 [HumanIK](../“HumanIK”窗口.md)（“骨架 > HumanIK”(Skeleton > HumanIK)），然后选择顶部的“控制”(Controls)选项卡。

“控制”(Controls)选项卡包含下列主要区域：

- [“控件”(Controls)选项卡工具栏](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-735DF85A-331C-4049-8C70-E53EFCDB4B73.htm)

- [HumanIK 控制](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-D5AB39F5-4677-4C5A-8A4B-BFD31BA00D6C.htm)
