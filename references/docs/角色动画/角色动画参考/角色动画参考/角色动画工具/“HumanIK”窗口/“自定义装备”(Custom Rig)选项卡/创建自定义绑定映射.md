# 创建自定义绑定映射

必须创建自定义绑定映射，以便于角色从 MotionBuilder 或 Maya 中的本地 HumanIK 角色中获取动画流的源。

创建新的自定义绑定映射的步骤

1. 在 Maya 中，通过自定义绑定加载或创建角色。

2. 在“定义”(Definition)选项卡中定义骨架。（请参见[定义现有骨架](../../../../../HumanIK/HumanIK/设置%20HumanIK%20角色/为%20HumanIK%20定义现有骨架.md)。）

  **注**

  有效的骨架定义需要创建自定义绑定映射。如果在不具有有效骨架定义的情况下尝试映射自定义绑定，则系统将显示警告消息。

3. 执行以下操作之一以创建新的自定义绑定映射：

  - 选择 ![图：选择 “定义 自定义绑定”(Define Custom Rig)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-39B60BBD-A9DF-46CA-8078-B4277C4CD703.png) <!-- baize:img-hook downloaded=false reason="正文 1025 字 ≥300，非承重" --> >“定义 > 自定义绑定”(Define > Custom Rig)。

  - 从[“定义”(Definition)选项卡工具栏中选择](../“定义”%28Definition%29选项卡/“定义”%28Definition%29选项卡工具栏.md)![图：从“定义”(Definition)选项卡工具栏中选择。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-1FB23DE5-14B0-41A5-8478-51F65BF3D27B.png) <!-- baize:img-hook downloaded=false reason="正文 1025 字 ≥300，非承重" -->。

4. 从您的自定义绑定转至“自定义绑定”(Custom Rig)选项卡以映射绑定的结构：选择其中一个自定义绑定控制器，然后右键单击**“自定义绑定”(Custom Rig)**选项卡中的相应单元并从显示的菜单中选择“指定选定的效应器”(Assign Selected Effector)。定义了某单元后，它将变为绿色，以指示其已被映射。

  默认情况下，IK 效应器映射平移和旋转，而 FK 效应器只映射旋转。

5. 要针对膝部和肘部映射上方向向量效应器（仅平移），请在**“角色”(Character)**表示中选择相应单元，然后完成以下步骤：

  - 在“映射控件”(Mapping Controls)中选择“贴图平移”(Map Translations)。

  - 在“映射控件”(Mapping Controls)中取消选择“贴图旋转”(Map Rotations)。

  - 将“平移 X 偏移”(Translation X Offset)、“平移 Y 偏移”(Translation Y Offset)和“平移 Z 偏移”(Translation Z Offset)设置为零。

6. 使用“映射控件”(Mapping Controls)调整自定义绑定效应器和骨架关节之间的偏移。

7. 创建自定义绑定映射以后，您可以通过单击“保存自定义绑定映射”(Save Custom Rig Mapping)图标 ![图：创建自定义绑定映射以后，您可以通过单击“保存自定义绑定映射”(Save Custom Rig Mapping)图标 对其…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-0BBF0D24-3F15-47BB-92F8-663D52862B7D.png) <!-- baize:img-hook downloaded=false reason="正文 1025 字 ≥300，非承重" --> 对其进行保存。

  您的自定义绑定映射存储在一个 XML 文件中，可以使用“加载自定义绑定映射”(Load Custom Rig Mapping)图标 ![图：您的自定义绑定映射存储在一个 XML 文件中，可以使用“加载自定义绑定映射”(Load Custom Rig Mappi…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-182DC074-FAB0-4935-B0C6-0562A84AC315.png) <!-- baize:img-hook downloaded=false reason="正文 1025 字 ≥300，非承重" --> 加载该文件，以便于以后重复使用。通过保存自定义绑定映射，您可以为自定义绑定创建模板。

与场景一起保存自定义绑定映射的步骤

1. 保存场景。

2. 重新启动 Maya 或选择“文件 > 新建”(File > New)。

3. 选择“文件 > 打开”(File > Open)，然后导航至保存的场景。

您的角色将加载，并且其自定义绑定映射仍然正确应用。
