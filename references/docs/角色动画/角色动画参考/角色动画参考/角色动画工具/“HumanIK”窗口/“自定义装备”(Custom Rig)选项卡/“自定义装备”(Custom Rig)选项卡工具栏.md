# “自定义装备”(Custom Rig)选项卡工具栏

- “自定义装备”(Custom Rig)选项卡工具栏位于 [HumanIK](../../“HumanIK”窗口.md) 的“自定义装备”(Custom Rig)选项卡顶部

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-64B3E003-D07C-4E1F-99F5-56154552CCF9.png) <!-- baize:img-hook downloaded=false reason="正文 344 字 ≥300，非承重" -->
