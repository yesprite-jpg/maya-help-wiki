# 控制角色表示

显示两足动物角色的图像和所有可用于为 HumanIK 控制装备设置动画的效应器。

为骨架定义创建控制装备后，角色表示会为装备中的每个 IK 和 FK 效应器显示各个单元。这些单元提供在固定、IK 融合和 IK 拉动（为每个效应器定义的）方面的视觉反馈，通过它们，您可以创建和选择辅助效应器和枢轴效应器。
