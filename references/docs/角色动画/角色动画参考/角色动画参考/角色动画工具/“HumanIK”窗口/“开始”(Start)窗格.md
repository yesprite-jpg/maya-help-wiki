# “开始”(Start)窗格

**“开始”(Start)**窗格包含若干按钮，可以指导您完成角色设置工作流程。使用“创建”(Create)和“定义”(Define)部分中的按钮，可在 [HumanIK 窗口](../“HumanIK”窗口.md)中打开一个新选项卡。每个选项卡均包含一个 HumanIK 工具，该工具会在角色设置过程中使用。“导入”(Import)部分中的按钮将打开一个网页，您可以从中下载免费的示例。

设置角色时，“HumanIK”窗口中将显示不同的选项卡。一旦在窗口中显示某一选项卡，该选项卡即会保留在该窗口中，您可以随时访问它。在选项卡之间切换不会影响当前角色状态。“开始”(Start)窗格中的某些按钮也会显示为“HumanIK”菜单按钮中的菜单项。这些选项可以互相结合使用。

您可以通过从[“角色”(Character)菜单](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-46964B80-1DEA-49BB-A7CF-0DBA40D9F87F.htm)中选择“无”(None)，在设置期间随时返回到此窗格。

## 创建

#### 创建骨架(Create Skeleton)

在场景中创建具有有效骨架定义的骨架，并在 [HumanIK 窗口](../“HumanIK”窗口.md)中打开“骨架”(Skeleton)、“定义”(Definition)和“控制装备”(Control Rig)选项卡。此操作会将“源”(Source)状态设置为“无”(None)。

**注**

仅当您在 Maya 中使用

“HumanIK”

窗口创建骨架时，

“骨架”(Skeleton)

选项卡才可用。

请参见[“骨架”(Skeleton)选项卡](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-3250FD5A-9A95-4A1C-8017-812149FC74F7.htm)和[创建和定义 HumanIK 骨架](../../../../HumanIK/HumanIK/设置%20HumanIK%20角色/创建和定义%20HumanIK%20骨架.md)。

#### 创建控制装备(Create Control Rig)

打开“创建控制装备”(Create Control Rig)对话框。选择“创建”(Create)按钮，创建 HumanIK 骨架和有效的骨架定义。如果已有骨架，而该骨架需要定义，请选择“定义”(Define)。

**注**

提示：

为骨架提供有效定义后，请从

“源”(Source)

菜单中选择

“控制装备”(Control Rig)

以创建控制装备。

请参见[“控制”(Controls)选项卡](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-5522E13D-C958-41E7-BD84-FC160B25DE22.htm)和[创建控制装备](../../../../HumanIK/HumanIK/设置%20HumanIK%20角色/创建控制装备.md)。

#### 创建角色定义(Create Character Definition)

打开[定义(Definition)选项卡](“定义”%28Definition%29选项卡.md)。您可在此选项卡中映射现有骨架的结构。请参见[为 HumanIK 定义现有骨架](../../../../HumanIK/HumanIK/设置%20HumanIK%20角色/为%20HumanIK%20定义现有骨架.md)。

#### 创建自定义装备映射(Create Custom Rig Mapping)

用于映射现有装备的结构。角色必须具有自定义装备和有效的骨架定义，您才可定义自定义装备。如果骨架没有骨架定义，选择此选项将打开“自定义装备”(Custom Rig)对话框。单击“定义”(Define)可打开“定义”(Define)选项卡，或者单击“取消”(Cancel)可返回到**“开始”(Start)窗格**。 请参见[“自定义装备”(Custom Rig)选项卡](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-803B17FD-B73C-485F-8976-D4478F821218.htm)和[创建自定义装备映射](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-D8B0FEDE-C651-4B88-8DAA-C1EA73F7D538.htm)。

#### 快速装备工具(Quick Rig Tool)

打开[快速装备工具](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-DC29C982-D04F-4C20-9DBA-4BBB33E027EF.htm)，用于快速装备动画的角色网格。请参见[为网格创建自动角色装备](../../../../HumanIK/HumanIK/为网格创建自动角色装备.md)。

## 导入采样

#### 导入 Human IK 示例(Import Human IK Example)和导入动画示例(Import Animation Example)

单击可直接加载示例场景。示例角色随有效的角色定义一起加载，且已准备好进行装备。
