# 移动蒙皮关节工具(Move Skinned Joints Tool)

- 蒙皮 > 移动蒙皮关节(Skin > Move Skinned Joints)（从“装备”(Rigging)菜单集）

允许重新定位含绑定蒙皮的角色的关节，而不必分离蒙皮。请参见[移动关节](../../../使用骨架/使用骨架/构建骨架/设置关节链/移动关节.md)和[关节方向设置](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865#GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865__SECTION_37A0CC9901F44305A0D663A90AE5FBAB)。
