# 动画约束融合

可以在同一对象上融合关键帧动画和约束。请参见[为对象设置动画并约束对象](为对象设置动画并约束对象.md)与[动画约束融合工作流](动画约束%28Animation-Constraint%29融合工作流.md)。

如果将关键帧动画和约束应用于同一对象，将自动生成 [pairBlend](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Tech-Docs/Nodes/pairBlend.html) 节点。请参见 [pairBlend](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E296FB24-D58A-4196-861D-DDB39E3B8E28.htm)。所有对象的动画和约束通道都将通过该“pairBlend”节点链接到对象。

您可以修改动画约束融合的权重来生成各种效果。该“权重”(Weight)属性位于“pairBlend”节点。请参见[通道盒中的融合权重](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E296FB24-D58A-4196-861D-DDB39E3B8E28.htm#WS17956D7ADBC6E7363438120E117AE30D38F-7FDA)。

**注**

- 由于动画约束融合允许您变换受驱动对象的受约束通道，因此您必须锁定确实希望其受目标对象影响的受约束通道。

- 变换某个受约束对象后，您可以通过从“修改受约束的轴选项”(Modify Constrained Axis Options)窗口重新应用“保持偏移”(Maintain Offset)保留它的新平移、旋转和/或缩放。这可避免在变换受约束对象的目标对象时将该受约束对象捕捉回其原始平移、旋转和/或缩放。

## 动画约束融合示例

- 一个人奔跑至停着的敞篷小汽车，跳过车门并坐入驾驶员的座位，然后驱车而去。在该示例中，角色和汽车模型都设置为动画，人体各部位都受到车门、车座和方向盘的点约束。

- 一名篮球运动员运球、拾球并将球扔给另一名球员。接到球的球员暂停，然后投篮。在该示例中，球和所有球员的手都设置为动画，球是每个球员的手的父约束。
