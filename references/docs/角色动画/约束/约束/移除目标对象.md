# 移除目标对象

从约束中移除目标对象

1. 选择驱动者对象，然后按住 Ctrl 键并单击要从中移除约束连接的目标对象。

2. 从[“约束”(Constrain)菜单](“约束”%28Constrain%29菜单.md)中选择“约束 > (修改)移除目标”(Constrain > (Modify) Remove Target) > ![图：从“约束”(Constrain)菜单中选择“约束 (修改)移除目标”(Constrain (Modify) Remove…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 356 字 ≥300，非承重" -->。

3. 勾选“约束类型”(constraint types)要断开连接的。

  - 如果要断开选定驱动者对象和目标对象之间的所有约束连接，请启用“全部”(All)。

  - 如果要保留目标对象的相对变换（平移、旋转和缩放等），请启用“保持偏移”(Maintain Offset)。

4. 单击“移除”(Remove)或“应用”(Apply)，以移除选定驱动者对象和目标对象之间的指定连接。“移除”(Remove)将关闭“移除目标选项”(Remove Target options)窗口，而“应用”(Apply)会使其保持打开状态。
