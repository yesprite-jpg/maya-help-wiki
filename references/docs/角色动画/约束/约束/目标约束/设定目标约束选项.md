# 设定目标约束选项

设定目标约束选项

1. 选择要约束的对象。最后选定的对象将是受约束的对象。

2. 选择[“约束 > 目标”(Constrain > Aim)](目标约束选项.md) > ![图：选择“约束 目标”(Constrain Aim) 。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 96 字 <300 且带图" -->。

3. 设定约束选项。

4. 单击“添加”(Add)或“应用”(Apply)创建目标约束。
