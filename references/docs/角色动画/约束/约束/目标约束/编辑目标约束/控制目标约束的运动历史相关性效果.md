# 控制目标约束的运动历史相关性效果

在某些情况下，受约束对象可能会与运动历史相关。有关详细信息，请参见[运动历史相关性效果](../../目标约束.md#WS17956D7ADBC6E736-3392E17117AE30CC4B-7FF7)。

通过确保目标向量和上方向向量不指向同一方向，可以控制运动历史相关性。如果它们指向同一方向，则阻止运动历史相关性的最佳方法是更改上方向向量的方向。您也可以更改目标向量，但您选择上方向向量时很可能对象会朝向特定的方向。

此外，如果将目标约束的“世界上方向类型”(World Up Type)设定为“None”，则受约束对象会依赖运动历史。

使用“属性编辑器”(Attribute Editor)更改上方向向量或目标向量的方向

1. 按照[编辑目标约束](../编辑目标约束.md)中所述，选中“目标向量”(Aim Vector)和“上方向向量”(Up Vector)属性。如果它们的方向相同，请编辑其中一个属性，以便它们不会同时指向同一方向。

使用“属性编辑器”(Attribute Editor)更改“世界上方向类型”(World Up Type)属性

1. 按照[编辑目标约束](../编辑目标约束.md)中所述，选中“世界上方向类型”(World Up Type)属性。如果设定为“无”(None)，则受约束对象可以为运动历史相关的。
