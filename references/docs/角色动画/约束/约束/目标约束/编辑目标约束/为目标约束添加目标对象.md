# 为目标约束添加目标对象

创建目标约束后，可以添加更多目标对象，从而加强对受约束对象方向的控制。添加更多目标对象类似于创建目标约束。

添加目标对象

1. 选择一个或多个要添加作为目标对象的对象，后跟受约束对象。

2. 选择[“约束 > 目标”(Constrain > Aim)](../目标约束选项.md) > ![图：选择“约束 目标”(Constrain Aim) 。 此时出现“目标约束选项”(Aim Constraint Optio…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 376 字 ≥300，非承重" -->。

  此时出现“目标约束选项”(Aim Constraint Options)窗口。

3. 单击“添加”(Add)以添加选定对象作为目标对象。

## 移除目标约束的目标对象

创建目标约束之后，可以移除任何目标对象，从而使这些对象不再约束受约束对象。移除目标对象与添加目标对象类似。

移除目标对象

1. 选择一个或多个要移除的对象作为目标对象，后跟受约束对象。

2. 选择“约束 > 移除目标”(Constraint > Remove Target)。

请注意，移除目标对象时，会同时移除附加到该目标对象的约束对象的所有动画曲线。

也可以从约束中移除特定轴。有关该过程，请参见[修改约束轴](../../修改约束轴.md)。
