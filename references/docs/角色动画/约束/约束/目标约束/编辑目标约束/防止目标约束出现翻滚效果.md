# 防止目标约束出现翻滚效果

在某些情况下，受约束对象可以围绕其目标向量快速翻滚。当目标向量接近或指向与向上向量的同一方向者相反方向时，可能会产生翻滚效果。有关详细信息，请参见[翻滚效果](../../目标约束.md#WS17956D7ADBC6E736-3392E17117AE30CC4B-7FF8)。

通过使目标点避开世界上方向向量的方向可以避免翻滚效果。例如，如果世界上方向向量指向场景的世界空间 Y 轴的方向（默认值），则应尝试避免正或负 Y 轴与目标点相交。可以根据需要移动目标对象，或更改目标对象权重，使目标点不接近 Y 轴。

但是，如果您的动画无法避免这些行为，则可通过更改世界上方向向量或设置其动画来防止翻滚。

使用“属性编辑器”(Attribute Editor)更改目标约束的世界上方向向量

1. 按照[编辑目标约束](../编辑目标约束.md)中所述，编辑“世界上方向类型”(World Up Type)属性。请注意，也可以使用“通道盒”(Channel Box)编辑“世界上方向向量”(World Up Vector)。

使用“通道盒”(Channel Box)对目标约束的世界上方向向量设置动画

1. 可通过使用“通道盒”(Channel Box)为“世界上方向向量”(World Up Vector)属性设定关键帧。若要选择“世界上方向向量”(World Up Vector)属性，请参见[编辑目标约束](../编辑目标约束.md)。若要在“世界上方向向量”(World Up Vector)上设置关键帧，请选择“世界上方向向量”(World Up Vector)属性，在该属性上单击鼠标右键，然后从显示的弹出菜单中选择“为选定项设置关键帧”(Key Selected)。
