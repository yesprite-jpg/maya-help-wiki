# 多边形上的点约束

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../.extension/assets/Maya-CharacterAnimation/GUID-9DF68F93-3907-4390-9804-5FDC24D17478.gif) <!-- baize:img-hook downloaded=true reason="正文 137 字 <300 且带图" -->

通过多边形上的点约束，可以将对象约束到网格，以便在网格变形时受约束对象贴附于曲面上的某个点。您可以将对象约束到整个网格，也可以约束到特定的顶点、面或边。使用该约束可以创建各种效果，例如外套变形时外套上的纽扣仍保留在原位。
