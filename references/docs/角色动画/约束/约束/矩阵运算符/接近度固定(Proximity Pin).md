# 接近度固定(Proximity Pin)

proximityPin 节点用于跟踪变形曲面上的位置。它从输入变换中曲面上的最近点派生位置。相反，uvPin 节点从指定的 UV 坐标派生位置。如果要使用相关控件以重新定位输入或不存在干净 UV，请使用 proximityPin 节点将对象附加到几何体。

由于 proximityPin 是程序节点，因此可以在创建后对输入、坐标系、对齐和偏移进行更改。

若要了解如何使用 proximityPin 节点将对象附加到几何体，请参见[创建接近度固定](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-92DA0E89-26BB-4F1A-A74B-541FE2359BDC.htm)。
