# 创建铆钉

“铆钉”(Rivet)命令可用于将定位器直接附加到变形网格。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-26B08938-B9EE-4FEE-AFE3-4CA306D1859D.png) <!-- baize:img-hook downloaded=false reason="正文 400 字 ≥300，非承重" -->

如果要快速地将道具添加到角色（例如，将纽扣粘贴到衬衫，或将勋章固定到制服上），则“铆钉”(Rivet)命令非常有用。

使用“铆钉”(Rivet)命令

1. 在几何体上选择面、点或 UV。

2. 在**“动画”(Animation)**(**F4**) 或**“绑定”(Rigging)**(**F3**) 菜单集中，选择“约束 > 铆钉”(Constrain > Rivet)。

  “铆钉”(Rivet)定位器会附加到选定的面、点或 UV。

3. 变换几何体或使几何体变形时，定位器会随之移动。

**注**

提示：

“铆钉”(Rivet)

命令，可轻松创建

uvPin

属性编辑器(Attribute Editor)

中的

“UV 固定”(UV Pin)选项

来调整其行为。
