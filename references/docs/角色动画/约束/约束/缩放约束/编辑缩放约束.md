# 编辑缩放约束

## 编辑缩放约束属性

使用“属性编辑器”(Attribute Editor)编辑缩放约束属性

1. 选择缩放约束节点。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

3. 以下区域提供可用属性：“变换属性”(Transform Attributes)、“缩放约束属性”(Scale Constraint Attributes)、“枢轴”(Pivots)、“限制信息”(Limit Information)、“显示”(Display)、“节点行为”(Node Behavior)和“附加属性”(Extra Attributes)。

4. 执行下列操作之一：

  - 单击“选择”(Select)以选择现在正编辑的节点作为场景中当前选定的对象。

  - 单击“加载属性”(Load Attributes)加载当前选定节点的属性值。

  - 单击“复制选项卡”(Copy Tab)以打开一个单独的窗口，其中包含选定节点的属性。

## 为缩放约束添加目标对象

创建缩放约束后，可以添加更多目标对象以实现对受约束对象位置的额外控制。添加更多目标对象类似于创建缩放约束。

为缩放约束添加目标对象

1. 选择要作为目标对象添加的一个或多个对象，后跟受约束对象。

2. 选择“约束 > 缩放”(Constrain > Scale) > ![图：选择“约束 缩放”(Constrain Scale) 以查看缩放约束选项。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" --> 以查看[缩放约束选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-CD49C0AF-F683-44E2-8A49-AC19FDC32A1A.htm)。

3. 单击“添加”(Add)以将选定对象添加为目标对象。
