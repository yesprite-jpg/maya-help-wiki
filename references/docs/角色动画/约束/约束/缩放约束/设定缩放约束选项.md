# 设定缩放约束选项

设定缩放约束选项

1. （可选）如果还要立即创建缩放约束，请选择要约束的对象。最后选定的对象将为受约束对象。

2. 选择[约束 > 缩放(Constrain > Scale)](缩放约束%28Scale%20constraint%29选项.md) > ![图：选择约束 缩放(Constrain Scale) 。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 114 字 <300 且带图" -->。

3. 设定约束选项。

4. 单击“添加”(Add)或“应用”(Apply)以创建缩放约束。
