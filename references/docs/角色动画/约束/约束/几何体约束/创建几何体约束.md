# 创建几何体约束

创建几何体约束

1. 选择一个或多个目标对象，然后选择要约束到这些对象的对象。

2. 选择“约束 > 几何体”(Constrain > Geometry) > ![图：选择“约束 几何体”(Constrain Geometry) 以打开几何体约束选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 77 字 <300 且带图" --> 以打开[几何体约束选项](几何体约束选项%28Geometry%20Constraint%20Options%29.md)。
