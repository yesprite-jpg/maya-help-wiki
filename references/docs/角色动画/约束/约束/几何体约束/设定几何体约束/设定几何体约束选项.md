# 设定几何体约束选项

设定几何体约束选项

1. 如果您现在还要创建几何体约束，请选择一个或多个对象。最后选定的对象将为受约束对象。

2. 选择“约束 > 几何体”(Constrain > Geometry) > ![图：选择“约束 几何体”(Constrain Geometry) 以打开几何体约束选项。](../../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 131 字 <300 且带图" --> 以打开[几何体约束选项](../几何体约束选项%28Geometry%20Constraint%20Options%29.md)。

3. 设定约束选项。

4. 单击“添加”(Add)或“应用”(Apply)，创建几何体约束。
