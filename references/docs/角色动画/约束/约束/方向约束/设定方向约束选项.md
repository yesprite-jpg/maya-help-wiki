# 设定方向约束选项

设定方向约束选项

1. （可选）如果现在也要创建方向约束，选择要约束的对象。最后选定的对象将为受约束对象。

2. 选择[约束 > 方向(Constrain > Orient)](方向约束选项.md) > ![图：选择约束 方向(Constrain Orient) 。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 114 字 <300 且带图" -->。

3. 设定约束选项。

4. 单击“添加”(Add)或“应用”(Apply)以创建方向约束。
