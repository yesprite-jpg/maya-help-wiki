# 添加方向约束目标对象

创建方向约束后，可以添加更多目标对象，从而加强对受约束对象位置的控制。添加更多目标对象类似于创建方向约束。

添加目标对象

1. 选择要作为目标对象添加的一个或多个对象，后跟受约束对象。

2. 选择[约束 > 方向(Constrain > Orient)](../方向约束选项.md) > ![图：选择约束 方向(Constrain Orient) 。](../../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 140 字 <300 且带图" -->。

3. 单击“添加”(Add)以将选定对象作为目标对象添加。
