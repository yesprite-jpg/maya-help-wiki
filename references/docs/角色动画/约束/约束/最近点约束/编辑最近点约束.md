# 编辑最近点约束

如果在创建最近点约束时创建了一个“输入位置定位器”(Input Position Locator)，则可以使用移动工具调整定位器的位置。

移动输入定位器

1. 选择定位器。

2. 选择“移动工具”![图：选择“移动工具”，然后移动定位器。 最近点定位器（如果已创建）和结果计算将相应地进行更新。（请参见查看最近点约束结果。）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-4F71754D-26E8-4AF4-889B-75B1D4A8F947.png) <!-- baize:img-hook downloaded=false reason="正文 408 字 ≥300，非承重" -->，然后移动定位器。

  最近点定位器（如果已创建）和结果计算将相应地进行更新。（请参见[查看最近点约束结果](查看最近点约束结果.md)。）

如果在创建约束时未创建“输入位置定位器”(Input Position Locator)，则可以使用约束的“输入位置”(In Position)属性手动定义输入位置。

手动设定输入位置

1. 选择 closestPointOnMesh、closestPointOnSurface 或 nearestPointOnCurve 节点。

2. 在“属性编辑器”(Attribute Editor)中，为“输入位置”(In Position)属性输入 X、Y 和 Z 值。

  这样会定义一个新的输入位置，并会相应地更新最近点结果计算。（请参见[查看最近点约束结果](查看最近点约束结果.md)。）
