# 创建最近点约束

使用默认选项创建最近点约束

1. 选择网格、曲面或曲线。

2. 从主菜单栏中，选择“约束 > 最近点”(Constrain > Closest Point)。

  默认情况下，Maya 将创建约束（closestPointOnMesh、closestPointOnSurface 或 nearestPointOnCurve），其中一个定位器表示输入位置，一个定位器表示最近点。

  可以在“属性编辑器”(Attribute Editor)中查看最近点信息。（请参见[查看最近点约束结果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1A112B9B-EB4A-4561-B3BE-678F5525313A.htm)。）

设定选项并创建最近点约束

1. 选择网格、曲面或曲线。

2. 从主菜单栏中，选择“约束 > 最近点”(Constrain > Closest Point) > ![图：从主菜单栏中，选择“约束 最近点”(Constrain Closest Point) ”。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 594 字 ≥300，非承重" -->”。

3. 在[最近点约束选项](“最近点”%28Closest%20Point%29约束选项.md)中，启用要创建的定位器类型。

  **注**

  如果启用“输入位置定位器”(Input Position Locator)，则将自动创建相对于原点的“最近点定位器”(Closest Point Locator)。有关调整输入定位器位置的信息，请参见[编辑最近点约束](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-765A5057-C50E-4923-9500-C76558408259.htm)。

4. 单击“应用并关闭”(Apply and Close)。

  您选择的定位器类型将创建并约束为网格、曲面或曲线，且 Maya 将创建 closestPointOnMesh、closestPointOnSurface 或 nearestPointOnCurve 节点。如果同时选择两种定位器，则将在原点创建输入位置定位器，且相对于该点创建最近点定位器。
