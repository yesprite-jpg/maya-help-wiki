# 创建父约束

使用父约束，您可以相关一个对象的位置到另一个对象，以便这些对象的行为就像具有多个目标父对象的父-子关系。有关使用父约束的详细信息，请参见[父约束](../父约束.md)。

**注**

注意：

建议在创建第一个父约束之前，先设置

“父约束选项”(Parent Constraint Options)

。

创建父约束

1. 选择一个或多个目标对象，后跟要约束的对象。

2. 在“动画”(Animation)或“装备”(Rigging)菜单集中，选择“约束 > 父对象”(Constrain > Parent) > ![图：在“动画”(Animation)或“装备”(Rigging)菜单集中，选择“约束 父对象”(Constrain Pare…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 872 字 ≥300，非承重" -->。

3. 设置约束选项或选择“编辑 > 重置设置”(Edit > Reset Settings)。

  **注**

  提示：

  启用“保持偏移”(Maintain Offset)以保持受约束对象相对于其目标的当前位置。之后，可以修改对象之间的偏移。（请参见[修改父约束偏移](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-E6658A95-7702-4BB1-BE19-15DFDE2A335E.htm)。）

4. 要完成约束设置，请执行下列操作之一：

  - 单击“添加”(Add)以创建父约束。此时将关闭“父约束选项”(Parent Constraint Options)窗口。选择“编辑 > 保存设置”(Edit > Save Settings)以保存约束选项。

  - 单击“应用”(Apply)以创建父约束。此时“父约束选项”(Parent Constraint Options)窗口将保持打开状态。通过单击“应用”，还可以将当前约束选项设置应用到其他对象。选择“编辑 > 保存设置”(Edit > Save Settings)以保存约束选项。

  - 单击“关闭”(Close)以关闭“父约束选项”(Parent Constraint Options)窗口而不设置或创建约束。

将父约束到添加动画层

1. 选择一个或多个目标对象，后跟要约束的对象。

2. 选择约束 > 父约束(Constrain > Parent) > ![图：选择约束 父约束(Constrain Parent) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 872 字 ≥300，非承重" -->。

3. 在“父约束选项”(Parent Constraint Options)窗口中，设定所需的约束选项。从“动画层”(Animation Layer)下拉菜单中，选择要添加约束的动画层。

  **注**

  提示：

  将约束添加到动画层时，请启用“保持偏移”(Maintain Offset)，使受约束对象不会意外移动。

  现在，约束动画包含在指定的动画层中，并有助于在场景中生成动画。
