# 将目标对象添加到父约束

创建父约束后，可以添加更多目标对象，以便增加对受约束对象的位置和旋转的控制。添加更多目标对象会更改目标点，从而更改受约束对象的位置。请参见[目标点](../../../约束.md#GUID-7665A291-FAA7-44C0-BDEB-A6C83482116C__WS17956D7ADBC6E736-3392E17117AE30CC4B-7FFD)。

将目标对象添加到父约束

1. 选择一个或多个要添加为目标对象的对象，后跟受约束对象。

2. 选择[“约束 > 父对象”(Constrain > Parent)](../父约束选项%28Parent%20constraint%20options%29.md)。

  **注**

  如果启用“父约束选项”(Parent Constraint Options)中的“保持偏移”(Maintain Offset)，则在将目标添加到约束时，受约束对象的位置和旋转不会更改。
