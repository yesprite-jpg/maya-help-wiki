# 矩阵运算符

矩阵运算符是一组[依存关系图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-51096BC4-32B7-4391-BE39-21641B374745) (DG) 节点，可以链接在一起以执行复杂数学运算，从而用作 Maya 矩阵驱动变换节点的输入。

在变换节点上添加矩阵输入时可打开与传统 Maya 工作流不同的新方法来驱动变换。使用矩阵运算符意味着您不必使用具有多个连接的无关 DG 和[有向非循环图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-5029CF89-D420-4236-A7CF-884610828B70) (DAG) 节点（这通常需要耗费大量时间进行修改、编辑和计算）。矩阵节点构建为程序节点。例如，proximityPin 和 uvPin 坐标系在创建后可进行编辑以包含新输入。

如果先前创建了约束，通常需要删除并重新创建约束以便做出修改。这些节点的程序特性意味着您可以在工作时修改设置。[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)可显示许多属性，便于精细地控制系统的运行方式。

#### 接近度固定(Proximity Pin)

通过计算曲面上距给定世界位置最近的点，proximityPin 节点输出位置。请参见[接近度固定(Proximity Pin)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-8A5E153C-8D06-408D-9D72-D82AC39D1288.htm)。

#### UV 固定(UV Pin)

类似于 proximityPin，但使用输入 UV 坐标来计算和输出位置。请参见 [UV 固定(UV Pin)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-17402067-DFA9-4F0B-99E3-233920040A0B.htm)。

#### 铆钉(Rivet)

“铆钉”(Rivet)命令可使用公用设置快速创建 uvPin 节点（请参见上文）。可以通过[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)访问完整的 uvPin 功能。请参见[“铆钉”(Rivet)命令](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-1CA0E628-DACF-4B42-AA9A-4EEC28EE2A4C.htm)。
