# 控制法线约束的运动历史相关性效果

在某些情况下，受约束对象可能会与运动历史相关。有关详细信息，请参见[运动历史相关性效果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6E2297A1-D8EA-452B-80C5-A692F24CF427.htm#WS17956D7ADBC6E736-3392E17117AE30CC4B-7FF7)。

通过确保目标向量和上方向向量不指向同一方向，可以控制运动历史相关性。如果它们指向相同的方向，防止运动历史相关性的最佳方法是更改上方向向量的方向。也可以更改目标向量，但选择目标向量后对象可能会以特定的方式进行定向。

此外，如果将法线约束的“世界上方向类型”(World Up Type)设定为“无”(None)，则受约束对象可能会与运动历史相关。

使用“属性编辑器”(Attribute Editor)更改法线约束的上方向向量或目标向量

1. 按照[编辑法线约束](../编辑法线约束.md)中所述，选中“目标向量”(Aim Vector)和“上方向向量”(Up Vector)属性。如果它们的方向相同，请编辑其中一个属性，以便它们不会同时指向同一方向。

使用“属性编辑器”(Attribute Editor)更改法线约束“世界上方向类型”(World Up Type)属性

1. 按照[编辑法线约束](../编辑法线约束.md)中所述，选中“世界上方向类型”(World Up Type)属性。如果设定为“无”(None)，则受约束对象可以为运动历史相关的。
