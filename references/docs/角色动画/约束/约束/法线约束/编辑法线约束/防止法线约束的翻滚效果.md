# 防止法线约束的翻滚效果

在某些情况下，受约束对象可以围绕其目标向量快速翻滚。当目标向量接近或指向与向上向量的同一方向者相反方向时，可能会产生翻滚效果。有关详细信息，请参见[翻滚效果](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-6E2297A1-D8EA-452B-80C5-A692F24CF427.htm#WS17956D7ADBC6E736-3392E17117AE30CC4B-7FF8)。

可以通过保持目标向量在世界上方向向量畅通来避免翻滚效果。例如，如果世界上方向向量指向场景的世界空间 Y 轴方向（默认），则可以尝试避免使用相同方向的正或负 Y 轴作为目标向量。可以根据需要移动目标对象或可能更改目标对象权重，使目标向量不会靠近 Y 轴。

但是，如果您的动画无法避免这些行为，则可通过更改世界上方向向量或设置其动画来防止翻滚。若要使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)更改法线约束的世界上方向向量，请按[编辑法线约束](../编辑法线约束.md)中所述编辑“世界上方向向量”(World Up Vector)属性/通道。

使用“通道盒”(Channel Box)设置法线约束的世界上方向向量。

1. 可通过使用“通道盒”(Channel Box)为“世界上方向向量”(World Up Vector)属性设定关键帧。若要选择“世界上方向向量”(World Up Vector)属性，请参见[编辑法线约束](../编辑法线约束.md)。若要在“世界上方向向量”(World Up Vector)上设置关键帧，请选择“世界上方向向量”(World Up Vector)通道，在该通道上单击鼠标右键，然后从显示的弹出菜单中选择“为选定项设置关键帧”(Key Selected)。
