# 创建法线约束

创建法线约束时，可以先设定创建选项，然后创建法线约束，也可以使用当前创建选项立即创建约束。

通常，需要先创建一个几何体约束来将对象约束到某个曲面，然后创建法线约束来约束对象的方向，以使其与曲面的法线向量对齐。

若要约束对象对准局部旋转正 X 轴方向，使用默认的约束选项即可。

创建法线约束

1. 选择一个或多个目标对象，然后选择要约束的对象。

2. 选择“约束 > 法线”(Constrain > Normal) > ![图：选择“约束 法线”(Constrain Normal) 以查看法线约束选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 200 字 <300 且带图" --> 以查看[法线约束选项](“法线约束”%28Normal%20constraint%29选项.md)。
