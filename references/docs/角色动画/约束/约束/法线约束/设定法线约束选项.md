# 设定法线约束选项

设定法线约束选项

1. （可选）如果要立即创建法线约束，请选择要约束的对象。最后选择的对象将为受约束对象。

2. 选择“约束 > 法线”(Constrain > Normal) > ![图：选择“约束 法线”(Constrain Normal) 以查看法线约束选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 124 字 <300 且带图" --> 以查看[法线约束选项](“法线约束”%28Normal%20constraint%29选项.md)。

3. 设定约束选项。

4. 单击“添加”(Add)或“应用”(Apply)创建法线约束。
