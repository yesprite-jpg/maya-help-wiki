# 编辑法线约束

## 编辑法线约束通道

用“通道盒”(Channel Box)编辑法线约束通道

1. 在场景中选择受约束对象。

2. 设定通道。

3. 单击要编辑的通道的名称。

4. 在场景中，单击鼠标中键并左右移动鼠标。通过移动鼠标，可以交互方式更改选定通道的值。移动鼠标时，请注意按 Ctrl 键可以提供更精细的控制，按 Shift 键可提供精细度较小的控制。

## 编辑法线约束属性

通过“属性编辑器”(Attribute Editor)编辑法线约束属性

1. 选择法线约束节点。

2. 打开[“属性编辑器”(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

3. 设定属性。

4. 请执行以下操作：

  - 单击“选择”(Select)以选中正在编辑的节点作为场景中当前选定的对象。

  - 单击“加载属性”(Load Attributes)加载当前选定节点的属性值。

  - 单击“复制选项卡”(Copy Tab)打开一个包含选定节点属性的单独窗口。
