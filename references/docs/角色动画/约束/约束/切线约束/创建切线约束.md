# 创建切线约束

创建相切约束时，可以先设定创建选项，然后现创建相切约束，也可以使用当前创建选项立即创建约束。

通常，需要先创建几何体约束，以将对象约束于某些曲线。然后创建相切约束，以约束对象的方向，使其与曲线的切线对齐。

若要约束对象对准局部旋转正 X 轴方向，使用默认的约束选项即可。

创建相切约束

1. 选择一个或多个目标对象，然后选择要约束的对象。

2. 选择“约束 > 切线”(Constrain > Tangent) > ![图：选择“约束 切线”(Constrain Tangent) 以查看切线约束选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=true reason="正文 199 字 <300 且带图" --> 以查看[切线约束选项](切线约束选项.md)。
