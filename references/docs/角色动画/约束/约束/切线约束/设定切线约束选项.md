# 设定切线约束选项

设定切线约束选项

1. 如果现在要创建切线约束，请选择一个或多个对象。最后选定的对象将为受约束对象。

2. 选择“约束 > 切线”(Constrain > Tangent) > ![图：选择“约束 切线”(Constrain Tangent) 以查看切线约束选项。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 116 字 <300 且带图" --> 以查看[切线约束选项](切线约束选项.md)。

3. 单击“添加”(Add)或“应用”(Apply)以创建切线约束。
