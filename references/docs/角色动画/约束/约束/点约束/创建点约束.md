# 创建点约束

点约束可用于使一个对象移动/跟随另一个对象的位置。此功能用于使一个对象匹配其他对象的运动。有关点约束的详细信息和示例，请参见[点约束](../点约束.md)。

创建点约束时，可以先设定创建选项，然后现创建点约束，也可以使用当前创建选项立即创建约束。使用约束创建选项，还可以将约束添加到动画层。请参见[点约束选项(Point Constraint Options)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-BB0B5F46-2BB7-4EA0-A611-27759EBA6609.htm)。

创建点约束

1. 选择一个或多个目标对象，然后选择要约束的对象。

2. 在“动画”(Animation)或“装备”(Rigging)菜单集中，选择“约束 > 点”(Constrain > Point)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-09F1A2CB-DE81-4558-897E-57166331A190.gif) <!-- baize:img-hook downloaded=false reason="正文 466 字 ≥300，非承重" -->

将点约束添加到动画层

1. 选择一个或多个目标对象，然后选择要约束的对象。

2. 选择“约束 > 点”(Constrain > Point) > ![图：选择“约束 点”(Constrain Point) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 466 字 ≥300，非承重" -->。

3. 在[点约束选项](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-BB0B5F46-2BB7-4EA0-A611-27759EBA6609.htm)中，设置所需的约束选项。

  从“动画层”(Animation Layer)下拉菜单中，选择要添加约束的动画层。

  **注**

  提示：

  将约束添加到动画层时，请启用

  “保持偏移”(Maintain Offset)

  ，使受约束对象不会意外移动。

  现在，约束动画包含在指定的动画层中，并有助于在场景中生成动画。
