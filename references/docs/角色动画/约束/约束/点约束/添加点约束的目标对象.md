# 添加点约束的目标对象

创建点约束之后，可以在受约束对象的位置为其他控制添加更多目标对象。添加多个目标对象更改目标点，可以更改受约束对象的位置。添加多个目标对象类似于创建点约束。

添加目标对象

1. 选择一个或多个要作为目标对象添加的对象（后跟受约束对象）。

2. 选择[约束 > 点(Constrain > Point)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-CharacterAnimation/files/GUID-BB0B5F46-2BB7-4EA0-A611-27759EBA6609.htm) > ![图：选择约束 点(Constrain Point) 。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 161 字 <300 且带图" -->。

3. 单击“添加”(Add)将选定对象添加为目标对象。
