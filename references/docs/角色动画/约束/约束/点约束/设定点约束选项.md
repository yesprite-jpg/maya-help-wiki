# 设定点约束选项

设定点约束选项

1. （可选）如果要现在创建点约束，则选择要约束的对象。最后选定的对象将成为受约束对象。

2. 选择[约束 > 点(Constrain > Point)](点约束选项.md) > ![图：选择约束 点(Constrain Point) 。](../../../../../.extension/assets/Maya-CharacterAnimation/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 102 字 <300 且带图" -->。

3. 单击“添加”(Add)或“应用”(Apply)创建点约束。
