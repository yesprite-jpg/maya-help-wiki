# 消息：“检测到 TDR。”

在 Windows 中，您可能会收到以下消息：

“检测到 TDR。应用程序必须关闭。”

当 Bifrost 图表的结果需要占用较长时间进行计算和绘制（例如，极高分辨率体积或大量复杂实例）时，会出现此情况。如果 Windows 在指定时间内未检测到来自显卡的响应，“超时检测和恢复”功能将重置显卡。

如果显示此消息，可以编辑 Windows 注册表以增加 Windows 将等待的超时期限。有关更多详细信息，请参见技术支持文章：[“检测到 TDR。”](https://knowledge.autodesk.com/zh-hans/support/maya/troubleshooting/caas/sfdcarticles/sfdcarticles/CHS/A-TDR-has-been-detected-The-application-must-close-message-and-Maya-crashes.html)
