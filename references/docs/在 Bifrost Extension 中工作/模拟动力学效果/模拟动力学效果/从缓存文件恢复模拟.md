# 从缓存文件恢复模拟

通过从缓存文件恢复模拟，可以对多个帧运行一次模拟，然后使用缓存结果作为模拟的新起点。

注意：

这不适用于 MPM 布料。

  将模拟的初始部分缓存到文件，例如，使用 `file_cache` 节点。

  - 缓存必须包含模拟所需的所有特性，因此，为了获得最佳结果，请将 `properties` 设置为默认值 `*`。

  - 支持的格式为 `.bob` 和 `.vdb`。

  - 将文件保存到磁盘后，不再需要 `file_cache` 节点。 如果希望将其保留在图表中以便在以后缓存最终结果，则可以将其设置为 `Passthrough Mode`。

  在模拟图表的设置节点的 `additional_settings` 输入上单击鼠标右键，选择**“创建图表”(Create Graph)**，然后选择 `Simulation:Common:set_initial_state`。将添加并连接 `set_initial_state` 节点。

  将 `filename` 设置为要用作模拟初始状态的缓存文件。

  （可选）将 `set_to_frame` 设置为要在其上使用初始状态的场景帧（如果它不同于第 1 帧）。

  - 这将成为发生任何模拟的最小场景帧，即使源或碰撞对象等其他节点已设置为从较早的帧开始。

  - 开始帧较晚的源和碰撞对象节点将照常在其指定帧上开始。

  如果需要，可以修改其他模拟节点上的任何参数。结果就好像使用原始设置运行模拟直到初始状态，然后使用新设置继续。
