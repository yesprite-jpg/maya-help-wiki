# Maya 安装和许可

可以在单个主机或网络服务器上安装 Maya。无需先卸载先前版本即可安装新版本。可以同时安装多个版本的 Maya。

如果在安装新版本之前卸载先前版本的 Maya，这两个版本的许可类型和产品激活方法可能有所不同，并且可能需要重新激活产品。

Maya 可以安装为采用英语、日语或简体中文运行。

Maya 的默认安装路径为：

| Windows | C:\Program Files\Autodesk\<Maya 版本> |
|---|---|
| Linux | /usr/autodesk/<Maya 版本> |
| macOS | /Applications/Autodesk/<Maya 版本> |

在 Linux 上，会自动建立从 /usr/local/bin/maya 到 /usr/autodesk/maya2020/bin/maya2020 的符号链接。

Bifrost、MtoA (Arnold for Maya) 和 Substance 随 Maya 一起安装。
