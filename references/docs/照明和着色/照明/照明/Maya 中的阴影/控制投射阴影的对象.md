# 控制投射阴影的对象

可以选择哪些对象和哪些阴影独立地进行渲染。例如，可以渲染对象，使它不投射阴影，但可以接收其他对象投射的阴影。

若要设置哪些对象投射阴影或者哪些对象不投射阴影，请参见[渲染统计信息(Render Stats)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3AF554B4-337F-4E03-81A1-26F454C1A90C)。

**注**

如果需要仅隔离有关接收阴影的对象的阴影信息，请将一种“使用背景”材质指定给它们。

## 选择要渲染的某个范围的对象和阴影

如果要仅渲染与摄影机的距离在某个特定范围内的对象和阴影（例如，仅前景对象），则可以使用摄影机的剪裁平面来控制渲染哪些对象和阴影（但是，从维护的角度看，将对象分离为层更好。）

有关更多详细信息，请参见[剪裁平面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D69C23DA-ECFB-4D95-82F5-81118ED41C95)。
