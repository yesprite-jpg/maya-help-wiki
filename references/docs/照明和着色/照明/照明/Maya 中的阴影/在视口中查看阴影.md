# 在视口中查看阴影

可以在视口中快速轻松地预览阴影，而无需渲染场景。

在视口中查看阴影

1. 在视口[面板菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)中，启用“照明 > 使用所有灯光”(Lighting > Use All Lights)，并确保同时启用“照明 > 阴影”(Lighting > Shadows)。

2. 如果对象不显示阴影，则选择该对象，并确保在属性编辑器的“渲染统计信息”(Render Stats)部分中已启用“投射阴影”(Casts Shadows)。

**注**

- 透明对象不显示硬件阴影。

- 点光源和区域光不显示硬件阴影。

- 在硬件 X 射线模式（“着色 > X 射线显示”(Shading > X-Ray)）下，所有对象都是透明的，并且不显示任何硬件阴影。
