# 设置直接光源

通常，设置直接光源的典型工作流如下所示：

1. 首先要确定场景的外观和感觉，以及如何在选择的光源中反射。

  请参见[规划光源](设置直接光源/规划光源.md)。

2. [创建光源](设置直接光源/创建光源.md)。

  可以为场景创建各种类型的光源，并设置用于进一步定义其特性的属性（选项）。

3. [调整光源属性](设置直接光源/调整光源属性.md)。

  通过更改“属性编辑器”(Attribute Editor)和“通道盒”(Channel Box)中的设置，可以调整已添加的灯光质。

4. 在场景中[定位灯光](调整照明/定位灯光.md)，并使用精度控制它们（可选）。

  请参见[显示、隐藏灯光操纵器或调整其大小](调整照明/定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。

  **注**

  由于对场景和对象进行照明（和构建场景），所以可以可视化（预览渲染）场景，以检查外观和感觉，以及灯光渲染的精确方式。

  要预览渲染场景，请参见[与 IPR 可视化交互](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-76A6C578-C4B9-42C8-9EC4-ECCE89A1E3BE)。

5. 通过从[面板菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)中选择“照明 > 使用所有灯光”(Lighting > Use All Lights)和“照明 > 阴影”(Lighting > Shadows)，在视口中查看灯光和阴影的效果。

6. （可选）[创建灯光光学效果](调整照明/辉光、光晕和镜头光斑/创建灯光光学效果.md)，例如辉光、光晕或镜头光斑。
