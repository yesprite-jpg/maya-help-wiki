# 调整光源属性

更改场景中灯光的基本属性（例如类型、颜色和强度）

1. 执行下列操作之一：

  - 在视口中选择灯光，然后在[属性编辑器(Attribute Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)中调整其值。

  - 双击 [Hypershade](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-447C9ADA-A285-483E-A93D-6ED1B2792D5F.htm) 灯光选项卡或工作区中的灯光图标，然后在 Hypershade“特性编辑器”(Property Editor)中调整其值。

  - 在“灯光编辑器”(Light Editor)中选择灯光，然后在 “特性编辑器”(Property Editor)中调整其值。

    您还可以选择多个灯光，并同时为所有选定灯光的某个属性设置相同的值。

    请参见[在灯光编辑器中修改灯光属性](../使用“灯光编辑器”%28Light%20Editor%29在场景中创建、分组和修改灯光/在灯光编辑器中修改灯光属性.md)。

  有关光源属性的描述，请参见[照明节点](../照明参考/照明节点.md)。
