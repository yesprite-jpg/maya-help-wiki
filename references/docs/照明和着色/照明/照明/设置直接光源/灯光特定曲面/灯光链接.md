# 灯光链接

创建光源后，默认情况下新的光源将照亮场景中的所有曲面（假设对光源的特性进行了适当的设定）。同样，创建曲面后，场景中的所有灯光将照亮新曲面。

您可以链接灯光与曲面，以便只有特定灯光（或灯光组）照亮特定曲面（或曲面组），或反之，只有特定对象（或对象组）接收特定灯光（或灯光组）的照明。

灯光链接可以帮助您更有效快速地渲染场景。您可以创建灯光集来控制复杂场景中灯光和对象之间的关系。
