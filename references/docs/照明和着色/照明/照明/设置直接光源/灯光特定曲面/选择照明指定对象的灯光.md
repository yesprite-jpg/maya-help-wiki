# 选择照明指定对象的灯光

有关灯光链接的信息，请参见[灯光链接](灯光链接.md)。

选择照明指定曲面的所有灯光

1. 选择曲面，然后从“渲染”(Rendering)菜单集中，选择照明/着色 > 选择照明对象的灯光(Lighting/shading > Select Lights Illuminating Object)。

  将亮显照明指定曲面的所有灯光。
