# 选择特定灯光照明的对象

有关灯光链接的信息，请参见[灯光链接](灯光链接.md)。

选择特定灯光照明的所有曲面

1. 选择灯光，然后从“渲染”(Rendering)菜单集中，选择照明/着色 > 选择灯光照明的对象(Lighting/shading > Select Objects Illuminated by Light)。

  会亮显选定灯光照明的所有对象。
