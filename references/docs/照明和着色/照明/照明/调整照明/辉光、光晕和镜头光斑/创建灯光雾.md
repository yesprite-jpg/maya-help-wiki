# 创建灯光雾

灯光雾通过将其添加到现有灯光中进行创建。

**注**

若要创建填充整个场景、不仅仅在特定灯光照明区域的雾，请使用环境雾体积材质。请参见[环境雾(Environment Fog)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-A88206BD-28F0-404A-92EB-DD7F929986C8.htm)。

将灯光雾添加到灯光

1. 选择要添加灯光雾的灯光。

2. 在灯光“属性编辑器”(Attribute Editor)的“灯光效果”(Light Effects)部分，单击“灯光雾”(Light Fog)属性旁的贴图按钮。

  Maya 会自动创建灯光雾节点，将其连接到灯光节点，并显示其“属性编辑器”(Attribute Editor)。
