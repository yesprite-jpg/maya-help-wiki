# 控制区域光的高光

控制区域光的镜面反射高光的大小和方向

1. 使用 Maya 变换工具（例如标准或特定光操纵器），通过“通道盒”(Channel Box)、“属性编辑器”(Attribute Editor)等对区域光进行定位和缩放。

2. IPR 场景以便以交互方式调整镜面反射高光。
