# 以交互方式设定衰退区域

可以使用衰退区域操纵器在聚光灯上以交互方式设定衰退区域。（或者，可以在“属性编辑器”(Attribute Editor)中输入精确距离位置。请参见[衰退区域属性](../../照明参考/照明节点/灯光效果%28Light%20Effects%29.md#WS17956D7ADBC6E7361022BC4117AE3252FD-7FD4)。）

衰退区域指示在三个截断圆锥体形状中需要照明的区域和不需要照明的区域。使用衰退区域操纵器来精确指示这些区域。

**注**

提示：

与聚光灯进行交互以获得距离尺寸的精确照明时，请调整场景视图，以使其垂直于聚光灯图标，从而使得更容易在正面看到距离效果。

以交互方式设定衰退区域

1. 确保启用“使用衰退区域”(Use Decay Regions)属性。

  若要启用衰退区域操纵器，请参见[显示、隐藏灯光操纵器或调整其大小](../定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。

2. 单击“索引操纵器”(Index Manipulator)，直到可以看到聚光灯的图标上的衰退区域为止。（若要了解有关“索引操纵器”(Index Manipulator)的详细信息，请参见[显示、隐藏灯光操纵器或调整其大小](../定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。）

  ![图：单击“索引操纵器”(Index Manipulator)，直到可以看到聚光灯的图标上的衰退区域为止。（若要了解有关“索引…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-A183B748-2DAC-4AFD-8237-FA75BCD7EB81.png) <!-- baize:img-hook downloaded=false reason="正文 641 字 ≥300，非承重" -->

3. 拖动衰退区域环形可设定开始距离和结束距离。如果需要，可以在“属性编辑器”(Attribute Editor)中验证和精细调整这些值。

  **注**

  提示：

  以交互方式设定灯光的衰退区域时：

  - 保持“属性编辑器”(Attribute Editor)打开，并使 IPR 渲染场景，以便能够以交互方式进行更改，从而获得所需的外观。

  - 应用“灯光雾”(Light Fog)（在聚光灯的“属性编辑器”(Attribute Editor)的“灯光效果”(Light Effects)区域中，单击“灯光雾”(Light Fog)旁边的框）以查看结果。
