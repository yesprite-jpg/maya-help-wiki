# 移动聚光灯的挡光板（快门）

移动“挡光板操纵器”(Barn Doors manipulators)使聚光灯的光束呈方形，或展平光束的一侧。还可以在“属性编辑器”(Attribute Editor)中更改聚光灯的“挡光板”(Barn Door)值。*仅聚光灯包括此选项*。

若要使用挡光板，请参见[将挡光板(快门)应用于光束](对光束应用“挡光板”%28barn%20doors%29（快门）.md)。

要显示该操纵器的详细信息，请参见[显示、隐藏灯光操纵器或调整其大小](../定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。
