# 定位灯光

通过使用灯光操纵器，可以按交互方式调整视图中某些光源的属性。灯光操纵器会显示在场景视图中（或者，在某些情况下，如果沿光源观看，会显示在光源的视图中）。可以使用灯光操纵器移动兴趣中心、原点或枢轴点。请参见[显示、隐藏灯光操纵器或调整其大小](定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。

若要更改照明的外观，请参见：

- [移动聚光灯的圆锥体半径](控制聚光灯/调整聚光灯的圆锥体角度.md)

- [移动聚光灯的半影半径](控制聚光灯/调整聚光灯的半影角度.md)

- [移动聚光灯的衰退区域](控制聚光灯/移动聚光灯的衰退区域.md)

- [移动聚光灯的挡光板（快门）](控制聚光灯/移动聚光灯的挡光板（快门）.md)

## 移动灯光的兴趣中心或原点

移动灯光操纵器的两个部分，以更改灯光的位置（原点）和方向（兴趣中心）。*所有灯光均会提供此选项*。

要显示该操纵器的详细信息，请参见[显示、隐藏灯光操纵器或调整其大小](定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。

## 移动灯光的枢轴点

移动并稍后单击“枢轴操纵器”(Pivot manipulator)，可以在移动灯光或兴趣中心时更改灯光的枢轴点。再次单击“枢轴操纵器”(Pivot manipulator)，可禁用枢轴点。*所有灯光均会提供此选项*。

要显示该操纵器的详细信息，请参见[显示、隐藏灯光操纵器或调整其大小](定位灯光/显示、隐藏灯光操纵器或调整其大小.md)。
