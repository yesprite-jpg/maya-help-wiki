# 灯光的吸收、反射和折射

若要创建**反光、反射或透明对象**，必须[创建材质并将其指定给对象](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-93AE85F5-F147-4B08-97B7-4D7423BB45AE.htm)，然后调整材质的属性。有关如何调整这些属性的详细信息，请参见[创建反射或折射灯光的材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-D7BC8A43-235C-4870-AB5E-055372C13D3D.htm)。

我们在自然界中看到的物体颜色是物体与光相互作用的结果。当光波照射到某个物体时，可能会被该物体吸收、反射或折射。所有物体都会产生一定程度的反射和吸收。

**注**

在自然界中，光也可能会透射过物体。即，光可以毫无影响地通过物体（如 X 射线）。但是，在 Maya 中不会表示这些类型的光，因为这些光不会产生任何视觉效果。
