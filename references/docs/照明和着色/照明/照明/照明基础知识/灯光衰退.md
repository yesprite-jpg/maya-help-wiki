# 灯光衰退

在现实世界中，灯光在光源处的亮度最强，而随着远离光源逐渐减弱或衰退。在 Maya 中，仅当启用衰退时灯光的亮度才会衰退。但无论离光源多远，灯光颜色始终保持不变。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-1CE86D42-5B0E-490E-9C18-1D5286B18B4E.png) <!-- baize:img-hook downloaded=false reason="正文 421 字 ≥300，非承重" -->

通过设置灯光的“衰退速率”(Decay Rate)属性，可以选择预设的亮度衰退速率。通常情况下，预设亮度衰退速率足以创建大多数类型的照明效果。但在某些情况下，可能希望创建独特的亮度衰退类型。

## 自定义强度和颜色衰退速率

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-F494189F-9FE5-4E50-8495-DF018B27D2B6.png) <!-- baize:img-hook downloaded=false reason="正文 421 字 ≥300，非承重" -->

还可以创建在现实世界中不可能的衰退效果。例如，可以使用自定义强度曲线，使聚光灯的亮度随着远离光源而逐渐增强，也可以使用自定义颜色曲线，使聚光灯的颜色随距离而改变。

**注**

此技巧仅适用于聚光灯。

强度曲线和颜色曲线是随距离变化的灯光亮度和颜色的图形表示。可以使用曲线图编辑器查看它们。垂直轴表示强度或颜色强度值，水平轴表示离光源的距离。（强度曲线和颜色曲线类似于动画曲线，但动画曲线的水平轴表示时间。）
