# 实际的灯光和阴影

实际上，当灯光照射在曲面上时，曲面面向光源的部分将被照亮，曲面背向光源的部分将变暗。如果某个对象位于第二个对象和光源之间，那么第一个对象会将阴影投射到第二个对象上。
