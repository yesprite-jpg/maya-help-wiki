# 曲面上的暗三角形楼梯（光线跟踪阴影）疑难解答

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-LightingShading/GUID-7A0EEFAF-62F1-4D93-A8A5-DC809ED942E2.png) <!-- baize:img-hook downloaded=true reason="正文 115 字 <300 且带图" -->

请执行下列操作之一：

- 为曲面增大“曲率容差”(Curvature Tolerance)。

- 为曲面增大“U 向分段因子”(U Divisions Factor)和“V 向分段因子”(V Divisions Factor)（至产生可接受结果的最小值）。
