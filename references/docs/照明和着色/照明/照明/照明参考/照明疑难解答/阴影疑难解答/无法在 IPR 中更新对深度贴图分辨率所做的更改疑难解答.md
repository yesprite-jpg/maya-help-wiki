# 无法在 IPR 中更新对深度贴图分辨率所做的更改疑难解答

如果在执行“IPR 渲染”(IPR render)后更改“深度贴图阴影属性中的深度贴图分辨率”(Dmap Resolution in Depth Map Shadow Attributes)或“深度贴图阴影属性中的使用自动聚焦”(Use Auto Focus in Depth Map Shadow Attributes)，就不会在“IPR 渲染”(IPR render)中更新这些更改。

有关 IPR 渲染的详细信息，请参见[关于交互式真实照片级渲染 (IPR)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9887F11F-E4DF-4F35-815A-9CB7417DD98D)。
