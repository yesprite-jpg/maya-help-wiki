# 粒状或闪烁阴影边（光线跟踪阴影）疑难解答

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-LightingShading/GUID-DED24A77-C643-4B7B-A7CC-29995C6CC816.png) <!-- baize:img-hook downloaded=true reason="正文 129 字 <300 且带图" -->

请执行下列操作之一：

- 减小阴影投射灯光的“灯光半径”(Light Radius)（点光源或聚光灯）或“灯光角度”(Light Angle)（平行光）。这样也会使阴影边更明晰。

- 增大阴影投射灯光的“阴影光线数”(Shadow Rays)（增大到产生可接受结果的最小值）。
