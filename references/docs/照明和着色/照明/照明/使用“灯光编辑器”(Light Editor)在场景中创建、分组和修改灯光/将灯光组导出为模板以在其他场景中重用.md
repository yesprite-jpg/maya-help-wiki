# 将灯光组导出为模板以在其他场景中重用

可以将灯光组导出为 .json 文件以在其他场景中重新创建和重用。导入此 .json 文件，灯光将保留模板中保存的组成员身份。

## 导出灯光组

您可以采用多种方式导出灯光组：

- 从“灯光编辑器”(Light Editor)中选择“文件 > 导出灯光组”(File > Export Light Groups)。

- 从“渲染设定”(Render Setup)编辑器中选择“文件 > 导出灯光编辑器灯光组”(File > Export Light Editor Light Groups)。

- 在“渲染设定”(Render Setup)编辑器的“场景 > 灯光”(Scene > Lights)部分中，单击 ![图：在“渲染设定”(Render Setup)编辑器的“场景 灯光”(Scene Lights)部分中，单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-15A05717-B953-472A-B6FC-39C64A718DC9.png) <!-- baize:img-hook downloaded=false reason="正文 1692 字 ≥300，非承重" -->。

- 选择“文件 > 导出全部”(File > Export All)以导出整个“渲染设定”(Render Setup)，包括场景中的灯光组。

导出灯光组时包括以下项：

- 灯光组本身

- 其成员身份信息（即，属于该组的灯光）

- 其“启用”(Enable)或“隔离”(Isolate)属性状态（即，组处于启用状态还是为隔离选定对象）

- 已应用于灯光组的自定义颜色

**注**

灯光本身不会与灯光组一起导出。

默认情况下，模板保存到用户预设位置；即 <Documents>\maya\Presets。有关详细信息，请参见[全局预设和用户预设](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-469A3F38-8E0B-4A28-8913-D8A7E3EF0733#GUID-469A3F38-8E0B-4A28-8913-D8A7E3EF0733__SECTION_1B399EB0AAA34C16AA60AD650DC96FC7)。

## 导入灯光组

您可以采用多种方式导入灯光组：

- 从“灯光编辑器”(Light Editor)中选择“文件 > 导入灯光组”(File > Import Light Groups)。

- 从“渲染设定”(Render Setup)编辑器中选择“文件 > 导入灯光编辑器灯光组”(File > Import Light Editor Light Groups)。

- 在“渲染设定”(Render Setup)编辑器的“场景 > 灯光”(Scene > Lights)部分中，单击 ![图：在“渲染设定”(Render Setup)编辑器的“场景 灯光”(Scene Lights)部分中，单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-15A05717-B953-472A-B6FC-39C64A718DC9.png) <!-- baize:img-hook downloaded=false reason="正文 1692 字 ≥300，非承重" -->。

您可以在向场景中添加灯光之前或之后导入灯光组模板。

导入模板时有两个选项可供选择：

- 覆盖(Overwrite)

  根据导入的模板，场景中的所有灯光都指定到相应组。场景中当前存在但模板中不存在的灯光组将被移除。其中包括嵌套的灯光组。例如，如果场景中包括嵌套组 ParentGroupA 和 ChildGroupA，但模板仅包括 ParentGroupA，则 ChildGroupA 将被移除。

- 合并(Merge)

  如果组名称相同，则将现有灯光组成员身份与导入的成员身份合并。模板中存在但当前场景中不存在的灯光组将被导入。当前场景中存在但模板中不存在的灯光组将保留不变。其中包括嵌套的灯光组。例如，如果场景中包括嵌套组 ParentGroupA 和 ChildGroupA，但模板仅包括 ParentGroupA，则在导入时，ParentGroupA 和 ChildGroupA 均保留在场景中。

导入的灯光组将会亮显并以斜体表示，以便您可以轻松地识别新导入的项目。单击“灯光编辑器”(Light Editor)中的 ![图：导入的灯光组将会亮显并以斜体表示，以便您可以轻松地识别新导入的项目。单击“灯光编辑器”(Light Editor)中的 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-EBD9664A-C400-4FAD-AE18-85DD92A3478A.png) <!-- baize:img-hook downloaded=false reason="正文 1692 字 ≥300，非承重" --> 可接受导入，以便“渲染设定”(Render Setup)编辑器中的所有项目现在均以常规文本显示。

### 解决当前场景与模板之间的差异

如果灯光当前所属组与在模板中所属组不同，则**在导入时由模板确定组成员身份**。

导入模板可能会更改灯光的可见性设置。例如，如果某个灯光当前属于某个已禁用的组，而在您导入的模板中该灯光属于某个已启用的组，则在导入该模板时将启用该灯光。“灯光编辑器”(Light Editor)中显示的 ![图：导入模板可能会更改灯光的可见性设置。例如，如果某个灯光当前属于某个已禁用的组，而在您导入的模板中该灯光属于某个已启用的组…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-26F4BBA7-E3E5-4772-9D3A-9CEE46601D39.png) <!-- baize:img-hook downloaded=false reason="正文 1692 字 ≥300，非承重" --> 标识受影响的灯光，此时“帮助行”(Help Line)和视口中将会显示一条消息，向您提醒您的场景中发生了更改。要关闭“灯光编辑器”(Light Editor)中的警告图标，请单击 ![图：导入模板可能会更改灯光的可见性设置。例如，如果某个灯光当前属于某个已禁用的组，而在您导入的模板中该灯光属于某个已启用的组…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-EBD9664A-C400-4FAD-AE18-85DD92A3478A.png) <!-- baize:img-hook downloaded=false reason="正文 1692 字 ≥300，非承重" -->。

如果在导入时，场景中缺少模板中引用的任何灯光，则在“灯光编辑器”(Light Editor) “特性编辑器”(Property Editor)的灯光成员身份列表中，它们将以灰色斜体删除线字体标识。要移除错误，可以执行下列任一操作：

- 在灯光成员身份列表上单击鼠标右键，然后选择“移除所有缺少的灯光”(Remove all missing lights)，从灯光组中移除所有缺少的灯光。

- 导入或重新创建缺少的灯光。根据导入的模板，这些灯光将自动指定到相应组。您可以从不同的资产导入灯光，在每次导入时，模板中的组成员身份都保持不变。
