# 模拟反射

若要模拟反射（会显著缩短渲染时间），必须使用纹理作为反射贴图。将贴图应用到对象材质的“反射的”(Reflected)颜色属性，以指定反射环境在对象上的效果。

有关贴图的详细信息，请参见[纹理映射](../关于着色和纹理曲面/纹理/纹理映射.md)。

**注**

反射率与反射的颜色

反射率决定了曲面反射其周围环境的程度；反射的颜色决定了要反射的对象（如果不使用光线跟踪）。

## 环境纹理

环境纹理使用一系列图像文件（“环境球”(Env Ball)、“环境立方体”(Env Cube)、“环境球体”(Env Sphere)）或计算机图形程序（[环境铬(Env Chrome)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-505CE282-1664-480D-A14C-64B51F8FA46A.htm)和[环境天空(Env Sky)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-992F0D3B-E3A1-4127-8700-681F97F49E7A.htm)）模拟 3D 空间。

可以使用它们来创建反射。

可以使用以下环境纹理来模拟反射：[环境球(Env Ball)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-51A56E3B-F777-4A59-B374-1D8728332AEB.htm)、[环境立方体(Env Cube)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-E8FA5222-C9C9-4700-B1D5-90C9E6CF55D9.htm)和[环境球体(Env Sphere)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-1FF8EE4D-DEAF-4E6C-895C-D2E6EB670BAA.htm)。模拟反射：

- 请参见[使用“环境球”(Env Ball)模拟反射](使用“环境球”%28Env%20Ball%29模拟反射.md)。

- 请参见[使用“环境立方体”(Env Cube)模拟反射](使用“环境立方体”%28Env%20Cube%29模拟反射.md)。

- 请参见[使用“环境球体”(Env Sphere)模拟反射](使用“环境球体”%28Env%20Sphere%29模拟反射.md)。

当用于映射图像平面时，环境纹理不使用反射方向；而是使用摄影机视图方向。因此以“环境天空”(Env Sky)纹理为例，如果要在背景中看到太阳，它在视图中就必须出现在摄影机前面。使用“环境天空”(Env Sky)操纵器并旋转或缩放它，直到表示太阳的线指向背景（也可以更改太阳仰角和方位角实现同样的结果）。（有关图像平面的详细信息，请参见[创建、编辑或定位图像平面](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F72F8E1B-EFFE-400E-BD92-5441BE9CD28F.htm)。）

**注**

不要将环境纹理映射到材质的“凹凸”(Bump)或“置换”(Displacement)参数。由于环境映射的基本特性，使得它在用于置换映射时无法实现精确计算。映射到“凹凸”(Bump)的环境纹理会产生不可预料的结果；Maya 会忽略映射到“置换”(Displacement)的环境纹理。有关置换映射的详细信息，请参见[关于表面起伏](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F403A3FF-55BE-43A0-B6E1-49BA7C6BF5EE.htm)。
