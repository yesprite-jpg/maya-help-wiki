# 创建真实反射

有关真实反射的详细信息，请参见[真实反射](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-858263F7-CF7F-4400-90EB-760BB9790A0E.htm)。

**注**

若要创建真实（真实照片级）反射，必须对场景进行光线跟踪，光线跟踪是一个可能会花费大量时间的过程。有关光线跟踪的详细信息，请参见[深度贴图和光线跟踪阴影](../../../照明/照明/Maya%20中的阴影/深度贴图和光线跟踪阴影.md)。

必须至少具有两个曲面才能创建真实反射（或者以某种方式弯曲的曲面，以便其曲面的一部分可以反射到其曲面的另一部分上）。

通过在每个曲面的“属性编辑器”(Attribute Editor)中启用或禁用“在反射中可见”(Visible in Reflections)，可以控制哪些曲面显示在反射中以及哪些曲面不显示在反射中（创建新曲面时，黙认情况下会启用“在反射中可见”(Visible in Reflections)）。

创建真实反射（示例）

1. 创建一个球体和一个平面，然后将球体放置到平面上。创建灯光来照亮两个曲面。

2. 创建镜面反射材质（“Phong”或“PhongE”），然后将其指定给球体。在平面中会反射球体。

3. 创建第二种材质，然后将其指定给平面。平面将反射球体。

4. 为每个曲面使用不同的颜色，以便可以看到一个曲面在另一个曲面中的反射。

5. 在“渲染设置”(Render Settings)窗口的“光线跟踪质量”(Raytracing Quality)区域中，启用“光线跟踪”。

  这会通知 Maya 对已启用“在反射中可见”/“在折射中可见”(Visible in Reflections/Refractions)的所有曲面进行光线跟踪。默认情况下会为所有曲面启用这些属性，但仅当在“渲染设置”(Render Settings)窗口中启用“光线跟踪”(Raytracing)时，光线跟踪才起作用。

  若要了解有关“渲染设置”(Render Settings)的详细信息，请参见[“渲染设置”(Render Settings)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-59DFB8B7-776B-4243-B404-A3D602FF8CFD)。

6. 执行测试渲染以可视化结果。如果希望球体反射平面，请打开平面的“属性编辑器”(Attribute Editor)，然后启用“渲染统计信息 > 在反射中可见”(Render Stats > Visible in Reflections)。

  若要测试场景的迭代，请参见[与 IPR 可视化交互](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-76A6C578-C4B9-42C8-9EC4-ECCE89A1E3BE)。
