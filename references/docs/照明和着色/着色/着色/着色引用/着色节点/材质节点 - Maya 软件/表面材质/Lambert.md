# Lambert

是一种材质（着色器），其表示没有镜面反射高光的蒙版曲面（如粉笔、蒙版涂料、粗糙曲面）。

初始（默认）着色组使用特殊的“Lambert”表面材质。请勿对其进行修改；作为替代，请创建并应用新的“Lambert”材质。

在[“创建”(Create)选项卡](../../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中找到此材质。

可以设定“Lambert”材质的属性，以控制其外观。请参见[公用表面材质属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-AEA3C15F-1C08-44CF-9CBF-C9E90CC0F09E.htm)。
