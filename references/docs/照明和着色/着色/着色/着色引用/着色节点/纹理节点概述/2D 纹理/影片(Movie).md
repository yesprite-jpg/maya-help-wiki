# 影片(Movie)

影片纹理假定：

- 整个多帧序列存储在单个多帧文件（一个影片文件）中，而不是存储在各个图像文件的序列中。

- 已进行优化，可尽可能快地以交互方式读取和显示这些帧。

“影片”(Movie)纹理与[文件](文件%28File%29纹理节点.md)纹理共享相同的属性。区别在于“影片”(Movie)纹理假定所有帧都使用指定的“图像名称”(Image Name)存储在单个串联文件中，而不是存储在单独的文件中。

在[“创建”(Create)选项卡](../../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中找到此纹理。若要作为纹理贴图应用该纹理，请参见[映射 2D 或 3D 纹理](../../../../关于着色和纹理曲面/纹理/纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。
