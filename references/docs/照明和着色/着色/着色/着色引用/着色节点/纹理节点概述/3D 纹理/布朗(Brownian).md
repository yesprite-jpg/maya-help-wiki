# 布朗(Brownian)

类似于绘制厚重的金属。

在[“创建”(Create)选项卡](../../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中找到此纹理。要应用该纹理作为纹理贴图，请参见[映射 2D 或 3D 纹理](../../../../关于着色和纹理曲面/纹理/纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

#### 间隙度(Lacunarity)

定义您添加以形成纹理的频率（“倍频程”(Octaves)）之间的间隙。默认情况下，基于噪波的纹理的“间隙度”(Lacunarity)设置为 2.0，但您可以调整该值以创建有趣的效果。

#### 增量(Increment)

确定分形噪波的比率。在接近 0 时，纹理会更清晰，在接近 1 时，纹理会更平滑。

#### 倍频程(Octaves)

设置噪波频率的上限（分形的重复值）。请参见[深度](云%28Cloud%29.md#WS73099CC142F48755-3D114B7511812357EFE-627F)。

#### 权重 3D (Weight3d)

确定在通过控制该过程中使用的任何分形的频率比例来进行投影时图像所呈现的波动情况。
