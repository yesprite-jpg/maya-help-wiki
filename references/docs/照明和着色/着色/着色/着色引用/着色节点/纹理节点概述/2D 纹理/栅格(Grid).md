# 栅格(Grid)

代表标量栅格图案。

在[“创建”(Create)选项卡](../../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中找到此纹理。若要将该纹理应用为纹理贴图，请参见[映射 2D 或 3D 纹理](../../../../关于着色和纹理曲面/纹理/纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

#### 线颜色(Line Color)

栅格线的颜色。默认颜色为白色。

#### 填充颜色(Filler Color)

栅格线之间的区域的颜色。默认颜色为黑色。

#### U 向宽度(U Width)、V 向宽度(V Width)

U 方向和 V 方向栅格线的宽度。有效取值范围为 0 到 1。范围是 0 到 0.5。默认值为 0.1。

#### 对比度(Contrast)

“线颜色”(Line Color)和“填充颜色”(Filler Color)之间的对比度。范围为 0（两种颜色在整个纹理上平均分布）到 1。默认值为 1。
