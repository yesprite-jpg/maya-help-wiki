# 渲染节点

可以从 Hypershade [“创建”(Create)选项卡](../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中创建这些渲染节点。

#### 渲染层(Render Layer)

创建该节点可将对象分成单独的层。该节点是传统渲染层系统的一部分。

有关如何在渲染设置系统中创建渲染层的信息，请参见 [Maya 渲染设置](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-646154F9-E4D2-4A3E-A0D9-B2F062960A4E)。

#### 渲染过程(Render Pass)

使用该节点创建渲染过程（如“漫反射”(Diffuse)、“镜面反射”(Specular)和“环境光”(Ambient)）。

#### 渲染目标(Render Target)

若要在“渲染视图”(Render View)或者批渲染中可视化一个节点（如着色节点或渲染过程），请将它连接到“渲染目标”(Render Target)节点。
