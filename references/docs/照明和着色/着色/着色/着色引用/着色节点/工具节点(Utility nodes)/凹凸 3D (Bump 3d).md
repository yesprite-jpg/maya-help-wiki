# 凹凸 3D (Bump 3d)

将 3D 纹理转化为凹凸贴图。也可以将凹凸贴图彼此层叠在一起。

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用凹凸 3D 工具](../../../渲染节点工具/使用“凹凸%203D”%28Bump%203d%29工具.md)。

#### 凹凸值(Bump Value)

用于凹凸贴图的源 3D 纹理。可以将任何着色网络的输出连接到“凹凸值”(Bump Value)以用作凹凸的源。

#### 凹凸深度(Bump Depth)

控制凹凸在曲面上显示得有多高。增大“凹凸深度”(Bump Depth)可使曲面更加凹凸不平。减小“凹凸深度”(Bump Depth)可使曲面更加平滑。
