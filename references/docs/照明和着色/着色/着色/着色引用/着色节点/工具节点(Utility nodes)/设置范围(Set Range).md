# 设置范围(Set Range)

设置当不希望在整个场景中进行操作时某一效果的发生范围。“设置范围”(Set Range)工具可与其他节点结合使用。

在“创建栏”(Create Bar)中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用设置范围工具](../../../渲染节点工具/使用“设置范围”%28Set%20Range%29工具.md)。

#### 值(Value)

Maya 将该值从旧范围（“旧最小值”(Old Min)到“旧最大值”(Old Max)）映射到新范围（“最小值”(Min)到“最大值”(Max)）。

#### 最小值/最大值(Min/Max)

新范围内的最小值和最大值。

#### 旧最小值(Old Min)、旧最大值(Old Max)

旧范围内的最小值和最大值。
