# 透明涂层(Clear Coat)

该工具是一个插件 (clearcoat.mll)。当某些材质（如汽车油漆）根据查看方向和曲面方向之间的关系以不同的方式反射光线时，您可以使用该节点。

在“Hypershade” [“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)中找到此工具。

clearCoat 节点具有与 studioClearCoat 节点相同的属性。详细信息请参见 [Studio 透明涂层](Studio%20透明涂层%28Studio%20Clear%20Coat%29.md)。
