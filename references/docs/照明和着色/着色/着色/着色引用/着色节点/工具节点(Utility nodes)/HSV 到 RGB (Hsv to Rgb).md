# HSV 到 RGB (Hsv to Rgb)

将 HSV（“色调”(Hue) -“饱和度”(Saturation) -“明度”(Value)）颜色转化为 RGB（“红”(Red)色-“绿”(Green)色-“蓝”(Blue)色）颜色。

对于某些效果，使用 HSV 值比使用 RGB 值更便于计算。可以将任何着色网络的输出转化为 HSV 值。

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用 HSV 到 RGB 工具](../../../渲染节点工具/使用“HSV%20到%20RGB”%28Hsv%20to%20Rgb%29工具.md)。

#### 输入 HSV (In Hsv)

转化为 HSV 值的颜色。

#### 输出 RGB (Out Rgb)

输出 RGB 值。
