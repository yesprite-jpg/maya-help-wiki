# 对比度(Contrast)

用于增大或减小纹理中的对比度。可以单独控制每个 R、G 和 B 通道的对比度。

如果增大“对比度”(Contrast)，明亮的颜色会变得更亮，而暗颜色会变得更暗。如果减小对比度，可以使所有颜色更接近中间范围。[偏移](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-134B17A2-B33D-497C-AA5E-3BEF6A69A273.htm#WS73099CC142F48755-3D114B7511812357EFE-5920)属性控制该范围的中心。

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用对比度工具](../../../渲染节点工具/使用“对比度”%28Contrast%29工具.md)。

#### 明度值(Value)

要调整的输入颜色或纹理。

#### 对比度(Contrast)

控制对比度的调整量。可以单独调整 R、G 和 B 分量的对比度。增大“对比度”(Contrast)会使明亮的颜色更亮，而使暗颜色更暗。减小“对比度”(Contrast)会使所有内容变灰。

#### 偏移(Bias)

控制对比度调整的中间点。增大“偏移”(Bias)会向上移动中间点（随着对比度增大，纹理的更多部分会变暗）。减小“偏移”(Bias)会向下移动中间点（随着对比度增大，纹理的更多部分会变亮）。
