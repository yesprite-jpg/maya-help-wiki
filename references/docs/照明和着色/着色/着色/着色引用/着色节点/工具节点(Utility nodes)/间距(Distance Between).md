# 间距(Distance Between)

“间距”(Distance Between)工具使用场景中两个定位器点之间的距离来控制着色材质或其连接到的纹理的一个属性。例如，可以使用“间距”(Distance Between)工具来控制噪波纹理的频率，如下所示：

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-74ED8E2D-8150-4950-BDB2-C84E50364587.png) <!-- baize:img-hook downloaded=false reason="正文 327 字 ≥300，非承重" -->

若要在 Hypershade 中查看定位器节点，请右键单击工作区，然后从标记菜单中选择“显示 > 对象 > 清除以下项”(Show > Objects > Clear Below)以清除显示过滤器。

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用间距工具](../../../渲染节点工具/使用“间距”%28Distance%20Between%29工具.md)。

#### 点 1 (Point 1)

要用作间距工具的第一个点的定位器的 X、Y、Z 轴坐标。

#### 点 2 (Point 2)

要用作间距工具的第二个点的定位器的 X、Y、Z 轴坐标。
