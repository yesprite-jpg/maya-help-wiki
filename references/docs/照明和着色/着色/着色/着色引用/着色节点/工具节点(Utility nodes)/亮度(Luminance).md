# 亮度(Luminance)

将颜色转化为灰度。亮度源于颜色值。Maya 通过使用以下公式将以下数量的红、绿和蓝相加，来计算亮度。

Luminance = 0.3 red + 0.59 green + 0.11 blue

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用亮度工具](../../../渲染节点工具/使用“亮度”%28Luminance%29工具.md)。

#### 明度值(Value)

输入颜色或纹理。
