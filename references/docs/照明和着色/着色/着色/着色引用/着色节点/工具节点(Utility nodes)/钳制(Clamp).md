# 钳制(Clamp)

隔离相对复杂的纹理中的颜色。创建复杂的着色器网络时这将非常有用。

在“创建”(Create)选项卡中找到该工具（请参见[“创建”(Create)选项卡](../../着色窗口和编辑器/Hypershade%20窗口/“创建”%28Create%29选项卡.md)）。

若要使用该工具，请参见[使用钳制颜色工具](../../../渲染节点工具/使用“钳制”%28Clamp%29颜色工具.md)。

#### 最小值(Min)

颜色通道的最小值。

#### 最大值(Max)

颜色通道的最大值。

#### 输入(Input)

Maya 钳制的输入颜色或纹理。
