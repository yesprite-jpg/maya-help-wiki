# “创建”(Create)选项卡

首次打开 Hypershade 时，“创建”(Create)面板将显示在左下方。从该面板中，您可在用于创建不同类型渲染效果的节点中进行选择。

单击“创建”(Create)选项卡中的节点以将它添加到场景。详细信息请参见[在 Hypershade 中创建和连接节点](../../../关于着色和纹理曲面/使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点.md)。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-AF6F0267-3766-4415-A9B8-376B5784D7C1.png) <!-- baize:img-hook downloaded=false reason="正文 932 字 ≥300，非承重" -->

选择一个或多个区域。仅选定区域中的节点显示在右侧面板上。若要清除选择，请在搜索区域按 Enter 键。

使用滚动条导航“创建”(Create)选项卡并单击以创建您需要的节点。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-3D3B78C0-AC97-4E79-81BB-4F2D252E8355.png) <!-- baize:img-hook downloaded=false reason="正文 932 字 ≥300，非承重" -->

## 搜索渲染节点

输入要创建的渲染节点关键字。当输入关键字时，“创建”(Create)选项卡的右侧面板会实时更新，并且仅显示名称与输入内容匹配的渲染节点。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-E85BADAD-A8F7-406B-9F34-4540624E4B0C.png) <!-- baize:img-hook downloaded=false reason="正文 932 字 ≥300，非承重" -->

## 收藏夹

可以创建“收藏夹”(Favorites)列表，以便轻松访问最常用的节点。

若要将着色器添加到“收藏夹”(Favorites)列表，请使用鼠标中键将着色器拖动到“收藏夹”(Favorites)。或者，可以在着色器上单击鼠标右键，然后选择“添加到收藏夹”(Add to favorites)。“Hypershade”将收藏按类别进行排序，以便轻松地找到着色器。

有关收藏夹的详细信息，请参见[创建和使用收藏夹](../../../关于着色和纹理曲面/使用%20Hypershade%20的外观开发/使用%20Hypershade%20构建和创建材质/创建和使用收藏夹.md)。

## 映射方法(Mapping method)

将 2D 或 3D 纹理映射到对象时，就将纹理连接到了该对象的材质的一个属性。如果正在选择 2D 纹理，请在纹理上单击鼠标右键，选择想要使用的[映射方法](../../../关于着色和纹理曲面/纹理/纹理映射/映射方法.md)。默认设置是法线贴图，但也可以选择“创建为投影”(Create as projection)或“创建为蒙板”(Create as stencil)。
