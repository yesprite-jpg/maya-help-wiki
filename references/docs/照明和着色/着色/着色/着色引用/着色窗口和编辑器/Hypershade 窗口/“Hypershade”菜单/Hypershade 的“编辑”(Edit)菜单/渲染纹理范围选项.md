# 渲染纹理范围选项

在“Hypershade”菜单中选择“编辑 > 渲染纹理范围”(Edit > Render Texture Range) > ![图：在“Hypershade”菜单中选择“编辑 渲染纹理范围”(Edit Render Texture Range) ，以设…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 440 字 ≥300，非承重" -->，以设定以下选项。

#### 图像名称(Image name)

结果渲染图像的名称。会将图像写入活动项目的图像目录中。将填充文件名（例如，checker.0001.iff）。

#### 文件格式(File Format)

渲染纹理图像的文件格式。

#### X/Y 分辨率(x/y Resolution)

渲染纹理图像的 X 分辨率和 Y 分辨率。

#### 开始帧(Start Frame)

用于序列的第一个帧编号。

#### 结束帧(End Frame)

用于序列的最后一个帧编号。

#### 帧数(By Frame)

在“开始”(Start)和“结束帧”(End frames)之间前进的帧数（请参见[“渲染设置”(Render Settings)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-59DFB8B7-776B-4243-B404-A3D602FF8CFD)）。

#### 填充(Padding)

以数字表示的填充位数的数量（例如，001 为 3，0001 为 4，依此类推）。

#### 在图像查看器中自动加载范围(Auto load range in image viewer)

启动新创建的序列，并将其加载到图像查看器中。
