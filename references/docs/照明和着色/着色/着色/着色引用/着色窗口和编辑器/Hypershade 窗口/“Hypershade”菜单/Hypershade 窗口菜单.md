# Hypershade 窗口菜单

#### 浏览器(Browser)

显示浏览器窗口，其中包含构成当前场景的渲染组件，例如材质、纹理、灯光和摄影机。请参见 [Hypershade 浏览器](../Hypershade%20浏览器.md)。

#### 特性编辑器(Property Editor)

#### 材质查看器(Material Viewer)

显示材质查看器，以便您可以实时可视化网络。材质查看器基于在工作区中所绘制内容的上下文，显示任何着色网络（包括材质、纹理和工具）。请参见在 Hypershade 材质查看器中实时渲染网络。

#### 创建(Create)

显示“创建”(Create)选项卡，您可以从其创建不同的节点以构建着色网络。请参见[“创建”(Create)选项卡](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-76B10C8D-EC19-4AFE-8433-743326C49DBE.htm)。

#### 存储箱(Bins)

显示排序存储箱以帮助您组织和跟踪场景中的着色节点。请参见[排序存储箱](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-2F388D20-1C54-4488-B817-2E0E5463132D.htm)。

#### 视口(Viewport)

将视口显示为单独的窗口，可以将其停靠到 Hypershade 中。

#### 渲染视图(Render View)

将“渲染视图”(Render View)显示为单独的窗口，可以将其停靠到 Hypershade 中。

#### 大纲视图(Outliner)

将大纲视图显示为单独的窗口，可以将其停靠到 Hypershade 中。

#### UV 编辑器(UV Editor)

将 UV 编辑器显示为单独的窗口，可以将其停靠到 Hypershade 中。

#### 曲线图编辑器(Graph Editor)

将曲线图编辑器显示为单独的窗口，可以将其停靠到 Hypershade 中。

#### 属性总表(Attribute Spread Sheet)

显示属性总表，并使用选定节点对其进行加载，以便可以同时编辑所有节点的属性。可以将此面板停靠到 Hypershade 中。

有关“属性总表”(Attribute Spread Sheet)的详细信息，请参见[属性总表(Attribute Spread Sheet)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F821EE09-D5D6-4DD0-9452-4695DFF50FEB)。

#### 连接编辑器(Connection Editor)

此选择会显示“连接编辑器”(Connection Editor)（不会在任一列中预先加载节点）。

有关连接编辑器的详细信息，请参见[连接编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2622D368-1DD5-45BA-9560-93626A5751FD)。

#### 连接选定项(Connect Selected)

显示“连接编辑器”(Connection Editor)，在“输出”(Outputs)列中加载了选定节点。

有关“连接编辑器”(Connection Editor)的详细信息，请参见[使用“连接编辑器”(Connection Editor)连接节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-92F35EC2-35BF-49AB-8CDE-9DE922EA85A1)。
