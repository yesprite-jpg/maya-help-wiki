# Hypershade 图形菜单

#### 为选定对象上的材质制图(Graph Materials on Selected Objects)

显示选定对象的着色组网络。

有关着色网络的详细信息，请参见[关于着色网络](../../../../关于着色和纹理曲面/将颜色和着色应用于对象/关于着色网络.md)。

#### 清除图表(Clear Graph)

清除所有节点和着色网络的工作区。

#### 输入和输出连接(Input and Output Connections)

显示选定节点的输入和输出连接。另请参见[输入和输出连接](../../../../关于着色和纹理曲面/使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点/显示节点连接.md#GUID-721BE1F1-1634-4107-9179-3439D5E4CE5E__GUID-DBE18937-6B98-421A-83A4-1739BB43435A)。

#### 输入连接(Input Connections)

仅显示选定节点的输入连接。请参见[输入连接](../../../../关于着色和纹理曲面/使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点/显示节点连接.md#GUID-721BE1F1-1634-4107-9179-3439D5E4CE5E__GUID-1231BA7C-5925-41C5-8936-5E949180AD7A)。

#### 输出连接(Output Connections)

仅显示选定节点的输出连接。请参见[输出连接](../../../../关于着色和纹理曲面/使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点/显示节点连接.md#GUID-721BE1F1-1634-4107-9179-3439D5E4CE5E__GUID-4E96F59C-5F77-4842-ABE2-636A4230CB4E)。

#### 将选定项添加到图表(Add Selected to Graph)

将选定节点添加到图表。该选项适用于将非渲染节点（如形状节点和变换节点）添加到“Hypershade”中，以供着色网络使用。

#### 从图表中移除选定项(Remove Selected from Graph)

从图表中移除选定节点。这有助于减少杂乱情况。

#### 重新排列图表(Rearrange Graph)

在当前布局中重新排列节点以查看所有不重叠的节点和着色网络。

#### 连接时的十字光标(Crosshair Cursor While Connecting)

启用此选项后，拖动连接线时将显示十字光标。
