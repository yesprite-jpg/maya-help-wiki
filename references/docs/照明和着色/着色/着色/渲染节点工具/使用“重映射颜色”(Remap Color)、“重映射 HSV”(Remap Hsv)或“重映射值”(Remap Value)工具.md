# 使用“重映射颜色”(Remap Color)、“重映射 HSV”(Remap Hsv)或“重映射值”(Remap Value)工具

仅用于软件渲染。

可以更精确地定义输入值（值、点、颜色）重映射到新输出值的方式。以下三个颜色工具节点具有“渐变”(Ramp)属性，这些属性与“重映射”纹理相比，可对重映射执行更多的控制。

使用这些工具节点可执行以下操作（例如）：

- 分别重映射和控制颜色值和 Alpha 值

- 执行简单的颜色修正

- 影响对象的转换

- 精细调整或完全更改颜色的色调、饱和度和亮度

  **注**

  提示：

  这三个工具适用于测试范围功能。请参见[测试纹理（和纹理范围）](../关于着色和纹理曲面/纹理/测试纹理（和纹理范围）.md)。

使用“重映射颜色”(Remap Color)、“重映射 HSV”(Remap Hsv)或“重映射值”(Remap Value)颜色工具

1. 在“Hypershade”中，选择“Maya > 工具”(Maya > Utilities)。

2. 选择要使用的工具：

  - 有关该工具的说明以及战略使用，请参见[重映射值](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-0E241693-3300-4570-A4DD-78B8BE371FDB.htm)。

  - 有关该工具的说明以及战略使用，请参见[重映射颜色](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F754F1A4-394D-4C9A-B8DC-AC740296444C.htm)。

  - 有关该工具的说明以及战略使用，请参见[重映射 HSV](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-D614C359-EA9C-42F9-9CB3-8BF923A9E08A.htm)。

3. 在工具的“属性编辑器”(Attribute Editor)中，调整渐变图形，并设定[输入和输出范围](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-0E241693-3300-4570-A4DD-78B8BE371FDB.htm#WS17956D7ADBC6E73638876AF8117AE33FA94-7EB2)。

  有关这些范围属性的描述，请参见[输入和输出范围](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-0E241693-3300-4570-A4DD-78B8BE371FDB.htm#WS17956D7ADBC6E73638876AF8117AE33FA94-7EB2)。
