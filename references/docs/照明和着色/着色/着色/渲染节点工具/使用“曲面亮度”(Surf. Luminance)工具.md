# 使用“曲面亮度”(Surf. Luminance)工具

有关“曲面亮度”(Surf. Luminance)工具的描述，请参见[曲面亮度](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-C9719C7F-5C02-4D3A-A75A-A3E112DBC604.htm)。

使用“曲面亮度”(Surf. Luminance)工具

1. 在“Hypershade”中，选择“创建 > 工具 > 曲面”(Create > Utilities > Surf)。“亮度”(Luminance)。

  工具节点显示在“Hypershade 工作区”(Hypershade Work Area)中，其属性显示在“属性编辑器”(Attribute Editor)中。

2. 在该工具的“属性编辑器”(Attribute Editor)中，根据需要调整属性。

  有关这些属性的描述，请参见[曲面亮度](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-C9719C7F-5C02-4D3A-A75A-A3E112DBC604.htm)。
