# 使用“四元值切换”(Quad Switch)工具

有关“四元值切换”(Quad Switch)工具的描述，请参见[四元值切换](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-75768B55-D9B5-4474-A70D-D0C5A0B2A1E9.htm)。

用于将不同的纹理映射到场景中的若干个对象。您可以切换任何四元值浮动属性，例如 RGB 输出颜色。

若要使用“四元值切换”(Quad Switch)工具，请参见[三元值切换](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-734708F6-0A57-4CF1-ACAB-664AD4A6FB62.htm)。
