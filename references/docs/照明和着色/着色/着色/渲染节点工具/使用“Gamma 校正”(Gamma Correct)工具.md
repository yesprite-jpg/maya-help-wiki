# 使用“Gamma 校正”(Gamma Correct)工具

有关“Gamma 校正”(Gamma Correct)工具的说明，请参见 [Gamma 校正](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-BA5E19E9-3D21-47BE-95D5-903C59936678.htm)。

使用“Gamma 校正”(Gamma Correct)工具重映射颜色

1. 将纹理映射到材质的“颜色”(Color)并将该材质指定给对象。

  在该示例中，将“文件”(File)纹理映射到“Lambert”材质。

2. 创建“Gamma 校正”(Gamma Correct)工具节点，并将它连接到要调整的材质节点上的输入属性；例如，“环境色”(Ambient Color)

3. 如有必要，请按如下方式更改“Gamma 校正”(Gamma Correct)属性设置。

  ![图：如有必要，请按如下方式更改“Gamma 校正”(Gamma Correct)属性设置。 纹理由 www.cgtextur…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-9E9BA257-DA97-4CDE-91A5-21291BF6E957.png) <!-- baize:img-hook downloaded=false reason="正文 350 字 ≥300，非承重" -->
