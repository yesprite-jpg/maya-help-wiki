# 使用“涂抹”(Smear)工具

有关“涂抹”(Smear)工具的说明，请参见[涂抹](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-C3A5BDD9-F10C-477D-9928-551FB09F155F.htm)。

使用“涂抹”(Smear)工具

1. 在“Hypershade”中，选择“创建 > 工具 > 涂抹”(Create > Utilities > Smear)。

  工具节点显示在“Hypershade 工作区”(Hypershade Work Area)中，其属性显示在“属性编辑器”(Attribute Editor)中。

2. 在该工具的“属性编辑器”(Attribute Editor)中，根据需要调整其属性。

  有关这些属性的说明，请参见[涂抹](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-C3A5BDD9-F10C-477D-9928-551FB09F155F.htm)。
