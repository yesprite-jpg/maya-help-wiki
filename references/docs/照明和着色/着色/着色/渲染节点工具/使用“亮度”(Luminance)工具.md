# 使用“亮度”(Luminance)工具

有关“亮度”(Luminance)工具的描述，请参见[亮度](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-09957E1B-6714-43A4-9BEB-0671DF1C428F.htm)。

使用“亮度”(Luminance)工具

1. 在“Hypershade”中，选择“创建 > 工具 > 亮度”(Create > Utilities > Luminance)。

  工具节点在“Hypershade”“工作区”(Work Area)中显示，其属性在“属性编辑器”(Attribute Editor)中显示。

2. 在该工具的“属性编辑器”(Attribute Editor)中，根据需要调整属性。

  有关这些属性的描述，请参见[亮度](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-09957E1B-6714-43A4-9BEB-0671DF1C428F.htm)。
