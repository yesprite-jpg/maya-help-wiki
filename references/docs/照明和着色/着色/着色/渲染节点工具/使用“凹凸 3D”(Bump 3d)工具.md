# 使用“凹凸 3D”(Bump 3d)工具

有关“凹凸 3D”(Bump 3D)工具的描述，请参见[凹凸 3D](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-DA37A96C-5764-469C-B3D8-159332F2C07F.htm)。

删除“bump3d”贴图

1. 打开材质的“属性编辑器”(Attribute Editor)。

2. 在“凹凸贴图”(Bump Mapping)一词上单击鼠标右键。

3. 从弹出菜单中选择“断开连接”(Break Connection)。
