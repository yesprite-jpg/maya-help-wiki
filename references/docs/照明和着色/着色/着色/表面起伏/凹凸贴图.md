# 凹凸贴图

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-1AD94AB5-26D0-416F-AE04-C2D7A4EF68F0.png) <!-- baize:img-hook downloaded=false reason="正文 570 字 ≥300，非承重" -->

凹凸贴图是灰度纹理，可将它们映射到对象以在其他平坦对象上创建出表面起伏（高地和洼地）的错觉。

借助凹凸贴图，洼地和高地看起来是真实的，因为它们不会像[置换贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-E7A03E4E-8C9A-4B62-8218-28FC063A82AB.htm)那样改变曲面的几何体。凹凸贴图只是基于凹凸贴图的“Alpha 增益”(Alpha Gain) 值更改曲面的法线的方向。

使用凹凸贴图创建非常浅的起伏。例如，可以使对象看起来像是凸雕的，具有很浅的山丘，等等。

因为凹凸贴图不是真正的表面起伏，所以它们：

- 不能投射或接收阴影

- 如果使映射的对象呈现暗色轮廓，则无法看到

- 渲染花费的时间比置换贴图的少

  **注**

  用于凹凸贴图的文件纹理通常是通过其

  “outAlpha”

  属性连接的。如果相应的纹理图像文件未提供 Alpha 通道，那么在使用某些图像格式时，凹凸效果可能会丢失。

  若要避免出现这种情况，请在“文件纹理”(File Texture)节点的“颜色平衡”(Color Balance)区域中启用“Alpha 为亮度”(Alpha is Luminance)属性。有关详细信息，请参见[文件](../着色引用/着色节点/纹理节点概述/2D%20纹理/文件%28File%29纹理节点.md)。

**注**

提示：

- 将表面起伏（凹凸或置换）映射到“Blinn”表面材质可减少高光呈挂绳状或闪烁。与“Phong”表面上的更强的高光相比，“Blinn”表面上的柔和高光不太可能导致呈挂绳状或闪烁。

- 尽管划痕就像小洼地一样，但是使用 2D 纹理可以更加轻松地实现它们。
