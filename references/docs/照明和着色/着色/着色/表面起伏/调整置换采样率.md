# 调整置换采样率

确定如何设定初始采样率和额外采样率

1. 确保已选定置换贴图对象，并且显示对象的“属性编辑器”(Attribute Editor)。

2. 显示对象的细分三角形。

3. [预览置换结果](在视口中预览置换结果.md)。

4. 对于每个细分三角形，请查看三角形中的纹理高度偏差值，然后在对象的“属性编辑器”(Attribute Editor)的“置换贴图”(Displacement Map)区域，调整[初始采样率](../着色引用/着色节点/基于特征的置换贴图属性.md#WS73099CC142F48755-3D114B7511812357EFE-5D01)。

5. 对于每个细分三角形，请注意特征的明晰度以及具有的弯曲特征数。特征越明晰，所需的[额外采样率](../着色引用/着色节点/基于特征的置换贴图属性.md#WS73099CC142F48755-3D114B7511812357EFE-5CF9)越高；需要进行相应的调整。
