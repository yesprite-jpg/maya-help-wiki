# 置换贴图

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-D76E0FB6-BDFA-4BFD-A9CD-9AA67A2C9C16.png) <!-- baize:img-hook downloaded=false reason="正文 892 字 ≥300，非承重" -->

“置换”(Displacement)贴图是灰度纹理，可将它们映射到对象以在其他平面对象上创建出真实的表面起伏（仰角和凹地）。

使用“置换”(Displacement)贴图，凹地和仰角会变成对象的几何体的一部分，从而会更改拓扑，这与“凹凸”(Bump)贴图不同，凹凸贴图仅创建表面的错觉。

**注**

- 因为置换会更改对象的几何体，所以置换贴图对象通常需要进一步细分（多个三角形，渲染器使用它们来近似曲面的平滑度）。默认情况下，Maya 使用[基于特征的置换](基于特征的置换.md)贴图在所需的位置自动添加更多的三角形。

- 用于置换贴图的文件纹理通常是通过其“outAlpha”属性连接的。如果相应的纹理图像文件未提供 Alpha 通道，那么在使用某些图像格式时，置换效果可能会丢失。要避免出现这种情况，请在“文件纹理”(File Texture)节点的“颜色平衡”(Color Balance)区域中启用“Alpha 为亮度”(Alpha is Luminance)属性。有关详细信息，请参见[文件](../着色引用/着色节点/纹理节点概述/2D%20纹理/文件%28File%29纹理节点.md)。

置换贴图会移动对象的顶点。默认情况下，置换的高度是由置换贴图的“属性编辑器”(Attribute Editor)中的“Alpha 增益”(Alpha Gain)值决定的。如果启用“Alpha 为亮度”(Alpha is Luminance)，那么高度结果会改为基于像素的强度。

使用置换贴图可创建浅的或深的表面起伏。例如，可以创建凸雕、山峰和山谷、尖刺等等。

因为“置换”(Displacement)贴图会创建真正的表面起伏，所以：

- 置换贴图可以投射或接收阴影

- 如果使对象呈现暗色轮廓，则可以看到置换贴图

- 置换贴图需要花费比凹凸贴图（创建表面起伏的错觉）更多的时间来渲染

**注**

通过将纹理连接到材质的着色组中的“置换材质”(Displacement mat)属性，可以作为置换贴图连接纹理。有关详细信息，请参见[连接纹理作为置换贴图](连接纹理作为置换贴图.md)。

## 置换边界框

因为置换贴图会更改对象的体积，所以其边界框可能会变得太小或太大。

边界框代表对象的边界体积，它可用于加快 Maya 操作的速度，并且对于复杂的模型，可能会存在显著的差异。

请参见[更改边界框比例](更改边界框比例.md)。
