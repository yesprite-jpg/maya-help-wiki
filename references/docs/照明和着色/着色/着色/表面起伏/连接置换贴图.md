# 连接置换贴图

因为置换贴图会改变曲面的几何体，所以用作贴图的纹理不应包含锯齿边（锯齿）或噪波。

若要在对曲面进行置换贴图前过滤出锯齿和噪波，请参见[纹理过滤](../关于着色和纹理曲面/纹理/纹理过滤.md)。

如果必须使用含有少量噪波的纹理进行置换贴图，请使用基于特征的置换贴图，并调整[纹理阈值](../着色引用/着色节点/基于特征的置换贴图属性.md#WS73099CC142F48755-3D114B7511812357EFE-5CF1)属性。

**注**

提示：

有时候，将具有明显特征的纹理映射到对象上时，对象的体积或大小可能发生更改。

若要调整此问题并保留对象的体积（大小），请对纹理使用负“Alpha 偏移”(Alpha Offset)值，以便将几何体的大小重新下调（例如 -2）。您可能还必须调整文件纹理才能获得所需结果。
