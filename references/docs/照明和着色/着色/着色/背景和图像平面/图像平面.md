# 图像平面

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-7E27C3D6-5E08-453C-A47B-72846081B719.png) <!-- baize:img-hook downloaded=false reason="正文 1053 字 ≥300，非承重" -->

可以导入一个图像，一系列图像文件或影片文件，并将其映射到图像平面以用作场景的背景。可通过下列方式使用该背景：

- 在构建场景时作为参考。

- 作为场景背景，而无需构建整个场景。

- 使用“使用背景”(Use Background)材质捕捉阴影和反射（请参见[阴影捕捉](../../../照明/照明/Maya%20中的阴影/阴影捕捉.md)）。

- 使用“环境”(Environment)纹理生成环境。

图像平面有两种类型：

- 未附加到摄影机的自由图像平面，可供自由选择和变换。

- 附加到摄影机的图像平面。这些平面是在摄影机的远剪裁平面自动创建的。

  它们与摄影机垂直并设置为其子对象，以便即使在摄影机移动或更改关注点时，图像平面仍会覆盖场景后的整个视图。

如果图像平面是具有深度通道的 .exr 或 .iff 文件，则可以在图像平面中包含深度信息。请参见[图像平面的深度合成](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-C35BA8EB-A706-4249-891C-B1A83AAB7254.htm)。

可以创建多个图像平面以添加有趣的背景（按深度排序）。若要创建、编辑或定位图像平面，请参见[创建、编辑或定位图像平面](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F72F8E1B-EFFE-400E-BD92-5441BE9CD28F.htm)。

“图像平面属性”(Image Plane Attributes)控制图像平面的外观和放置。有关图像平面属性的详细说明以及如何更改它们的指导原则，请参见[图像平面属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-60471C15-F6AC-4041-A7D7-5F89A2D2A4DB.htm)。

**注**

“缓存播放”(Cached Playback)支持图像平面，但仅在将

“解算缓存”(Evaluation Cache)

设置为缓存模式时才支持。有关缓存模式的详细信息，请参见

选择缓存播放模式

。

## 图像平面语法

在作为图像平面导入图像时，必须遵循如下语法：

- 名称.#

- 名称.#.ext

## 静态图像文件背景

静态图像文件背景使用单个图像文件作为背景。背景图像在动画期间不会更改。

若要创建静态图像文件背景，请参见[创建静态图像文件背景](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-20782989-F864-4CA6-9A11-60BE8CEA921C.htm)。

## 已设置动画的图像文件背景

可以使用一系列图像文件或影片文件创建已设置动画的图像文件背景。（影片文件在视图中的更新速度比一系列图像文件快得多。）

若要创建已设置动画的图像文件背景，请参见[创建已设置动画的图像文件背景](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-28ED30C1-DCF1-406A-9C83-CF7CB92610C8.htm)。

## 3D 背景模拟

图像文件背景是 2D 图像，位于场景中的对象后面。但是，可以通过创建表示背景图像中对象的“替代对象”曲面来模拟 3D 背景。场景中的对象随后可以：

- 移动到背景图像中的对象后。

- 将阴影投射到背景图像中的对象上。

- 从背景图像中的对象接收阴影。

- 由背景图像中的对象精确地反射。
