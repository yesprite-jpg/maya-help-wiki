# 创建静态图像文件背景

有关如何创建图像平面的信息，请参见[创建、编辑或定位图像平面](创建、编辑或定位图像平面.md)。

创建静态图像文件背景

1. 选择图像平面。

2. 在“属性编辑器”(Attribute Editor)中，将图像平面的“类型”(Type)属性设置为“图像文件”(Image File)（默认设置）。

3. 单击“图像名称”(Image Name)属性对应的文件夹按钮。

  将显示文件浏览器。

4. 选择要用作背景的图像文件，然后单击“打开”(Open)。

  这会将该图像文件连接到图像平面。
