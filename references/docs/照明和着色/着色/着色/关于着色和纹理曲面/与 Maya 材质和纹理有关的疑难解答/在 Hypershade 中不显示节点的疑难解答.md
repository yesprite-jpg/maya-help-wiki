# 在 Hypershade 中不显示节点的疑难解答

您可以从 [Hypershade 工作区](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-225AB3A8-9013-49EB-93FE-F5A287159FF4.htm)中的图表以及从 [Hypershade 浏览器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-CA8C895B-496A-40C3-9B91-8356E04931C8.htm)过滤出节点类型。未显示的节点可能已被过滤掉。

若要在工作区中检查过滤器设置，请单击鼠标右键，然后从标记菜单中选择“显示 > 对象”(Show > Objects)。

若要在浏览器中检查过滤器设置，请单击“显示”(Show)按钮，然后选择“对象”(Objects)。有关详细信息，请参见 [Hypershade 浏览器工具栏](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-5B48E281-2DCB-4C65-9DCA-52CBA26A7BBA.htm)。

若要清除所有过滤器，请选择“清除以下项”(Clear Below)。此外，验证您尚未在过滤器文本框中输入任何文字。过滤器文本框位于工作区和浏览器的各自工具栏中。
