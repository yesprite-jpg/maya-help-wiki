# 扭曲纹理疑难解答

2D 纹理直接定位在 NURBS 曲面的 UV 空间中。如果第一次应用纹理时其显示为扭曲的，则可能需要编辑曲面方向、修复不均匀的 UV 值（修复纹理扭曲），甚至重建曲面。请参见[纹理贴图](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-A47D9E3F-2973-4C84-B020-DF9AA0236FF2)。

**注**

如果曲面使用“修复纹理扭曲”(Fix Texture Warp)，“转化为文件纹理(Maya 软件)”(Convert to File Texture (Maya Software))将不支持“修复纹理扭曲”(Fix Texture Warp)，转化材质时其将被忽略。
