# 当我移动参照对象时纹理游移的疑难解答

通过该工作流可以将被引用对象移到场景中的任何位置，而不会使纹理在原始对象上游动。

如果 3D 纹理节点在对象的层次内进行分组

1. 选择对象层次的顶级节点。

2. 创建被引用对象。请参见[创建纹理引用对象](../纹理/纹理映射/2D%20和%203D%20纹理位置/将%203D%20纹理或投影的%202D%20纹理锁定到曲面.md#GUID-C575BA54-DC55-4AC7-BCBF-FAB2D032D630__WS73099CC142F48755-3D114B7511812357EFE-796E)。

3. 运行“优化场景大小”(Optimize Scene Size)工具。

4. 将原始 3D 纹理节点从原始对象的层次移到被引用对象的层次中。
