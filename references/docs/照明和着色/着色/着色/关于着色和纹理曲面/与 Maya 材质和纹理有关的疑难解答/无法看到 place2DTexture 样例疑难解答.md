# 无法看到 place2DTexture 样例疑难解答

如果无法看到 place2dTexture 样例，请执行以下操作之一：

- 选择纹理样例，然后单击“Hypershade”工具栏上的“输入连接”(Input Connections)按钮。

- 如果不存在 place2DTexture 样例，则已删除或未创建该样例（因为默认情况下禁用其自动创建）。必须添加一个节点（请参见[在 Hypershade 中创建和连接节点](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F90898A6-55E7-47EA-8542-8A9FD9CBC561.htm)），然后将它连接到纹理（请参见[通过拖动来连接节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-591E9EB3-7B11-456D-92C2-0A6B470079FC)），再重新定位它。
