# 显示节点连接

有关渲染节点和连接的详细信息，请参见[关于着色网络](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-599CACDB-76C1-4FAC-AA94-0E77F0042C8D.htm)。

显示连接

1. 选择要查看连接的节点，然后在 Hypershade 工具栏中单击以下图标之一。（将光标悬停在一个图标上以显示其名称。）

  **注**

  输入和输出连接有时称为上游/下游连接。
