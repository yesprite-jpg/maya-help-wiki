# 将热键指定给 Hypershade 中的常用功能

提供了预定义的热键，尽管也可以指定自定义热键。

在[节点编辑器和 Hypershade 热键](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8E175070-AB7C-41A2-B0D7-85E842F83C4E)中可以找到预定义热键的列表。此外，可以将自定义热键指定给任何 Hypershade 菜单和工具栏项，以及常用节点绘制功能。

选择“Windows > 设置/首选项 > 热键编辑器”(Windows > Settings/Preferences > Hotkey Editor)以打开热键编辑器。在“为以下项编辑热键”(Edit Hotkeys For)下，选择“编辑器”(Editors)，然后从编辑器列表中选择“Hypershade”。

将列出所有的 Hypershade 菜单和工具栏项。选择要为其指定热键的命令并输入热键快捷方式。
