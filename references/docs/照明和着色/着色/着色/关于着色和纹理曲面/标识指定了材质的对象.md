# 标识指定了材质的对象

若要标识指定了特定材质的对象，请执行以下操作：

- 在“Hypershade”中，在材质样例上单击鼠标右键，然后选择“选择具有材质的对象”(Select Objects with Material)。

  在“大纲视图”(Outliner)中，启用“显示 > 指定的材质”(Display > Assigned Materials)以显示指定给场景中每个对象的着色器，然后在材质上单击鼠标右键并选择“选择具有材质的对象”(Select Objects with Material)。也可以选择“框显具有材质的对象”(Frame Objects with Material)。

  这样便可标识指定给同一着色器的所有其他对象。
