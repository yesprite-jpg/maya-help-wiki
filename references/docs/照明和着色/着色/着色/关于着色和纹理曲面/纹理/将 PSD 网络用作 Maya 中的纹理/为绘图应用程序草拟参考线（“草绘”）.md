# 为绘图应用程序草拟参考线（“草绘”）

可以使用 Maya 的“3D 绘制工具”(3D Paint Tool)开始草拟（“草绘”），其中的绘制应该应用于对象。然后，绘制者可以在 Adobe Photoshop 中更富有战略性地进行绘制，因为他们可以轻松看到要将绘制应用于何处。这尤其适用于具有 UV 的模型，它们不会为您提供足够的信息来有效地进行绘制。

**注**

也可以首先映射文件纹理（而不是使用“3D 绘制工具”(3D Paint Tool)）。

草绘模型

1. 使用 Maya 的“3D 绘制工具”(3D paint Tool)，在模型上大致绘制您要看到的对象（例如，眼睛、嘴、胡须）。请参见 [3D 绘制工具概述](../3D%20绘制工具.md)。

2. 保存场景。

3. 按步骤创建和使用“PSD 文件”(PSD File)纹理。请参见[从 Maya 中创建包含层集的 PSD 文件](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-B750BF4E-2343-4AA0-A09F-C7FA5F270B95.htm)。

  将绘制的纹理作为基础层插入到每个层集中。

  **注**

  在为这些属性创建了 PSD 后，便不能返回这些属性的 3D 绘制。
