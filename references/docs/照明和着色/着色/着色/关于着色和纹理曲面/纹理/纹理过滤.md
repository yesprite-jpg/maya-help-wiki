# 纹理过滤

纹理过滤是一种抗锯齿技术，用于细化文件纹理、减少闪烁或实现特殊效果。“文件”(File)纹理的“过滤器”(Filter)属性（请参见[文件](../../着色引用/着色节点/纹理节点概述/2D%20纹理/文件%28File%29纹理节点.md)）缩放过滤器的大小，并用于指定纹理贴图中的模糊量。

如果纹理贴图图像太明晰，则可能会在最终渲染的图像中显示锯齿（楼梯）效果。默认情况下，“过滤器”(Filter)值设定为 1.0 以帮助避免此类锯齿效果。

“过滤器”(Filter)的效果与眼空间直接相关。对象移动得离眼越远，纹理就越模糊。

## 多像素过滤器插件

（仅适用于 Maya 软件渲染器）

多像素过滤器处理整个渲染的图像，以帮助消除瑕疵，如渲染的图像中的锯齿或锯齿状边，或渲染的动画中的挂绳状瑕疵或闪烁。可以从几个不同类型的多像素过滤器中进行选择，也可以创建并使用自己的插件。

若要创建并使用自己的插件，请参见[创建和加载插件多像素过滤器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EE43D49E-D1ED-44C8-BB7C-043E893652A9)。
