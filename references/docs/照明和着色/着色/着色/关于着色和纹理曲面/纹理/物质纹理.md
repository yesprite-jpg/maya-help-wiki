# 物质纹理

可以使用“物质”(Substance)节点，通过有机、织物和材质预设库快速创建逼真的程序纹理。

此外，可以将物质用作噪波或智能过滤器。每种物质都可以进行自定义以生成无限变体。

有关物质纹理的详细信息，请参见：[http://www.autodesk.com/maya-substance-docs](http://www.autodesk.com/maya-substance-docs)。有关视频教程，请参见 [http://www.autodesk.com/maya-substance-training](http://www.autodesk.com/maya-substance-training)。
