# 对纹理进行分层

有关分层纹理的详细信息，请参见[分层纹理](../2D%20和%203D%20纹理.md#WS17956D7ADBC6E736-51D3585C117AE33DCFA-7FE4)。

在着色器图表中使用分层纹理

1. 在“Hypershade”中，将“分层纹理”(Layered Texture)从“创建”(Create)选项卡拖放到工作区来进行创建。

2. 在“分层纹理”(Layered Texture)的“属性编辑器”(Attribute Editor)中，选择要编辑的层。

  ![图：在“分层纹理”(Layered Texture)的“属性编辑器”(Attribute Editor)中，选择要编辑的层。…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-395E4720-D493-4A29-9AC1-FB91F665B127.png) <!-- baize:img-hook downloaded=false reason="正文 610 字 ≥300，非承重" -->

  ![图：在“分层纹理”(Layered Texture)的“属性编辑器”(Attribute Editor)中，选择要编辑的层。…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-0751068D-D20F-4D08-9344-F691F43ECDE5.png) <!-- baize:img-hook downloaded=false reason="正文 610 字 ≥300，非承重" -->

  **注**

  提示：

  若要重新排列“分层纹理 属性编辑器”(Layered Texture > Attribute Editor)中的层，请使用鼠标中键拖动层样例。

  ![图：在“分层纹理”(Layered Texture)的“属性编辑器”(Attribute Editor)中，选择要编辑的层。…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-F11E37FA-9903-47A8-B731-08F9D4C7BF94.png) <!-- baize:img-hook downloaded=false reason="正文 610 字 ≥300，非承重" -->

3. 从“分层纹理 属性编辑器”(Layered Texture > Attribute Editor)中选择“融合模式”(Blend Mode)；例如，“覆盖”(Over)、“相加”(Add)或“相乘”(Multiply)。

  尝试使用不同的模式选择最适合您的结果。有关融合模式和其他“分层纹理”(Layered Texture)属性的详细信息，请参见[分层纹理](../../../着色引用/着色节点/纹理节点概述/分层纹理%28Layered%20texture%29.md)。

4. 将“分层纹理”(Layered Texture)连接到着色节点。

  例如，将分层纹理”(Layered Texture)的“输出颜色”(Out Color)输出连接到“Blinn”的“颜色”(Color)输入。

5. 在视口或“材质查看器”(Material Viewer)中可视化结果。

**注**

提示：

若要更改层的纹理属性，请在着色器图表中选择纹理节点以访问该纹理的属性。

编辑层中的任何纹理，然后实时查看“材质查看器”(Material Viewer)更新。
