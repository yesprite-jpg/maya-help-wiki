# 适用于纹理文件的过滤器功能

可用的过滤器功能如下所述。

预过滤(Pre Filter)

- 在用于渲染前先对图像进行模糊处理。

- 若要启用此功能，请在文件节点“属性编辑器”(Attribute Editor)中的“文件属性”(File Attributes)区域下选择“预过滤”(Pre Filter)。

过滤器(Filter)/过滤器偏移(Filter Offset)

- 以下是选定过滤器类型的各项参数。[过滤器](../../../着色引用/着色节点/纹理节点概述/2D%20纹理/共享%202D%20纹理属性.md#WS73099CC142F48755-3D114B7511812357EFE-62C7)属性对过滤器的大小进行缩放，并允许您指定纹理贴图的模糊度。此属性可用作抗锯齿技术来优化文件的纹理、减少闪烁，或实现特殊效果。[过滤器偏移(Filter Offset)](../../../着色引用/着色节点/纹理节点概述/2D%20纹理/共享%202D%20纹理属性.md#WS73099CC142F48755-3D114B7511812357EFE-62C1)属性控制纹理空间（不是眼空间）中的纹理模糊度。使用“过滤器偏移”(Filter Offset)而不是抗锯齿来获得模糊效果。

- 在文件节点的“属性编辑器”(Attribute Editor)下的“效果”(Effects)区域下设定这些参数。
