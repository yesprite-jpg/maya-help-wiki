# 纹理放置与标签映射

默认情况下，“纹理放置工具”(Texture Placement tool)针对“标签映射”(Label Mapping)设置，让您可以像标签一般拉伸、收缩、移动和旋转纹理。该工具可以改为针对“曲面放置”(Surface Placement)设置，让您可以像墙纸一般拉伸、收缩、移动和旋转纹理。

在这两种情况下，U 向折回和 V 向折回控制纹理在水平和垂直方向上的平铺（基于对象上的 UV 坐标）。

若要更改“纹理放置工具”(Texture Placement Tool)，请双击工具栏中的“纹理放置工具”(Texture Placement Tool)图标，或选择“纹理 > NURBS 纹理放置工具”(Texturing > NURBS Texture Placement Tool) > ![图：若要更改“纹理放置工具”(Texture Placement Tool)，请双击工具栏中的“纹理放置工具”(Textur…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 582 字 ≥300，非承重" -->详细信息请参见[“纹理”(Texturing)菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2655A075-1B14-4822-94E2-E4F12A25B0DD)。。

## 曲面放置

当拖动操纵器控制柄时，[UV 向重复](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D.htm#GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D__WS1A9193826455F5FF-4F542F6211C79DEA861-1775)、[偏移](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D.htm#GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D__WS1A9193826455F5FF-4F542F6211C79DEA861-1774)和[UV 向旋转](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D.htm#GUID-94070C7E-C550-42FD-AFC9-FBE82B173B1D__WS1A9193826455F5FF-4F542F6211C79DEA861-1773)的属性设置将在 place2dTexture 的“属性编辑器”(Attribute Editor)中发生更改。这样可以让您如墙纸一般拉伸、收缩、移动和旋转纹理。
