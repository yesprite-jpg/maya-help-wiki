# 将纹理或着色网络转化为文件纹理

当您将照明、阴影、着色和纹理转化为文件纹理时，表明您正在执行渲染；该过程将使用“Maya 软件”(Maya Software)的 “渲染设置”(Render Settings)中的设置（请参见[“渲染设置”(Render Settings)窗口](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-59DFB8B7-776B-4243-B404-A3D602FF8CFD)）。请确保已设定这些设置，以获得所需的结果。

如果将程序纹理或着色网络映射到曲面、且需要将其更改为文件纹理时，请使用该步骤。

若要了解有关文件纹理的一般信息，请参见[程序纹理](../程序纹理.md)。

有关转化和烘焙之间差集的详细信息，请参见[烘焙照明和颜色](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F68686B3-965D-412A-87BA-CFAC81905ED9.htm)。

将程序纹理或着色网络转化为“文件”(File)纹理

1. 请在按住 Shift 键的同时单击视图中的对象和“Hypershade”中的材质样例。

2. 执行下列操作之一：

  - 在“Hypershade”的“编辑”(Edit)菜单上选择[转化为文件纹理(Maya 软件)](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-EF6DFB31-CFCF-428D-8961-3D96CE673F99.htm#GUID-EF6DFB31-CFCF-428D-8961-3D96CE673F99__GUID-00259A6A-3E21-4DA8-A573-B46A4088871A)。

  - 单击[编辑 > 转化为文件纹理(Maya 软件) (Edit > Convert to File Texture (Maya Software))](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-EF6DFB31-CFCF-428D-8961-3D96CE673F99.htm#GUID-EF6DFB31-CFCF-428D-8961-3D96CE673F99__GUID-00259A6A-3E21-4DA8-A573-B46A4088871A) > ![图：单击编辑 转化为文件纹理(Maya 软件) (Edit Convert to File Texture (Maya So…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 435 字 ≥300，非承重" -->，调整选项，然后单击“转化”(Convert)。
