# 2D 和 3D 纹理

纹理节点是一种可在[映射到对象的材质](纹理映射/将%202D%20或%203D%20纹理映射到材质.md)后用于定义对象曲面在渲染后的外观的渲染节点。

纹理节点（具有材质节点）添加到告知渲染器如何对曲面进行着色的“着色组”(Shading Group)节点中。另请参见[关于着色网络](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-599CACDB-76C1-4FAC-AA94-0E77F0042C8D.htm)。

纹理节点是由 Maya 或导入到 Maya 的可用作材质属性的纹理贴图的位图图像生成的程序纹理（请参见[程序纹理](程序纹理.md)）。不同属性（如颜色、凹凸和反射）上的纹理贴图会影响材质的外观。有关纹理贴图的详细信息，请参见[纹理贴图](纹理映射.md)。

## 2D 纹理

2D 纹理包裹对象，如礼品包装；或粘贴到平面，如墙纸。

- 有关 Maya 2D 纹理的列表，请参见 [2D 纹理](../../着色引用/着色节点/纹理节点概述/2D%20纹理.md)。

- 若要对 2D 纹理进行贴图，请参见[映射 2D 或 3D 纹理](纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

- 若要将已映射 2D 纹理置于对象上，请参见[定位 2D 纹理和标签](纹理映射/2D%20和%203D%20纹理位置/定位%202D%20纹理和标签.md)。

## 3D 纹理

3D 纹理可以投影到对象，如大理石或木材中的纹理。

使用 3D 纹理，对象看起来就像是由物体雕刻的，如岩石或木材。在场景视图中能够以交互方式缩放、旋转和移动 3D 纹理，以获得所需结果。

- 有关 Maya 3D 纹理的列表，请参见 [3D 纹理](../../着色引用/着色节点/纹理节点概述/3D%20纹理.md)。

- 若要对 3D 纹理进行贴图，请参见[映射 2D 或 3D 纹理](纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

- 若要将已映射 3D 纹理置于对象上，请参见[定位 3D 纹理](纹理映射/2D%20和%203D%20纹理位置/定位%203D%20纹理.md)。

## 环境纹理

环境纹理通常用作场景中对象的背景或用作反射贴图。

有关使用环境贴图模拟反射的详细信息，请参见[真实反射](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-858263F7-CF7F-4400-90EB-760BB9790A0E.htm)。

有关 Maya 环境纹理的详细描述，请参见[关于环境纹理](../../着色引用/着色节点/纹理节点概述/环境纹理.md)。

## 分层纹理

在 Maya 中可以使用两种方法对纹理进行分层：使用带纹理合成标志的“分层着色器”(Layered Shader)，或使用“分层纹理”(Layered Texture)节点。

尽管使用“分层纹理”(Layered Texture)节点的工作流程类似于“分层着色器”(Layered Shader)，但建议使用“分层纹理”(Layered Texture)节点，因为您可以设定许多融合模式。

若要使用“分层纹理”(Layered Texture)节点对纹理进行分层，请参见[创建分层着色器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-6DFCE108-8C98-4365-9D60-8A44149052A6.htm)。
