# 在视口中加载文件纹理

如果场景中包含的高分辨率纹理超出您的显卡内存的处理能力，则纹理可能看起来模糊或无法在视口中加载。这表示“钳制纹理分辨率”(Clamp Texture Resolution)已启用并且生效。若要解决此问题，请参见[纹理模糊或“超出 GPU 纹理 RAM，纹理加载失败”错误消息疑难解答](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8BAA3B98-F6C5-48F4-834F-14A551836B34)

此外，在“首选项”(Preferences)窗口的“显示”(Display)区域中，您还可以在不同的纹理加载模式中进行选择。选择“即时”(Immediate)模式可使加载时间最短；但是，您可能必须等待片刻后才能与场景进行交互。或者，可以选择“平行”(Parallel)模式，使您能够在材质实现和纹理加载的同时与场景进行交互。请参见[显示首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BF017019-B89A-47F0-8AB5-106C058AB854)。
