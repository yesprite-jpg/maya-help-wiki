# 动画文件纹理

若要使用图像文件序列来创建动画文件纹理，则文件扩展名必须用句点与基础名称和/或扩展名隔开。有关示例，请参见[图像名称](../../../着色引用/着色节点/纹理节点概述/2D%20纹理/文件%28File%29纹理节点.md#WS73099CC142F48755-3D114B7511812357EFE-6453)。

**注**

使用“.”描述动画文件纹理名称可能导致将错误的帧用于纹理映射。

若要由 Maya 进行求值，动画文件纹理应该采用 XXX.ext.### 形式，其中 XXX 是文件名，ext 是可选文件扩展名（.sgi、.tif、.iff 等等），### 是帧编号。

也可以使用 XXX.###.ext 形式的文件纹理。我们不支持 XXX###.ext（XXX 和 ### 之间没有“.”），也不支持 XXX.YYY.###.ext（但支持 XXX_YYY.###.ext）。
