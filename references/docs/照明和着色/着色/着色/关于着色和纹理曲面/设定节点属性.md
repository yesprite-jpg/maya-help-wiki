# 设定节点属性

有关材质节点属性的详细说明，请参见[关于表面材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-634CAFBE-AC48-4B73-89CA-82D64FA1BC70.htm)、[关于置换材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-204712F3-344B-4A41-9399-51B2BD19A3F7.htm)和[关于体积材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-6FF09EBA-CD7C-45B7-8B49-305D748EE7B4.htm)。

可以一次调整一个节点（例如，如果需要在使用 IPR 时调整单个属性），也可以同时调整多个节点，方法是使用“属性编辑器”(Attribute Editor)的“属性总表”(Attribute Spread Sheet) >“渲染标志”(Rendering Flags)窗口或“通道盒”(Channel Box)。

设定一个节点的属性

1. 选择要调整其属性的节点，然后打开其[属性编辑器](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-67A58D31-4722-4769-B3E6-1A35B5B53BED)。

  可以在 Hypershade 中、节点编辑器中或大纲视图中选择节点。

  如果要创建着色器图表，则可以在 Hypershade 特性编辑器中调整渲染节点属性。默认情况下，特性编辑器在模板视图（该视图为着色工作流而优化，且具有仅列出最常用属性的更简单布局）中显示渲染节点。通过在特性编辑器中单击 ![图：如果要创建着色器图表，则可以在 Hypershade 特性编辑器中调整渲染节点属性。默认情况下，特性编辑器在模板视图（该…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-4A7A53DB-FDC6-4913-800E-FF48465A4C87.png) <!-- baize:img-hook downloaded=false reason="正文 1259 字 ≥300，非承重" -->，可以切换到属性编辑器视图。

2. 通过移动滑块或者在属性名称旁边的字段中键入值来调整属性。如果希望映射纹理、工具或光学效果，请单击属性名称末尾的映射按钮。

有关如何[调整材质属性](将颜色和着色应用于对象.md#GUID-93AE85F5-F147-4B08-97B7-4D7423BB45AE__SECTION_F04F454ECB6C46F7BECE200D72571B54)的视频演示，请参考此[介绍性教程](将颜色和着色应用于对象.md)。

在“属性总表”(Attribute Spreadsheet)中设定多个渲染节点的属性

1. 选择要调整其属性的表面或渲染节点。

2. 选择窗口 > 常规编辑器 > 属性总表(Window > General Editors > Attribute Spread Sheet)。

3. 单击选项卡标题以查看属性。

  - “可设定关键帧”(Keyable)选项卡包含渲染节点属性。

  - “渲染”(Render)选项卡包含用于确定如何渲染表面的属性。

4. 使用滚动条可以水平查看属性。

5. 向下拖动属性列可以选择其内容并选择顶部字段以选择列中的所有条目。

6. 在选定属性列的顶部字段中键入所需值并按 Enter 键（Windows 和 Linux）或 Return 键 (Mac OS X)。

  该列中的所有属性都将更新为新值。

在“渲染标志”(Rendering Flags)窗口中设定节点的属性

1. 单击“窗口 > 渲染编辑器 > 渲染标志”(Windows > Rendering Editors > Rendering Flags)。

2. 在“渲染标志”(Rendering Flags)窗口中，从“显示”(Show)下拉列表中，选择要查看其属性列表的项目。

  这些项目的属性将在右侧面板中列出，您可以在其中更改和设定属性，就像在“通道盒”(Channel Box)中那样。

3. 执行下列操作之一：

  - 若要更改一个节点的属性，请单击左侧面板中列出的节点以便在右侧面板中显示属性，然后更改属性。

    ![图：若要更改一个节点的属性，请单击左侧面板中列出的节点以便在右侧面板中显示属性，然后更改属性。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-2533F4C6-385D-4FB9-8710-2D663786602A.png) <!-- baize:img-hook downloaded=false reason="正文 1259 字 ≥300，非承重" -->

  一旦更改选定项目的属性，列表中的标题颜色即会变化，以提醒您发生了更改。

  **注**

  提示：

  也可以使用“渲染标志”(Rendering Flags)窗口或“通道盒”(Channel Box)设定多个节点的属性。
