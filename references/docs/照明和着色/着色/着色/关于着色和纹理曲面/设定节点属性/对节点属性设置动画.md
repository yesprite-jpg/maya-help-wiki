# 对节点属性设置动画

有关材质节点属性的描述，请参见[表面材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-634CAFBE-AC48-4B73-89CA-82D64FA1BC70.htm)、[置换材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-204712F3-344B-4A41-9399-51B2BD19A3F7.htm)和[体积材质](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-6FF09EBA-CD7C-45B7-8B49-305D748EE7B4.htm)。

对属性设置动画

1. 在 Maya 的主窗口中，将时间滑块设定到某一帧。

2. 在节点的“属性编辑器”(Attribute Editor)中，在要设定关键帧的属性（如“颜色”(Color)属性）的标签上单击鼠标右键，然后从弹出菜单中选择“设定关键帧”(Set Key)来创建关键帧。

  ![图：在节点的“属性编辑器”(Attribute Editor)中，在要设定关键帧的属性（如“颜色”(Color)属性）的标签…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-715709C8-D142-427E-A345-7ED73DB7B829.png) <!-- baize:img-hook downloaded=false reason="正文 301 字 ≥300，非承重" -->

3. 将时间滑块设定到另一帧。

4. 调整该属性，并设定另一个关键帧。例如，单击“Blinn”材质的颜色属性，并在每次设置新关键帧时，从“颜色”(Color)选择器中选择一种不同的颜色。

5. 播放动画。视图中会以动画形式显示渲染属性所指定给的曲面（例如，“Blinn”颜色在设置的每个关键帧处都会改变）。
