# 将着色器指定给多边形面

通过使用标记菜单或者使用 Maya® Artisan™ 笔刷绘制，可以将着色器指定给多边形曲面上的面。使用该功能可将不同的着色器指定给同一模型的面（例如，部分为砖部分为玻璃的建筑纹理）。

使用标记菜单将着色器指定给多边形曲面上的面

1. 在曲面上单击鼠标右键，从标记菜单中选择“面”(Face)。

2. 选择（拖动或按住 Shift 键并单击）要映射的面，然后单击鼠标右键并从材质指定选项（例如，“指定新材质”(Assign New Material)或“指定现有材质”(Assign Existing Material)）中选择。

使用 Artisan 笔刷将着色器指定给多边形曲面上的面

1. 在视口中，选择要为其指定材质的对象。

2. 在 [Hypershade](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-252707EC-4AAF-4D3F-9600-804F783652B7.htm) 中，在材质样例上单击鼠标右键，然后从标记菜单中选择“绘制指定着色器”(Paint Assign Shader)。

**注**

此外，您也可以从

大纲视图(Outliner)

中选择

“绘制指定着色器”(Paint Assign Shader)

。请确保

“显示 > 指定的材质”(Display > Assigned Materials)

处于启用状态，以便显示指定给每个对象的着色器。在材质上单击鼠标右键，然后从标记菜单中选择

“绘制指定着色器”(Paint Assign Shader)

。

3. Artisan 笔刷将显示在场景视图中。将笔刷拖动到要对其应用着色器的面上。

  **注**

  提示：

  如果您的 Artisan 笔刷选择顶点，而不是面，则在曲面上单击鼠标右键并选择“面”(Face)以转换为“面”(Face)模式。

有关 Maya 着色器的详细信息，请参见[曲面着色](../../../../着色.md)。

有关基于 Artisan 的笔刷的详细信息，请参见 [Artisan 笔刷工具的工作方式](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D0A5ACD2-8D10-4B51-ADD3-E261F9337B07)。
