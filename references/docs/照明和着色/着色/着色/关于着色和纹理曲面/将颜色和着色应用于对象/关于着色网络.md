# 关于着色网络

定义材质外观的颜色和纹理可以表示为着色网络。在此示例中，岩石纹理定义 Phong 材质的颜色，而山脉纹理定义白炽度。

着色网络是数据流网络，数据从该网络的左侧向右侧传输，从而产生最终着色结果。该网络的左侧包含渲染节点。渲染节点可能是[材质节点](Maya%20材质.md)、[纹理节点](../../着色引用/着色节点/纹理节点概述.md)、[工具节点](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-DA9707D2-8A0D-4911-A010-8274C57D3FD3.htm)等。最右侧的节点（在此示例中为 phong1SG）是该特定网络的着色组。默认情况下，它并不始终可见；若要查看，请选择材质（在此示例中为 Phong），然后单击 Hypershade 的[工作区](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-225AB3A8-9013-49EB-93FE-F5A287159FF4.htm)中的 ![图：着色网络是数据流网络，数据从该网络的左侧向右侧传输，从而产生最终着色结果。该网络的左侧包含渲染节点。渲染节点可能是材质节…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-63896264-648D-4965-A429-C450C9E373D6.png) <!-- baize:img-hook downloaded=false reason="正文 744 字 ≥300，非承重" -->。着色组的所有连接上游（即：节点最左侧）的节点均有助于改进曲面在场景中的最终外观。调整任何节点的属性或连接时，均会导致出现最终渲染图像中可以看到的下游（即：最右侧）反应。

使用 [Hypershade](../使用%20Hypershade%20的外观开发.md) 构建您自己的着色网络，并将其指定给场景中的对象。在此编辑器中，您可以调整节点属性，以及在着色网络中[创建和连接节点](../使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点.md)。

若要调整任何渲染节点（例如，修改其[颜色](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-AEA3C15F-1C08-44CF-9CBF-C9E90CC0F09E.htm)、[透明度](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-AEA3C15F-1C08-44CF-9CBF-C9E90CC0F09E.htm)和[反射率](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-D9193CD6-EF2C-4EA3-A31E-C3BDB3E17F87.htm)），请选择相应节点并在“属性编辑器”(Attribute Editor)或 [Hypershade 特性编辑器](../使用%20Hypershade%20的外观开发/在%20Hypershade%20特性编辑器中查看属性.md)中调整其属性。

使用[纹理](../纹理.md)向材质添加曲面细节。例如，您可以将 [2D 或 3D 纹理](../纹理/2D%20和%203D%20纹理.md)作为凹凸贴图进行连接，以向材质添加高地或洼地，或连接文件纹理以定义其颜色。有关如何向着色网络添加纹理的信息，请参见[将 2D 或 3D 纹理映射到材质](../纹理/纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

## 关于节点端口和连接

节点端口和连接在着色网络中以不同的颜色显示，以表示通过连接传输的数据类型。根据使用的节点和连接类型传递不同的信息。即，值可能为颜色、距离、位置、角度或对象 ID。 某些信息可以作为单个值（例如，“OutAlpha”是单个值）或三元值（例如，“输出颜色”(Out Color) RGB 值或 XYZ 值）。有关如何自定义这些颜色的信息，请参见[更改默认的端口和连接线颜色](../使用%20Hypershade%20的外观开发/在%20Hypershade%20中创建和连接节点/通过创建连接线在%20Hypershade%20中连接节点/在%20Hypershade%20中更改默认的端口和连接线颜色.md)。
