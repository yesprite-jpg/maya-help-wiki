# 在视口中查看着色和灯光

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/images/GUID-971B0D7E-A601-496E-9981-D96AD5370F32.png) <!-- baize:img-hook downloaded=false reason="正文 343 字 ≥300，非承重" -->

您可以轻松地启用或禁用硬件纹理，支持您查看场景中的近似纹理、灯光和对象。

您所看到的内容取决于 [Viewport 2.0 设置](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BBB6035-2A02-41BB-AF2D-99D9BEE580F1)和每对象设置。您所看到的内容不一定是最终渲染中显示的内容，但它可以为您提供不错的主意。

在视口中查看纹理、灯光和对象

1. 在视口的[面板菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-BD5D066A-4876-4B56-8A9F-96E2243E22A3)中，选择“着色 > 对所有项目进行平滑着色处理”(Shading > Smooth Shade All)。

2. 选择“着色 > 硬件纹理”(Shading > Hardware Texturing)（或按热键 6）。

3. 要使用场景中的灯光而非默认照明，请选择“照明 > 使用所有灯光”(Lighting > Use All Lights)（或按热键 7）。

**注**

提示：

要在视口中查看分辨率边界，请启用“分辨率门”(Resolution Gate)。有关详细信息，请参见[启用或禁用场景视图参考线](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4A4C539D-0263-4D14-82B4-0CCB65E5A804)。
