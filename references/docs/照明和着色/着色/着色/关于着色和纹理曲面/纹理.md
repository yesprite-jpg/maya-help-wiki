# 纹理

在视觉艺术中，纹理是任何种类的曲面细节，包括视觉和触觉。在 Maya 中，使用连接到作为纹理贴图的对象材质上的纹理，创建曲面细节。材质定义对象的基本物质，而纹理添加细节。

您可以将纹理连接到材质的几乎任何属性；最常见的属性是颜色、透明度和光泽（镜面反射度）。有关材质属性的详细信息，请参见[公用表面材质属性](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-AEA3C15F-1C08-44CF-9CBF-C9E90CC0F09E.htm)和[常见表面材质镜面反射着色属性。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-D9193CD6-EF2C-4EA3-A31E-C3BDB3E17F87.htm)有关如何连接纹理贴图的可视演示，请参见[映射 2D 或 3D 纹理](纹理/纹理映射/将%202D%20或%203D%20纹理映射到材质.md)。

此外，您还可以通过添加[表面起伏](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F403A3FF-55BE-43A0-B6E1-49BA7C6BF5EE.htm)向对象曲面的外观添加细节。通过将纹理作为[凹凸贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-792F3CD8-FD78-41C6-B967-14A0FC13AF46.htm)或[置换贴图](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-E7A03E4E-8C9A-4B62-8218-28FC063A82AB.htm)进行连接可完成此操作。有关常用纹理贴图的信息，请参见[纹理映射](纹理/纹理映射.md#GUID-DC60577E-1A09-4D51-BD6E-6400F4F5EFD7__WS73099CC142F48755-3D114B7511812357EFE-7CF1)。

Maya 中提供了一组 [2D 和 3D 纹理](纹理/2D%20和%203D%20纹理.md)。此外，您还可以创建[文件纹理](../着色引用/着色节点/纹理节点概述/2D%20纹理/文件%28File%29纹理节点.md)，并将其连接到您自己的图像文件。

也可以将照明和颜色烘焙到稍候将应用于场景中对象的纹理。请参见[烘焙照明和颜色](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-F68686B3-965D-412A-87BA-CFAC81905ED9.htm)。
