# 重命名组

若要重命名组节点的分类（Class name、Category name、Sub menu name），以便重命名您在其中创建组节点的标记菜单项，则必须先重新保存具有新 Class name、Category name 和/或 Sub menu name 的组，然后删除旧组。有关更多信息，请参见[删除组](删除组.md)。
