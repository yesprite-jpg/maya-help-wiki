# 更新组

更新并保存组

1. 选择组节点，然后单击该节点顶部的“组” ![图：选择组节点，然后单击该节点顶部的“组” 图标，以查看其组网络。](../../../../../../../.extension/assets/Maya-LightingShading/GUID-A0BF4325-29A5-4BBB-BA85-4EE11D93834B.png) <!-- baize:img-hook downloaded=true reason="正文 159 字 <300 且带图" --> 图标，以查看其组网络。

2. 进行必要的更改，然后选择该组节点并选择 Group > Save Group to Disk。

您所做的更改将保存到磁盘上，并且在您下次通过工作区标记菜单创建组节点时显示。

**注**

您必须先选择要保存的组节点，然后才能选择

Group > Save Group to Disk

。
