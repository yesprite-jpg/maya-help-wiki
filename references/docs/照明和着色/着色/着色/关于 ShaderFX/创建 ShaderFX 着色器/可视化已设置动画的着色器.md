# 可视化已设置动画的着色器

可以在“ShaderFX”编辑器中可视化已设置动画的着色器的动画，例如，“UVRotator”(Hw Shader Nodes > Textures > UV Rotator)。

1. 单击“渲染样例”(Render Swatch)图标，以便显示较小或较大的渲染样例。

2. 选择 Settings > Play Animated Shaders 可以可视化已设置动画的着色器及其下游节点的动画。
