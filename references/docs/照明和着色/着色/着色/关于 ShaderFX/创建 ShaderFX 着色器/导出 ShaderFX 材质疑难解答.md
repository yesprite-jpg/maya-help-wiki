# 导出 ShaderFX 材质疑难解答

当您按照[将 ShaderFX 材质导出到 HLSL、CgFX 和 GLSL](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-LightingShading/files/GUID-12C5BAA1-1709-4082-ACAD-03CBE827936B.htm) 中列出的步骤导出 ShaderFX 材质时，如果遇到问题，请尝试通过指定“硬件着色器/文件名”(HwShader/Filename)属性中的文件扩展名解决该问题。即：不输入 myDrive:\myProject\myFolder\myshader.*，而应输入 myDrive:\myProject\myFolder\myshader.fx。
