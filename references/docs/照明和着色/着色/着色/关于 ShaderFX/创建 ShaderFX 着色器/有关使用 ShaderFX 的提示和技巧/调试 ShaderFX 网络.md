# 调试 ShaderFX 网络

如果 ShaderFX 样例未编译，请选择“设置 > 显示样例编译错误”(Settings > Show Swatch Compile Errors)，然后单击“渲染样例”(Render Swatch) ![图：如果 ShaderFX 样例未编译，请选择“设置 显示样例编译错误”(Settings Show Swatch Comp…](../../../../../../../.extension/assets/Maya-LightingShading/GUID-997874AC-2919-414E-BEDE-BF9C19791FB6.png) <!-- baize:img-hook downloaded=true reason="正文 185 字 <300 且带图" --> 图标，并检查在 ShaderFX 编辑器窗口中显示的错误。

若要查看视口编译错误，请设置环境变量：MAYA_VP2_WANT_OGS_WARNINGS =1，并检查在 Maya 输出窗口中显示的错误。
