# 针对各个节点类型查找帮助

从[标记菜单](ShaderFX%20标记菜单.md)中选择节点时，ShaderFX 窗口将在工作区域的右下角显示一个工具提示。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../.extension/assets/Maya-LightingShading/GUID-AA307F36-A2DD-4744-B653-11011494D11F.png) <!-- baize:img-hook downloaded=true reason="正文 137 字 <300 且带图" -->

您稍后可以显示相同的文本，方法是：单击某节点以将其高亮显示，然后单击节点“属性编辑器”(Attribute Editor)中的“帮助”(Help)按钮：

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../.extension/assets/Maya-LightingShading/GUID-98E3E13B-293F-4E4B-AC61-94261EC6E8DF.png) <!-- baize:img-hook downloaded=true reason="正文 137 字 <300 且带图" -->

这将打开一个对话框，其中也会显示工具提示：
