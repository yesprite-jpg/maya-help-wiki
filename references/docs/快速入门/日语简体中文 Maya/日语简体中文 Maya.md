# 日语/简体中文 Maya

Maya 日语/简体中文用户界面的用户应使用满足以下要求的计算机：Windows 和 Mac OS X 操作系统能够支持日语/简体中文环境。（不适用于 Linux 操作系统。）

若要在 Windows 中运行日语/简体中文用户界面的 Maya，请确保：

- 计算机使用兼容 Maya 的日语/简体中文 Windows 操作系统或兼容 Maya 且支持日语/简体中文的 Windows 操作系统进行操作。如果不确定计算机的操作系统是如何配置的，请联系贵公司的系统管理员或 Microsoft 技术支持。

- 非 Unicode 程序的默认语言设置为日语/简体中文。有关在 Windows 操作系统上设定默认语言设置的详细信息，请参见[运行日语或简体中文用户界面的 Maya](日语简体中文%20Maya/运行日语或简体中文界面的%20Maya.md)。

若要在 Mac OS X 中运行日语/简体中文用户界面的 Maya，请确保：

- 计算机使用兼容 Maya 的 Mac OS X 操作系统进行操作。

- 个人系统语言首选项设置为日语/简体中文。有关在 Mac OS X 操作系统上设定默认语言设置的详细信息，请参见[运行日语或简体中文用户界面的 Maya](日语简体中文%20Maya/运行日语或简体中文界面的%20Maya.md)。

  **注**

  有关可运行 Maya 的合格硬件和操作系统的最新信息，请参见 [http://www.autodesk.com/hardware-chs](http://www.autodesk.com/hardware-chs)。

请注意以下与 Maya 不同语言用户界面相关的问题：

- 如果要在其他硬件平台和操作系统上使用日语/简体中文 Maya 文本文件（.ma 和 .mel），可能需要将这些文件转化为适合目标平台的文本编码格式（例如，Shift_JIS 或 UTF 8）。有关详细信息，请参见[准备包含日语或简体中文文本的 Maya 文件](日语简体中文%20Maya/准备包含日语或简体中文文本的%20Maya%20文件.md)。

- Maya 仅支持作为单字节字符（ASCII 或纯西文文本）输入的对象名称。

- Maya 用户首选项。
