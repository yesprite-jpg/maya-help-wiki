# 注释和过程

以下主题介绍一些在 macOS X 中使用 Maya 的特定过程和注释。这些主题介绍在 macOS X 中使用 Maya 时，功能和一般过程的不同之处。

## 适用于 macOS X 但不适用于 Windows 或 Linux 的功能

以下功能适用于 macOS X 版本的 Maya，但不适用于 Windows 或 Linux 版本。

- QuickTime 集成

- 拖动时在时间线上播放线程声音

- AppleScript 执行 Maya MEL 命令，并返回结果。（另请参见 MEL 和表达式指南中的[从 AppleScript 调用 MEL 或相反情况](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-6BBC67B3-5ED8-4E7D-90D7-E0054E2132D9)。）

- 全屏模式（另请参见[进入全屏模式](进入全屏模式%20%28macOS%29.md)。）

### 不适用于 macOS X 版的第三方程序

- 运动捕捉驱动程序

## 在平台之间传递文件

macOS X 文件使用的行结束符不同于 UNIX 或 Windows 文件。macOS X 程序通过兼容其他行结束符来解决这一问题，但 Windows 和 UNIX 程序（包括从 macOS X 终端窗口运行的类似 Unix 的程序）仅使用其各自专有的行结束符形式。

Maya Bin 文件夹中包括两个可以从终端窗口运行的 UNIX 工具，可以帮助用户轻松将文件从一个平台传递至另一个平台：tounix 和 tomac。

下表介绍特定平台之间传递文件所需进行的操作。

| 从 | 到 | 要求 |
|---|---|---|
| OS X 上的 mayaBinary | 任何平台 | *放置*；或者在非 Macintosh 平台上使用 AppleShare IP 从 macOS 作为二进制文件传递。（从非 Macintosh 平台使用 FTP 会损坏文件。） |
| UNIX 或 Windows 上的 mayaBinary | Maya | 从终端窗口、二进制模式取回应用程序或任何其他二进制机制，作为二进制文件使用 FTP 获取；或者在非 Macintosh 平台上使用 AppleShare IP 从 macOS 作为二进制文传递件。（从非 Macintosh 平台使用 FTP 会损坏文件。） |
| UNIX 或 Windows 上的 mayaAscii 或 mel 文件 | Maya | 无需特殊处理 |
| Maya mayaAscii 或 mel 文件 | UNIX 或 Windows 上的 Maya 5.0+ | 无需特殊处理 |
| Maya mayaAscii 或 mel 文件 | 可读取文本文件的 macOS X 应用程序 | 无需特殊处理 |
| Maya mayaAscii 或 mel 文件 | macOS X UNIX 应用程序（例如 vi 或 grep） | 使用 tounix 工具。在终端窗口中输入： tounix scene_file.ma |
| Maya mayaAscii 或 mel 文件 | UNIX 或 Windows 上的 Maya 3.0 | a）从终端窗口使用 tounix 工具：tounix scene_file.ma，然后作为 ascii 文件使用 FTP 获取。 *或* b) 以 ascii 传递模式使用交互式 Macintosh 取回应用程序。 |
| 已通过 tounix 工具运行的 mayaAscii 或 mel 文件 | 可读取文本文件的 macOS X 应用程序 | 使用 tomac 工具。在终端窗口中输入： tomac scene_file.ma |
| 已通过 tomac 工具运行的 mayaAscii 或 mel 文件 | Maya | 无需特殊处理 |
| 已通过 tounix 工具运行的 mayaAscii 或 mel 文件 | Maya | 无需特殊处理 |
