# 进入全屏模式 (macOS)

全屏模式可以最大化 Maya 的工作区，从而使 Maya 在更小的屏幕上更易于使用。启用了全屏模式后，标题栏、菜单栏以及固定窗口都将被隐藏。

**注**

- 仅当在 macOS X 10.7 或更高版本上运行 Maya 时全屏模式才可用。

- 此步骤特定于 macOS。对于 Windows，请参见[进入全屏模式 (Windows)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E4B38FC4-D049-48A7-B635-02927ED4E7D7)。

在 Mac 上进入全屏模式

1. 在 Maya 中，执行下列操作之一：

  - 选择 Maya > Enter Full Screen

  - 单击 Maya 主窗口右上角的全屏图标 ![图：单击 Maya 主窗口右上角的全屏图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-GettingStarted/images/GUID-CE77EB64-BFF7-42B3-8875-D2F1424ED7EA.png) <!-- baize:img-hook downloaded=false reason="正文 438 字 ≥300，非承重" -->。

  - 按下 Ctrl + ![图：按下 Ctrl + + F](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-GettingStarted/images/GUID-E3D3ABB4-6F9E-4CF4-B886-7CF47B647078.png) <!-- baize:img-hook downloaded=false reason="正文 438 字 ≥300，非承重" --> + F

  Maya 将移动到一个新的桌面，标题栏、菜单栏和固定窗口将被隐藏。激活全屏模式时处于打开状态的所有浮动窗口也将移到这一新桌面。

  **注**

  提示：

  启用全屏模式后，将鼠标移至屏幕的顶部和底部可以显示隐藏的界面元素。

退出全屏模式

1. 在 Maya 中，执行下列操作之一：

  - 选择 Maya > Exit Full Screen。

  - 单击 Maya 主窗口右上角的恢复屏幕图标 ![图：单击 Maya 主窗口右上角的恢复屏幕图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-GettingStarted/images/GUID-34FAC887-8819-48E5-B249-6B9B4C913ED0.png) <!-- baize:img-hook downloaded=false reason="正文 438 字 ≥300，非承重" -->。

  - 按下 Ctrl + ![图：按下 Ctrl + + F](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-GettingStarted/images/GUID-E3D3ABB4-6F9E-4CF4-B886-7CF47B647078.png) <!-- baize:img-hook downloaded=false reason="正文 438 字 ≥300，非承重" --> + F

  Maya 会返回到主桌面并恢复启用全屏模式之前使用的窗口大小。
