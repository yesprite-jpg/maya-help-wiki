# Maya 社区

您可以在 AREA by Autodesk 以及其他 Autodesk 和非 Autodesk 网站上查找其他学习资源。

[AREA](https://area.autodesk.com/) 是专属于使用 Autodesk 3D 产品的美工人员和开发人员的免费社区门户。 创建一个帐户并登录到 AREA，即可访问所有资源并加入 Maya 社区。

与其他 Maya 用户联系：

- AREA 上的 [Maya 讨论组](https://forums.autodesk.com/t5/maya/ct-p/area-c2?profile.language=zh-CN)

- cgTalk (cgSociety) 上的 [Maya 用户论坛](http://forums.cgsociety.org/forumdisplay.php?f=7)

- [Maya 社区](https://www.reddit.com/r/Maya/)是供大家获取建议或共享创作的良好平台。

关注 Maya 和 Maya LT 社区中的最新动态：

- AREA 上的 [Maya 博客](http://area.autodesk.com/blogs)，例如，My Oh Maya! 和 The Desk。

- [Maya Facebook 页面](https://www.facebook.com/AdskMaya)

- [Autodesk 活动与研讨会](http://www.autodesk.com/maya-events-seminars)

- [Autodesk YouTube 频道](https://www.youtube.com/user/Autodesk)，其中经常发布有关 Maya 和其他 Autodesk 产品新功能的视频。

获得更多培训！

- [专家访谈](https://www.autodesk.co.uk/campaigns/webinars/meet-the-experts/upcoming-webinars)是一系列深入研究 3D 行业中诸多话题的现场网络研讨会。这些网络研讨会由各个不同领域的 Autodesk 专家主持并进行录制，以便您在闲暇时观看。

- AREA 上的[用户撰稿教程](http://area.autodesk.com/tutorials)。查找教程或独立撰写教程！
