# 关于 Maya 帮助

Maya 帮助（您所查看的内容）提供有关 Maya 中所有功能（从初级到高级技术）的可搜索文档。此外，它还包含脚本信息的技术文档以及 Maya API 详细信息的开发人员帮助。

  如果您是**从 Maya 中**通过按 F1 键或者选择“帮助 > Maya 帮助”(Help > Maya Help)到达此处，则只需使用左侧的目录或右上角的搜索栏来查找所需内容。

  **注**

  如果文章显示过期或视频显示缺失，则可能使用的是

  脱机

  帮助。如果您不能正常连接到 Internet，则可以使用

  脱机帮助

  ，但

  联机

  版本提供了更多最新内容、更好的搜索体验、YouTube 和 AREA 视频以及论坛帖子。如果您认为得到的是脱机帮助，请与系统管理员联系，确认是否可以切换，并确保将

  帮助首选项(Help Preferences)

  中的

  “帮助位置”(Help Location)

  设置为

  “Autodesk 网站”(Autodesk Web Site)

  。

  如果您是**从 Internet** 到达此处，例如通过 Google 等搜索引擎，您可能看到的是此页面的 [Autodesk Knowledge Network](https://knowledge.autodesk.com/zh-hans/) (AKN) 版本。单击上面（Autodesk 标识正下方）的 ![图：如果您是从 Internet 到达此处，例如通过 Google 等搜索引擎，您可能看到的是此页面的 Autodesk K…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-GettingStarted/images/GUID-13AE3A92-8FAF-4E23-B3F6-E4F79CED62EF.png) <!-- baize:img-hook downloaded=false reason="正文 1542 字 ≥300，非承重" --> 链接访问完整的 Maya 用户手册，然后使用目录和搜索栏查找所需的内容。您可以在任一 AKN 版本的帮助页面中进行此操作。

  **注**

  确保帮助文章中的 Maya 版本与您当前使用的 Maya 版本相匹配也是一种非常好的做法。可以在 URL 中看到文章版本，也可以在 AKN 中通过单击

  “涵盖的产品和版本”(Products and versions covered)

  按钮了解版本信息。

## 特定帮助任务疑难解答

| 目标 | 操作 |
|---|---|
| 打开并搜索联机帮助。 | 选择“帮助 > Maya 帮助”(Help > Maya Help)或按 F1 键，然后在搜索栏中输入关键字。 |
| 查找界面中的工具或菜单项。 | 选择帮助 > 查找菜单(Help > Find Menu)。 系统将返回菜单项名称以及该菜单项所属的菜单和菜单集。 [界面概述](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-F4FCE554-1FA5-447A-8835-63EB43D2690B)是 Maya 界面的图像，其中包含所有主界面元素的名称和基本描述。通过它可链接至所描述的内容，以查找更多信息。 |
| 查找特定窗口或工具的帮助。 | 查找工具设置中的“帮助”(Help)菜单（而不是主“帮助”(Help)菜单）。 |
| 获取光标下有关操作的描述/说明。 | 查看[帮助行](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-AD137576-F1CF-4A62-A7DA-E0ECF6524D11)（左下角），或启用[帮助首选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-2B90FD26-20F6-4CF6-8A68-2DD4AD6CF334)中的“显示工具动画演示”(Display ToolClips)。 |
| 查找热键。 | [所有 Maya 热键](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-30CACC9D-8FBE-4B85-8A8F-C5ADF32DDD4E)列出了在 Maya 中可以使用的各个键盘快捷键。 |
| 查找技术文档。 | 您可以在[脚本(Scripting)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-1C6C0BC0-002C-4035-ADC7-97AD2F390190)主题（包括 [MEL](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-60178D44-9990-45B4-8B43-9429D54DF70E)、[Python](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C0F27A50-3DD6-454C-A4D1-9E3C44B3C990) 和 [Dash](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-94DA2210-6FF1-4993-8EB9-9A6D87562D35)）中访问此内容。 |
