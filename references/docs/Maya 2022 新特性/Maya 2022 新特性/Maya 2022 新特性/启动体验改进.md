# 启动体验改进

Maya 的启动体验已进行了多项改进，包括：

- 更快的启动和退出速度

- 启动时不再强行获得焦点

- 记住“输出窗口”(Output Window)的状态

- 能够从以前的安装复制特定首选项

- 信息更丰富的新初始屏幕

## 更快的启动和退出速度以及新的初始屏幕

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-WhatsNewPR/images/GUID-2107483F-4E6D-4D0A-B4FE-9171BA29FDA5.png) <!-- baize:img-hook downloaded=false reason="正文 507 字 ≥300，非承重" -->

已经进行了优化，大幅提高了 Maya 的启动和退出速度。在此期间，将显示一个新的初始屏幕，其中包含有关该过程中加载的内容的更多详细信息。

与以前不同，Maya 在启动期间不再显示无响应的 UI - UI 只有在完全可以交互之后**才**会显示。最后，Maya 在启动过程中不再从其他应用程序强行获得焦点，这样您就可以在等待时自由地在其他应用程序中操作。

## 新的复制首选项选项

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-WhatsNewPR/images/GUID-761538A1-E9CA-4346-9006-BA35F2FBF2CA.png) <!-- baize:img-hook downloaded=false reason="正文 507 字 ≥300，非承重" -->

与先前版本一样，Maya 允许您在首次启动时创建默认首选项，或将旧版 Maya 中的首选项复制到新版 Maya。现在，您还可以选择复制特定首选项，如工具架、热键等。

## “输出窗口”(Output Window)状态

Maya 现在将记住“输出窗口”(Output Window)的先前状态。因此，如果您在上一个会话中将其关闭，则在启动下一个会话时它将保持关闭状态。如果您喜欢旧行为，可以使用环境变量 MAYA_SHOW_OUTPUT_WINDOW 强制在每次启动时显示它。
