# 海洋沿地平线抖动

海洋似乎沿其地平线发生抖动或振动。如果发生这种情况，可以沿海洋地平线平滑或过滤闪烁像素。

沿其地平线过滤海洋

1. 在场景视图中，选择似乎沿其地平线发生抖动的海洋。

2. 在“属性编辑器”(Attribute Editor)中，选择“oceanShader”选项卡。

3. 在“海洋属性”(Ocean Attributes)区域中，增加“地平线过滤器”(Horizon Filter)，然后对海洋的模拟进行测试渲染。重复该步骤，直到沿海洋地平线的抖动消失。请参见[地平线过滤器](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-SimulationEffects/files/GUID-549B8D6D-0844-40A4-BA10-7B3180437686.htm#WS73099CC142F48755-3D114B7511841AEFA9F-5E50)。
