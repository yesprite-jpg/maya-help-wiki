# 重命名当前 UV 集选项(Rename Current UV Set options)

使用这些选项可设置在选择“UV > 重命名当前 UV 集”(UV > Rename Current UV Set)时发生的情况。

## 设置

#### 新 UV 集名称(New UV Set name)

键入要在该文本字段中切换的 UV 集的名称。
