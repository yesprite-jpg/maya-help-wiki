# “UV 编辑器”(UV Editor)  的“切割/缝合”(Cut/Sew)菜单

该菜单包含与创建和缝合 UV 接缝有关的各种操作。此处列出的许多命令也可以在“UV 工具包”(UV Toolkit)中找到。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)。

#### 自动接缝(Auto Seams)

允许 Maya 自动选择或切割选定对象/UV 壳上的边，以形成适当的接缝。请参见[自动接缝(Auto Seams)选项](../../../../../../多边形建模/多边形建模/多边形建模参考/“建模”%28Modeling%29菜单集/UV%20菜单/自动接缝%28Auto%20Seams%29.md)。

#### 创建 UV 壳(Create UV Shell)

将当前选定的组件（顶点、UV、边或面）转化为围绕选定周长的一系列边，然后沿着周长切割，创建一个新的 UV 壳。请参见[创建 UV 壳](../../../../编辑%20UV/创建%20UV%20壳.md)。

#### 创建壳(栅格)(Create Shell (Grid))

通过沿当前选择的边周长切割，然后将 UV 均匀地分布到 0 到 1 的 UV 栅格空间，创建归一化的方形 UV 壳。

#### 切割(Cut)

分离选定边。有关详细信息，请参见[分离和附加 UV](../../../../编辑%20UV/分离和附加%20UV.md)。

#### 缝合(Sew)

焊接选定边。有关详细信息，请参见[分离和附加 UV](../../../../编辑%20UV/分离和附加%20UV.md)。

#### 分割(Split)

沿连接到选定 UV 点的边将 UV 彼此分离，从而创建边界。

#### 合并(Merge)

将单独的 UV 壳合并到一起。请参见[合并 UV (Merge UVs)选项](../../../../../../多边形建模/多边形建模/多边形建模参考/“建模”%28Modeling%29菜单集/UV%20菜单/合并%20UV%20选项%28Merge%20UVs%20options%29.md)。

#### 移动并缝合(Move and Sew)

沿选定边界附加 UV，并在编辑器视图中一起移动它们。请参见[移动并缝合 UV 边(Move and Sew UV Edges)选项](“UV%20编辑器”%28UV%20Editor%29%20的“切割缝合”%28CutSew%29菜单/移动并缝合%20UV%20边选项%28Move%20and%20Sew%20UV%20Edges%20options%29.md)。

#### 缝合到一起(Stitch Together)

通过在指定方向上朝一个壳移动另一个壳，将两条选定边缝合在一起。
