# 复制到新 UV 集选项(Copy into New UV Set options)

使用这些选项可设置在选择“UV > 将 UV 复制到 UV 集 > 复制到新 UV 集”(UV > Copy UVs to UV Set > Copy into New UV Set)时发生的情况。

## 设置

#### 新 UV 集名称(New UV Set name)

输入要将当前 UV 集复制到的 UV 集名称。
