# 平滑 UV 工具(Smooth UV Tool)

使用该选项可以按交互方式展开或松弛 UV。选择一组 UV，然后将“展开”(Unfold)或“松弛”(Relax)控件拖动到右侧。

若要打开“平滑 UV 工具”(Smooth UV Tool)，请从“UV 编辑器”(UV Editor)菜单中选择“工具 > 平滑”(Tools > Smooth)。

## 平滑设置

#### 固定边界(Pin Borders)

如果启用该选项，那么移动“展开”(Unfold)或“松弛”(Relax)控件时，选定 UV 集的边界 UV 将不会移动。

#### 空间(Space)

使用该选项可以调整在“UV 空间”(UV Space)或“世界”(World)空间中是“展开”(Unfold)还是“松弛”(Relax) UV。
