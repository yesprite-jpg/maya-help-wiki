# “UV 编辑器”(UV Editor)  的“修改”(Modify)菜单

该菜单包含可对当前选定 UV 执行的各种操作。此处列出的许多命令也可以在“UV 工具包”(UV Toolkit)中找到。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)。

#### 对齐(Align)

对齐选定 UV 的位置。请参见[对齐 UV 选项(Align UVs options)](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/对齐%20UV%20选项%28Align%20UVs%20options%29.md)。

#### 循环(Cycle)

旋转选定多边形的 U 值和 V 值。

#### 分布 UV(Distribute UVs)

跨所选轴均匀间隔 UV。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“变换 > 分布”(Transform > Distribute)。

#### 分布距离(Distribution Distance)

指定 UV 相距多远排列。

#### 分布方向(Distribute Along)

指定沿哪些轴均匀分布选定 UV。

#### 翻转(Flip)

翻转选定 UV 的位置。请参见[翻转 UV 选项(Flip UVs options)](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/翻转%20UV%20选项%28Flip%20UVs%20options%29.md)。

#### 线性对齐

沿穿过所有选定 UV 的线性趋势线对齐这些 UV。

#### 匹配栅格(Match Grid)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“匹配栅格”(Match Grid)。

#### 匹配 UV(Match UVs)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“匹配 UV”(Match UVs)。

#### 归一化(Normalize)

将选定面的 UV 缩放到 0 到 1 纹理空间内。请参见[归一化 UV 选项(Normalize UVs options)](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/归一化%20UV%20选项%28Normalize%20UVs%20options%29.md)。

#### 旋转(Rotate)

围绕枢轴旋转选定 UV。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“变换 > 旋转”(Transform > Rotate)。

#### 对称(Symmetrize)

选择该选项后，选择要绕其对称的边。然后，这将一次性使当前选择的所有 UV 对称。请参见[对称 UV 工具](../../../UV%20工具/对称%20UV%20工具%28Symmetrize%20UV%20Tool%29.md)。

#### 单位化(Unitize)

将选定面的 UV 放置到 0 到 1 纹理空间的边界上。“单位化”(Unitize)通常用于映射复杂的弯曲曲面（如管和管道）。它获取 UV 壳的每个面、将其分离，然后再将其归一化为 0 到 1 的纹理空间。请参见[单位化 UV 选项(Unitize UVs options)](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/单位化%20UV%20选项%28Unitize%20UVs%20options%29.md)。

#### 分布壳(Distribute Shells)

在所选方向上分布选定 UV 壳，同时确保 UV 壳之间相隔一定数量的单位。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“排列和排布 > 分布”(Arrange and Layout > Distribute)。

#### 方向(Direction)

指定壳的分布方向。

#### 壳填充(Shell Padding)

指定要在壳之间保留的空间大小。

#### 聚集壳(Gather Shells)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“聚集壳”(Gather Shells)。

#### 排布(Layout)

根据“排布 UV”(Layout UVs)选项框中的设置，尝试将 UV 壳重新排列到一个更干净的布局中。请参见[排布 UV (Layout UVs)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/布局%20UV%20选项%28Layout%20UVs%20options%29.md)。

#### 排布方向(Layout Along)

自动排列 UV 壳以最大限度地使用指定方向上的 UV 空间。

#### 定向壳(Orient Shells)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“定向壳”(Orient Shells)。

#### 将壳定向到边(Orient Shells to Edges)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“将壳定向到边”(Orient Shells to Edges)。

#### 随机化壳(Randomize Shells)

随机化 UV 壳平移、旋转和缩放。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“随机化壳”(Randomize Shells)。

#### 平移(Translate)

指定壳可以随机移动的轴以及每个壳的最大距离。

#### 旋转(Rotate)

指定壳可以随机旋转的方向以及最大角度。

#### 比例(Scale)

指定壳可以随机缩放的方向以及最大数量（以其当前大小的百分比表示）。

#### 捕捉和堆叠(Snap and Stack)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“捕捉和堆叠”(Snap & Stack)。

#### 捕捉到一起(Snap Together)

通过使选定 UV 相互重叠，将一个 UV 壳移动到另一个 UV 壳。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“捕捉到一起”(Snap Together)。

#### 堆叠壳(Stack Shells)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“堆叠壳”(Stack Shells)。

#### 堆叠类似的壳(Stack Similar Shells)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“堆叠类似”(Stack Similar)。

#### 取消堆叠壳(Unstack Shells)

移动所有选定 UV 壳，使其不再重叠，同时保持相互靠近。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“取消堆叠壳”(Unstack Shells)。

#### 翻转已反转 UV 壳(Flip reversed UV shells)

逆时针反转任何壳的缠绕顺序。

#### 映射边界(Map Border)

将 UV 边界移动到 0 到 +1 纹理空间的边上。请参见[映射 UV 边界(Map UV Border)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/“映射边界”%28Map%20Border%29选项.md)。

**注**

在多个壳上映射 UV 时会将单独映射每个壳。

#### 优化(Optimize)

展开所有 UV，以使它们更易于使用。请参见[优化 UV (Optimize UVs)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/优化%20UV%20选项%28Optimize%20UVs%20options%29.md)。

#### 拉直边界(Straighten Border)

解开 UV 纹理壳的边界，如围绕自身循环的边。请参见[拉直 UV 边界(Straighten UV Border)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/“拉直边界”%28Straighten%20Border%29选项.md)。

#### 拉直壳(Straighten Shell)

请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“拉直壳”(Straighten Shell)。

#### 拉直 UV(Straighten UVs)

将彼此共同位于特定角度内的 UV 与相邻 UV 对齐。请参见 [UV 编辑器概述](../../../../“UV%20编辑器”%28UV%20Editor%29概述.md)中的“拉直 UV”(Straighten UVs)。

#### 拉直方向(Straighten Along)

指定要沿哪些轴拉直。

#### 角度(Angle)

指定要拉直的相邻 UV 之间允许的最大角度。

#### 展开(Unfold)

该选项可用于为多边形对象展开 UV 网格，并且会避免您创建重叠 UV。请参见[“展开 UV”(Unfold UVs)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/展开%20UV%20选项%28Unfold%20UVs%20options%29.md)。

#### 扭曲图像(Warp Image)

通过比较单个多边形网格上的两个 UV 集来修改纹理图像，并产生新的位图图像。请参见[扭曲图像 UV (Warp Image UVs)选项](“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/扭曲图像%20UV%20选项%28Warp%20Image%20UVs%20Options%29.md)。
