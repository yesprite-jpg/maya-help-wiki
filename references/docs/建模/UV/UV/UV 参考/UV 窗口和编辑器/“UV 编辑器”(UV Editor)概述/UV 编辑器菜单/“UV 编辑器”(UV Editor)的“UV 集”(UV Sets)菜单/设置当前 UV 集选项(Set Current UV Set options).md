# 设置当前 UV 集选项(Set Current UV Set options)

使用这些选项可查看在选择“UV > 设置当前 UV 集”(UV > Set Current UV Set)时发生的情况。

## 设置

#### UV 集名称(UV Set name)

在此文本字段中键入要切换到的 UV 集的名称。
