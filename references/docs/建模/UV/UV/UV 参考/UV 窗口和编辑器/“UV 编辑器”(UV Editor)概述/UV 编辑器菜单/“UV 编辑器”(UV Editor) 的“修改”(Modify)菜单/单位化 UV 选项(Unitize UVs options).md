# 单位化 UV 选项(Unitize UVs options)

使用这些选项可设置在选择“UV > 单位化”(UV > Unitize)时发生的情况。

## 设置

#### 创建新 UV 集(Create new UV Set)

启用此选项可以在对象上自动创建新 UV 集，以容纳单位化的 UV。在“UV 集名称”(UV Set name)框中输入新 UV 集的名称。
