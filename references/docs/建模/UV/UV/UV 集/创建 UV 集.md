# 创建 UV 集

UV 集最快的创建方法就是映射 UV。映射 UV 时，应打开选项窗口，然后启用“创建新 UV 集”(Create New UV Set)并在“UV 集名称”(UV Set Name)框中键入名称。例如，如果创建两个平面映射（一个从顶部映射，一个从侧边映射），那么每次映射都需键入新的 UV 集名称。

或者可以在开始时使用空 UV 集，然后创建 UV。

创建空 UV 集

1. 选择对象，然后打开 [UV 编辑器(UV Editor)](../“UV%20编辑器”%28UV%20Editor%29概述.md)。

2. 在“UV 编辑器”(UV Editor)菜单中，选择“UV 集 > 创建空 UV 集”(UV Sets > Create Empty UV Set) > ![图：在“UV 编辑器”(UV Editor)菜单中，选择“UV 集 创建空 UV 集”(UV Sets Create Emp…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 421 字 ≥300，非承重" -->。将显示[创建 UV 集选项(Create UV Set options)](../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29的“UV%20集”%28UV%20Sets%29菜单/创建%20UV%20集选项%28Create%20UV%20Set%20options%29.md)窗口。

3. 在“创建 UV 集名称”(Create UV Set Name)框中，键入空集的名称并单击“创建”(Create)。

4. 选择新的 UV 集（请参见[在 UV 集之间切换](在%20UV%20集之间切换.md)）。

5. 使用其中一种映射操作创建 UV，或通过复制创建 UV。
