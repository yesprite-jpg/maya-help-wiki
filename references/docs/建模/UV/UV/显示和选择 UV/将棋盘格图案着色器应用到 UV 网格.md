# 将棋盘格图案着色器应用到 UV 网格

应用棋盘格图案着色器

1. 在“UV 编辑器”(UV Editor)工具栏中，单击棋盘格图案着色器图标 ![图：在“UV 编辑器”(UV Editor)工具栏中，单击棋盘格图案着色器图标 ，或转到“纹理 棋盘格贴图”(Texture…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96307EC3-7425-4FA5-BEEB-40BAF69406D6.png) <!-- baize:img-hook downloaded=false reason="正文 402 字 ≥300，非承重" -->，或转到“纹理 > 棋盘格贴图”(Textures > Checker Map)。

  棋盘格图案着色器将应用于 UV 网格的曲面，并显示在 UV 编辑器中栅格的后面。您可以在[棋盘格贴图(Checker Map)选项](../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29的“纹理”%28Textures%29菜单.md)中从简单的黑白着色器切换到颜色渐变。颜色渐变使您可以更轻松地查找 UV 网格上的平铺。

  **注**

  提示：

  如果棋盘格图案着色器未显示在网格中，请确保在

  “渲染器”(Renderer)

  面板菜单中选择了

  “Viewport 2.0”

  。

  在以下示例中，棋盘格的大小不一致，这表示某些区域的纹理被拉伸。

  ![图：在“UV 编辑器”(UV Editor)工具栏中，单击棋盘格图案着色器图标 ，或转到“纹理 棋盘格贴图”(Texture…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-84E18D8E-40D8-4EF3-929F-C19CA538E4CC.png) <!-- baize:img-hook downloaded=false reason="正文 402 字 ≥300，非承重" -->

  **注**

  棋盘格图案着色器并不影响对象的原始材质、着色器和纹理指定。

2. 要禁用棋盘格着色器，请执行以下操作之一：

  - 关闭 UV 编辑器。

  - 单击棋盘格图案着色器图标。

  该网格的原始材质、着色器和纹理指定会重新显示在 UV 网格上和 UV 编辑器中。
