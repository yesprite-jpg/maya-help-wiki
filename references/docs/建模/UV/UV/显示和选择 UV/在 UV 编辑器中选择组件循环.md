# 在 UV 编辑器中选择组件循环

选择 UV 循环边

UV 循环边是由 UV 边界包围的循环边，而不是由边边界包围的循环边。

1. 双击某个边。

  整个循环边将被选中。

选择部分顶点/面/UV/循环边

1. 选择一个组件（顶点、面、UV 或边）

2. 按住 Shift 键并双击不相邻的组件。

  将选定部分循环。

取消选择顶点/面/UV/循环边

1. 按住 Ctrl 键并单击选定组件。

2. 执行下列操作之一：

  - 按住 Ctrl 键并双击相邻组件可取消选择整个循环。

  - 按住 Ctrl 键并双击不相邻的组件可取消选择部分循环。
