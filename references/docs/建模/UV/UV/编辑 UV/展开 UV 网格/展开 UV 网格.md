# 展开 UV 网格

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-E4ACBD72-11A1-4A68-925B-A06D1DEEAE01.gif) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" -->

展开 UV 网格是指切割 UV 网格中的接缝，然后沿该接缝展开的过程。

展开 UV 网格

1. [准备展开 UV 网格](准备%20UV%20网格以进行展开.md)。

2. 在“UV 编辑器”(UV Editor)中，选择网格上要展开的 UV。

3. 在“UV 工具包”(UV Toolkit)中，选择“展开 > 展开”(Unfold > Unfold)（或者，在菜单栏中选择“UV > 展开”(UV > Unfold) > ![图：在“UV 工具包”(UV Toolkit)中，选择“展开 展开”(Unfold Unfold)（或者，在菜单栏中选择“U…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" -->来自定义选项）。

4. 在[“展开 UV 选项”(Unfold UVs options)](../../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/展开%20UV%20选项%28Unfold%20UVs%20options%29.md)窗口中。特别是：

  - 如果将“方法”(Method)设置为“Unfold3D”，任何未选定的 UV 均会自动固定。

  - 如果将“方法”(Method)设置为“旧版”(Legacy)，则仅固定选定 UV。

5. 单击“应用并关闭”(Apply and Close)。

6. 如果要停止展开操作，请按 Esc 键。

或者，您可以使用“展开工具”(Unfold Tool)（在“UV 工具包”(UV Toolkit)中选择“展开 > 展开工具”(Unfold > Unfold Tool)，或在菜单栏中选择“工具 > 展开”(Tools > Unfold)）以交互方式在要展开的区域上绘制。这仅适用于 Unfold3D 方法。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-12BA58C6-1468-4173-8D88-542239693089.gif) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" -->

**注**

在

“工具设置”(Tool Settings)

中，可以快速在

“展开”(Unfold)

与

“优化工具”(Optimize Tool)

之间切换。

**注**

您可以

固定 UV

，防止它们在展开操作期间移动。
