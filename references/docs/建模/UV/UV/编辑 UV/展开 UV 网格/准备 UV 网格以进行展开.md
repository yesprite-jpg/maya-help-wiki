# 准备 UV 网格以进行展开

准备 UV 网格以进行展开

1. 确保您的多边形模型具有 UV。

  执行初始 UV 映射操作，以生成 UV 网格。您可以使用任何 UV 映射技术创建 UV。请参见[映射 UV](../../映射%20UV.md)。

2. 执行网格清理，特别是对于非流形几何体更是如此。从[网格 > 清理(Mesh > Cleanup)](../../../../多边形建模/多边形建模/多边形建模参考/“建模”%28Modeling%29菜单集/“网格”%28Mesh%29菜单/清理选项%28Cleanup%20Options%29.md)中或者通过在[展开选项](../../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/展开%20UV%20选项%28Unfold%20UVs%20options%29.md)中激活“修复非流形几何体”(Fix Non-Manifold Geometry)选项，可以执行此操作。

3. 应用棋盘格图案着色器。请参见[将棋盘格图案着色器应用到 UV 网格](../../显示和选择%20UV/将棋盘格图案着色器应用到%20UV%20网格.md)。

  当棋盘格图案看起来很平均时，表明 UV 扩散均匀。为避免在应用纹理时纹理扭曲，均匀扩散 UV 很重要。在某些情况下，您可能需要试用不同的映射，以便在开始就获得最佳的基础。

4. 通过手动[切割 UV 网格上的边](../分离和附加%20UV.md)或者通过使用[自动接缝(Auto Seams)](../../../../多边形建模/多边形建模/多边形建模参考/“建模”%28Modeling%29菜单集/UV%20菜单/自动接缝%28Auto%20Seams%29.md)命令，对 UV 网格执行边切割。

  预计该切割将导致沿边的纹理不一致，并找到模型上可见性最差的边。例如，在角色的手臂下或腿的背面上进行切割。

  对所做的切割感到满意之后，可以准备展开 UV 壳。请参见[展开 UV 网格](展开%20UV%20网格.md)。
