# 使用 UV 编辑器栅格

UV 编辑器具有栅格功能，该功能允许您在移动、旋转或缩放 UV 时准确控制它们的位置和间距。

| 目标 | 操作 |
|---|---|
| 显示或隐藏栅格。 | 在“UV 编辑器”(UV Editor)中，单击工具栏上的“切换栅格”(Toggle Grid)按钮，或者选择“视图 > 栅格”(View > Grid) (![图：在“UV 编辑器”(UV Editor)中，单击工具栏上的“切换栅格”(Toggle Grid)按钮，或者选择“视图 栅…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-7748D20F-FF5B-4BCE-872D-4B9D665DB74F.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" -->)。 |
| 更改栅格。 | 在“UV 编辑器”(UV Editor)中，选择“视图 > 栅格”(View > Grid) > ![图：在“UV 编辑器”(UV Editor)中，选择“视图 栅格”(View Grid) ()。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" --> (![图：在“UV 编辑器”(UV Editor)中，选择“视图 栅格”(View Grid) ()。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-7748D20F-FF5B-4BCE-872D-4B9D665DB74F.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" -->)。 有关详细信息，请参见[“UV 编辑器”(UV Editor)的“视图”(View)菜单](../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29的“视图”%28View%29菜单.md)。 |
| 在移动时将 UV 捕捉到栅格。 | 使用栅格捕捉（按住 X 键并移动 UV）。 |
| 在移动时更改 UV 捕捉方式。 | 双击“移动”(Move)工具以打开其选项面板。 使用“保留组件间距”(Retain Component Spacing)选项控制 UV 捕捉方式： 禁用时，所有选定的 UV 将捕捉到同一点。 启用时，选定的 UV 在移动时将保留它们之间的相对位置。 |
| 在移动时将 UV 捕捉到像素。 | 在“UV 编辑器”(UV Editor)中，单击工具栏中的“切换捕捉到像素”(Toggle Snap to Pixel)按钮，或者选择“图像 > 像素捕捉”(Image > Pixel Snap) > ![图：在“UV 编辑器”(UV Editor)中，单击工具栏中的“切换捕捉到像素”(Toggle Snap to Pixel)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" -->。 (![图：在“UV 编辑器”(UV Editor)中，单击工具栏中的“切换捕捉到像素”(Toggle Snap to Pixel)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-960DB20F-FAE6-4369-8A4C-0D5A2F5040DA.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" -->) 在选项中，选择是否会捕捉到像素角点或像素中心。 |
| 一次性将多个 UV 捕捉到栅格。 | 选择 UV，然后在“UV 工具包”(UV Toolkit)中选择“对齐和捕捉 > 匹配栅格”(Align & Snap > Match Grid) (![图：选择 UV，然后在“UV 工具包”(UV Toolkit)中选择“对齐和捕捉 匹配栅格”(Align & Snap Ma…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-F6F196DC-B6A9-458E-92C0-BEA2EAC9F888.png) <!-- baize:img-hook downloaded=false reason="正文 701 字 ≥300，非承重" -->)，或者在菜单中选择“修改 > 栅格”(Modify > Grid)。 注： 您需要确保[栅格 UV 选项](../UV%20参考/UV%20窗口和编辑器/“UV%20编辑器”%28UV%20Editor%29概述/UV%20编辑器菜单/“UV%20编辑器”%28UV%20Editor%29%20的“修改”%28Modify%29菜单/“匹配栅格”%28Match%20Grid%29选项.md)的“U 向栅格”(Grid U)和“V 向栅格”(Grid V)值与每 UV 平方的栅格空间数匹配，才能使 UV 与所示栅格精确匹配。 |
