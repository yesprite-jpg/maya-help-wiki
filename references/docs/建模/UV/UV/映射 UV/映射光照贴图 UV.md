# 映射光照贴图 UV

光照贴图是一种曲面缓存，其中各个曲面点处的亮度将预先计算并存储在纹理贴图中（方式与纹理贴图、法线贴图或置换贴图大致相同）。其计算量比实时计算照明更少。

从现有 UV 贴图创建光照贴图

1. [复制](../UV%20集/复制、重命名或删除%20UV%20集.md)现有贴图。

2. （可选）为整个网格设置均匀的 Texel 密度（除非您特别希望某些区域的分辨率更高或更低）。有关详细信息，请参见 [Texel 密度工具](../“UV%20编辑器”%28UV%20Editor%29概述.md)。

3. 使用[取消堆叠壳(Unstack Shells)](../“UV%20编辑器”%28UV%20Editor%29概述.md)命令确保无壳重叠。

  如果最终 UV 仍然重叠，请执行边切割使其变小，然后再次取消堆叠（确保壳间距适当）。

布局现在即可用于光照贴图。
