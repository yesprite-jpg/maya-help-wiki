# 多边形建模概述

可以采用多种方法在 Maya 中创建 3D 多边形模型：

- 基本体是可以在 Maya 中创建的三维几何形状。可用的基本体形状包括球体、立方体、圆柱体、圆锥体、平面和许多其他形状。可以修改这些基本基本体的属性，以使其更复杂或不那么复杂。此外，您还可以使用[建模工具包](多边形建模参考/多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)中的各种工具分割、挤出、合并或删除基本体多边形网格上的各种组件，以修改基本体的形状。许多 3D 建模者开始使用多边形基本体作为模型的起始点。该方法称为基本体向上建模。

- 使用[创建多边形工具(Create Polygon Tool)](多边形选择和创建/绘制多边形.md)或[四边形绘制工具(Quad Draw Tool)](多边形建模参考/多边形建模工具/四边形绘制工具.md)，可以创建单个多边形。通过这些工具，可以将单个顶点放置在场景视图中，以便定义单个多边形面的形状。稍后，可以进一步分割或挤出这些面来构建多边形网格。当您需要密切匹配特定形状或轮廓时，该多边形创建方法非常有用。例如，需要为动画徽标序列建立特定 3D 徽标类型的模型时，或需要使用作为引用导入到图像平面之上的位图图像跟踪 2D 图像轮廓时。

- 也可以通过使用“修改”(Modify)菜单下的“转化”(Convert)功能，转化现有 NURBS 或细分曲面模型的方式创建多边形。
