# 平面和非平面多边形

在下列情况下多边形面为平面:

- 它的所有顶点位于一个特定平面中。例如，一个三角形面始终为平面，因为其三个点定义一个平面。

在下列情况下多边形面为非平面：

- 它具有三个以上顶点，并且其中一个或多个顶点不在同一平面中。当多边形网格由四边形或 n 边形组成，则可能为非平面多边形面。

  ![图：它具有三个以上顶点，并且其中一个或多个顶点不在同一平面中。当多边形网格由四边形或 n 边形组成，则可能为非平面多边形面。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-752F96F6-89E4-4ACB-8E9D-B25034EB01FE.png) <!-- baize:img-hook downloaded=false reason="正文 575 字 ≥300，非承重" -->

尽可能尝试在多边形网格上创建平面多边形面。在最终图像中或导出到一个交互式视频游戏控制台时，非平面多边形面可能会错误渲染。例如，一个可视化着色线或不需要的钉形可能会出现在多边形网格上，其中已被细分用于渲染，因为它是非平面。

下列功能有助于您避免多边形网格中出现非平面多边形面：

- 若要避免创建非平面多边形，使用[网格工具 > 创建多边形工具(Mesh Tools > Create Polygon Tool)](多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/创建多边形工具选项%28Create%20Polygon%20Tool%20Options%29.md)和[网格工具 > 附加到多边形工具(Mesh Tools > Append to Polygon Tool)](多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/附加到多边形工具选项%28Append%20to%20Polygon%20Tool%20Options%29.md)功能时，可以使用“保持新面为平面”(Keep New Faces Planar)选项。

- 若要更正非平面多边形面，可以使用[多切割工具(Multi-Cut Tool)](多边形建模参考/多边形建模工具/多切割工具.md)将其分割为平面三角形或重新拓扑面，以便更好地处理弯曲点。

  ![图：若要更正非平面多边形面，可以使用多切割工具(Multi-Cut Tool)将其分割为平面三角形或重新拓扑面，以便更好地处…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-9C75D6A4-872A-49E3-A89A-842E7A20CC61.png) <!-- baize:img-hook downloaded=false reason="正文 575 字 ≥300，非承重" -->

- 若要直观地标识非平面多边形面，可以通过选择“显示 > 多边形 > 非平面面”(Display > Polygons > Non-planar Faces)来自定义多边形的显示。
