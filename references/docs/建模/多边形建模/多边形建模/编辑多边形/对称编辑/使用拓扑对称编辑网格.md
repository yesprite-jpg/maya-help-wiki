# 使用拓扑对称编辑网格

拓扑对称使用模型的拓扑查找对称组件。若要在网格上使用拓扑对称，其每一半上的面数必须相等，且某个边必须在网格的中心线下延伸，没有横跨中心线的面。

在网格不是完美对称时，可以使用部分拓扑对称编辑对称网格的各个部分，即使网格不是整体对称也可以这样做。请参见[使用部分拓扑对称编辑网格](使用部分拓扑对称编辑网格.md)。

使用拓扑对称编辑网格

1. 请确保模型的拓扑对称并且为非流形。（当每侧的面数量相等时，模型就是拓扑对称的。）

2. 选择模型接缝上的边。

  **注**

  重要：

  选择不包括在编辑中的接缝边。修改任何接缝边都会禁用对称。

  ![图：选择模型接缝上的边。 重要： 选择不包括在编辑中的接缝边。修改任何接缝边都会禁用对称。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-0422263F-2B1E-4EB1-BD13-68B5DE62EAD3.png) <!-- baize:img-hook downloaded=false reason="正文 308 字 ≥300，非承重" -->

3. 激活拓扑对称。请参见[激活或取消激活对称](激活或取消激活对称.md)。

4. 在网格的一侧进行选择，并对所选内容进行编辑。

  您所做的更改也将应用于网格的另一侧。
