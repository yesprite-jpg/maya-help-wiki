# 变换多边形组件

通过使用[工具箱](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B345E162-0149-4E09-AC98-48DCFC227F33)（“移动”(Move)、“旋转”(Rotate)、“缩放”(Scale)）中的工具，可以变换多边形组件（顶点、边、面、UV）。有关如何变换组件的详细信息，请参见[变换对象和组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9622730D-3D21-451C-8BEE-E01BCC979F91)。

变换组件时，可以使用不同的方法更改组件移动的方式。

| 方式 | 示例： |
|---|---|
| 一起：通过使用“移动”(Move)、“旋转”(Rotate)或“缩放”(Scale)工具，可一起变换所有选定组件。有关详细信息，请参见[变换对象和组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9622730D-3D21-451C-8BEE-E01BCC979F91)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-4AF4A4B6-1CFA-46CC-8EA0-3023E577544F.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 单独：通过使用参考的局部帧，可以较小的组或分别变换选定组件。有关详细信息，请参见[独立变换多个组件](变换多边形组件/独立变换多个组件.md)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-FFD4C2D4-0679-473E-B9C4-23B81744743A.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 滑动：沿边或曲面滑动组件。有关详细信息，请参见[沿边滑动多边形组件](变换多边形组件/沿边滑动多边形组件.md)或[沿曲面移动多边形组件](变换多边形组件/沿曲面移动多边形组件.md)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-B01E2B2F-36AD-4444-BBD7-D3AFCF355076.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 沿自定义枢轴：变换组件时，可以暂时更改枢轴点以影响组件移动的方式。有关详细信息，请参见[更改枢轴点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-150B390E-840B-4FE3-B8E9-8DEBCE7CEC97)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-DE1E7DEB-0E85-403E-A713-30054C304C38.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 一致：变换组件，使其与另一个多边形曲面保持一致。有关详细信息，请参见[使顶点与曲面保持一致](变换多边形组件/使顶点与曲面保持一致.md)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-8B3A9DC6-14DA-466C-B24D-B6A05197B96F.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 对称：镜像组件将沿对称线进行变换。有关详细信息，请参见[对称编辑](对称编辑.md)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-CD00F63E-1119-4107-8B6E-5D287FD165F5.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
| 软选择：使用衰减变换组件。有关详细信息，请参见[使用衰减移动组件](变换多边形组件/使用衰减移动组件.md)。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-748D4ADE-4C37-4FFF-B502-AFA733EC4865.gif) <!-- baize:img-hook downloaded=false reason="正文 451 字 ≥300，非承重" --> |
