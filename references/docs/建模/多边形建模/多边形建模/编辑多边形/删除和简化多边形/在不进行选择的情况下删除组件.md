# 在不进行选择的情况下删除组件

在不进行选择的情况下删除组件

1. 可以一个组件模式进行选择。请参见[选择多边形组件](../../多边形选择和创建/选择多边形组件.md)。

2. 将光标移动到网格上。

  Maya 会亮显最近的组件。

3. 按 Delete 键或 Backspace 键删除该组件。
