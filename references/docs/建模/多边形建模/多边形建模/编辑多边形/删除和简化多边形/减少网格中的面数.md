# 减少网格中的面数

“减少”(Reduce)功能可以自动按所指定的总体多边形计数百分比、目标顶点数或目标三角形数，减少网格中的多边形数。作为减小过程的一部分，“减少”(Reduce)功能也尝试保留原始形状。

需要减少多边形网格中的多边形总数或要减少网格中特定区域的多边形的数目时，减少多边形数非常有用。例如，在交互式视频游戏中，可能需要以较少的多边形数量为高分辨率多边形模型创建低分辨率复本，用于不同级别的细节显示目的。又例如，要简化经过 3D 激光扫描的详细物理模型的多边形数据集。

总的来说，在场景视图设置动画时，被简化的多边形模型数据会减少，且交互式性能会改进。

减少多边形通过创建的“polyReduce”节点控制。通过此功能，可以尝试不同量的融合减少，并在希望多边形网格恢复为其原始减少前状态时将所有减少完全删除。

也可以使用 Artisan 绘画功能来指定多边形网格中希望多边形减少的区域。使用“绘制减少权重工具”(Paint Reduce Weights Tool)绘制要减少的区域，可以更精确地控制多边形减少以及与减少较少区域的融合。

3. 设置减少百分比、目标顶点数或目标三角形数并启用“保持原始”(Keep original)，然后单击“减少”(Reduce)。

## 使用“网格”(Mesh) >“减少”(Reduce)的注意事项

- 不能在减少的版本上绘制减少权重。必须使用“保持原始”(Keep original)选项并在原始对象上绘制。

  如果尝试在减少的版本上绘制减少权重，Maya 将自动选择原始版本。

- 如果选择减少面（而不是减少整个网格），毗邻选择面的面可能会移动或也被减少。

  可通过在减少前将多边形从网格中提取出来来避免此效果。启用“网格边界”(Mesh borders)选项即可稍后重新附加提取的网格。

- 当绘制减少权重时，“绘制属性工具”(Paint Attributes Tool)的默认设置是仅在完成一个笔划后更新。这是因为对于大网格减少操作会花费较多时间。

  如果希望在绘制时更新减少的版本，请选择“修改 > 绘制属性工具”(Modify > Paint Attributes Tool) > ![图：如果希望在绘制时更新减少的版本，请选择“修改 绘制属性工具”(Modify Paint Attributes Tool)…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1941 字 ≥300，非承重" --> ，然后在[“绘制属性工具”(Paint Attributes Tool)选项](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8539DC98-B8EC-4C8D-B990-BD2212A5B144)中打开“笔划”(Stroke)区域，并启用“持续更新”(Update continuously)。

- 减少权重是一种偏移，而不是绝对控制。在某些极端情况下，绘制为白色但并不需要的多边形，仍将被减小以在其他位置保持形状。

- “减少”(Reduce)适用于四边形和 n 边多边形，但是，非平面多边形可能会变形和可能不会减少。

- “保留四边形”(Preserve quads)选项在某些情况会产生扭曲效果。当发生这种情况时，请减少“保留四边形”(Preserve quads)滑块值。

- 如果在绘制减少权重时想要将某个区域还原到其原始状态，可以撤销绘制笔划或用为网格整体应用黑色即可。

- 将“减少选项”(Reduce Options)的“功能保留”(Feature Preservation)区域中的任何选项设置为 1.0 可确保这些组件不会因减少而改变。这可用于准确保留曲面会合的边界边。

- “减少”(Reduce)功能会保留拓扑，因此，在减少多边形的数量之前，应先清理具有无关小控制柄的已扫描网格数据。
