# 清理、简化或验证网格

“清理”(Cleanup)功能支持从多边形网格中移除不需要的几何体（例如，区域为零的面或长度为零的边）。也可以细分在 Maya 内有效、但在游戏控制台中无效的面（如凹面或带洞面）。

**注**

提示：

在执行网格清理之前先选择

“移除隔离的组件”(Remove Isolated Components)

选项，可移除在建模操作期间创建的孤立组件。

**注**

由于

“清理”(Cleanup)

功能可以合并顶点并收拢零长度边，因此可能会出现

“清理”(Cleanup)

功能输出非流形几何体的情况。如果设定

“清理”(Cleanup)

选项以层叠方式在网格上执行多个清理操作时，则会出现这种情况。如有可能出现，建议多次运行

“清理”(Cleanup)

功能，并且仅在最后一次迭代中启用

“移除几何体”(Remove Geometry)

区域中的

“非流形几何体”(Non-Manifold Geometry)

选项。

清理多边形网格

1. 选择要清理的多边形网格。

2. 选择网格 > 清理(Mesh > Cleanup)。
