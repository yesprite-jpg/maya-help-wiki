# 插入循环边

通过“插入循环边工具”(Insert Edge Loop Tool)（在“建模 > 网格工具”(Modeling > Mesh Tools)菜单中），可以选择多个多边形面，然后沿着多边形网格上的全部或部分环形边来分割这些多边形面。当要对多边形网格的大片区域添加详细信息，或者要沿着用户定义的路径插入边时，此项会很有用。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-03C5BA9C-9F0E-4A83-86FE-ED82DA42E446.gif) <!-- baize:img-hook downloaded=false reason="正文 915 字 ≥300，非承重" -->

有关环形边的描述，请参见[选择环形边](../../../多边形选择和创建/选择多边形组件/选择环形边.md)。

有关插入简单循环边的快捷方法，请参见[使用四边形绘制插入循环边](../../../重新拓扑/使用“四边形绘制”%28Quad%20Draw%29手动创建或重新拓扑网格/使用四边形绘制插入循环边.md)和[使用多切割工具插入循环边](通过多切割工具分割多边形/使用多切割工具插入循环边.md)。

当插入循环边时，就意味着要分割与选定环形边关联的多边形面。通过“插入循环边工具”(Insert Edge Loop Tool)，您可以沿着整个、部分或多方向环形边插入一个或多个循环边。

## “插入循环边工具”(Insert Edge Loop Tool)注释

可以使用标记菜单，在“插入循环边工具”(Insert Edge Loop Tool)处于活动状态时，打开或关闭该工具的很多选项。这样您无需重新打开工具选项窗口即可继续工作，有助于工作流程的持续进行。

在“插入循环边工具”(Insert Edge Loop Tool)处于活动状态时更改工具选项

1. 从“建模”(Modeling)[菜单集](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D90A2BDB-FD05-4528-8A95-C33A02D15129)中的“网格工具 > 插入循环边”(Mesh Tools > Insert Edge Loop)中选择“插入循环边工具”(Insert Edge Loop Tool)。

2. 同时按住 Ctrl 和 Shift 键并在场景视图中远离曲面的任意位置单击鼠标右键。

  此时标记菜单上将显示“插入循环边工具”(Insert Edge Loop Tool)选项（“自动完成”(Auto Complete)、“与边的绝对距离”(Absolute distance from edge)、“与边的相对距离”(Relative distance from edge)和“多个循环边”(Multiple edge loops)）。

  ![图：同时按住 Ctrl 和 Shift 键并在场景视图中远离曲面的任意位置单击鼠标右键。 此时标记菜单上将显示“插入循环边工…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-15B91328-D618-42C5-9A58-F5839CCC98DD.gif) <!-- baize:img-hook downloaded=false reason="正文 915 字 ≥300，非承重" -->

3. 您可以从标记菜单中选择任意选项，使其处于启用或禁用状态，具体取决于工作流程。

  可以继续使用“插入循环边工具”(Insert Edge Loop Tool)与选定的选项。
