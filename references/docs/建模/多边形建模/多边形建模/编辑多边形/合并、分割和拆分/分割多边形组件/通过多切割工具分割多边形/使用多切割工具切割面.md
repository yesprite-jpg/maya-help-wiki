# 使用多切割工具切割面

通过使用多切割工具绘制新边，您可以采用交互式方式在网格上划分组件。这使您能够快速更改网格的拓扑。

使用多切割工具切割面

1. 选择要切割的网格。

2. 打开[多切割工具](../../../../多边形建模参考/多边形建模工具/多切割工具.md)。

3. （可选）启用对象、世界或拓扑对称，以便在网格的两侧进行切割。请参见[激活或取消激活对称](../../../对称编辑/激活或取消激活对称.md)。

4. （可选）为要粘附到的切割边[设置激活的曲面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EBF1E652-4DDD-423F-B42E-3BF85AE46A5D)。

5. 单击现有边或顶点作为起点。必须从顶点或边开始切割。如果从面开始切割，还将选择最近的顶点，从而创建两个切割点。

  **注**

  提示：

  按住 Shift 键并单击某条边以从其中点开始绘制。

  **注**

  放置切割点时，您可以使用栅格（按住 X 键）或点（按住 V 键）捕捉。

6. 单击其他边、顶点或面，以将这些点添加到切割线。

  插入分隔多个面的点时，将自动创建任何必需的中间点。您也可以沿同一条边执行多个切割。

  此外，当多切割工具处于活动状态时，您还可通过下列操作以交互方式编辑切割线：

  - 按 Backspace 键移除点。

  - 按住 Shift 键沿着边捕捉点。使用“多切割选项”(Multi-Cut Options)中的“捕捉 %”(Snap %)字段来调整捕捉间隔。

  - 撤消（热键：Z）或重做（热键：Shift+Z）任何操作。

  - 拖动以在网格的任意位置重新定位切割点。[使用多切割工具重新定位切割点](使用多切割工具重新定位切割点.md)。

  - 在“多切割选项”(Multi-Cut Options)中，调整[“切割/插入循环边工具”(Cut/Insert Edge Loop Tool)设置](../../../../多边形建模参考/多边形建模工具/多切割工具.md#GUID-93324AE7-5B19-4D74-B41B-74934B4AD20C__SECTION_7E2A671B77F6478BB674F51C638BDFE8)。

8. 完成后，执行下列操作之一，对面进行切割：

  - 按 Enter 键

  - 单击鼠标右键

  - 切换到另一个工具

  - 再次单击 ![图：再次单击 以退出工具](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-DE36D361-0FE8-455E-A3A6-4F309F00F36C.png) <!-- baize:img-hook downloaded=false reason="正文 671 字 ≥300，非承重" --> 以退出工具
