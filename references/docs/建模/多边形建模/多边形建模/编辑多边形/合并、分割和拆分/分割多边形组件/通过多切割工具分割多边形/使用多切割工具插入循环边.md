# 使用多切割工具插入循环边

使用多切割工具插入循环边

1. 打开[多切割工具](../../../../多边形建模参考/多边形建模工具/多切割工具.md)。

2. （可选）启用对象、世界或拓扑对称，以便在网格的两侧进行编辑。请参见[激活或取消激活对称](../../../对称编辑/激活或取消激活对称.md)。

3. 按住 Ctrl 键或同时按住 Ctrl 和 Shift 键并在网格上拖动光标以预览循环边。

4. 执行以下操作之一，插入循环边：

  - 按住 Ctrl 键并单击以在网格上的任意位置插入循环边。

  - 按住 Ctrl 键并用鼠标中键单击以插入居中的循环边。

  - 同时按住 Ctrl 和 Shift 键并单击以插入循环边并按照“捕捉步长 %”(Snap Step %)增量进行捕捉，如[多切割工具选项](../../../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/多切割工具选项.md)中所述。
