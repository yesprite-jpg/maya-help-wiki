# 使用多切割工具进行 90 度角切割

使用多切割工具进行 90 度角切割

1. 开始进行切割。请参见[使用多切割工具切割面](使用多切割工具切割面.md)。

2. 想要进行 90 度角切割时，请同时按住 Ctrl 和 Shift 键并将光标向上一个切割点移近。

  灰色量角器线显示为与上一个分段呈 90 度和 180 度角。

  ![图：想要进行 90 度角切割时，请同时按住 Ctrl 和 Shift 键并将光标向上一个切割点移近。 灰色量角器线显示为与上…](../../../../../../../../assets/Maya-Modeling/GUID-DB1DD850-0CB8-4AE8-BA50-433356824001.png) <!-- baize:img-hook downloaded=true reason="正文 262 字 <300 且带图" -->

3. 在其中一条量角器线上方移动光标。

  在沿量角器线方向移动光标时，将会显示一条绿色切割预览线。

  ![图：在其中一条量角器线上方移动光标。 在沿量角器线方向移动光标时，将会显示一条绿色切割预览线。](../../../../../../../../assets/Maya-Modeling/GUID-71E821A6-2F60-4BA6-BA31-29DA180F5602.png) <!-- baize:img-hook downloaded=true reason="正文 262 字 <300 且带图" -->

4. 单击网格放置切割点并创建 90 度角切割。

  ![图：单击网格放置切割点并创建 90 度角切割。](../../../../../../../../assets/Maya-Modeling/GUID-5AA321FB-FA80-4073-88FC-49D2FB506D47.png) <!-- baize:img-hook downloaded=true reason="正文 262 字 <300 且带图" -->

在现有边上查找 90 度角

1. 同时按住 Ctrl 和 Shift 键并在现有边上方移动光标以查找其他 90 度角。

  ![图：同时按住 Ctrl 和 Shift 键并在现有边上方移动光标以查找其他 90 度角。](../../../../../../../../assets/Maya-Modeling/GUID-097837E3-05F3-4C4F-98A0-3AAF64D9DDFC.png) <!-- baize:img-hook downloaded=true reason="正文 262 字 <300 且带图" -->
