# 使用多切割工具将切割点捕捉到边

将切割点捕捉到边的中点

1. 按住 Shift 键并单击边。

  切割点将自动捕捉到该边的中点。

以某个角度将切割点捕捉到边

1. 执行下列操作之一：

  - 按住 Shift 键并沿着边拖动以捕捉到捕捉步长 %(Snap Step %) 增量。

    例如，如果“捕捉步长 %”(Snap Step %)设置为 25，可按照 25%、50% 或 75% 捕捉切割点。您可以在[多切割工具选项(Multi-Cut Tool Options)](../../../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/多切割工具选项.md)中更改此值。

    在预览模式中，黑色点标记捕捉增量。
