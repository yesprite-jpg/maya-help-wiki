# 合并选定组件

使用“编辑网格 > 合并”(Edit Mesh > Merge)和“编辑网格 > 合并到中心”(Edit Mesh > Merge to Center)命令，可以合并预先选择的顶点。前者适用于合并非常接近或重叠的组件（如同将多边形网格合并到镜像副本），而后者适用于填充洞或创建点。

**注**

在合并顶点时，会同时合并相应的 UV。在某些情况下，UV 无法合并。例如，分离壳上的 UV 必须手动合并。（在

“UV 纹理编辑器”(UV Texture Editor)

中选择

编辑 UV > 合并 UV(Edit UVs > Merge UVs)

。）

同时合并多个顶点

1. 选择要合并的顶点。

  ![图：选择要合并的顶点。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-9FF89605-72CB-44CC-A8E5-1BE04A4C3361.png) <!-- baize:img-hook downloaded=false reason="正文 739 字 ≥300，非承重" -->

2. 执行下列操作之一：

  - 从主菜单栏中，选择“编辑网格 > 合并”(Edit Mesh > Merge) > ![图：从主菜单栏中，选择“编辑网格 合并”(Edit Mesh Merge) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 739 字 ≥300，非承重" --> 。

  - 从[顶点(Vertex)标记菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8BA1A3AA-4C44-4779-8B22-0AAE3627E8EB)中，选择“合并顶点 > 合并顶点”(Merge Vertices > Merge Vertices) > ![图：从顶点(Vertex)标记菜单中，选择“合并顶点 合并顶点”(Merge Vertices Merge Vertices…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 739 字 ≥300，非承重" --> 。

3. 在“合并顶点选项”(Merge Vertices options)窗口中，调整“阈值”(Threshold)。

4. 单击“合并”(Merge)。

  如果选定顶点之间的距离小于“阈值”(Threshold)值，则它们将被合并。

  ![图：单击“合并”(Merge)。 如果选定顶点之间的距离小于“阈值”(Threshold)值，则它们将被合并。 注： 合并顶…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-40B04148-9894-4350-B2F5-2E6B93BAD4F6.png) <!-- baize:img-hook downloaded=false reason="正文 739 字 ≥300，非承重" -->

  **注**

  合并顶点后可将几何体设置为非流形。使用

  “网格 > 清理”(Mesh > Cleanup)

  修复非流形几何体。

5. 在显示的[视图中编辑器](../../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 polySewEdge 节点属性。

将边或面合并为单个顶点

1. 选择要合并到中心点的顶点或者毗邻这些顶点的边或面。

  **注**

  只能合并属于同一多边形网格的边。如果要合并不同网格对象的边，必须首先结合（

  “网格 > 结合”(Mesh > Combine)

  ）这些对象。

2. 从主菜单栏中，选择“编辑网格 > 合并到中心”(Edit Mesh > Merge to Center)。

  ![图：从主菜单栏中，选择“编辑网格 合并到中心”(Edit Mesh Merge to Center)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-BD18B9B9-E368-4AAA-88CC-340FB6728D14.png) <!-- baize:img-hook downloaded=false reason="正文 739 字 ≥300，非承重" -->
