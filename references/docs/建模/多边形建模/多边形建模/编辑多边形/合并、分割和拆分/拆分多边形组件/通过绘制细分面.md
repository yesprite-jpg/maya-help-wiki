# 通过绘制细分面

可以使用“绘制选择工具”(Paint Selection tool)来选择和细分面。

1. 选择网格。

2. 在“工具箱”(Toolbox)中，选择“绘制选择工具”(Paint Selection Tool) ![图：在“工具箱”(Toolbox)中，选择“绘制选择工具”(Paint Selection Tool) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-DE3A3F4A-8FE3-4BF4-9506-990AB8722D1E.png) <!-- baize:img-hook downloaded=false reason="正文 330 字 ≥300，非承重" -->。

3. 在工具设置窗口的“绘制操作”(Paint Operations)区域中，禁用“添加到当前选择”(Add to Current Selection)。

4. 将拾取遮罩更改为“多边形面”(Poly Faces)。

5. 在“笔划”(Stroke)区域中，在“笔划后命令”(After Stroke Cmd)中键入以下命令：polySubdivideFacet -dv 1 -m 0 -ch 1

6. 绘制要细分的面。在完成笔划时每个绘制的面会自动细分。
