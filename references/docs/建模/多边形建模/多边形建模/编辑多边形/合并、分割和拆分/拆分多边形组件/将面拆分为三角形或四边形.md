# 将面拆分为三角形或四边形

可以将多边形面细分到三角形或四边形中。将以指数或线性方式添加分段。若要了解两者的差异，请参见[平滑选项](../../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格”%28Mesh%29菜单/平滑选项%28Smooth%20Options%29.md)。

**注**

还可以使用

“添加分段”(Add Divisions)

分割多边形边。有关详细信息，请参见

分割多边形边

。

拆分面

1. 选择要拆分的面，然后选择“编辑网格 > 添加分段”(Edit Mesh > Add Divisions)，或者单击建模工具包中的 ![图：选择要拆分的面，然后选择“编辑网格 添加分段”(Edit Mesh Add Divisions)，或者单击建模工具包中的…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-77C3F938-2C11-4FFF-AE90-DD98E444FE47.png) <!-- baize:img-hook downloaded=false reason="正文 655 字 ≥300，非承重" -->。

2. 在显示的[视图中编辑器](../../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，编辑 polySubdFace 节点选项：

  - 将“添加分段”(Add divisions)设置为“指数”(Exponentially)或“线性”(Linearly)。

    “指数”(Exponentially)以递归方式细分面或边。“线性”(Linearly)设置将面细分为绝对分段数。此外，通过“线性”(Linearly)设置，可以按 U 向和 V 向指定细分。

  - 设定“分段级别”(Division Levels)，以便根据“添加分段”(Add divisions)设置来指定选定面出现的细分数。

  - “指数”(Exponentially)控件允许您将“模式”(Mode)指定为三角形或四边形。

## “添加分段”(Add Divisions)功能疑难解答

#### **面无法细分**

无法在包含洞的面上使用“添加分段”(Add Divisions)功能。另外，除非中心点在面内部，否则无法细分凹面。

![图：无法在包含洞的面上使用“添加分段”(Add Divisions)功能。另外，除非中心点在面内部，否则无法细分凹面。 若要…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-37A20026-7737-4730-AD7F-F3703EB57F18.png) <!-- baize:img-hook downloaded=false reason="正文 655 字 ≥300，非承重" -->

若要将凹面细分为凸部位，请使用[多切割工具(Multi-Cut Tool)](../../../多边形建模参考/多边形建模工具/多切割工具.md)或网格 > 三角算法(Mesh > Triangulate)。使用“三角算法”移除洞。
