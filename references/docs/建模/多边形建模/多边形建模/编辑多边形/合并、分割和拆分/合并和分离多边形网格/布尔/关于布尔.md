# 关于布尔

下列功能使 Maya 的布尔成为可靠的建模技术。

## 多个对象

可以在一个“差集”(Difference)布尔运算中使用多个对象。在以下示例中，将从一个大型球体中减去一圈小型球体，从而创建一系列裁切。

## 大型数据集

布尔使内存使用量保持在最低级别，以便您可以对较大的复杂场景和稠密的网格执行布尔运算，而不会影响 Maya 的性能。
