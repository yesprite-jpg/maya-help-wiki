# 将多边形壳分离为单独的网格

“分离”(Separate)命令可将多边形网格内的多边形壳分离为其各自的单独网格。可以一次分离所有壳，或通过选择某些壳上的某些面来指定仅分离这些壳。

将壳分离为单独的网格

1. 执行下列操作之一：

  - 选择网格对象，然后选择“网格 > 分离”(Mesh > Separate)或者单击[建模工具包](../../../多边形建模参考/多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)中的 ![图：选择网格对象，然后选择“网格 分离”(Mesh Separate)或者单击建模工具包中的 。 这些壳将拆分为单独的网格。](../../../../../../../assets/Maya-Modeling/GUID-35C4D3AB-B50A-484A-B2F0-A270DD01944B.png) <!-- baize:img-hook downloaded=true reason="正文 259 字 <300 且带图" -->。

    这些壳将拆分为单独的网格。

  - 选择要分离的壳上的一些面，然后选择“编辑网格 > 提取”(Edit Mesh > Extract)。

    仅将包含选定面的壳分离为其各自的单独网格。所有其余壳均不受影响。
