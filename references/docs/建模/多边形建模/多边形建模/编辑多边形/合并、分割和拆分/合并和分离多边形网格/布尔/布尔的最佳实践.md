# 布尔的最佳实践

为获得使用布尔的最佳结果：

- 所有对象都应该是流形网格

  **注**

  只有非流形组件不在布尔运算的相交处时，才支持非流形网格。

- 面法线应在所有曲面之间一致

  **注**

  提示：

  在执行布尔运算之前，请查看网格上的法线（

  “显示 > 多边形 > 面法线”(Display > Polygons > Face Normals)

  ）。如果要生成可预测的布尔结果，请使用

  “网格显示 > 一致”(Mesh Display > Conform)

  使法线变得一致。

- 显式选择对象以获得一致的结果

  对父对象执行布尔操作可能会产生不需要的结果。如果将多个网格组合到一个公共父对象之下，则显式选择对象作为布尔操作的输入。
