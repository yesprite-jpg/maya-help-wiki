# 布尔

布尔（网格 > 布尔(Mesh > Booleans)）可用于利用多边形对象进行建模。通过三个布尔运算，可以组合对象来制作形状，否则，这些形状很难通过其他技术进行建模。可以对多个对象执行相加、减去或相交操作，以创建复杂的新形状。请参见[使用布尔运算组合多边形网格](布尔/使用布尔运算组合多边形网格.md)。

布尔操作依靠交集（即两个网格的共享体积）来确定布尔结果。

- 并集 = 两个网格的面 - 交集的面

- 差集 = 第一个选定网格的面 - 交集的面 + 第二个选定网格的面（作为交集的一部分）

在执行布尔运算之后，无法在场景中选择原始对象。如果构建历史处于启用状态，可以在“通道盒”(Channel Box)、“Hypergraph”、“属性编辑器”(Attribute Editor)或“大纲视图”(Outliner)中选择对象。对原始对象所做的任何更改都会自动应用到新的形状。请参见[在执行布尔运算后编辑原始对象](布尔/在执行布尔运算后编辑原始对象.md)。
