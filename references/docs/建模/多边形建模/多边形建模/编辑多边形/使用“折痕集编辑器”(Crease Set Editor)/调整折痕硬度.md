# 调整折痕硬度

调整折痕硬度

1. 在“折痕集编辑器”(Crease Set Editor)（“窗口 > 关系编辑器 > 折痕集”(Windows > Relationship Editors > Crease Sets)）中，选择折痕集，然后执行下列操作之一：

  - 双击“折痕”(Crease)字段，然后输入新的值。

  - 在字段中按住鼠标中键并拖动以增加或减小值。

    **注**

    提示：

    若要控制在按住鼠标中键并拖动时的增量级别，请选择

    “设置 > 折痕级别拖动增量”(Settings > Crease Level Drag Increment)

    并输入值。
