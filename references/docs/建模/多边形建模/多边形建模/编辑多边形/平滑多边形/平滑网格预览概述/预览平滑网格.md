# 预览平滑网格

在实际应用[平滑(Smooth)](../通过添加新的多边形平滑网格.md)操作之前，可以使用[平滑网格预览(Smooth Mesh Preview)](../平滑网格预览概述.md)查看平滑版本网格的外观。

使用“平滑网格预览”(Smooth Mesh Preview)预览平滑网格

1. 选择您要平滑的多边形网格。

2. 执行下列操作之一：

  - 按 1 键可关闭“平滑网格预览”(Smooth Mesh Preview)。

  - 按 2 键启用“框架 + 平滑网格”(Cage + Smooth Mesh)显示模式。

    Maya 会同时显示原始网格（作为线框框架）和平滑预览，这样您可以选择任一版本网格上的组件。

  - 按 3 键启用“平滑网格”(Smooth Mesh)显示模式。

    Maya 仅显示平滑预览。当您直接在平滑预览上选择和编辑组件时，更改将反映回原始网格上。

3. 按向上翻页或向下翻页键可更改平滑预览中出现的平滑/细分级别。

或者，可以针对任何网格的 polyShape 节点转到“属性编辑器”(Attribute Editor)，然后在“平滑网格”(Smooth Mesh)部分中启用“平滑网格预览”(Smooth Mesh Preview)。

**注**

缓存平滑网格可能会导致性能下降并占用大量内存。可以使用

缓存播放首选项(Cached Playback Preferences)

中的

“缓存平滑网格”(Cache Smooth Meshes)

选项来禁用

“平滑网格预览”(Smooth Mesh Preview)

。
