# 在平滑网格预览中显示细分

可以使用[平滑网格预览(Smooth Mesh Preview)](../平滑网格预览概述.md)查看和编辑平滑版本网格的外观。显示细分有助于完全确定网格处于不同平滑度时的外观。

在平滑网格预览中显示细分

1. 选择在“平滑网格预览”(Smooth Mesh Preview)模式下显示的平滑网格。

2. 在 polyShape 节点“属性编辑器”(Attribute Editor)的“平滑网格预览”(Smooth Mesh Preview)部分中，执行以下操作：

  - 设置[“预览分段级别”(Preview Division Levels)](../../../多边形建模参考/多边形节点/平滑网格%28Smooth%20Mesh%29.md#GUID-FF35F773-1FC0-4EBA-A64C-6199375F489A__WS1A9193826455F5FF-4F542F6211C79DEA861-100A)的值。

  - 选择[“显示细分”(Display Subdivisions)](../../../多边形建模参考/多边形节点/平滑网格%28Smooth%20Mesh%29.md#GUID-FF35F773-1FC0-4EBA-A64C-6199375F489A__WS1A9193826455F5FF-4F542F6211C79DEA861-100B)。

  在网格中会显示虚线，表示细分。

3. 拖动“预览分段级别”(Preview Division Levels)属性或者按 Page Up 或 Page Down 键，可以更改平滑预览中出现的平滑/细分级别。

**注**

缓存平滑网格可能会导致性能下降并占用大量内存。可以使用

缓存播放首选项(Cached Playback Preferences)

中的

“缓存平滑网格”(Cache Smooth Meshes)

选项来禁用

“平滑网格预览”(Smooth Mesh Preview)

。
