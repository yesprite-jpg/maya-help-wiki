# 将平滑网格预览转化为多边形

可以使用[平滑网格预览(Smooth Mesh Preview)](../平滑网格预览概述.md)查看和编辑平滑版本网格的外观。当预览具有所需的外观之后，可以直接将平滑版本应用于受影响的网格。

**注**

缓存平滑网格可能会导致性能下降并占用大量内存。可以使用

缓存播放首选项(Cached Playback Preferences)

中的

“缓存平滑网格”(Cache Smooth Meshes)

选项来禁用

“平滑网格预览”(Smooth Mesh Preview)

。

将平滑网格预览转化为多边形

1. 选择要转化的网格并确保已启用“平滑网格预览”(Smooth Mesh Preview)。请参见[预览平滑网格](预览平滑网格.md)。

2. 选择“修改 > 转化 > 平滑网格预览到多边形”(Modify > Convert > Smooth Mesh Preview to Polygons)。

  原始版本的网格（框架）使用“平滑网格预览”(Smooth Mesh Preview)属性进行平滑。Maya 将这些属性复制到新的 polySmooth 节点。

  **注**

  “平滑网格预览”(Smooth Mesh Preview)

  选项是在

  “属性编辑器”(Attribute Editor)

  中“polyShape”选项卡的

  “平滑网格”(Smooth Mesh)

  部分设置的。有关

  “平滑网格预览”(Smooth Mesh Preview)

  属性的详细信息，请参见

  平滑网格(Smooth Mesh)

  。
