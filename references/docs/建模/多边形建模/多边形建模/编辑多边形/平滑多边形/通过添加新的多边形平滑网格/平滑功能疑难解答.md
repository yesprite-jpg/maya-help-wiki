# 平滑功能疑难解答

## 平滑作用异常或根本无效

平滑在凸面和甚至星形凹面上也适用。但是，对于中心点不在面内的凹面，平滑可能会产生不必要的结果。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-Modeling/GUID-68967740-6F57-4FD5-854E-18AE829F9971.png) <!-- baize:img-hook downloaded=true reason="正文 134 字 <300 且带图" -->

若要修复凹面，请使用[多切割工具(Multi-Cut Tool)](../../../多边形建模参考/多边形建模工具/多切割工具.md)或网格 > 三角化(Mesh > Triangulate)。
