# 平滑网格预览概述

“平滑网格预览”(Smooth Mesh Preview)可以快速而轻松地查看平滑时多边形网格的显示方式。选定对象之后，通过按 1、2 或 3 键，可以在不同的平滑网格预览模式之间快速切换。

默认情况下，当“平滑网格预览”(Smooth Mesh Preview)处于禁用状态时，网格将会自动显示。当平滑网格预览”(Smooth Mesh Preview)处于启用状态时，您可以同时显示原始网格和平滑预览（“框架 + 平滑网格”(Cage + Smooth Mesh)显示模式），也可以显示平滑预览本身（“平滑网格”(Smooth Mesh)显示模式）。

此模式非常适用于在执行实际平滑网格操作之前调整网格，这是因为您对原始网格所做的任何修改均会自动更新平滑预览。但是，请记住，“平滑网格预览”(Smooth Mesh Preview)仅更改网格的显示，因而允许您可视化平滑时的显示方式。未修改或平滑原始网格。

例如，如果在“平滑网格预览”(Smooth Mesh Preview)处于启用状态时渲染网格，网格将以原始的未平滑状态显示在最终图像中。如果要在渲染中显示已平滑的网格，您可以将其转化为完全平滑的网格，或从平滑网格预览中创建细分曲面代理。请参见[将平滑网格预览转化为多边形](平滑网格预览概述/将平滑网格预览转化为多边形.md) 和[细分曲面代理选项](../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格”%28Mesh%29菜单/细分曲面代理选项%28Subdiv%20Proxy%20Options%29.md)。

默认情况下，“平滑网格预览”(Smooth Mesh Preview)使用“OpenSubdiv Catmull-Clark”细分方法，该方法将对网格面应用统一的优化方案。有关详细信息，请参见 [OpenSubdiv 概述](OpenSubdiv%20概述.md)。

**注**

缓存平滑网格可能会导致性能下降并占用大量内存。可以使用

缓存播放首选项(Cached Playback Preferences)

中的

“缓存平滑网格”(Cache Smooth Meshes)

选项来禁用

“平滑网格预览”(Smooth Mesh Preview)

。
