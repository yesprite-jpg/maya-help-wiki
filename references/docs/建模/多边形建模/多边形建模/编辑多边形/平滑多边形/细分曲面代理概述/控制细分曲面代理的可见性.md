# 控制细分曲面代理的可见性

显示或隐藏代理和/或平滑网格

1. 在创建细分曲面代理时，确保以下选项处于启用状态：

  - 层中的细分曲面代理(Subdiv Proxy In Layer)

  - 平滑层中的网格(Smooth Mesh in Layer)

  Maya 会将两种网格都添加到“层编辑器”(Layer Editor)中的新层。

2. 在“层编辑器”(Layer Editor)中，单击“显示”(Display)选项卡，再单击每个网格名称旁边的可见性图标。

  ![图：在“层编辑器”(Layer Editor)中，单击“显示”(Display)选项卡，再单击每个网格名称旁边的可见性图标。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-8A2C9806-0D03-4F70-9D86-14F7D1356649.png) <!-- baize:img-hook downloaded=false reason="正文 487 字 ≥300，非承重" -->

使代理和/或平滑网格透明

1. 将新材质指定给相应的网格。请参见[将材质指定给曲面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-D41AF807-F7CB-447E-BACC-7F0867C14E8D)。

2. 在“属性编辑器”(Attribute Editor)中打开材质节点，然后调整“透明度”(Transparency)属性。

切换细分曲面代理显示模式

1. 按 Ctrl + Shift + ~。

  **注**

  提示：

  如果对象未切换到细分曲面代理显示模式，请在

  “细分曲面代理选项”(Subdiv Proxy Options)

  （

  “网格 > 平滑代理 > 细分曲面代理”(Mesh > Smooth Proxy > Subdiv Proxy) > ![图：按 Ctrl + Shift + ~。 提示： 如果对象未切换到细分曲面代理显示模式，请在“细分曲面代理选项”(Subd…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 487 字 ≥300，非承重" -->

  ）中启用

  “切换细分曲面代理”(Toggle Subdiv Prox)

  。
