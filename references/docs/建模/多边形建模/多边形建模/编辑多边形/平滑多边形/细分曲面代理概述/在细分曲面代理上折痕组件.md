# 在细分曲面代理上折痕组件

在细分曲面代理上使选定边或顶点产生折痕

1. 选择“网格 > 平滑代理 > 折痕工具”(Mesh > Smooth Proxy > Crease Tool) > ![图：选择“网格 平滑代理 折痕工具”(Mesh Smooth Proxy Crease Tool) 。](../../../../../../../assets/Maya-Modeling/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 141 字 <300 且带图" --> 。

2. 在要折痕的代理网格上选择组件。

3. 按住鼠标中键在场景中拖动以调整折痕值。
