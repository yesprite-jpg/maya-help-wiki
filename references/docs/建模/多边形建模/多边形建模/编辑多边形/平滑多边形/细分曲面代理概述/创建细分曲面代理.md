# 创建细分曲面代理

创建细分曲面代理

1. 选择一个网格。

  **注**

  与

  “网格 > 平滑”(Mesh > Smooth)

  不同，不能在特定面上使用

  “细分曲面代理”(Subdiv Proxy)

  。

2. 执行下列操作之一：

  - 选择“网格 > 平滑代理 > 细分曲面代理”(Mesh > Smooth Proxy > Subdiv Proxy)。

  - 按 Ctrl + Shift + ~（波浪号）。

  Maya 会平滑选定的网格，并将其放置在原始的未平滑网格（代理）中。Maya 还会创建包含两种网格的新组，并为每个网格创建新层。

3. 编辑您的代理网格。

  当您为代理网格建模时，平滑网格会自动更新。

  **注**

  提示：

  您可以在代理网格上使用

  “编辑网格 > 倒角”(Edit Mesh > Bevel)

  来控制角点处平滑网格的形状。
