# 通过平均化顶点之间的距离平滑网格

“平均化顶点”(Average Vertices)（“编辑网格 > 平均化顶点”(Edit Mesh > Average Vertices)）命令平滑网格，同时保持其多边形计数。它对现有顶点的值进行平均化，以在不修改当前拓扑的情况下生成更平滑的曲面。

**注**

提示：

在开始平滑之前，您可能希望在

平均化顶点选项(Average Vertices Options)

（

“编辑网格 > 平均化顶点”(Edit Mesh > Average Vertices) > ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 432 字 ≥300，非承重" -->

）中设置特定的

“平滑量”(Smoothing amount)

。

通过移动顶点进行平滑

1. 选择要平滑的网格或顶点。

2. 选择“编辑网格 > 平均化顶点”(Edit Mesh > Average Vertices)。

  **注**

  提示：

  通过按“g”热键重复最后一个操作，可以重复执行平滑操作。

3. 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 polyAverageVertex 节点属性。

**注**

“平均化”(Average)

命令类似于

Autodesk 3ds Max

中的平滑功能，它通过平均化现有组件发挥作用。
