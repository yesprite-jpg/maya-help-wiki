# 通过添加新的多边形平滑网格

平滑功能（“网格 > 平滑”(Mesh > Smooth)）通过添加新的多边形，然后平滑顶点以及与其连接的边，修改多边形网格。

通过添加多边形来进行平滑是最通用、最持久的平滑版本，因为这样做实际上会将多边形添加到现有网格，但同时也会产生最高昂的性能成本。必须经常（但并非总如此）对最终渲染和动画进行平滑处理，但您通常希望尽量在建模过程的晚期阶段应用实际平滑。在这之前，最好依赖永久性更低的方法。

通过添加多边形进行平滑

1. 选择要平滑的网格或仅选择要平滑的面。

2. 选择“网格 > 平滑”(Mesh > Smooth)或单击[建模工具包](../../多边形建模参考/多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)中的 ![图：选择“网格 平滑”(Mesh Smooth)或单击建模工具包中的 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-05A37C93-4B88-4042-B216-8488A53B9F87.png) <!-- baize:img-hook downloaded=false reason="正文 331 字 ≥300，非承重" -->。

  ![图：选择“网格 平滑”(Mesh Smooth)或单击建模工具包中的 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-0C7FBF8D-67EC-4E2F-8C26-0C96D0AE4D50.png) <!-- baize:img-hook downloaded=false reason="正文 331 字 ≥300，非承重" -->

3. 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 polySmoothFace 属性。

  **注**

  如果输入大于 5 的

  “分段”(Divisions)

  值，则显示一条警告消息。
