# 细分曲面概述

使用细分曲面可以细分网格的特定区域，从而能够精细调整或平滑特定区域，而无需更改整个网格。

细分曲面有助于保持较低的多边形总数，因为它们仅在需要的位置插入控制点（而不是在整个网格上均匀插入）。但是，细分曲面是三种平滑方法中执行速度最慢的。请参见[平滑多边形](../平滑多边形.md)。

**注**

细分曲面一般不受 Maya 以外的流水线的支持，因此您需要将其转换为多边形或 NURBS 之后才能导出至这些流水线。您可以将使用

“修改 > 将细分曲面转化为多边形”(Modify > Convert Subdiv to Polygons)

或

“修改” > 将细分曲面转化为 NURBS”(Modify > Convert Subdiv to NURBS)

。

有关细分曲面的详细信息，请参见细分曲面文档归档，可从以下网站获得该归档文件：[http://www.autodesk.com/maya-docs-archive](http://www.autodesk.com/maya-docs-archive)。
