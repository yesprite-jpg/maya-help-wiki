# 细分曲面代理概述

“细分曲面代理”(Subdiv Proxy)平滑方法通过添加多边形并将其放置在原始的未平滑网格（代理）内来平滑选定的网格。

当您创建细分曲面代理时，网格的平滑版本和原始版本可以同时显示。默认情况下，原始网格显示为部分透明，以便查看下方的平滑网格。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-2A9F3CAA-AE5B-417F-80BB-5C6E74E43560.png) <!-- baize:img-hook downloaded=false reason="正文 685 字 ≥300，非承重" -->

网格通过它们的构建历史链接在一起，这样，对代理形状或拓扑进行的任何编辑也会反映在网格的已平滑版本中。您可以重新定形并对原始网格（代理）设定动画，以及在已平滑网格上查看结果。

不同于使用“平滑网格预览”(Smooth Mesh Preview)时获得的平滑预览，网格的细分曲面代理版本完全可渲染，并且可以为动画执行蒙皮和权重。细分曲面代理还允许您以镜像方式使用网格。您可以修改一半对象的原始网格，然后查看模型的另一半平滑版本中反应的更改。请参见[使用细分曲面代理镜像多边形网格](细分曲面代理概述/通过细分曲面代理镜像多边形网格.md)。

默认情况下，细分曲面代理使用“OpenSubdiv Catmull-Clark”细分方法，该方法对网格面应用统一的细化方案。有关详细信息，请参见 [OpenSubdiv 概述](OpenSubdiv%20概述.md)。
