# 倒角多边形边和面

倒角会将选定的每条边展开为一个新面，为多边形网格的边添加圆角。请参见[倒角命令](../../多边形建模参考/多边形建模命令/倒角命令.md)。

对边或面进行倒角

1. 选择网格对象，或者选择要进行倒角的边或面。

  **注**

  如果选择网格对象，Maya 会倒角网格中的每条边。

2. 从主菜单中选择“编辑网格 > 倒角”(Edit Mesh > Bevel)，或者在建模工具包中单击 ![图：从主菜单中选择“编辑网格 倒角”(Edit Mesh Bevel)，或者在建模工具包中单击 。 Maya 将对选定边或选…](../../../../../../assets/Maya-Modeling/GUID-8A4DEA88-0DFC-426B-8028-E40F8C542E54.png) <!-- baize:img-hook downloaded=true reason="正文 239 字 <300 且带图" -->。

  Maya 将对选定边或选定面的周长边进行倒角。

  **注**

  执行倒角操作后，将会保留逐面着色器指定。

  ![图：从主菜单中选择“编辑网格 倒角”(Edit Mesh Bevel)，或者在建模工具包中单击 。 Maya 将对选定边或选…](../../../../../../assets/Maya-Modeling/GUID-A5A5E82F-221C-4CA8-9CF7-637B56F126FB.png) <!-- baize:img-hook downloaded=true reason="正文 239 字 <300 且带图" -->

3. 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 [polyBevel](../../多边形建模参考/多边形节点/polyBevel.md) 属性。
