# 自旋多边形边

可以使用“正向自旋边”(Spin Edge Forward)或“反向自旋边”(Spin Edge Backward)选项自旋多边形网格上的边。通过一次更改选定边的连接 1 个顶点，旋转边会修改多边形网格。可以使用该选项快速更改网格拓扑的流动。以下显示了一个示例。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-C67B0ABB-0231-40D1-BAFD-74ACB99A1824.png) <!-- baize:img-hook downloaded=false reason="正文 418 字 ≥300，非承重" -->

可以基于其缠绕方向正向或反向旋转边。如果旋转之前已旋转过的边，或旋转一条边多次，Maya 将编辑现有历史节点的偏移属性而不是创建新属性。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-B48509E9-9535-4EDC-BF7C-0033E5DFC89E.png) <!-- baize:img-hook downloaded=false reason="正文 418 字 ≥300，非承重" -->

旋转边不会影响顶点 ID 或边 ID，但是在旋转边时，邻近面也会与它一起旋转。

**注**

只能旋转附加到两个面的边。可以一次旋转多个边，但每个面只能有 1 个边。

旋转一条或多条边

1. 选择要旋转的边。

2. 选择“编辑网格 > 正向自旋边”(Edit Mesh > Spin Edge Forward)或“编辑网格 > 反向自旋边”(Edit Mesh > Spin Edge Backward)。或者，也可以按 Ctrl + Alt + 左箭头键或右箭头键，以分别向前或向后旋转边。

  边会基于其各自缠绕顺序在适当方向旋转。
