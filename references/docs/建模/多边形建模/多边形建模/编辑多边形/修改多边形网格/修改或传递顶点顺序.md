# 修改或传递顶点顺序

创建多边形对象时，Maya 会自动为其指定顶点 ID。您可以使用“对顶点重新排序”(Reorder Vertices)命令更改顶点顺序。

对顶点重新排序

1. [针对顶点重新排序的多边形对象删除历史](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-503E227B-EF49-4A78-B3CA-7EAC588017C9)。

2. （可选）通过选择该对象，然后转到“显示 > 多边形 > 组件 ID > 顶点”(Display > Polygons > Component IDs > Vertices)，可显示其顶点 ID。

3. 选择[对顶点重新排序(Reorder Vertices)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“编辑网格”%28Edit%20Mesh%29菜单.md)命令。

4. 按照要建立的新顶点顺序，单击与前三个顶点相关的三个相邻顶点。

  Maya 将根据您设置的初始路径对其余顶点重新排序。

  **注**

  “对顶点重新排序”(Reorder Vertices)命令将始终保持活动状态，直到您切换到其他命令或工具为止。这样一来，您便可以一直尝试使用新顶点顺序，直到实现所需的顺序为止。

您可以使用“传递顶点顺序”(Transfer Vertex Order)命令将顶点顺序从一个对象传递到另一个对象，而不是手动对顶点重新排序。

**注**

若要获得最佳结果，请先确保两个网格的拓扑类似。

将顶点顺序从一个网格传递到另一个网格

1. [针对传递中涉及的两个对象删除历史](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-503E227B-EF49-4A78-B3CA-7EAC588017C9)。

2. （可选）通过选择这两个对象，然后转到“显示 > 多边形 > 组件 ID > 顶点”(Display > Polygons > Component IDs > Vertices)，可显示其顶点 ID。

3. 选择[传递顶点顺序(Transfer Vertex Order)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格”%28Mesh%29菜单.md)命令。

4. 在源对象上，单击三个相邻的顶点。

5. 在目标对象上，单击拓扑与源对象上选择的三个顶点相关的三个相邻顶点。

  Maya 会将其余顶点重新排序，使之相对于三个选定的基础节点与源对象匹配。
