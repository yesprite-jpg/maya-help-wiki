# 在多边形面中生成洞

## 从外部面生成永久洞

您可以使用“生成洞工具”(Make Hole Tool)在选定多边形面中以其他面的形状创建洞。

**注**

如果生成洞时使用的面形状与要在其中生成洞的面位于不同的网格，必须在使用

“生成洞”(Make Hole)

之前组合这些面（选择两个网格，然后选择

“网格 > 结合”(Mesh > Combine)

）。请参见

组合选项(Combine Options)

在面上生成洞不会增加多边形模型中的面数或更改其顶点、边或面的组件索引。这在应用逐顶点颜色或导入外部多边形对象时尤为重要。

还可以在绘制时在面上生成洞。请参见[创建带洞的多边形面](../../多边形选择和创建/绘制多边形/创建带洞的多边形面.md)。

在第二个面的图形中生成洞

1. 选择“网格工具 > 生成洞”(Mesh Tools > Make Hole) > ![图：选择“网格工具 生成洞”(Mesh Tools Make Hole) 。 在“工具设置”(Tool Settings)对…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" --> 。

  在“工具设置”(Tool Settings)对话框中，可选择设置洞与面的交互方式。请参见[生成洞工具选项(Make Hole Tool Options)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/生成洞工具选项%28Make%20Hole%20Tool%20Options%29.md)。

2. 在要生成洞的面的中心单击面指示器。

3. 在表示洞形状的面的中心单击面指示器。

  ![图：在表示洞形状的面的中心单击面指示器。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-72F6FCAC-35A1-4AA3-9BAF-33D6BDC949E1.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

4. 按 Enter 键以生成洞。

  ![图：按 Enter 键以生成洞。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-60047137-2637-4918-A3BD-F9BD209AA36E.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

也可以通过选择两边的面在单个对象中创建洞。

在绘制时在多边形中创建洞

1. 选择“网格工具 > 创建多边形”(Mesh Tools > Create Polygon)。

  请参见[创建多边形工具选项(Create Polygon Tool Options)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“网格工具”%28Mesh%20Tools%29菜单/创建多边形工具选项%28Create%20Polygon%20Tool%20Options%29.md)

2. 在场景视图中，单击以放置多边形顶点，但请勿在放置最后一个多边形顶点时按 Enter 键。而是执行以下操作：

  - 按住 Ctrl 键并单击以放置该洞的第一个顶点。

  - 松开 Ctrl 键并单击以放置该洞的其余顶点。

  - 绘制玩洞后，按 Enter 键完成多边形。

    ![图：绘制玩洞后，按 Enter 键完成多边形。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-37942E40-8093-43D8-B466-4192C76291E8.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

    ![图：绘制玩洞后，按 Enter 键完成多边形。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-25DCA9D5-8A5C-4686-9BAF-3E3F0CD18B96.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

    ![图：绘制玩洞后，按 Enter 键完成多边形。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-80891B72-7F42-491A-8F2E-2FC8E2DF5CCB.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

## 使面不可见

也可以使面不可见，而不是在多边形中实际创建洞。如果需要在几何体中显示洞，同时又希望在使用细分操作（如“平滑”(Smooth)）时保持整体形状，该选项非常有用。

将面指定为不可见

1. 选择要使其不可见的面。

2. 选择“编辑网格 > 指定不可见面”(Edit Mesh > Assign Invisible Faces) > ![图：选择“编辑网格 指定不可见面”(Edit Mesh Assign Invisible Faces) 。 将出现 “指定不…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" --> 。

  将出现[“指定不可见面选项”(Assign Invisible Faces Options)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“编辑网格”%28Edit%20Mesh%29菜单/指定不可见面选项%28Assign%20Invisible%20Faces%20Options%29.md)窗口。

3. 选择“指定”(Assign)。

4. 单击“创建”(Create)。

  面可能会消失，也可能不消失，具体取决于您的设置。如果不消失，请选择“显示 > 多边形 > 不可见面”(Display > Polygons > Invisible Faces)。

与几何体中的真实洞不同，处于“面”(Face)选择模式时，仍然可以在不可见面上选择并执行操作。如果细分网格（例如，使用“平滑”(Smooth)操作），则细分可确保该面仍然存在。

例如，下图显示了平滑之后的两个立方体。在进行平滑之前，对左侧立方体上的正面进行了设置使其不可见，而右侧立方体上相同的面已删除。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-17FBE132-03C2-406A-891B-E444E6F5AC54.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" -->

取消将面指定为不可见

1. 选择要取消指定的面。

2. 选择“编辑网格 > 指定不可见面”(Edit Mesh > Assign Invisible Faces) > ![图：选择“编辑网格 指定不可见面”(Edit Mesh Assign Invisible Faces) 。 将出现 “指定不…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 1347 字 ≥300，非承重" --> 。

  将出现[“指定不可见面选项”(Assign Invisible Faces Options)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“编辑网格”%28Edit%20Mesh%29菜单/指定不可见面选项%28Assign%20Invisible%20Faces%20Options%29.md)窗口。

3. 选择“取消指定”(Unassign)。

4. 单击“创建”(Create)。

  以前指定的任何不可见面将重新可见。
