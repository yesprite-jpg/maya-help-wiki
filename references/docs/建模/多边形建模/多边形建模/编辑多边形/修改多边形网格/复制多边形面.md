# 复制多边形面

“复制”(Duplicate)功能支持复制网格中的一个或多个多边形面。可以复制面，并指定要成为现有网格内多边形壳的副本，或者要形成新的单独多边形网格的副本。

复制多边形面

1. 选择要复制的面，并选择“编辑网格 > 复制”(Edit Mesh > Duplicate) > ![图：选择要复制的面，并选择“编辑网格 复制”(Edit Mesh Duplicate) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 748 字 ≥300，非承重" -->。

2. 按如下所示设定“复制”(Duplicate)选项：

  - 如果要使复制的面成为自身的网格，请启用“分离复制的面”(Separate duplicated faces)。复制的面将分离到自身的单独对象中。网格中任何已存在的壳将不会受影响。

  - 禁用“分离复制的面”(Separate duplicated faces)，使复制的面成为现有网格的一部分。

3. 单击“复制”(Duplicate)。

  该操作将创建一个 polyChipOff 节点，并切换到“显示操纵器工具”(Show Manipulator tool)。

4. 请执行下列任一操作：

  - 使用操纵器控制复制的方向和距离。请记住，也可以通过按 Insert 键或 Home 键来更改枢轴。单击附加到操纵器的圆形控制柄以在局部轴和世界轴之间进行切换。

  - 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，编辑 polyChipOff 属性。

    [“保持面的连接性”(Keep Faces Together)](保持面的连接性.md)选项用于控制“复制”(Duplicate)处理相邻面的边的方式。如果启用“保持面的连接性”(Keep Faces Together)，则面将会展开，使其边将保持连接。禁用“保持面的连接性”(Keep Faces Together)而启用“分离复制的面”(Separate duplicated faces)时，复制的面将断开连接，且每个面都将成为单独的网格。
