# 沿路径曲线挤出边或面

沿路径曲线挤出边或面

1. 选择要挤出的边或面以及要沿其挤出的曲线。

  ![图：选择要挤出的边或面以及要沿其挤出的曲线。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-699EBC8B-B45B-4C8A-81AA-410097A3AD0F.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->

2. 选择编辑网格 > 挤出(Edit Mesh > Extrude) > ![图：选择编辑网格 挤出(Edit Mesh Extrude) 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->。

3. 启用“选定的”(Selected)或“已生成”(Generated)选项。

4. 单击“挤出”(Extrude)。

  ![图：单击“挤出”(Extrude)。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-93DB608E-DF1D-491E-B7C0-52701F67BA90.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->

5. 使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的控件编辑挤出。

  例如，增加“分段”(Divisions)数”，以便挤出的多边形更好地匹配曲线的图形。

  ![图：使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的控件编辑挤出。 例如，增…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-2E2B534C-163D-4D9C-B9C1-EA5578A198DA.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->

  “减少锥化”(Reduce Taper)以便挤出的多边形沿曲线逐渐变得狭窄。（也可以使用“锥化曲线”(Taper Curve)控件来创建更复杂的锥化。）

  ![图：使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的控件编辑挤出。 例如，增…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-EC4D6450-DE10-4C15-9277-807FD96E5093.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->

  调整“扭曲”(Twist)以便挤出的多边形沿曲线旋转。

  ![图：使用“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的控件编辑挤出。 例如，增…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-C4FA3720-DDFA-45AF-8399-54603BCDB94F.png) <!-- baize:img-hook downloaded=false reason="正文 332 字 ≥300，非承重" -->
