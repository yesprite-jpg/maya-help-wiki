# 为多边形边和顶点生成折痕

对组件应用折痕可以修改多边形网格，这样就可以在不提高基础网格分辨率的情况下创建在硬度和平滑度之间过渡的图形。

折痕以折痕值进行度量，该值指明了对每个细分级别进行折痕处理的量。折痕值越高，折痕就越清晰。例如，折痕值为 2 意味着基础级别边和第一级别边已完全经过折痕处理，但是更精细级别的边完全没有经过折痕处理。

Maya 提供了以下两种方法对多边形网格的边和顶点进行折痕处理：“折痕工具”(Crease Tool)（“网格工具 > 折痕工具”(Mesh Tools > Crease Tool)）和“折痕集编辑器”(Crease Set Editor)（“窗口 > 建模编辑器 > 折痕集”(Windows > Modeling Editors > Crease Sets)）。

**“折痕工具”(Crease Tool)**直接在网格上修改折痕值。**“折痕集编辑器”(Crease Set Editor)**可用来在一个窗口中处理场景中的所有折痕集，从而轻松地跨多个网格创建、选择和编辑折痕值和折痕集。

**注**

重要：

您必须选择一个要在整个工作流中使用的方法，因为在同一组件上不能交替使用多种方法。

## 折痕工具(Crease Tool)

在多边形网格上对边或顶点进行折痕处理

1. 选择“网格工具 > 折痕工具”(Mesh Tools > Crease Tool)。

  处于边或顶点选择模式时，也可以在场景视图中按住 Shift 键并单击鼠标右键，然后从标记菜单中选择“折痕工具”(Crease Tool)。

2. 在网格上选择要进行折痕处理的边或顶点。

  **注**

  在网格上每次可以选择要进行折痕处理的多条边或多个顶点。也可以选择多个多边形对象上的项目并同时对所有项目进行折痕处理。但是，可能会出现折痕弹出现象。

3. 使用鼠标中键在场景视图中拖动以调整折痕值。

  视口中出现平视显示器以指示当前“细分级别”(subdivision level)可见的“折痕模式”(Crease Mode)、当前“折痕值”和“最大折痕值”(maximum crease value)。

  应用折痕的边以原始网格上伴有较粗的线的形式出现。包围顶点的小圆圈指示应用折痕的顶点。

  最大折痕值与网格的细分级别数相同。

## 折痕集编辑器(Crease Set Editor)

使用“折痕集编辑器”(Crease Set Editor)创建折痕集

1. 选择要包含在折痕集中的组件（多边形边或顶点）。

2. 选择“窗口 > 建模编辑器 > 折痕集”(Windows > Modeling Editors > Crease Sets)。

  此时将显示“折痕集编辑器”(Crease Set Editor)。

3. 执行下列操作之一：

  - 单击[“折痕集编辑器”(Crease Set Editor)操作按钮](../../多边形建模参考/多边形建模编辑器/折痕集编辑器%28Crease%20Set%20Editor%29/“折痕集编辑器”%28Crease%20Set%20Editor%29列表和操作按钮.md#GUID-AE276879-1E25-464F-A7A9-5D2DE02C7158__SECTION_6C37E974A8274186BB2C5ABCBAA8B825)中的“新建”(New)。

  - 在编辑器中的任意位置单击鼠标右键，然后从上下文相关菜单中选择“创建集”(Create Set)。

    新的折痕集将出现在[折痕集列表](../../多边形建模参考/多边形建模编辑器/折痕集编辑器%28Crease%20Set%20Editor%29/“折痕集编辑器”%28Crease%20Set%20Editor%29列表和操作按钮.md#GUID-AE276879-1E25-464F-A7A9-5D2DE02C7158__SECTION_BAD60880A36D4FBAB849D2CECF7B5AA0)中。

    **注**

    提示：

    要更改默认的名称，请选择

    “设置 > 默认折痕集名称”(Settings > Default Crease Set Name)

    ，并输入新的名称，然后再创建折痕集。

4. （可选）调整折痕硬度。请参见[调整折痕硬度](../使用“折痕集编辑器”%28Crease%20Set%20Editor%29/调整折痕硬度.md)。
