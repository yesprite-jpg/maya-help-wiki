# 挤出多边形的面、边或顶点

[“挤出”(Extrude)命令](../../多边形建模参考/多边形建模命令/“挤出”%28Extrude%29命令.md)。

**注**

仅当启用

“构建历史”(Construction History)

时，才显示此任务中使用的

“显示操纵器工具”(Show Manipulator Tool)

。

挤出多边形的面或边

1. 选择要挤出的面或边。

  **注**

  在

  “建模”(Modeling)

  首选项中，确保已启用

  “保持面的连接性”(Keep faces together)

  ，因此在挤出操作后相邻面的边保持连接状态。

2. 执行下列操作之一：

  - 激活“移动”(Move)、“旋转”(Rotate)或“缩放工具”(Scale Tool)，然后按 Shift 键并拖动操纵器（也称为智能挤出）。

  - 选择“编辑网格 > 挤出”(Edit Mesh > Extrude)。

  - 在[建模工具包(Modeling Toolkit)](../../多边形建模参考/多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)中单击 ![图：在建模工具包(Modeling Toolkit)中单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-C073DEE6-67CC-450C-B573-74357735106B.png) <!-- baize:img-hook downloaded=false reason="正文 789 字 ≥300，非承重" -->。

  - 按 Ctrl + E

  此时将创建挤出节点。如果未使用快速挤出方法，则还会显示“显示操纵器工具”(Show Manipulator Tool)和“视图中编辑器”(In-View Editor)。

  ![图：执行下列操作之一： 激活“移动”(Move)、“旋转”(Rotate)或“缩放工具”(Scale Tool)，然后按 S…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-4919163E-769B-46E7-B0F8-8227B6A0D174.png) <!-- baize:img-hook downloaded=false reason="正文 789 字 ≥300，非承重" -->

  **注**

  顶点将沿其顶点法线挤出，从而为共享这些顶点的每个面创建其他面。

3. 使用操纵器控制挤出的方向和距离，或在[“视图中编辑器”(In-View Editor)](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中调整属性。有关属性的详细信息，请参见[挤出选项(Extrude Options)](../../多边形建模参考/“建模”%28Modeling%29菜单集/“编辑网格”%28Edit%20Mesh%29菜单/挤出选项%28Extrude%20Options%29.md)。

  **注**

  提示：

  通过在

  通道盒

  中选择

  “编辑 > 设置 > 更改精度”(Edit > Settings > Change Precision)

  ，可以设置

  “厚度”(Thickness)

  、

  “偏移”(Offset)

  和

  “分段”(Divisions)

  属性的精度。

  视图中编辑器

  使用与

  通道盒

  相同的精度设置。

4. （可选）挤出边可以使网格成为非流形网格。使用网格 > 清理(Mesh > Cleanup)修复非流形几何体。
