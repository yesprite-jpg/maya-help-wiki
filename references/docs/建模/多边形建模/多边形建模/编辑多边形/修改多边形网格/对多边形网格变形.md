# 对多边形网格变形

可以使用称为“变形器”(deformers)的功能修改多边形网格的形状。通过“变形器”(Deformers)，可以在全局级别修改网格的各个组件，因此您不必分别修改每个组件。“变形器”(Deformers)还可用于设置对象形状的动画。例如，使用晶格变形器可以构造一个笼子形状的框或晶格，用于包围要修改的对象。然后修改晶格，这随之将修改该对象。Maya 提供了许多类型的变形器：融合变形、晶格、簇、非线性、雕刻、软修改等等。
