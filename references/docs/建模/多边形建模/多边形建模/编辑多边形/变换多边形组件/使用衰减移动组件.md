# 使用衰减移动组件

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-8B5CB835-D6EF-4767-B425-B5F911A13560.png) <!-- baize:img-hook downloaded=false reason="正文 341 字 ≥300，非承重" -->

使用“软选择”(Soft Selection)，可以通过包括周围组件的衰减，按自然方式移动几何体组件。如果要雕刻平滑对象或在模型中制作平滑整合的渐变或轮廓效果，该功能将非常有用，因为用户无需手动变换每个顶点。

从选定组件到选择区周围的其他组件，“软选择”(Soft Selection)会始终保持相同的衰减，从而创建平滑过渡效果。

例如，如果在平面中心选择一个顶点并向上平移来创建钉形，同时不使用“软选择”(Soft Selection)，其侧面就会非常陡峭，这个点也会非常明晰。启用“软选择”(Soft Selection)后，渐变和尖端会更加平滑。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-D8C963C2-03F4-4292-8F07-DDB903D5186D.png) <!-- baize:img-hook downloaded=false reason="正文 341 字 ≥300，非承重" -->

可以对多边形网格、NURBS 曲面或 NURBS 曲线应用“软选择”(Soft Selection)。 特别是在多边形上，您可以使用[雕刻](../../../../雕刻/雕刻.md)达到类似的效果。
