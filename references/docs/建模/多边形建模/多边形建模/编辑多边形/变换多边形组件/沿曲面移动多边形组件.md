# 沿曲面移动多边形组件

可以使用“曲面”(Surface)变换约束沿多边形网格的曲面移动、旋转或缩放组件。

**注**

也可以使用

“激活”(Make Live)

将工具约束到网格曲面。例如，可以使用

“激活”(Make Live)

将

“四边形绘制”(Quad Draw)

工具约束到要重新拓扑的网格，然后基于参考曲面的特征创建新拓扑。

“激活”(Make Live)

处于活动状态期间，变换约束会遭到禁用。有关重新拓扑的详细信息，请参见

使用四边形绘制重新拓扑网格

。

沿曲面移动组件

1. 选择要沿曲面移动的组件。

2. 双击工具箱中的变换工具。

3. 在显示的“工具设置”(Tool Settings)中，从“变换约束”(Transform Constraint)下拉菜单中选择“曲面”(Surface)。

  **注**

  提示：

  也可以在

  建模工具包

  窗口中选择变换约束。

4. 使用工具操纵器变换选定的组件。

5. 在“工具设置”(Tool Settings)或“建模工具包”(Modeling Toolkit)窗口中，从“变换约束”(Transform Constraint)下拉菜单中选择“禁用”(Off)以变换没有约束的组件。

  **注**

  提示：

  用鼠标中键单击

  “建模工具包”(Modeling toolkit)

  中的变换约束按钮

  ，以切换上一选择。
