# 使顶点与曲面保持一致

“一致”(Conform)可将一个对象（包裹器）的顶点包裹到另一个对象（目标）的曲面上。

**注**

在 Maya 2015 和早期版本中，

“一致”(Conform)

称为

“收缩包裹”(Shrinkwrap)

，并位于

“建模工具包”(Modeling Toolkit)

菜单中。

使顶点与曲面保持一致

1. 在 Maya 中，打开一个至少包含两个多边形网格的场景。

2. 将目标对象变成激活的曲面。请参见[设置激活的曲面](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-EBF1E652-4DDD-423F-B42E-3BF85AE46A5D)。

3. 选择场景中的包裹器网格。

4. 在主菜单中，选择“网格 > 一致”(Mesh > Conform)。

  包裹器网格会自动捕捉到目标网格的曲面。

  **注**

  提示：

  默认情况下，包裹器网格的每个顶点沿其法线捕捉到目标网格上的最近点。通过调整

  一致选项(Conform Options)

  （

  “网格 > 一致”(Mesh > Conform) >

  ），可以更改此行为。
