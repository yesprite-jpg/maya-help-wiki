# 独立变换多个组件

移动、旋转或缩放组件时，您可以根据选定组件选择相对于单个共享参考点变换所有组件，也可以选择沿多个参考帧变换所有组件。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-1A642C17-D688-4535-884D-1EF01919AA78.gif) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" -->

- 若要相对于单个共享参考帧变换组件，请使用“移动”(Move)、“旋转”(Rotate)或“缩放”(Scale)工具，并将[轴方向(Axis Orientation)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)设置为“世界”(World)或“局部”(Local)。有关详细信息，请参见[变换对象和组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9622730D-3D21-451C-8BEE-E01BCC979F91)。

- 若要沿局部参考帧变换组件组，请使用“移动”(Move)、“旋转”(Rotate)或“缩放”(Scale)工具，并将[轴方向(Axis Orientation)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)设置为“组件”(Component)。有关详细信息，请参见下面的“组件分组”一节。

- 若要使用相应的参考帧平移每个组件，请在使用“移动工具”(Move Tool)时，按住 Ctrl 键并使用鼠标中键拖动。

## 组件分组

组件组是指当前选择内的任何相邻组件集。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-417586BE-90B8-453F-8236-78909663CEC4.png) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" -->

将“轴方向”(Axis Orientation)设置为“组件”(Component)时，可根据相应的参考帧变换每个组。每个组的参考帧均是该组内所有组件的平均值。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-2DF9BF13-8F49-47D4-95FB-C90611444815.png) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" -->

但是，按住 Ctrl 键并使用鼠标中键在“移动”(Move)工具上拖动时会出现例外。此操作会沿相应的参考帧平移每个组件，而忽略其组。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-7E327A36-E86D-4C75-A06D-C59332FEC132.png) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" -->

### 暂时激活组件轴方向

使用“移动”(Move)、“旋转”(Rotate)或“缩放”(Scale)工具时，可以通过按住 Ctrl 键并使用鼠标中键拖动暂时激活“组件”(Component)模式。这适用于当前处于活动状态的任何[轴方向(Axis Orientation)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-9BCE8B23-6DA6-4C7F-B897-7E25D6E8A865)（但“法线”(Normal)除外），且根据处于活动状态的工具的不同，将以不同的方式约束移动。

| 操作 | 效果： |
|---|---|
| 按住 Ctrl 键并使用鼠标中键在“移动”(Move)工具上拖动，会沿法线移动每个组件（忽略组件组）。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-AA302F60-97CC-41E2-AD1A-E289547A8D80.gif) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" --> |
| 按住 Ctrl 键并使用鼠标中键在“旋转”(Rotate)工具上旋转，会沿局部 X 轴旋转每个组件组。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-E27B6C0D-AFB9-472B-89E7-D552A6231244.gif) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" --> |
| 按住 Ctrl 键并使用鼠标中键在“缩放”(Scale)工具上缩放，会沿局部 YZ 轴缩放每个组件组。 | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-3A4B1539-E51E-4857-B76D-BC36E68FB151.gif) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" --> |

**注**

避免调整具有历史的对象（移动 CV，并使用

“移动”(Move)

、

“旋转”(Rotate)

或

“缩放”(Scale)

移动多边形组件）。如果调整具有历史的对象，则该调整将应用于特定的组件 ID。后续更改对象历史时，将导致组件 ID 更改，从而改变调整的效果。

例如，如果旋转曲线来创建曲面，然后调整曲面中编号为 3 的 CV，则所做调整将始终应用于编号为 3 的 CV。如果稍后更改旋转节点属性，以减少曲面中的分段数，则已调整的 CV 现在将具有新编号，且调整不再应用于该 CV。调整将应用于现在编号为 3 的 CV，该 CV 可能位于曲面中的不同位置。

**注**

如果在含有已设置动画顶点调整的多边形对象中删除历史，则会导致调整中的动画丢失。

## 变换具有历史的组件

除了上述方法之外，您还可以移动具有历史的组件。通过这种方法，可以修改其关联的历史节点，但在使用对称等其他功能时，也会存在更多限制。

创建历史节点以变换组件

1. 选择要移动的组件。

2. 选择“编辑网格 > 变换”(Edit Mesh > Transform)。

  Maya 将创建变换节点 (polyMoveComponentType)，并自动切换到“显示操纵器工具”(Show Manipulator tool)，从而允许编辑节点。

  ![图：选择“编辑网格 变换”(Edit Mesh Transform)。 Maya 将创建变换节点 (polyMoveComp…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-4919163E-769B-46E7-B0F8-8227B6A0D174.png) <!-- baize:img-hook downloaded=false reason="正文 1766 字 ≥300，非承重" -->

3. 拖动操纵器控制柄，以移动、旋转或缩放组件，或更改“属性编辑器”(Attribute Editor)或“通道盒”(Channel Box)中的设置。

  该操纵器是标准的移动/旋转/缩放组合操纵器，并有一个额外的控制柄，可以在“局部”(Local)轴和“世界”(World)轴之间切换。要将组件“向内”或“向外”移动，则沿着其局部 Y 轴移动组件将十分有用。

### 使用“编辑网格 > 变换”(Edit Mesh > Transform)移动 UV

- 在 UV 纹理坐标中使用“编辑网格 > 变换”(Edit Mesh > Transform)时，该操纵器不会显示在场景视图中，但会显示在 UV 纹理编辑器中。

- 本地坐标模式不适用于 UV。

- 必须将纹理指定给对象，才能在场景视图中查看变换的结果。

- 选择对象中的 UV 之后，请使用选项窗口或“通道盒”(Channel Box)，以便在选定的区域内更改设置并变换 UV。

- 如果变换 UV 时需要更多控件，建议使用“UV 纹理编辑器”(UV Texture Editor)。
