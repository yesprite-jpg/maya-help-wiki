# 平滑多边形

在 Maya 中，可以通过多种不同方式平滑网格。每种方法各有利弊，请认真考虑哪一种方法最适合您的需求，这一点至关重要。

| 平滑方法 | 优点 | 限制 | 何时使用？ |
|---|---|---|---|
| [通过添加新的多边形平滑网格](平滑多边形/通过添加新的多边形平滑网格.md) | 可以仅在需要细节的网格区域中增加细节 默认情况下使用 [OpenSubdiv Catmull-Clark](平滑多边形/OpenSubdiv%20概述.md) 细分方法。 | 向网格添加分段，从而增加多边形数 | 当最终模型已完成且随时可沿流水线向下传递时。 当您绝对需要处理高分辨率网格的多功能性时（即，处理需要真实几何体的特征）。 |
| [平滑网格预览(Smooth Mesh Preview)](平滑多边形/平滑网格预览概述.md) （热键：1、2、3） | 最佳性能 不会生成额外的几何体 默认情况下使用 [OpenSubdiv Catmull-Clark](平滑多边形/OpenSubdiv%20概述.md)。 | 无法执行线性平滑 复杂的镜像设置 无法与粒子碰撞 | 在大多数情况下，需要使用平滑网格预览 需要查看平滑操作的效果时 需要通过修改其不太复杂的未平滑对应版本更改平滑网格时 |
| [细分曲面代理](平滑多边形/细分曲面代理概述.md) | 允许用于线性平滑 提供一键单击的镜像平滑 允许您查看粒子碰撞的效果 默认情况下使用 [OpenSubdiv Catmull-Clark](平滑多边形/OpenSubdiv%20概述.md) 细分方法。 | 增加多边形数 | 需要执行线性平滑时 需要在平滑之前查看粒子碰撞对平滑对象产生的效果时 需要执行镜像平滑时（尽管这可以通过几个额外步骤在平滑网格预览中重新创建） |
| [通过平均化顶点之间的距离平滑](平滑多边形/通过平均化顶点之间的距离平滑网格.md) | 保持对象的当前多边形计数 | 由于只能使用现有顶点，因此缺乏多功能性。 | 当多边形计数受到严格限制时。 当您需要修改凹凸不平的区域时。 |
| [细分曲面](平滑多边形/细分曲面概述.md) | 可以仅在需要细节的网格区域中增加细节 可以影响不同细节级别的网格 | 性能最慢 无外部制作流程支持（不先转换为多边形） | 为不打算装备的对象建模时 为转化为 NURBS而建模时 |
