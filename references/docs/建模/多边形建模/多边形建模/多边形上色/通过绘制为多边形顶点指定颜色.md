# 通过绘制为多边形顶点指定颜色

可以使用“绘制顶点颜色工具”(Paint Vertex Color Tool)直接在多边形网格上绘制逐顶点颜色 (CPV) 数据。

使用“绘制顶点颜色工具”绘制顶点颜色

1. 选择要在其上进行绘制的网格。

2. 选择“网格显示 > 绘制顶点颜色工具”(Mesh Display > Paint Vertex Color Tool) > ![图：选择“网格显示 绘制顶点颜色工具”(Mesh Display Paint Vertex Color Tool) 。 将显…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 433 字 ≥300，非承重" --> 。

  将显示[“绘制顶点颜色工具选项”(Paint Vertex Color Tool Options)](../多边形建模参考/“建模”%28Modeling%29菜单集/网格显示%28Mesh%20Display%29/绘制顶点颜色工具选项%28Paint%20Vertex%20Color%20Tool%20Options%29.md)。

3. 单击“颜色值”(Color value)样例使用颜色编辑器对颜色进行编辑。

4. 请执行下列任一操作：

  - 在网格中拖动笔刷为顶点着色。

  - 保持/（斜线）并单击屏幕上的任何像素切换到其颜色。

  - 单击“整体应用”(Flood)按钮将所有顶点都设定为工具选项面板中的当前颜色和属性。
