# 从多边形顶点移除颜色或预照明

可以使用“应用颜色”(Apply Color)功能移除已应用于多边形网格的逐顶点颜色 (CPV) 数据。

从多边形顶点移除逐顶点颜色数据

1. 选择要移除其逐顶点颜色数据的一个或多个顶点，然后选择“网格显示 > 应用颜色”(Mesh Display > Apply Color) > ![图：选择要移除其逐顶点颜色数据的一个或多个顶点，然后选择“网格显示 应用颜色”(Mesh Display Apply Col…](../../../../../assets/Maya-Modeling/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=true reason="正文 295 字 <300 且带图" --> 。

2. 在 [“应用颜色”(Apply Color Options)](../多边形建模参考/“建模”%28Modeling%29菜单集/网格显示%28Mesh%20Display%29/应用颜色选项%28Apply%20Color%20Options%29.md)中，将 “操作”(Operation) 设定为 “移除颜色”。

3. 单击“应用颜色”(Apply Color)。

  会为选定顶点移除逐顶点颜色信息。
