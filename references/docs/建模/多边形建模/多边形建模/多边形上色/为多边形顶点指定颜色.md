# 为多边形顶点指定颜色

可以使用“应用颜色”(Apply Color)功能，手动将颜色数据指定给多边形顶点 (CPV)。“应用颜色”(Apply Color)功能提供颜色编辑器来执行此操作。

将颜色指定给顶点

1. 选择顶点，然后选择“网格显示 > 应用颜色”(Mesh Display > Apply Color) > ![图：选择顶点，然后选择“网格显示 应用颜色”(Mesh Display Apply Color) 。 将显示应用颜色选项(A…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 596 字 ≥300，非承重" --> 。

  将显示[应用颜色选项(Apply Color Options)](../多边形建模参考/“建模”%28Modeling%29菜单集/网格显示%28Mesh%20Display%29/应用颜色选项%28Apply%20Color%20Options%29.md)。

2. 请执行下列操作之一：

  - 单击“替换”(Replace)颜色，以便为这些顶点设定颜色。

  - 单击“添加”(Add)颜色或“减去”(Subtract)颜色，将此处所选颜色的 RGB 值添加或减去到顶点的当前颜色。该功能适用于同时将白、红、绿、蓝、青、黄或洋红从许多不同颜色的顶点中添加或减去。

3. 单击颜色样例，以便使用颜色编辑器来编辑颜色；或者单击“抓取颜色”(Grab color)按钮（滴管图标），然后在屏幕上单击任意像素以拾取该像素颜色。

4. 单击“应用颜色”(Apply Color)。

  **注**

  逐顶点颜色动画不适用于不具有建模/构建历史的多边形对象。通过选择对象，然后选择

  “编辑网格 > 变换”(Edit Mesh > Transform)

  ，可以在不移动任何内容的情况下在模型上快速创建历史。
