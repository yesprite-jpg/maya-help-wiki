# 使用逐顶点颜色数据为多边形上色

除了将着色器指定给多边形网格外，您还可以将颜色指定给与多边形面相关联的每个顶点。逐顶点颜色数据 (CPV) 通常应用于为使交互式视频游戏更高效地模拟着色和预照明效果而创建的 3D 模型。

即使在几个面共享一个多边形顶点时，也可以指定逐顶点颜色数据，该多边形顶点针对每个共享它的每个面都有一种颜色。面顶点处的颜色将跨面融合在一起。

保存逐顶点颜色数据时，将其单独存储在场景文件中。您还可以将一组或多组 CPV 数据（称为颜色集）应用到多边形网格。
