# 多边形组件显示

Maya 默认的多边形组件显示使用不同的颜色和尺寸，帮助您识别选定和未选定组件。

| 组件 | 未选定 | 选定 |
|---|---|---|
| 顶点 | 小紫框。 | 黄色。 |
| 边 | 浅蓝色。 | 浅橙色。 |
| 边界边 | 较粗的线。 |  |
| 面 | 处于中心的蓝色圆点。 | 浅橙色。 |
| UV | 中紫框。 | 鲜绿色。 |
