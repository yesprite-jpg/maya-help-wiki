# 使用四边形绘制填充洞

您可以通过“四边形绘制”(Quad Draw)工具使用四边形或三角形（四边形通常更适用于变形）填充现有网格上的间隙。

使用“四边形绘制”(Quad Draw)填充洞

1. 选择网格。

2. 激活[四边形绘制(Quad Draw)](../../多边形建模参考/多边形建模工具/四边形绘制工具.md)工具。

3. 在按住 Shift 键的同时将光标移动到孔上。

  “四边形绘制”(Quad Draw)工具将进入预览模式。如果要创建的面是三角形，它将以紫色亮显：

  ![图：在按住 Shift 键的同时将光标移动到孔上。 “四边形绘制”(Quad Draw)工具将进入预览模式。如果要创建的面是…](../../../../../../assets/Maya-Modeling/GUID-354C98E5-21E8-418C-B780-CA409AB78A41.png) <!-- baize:img-hook downloaded=true reason="正文 240 字 <300 且带图" -->

  但如果要创建的面是四边形，它将以绿色亮显：

  ![图：在按住 Shift 键的同时将光标移动到孔上。 “四边形绘制”(Quad Draw)工具将进入预览模式。如果要创建的面是…](../../../../../../assets/Maya-Modeling/GUID-6A06BA3A-23AD-4CF7-8873-2CECF6F4F01F.png) <!-- baize:img-hook downloaded=true reason="正文 240 字 <300 且带图" -->

4. 按住 Shift 键单击面预览。

  此时将显示新面，并填充孔。
