# 使用四边形绘制添加多边形

您可以使用“四边形绘制”(Quad Draw)工具向现有网格添加新的多边形面。如果要附加包含新细节的基础形状，这将非常有用。

使用四边形绘制添加多边形

1. 选择要将多边形添加到的网格。

2. 激活[四边形绘制(Quad Draw)](../../多边形建模参考/多边形建模工具/四边形绘制工具.md)工具。

3. 如同任何常规“四边形绘制”(Quad Draw)操作一样[删除点](使用四边形绘制重新拓扑网格/使用四边形绘制删除点.md)并[创建多边形](使用四边形绘制重新拓扑网格/使用四边形绘制创建多边形.md)。

  您可以在点与现有顶点的组合之间创建四边形或三角形。

**注**

如果在

拓扑对称(Topological Symmetry)

处于启用状态时向不对称网格添加多边形，则

“四边形绘制”(Quad Draw)

工具可能会在镜像侧上生成层状体面或其他不需要的构造。之后，建议仅在网格 100% 对称或运行

“清理”(Cleanup)命令

时才使用对称“四边形绘制”(Quad Draw)移除任何不需要的组件构造。
