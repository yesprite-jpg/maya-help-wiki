# 使用四边形绘制删除组件

使用四边形绘制删除组件

1. 请确保“四边形绘制”(Quad Draw)处于启用状态。

2. 请执行下列任一操作：

  - 要删除面，请在按住 Ctrl + Shift 的同时单击一个面。

  - 要删除循环边，请在按住 Ctrl + Shift 的同时单击一个循环边。

    **注**

    如果要删除边界循环边，相应的边界面也将被删除。
