# 使用四边形绘制插入循环边

1. 按 Ctrl 键并将鼠标移至网格上。

  此时，网格中将显示绿色虚线循环边预览线，指示将插入新循环边的位置。

2. 单击即可插入循环边。

插入捕捉至面中心的循环边

1. 按住 Ctrl 键并使用鼠标中键将鼠标拖动到网格上。

2. 单击即可插入循环边。
