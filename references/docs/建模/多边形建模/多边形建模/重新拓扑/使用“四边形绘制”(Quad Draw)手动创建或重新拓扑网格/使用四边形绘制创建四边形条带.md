# 使用四边形绘制创建四边形条带

创建四边形条带

1. [设定引用网格](使用四边形绘制重新拓扑网格/设置四边形绘制的引用网格.md)。

2. 按住 Tab 键并单击鼠标中键进行拖动以调整四边形的大小。

  **注**

  提示：

  可以使用

  “四边形绘制选项”(Quad Draw Options)

  中的

  “四边形条宽”(Quad Strip Width)

  字段设置特定宽度。

3. 按住 Tab 键并沿引用网格拖动以创建条带。

4. 使用[四边形绘制热键](四边形绘制工具热键.md)优化条带。
