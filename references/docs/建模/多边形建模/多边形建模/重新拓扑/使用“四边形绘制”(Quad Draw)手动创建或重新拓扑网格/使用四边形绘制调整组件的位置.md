# 使用四边形绘制调整组件的位置

1. 请执行下列任一操作：

  - 拖动组件。

  - Ctrl + 使用鼠标中键拖动边循环。

  **注**

  提示：

  启用

  “自动焊接”(Auto-weld)

  选项后，如果调整顶点或边，

  “四边形绘制”(Quad Draw)

  会自动焊接移近的组件。
