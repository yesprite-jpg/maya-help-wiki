# 使用四边形绘制创建多边形

使用四边形绘制创建多边形

1. 确保“四边形绘制”(Quad Draw)工具处于启用状态。请参见[使用四边形绘制重新拓扑网格](../使用四边形绘制重新拓扑网格.md)。

2. 在场景中，按住 Shift 键的同时，将光标移动到点上方。

  “四边形绘制”(Quad Draw)工具进入面预览模式，可能的面以绿色亮显。

  这有助于预览面，因为一组点可能有许多种面组合。

3. 在按住 Shift 键的同时单击面预览。

  已创建名为 polySurface1 的新曲面。

  ![图：在按住 Shift 键的同时单击面预览。 已创建名为 polySurface1 的新曲面。 提示： 选择“着色 着色对象…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-ADFA75D4-2088-4827-BCA7-ACB4810AAB90.png) <!-- baize:img-hook downloaded=false reason="正文 378 字 ≥300，非承重" -->

  **注**

  提示：

  选择

  “着色 > 着色对象上的线框”(Shading > Wireframe on Shaded)

  叠加引用网格上的线框。

4. 通过放置其他点和延伸现有边继续添加面。请参见[使用四边形绘制延伸边](../使用四边形绘制延伸边.md)。

5. 在新网格中填充三角形的孔。请参见[使用四边形绘制填充洞](../使用四边形绘制填充洞.md)。

6. 使用“四边形绘制”(Quad Draw)热键来优化新网格。请参见[使用四边形绘制细化多边形](使用四边形绘制细化多边形.md)。
