# 使用四边形绘制删除点

点（顶点）会创建多边形的框架。

使用四边形绘制删除点

1. 确保已启用“四边形绘制工具”(Quad Draw Tool)。请参见[使用四边形绘制重新拓扑网格](../使用四边形绘制重新拓扑网格.md)。

2. （可选）如果要沿轴创建对称点，请在“建模工具包”(Modeling Toolkit)中适当地设置“对称”(Symmetry)。

3. 单击引用网格上的任意位置。

  此时将显示一个绿色点并捕捉到引用网格的曲面。

4. 单击引用网格上的任意位置。

  此时将显示一个绿色点并捕捉到引用网格的曲面。

5. （可选）将点拖动到新位置以将其重新定位。

6. （可选）按住 Ctrl + Shift 并单击一个点以将其移除，或在“建模工具包”(Modeling Toolkit)面板中，打开 “四边形绘制选项”(Quad Draw Options)，然后单击“清除点”(Clear Dots)移除引用网格中的所有点。

7. 继续删除点，直到您准备好创建多边形。请参见[使用四边形绘制创建多边形](使用四边形绘制创建多边形.md)。
