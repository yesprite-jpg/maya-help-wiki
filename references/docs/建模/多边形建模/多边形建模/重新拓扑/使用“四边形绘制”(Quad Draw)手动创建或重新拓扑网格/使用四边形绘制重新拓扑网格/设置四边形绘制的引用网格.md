# 设置四边形绘制的引用网格

引用网格是要重新拓扑的模型。如果不设定引用网格，“四边形绘制”(Quad Draw)工具会自动捕捉到栅格。

设定引用网格

1. 选择要用作引用网格的对象。

  引用曲面可以是多边形网格、NURBS 曲面、[GPU 缓存节点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C893BE60-6E65-4F36-8005-FD4D1A0E9822)或构造平面。

2. 执行下列操作之一：

  - 单击“状态行”(Status Line)中的![图：单击“状态行”(Status Line)中的“激活”(Make Live)图标 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-D74884C1-B136-4190-ACA4-866BE1EAF4B9.png) <!-- baize:img-hook downloaded=false reason="正文 371 字 ≥300，非承重" -->“激活”(Make Live)图标 。

  - 在该对象上单击鼠标右键，然后选择“激活”(Make Live)。

  网格变为激活状态，并且“四边形绘制”(Quad Draw)工具会捕捉到其曲面。

3. （可选）选择引用网格，然后选择“建模工具包”(Modeling Toolkit)菜单中的“对象 > 开启/关闭 X 射线”(Object > X-Ray On/Off)。

  引用网格变为透明，使新拓扑更容易看到。

4. 开始下降点。请参见[使用四边形绘制下降点](使用四边形绘制删除点.md)。
