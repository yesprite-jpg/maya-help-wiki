# 使用四边形绘制延伸边

使用“延伸”(Extend)工具加快拓扑创建速度。您可以通过拖动现有边、循环边、边界和顶点快速创建新多边形。

延伸边

1. [打开四边形绘制工具(Quad Draw Tool)](../../多边形建模参考/多边形建模工具/四边形绘制工具.md)。

2. 从[“四边形绘制工具”(Quad Draw Tool)标记菜单](../../多边形建模参考/多边形建模工具/四边形绘制工具/四边形绘制工具标记菜单.md)（Ctrl + Shift + 单击鼠标右键）或[“四边形绘制选项”(Quad Draw Options)](../../多边形建模参考/多边形建模工具/四边形绘制工具.md#GUID-20DEA0B6-C090-49EA-98AE-172F1C382A05__GUID-23D9729A-80BF-48C2-BB0C-71D6DC92175C)中选择“延伸”(Extend)选项。

3. 按 Tab 在场景视图中拖动边。

  选定“边”(Edge)延伸选项后，还可以拖动顶点以创建多边形。

  **注**

  提示：

  如果

  “自动焊接”(Auto-weld)

  处于启用状态，并且您延伸边，则

  “四边形绘制”(Quad Draw)

  工具自动将相邻边和顶点焊接在一起。

延伸循环边的步骤

1. 选择了任何[“延伸”(Extend)](../../多边形建模参考/多边形建模工具/四边形绘制工具.md#GUID-20DEA0B6-C090-49EA-98AE-172F1C382A05__GUID-23D9729A-80BF-48C2-BB0C-71D6DC92175C)选项时，按 Tab 键并单击鼠标中键拖动边界边来延伸循环。
