# 使用四边形绘制重新拓扑网格

通过重新拓扑可以基于引用曲面的特征生成整洁的新拓扑。使用[“四边形绘制”(Quad Draw)工具](../../多边形建模参考/多边形建模工具/四边形绘制工具.md)，可以重新拓扑网格，包括从其他应用程序中导入的三角形网格。

使用四边形绘制工具(Quad Draw Tool)重新拓扑网格

1. [设置参考网格](使用四边形绘制重新拓扑网格/设置四边形绘制的引用网格.md)：将“四边形绘制”(Quad Draw)工具捕捉到您要重新拓扑的网格。

2. 通过执行下列操作之一打开“四边形绘制工具”(Quad Draw Tool)：

  - 从[“建模工具包”(Modeling Toolkit)](../../多边形建模参考/多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)窗口的“工具”(Tools)部分中，单击 ![图：从“建模工具包”(Modeling Toolkit)窗口的“工具”(Tools)部分中，单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-39135AA5-5A05-4CCF-9BEF-C87067D0721F.png) <!-- baize:img-hook downloaded=false reason="正文 433 字 ≥300，非承重" -->。

  - 从主菜单栏中，选择“网格工具 > 四边形绘制”(Mesh Tools > Quad Draw)。

  - 从标记菜单中，选择“四边形绘制工具”(Quad Draw Tool)。（若要打开标记菜单，请按 Shift 键并在场景中单击鼠标右键。）

3. [放置点](使用四边形绘制重新拓扑网格/使用四边形绘制删除点.md)：定义顶点。

4. [创建多边形](使用四边形绘制重新拓扑网格/使用四边形绘制创建多边形.md)：创建四边形并填充三角形的孔。

5. [细化多边形](使用四边形绘制重新拓扑网格/使用四边形绘制细化多边形.md)：清理新拓扑。

6. 完成后，再次单击 ![图：完成后，再次单击 以退出工具。 提示： 切换到其他工具后，可以按 Y 键重新激活“四边形绘制工具”(Quad Draw …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-39135AA5-5A05-4CCF-9BEF-C87067D0721F.png) <!-- baize:img-hook downloaded=false reason="正文 433 字 ≥300，非承重" --> 以退出工具。
