# 四边形绘制工具热键

下表列出了“四边形绘制”(Quad Draw)工具的默认热键。

**注**

提示：

使用

建模首选项

中的选项，可以更改

“四边形绘制”(Quad Draw)

工具的默认热键映射，以适合您的工作流。

| 热键 | 对四边形网格进行操作 | 取消对四边形网格的操作 |
|---|---|---|
| 单击引用曲面或栅格 | [下降点](使用四边形绘制重新拓扑网格/使用四边形绘制删除点.md) |  |
| 拖动 或 使用鼠标中键拖动 | [调整组件](使用四边形绘制调整组件的位置.md) |  |
| 按住 Shift 键并拖动 | [松弛顶点](使用四边形绘制松弛顶点.md) | [创建四边形或三角形](使用四边形绘制重新拓扑网格/使用四边形绘制创建多边形.md) |
| 按住 Shift 键并使用鼠标中键拖动 | [松弛顶点的选择](使用四边形绘制松弛顶点.md) |  |
| 按住 Ctrl 键并单击 | [插入循环边](使用四边形绘制插入循环边.md) |  |
| Ctrl + 单击鼠标中键 | [插入捕捉至面中心的循环边](使用四边形绘制插入循环边.md) |  |
| 同时按住 Ctrl 和 Shift 键并单击 | [删除组件](使用四边形绘制删除组件.md) |  |
| 按住 Ctrl + Shift 键并使用鼠标中键拖动 | [移动循环边](使用四边形绘制调整组件的位置.md) |  |
| 按 Tab 键并拖动 | [延伸边](使用四边形绘制延伸边.md) | [创建四边形带](使用四边形绘制创建四边形条带.md) |
| 按住 Tab 并使用鼠标中键拖动 | [延伸循环边](使用四边形绘制延伸边.md) | [调整四边形带大小](使用四边形绘制创建四边形条带.md) |
| Y | 重新激活“四边形绘制工具”(Quad Draw Tool) | 重新激活“四边形绘制工具”(Quad Draw Tool) |
| 按 Ctrl + Shift 键并单击鼠标右键 | 打开“四边形绘制工具”(Quad Draw Tool)标记菜单 |  |
