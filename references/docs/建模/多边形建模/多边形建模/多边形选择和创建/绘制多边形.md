# 绘制多边形

您可以使用顶点开始绘制多边形网格，而不是从基本体形状开始。如果具有要跟踪的特定 2D 形状，这将非常有用。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-221E7F33-BF6F-45FE-8008-1DF914EAA4AC.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" -->

创建新多边形

1. 选择“网格工具 > 创建多边形工具”(Mesh Tools > Create Polygon Tool)。

2. 单击可放置第一个顶点。

  除非您将顶点们捕捉到现有几何体，否则 Maya 会将其放置在地平面上。

  ![图：单击可放置第一个顶点。 除非您将顶点们捕捉到现有几何体，否则 Maya 会将其放置在地平面上。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-495EE7AB-20E8-4EAF-99FF-03DB18AE2756.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" -->

3. 单击可放置下一个顶点。Maya 将在放置的第一个点和最后一个点之间创建一条边。

  ![图：单击可放置下一个顶点。Maya 将在放置的第一个点和最后一个点之间创建一条边。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-D573BA3B-3E28-4A9B-BD3A-6DE7FE74530D.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" -->

4. 放置另一个顶点。一条虚线边将连接三个顶点。

  **注**

  重要：

  顶点的放置方式决定面法线的方向。如果以顺时针方向放置顶点，则面法线指向下方。如果以逆时针方向放置顶点，则面法线指向上方。

  ![图：放置另一个顶点。一条虚线边将连接三个顶点。 重要： 顶点的放置方式决定面法线的方向。如果以顺时针方向放置顶点，则面法线指…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-26CD0C7C-EBE2-4A2D-B22C-62AB6830AB1A.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" -->

5. 请执行下列任一操作：

  - 按 Enter 键以完成多边形创建。

  - 按 Delete 键以删除放置的最后一个点。

  - 按 Y 键开始创建新多边形。

  - 继续放置顶点以创建四边形或 n 边多边形。

  - 若要切换以编辑顶点，请按 Home 键或 Insert 键。将有一个操纵器显示在上一个顶点上。使用该操纵器来移动顶点，按 Delete 键删除一个分段，或单击另一个顶点来进行编辑。再次按 Home 键或 Insert 键以完成操作。

    ![图：若要切换以编辑顶点，请按 Home 键或 Insert 键。将有一个操纵器显示在上一个顶点上。使用该操纵器来移动顶点，按…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-1912202C-E10D-4B45-919C-1026BF0A8C64.png) <!-- baize:img-hook downloaded=false reason="正文 540 字 ≥300，非承重" -->
