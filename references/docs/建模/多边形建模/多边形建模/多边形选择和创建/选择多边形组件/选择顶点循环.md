# 选择顶点循环

顶点循环选择可以选择多边形网格上的多个顶点，而不必单独选择每个顶点。详细信息请参见[多边形组件循环和环形](../../多边形组件循环和环形.md)。

选择多边形网格上的顶点循环

1. 在场景视图中，在一个多边形网格上单击鼠标右键，并从标记菜单中选择“顶点”(Vertex)。

2. 在要选择的顶点循环上选择一个顶点。

3. 按住 Shift 键并双击要选择的顶点循环方向上连接到相邻边的顶点。

  相同线上的所有顶点都将选中。

选择多边形网格上的部分顶点循环

1. 在场景视图中，在一个多边形网格上单击鼠标右键，并从标记菜单中选择“顶点”(Vertex)。

2. 在要选择的顶点循环上选择一个顶点。

3. 按住 Shift 键并双击相同经度线或纬度线上不相邻的顶点。

  两个顶点之间的所有顶点都将选中。

**注**

先前循环选择中的顶点可以重用作另一循环选择的第一个选中顶点。可以使用该方法选择多向顶点循环。
