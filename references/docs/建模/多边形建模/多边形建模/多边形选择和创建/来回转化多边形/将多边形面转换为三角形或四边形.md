# 将多边形面转换为三角形或四边形

将多边形面转化为三角形是确保非平面正确渲染的一种快速途径。将多边形面转化为四边形则是清理多边形或减少面数的一种良好方式。

将面转化为三角形或四边形

1. 选择面。

2. 执行下列操作之一：

  - 选择网格 > 三角化(Mesh > Triangulate)。

  - 选择网格 > 四边形化(Mesh > Quadrangulate)。

**注**

尝试四边形化 n 边形可能不会产生任何影响。为此，通常需要先三角化面，然后再四边形化结果。
