# 使用“创建”(Create)菜单创建多边形基本体

通过从“创建”(Create)菜单选择来创建基本体可以指定基本体属性，然后再创建基本体。使用该方法，在 X、Y、Z 原点处创建基本体。

使用“创建”(Create)菜单在 X、Y、Z 原点处创建基本体

1. 选择创建 > 多边形基本体(Create > Polygon Primitives)，然后从基本体列表中选择基本体选项框。例如，“球体”(Sphere) > ![图：选择创建 多边形基本体(Create Polygon Primitives)，然后从基本体列表中选择基本体选项框。例如，…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 572 字 ≥300，非承重" --> 或“立方体”(Cube) > ![图：选择创建 多边形基本体(Create Polygon Primitives)，然后从基本体列表中选择基本体选项框。例如，…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 572 字 ≥300，非承重" -->。

  选择基本体旁边的 ![图：选择基本体旁边的 时，将显示该基本体的“工具设置”(Tool Settings)窗口。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 572 字 ≥300，非承重" --> 时，将显示该基本体的“工具设置”(Tool Settings)窗口。

2. 在基本体的“工具设置”(Tool Settings)窗口中，根据需要编辑基本体的属性。

  可以设定指定半径、缩放和细分的属性以及指定默认 UV 纹理坐标是否与基本体一同创建的属性。

3. 单击“创建”(Create)。

  基本体对象将显示在场景视图的 X、Y、Z 原点处。默认情况下，基本体保持选定状态，因此可以对它执行其他操作，如“移动”(Move)、“旋转”(Rotate)或“缩放”(Scale)。

  **注**

  创建基本体后，可以使用通道盒或属性编辑器修改其属性。

4. 按 T 键以激活“显示操纵器工具”(Show Manipulator Tool)。

5. 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 poly<shape> 节点属性。
