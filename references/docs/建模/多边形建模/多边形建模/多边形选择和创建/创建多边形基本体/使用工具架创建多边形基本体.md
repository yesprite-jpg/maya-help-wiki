# 使用工具架创建多边形基本体

可以使用工具架创建多边形基本体。工具架中提供了许多可轻松选择的基本体图标。使用工具架，还可以设定基本体的选项，然后将该基本体的自定义版本保存到工具架，以便将来使用。有关详细信息，请参见[向工具架添加工具、操作或 Maya 脚本](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-C693E884-F81A-4858-B5D6-3856EB8F394E)。

使用工具架创建多边形基本体

1. 在场景视图中，选择工具架中的“多边形”选项卡。

2. 单击多边形基本体图标。

  根据“交互式创建”(Interactive Creation)选项的设定方式，基本体将出现在原点，或者系统将提示您单击并拖动，以在场景中创建基本体。有关详细信息，请参见以下主题：

  - [以交互方式创建多边形基本体](以交互方式创建多边形基本体.md)

  - [使用创建菜单创建多边形基本体](使用“创建”%28Create%29菜单创建多边形基本体.md)

3. 按 T 键以激活“显示操纵器工具”(Show Manipulator Tool)。

4. 在显示的[视图中编辑器](../../多边形建模参考/多边形建模编辑器/视图中编辑器.md)中，调整 poly<shape> 节点属性。
