# 导入向量数据作为曲线或生成多边形曲面

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-ED2C8E91-03B4-4AD2-A2EA-ADE42A7D4B4A.png) <!-- baize:img-hook downloaded=false reason="正文 342 字 ≥300，非承重" -->

您可以使用 [SVG 工具](../从%20SVG%20对象创建多边形网格.md)将在 Adobe® Illustrator® 中创建的 2D SVG 对象作为 3D 几何体导入。

导入 SVG 对象

1. 单击“多边形”(Polygons)工具架中的 SVG 图标，或转到“创建 > SVG”(Create > SVG)。

2. 在“属性编辑器”(Attribute Editor)中的“SVG”选项卡下，单击“粘贴”(Paste)以导入复制的 SVG 对象，或单击“导入”(Import)并从文件浏览器中导航到 SVG 文件。

**注**

您也可以使用

“创建 > Adobe Illustrator 对象”(Create > Adobe Illustrator Object)

以完成同样的操作，尽管具有更多的限制。有关更多信息，请参见

“Adobe Illustrator 对象”(Adobe Illustrator Object)选项

。
