本示例说明了如何使用[“扫描网格”(Sweep Mesh)工具](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具.md)中的自定义扫描创建图片框架。可以使用这些设置快速创建天花线、门、框架等。

使用“扫描网格”(Sweep Mesh)创建基本框架

1. 从简单的二维方形开始。若要快速创建方形，请选择“创建 > 曲线工具 > 创建 EP 曲线”(Create > Curve Tools > Create EP Curve)。将 [EP 曲线工具选项(EP Curve Tool Options)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-374194A8-C9FE-4B69-BA63-82E073D4482F)中的**“曲线次数”(Curve Degree)**设置设为**“线性”(Linear)**。

2. 在视口中绘制矩形的三条边，然后选择“曲线 > 闭合”(Curves > Close)以添加缺少的边。

3. 在原点处创建一条要用作图案的剖面曲线。它将用于定义挤出的形状。

  ![图：在原点处创建一条要用作图案的剖面曲线。它将用于定义挤出的形状。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-BFE666CB-5190-4832-9AC5-E55B0681E09B.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

4. 选择该方形，然后从“多边形建模”(Poly Modeling)工具架中选择“扫描网格”(Sweep Mesh) ![图：选择该方形，然后从“多边形建模”(Poly Modeling)工具架中选择“扫描网格”(Sweep Mesh) ，或在 …](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-DC8543C9-FAAD-453D-9063-8EAD87CC1BD1.png) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->，或在 [Maya 主菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-AF592D59-02CB-4B97-9C57-37795C8B1D8A)中选择“创建 > 扫描网格”(Create > Sweep Mesh)。此时将显示[“扫描网格”(Sweep Mesh)选项](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具/“扫描网格”%28Sweep%20Mesh%29选项.md)。将创建具有圆角的框架的默认扫描网格。

5. 将**“扫描剖面”(Sweep Profile)**设置为**“矩形”(Rectangle)**。

6. 减小**“角半径”(Corner Radius)**以创建尖角。

  ![图：减小“角半径”(Corner Radius)以创建尖角。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-546D6885-FC1F-4D0C-9F84-0723333AEF63.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

7. 调整**“高度”(Height)**和**“宽度”(Width)**设置以更改框架的总体大小。

在接下来的一组步骤中，可以使用剖面曲线将更多细节添加到框架。

使用剖面曲线和自定义扫描

1. 使用在上述步骤中创建的基本框架形状，在[“扫描网格”(Sweep Mesh)工具](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具.md)中，选择**“自定义”(Custom)**。此时将打开**“自定义扫描剖面”(Custom Sweep Profile)**对话框。

  ![图：使用在上述步骤中创建的基本框架形状，在“扫描网格”(Sweep Mesh)工具中，选择“自定义”(Custom)。此时将…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-5189157C-B4B2-4B7E-935C-C5C92DF4AFD6.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

2. 确保将“类型”(Type)设置为**“曲线对象”(Curve Object)**，然后单击“剖面曲线”(Profile Curve)。

  ![图：确保将“类型”(Type)设置为“曲线对象”(Curve Object)，然后单击“剖面曲线”(Profile Curv…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-78F5FC3B-D57E-4BB1-B6EA-BFD33652F7D6.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

3. 剖面曲线的方向会影响网格上的结果。可沿不同方向旋转剖面曲线以查看各种结果。

  ![图：剖面曲线的方向会影响网格上的结果。可沿不同方向旋转剖面曲线以查看各种结果。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-65169442-E756-4888-9192-18BCF8A4BFC0.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

4. 当框架看起来合适时，在“自定义扫描剖面”(Custom Sweep Profile)对话框中单击**“确定”(OK)**。单击**“确定”(OK)**将设置当前剖面曲线方向。

5. 缩放框架网格以更改其尺寸。

扫描网格与剖面曲线保持实时链接，以便对其所做更改也会更改生成的网格。这样，您可以在工作时调整结果。有关此效果的演示，请参见以下工作流。

通过修改剖面曲线来更改自定义扫描网格

该工作流使用上述工作流中的框架网格和剖面示例来演示扫描网格如何连接到剖面曲线并在您进行更改时进行更新。

1. 使用上例中的剖面曲线，复制 (**Ctrl** + **D**) 剖面曲线，然后将其移动到原始剖面曲线旁。

  ![图：使用上例中的剖面曲线，复制 (Ctrl + D) 剖面曲线，然后将其移动到原始剖面曲线旁。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-4B73A709-6BB0-42A4-A4FB-6006F0FFA023.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

2. 选择框架，然后在“属性编辑器”(Attribute Editor)中选择**“扫描网格创建器 1”(Sweep Mesh Creator1)**以查看[“扫描网格”(Sweep Mesh)工具](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具.md)。

3. 在[“扫描网格”(Sweep Mesh)选项](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具/“扫描网格”%28Sweep%20Mesh%29选项.md)中单击**“自定义”(Custom)**，此时将打开“自定义扫描剖面”(Custom Sweep Profile)对话框。

4. 选择复制的剖面曲线，然后在“自定义扫描剖面”(Custom Sweep Profile)对话框中单击**“确定”(OK)**，将第二条剖面曲线设置为框架的驱动者。

  ![图：选择复制的剖面曲线，然后在“自定义扫描剖面”(Custom Sweep Profile)对话框中单击“确定”(OK)，将…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-E00B01BC-A1AD-409C-BBA7-B2890C10CE9B.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

5. 修改第二条剖面曲线。例如，对其进行缩放，或在其上单击鼠标右键，选择**“控制顶点”(Control Vertex)**，然后移动这些点。

  ![图：修改第二条剖面曲线。例如，对其进行缩放，或在其上单击鼠标右键，选择“控制顶点”(Control Vertex)，然后移动…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-B7DAA6ED-6EF5-43FF-9946-FDED9E9A1625.gif) <!-- baize:img-hook downloaded=false reason="正文 1545 字 ≥300，非承重" -->

  默认情况下，原始框架曲线（方形）埋在网格的中心，这可能会造成难以选择它。您可以在[大纲视图(Outliner)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4B9A9A3A-83C5-445A-95D5-64104BC47406)中选择曲线，也可以在[“扫描网格”(Sweep Mesh)工具](../../多边形建模参考/多边形建模工具/“扫描网格”%28Sweep%20Mesh%29工具.md)的**“对齐”(Alignment)**设置中进行更改，方法是将**“水平”(Horizontal)**设置更改为“顶”(Top)或“底”(Bottom)，将**“垂直”(Vertical)**设置更改为“左”(Left)或“右”(Right)。
