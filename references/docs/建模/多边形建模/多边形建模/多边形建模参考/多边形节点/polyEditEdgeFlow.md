# polyEditEdgeFlow

在执行和使用“编辑边流”(Edit Edge Flow)命令时将会创建 polyEditEdgeFlow 节点。

## 多边形编辑边流历史

#### 边流(Edge Flow)

针对选定边启用和禁用边流。

#### 调整边流(Adjust Edge Flow)

输入值或调整滑块以更改选定边的形状。此选项允许您调整边流结果。

默认情况下，“调整边流”(Adjust Edge Flow)设置为 1。设置为 0 时，选定的边将移动到附近其他边的中间，从而形成平面。
