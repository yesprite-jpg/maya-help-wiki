# polyCBoolOp

执行布尔运算时，将会创建 polyCBoolOp 节点。请参见[关于布尔](../../编辑多边形/合并、分割和拆分/合并和分离多边形网格/布尔/关于布尔.md)。

可以使用下列属性编辑布尔运算。

#### 运算(Operation)

可用于在执行布尔运算之后应用其他类型的运算。

#### 并集(union)

合并选定网格的体积。

#### 差集(Difference)

从第一个选定网格减去第二个（以及后续）选定网格的体积。

**注**

借助布尔，可以通过一次

“差集”(Difference)

运算从第一个选择中提取多个网格。

#### 交集(Intersection)

仅保留选定网格的共享体积。

#### “使用阈值”(Use Thresholds)

启用时，布尔运算会使用指定的“顶点距离阈值”(Vertex Distance Threshold)和“面区域阈值”(Face Area Threshold)值自动检查并消除极小的面和边。默认情况下会禁用该属性。

**注**

重要：

“使用阈值”(Use Thresholds)

是旧版属性，仅当您执行具有旧版布尔算法的运算时才会有用。建议在使用布尔时，使该属性处于禁用状态。
