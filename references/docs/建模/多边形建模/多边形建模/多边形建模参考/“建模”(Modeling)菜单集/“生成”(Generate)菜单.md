## 相关服务

#### 角色生成器(Character Generator)

启动角色生成器网页。通过角色生成器，可以从实体类型、装备、发型和物理属性的目录创建、自定义和下载已装备的 3D 角色。

#### ReCap

启动 Autodesk® ReCap™ 网页。ReCap 是用于几种不同的 Autodesk Reality Capture 技术的基于 Web 的协作和创建环境。
