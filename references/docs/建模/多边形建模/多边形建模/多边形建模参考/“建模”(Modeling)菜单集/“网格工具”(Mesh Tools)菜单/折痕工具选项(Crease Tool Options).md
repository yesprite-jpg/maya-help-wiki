在“建模”(Modeling)菜单集中，选择“网格工具 > 折痕”(Mesh Tools > Crease) > ![图：在“建模”(Modeling)菜单集中，选择“网格工具 折痕”(Mesh Tools Crease) 可打开这些选项。有…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 674 字 ≥300，非承重" -->可打开这些选项。有关如何使用该工具的详细信息，请参见[为多边形边和顶点生成折痕](../../../编辑多边形/修改多边形网格/为多边形边和顶点生成折痕.md)。

#### 模式(Mode)

选择下列选项之一：

#### 绝对(Absolute)

启用“绝对”(Absolute)设置时，多个边和顶点的折痕是相同的。也就是说，如果选择多个边或顶点来生成折痕，且它们具有已存在的折痕，那么完成之后，所有选定组件将具有相似的折痕值。这是默认设置。折痕值可在 0 到 7 的范围内。值为 7 指示组件已完全折痕。

#### 相对(Relative)

启用“相对”(Relative)设置时，会相对于彼此维护多个边和顶点的折痕。希望维护网格上已存在的折痕，且需要增加或减少折痕总体数量时，请使用该设置。

**注**

使用折痕工具时，帮助行中会显示反馈。它显示对于网格上的当前细分级别可能的折痕

“模式”(Mode)

、

“当前折痕值”(current crease value)

和

“最大折痕值”(maximum crease value)

。将

“模式”(Mode)

设置为

“相对”(Relative)

时，显示在帮助行中的

“当前折痕值”(current crease value)

指示相对于那些组件的当前折痕设置的偏移值。

#### 选择(Selection)

启用“延伸到折痕组件”(Extend to creased components setting)设置时，会将折痕边的当前选择自动延伸到连接到当前选择的任何折痕。这样可省去必须单独选择所有折痕的工作。生成顶点的折痕时，该选项没有任何效果。
