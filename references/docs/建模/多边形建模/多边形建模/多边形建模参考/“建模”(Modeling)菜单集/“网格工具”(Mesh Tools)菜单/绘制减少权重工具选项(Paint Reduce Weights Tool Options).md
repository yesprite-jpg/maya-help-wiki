# 绘制减少权重工具选项(Paint Reduce Weights Tool Options)

“绘制减少权重”(Paint Reduce Weights)与“网格 > 减少”(Mesh > Reduce)功能一起使用时，可以支持您在尝试保留原始图形的同时，减少网格中的多边形数量。使用“绘制减少权重工具”(Paint Reduce Weights Tool)，可以在网格中绘制，以指定要减少多边形的网格中的区域。

**注**

若要使用

“绘制减少权重工具”(Paint Reduce Weights Tool)

，必须已在启用

“保持原始”(Keep Originals)

的前提下使用

“减少”(Reduce)

功能，这样才能为要减少的对象创建

“polyReduce 节点”(polyReduce node)

。

为此，请先选择多边形网格，然后选择“网格 > 减少”(Mesh > Reduce) > ![图：为此，请先选择多边形网格，然后选择“网格 减少”(Mesh Reduce) 。启用“保持原始”(Keep Origina…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-96432FB8-EBE9-4D1A-8DED-5173E032EBC0.png) <!-- baize:img-hook downloaded=false reason="正文 419 字 ≥300，非承重" -->。启用“保持原始”(Keep Original)选项，然后单击“减少”(Reduce)。稍后，您可在原始网格中绘制，且网格副本将会减少。
