# 连接工具选项(Connect Tool Options)

使用这些选项可设置在使用连接工具时发生的情况。选择“网格工具 > 连接工具”(Mesh Tools > Connect Tool) > ![图：使用这些选项可设置在使用连接工具时发生的情况。选择“网格工具 连接工具”(Mesh Tools Connect Tool…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 300 字 ≥300，非承重" -->，单击“建模工具包”(Modeling Toolkit)中的 ![图：使用这些选项可设置在使用连接工具时发生的情况。选择“网格工具 连接工具”(Mesh Tools Connect Tool…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-875D90E7-318D-45B0-88D3-18CD8C53DAF7.png) <!-- baize:img-hook downloaded=false reason="正文 300 字 ≥300，非承重" -->，或从[顶点(Vertex)标记菜单](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-8BA1A3AA-4C44-4779-8B22-0AAE3627E8EB)中选择该工具时，“建模工具包”(Modeling Toolkit)中将显示以下选项。有关如何使用该工具的详细信息，请参见[连接多边形组件](../../../编辑多边形/合并、分割和拆分/分割多边形组件/使用连接工具在多边形组件之间添加边.md)。

#### 滑动(Slide)

指定在网格上的什么位置插入边。在将“滑动”(Slide)设置为 0.50（默认值）时，边将插入面中间。

![图：指定在网格上的什么位置插入边。在将“滑动”(Slide)设置为 0.50（默认值）时，边将插入面中间。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-CA1F8FFF-17E3-4082-91EE-12C964D65497.png) <!-- baize:img-hook downloaded=false reason="正文 300 字 ≥300，非承重" -->

#### 分段(Segments)

指定插入网格中的已连接的分段数。默认值为 1。

![图：指定插入网格中的已连接的分段数。默认值为 1。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-3A1037B5-59AE-4806-B50B-79EF5B76FB99.png) <!-- baize:img-hook downloaded=false reason="正文 300 字 ≥300，非承重" -->

#### 收缩(Pinch)

指定外侧边和已连接分段之间的距离。

![图：指定外侧边和已连接分段之间的距离。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-3FA9751A-AF2B-42F2-A60C-ADE22F1BC4DE.png) <!-- baize:img-hook downloaded=false reason="正文 300 字 ≥300，非承重" -->
