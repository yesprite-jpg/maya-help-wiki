使用这些选项可设置在使用“目标焊接工具”(Target Weld Tool)时发生的情况。单击顶点或边并将其拖动到目标可合并所有选定顶点或边。有关如何使用该工具的详细信息，请参见[合并多边形组件](../../../编辑多边形/合并、分割和拆分/合并多边形/使用目标焊接工具%28Target%20Weld%20Tool%29以交互方式合并多边形组件.md)。

#### 合并到(Merge To)

##### 目标(Target)

（默认）目标顶点将成为新顶点，源顶点将被删除。

##### 中心(Center)

将在与源和目标组件等距的地方创建新顶点或边。然后移除源和目标组件。 ![图：将在与源和目标组件等距的地方创建新顶点或边。然后移除源和目标组件。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-5379F79C-A919-4CFD-8635-2F5AE1E44B76.png) <!-- baize:img-hook downloaded=false reason="正文 434 字 ≥300，非承重" -->

#### 保持 UV

![图：在激活和未激活“保持 UV”(Preserve UVs)选项的情况下，在基本体上显示目标焊接。 处于活动状态时，UV 将…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-CB4BDBDE-3C6A-464D-AB16-4C6528EF2551.gif) <!-- baize:img-hook downloaded=false reason="正文 434 字 ≥300，非承重" -->

在激活和未激活“保持 UV”(Preserve UVs)选项的情况下，在基本体上显示目标焊接。

处于活动状态时，UV 将调整以保留 3D 纹理放置。该设置为默认设置。

如果希望在调整顶点或边时 3D 纹理发生扭曲，则禁用此选项。
