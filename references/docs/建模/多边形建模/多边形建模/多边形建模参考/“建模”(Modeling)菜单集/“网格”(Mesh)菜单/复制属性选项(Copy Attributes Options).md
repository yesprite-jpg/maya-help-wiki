# 复制属性选项(Copy Attributes Options)

使用这些选项可设置在选择“网格 > 剪贴板操作 > 复制属性”(Mesh > Clipboard Actions > Copy Attributes)时发生的情况。

#### UV

将复制功能设定为将与选定多边形面相关的 UV 属性复制到剪贴板。

#### 着色器(Shader)

将复制功能设定为将与选定多边形面相关的着色器属性复制到剪贴板。

#### 颜色(Color)

将复制功能设定为将与选定多边形面相关的逐顶点颜色信息复制到剪贴板。
