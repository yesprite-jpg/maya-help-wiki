# 弯曲曲线选项(Bend Curves Options)

使用以下选项可设置在选择“曲线 > 弯曲”(Curves > Bend)时发生的情况。

#### 弯曲量(Bend Amount)

确定选定曲线的每个分段的弯曲程度。“弯曲量”(Bend Amount)越大，曲线的弯曲程度越大。由于“弯曲量”(Bend Amount)会影响每个分段，因此，具有较多 CV 的曲线将比具有较少 CV 的曲线弯曲程度更大。

#### 扭曲(Twist)

控制选定曲线的弯曲方向。
