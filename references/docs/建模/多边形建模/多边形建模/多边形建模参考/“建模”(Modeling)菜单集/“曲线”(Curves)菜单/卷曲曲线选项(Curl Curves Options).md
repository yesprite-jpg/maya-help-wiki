# 卷曲曲线选项(Curl Curves Options)

使用以下选项可设置在选择“曲线 > 卷曲”(Curves > Curl)时发生的情况。

#### 卷曲量(Curl Amount)

确定选定曲线的每个分段将被卷曲的量。“卷曲量”(Curl Amount)越高，产生的效果就越大。相对于具有较少 CV 的曲线，对具有多个 CV 的曲线产生的效果更大，因为“卷曲量”(Curl Amount)影响每个分段。

#### 卷曲频率(Curl Frequency)

确定选定曲线将被卷曲的量。
