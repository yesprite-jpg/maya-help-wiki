# 反转方向选项(Reverse Direction Options)

使用以下选项可设置在选择“曲线 > 反转方向”(Curves > Reverse Direction)时发生的情况。

#### 保持原始(Keep Original)

保留经过“反转曲线”(Reverse Curve)操作后的原始曲线。如果启用“保持原始”(Keep Original)（且构建历史处于启用状态），您可以使用“显示操纵器工具”(Show Manipulator Tool)单击一个操纵器以反转曲线方向。
