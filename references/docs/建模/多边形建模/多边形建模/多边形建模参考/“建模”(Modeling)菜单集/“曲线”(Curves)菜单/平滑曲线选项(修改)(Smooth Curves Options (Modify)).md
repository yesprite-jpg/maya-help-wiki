# 平滑曲线选项(修改)(Smooth Curves Options (Modify))

使用以下选项可设置在选择“曲线 > (修改)平滑”(Curves > (Modify) Smooth)时发生的情况。

#### 平滑因子(Smooth Factor)

确定选定曲线的每个分段要平滑的程度。“平滑因子”(Smooth Factor)越大，效果越好。曲线具有的 CV 越多，效果越好，因为“平滑因子”(Smooth Factor)会影响每个分段。
