# 楔形选项(Wedge Options)

使用这些选项可设置在选择“编辑网格 > 楔形”(Edit Mesh > Wedge)时发生的情况。

#### 弧形角度

围绕枢轴边旋转的度数。

#### 分段

围绕旋转的细分数。
