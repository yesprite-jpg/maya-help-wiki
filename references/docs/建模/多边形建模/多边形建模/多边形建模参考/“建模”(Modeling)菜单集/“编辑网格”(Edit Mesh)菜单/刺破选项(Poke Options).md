# 刺破选项(Poke Options)

使用这些选项可设置在选择“编辑网格 > 刺破”(Edit Mesh > Poke)时发生的情况。

#### 顶点偏移

指定 X、Y、Z 方向以及新顶点将与原始面的偏移距离。

#### 偏移空间

确定偏移的坐标空间。

#### World

以世界空间单位指定偏移。即，顶点将基于绝对 X、Y、Z 值偏移。

#### 局部

以局部空间单位指定偏移。即，顶点偏移将相对于对象单位。
