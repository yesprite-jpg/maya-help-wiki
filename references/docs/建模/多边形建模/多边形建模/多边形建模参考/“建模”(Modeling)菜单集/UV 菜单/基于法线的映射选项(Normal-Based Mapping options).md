# 基于法线的映射选项(Normal-Based Mapping options)

使用这些选项可设置在选择“UV > 基于法线”(UV > Normal-Based)时发生的情况。

## 设置

#### 保持比例(Keep Ratio)

保持图像的宽高比，使其不会扭曲。禁用该选项会使映射的 UV 填充 0-1 UV 空间。

#### 在变形器之前插入投影(Insert projection before deformers)

当网格应用了变形器时使用此选项可确保纹理放置不受移动的顶点位置影响。

#### UV 集(UV Set)

启用此选项可以将投影的 UV 放置在新的 UV 集中。可以在相应的字段中指定此新 UV 集的名称。
