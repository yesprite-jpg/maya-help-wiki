## 工具

#### 附加到多边形(Append to Polygon)

使用该工具，您可以将多边形添加到现有网格，将多边形边用作起始点。

#### 连接(Connect)

可以通过其他边连接顶点和/或边。请参见[使用连接工具在多边形组件之间添加边](../../编辑多边形/合并、分割和拆分/分割多边形组件/使用连接工具在多边形组件之间添加边.md)。

#### 折痕(Crease)

允许您在多边形网格上使边和顶点起折痕。可以使用折痕工具修改多边形网格，并获取在硬和平滑之间过渡的形状，而不会过度增大基础网格的分辨率。

选择“网格工具 > 折痕”(Mesh Tools > Crease) > ![图：选择“网格工具 折痕”(Mesh Tools Crease) ，可设置折痕工具选项(Crease Tool Option…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[折痕工具选项(Crease Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/折痕工具选项%28Crease%20Tool%20Options%29.md)。

提示：

“折痕工具”(Crease Tool)

#### 创建多边形(Create Polygon)

可以通过在场景视图中放置顶点来创建单独的多边形。

选择“网格工具 > 创建多边形”(Mesh Tools > Create Polygon) > ![图：选择“网格工具 创建多边形”(Mesh Tools Create Polygon) ，可设置创建多边形工具选项(Crea…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[创建多边形工具选项(Create Polygon Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/创建多边形工具选项%28Create%20Polygon%20Tool%20Options%29.md)。

#### 插入循环边(Insert Edge Loop)

允许您在多边形网格的整个或部分环形边上插入一个或多个循环边。循环边是由其共享顶点按顺序连接的多边形边的路径。

选择“网格工具 > 插入循环边”(Mesh Tools > Insert Edge Loop) > ![图：选择“网格工具 插入循环边”(Mesh Tools Insert Edge Loop) ，可设置插入循环边工具选项(In…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[插入循环边工具选项(Insert Edge Loop Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/插入循环边工具选项%28Insert%20Edge%20Loop%20Tool%20Options%29.md)。

#### 生成洞(Make Hole)

允许您在多边形的一个面中创建一个洞，也可以在另一个面的图形中创建一个洞。

选择“网格工具 > 生成洞”(Mesh Tools > Make Hole) > ![图：选择“网格工具 生成洞”(Mesh Tools Make Hole) ，可设置生成洞选项(Make Hole Optio…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[生成洞选项(Make Hole Options)](“网格工具”%28Mesh%20Tools%29菜单/生成洞工具选项%28Make%20Hole%20Tool%20Options%29.md)。

#### 多切割(Multi-Cut)

允许您对循环边进行切割、切片和插入。您可以沿着切割提取或删除边，通过边流和细分插入循环边和切割，并在“平滑网格预览”(Smooth Mesh Preview)模式下进行编辑。

选择“网格工具 > 多切割”(Mesh Tools > Multi-Cut) > ![图：选择“网格工具 多切割”(Mesh Tools Multi-Cut) ，可设置多切割工具选项(Multi-Cut Too…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[多切割工具选项(Multi-Cut Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/多切割工具选项.md)。

#### 偏移循环边(Offset Edge Loop)

允许您在所选的任何边的任一侧上插入两个循环边。

循环边是由其共享顶点按顺序连接的多边形边的路径。循环边形成的平行边线可穿越边选择的范围。在单一边的两侧或边线上向多边形网格添加本地化详细信息时，以这种方式复制边非常有用。

选择“网格工具 > 偏移循环边”(Mesh Tools > Offset Edge Loop) > ![图：选择“网格工具 偏移循环边”(Mesh Tools Offset Edge Loop) ，可设置偏移循环边工具选项(Of…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[偏移循环边工具选项(Offset Edge Loop Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/偏移循环边工具选项%28Offset%20Edge%20Loop%20Tool%20Options%29.md)。

#### 绘制减少权重(Paint Reduce Weights)

允许您在网格上绘制区域以指定要减少多边形的位置。

“绘制减少权重”(Paint Reduce Weights)与“网格 > 减少”(Mesh > Reduce)命令一起使用时，可以支持您在尝试保留原始图形的同时，减少网格中的多边形数量。请参见[减少选项(Reduce Options)](“网格”%28Mesh%29菜单/减少选项%28Reduce%20Options%29.md)。

选择“网格工具 > 绘制减少权重”(Mesh Tools > Paint Reduce Weights) > ![图：选择“网格工具 绘制减少权重”(Mesh Tools Paint Reduce Weights) ，可设置绘制减少权重工…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[绘制减少权重工具选项(Paint Reduce Weights Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/绘制减少权重工具选项%28Paint%20Reduce%20Weights%20Tool%20Options%29.md)。

#### 绘制传递属性(Paint Transfer Attributes)

允许您基于每个顶点融合源和目标的属性值，以控制任一网格对结果变形的影响。融合由您使用 Artisan 笔刷工具在网格上绘制的属性贴图控制。

选择“网格工具 > 绘制传递属性”(Mesh Tools > Paint Transfer Attributes) > ![图：选择“网格工具 绘制传递属性”(Mesh Tools Paint Transfer Attributes) ，可设置绘制…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[绘制传递属性工具选项(Paint Transfer Attributes Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/绘制传递属性工具选项%28Paint%20Transfer%20Attributes%20Tool%20Options%29.md)。

#### 四边形绘制(Quad Draw)

可用于以自然而有机的方式建模，使用简化的单工具工作流重新拓扑化网格。使用手动重新拓扑流程时，可以在保留参考曲面形状的同时，创建整洁的网格。

选择“网格工具 > 四边形绘制”(Mesh Tools > Quad Draw) > ![图：选择“网格工具 四边形绘制”(Mesh Tools Quad Draw) ，可设置“四边形绘制工具选项”(Quad Dr…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[“四边形绘制工具选项”(Quad Draw Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/四边形绘制工具选项%28Quad%20Draw%20Tool%20Options%29.md)。

#### 雕刻工具(Sculpting Tools)

允许您雕刻虚拟 3D 曲面，像在粘土或其他建模材质上雕刻真正的 3D 对象那样。不是使用粘土，而是使用多边形构建虚拟 3D 曲面。有关雕刻工具的列表，请参见[雕刻工具架](../../../../雕刻/雕刻/雕刻工具.md)。

选择“网格工具 > 雕刻工具 > <工具名称>”(Mesh Tools > Sculpting Tools > <tool name>) > ![图：选择“网格工具 雕刻工具 <工具名称 ”(Mesh Tools Sculpting Tools <tool name )…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置对应的[雕刻工具设置](../../../../雕刻/雕刻/雕刻工具设置.md)。

#### 滑动边(Slide Edge)

允许您重新定位多边形网格上的边或整个循环边的选择。

可以在按住 Shift 键的同时逐个选择边，或者双击某个边以选择整个循环边，然后使用鼠标中键拖动以滑动选定边。与选定边关联的顶点沿它们的共享垂直边移动。或者，可以按住 Shift 键并使用鼠标中键拖动以沿每个顶点法线移动边/循环边。

选择“网格工具 > 滑动边”(Mesh Tools > Slide Edge) > ![图：选择“网格工具 滑动边”(Mesh Tools Slide Edge) ，可设置滑动边工具选项(Slide Edge T…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 2415 字 ≥300，非承重" -->，可设置[滑动边工具选项(Slide Edge Tool Options)](“网格工具”%28Mesh%20Tools%29菜单/滑动边工具选项%28Slide%20Edge%20Tool%20Options%29.md)。
