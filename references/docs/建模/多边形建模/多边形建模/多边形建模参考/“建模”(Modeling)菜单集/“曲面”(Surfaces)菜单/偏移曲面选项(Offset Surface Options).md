# 偏移曲面选项(Offset Surface Options)

使用以下选项可设置在选择“曲面 > 偏移”(Surfaces > Offset)时发生的情况。

#### 方法(Method)

“曲面拟合”(Surface Fit)可创建保留曲面曲率的偏移曲面。

“CV 拟合”(CV Fit)将创建代表 CV 位置沿着其法线偏移的偏移曲面。

#### 偏移距离(Offset Distance)

此距离是指新曲面将会偏移的距离。凹曲面可能产生重叠和相交的区域。
