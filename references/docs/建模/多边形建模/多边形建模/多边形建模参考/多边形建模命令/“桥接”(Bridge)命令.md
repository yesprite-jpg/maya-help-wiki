# “桥接”(Bridge)命令

可以使用“桥接”(Bridge)命令在各对边界边之间构建面。生成的桥接面将合并到原始网格中。如果需要通过一块网格将两组边连接到一起，“桥接”(Bridge)十分有用。例如，将某个角色手臂上的手腕连接并合并到手上。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../assets/Maya-Modeling/GUID-81E54DF7-4C85-48A3-B94A-56CB4854D05E.png) <!-- baize:img-hook downloaded=true reason="正文 283 字 <300 且带图" -->

使用以下方法之一访问“桥接”(Bridge)命令：

- 从主菜单栏中选择“编辑网格 > 桥接”(Edit Mesh > Bridge)。

- 从标记菜单（Shift + 单击鼠标右键）中选择“桥接”(Bridge)

- 在[建模工具包](../多边形建模工具/建模工具包%28Modeling%20Toolkit%29.md)中单击 ![图：在建模工具包中单击](../../../../../../assets/Maya-Modeling/GUID-122BF128-2241-4A00-93E4-3B8DC0123E9F.png) <!-- baize:img-hook downloaded=true reason="正文 283 字 <300 且带图" -->

有关如何使用“桥接”(Bridge)命令的详细信息，请参见相关主题。
