# 倒角疑难解答

## 凸面和凹面

“倒角”(Bevel)工具作用于凸面，甚至星形凹面。但对于中心点不在面内的凹面，倒角会生成不合需要的结果。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](../../../../../../../assets/Maya-Modeling/GUID-9928D602-B6F5-4E3B-B0E6-539737837413.png) <!-- baize:img-hook downloaded=true reason="正文 144 字 <300 且带图" -->

若要修复凹面，请使用[“多切割工具”(Multi-Cut Tool)](../../多边形建模工具/多切割工具.md)或“网格 > 三角化”(Mesh > Triangulate)。
