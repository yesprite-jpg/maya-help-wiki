# 视图中编辑器

若要切换“视图中编辑器”(In-View Editors)的显示，请选择“显示 > 平视显示仪 > 视图中编辑器”(Display > Heads Up Display > In-View Editors)。

可用于直接在场景中调整属性，而不是打开通道盒或属性编辑器。

创建多边形基本体或执行许多常见的建模操作后，视图中编辑器将显示节点属性的可自定义子集，以允许您着重于使用最多的属性。

**注**

创建多边形基本体后，必须在

视图中编辑器

出现之前激活

“显示操纵器工具”(Show Manipulator Tool)

（热键：T）。

可以在视图中编辑器中调整通道盒中的所有属性。在通道盒中锁定属性也会在视图中编辑器中锁定它。

| 目标 | 操作 |
|---|---|
| 移动编辑器窗口 | 将窗口拖动到场景中的任意位置。 |
| 调整编辑器窗口的大小 | 拖动窗口的右下角。 |
| 显示或隐藏属性 | 单击 ![图：单击 ，然后从弹出菜单中选择或取消选择属性。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-D3FD6C66-4F2F-4481-9C84-A834BEA6FE4B.png) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" -->，然后从弹出菜单中选择或取消选择属性。 |
| 调整属性值 | 选择属性，然后使用鼠标中键在“视图中编辑器”(In-View Editors)窗口或场景中拖动。 |
| 在拖动期间加快或减慢属性更改。 | 单击 ![图：单击 。这会链接到通道盒中的相同设置。 注： 您也可以按住 Ctrl 键、Ctrl + Shift 键或 Shift 键…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-58C5C375-261A-4F3B-B136-F49A4AFCD34D.png) <!-- baize:img-hook downloaded=false reason="正文 616 字 ≥300，非承重" -->。这会链接到[通道盒](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-19CD9DD8-0119-448F-A1B8-93C82A74B633)中的相同设置。 注： 您也可以按住 Ctrl 键、Ctrl + Shift 键或 Shift 键并拖动属性名称来暂时减慢或加快属性更改，而无需实际上更改此设置。 |
| 将属性重置、移除或重新排序 | 在“视图中编辑器”(In-View Editors)窗口中的属性上单击鼠标右键，然后从弹出菜单中选择一个选项。 |
