# 多切割工具热键

| 热键 | 功能 |
|---|---|
| 单击/拖动 | 放置新点或移动现有点。 |
| 尚未放置任何切割点或切片点时： 按住 Ctrl 键并单击 按住 Ctrl 键并单击鼠标中键（捕捉到路径的中间） 同时按住 Ctrl 和 Shift 键并单击（捕捉到“捕捉步长 %”(Snap Step %)的增量） | [插入循环边](../../../编辑多边形/合并、分割和拆分/分割多边形组件/通过多切割工具分割多边形/使用多切割工具插入循环边.md)。 |
| 已经放置切割点时： 按住 Shift 键并单击边（捕捉到“捕捉步长 %”(Snap Step %)的增量） 按住 Shift 键并在边上拖动（以交互方式设置“捕捉步长 %”(Snap Step %)） 同时按住 Ctrl 和 Shift 键并单击（约束到垂直角度）。 | [将切割点捕捉到边](../../../编辑多边形/合并、分割和拆分/分割多边形组件/通过多切割工具分割多边形/使用多切割工具将切割点捕捉到边.md)。 [约束到垂直角度](../../../编辑多边形/合并、分割和拆分/分割多边形组件/通过多切割工具分割多边形/使用多切割工具进行%2090%20度角切割.md)。 |
| 放置切割点或切片点时： 按住 X 键并单击（将切片点捕捉到栅格） 按住 V 键并单击（将切片点捕捉到其他点） | [捕捉切片点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-86E5CEDA-4100-40AE-8F95-346206CF8456)。 |
| 从网格开始拖动 | [对面进行切片](../../../编辑多边形/合并、分割和拆分/分割多边形组件/通过多切割工具分割多边形/使用多切割工具对面进行切片.md) |
| 使用鼠标中键拖动到任意位置 | [快速对面进行切片](../../../编辑多边形/合并、分割和拆分/分割多边形组件/通过多切割工具分割多边形/使用多切割工具对面进行切片.md) |
| Backspace/Delete 键 | 撤消上次放置点，或删除亮显的边。 |
| Z/Shift + Z | 撤消/重做任何操作。 |
| 按住鼠标中键并拖动切片平面 | 重新放置切片平面。 |
| 单击鼠标右键/输入 | 完成切割或切片。 |
| Esc 键 | 取消切割或切片操作。 |
| 按住 X 或 V 键并单击 | 在放置点时激活栅格或点捕捉。 |
| 按 Ctrl + Shift 键并单击鼠标右键 | 打开“多切割工具”(Multi-Cut Tool)标记菜单 |
