# “扫描网格”(Sweep Mesh)工具

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-69A508A8-2558-4720-AC8A-0FEF8496C475.gif) <!-- baize:img-hook downloaded=false reason="正文 303 字 ≥300，非承重" -->

使用“扫描网格”(Sweep Mesh)工具可以从曲线的长度生成可编辑网格，从而创建大量的有机和硬曲面形状，如管、管道、带子、电缆、绳索、道路、角、发卡以及天花线等建筑细节。

若要使用“扫描网格”(Sweep Mesh)工具，请参见[使用“扫描网格”(Sweep Mesh)从曲线创建网格](../../多边形选择和创建/使用“扫描网格”%28Sweep%20Mesh%29从曲线创建网格/使用“扫描网格”%28Sweep%20Mesh%29创建自定义网格.md)。

若要打开“扫描网格”(Sweep Mesh)，请在选择曲线后，从“建模”(Modeling)菜单集 (**F2**) 中选择“曲线 > 扫描网格”(Curves > Sweep Mesh)。

有关使用“扫描网格”(Sweep Mesh)的示例项目，请参见[扫描网格示例工作流：开瓶器](../../多边形选择和创建/使用“扫描网格”%28Sweep%20Mesh%29从曲线创建网格/扫描网格示例工作流：开瓶器.md)、[扫描网格示例工作流：框架](../../多边形选择和创建/使用“扫描网格”%28Sweep%20Mesh%29从曲线创建网格/扫描网格示例工作流：开瓶器.md)和[扫描网格示例工作流：动画曲线](../../多边形选择和创建/使用“扫描网格”%28Sweep%20Mesh%29从曲线创建网格/扫描网格示例工作流：开瓶器.md)。
