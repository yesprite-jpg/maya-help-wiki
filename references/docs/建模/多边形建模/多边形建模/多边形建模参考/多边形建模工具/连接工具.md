# 连接工具

使用“连接工具”(Connect Tool)可以通过在多边形组件之间插入边来连接这些组件。顶点将直接连接到连接边，而边将在其中点处进行连接。插入边可以将细节添加到简单网格。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-F8092685-6024-47BC-B263-0E2D3D2C253E.png) <!-- baize:img-hook downloaded=false reason="正文 309 字 ≥300，非承重" -->

可以通过以下方式访问“连接工具”(Connect Tool)：

- 访问[建模工具包(Modeling Toolkit)](建模工具包%28Modeling%20Toolkit%29.md)窗口的“工具”(Tools)部分，然后单击 ![图：访问建模工具包(Modeling Toolkit)窗口的“工具”(Tools)部分，然后单击 。](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-875D90E7-318D-45B0-88D3-18CD8C53DAF7.png) <!-- baize:img-hook downloaded=false reason="正文 309 字 ≥300，非承重" -->。

- 选择“网格工具 > 连接”(Mesh Tools > Connect)，访问主菜单栏。

- 选择“连接工具”(Connect Tool)（以打开标记菜单，在选中对象、边或面后，按住 Shift 键单击鼠标右键），访问标记菜单。

有关如何使用该工具的详细信息，请参见相关主题。
