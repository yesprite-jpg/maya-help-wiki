# 建模工具包选择约束

可以使用选择约束来快速预览和选择一组组件。

**注**

提示：

使用鼠标中键单击

按钮可在上次选定的选择约束和

“禁用”(Off)

之间切换。

“建模工具包”(Modeling Toolkit)中的选择约束不会过滤选择。以下选项使用传播，会将选择扩展到同一网格上的其他组件。

#### 禁用(Off)

禁用选择约束。

#### 角度(Angle)

启用时，将光标移至网格上会自动亮显指定的角度容差内的连续组件。单击亮显的区域会将其选中。

“角度”(Angle)选择约束启用后，进行框选会选择选取框内的所有组件并将选择扩展到选取框外处于指定角度容差内的所有组件。

**注**

选择面后，会比较每个面法线的角度，以确定其是否在指定的角度容差范围内。选择边或顶点后，选择先转化为其关联的面，然后比较每个面法线的角度。

#### 边界(Border)

启用时，将光标移至网格上将自动亮显现有边界。单击亮显的边界会将其选中。

如果框选范围包含边界组件，则仅选择选取框内外的边界组件。

#### 循环边(Edge Loop)

启用时，将光标移至网格上将自动亮显循环边。单击亮显的循环边会将其选中。

“循环边”(Edge Loop)选择约束启用后，进行框选会选择选取框内的边及所有关联的循环边。在进行框选时，也可以添加和移除循环边。请参见[在选择中添加和移除组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-98CCC417-B06A-4E19-A3C6-19EF75295EEA)。

**注**

只有

“边”(Edge)

选择模式处于启用状态时，

“循环边”(Edge Loop)

选择约束才可用。

#### 环形边(Edge Ring)

启用时，将光标移至网格上将自动亮显环形边。单击亮显的环形边会将其选中。

“环形边”(Edge Ring)选择约束启用后，进行框选会选择选取框内的边及所有关联的环形边。在进行框选时，也可以添加和移除环形边。请参见[在选择中添加和移除组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-98CCC417-B06A-4E19-A3C6-19EF75295EEA)。

**注**

只有

“边”(Edge)

选择模式处于启用状态时，

“环形边”(Edge Loop)

选择约束才可用。

#### 壳(Shell)

启用时，将光标移至网格上将自动亮显现有壳。单击亮显的壳会将其选中。此选项可用于由一系列单独片生成的对象，类似于使用“网格 > 结合”(Mesh > Combine)创建的网格。

#### UV 循环边(UV Edge Loop)

启用时，如果在网格上方移动光标时，则会自动亮显在 UV 纹理边界处结束的循环边。
