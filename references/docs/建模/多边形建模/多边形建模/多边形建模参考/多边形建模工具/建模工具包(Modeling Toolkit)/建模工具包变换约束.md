# 建模工具包变换约束

通过建模工具包中的变换约束，可以沿活动网格的边或曲面滑动组件。

可以在[“建模工具包”(Modeling Toolkit)](../建模工具包%28Modeling%20Toolkit%29.md)或任何变换工具的工具设置中启用变换约束。

**注**

提示：

使用鼠标中键单击

按钮可在上次选定的变换约束和

“禁用”(Off)

之间切换。

#### 禁用(Off)

（默认）禁用变换约束。允许您使用变换工具来平移、旋转或缩放组件，而不受约束。

#### 边滑动(Edge Slide)

允许您沿活动对象的边滑动选定组件。在“组件模式”(Component Mode)下移动组件时，也可以按 Ctrl + Shift 以激活此约束。请参见[滑动多边形组件](../../../编辑多边形/变换多边形组件/沿边滑动多边形组件.md)。

#### 曲面滑动(Surface Slide)

允许您在活动对象的曲面上滑动选定组件。请参见[沿曲面移动多边形组件](../../../编辑多边形/变换多边形组件/沿曲面移动多边形组件.md)。

**注**

您也可以使用

“激活”(Make Live)

将工具约束到曲面。例如，您可以将

“四边形绘制”(Quad Draw)

工具约束到要重新拓扑的网格的曲面。

“激活”(Make Live)

处于活动状态期间，变换约束会遭到禁用。有关重新拓扑的详细信息，请参见

使用四边形绘制重新拓扑网格

。
