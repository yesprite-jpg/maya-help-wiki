# “建模工具包”(Modeling Toolkit)热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

**注**

提示：

在

“建模工具包”(Modeling Toolkit)

窗口中，展开

“四边形绘制选项”(Quad Draw Options)

、

“连接选项”(Connect Options)

、

“多切割选项”(Multi-Cut Options)

和

“目标焊接选项”(Target Weld Options)

中的

“键盘/鼠标快捷方式”(Keyboard/Mouse Shortcuts)

部分以查看每个工具的热键。

|  | 功能 |
|---|---|
| Ctrl + Tab | 多组件选择模式 |
| F9 | 顶点选择模式 |
| F10 | 边选择模式 |
| F11 | 面选择模式 |
| 切换组件模式 | 按住 Ctrl 键并单击选择模式图标（顶点、边、面）。 |

请参见[使用“建模工具包”(Modeling Toolkit)选择组件](../../../多边形选择和创建/使用建模工具包选择多边形组件/使用建模工具包选择模式选择组件.md)

|  | 功能 |
|---|---|
| ` | 调整模式。请参见[在调整模式下移动组件](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-4E480668-4BF3-4E27-823B-41DB4C61C19A)。 |
| b | 软选择模式。请参见[软选择组件](../../../多边形选择和创建/软选择组件.md)。 |
| d | 自定义枢轴编辑模式。请参见[更改枢轴点](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-150B390E-840B-4FE3-B8E9-8DEBCE7CEC97)。 |

|  | 功能 |
|---|---|
| x | 捕捉到栅格交点 |
| c | 捕捉到曲线 |
| V | 捕捉到 CV、顶点、枢轴 |

## 多切割工具

请参见[多切割工具热键](../多切割工具/多切割工具热键.md)。

| 热键 | 功能 |
|---|---|
| 单击边 | 插入循环边。 |
| 按住 Shift 键并单击组件 | 在组件之间插入连接边。 |
| 按住 Ctrl 键并单击组件 | 从当前选择中移除组件。 |

请参见[使用连接工具在多边形组件之间添加边](../../../编辑多边形/合并、分割和拆分/分割多边形组件/使用连接工具在多边形组件之间添加边.md)。

| 热键 | 功能 |
|---|---|
| 拖动 | 合并组件。 |
| 使用鼠标中键拖动 | 将组件合并到中心。 |

请参见[合并多边形组件](../../../编辑多边形/合并、分割和拆分/合并多边形/使用目标焊接工具%28Target%20Weld%20Tool%29以交互方式合并多边形组件.md)。
