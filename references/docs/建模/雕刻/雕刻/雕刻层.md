# 雕刻层

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-A1A41652-7B66-4387-BB37-F368C87B98B4.png) <!-- baize:img-hook downloaded=false reason="正文 634 字 ≥300，非承重" -->

在网格上雕刻细节时，可以使用[融合变形目标](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-E980D990-53FC-47C9-B9B8-C8451E933665)作为雕刻层。这样，您能够以堆叠方式构建雕刻效果，单独构建不同种类的雕刻（如褶皱和毛孔），或尝试以非破坏性方式对模型应用新雕刻。

设置层以进行雕刻

1. 转到“窗口 > 动画编辑器 > 形变编辑器”(Windows > Animation Editors > Shape Editor)或切换到“雕刻工作区”(Sculpting Workspace)，以打开[形变编辑器(Shape Editor)](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-3C92402C-B24E-4874-AC8D-EADF976A19DC)。

2. 选择要进行雕刻的网格，然后单击“形变编辑器”(Shape Editor)中的“创建融合变形”(Create Blend Shape)。

3. 单击“添加目标”(Add Target)按钮以添加第一个层。

  默认情况下，该层将成为活动“编辑”(Edit)层。任何雕刻操作均会添加到该层中。

4. 单击“添加目标”(Add Target)以添加其他层。

**注**

当前

“编辑”(Edit)

层始终标记为红色。网格的任何雕刻操作或变换均在该层上发生。若要更改活动

“编辑”(Edit)

层，请单击要激活的层旁边的

“编辑”(Edit)

按钮。

![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-F5B52F4D-3468-4E8E-B8C5-AD738D1F0996.gif) <!-- baize:img-hook downloaded=false reason="正文 634 字 ≥300，非承重" -->

在层上雕刻后，可以使用几种不同的方式减弱/隐藏该层的效果。

减弱/隐藏层效果

1. 在“形变编辑器”(Shape Editor)中拖动目标形状旁边的滑块以更改其权重。

2. 单击目标形状左侧的可见性图标以完全禁用该层的效果。

3. 在层上单击鼠标右键，然后选择“单放”(Solo)以禁用所有其他层。

**注**

您可以在

“形变编辑器”(Shape Editor)

中使用鼠标中键拖动层以对其进行重新排序。
