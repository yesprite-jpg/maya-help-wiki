# 雕刻目标工具

除了常规雕刻工具以外，Maya 还提供了一部分专用于处理融合变形的工具。这些工具适用于将一个或多个融合变形特定的变形作为目标，而不会对其他融合变形产生负面影响。有关融合变形工作流的详细信息，请参见[形变创作](https://beehive.autodesk.com/community/service/rest/cloudhelp/resource/cloudhelpchannel/guidcrossbook/jsonp?v=2022&p=MAYAUL&l=CHS&accessmode=live&guid=GUID-B8853C3F-2997-4DC2-95A0-7C43E45888E4)。

在“雕刻”(Sculpting)工具架上和“网格工具 > 雕刻工具”(Mesh Tools > Sculpting Tools)菜单中，将显示以下工具。有关与这些工具关联的公用设置列表，请参见[雕刻工具设置](雕刻工具设置.md)。

| 工具名称 | 图标 | 用途 |
