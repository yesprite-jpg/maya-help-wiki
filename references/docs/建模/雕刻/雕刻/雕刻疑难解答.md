# 雕刻疑难解答

此表列出了常见的雕刻问题和可能的解决方案：

| 问题/错误消息 | 可能的解决方案 |
|---|---|
| 雕刻笔划看起来不稳定、不平滑。 | 手颤抖会使雕刻平滑笔划变得很难。启用“稳定笔划”(Steady Stroke)选项以生成更平滑的笔划。请参见[生成平滑工具笔划](生成平滑工具笔划.md)。 |
| 指示雕刻工具半径的光标轮廓消失了。 | 仅当雕刻工具在视口中的模型之上时，才显示工具光标的轮廓。将光标定位到模型之上以查看它。 “半径”(Radius)设置设得太大，轮廓显示在当前视口之外。如果工具光标离开模型，则使用 B 热键设置“半径”(Radius)时会出现此情况。请参见[雕刻工具设置](雕刻工具设置.md)。 |
| 在模型上雕刻时未显示笔划。 | 与当前雕刻工具的大小相比，模型的分辨率太粗糙。添加更多的细分级别以提高模型的分辨率，或者增大工具的半径。 对于雕刻工具，雕刻工具的“强度”(Strength)设置设得太低。增大“强度”(Strength)。 |
| 在模型的曲面上显示了两个雕刻工具光标。 | 工具的“镜像”(Mirror)设置已启用。如果您不希望进行对称雕刻，请禁用“镜像”(Mirror)。请参见[雕刻工具设置](雕刻工具设置.md)。 |
| 雕刻导致在模型上显示了大钉形效果。 | 与工具半径相比，工具的“强度”(Strength)设置设得太高。撤消笔划 (Ctrl + Z) 并降低雕刻工具的“强度”(Strength)设置。请参见[雕刻工具设置](雕刻工具设置.md)。 |
| 在雕刻时对称设置没有任何效果。 | 指定了错误的镜像轴。检查镜像雕刻设置，并根据需要进行重置。 如果将模型移离 XYZ 原点，则一些镜像轴特性将不起作用。请参见[使用工具对称进行雕刻](使用对称进行雕刻.md)。 |
| 雕刻性能下降。 | 为避免交互性能下降，请尝试以下几项操作： 在“首选项”(Preferences)的“显示”(Display)设置中，将 Viewport 2.0 的“渲染引擎”(Rendering Engine)设置为 OpenGL。然后，在当前雕刻笔刷“工具设置”(Tool Settings)的“显示”(Display)部分中，同时禁用“显示冻结/遮罩”(Show frozen/masked)和“线框显示”(Wireframe Display)。 与较低的细分级别（使用相同大小的笔刷）相比，在较高的细分级别（特定大小的笔刷修改多个顶点时）上雕刻需要更多的 RAM，因为影响更少的顶点。 通常，在较低的细分级别上进行影响曲面的较大区域的更改。移动了较少的顶点，因此提高了雕刻性能。 |
