# 雕刻工具

在“雕刻”(Sculpting)工具架上和“网格工具 > 雕刻工具”(Mesh Tools > Sculpting Tools)菜单中，将显示以下工具。有关与这些工具关联的公用设置列表，请参见[雕刻工具设置](雕刻工具设置.md)。

| 平滑(Smooth) | ![图：（图旁无可取正文，Maya 手册 img 无 alt）](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-11884A09-A586-43E0-B60E-7B5C8E37D78B.png) <!-- baize:img-hook downloaded=false reason="正文 1749 字 ≥300，非承重" --> | 通过平均化顶点的位置，将相对彼此的顶点位置拉平。 在其他雕刻工具已处于活动状态时，按 Ctrl + 2 可激活“平滑”(Smooth)工具。 |
