# 雕刻工具热键

**注**

除非另有指定，否则请使用 Mac OS X 上的以下特殊键，而不是其 Windows 等效键。

- Alt = Option

- Ctrl = Control

- Windows 键 = Command

| **操作** | **Windows** 和 **Linux** | **Mac OS X** | **结果** |
|---|---|---|---|
| 调整笔刷大小 | 按住 B 键并拖动，或者使用鼠标中键 (MMB) 向左/向右拖动 | 按住 B 键并拖动，或者使用鼠标中键向左/向右拖动 | 在您拖动时，工具光标将调整为更大和更小。 |
| 从 0 调整笔刷大小 | 按住 B 键并使用鼠标中键向左/向右拖动，或者按住 Ctrl 键并使用鼠标中键向左/向右拖动 | 按住 B 键并使用鼠标中键向左/向右拖动，或者按住 Ctrl 键并使用鼠标中键向左/向右拖动 | 在您拖动时，工具光标将调整为更大和更小。 |
| 调整笔刷强度 | 按住 M 键并拖动，或者使用鼠标中键向上/向下拖动 | 按住 M 键并拖动，或者使用鼠标中键向上/向下拖动 | 在您拖动时，笔刷强度指示器将变长或变短。 |
| 从 0 调整笔刷强度 | 按住 M 键并使用鼠标中键向上/向下拖动，或者按住 Ctrl 键并使用鼠标中键向上/向下拖动 | 按住 M 键并使用鼠标中键向上/向下拖动，或者按住 Ctrl 键并使用鼠标中键向上/向下拖动 | 在您拖动时，笔刷强度指示器将变长或变短。 |
| 反转(Invert) | Ctrl | Ctrl | 如果当前工具具有反转功能，则在雕刻时将应用反转功能。 “反转”(Invert)处于活动状态时，工具的笔刷环将变为白色。 |
| 平均化法线(Averaged Normal) | Ctrl | Ctrl | 沿平均化法线在笔刷内拉动顶点。 “平均化法线”(Averaged Normal)处于活动状态时，工具的笔刷环将变为白色。 注： “平均化法线”(Averaged Normal)特定于“抓取”(Grab)雕刻工具。 |
| 反转冻结(Invert Frozen) | Ctrl + Shift + I | Ctrl + Shift + I | 反转活动网格的已冻结和未冻结部分。 |
| 全部解冻(Unfreeze All) | Shift + U | Shift + U | 在使用任何雕刻工具时，移除活动网格上的所有冻结。 |
| 暂时激活“平滑”(Smooth) 工具 | Shift 键 | Shift 键 | 暂时平滑顶点，而不管哪个工具处于活动状态。（松开 Shift 键将还原为选定的工具功能。） “平滑”(Smooth)处于活动状态时，工具的笔刷环将变为浅蓝色。 |
| 松弛(Relax) | Ctrl+Shift | Ctrl+Shift | 平滑网格的曲面，而不影响其形状。 “松弛”(Relax)处于活动状态时，工具的笔刷环将变为浅黄色。 |
| 将雕刻工具添加到活动工具架 | Ctrl+Shift | Ctrl+Shift | 按住 Ctrl 和 Shift 键并将菜单项从“网格工具 > 雕刻工具”(Mesh Tools > Sculpting Tools)菜单拖动到工具架。 |
| 框显光标下的网格区域 | F | F | 光标位于活动雕刻网格上方时，摄影机将放大光标下的区域。 |
| 围绕将雕刻的网格部分翻滚 | 启用“翻滚枢轴”(Tumble pivot)和“自动设置翻滚枢轴”(Automatically set tumble pivot)（“视图 > 摄影机工具 > 翻滚工具”(View > Camera Tools > Tumble Tool) > ![图：启用“翻滚枢轴”(Tumble pivot)和“自动设置翻滚枢轴”(Automatically set tumble p…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1986 字 ≥300，非承重" -->），然后按住 Alt 键并拖动 | 启用“翻滚枢轴”(Tumble pivot)和“自动设置翻滚枢轴”(Automatically set tumble pivot)（“视图 > 摄影机工具 > 翻滚工具”(View > Camera Tools > Tumble Tool) > ![图：启用“翻滚枢轴”(Tumble pivot)和“自动设置翻滚枢轴”(Automatically set tumble p…](https://help.autodesk.com/cloudhelp/2022/CHS/Maya-Modeling/images/GUID-23B160F6-E1FB-4E29-94B2-7323BFE33726.png) <!-- baize:img-hook downloaded=false reason="正文 1986 字 ≥300，非承重" -->），然后按住 Alt 键并拖动 | 围绕最近笔划的开始点翻滚摄影机。如果没有要考虑的笔划，则摄影机将围绕视图中心翻滚。 |
| 打开“雕刻工具”(Sculpting Tools)标记菜单 | 在雕刻工具处于活动状态时按住 Ctrl 或 Shift 键并单击鼠标右键 | 在雕刻工具处于活动状态时按住 Ctrl 或 Shift 键并单击鼠标右键 | 打开“雕刻工具”(Sculpting Tools)标记菜单。 （必须已选择另一个雕刻工具。） |
| 切换到“雕刻”(Sculpt)工具 | Ctrl + 1 | Ctrl + 1 | 激活“雕刻”(Sculpt)工具。 （必须已选择另一个雕刻工具。） |
| 切换到平滑工具 | Ctrl + 2 | Ctrl + 2 | 激活平滑工具。 （必须已选择另一个雕刻工具。） |
| 切换到松弛工具 | Ctrl + 3 | Ctrl + 3 | 激活松弛工具。 （必须已选择另一个雕刻工具。） |
| 切换到抓取工具 | Ctrl + 4 | Ctrl + 4 | 激活抓取工具。 （必须已选择另一个雕刻工具。） |
| 切换到收缩工具 | Ctrl + 5 | Ctrl + 5 | 激活收缩工具。 （必须已选择另一个雕刻工具。） |
| 切换到展平工具 | Ctrl + 6 | Ctrl + 6 | 激活展平工具。 （必须已选择另一个雕刻工具。） |
| 切换到泡沫工具 | Ctrl + 7 | Ctrl + 7 | 激活泡沫工具。 （必须已选择另一个雕刻工具。） |
| 切换到喷射工具 | Ctrl + 8 | Ctrl + 8 | 激活喷射工具。 （必须已选择另一个雕刻工具。） |
| 切换到重复工具 | Ctrl + 9 | Ctrl + 9 | 激活重复工具。 （必须已选择另一个雕刻工具。） |
| 切换到冻结工具 | Ctrl + 0 | Ctrl + 0 | 激活冻结工具。 （必须已选择另一个雕刻工具。） |
